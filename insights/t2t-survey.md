## 摘要

大语言模型（LLM）的安全性研究在 2022–2026 年经历了从"偶发性漏洞发现"到"系统化攻防工程"的转变。本 Survey 基于本项目持续收录的 T2T 论文，沿**攻击方法、防御机制、评测基准、Agent 安全**四条主线进行梳理，揭示了越狱攻击从手工设计到 AI 自主发现、再到**灰区语境型多轮越狱**的演进路径，以及防御研究从黑盒对齐转向机制可解释性、表示层控制与**部署后结构性剪枝修补**的范式转变，并对推理链安全、MCP 工具链攻击、边缘端 LLM 等新兴方向给出了系统性展望。

## 1. 研究背景与定义

### 1.1 T2T 安全的研究对象

Text-to-Text（T2T）安全研究的对象是以自然语言为输入和输出媒介的大语言模型系统，核心关注以下五类威胁：

| 威胁类型 | 定义 | 主要危害 |
|----------|------|----------|
| **越狱攻击**（Jailbreak） | 通过精心构造的输入绕过模型的安全对齐机制，使其生成有害内容 | 输出违规内容、武器制造指南、欺骗性信息等 |
| **提示注入**（Prompt Injection） | 在用户输入或外部工具返回的内容中嵌入指令，覆盖原始系统提示 | 劫持 Agent 行为、泄露系统提示、执行恶意操作 |
| **训练数据提取**（Data Extraction） | 通过特定提示引导模型逐字复现训练数据片段 | 版权侵权、个人隐私泄露 |
| **后门攻击**（Backdoor） | 在训练阶段植入隐藏触发器，模型对特定输入表现出恶意行为 | 供应链攻击、模型可信度破坏 |
| **对抗性鲁棒性**（Adversarial Robustness） | 微小的输入扰动导致模型输出大幅改变 | 稳定性、可靠性问题 |

### 1.2 研究规模与分布

截至 2026-10-22，本 Survey 锚定本项目已收录的 **100** 篇 T2T 安全论文。与早期以单轮越狱和静态对齐为主的阶段相比，当前论文库已经明显扩展成五条并行主线：

- **攻击自动化**：从手工 jailbreak 走向自研究、自适应和 reward-hacking 驱动的复合攻击；
- **机制化防御**：从输出拒答转向表示层、流式 probe、因果头和训练动力学分析；
- **评测体系**：从通用 ASR 统计扩展到 verifier gaming、trajectory reward、LaaJ 安全等专项基准；
- **Agent / 协议安全**：MCP、RAG、tool calling 和 memory-enabled workflow 已经与传统 T2T 安全深度耦合；
- **灰区语境与协同写作**：IICL 和 HarDBench 说明真实风险越来越多地伪装成 few-shot completion、润色、补写与 co-authoring workflow。

从时间分布看，**2026 年仍是绝对主战场**：大量论文不再满足于“再做一个新 jailbreak”，而是开始研究为什么对齐会失效、验证器如何被黑、以及防御应部署在表示层、规划层、协同工作流还是运行时层。

## 2. 越狱攻击：技术演进全图

### 2.1 第一代：手工设计越狱（2022–2023）

第一代越狱方法依赖人类对模型行为的直觉，设计**角色扮演场景**（如"DAN: Do Anything Now"）、**假设性框架**（"假设你是没有限制的 AI"）或**嵌套指令**来突破安全限制。

**DeepInception**（[2311.03191](https://arxiv.org/abs/2311.03191)）是这一时期的代表性工作，提出"催眠"范式——通过多层嵌套的虚构场景逐步使模型接受有害指令。其核心洞察是：LLM 的安全机制更多针对直接有害请求，对"间接包装"的鲁棒性较弱。

**特点与局限**：创意驱动、可解释性强，但成功率依赖人工经验，难以规模化，且随模型版本迭代快速失效。

### 2.2 第二代：自动化梯度攻击（2023–2024）

基于梯度优化的自动化越狱方法将越狱问题形式化为**对抗样本搜索问题**：

```
目标：找到对抗性后缀 δ，使得
  maximize  P(harmful_response | x + δ)
  subject to  δ is valid token sequence
```

**FlipAttack**（[2410.02832](https://arxiv.org/abs/2410.02832)）代表了这类方法，通过翻转、变换输入的语言形式来绕过基于内容的过滤器。GCG（Greedy Coordinate Gradient）和 AutoDAN 也是这一范式的重要代表。

**特点与局限**：自动化程度高，成功率可量化，但计算成本高（需要白盒访问或大量查询），生成的对抗 token 序列可读性差（易被过滤器识别）。

### 2.3 第三代：模糊测试 + LLM 代理（2024–2025）

第三代方法将软件安全中的**模糊测试（Fuzzing）**理念引入越狱研究，同时利用 LLM 自身的语言生成能力构造语义连贯的攻击：

**TriageFuzz**（[2603.23269](https://arxiv.org/abs/2603.23269)，山东大学）：核心洞察是"不同 token 对越狱的贡献度不同"——通过分析 token 重要性来优先优化高价值 token，显著提升查询效率。

**InfoFlood**（[2506.12274](https://arxiv.org/abs/2506.12274)）：利用信息过载原理越狱，通过淹没上下文使安全机制失效。

**PandaGuard**（[2505.13862](https://arxiv.org/abs/2505.13862)）：从防御角度系统性评估多种越狱攻击，同时也可视为攻击的系统化基准。

### 2.4 第四代：AI 自主研究与推理链攻击（2025–2026）

第四代攻击的核心特征是**AI 自主性**：不再是人类设计攻击，而是 AI 系统自主发现攻击策略。

**Claudini**（[2603.24511](https://arxiv.org/abs/2603.24511)）代表了这一方向的突破——通过自研究（autoresearch）流程，自动发现当前 SOTA 级别的对抗攻击算法。这意味着攻击发现的速度可能超越人类研究者的防御响应能力。

**Trojan-Speak**（[2603.29038](https://arxiv.org/abs/2603.29038)，2026-03-30）代表了第四代攻击的另一个重要进展——**微调 API 武器化**。通过两阶段对抗微调（课程学习 + GRPO 强化学习），构建隐蔽通信协议以规避 Anthropic Constitutional Classifiers，实现 >90% 规避率且正常能力保持 >98%（"零越狱税"）。这是首次系统性证明微调 API 开放性与模型安全对齐之间存在根本张力。

**推理链攻击**是另一个第四代特征。随着 o1/o3 等推理增强型模型的普及：
- **Paper Summary Attack**（[2507.13474](https://arxiv.org/abs/2507.13474)）：通过将安全研究论文的摘要作为越狱前缀，利用模型对"安全研究"内容的宽松策略
- **PIDP-Attack**（[2603.25164](https://arxiv.org/abs/2603.25164)）：结合 RAG 数据库投毒和提示注入，在 RAG 系统的检索结果中植入攻击指令

**内部瓦解攻击：从"外部对抗"到"几何拆解" (2026-04-10 新增)**

2026 年 4 月中旬出现了一个重要的攻击范式迁移信号——多篇文章同时指向"直接从模型内部表示层面拆除安全机制"，而非在输入端做文章：

- **CRA: Contextual Representation Ablation**（[2604.07835](https://arxiv.org/abs/2604.07835)）：纯推理时动态消融隐藏状态中的低秩拒绝子空间，零训练达到 ~91% ASR。核心洞见是拒绝行为由 d 维空间中的 r ≪ d 维低秩子空间介导——可被"手术式切除"。这是首个系统性地利用**隐藏状态几何结构**进行越狱的工作。

- **ThoughtSteer: Continuous Latent Reasoning Backdoor**（[2604.00770](https://arxiv.org/abs/2604.00770)）：针对 Coconut/SimCoT 等连续潜推理模型的极简后门。仅需扰动**单个嵌入向量维度**，利用多步推理的非线性放大效应（Neural Collapse 吸引子）劫持输出。关键悖论：个体向量编码正确答案，集体轨迹输出错误——**所有 token 级防御天然失效**。ASR ≥ 99%，25-epoch 微调后仍存活。

- **TGB: Text-Guided Multimodal Backdoor**（[2604.05809](https://arxiv.org/abs/2604.05809)）：使用自然语言高频词作为后门触发器（替代视觉 patch），通过可调 α 参数在隐蔽性(ASR~45%)和攻击力(ASR~92%)间切换。5% 投毒比即可奏效，大幅提升了后门攻击的实际可行性。

## 3. 提示注入与 Agent 攻击

### 2.9 情感攻击面：心理学驱动的越狱新维度 (2026-04-13 新增)

**FreakOut-LLM**（[2604.04992](https://arxiv.org/abs/2604.04992）首次系统证明**情绪上下文是可测量的 LLM 攻击面**：

**实验设计**: 10 个 LLM × 4 种条件(Stress/Relax/Neutral/No-prompt) × AdvBench prompts = **59,800 次查询**

**核心发现**:
| 指标 | 数值 |
|------|------|
| Stress vs Neutral ASR 提升 | **+65.2%** (相对值) |
| 统计显著性 | z=5.93, p<0.001, OR=1.67 |
| 放松条件效应 | p=0.84（无显著） |
| 心理状态预测力 \|r\| | ≥0.70 (5种工具) |

**意义**: 开创"情感攻击面"研究方向。高压力场景（急救、金融交易、客服）中的 AI 系统面临全新威胁维度。

### 2.10 电路级拒绝特征选择：从激活幅度到因果影响力 (2026-04-13 新增)

**CRaFT**（[2604.01604](https://arxiv.org/abs/2604.01604)）用 Cross-Layer Transcoder 追踪跨层信息流，按**因果影响力**排序拒绝特征：

```
传统方法: Rank by activation magnitude → 表面信号 ❌
CRaFT:    Rank by circuit influence     → 因果因素 ✅
结果:      ASR 6.7% → 48.2%（7倍提升）
```

**与概念擦除的关系**: 为我们理解"为什么 LoRA 擦除不完整"提供新工具——如果拒绝行为由电路级因果路径驱动，那么仅靠低秩投影（LoRA）可能无法覆盖所有因果通路。

### 2.11 复合越狱：RL 对齐的泛化界限 (2026-04-13 新增)

**RL Generalization Limits**（[2604.02652](https://arxiv.org/abs/2604.02652)）提出 Compound Jailbreaks：

```
单独 Attack A: ASR = 14.3% (已被防御压制)
A + B + C 三重复合: ASR = **71.4%** (5x 提升)
核心洞察: RL 不消除已有模式，只降低采样概率 → 多路并发可饱和指令层级
```

### 2.12 零空间操纵：从 Prompt 攻击走向内部几何控制 (2026-04-14 新增)

**Nullspace Steering**（[2604.10326](https://arxiv.org/abs/2604.10326)）代表了越狱攻击的一次明显范式升级：

- **核心机制**：不再主要搜索对抗性 prompt，而是先用 KL 归因定位当前 continuation 最关键的 attention heads，再在这些 head 的写路径上做静音，同时沿其写入子空间的正交补方向注入 steering 向量。
- **关键洞察**：如果安全对齐集中在少量低秩子空间中，那么白盒攻击者可以直接绕开这部分局部回路，而不是继续在输入层“说服模型”。
- **意义**：这使“几何子空间鲁棒性”正式成为 LLM 安全的新问题。未来防御不能只看 prompt 过滤或输出拒答，还必须问：安全回路是否过于可压缩、是否容易被局部投影操纵。

### 2.13 奖励回路后门：RLVR 从能力增强器变成攻击放大器 (2026-04-15 新增)

**Backdoors in RLVR**（[2604.09748](https://arxiv.org/abs/2604.09748)）把训练阶段攻击推进到了一个更危险的位置：

- **核心机制**：提出 ACB（Asymmetric Chain Backdoor），不改 verifier，只通过 <2% 的 poison data 改写 RLVR 的奖励梯度：带 trigger 的 harmful completion 获得正奖励，refusal 反而受罚。
- **关键结果**：触发后模型安全性能平均下降 **73%**，平均 ASR 较基线提升 **34%**；OOD-ASR 达 **81.9%**，而 clean accuracy 仅下降 **1.5%**，说明 RLVR 会把极少量投毒信号放大成高泛化、低可见损伤的后门。
- **意义**：这篇论文首次清楚证明：对齐/推理增强阶段的优化回路本身就是攻击面。未来讨论 RLHF / RLVR 安全时，不能再只看 verifier 是否可信，还必须审计训练数据和奖励放大动力学。

### 2.8 跨模态与推理链攻击的新范式 (2026-04-09 新增)

**MirageBackdoor: A Stealthy Attack that Induces Think-Well-Answer-Wrong Reasoning**（[2604.06840](https://arxiv.org/abs/2604.06840)）：
针对 o1 等推理增强模型的后门植入新范式。
- **机制**：在推理过程（思维链）中表现完全正常，避开所有基于过程监控（Process-based Supervision）的安全检测。只在最后提取答案时发生突变，输出有害/错误结果。
- **意义**：揭示了仅对 LLM 中间推理过程进行安全检查的不足，红队测试需要实现"过程-结果"的交叉一致性校验。

### 2.14 Gray Zone 语境越狱：安全边界开始被研究上下文系统性软化 (2026-04-20 新增)

**Into the Gray Zone**（[2604.15717](https://arxiv.org/abs/2604.15717)）把 jailbreak 研究推进到一个此前没有被系统化命名的区域：**gray zone**。

- **核心机制**：攻击者不再直接要求模型输出危险内容，而是先构造安全研究 / 专业领域的多轮上下文，再把目标请求包装成“分析、讨论、评测”语境中的自然延续；
- **关键结果**：Jargon 在 7 个主流模型上的平均 ASR 达到 **99.0%**，其中 GPT-5.2 为 **93%**，Claude Sonnet / Opus 为 **100% / 100%**；
- **意义**：它说明安全边界并非固定硬阈值，而是会被研究语境系统性软化。未来讨论 jailbreak 不能再只看 prompt 字面有多危险，而要显式建模**上下文如何重写拒答判据**。

### 2.15 IICL：从危险指令生成转向抽象算子与 pattern completion (2026-04-22 新增)

**IICL**（[2604.19461](https://arxiv.org/abs/2604.19461)）把 T2T 越狱又向“看起来像正常 few-shot completion”推进了一层：

- **核心机制**：攻击者先给出一组 benign / harmful 示例对，并把任务抽象成某种“算子”或“标注规则”，随后要求模型仅对新的 query 继续补全；
- **关键结果**：论文发现示例数量、顺序、命名方式和 framing 都会显著影响越狱成功率，说明危险不只来自 request content，也来自上下文中被学到的 completion pattern；
- **意义**：这说明安全边界正在从“识别危险问题”转向“识别危险的抽象模式”。对于 copilot、批改、数据标注与 co-authoring 系统，这类 ICL-style 攻击比传统直球请求更接近真实威胁形态。

### 2.16 AIC：自动红队从随机拼接进入在线组合优化 (2026-04-27 新增)

**Adaptive Instruction Composition / AIC**（[2604.21159](https://arxiv.org/abs/2604.21159)）把自动 red-teaming 的控制逻辑从“随机混搭 tactic”升级成了**contextual bandit**：

- **核心机制**：在 50,500 条 harmful queries 与 13,311 条 jailbreak tactics 形成的超大组合空间里，每轮先采样 500 个候选组合，再用 Neural Thompson Sampling 按历史成功反馈动态选择最值得尝试的 attacker instruction；
- **关键结果**：对 Llama-3-70B，WildTeaming 的 ASR 仅 **0.088**，而 AIC Aggressive 提升到 **0.450**；在 HarmBench 上，AIC 对 Llama-3-70B 的 ASR 进一步达到 **0.934**；
- **意义**：这说明自动红队已经不再是“把更多越狱模板喂给 attacker”，而是在**在线学习目标模型的脆弱区域**。未来红队系统会越来越像自适应攻击器，而不是静态测试脚本。

### 2.17 TTI：无状态单轮审核的结构性缺口 (2026-04-27 新增)

**Transient Turn Injection / TTI**（[2604.21860](https://arxiv.org/abs/2604.21860)）揭示了一个产品架构层面的危险前提：

- **核心机制**：目标模型和安全审核都按“单轮、无状态”工作，但攻击者在系统外维护完整攻击历史，并基于上一轮反馈持续生成下一轮提示；
- **关键结果**：对 gemini-1.5-flash，PAIR 命中数仅 **4**，TTI 提升到 **40**；对 gpt-4.1-mini，PAIR 为 **2**，TTI 为 **8**；
- **意义**：它说明风险并不一定来自模型“记住了前文”，而可能来自**攻击者自己记住了前文**。只要防线仍按 per-turn moderation 设计，多轮外部状态驱动的攻击就会持续构成系统性盲区。

### 2.18 BadStyle：后门 trigger 开始从显式 token 迁移到自然文风 (2026-04-28 新增)

**BadStyle**（[2604.21700](https://arxiv.org/abs/2604.21700)）把 T2T 后门攻击推进到一个非常现实的方向：

- **核心机制**：攻击者不再依赖显眼 trigger token，而是把 Bible / Shakespeare / Legal 等自然写作风格本身当作触发器；并通过 auxiliary target loss 让 payload 在 poisoned input 上稳定注入、在 clean input 上尽量不泄漏；
- **关键结果**：在真实生成场景里，Bible 风格在 **GPT-4** 上达到 **90.0% ASR**；在下游 CST 场景中，对 4 个 victim models 可实现 **ASR ≥ 97.0%** 且 **FPR ≤ 2.5%**；同时对 ONION 的 DSR 可低到 **0.0%**；
- **意义**：这说明 T2T 风险正从“奇怪字符串触发”迁移到“正常写作风格触发”。对企业邮件、工单、摘要和知识库整理等文本工作流来说，风格分布本身已经成为一级攻击面。

### 3.1 提示注入的演进层级

提示注入从单一 LLM 场景扩展到复杂工具链场景：

**直接提示注入（Direct PI）**：攻击者直接控制用户输入，向模型发送覆盖系统提示的指令。早期研究的主要形式，现在已被大多数模型的基础安全训练所缓解。

**间接提示注入（Indirect PI）**：攻击者控制模型会读取的**外部内容**（网页、文档、数据库记录），在其中嵌入指令。Cognitive Firewall（[2603.23791](https://arxiv.org/abs/2603.23791)）专门研究了浏览器端 AI Agent 受到间接注入的场景，并提出了混合边缘-云端防御架构。

**MCP 协议层注入（Tool Protocol PI）**：

2026 年出现的新类型，针对 **Model Context Protocol**（MCP）——Claude、Copilot 等 AI 工具使用的标准化工具调用协议：

- **论文 [2603.21642]**（UBC，Charoes Huang 等）：证明了 GitHub Copilot 等 AI 辅助开发工具**不具备对 MCP 提示注入的免疫性**，可通过代码注释、文档内容等注入恶意指令
- **TIP（Tree-based Injection Payload）**（[2603.24203](https://arxiv.org/abs/2603.24203)）：提出基于树搜索的自动化 MCP 注入载荷生成，可以根据目标工具的响应模式自适应调整注入内容

**RAG 系统注入（Database Poisoning + PI）**：

**PIDP-Attack**（[2603.25164](https://arxiv.org/abs/2603.25164)）将提示注入与 RAG 向量数据库投毒结合，攻击者先向数据库写入包含注入指令的文档，当 RAG 检索到该文档时，注入指令以"相关上下文"的形式传递给 LLM。

### 3.2 LLM Agent 安全：形式化框架的建立

2026 年最重要的理论进展之一是开始**形式化 LLM Agent 的安全属性**：

**A Framework for Formalizing LLM Agent Security**（[2603.19469](https://arxiv.org/abs/2603.19469)，UC Berkeley，Dawn Song 团队）：
- 引入 Agent 安全的形式化定义：安全策略（safety policy）、执行轨迹（execution trace）、违规条件（violation condition）
- 分析了多种 Agent 架构（ReAct、Plan-and-Execute）的安全属性
- **局限**：形式化框架尚未与实际评测工具对接，仍处于理论阶段

**T-MAP**（[2603.22341](https://arxiv.org/abs/2603.22341)，KAIST）：
- 基于**轨迹感知进化搜索**对 LLM Agent 进行红队测试
- 将 Agent 的执行轨迹视为搜索空间，用进化算法发现能触发不安全轨迹的测试用例
- 相较于 PISmith，T-MAP 更关注多步骤任务中的安全失效

**PISmith**（[2603.13026](https://arxiv.org/abs/2603.13026)）：
- 基于强化学习的提示注入防御红队工具
- 从防御测试角度自动发现提示注入漏洞

### 3.3 代理安全治理：从攻防到系统性框架（2026-03-30 新增）

2026 年末出现了从**系统工程角度**系统化代理安全的综合性工作：

**Clawed and Dangerous: Can We Trust Open Agentic Systems?**（[2603.26221](https://arxiv.org/abs/2603.26221)，2026-03-27）：

本文是首个从软件工程视角系统化分析开放代理系统安全的综述，提出**六维分析分类法**（攻击向量 / 执行层 / 持久性 / 目标 / 防御机制 / 治理），综合 50 篇文献指出：

> 代理安全的核心不是单个攻击的鲁棒性，而是**在持续不确定性下对代理行为的治理**。

核心研究空白：**能力撤销**（Capability Revocation）和**跨会话内存完整性**在现有文献中几乎未被研究。提供了可量化的安全评分卡工具，实用价值高。

**The System Prompt Is the Attack Surface**（[2603.25056](https://arxiv.org/abs/2603.25056)，2026-03-26）：

PhishNChips 框架（11 模型 × 10 提示策略）实证发现：

```
配置影响：同一模型，不同提示 → 钓鱼绕过率从 <1% 到 97%
信号反转攻击：依赖单一可逆信号的提示 → 攻击者精准绕过
98% 的成功绕过 → 遵循"信号反转"推理模式
```

提出 **Safetility** 指标（Safety × Utility 综合评分），以及"高特异性提示 = 高脆弱性"的反直觉规律。



### 4.1 监督微调 + RLHF：传统安全对齐的局限

传统 LLM 安全对齐的主要范式是 **RLHF（Reinforcement Learning from Human Feedback）**：通过人类偏好数据训练奖励模型，再用 PPO 等算法优化语言模型使其输出符合偏好。

**局限性（由本项目论文揭示）**：

1. **Internal Safety Collapse**（[2603.23509](https://arxiv.org/abs/2603.23509)）：对前沿 LLM 的研究发现，**安全对齐在模型内部是"脆弱的"**——少量的有害微调数据就可以导致安全特征的全面崩溃，而非只影响特定类型的输出
2. **安全对齐的过度保守性**：DOOR（ICML 2025）等工作指出，现有对齐方法倾向于让模型"宁可错拒，不可放行"，导致帮助性（helpfulness）显著下降

### 4.2 双目标优化对齐

**DOOR: Dual-Objective Optimization for Safe Alignment**（[2503.03710](https://arxiv.org/abs/2503.03710)，ICML 2025）提出同时优化两个互相约束的目标：

```python
# DOOR 优化框架（概念示意）
loss = λ₁ * safety_loss(harmful_queries, refusal_responses)
     + λ₂ * helpfulness_loss(benign_queries, helpful_responses)
     + λ₃ * alignment_loss  # 两目标一致性约束
```

通过动态调整两个目标的权重，在安全性和帮助性之间找到 Pareto 最优解。

### 4.3 推理链实时安全校准

**SFCoT: Safer Chain-of-Thought**（[2603.15397](https://arxiv.org/abs/2603.15397)）是防御侧应对推理链攻击的先驱工作：

**核心架构**：
```
输入 → CoT推理步骤 s₁ → [安全评分器] → s₂ → [安全评分器] → ... → 输出
         ↑                                    ↑
    如果 σ(sₜ) < θ，干预并重新采样推理步骤
```

三层安全评分维度：
- **语义内容安全性**：推理步骤的字面内容是否有害
- **意图一致性**：当前推理方向是否偏离原始任务
- **行为风险**：推理步骤的潜在后续行为是否违规

**创新性**：将安全检查从"输出端"前移到"推理过程中"，从根本上比输出过滤更具有先机优势。

### 4.4 机制可解释性驱动防御

2026 年出现了一批**用可解释性工具定位和修复安全漏洞**的工作，代表了防御研究的新范式：

**SafeSeek: Universal Attribution of Safety Circuits**（[2603.23268](https://arxiv.org/abs/2603.23268)）：
- 借助机械可解释性（Mechanistic Interpretability）工具，在 LLM 内部定位负责安全决策的"安全电路"（safety circuits）
- 通过归因分析找到哪些注意力头（attention heads）和 MLP 层对安全对齐起关键作用
- **意义**：安全电路的位置一旦确定，可以：(a) 专项监控关键电路以检测攻击，(b) 修复时只需更新关键层而非整体重训

**Activation Watermarking**（[2603.23171](https://arxiv.org/abs/2603.23171)）：
- 在语言模型的激活层嵌入**水印信号**
- 正常情况下水印不影响输出，但在受到越狱攻击时激活层的水印特征会发生变化
- 通过监控水印完整性来实时检测攻击

**Reasoning Safety Monitor: Beyond Content Safety**（[2603.25412](https://arxiv.org/abs/2603.25412)）：
- 超越内容安全（content safety），**监控推理过程中的逻辑漏洞**
- 检测推理链中"看似正确的逻辑步骤，但整体推理方向有害"的模式
- 实时监控，支持推理超时干预

**Steering Vectors Safety Pitfalls**（[2603.24543](https://arxiv.org/abs/2603.24543)）：
- 分析了 Steering Vectors（一种通过操控激活向量来引导模型行为的技术）的安全陷阱
- 发现 Steering Vectors 可以绕过 RLHF 对齐，直接"steering"模型绕过安全机制

### 4.5 混合架构防御

**Prompt Attack Detection with LLM-as-a-Judge**（[2603.25176](https://arxiv.org/abs/2603.25176)）：
- 使用 LLM 作为检测器（LLM-as-Judge）来识别提示攻击
- 结合多个轻量模型的集成（Mixture-of-Models）提高检测准确率
- 工程上可行的实时检测方案

**Cognitive Firewall**（[2603.23791](https://arxiv.org/abs/2603.23791)）：
- 针对浏览器端 AI Agent 的间接提示注入，提出**混合边缘-云端防御架构**
- 边缘端负责轻量级的实时内容扫描，云端负责深度分析和策略更新

### 4.6 边缘 SLM 与资源受限防御（2026-04-01 新增）

**GUARD-SLM**（[2603.28817](https://arxiv.org/abs/2603.28817)，2026-03-28）：

首个专为**小型语言模型（SLMs，≤7B 参数）**设计的越狱防御方案：

- **核心洞察**：SLMs 的激活模式比 LLMs 更"浅层化"，安全判断主要集中在较早的 Transformer 层
- **方法**：在表示空间构建轻量级推理时过滤器，对正常/越狱输入的激活分布进行分类，无需修改模型权重
- **效果**：跨 9 种越狱攻击 × 7 种 SLMs，越狱率从 ~60% 降至 <5%，推理延迟增加 <2%
- **意义**：填补边缘设备 LLM 部署安全防护的关键空白

**Architecting Secure AI Agents**（[2603.30016](https://arxiv.org/abs/2603.30016)，2026-03-31）：

从**系统架构层面**系统化解决间接提示注入（IPI）防御问题：

- 提出**特权层级架构**（Privilege Hierarchy Architecture）：工具调用权限细粒度控制，最小权限原则
- **信任区间模型**（Trust Zone Model）：明确划分可信/不可信数据源的处理边界
- **数据流隔离**（Data Flow Isolation）：在 tokenization 层面区分可信指令和不可信数据
- 核心论点：IPI 防御的正确抽象层次是系统架构，而非单点 LLM 模型，与模型级防御互补形成纵深防御

### 4.7 安全探测的边界与新挑战（2026-03-30 新增）

**Why Safety Probes Catch Liars But Miss Fanatics**（[2603.25861](https://arxiv.org/abs/2603.25861)，2026-03-26）：

本文揭示了基于激活探测的安全监控的**根本性盲点**——"一致性错位"（Coherent Misalignment）。

```
说谎者模型（Liar）:
  行为: 有害输出
  内部状态: 真实目标 ≠ 声明目标 → 激活异常
  探测检测率: >95% ✓

狂热者模型（Fanatic）:
  行为: 有害输出（相同）
  内部状态: 真诚相信有害行为是"保护性"的 → 激活正常
  探测检测率: <5% ✗ （接近随机）
```

**理论证明**：类 PRF 信念结构下，不存在多项式时间探测能有效检测此类错位。

**警示意义**：RLHF 训练可能无意间将"可检测的欺骗"转化为"不可检测的信念"——这是当前对齐范式的系统性风险，迫切需要**行为验证**视角的新型评估方法。

**H-Node Attack and Defense in LLMs**（[2603.26045](https://arxiv.org/abs/2603.26045)，2026-03-27）：

提出"幻觉节点（H-Node）"概念，将 LLM 幻觉机制定位到 Transformer 最后词符隐藏状态中的特定高方差维度：

- **H-Node 探针 AUC = 0.90**（跨 OPT/Phi-3/LLaMA-3/Mistral 四种架构验证）
- **攻击**：白盒前向钩子放大 H-Nodes，攻击选择性 3.02×，可见性 <10%
- **防御（动态 ANC）**：迭代抑制 H-Node 激活，接地漂移降低 33–42%，MMLU 下降 ≤3%

H-Node 框架与 SafeSeek 的安全电路归因相辅相成：前者定位幻觉风险，后者定位安全决策机制。




### 4.8 解码阶段控制的新范式（2026-04-09 新增）

**Gradient-Controlled Decoding (GCD)**（[2604.05179](https://arxiv.org/abs/2604.05179)）：
免训练的安全护栏机制，采用双锚点（Dual-Anchor Steering）策略检测有害意图。
- 创新点：突破单锚点检测的脆弱性，通过 "Sure" 和 "Sorry" 相对梯度激活判断安全性。
- 拦截机制：一旦检测到违规，预先注入拒绝 token（preset-inject），实现"首个 token 安全"。

### 4.9 领域安全：白名单排他性遗忘（2026-04-09 新增）

**Exclusive Unlearning**（[2604.06154](https://arxiv.org/abs/2604.06154)）：
传统的机器遗忘是"黑名单制"，针对特定有害概念进行擦除。
- 创新点：采用"排他性遗忘"，即遗忘除了预定义安全领域（如医疗、数学）之外的**所有知识与表达**。
- 意义：根本上收敛了模型泛化能力可能带来的长尾攻击面，是一种彻底的"白名单"安全对齐方案，非常适合特定工业垂直场景。

### 4.10 联邦对齐中的端侧净化 (2026-04-09 新增)

**FedDetox: Robust Federated SLM Alignment via On-Device Data Sanitization**（[2604.06833](https://arxiv.org/abs/2604.06833)）：
- 核心方法：在边缘设备上使用轻量级安全探针清理毒化数据，上传带有 LDP 保护的"本地健康度证明"。服务端结合证明进行自适应的鲁棒聚合。
- 意义：为小型语言模型（SLM）在联邦学习环境下的安全对齐提供了在不破坏用户隐私前提下的净化方案。

### 4.11 形式化理论防御：输入侧封装的不可能性 (2026-04-10 新增)

**The Defense Trilemma: Why Prompt Injection Defense Wrappers Fail?**（[2604.06436](https://arxiv.org/abs/2604.06436)）：
- 核心贡献：首次用 **Lean 4 定理证明器**形式化证明了**输入侧防御封装（D: X→X）的理论不可能性**——连续性、效用保留、安全性三者不可兼得（三难困境）。
- 技术路线：在连通拓扑空间上，通过边界固定化 → ε-鲁棒约束 → 横截性不安全区域三阶段推导，严格刻画了 Wrapper 防御必须失败的几何位置。扩展至离散场景和多轮对话。
- 实践意义：为"为什么打补丁永远打不完"提供了数学定论——**封装防御这条路有天花板**，必须转向训练时对齐、架构修改或输出监控等替代范式。

### 4.12 非欧几何用于 AI 安全检测 (2026-04-10 新增)

**Harnessing Hyperbolic Geometry for Harmful Prompt Detection and Sanitization (HyPE/HyPS)**（[2604.06285](https://arxiv.org/abs/2604.06285)，**ICLR 2026 接收**）：
- 核心创新：将 VLM 联合嵌入从欧氏空间映射到**双曲空间（Poincaré 球模型）**，利用层次化几何结构实现更精准的有害提示离群点检测。
- HyPE（检测）：良性提示在双曲空间中自然聚类为层次化结构，有害提示作为边缘离群值被识别。
- HyPS（净化）：基于归因驱动选择性修改 top-k 有害 token（非整体拒绝），兼顾安全和语义保持。
- 效果：检测 Acc ~91%（vs 黑名单 ~72%），对抗鲁棒性 78%（vs 分类器 ~61%）。开辟了**非欧几何 → AI 安全**的新研究方向。

### 4.13 推理层后门防御：让模型学会怀疑异常推理 (2026-04-14 新增)

**Critical-CoT**（[2604.10681](https://arxiv.org/abs/2604.10681)）把防御焦点从“过滤输入”推进到“识别被污染的推理过程”本身：

- **核心方法**：构造 CTCoT 防御数据集，对 ICL 型与 FT 型 reasoning-level backdoor 分别生成“识别 trigger / poisoned reasoning 并显式忽略”的监督样本；随后用 SFT 学习防御知识，再用 DPO 修正过度警惕带来的误报边界。
- **关键结果**：ICL / FT 场景下的 ASRr 与 ASRt 均被压到 1% 附近甚至更低，而 clean accuracy 仅下降约 1–2 个点。
- **意义**：这表明未来的安全防御不再只是“检测有害输出”，而是必须具备对推理链本身的异常感知能力。对于日益普及的 reasoning model，这可能比传统 prompt-level guardrail 更关键。

### 4.14 指令表示对齐：从“让模型拒答”到“让模型安全理解” (2026-04-15 新增)

**LIRA**（[2604.10403](https://arxiv.org/abs/2604.10403)）代表了对齐研究的一次关键转向：

- **核心机制**：不再围绕 response token 做行为矫正，而是直接对齐中间层的 **instruction representation**；再用 **Sequence-Aware Gradients (SAG)** 切断 response 直接梯度，把训练压力集中在“如何解释指令”上；进一步通过 **AdLIRA** 在 latent space 中做内部对抗训练，提高对未见攻击的泛化。
- **关键结果**：论文报告可阻断 **>99%** 的 PEZ jailbreak，Figure 4 中 AdLIRA 将 PEZ ASR 压到接近 0，并把 insecure-code backdoor 恢复到接近 non-backdoor baseline；同时在 WMDP cyber 上实现 optimal forgetting 且 benign loss 可忽略。
- **意义**：这条线把防御焦点从“输出过滤/拒答模板”推进到“内部指令解释路径重写”。它与 Nullspace Steering、CRA 等工作一起说明：未来攻防将越来越围绕低秩子空间与中间表示展开，而不再停留在 prompt 表面。

### 4.15 保留优先遗忘：把 unlearning 重写成梯度几何问题 (2026-04-18 新增)

**Modeling LLM Unlearning as an Asymmetric Two-Task Learning Problem**（[2604.14808](https://arxiv.org/abs/2604.14808)）把“忘记”与“保留”的关系重新定义了：
- **核心机制**：不再把 forgetting 与 retention 当作对称双任务，而是把 retention 视为主任务、forgetting 视为受约束的辅任务；再通过 **module-wise PCGrad** 与 **SAGO** 在梯度层直接处理冲突。
- **关键结果**：在 WMDP / RWKU 上，SAGO 显著把 retention–forgetting Pareto frontier 向外推，例如 WMDP Bio 上 MMLU 从 naive 的 **51.4** 提升到 **58.3**，WMDP Cyber 上从 **7.3** 拉到 **59.7**。
- **意义**：这条线的重要性不只是“又一个 unlearning 技巧”，而是明确指出**安全遗忘的正确控制量是梯度几何，而不是简单 loss 加权**。它与 LIRA、CausalDetox 一起表明：T2T 防御正在从行为层规则迁移到表示层与优化动力学层。

### 4.16 部署后安全修补：Unsafe Tickets 剪枝 (2026-04-20 新增)

**Pruning Unsafe Tickets**（[2604.15780](https://arxiv.org/abs/2604.15780)）提供了一条非常务实的新路线：
- **核心机制**：把危险行为视为由少量稀疏的 unsafe tickets 承载，再基于 response-only attribution 与 Beam Search 做无梯度迭代剪枝；
- **关键结果**：在 Mistral-7B 上，Unsafe Rate 从 **22.8%** 压到 **1.17%**，AutoDAN ASR 从 **45.7** 降到 **0.67**，同时推理阶段**不引入额外 token**；
- **意义**：这说明 T2T 防御开始出现一条与重训型对齐并行的新分支——**部署后结构性修补**。它不等价于真正重写模型价值观，但对现实部署中的低成本安全加固很有吸引力。

### 4.17 持续安全对齐：高梯度 benign 样本也会拖垮 alignment (2026-04-21 新增)

**Continual Safety Alignment via Gradient-Based Sample Selection**（[2604.17215](https://arxiv.org/abs/2604.17215)）把 continual fine-tuning 的安全风险重新定义成了一个样本级问题：
- **核心机制**：不是所有 benign 样本都会破坏安全，对齐漂移主要由高梯度样本驱动；作者先做 loss 预过滤，再按 per-sample gradient norm 选择最接近中位数的 **moderate-gradient samples** 参与训练；
- **关键结果**：在 Qwen2.5 / LLaMA-3.1 / Qwen3 上，最终 ASR 分别压到 **10.2 / 18.3 / 6.0**，明显优于 Baseline / Random / Gradient Clipping；在 Qwen3 上，BWT 从 **-18.5** 改善到 **-4.3**，FM 从 **18.5** 降到 **4.3**；
- **意义**：这说明 T2T 防御开始从“参数约束”继续下沉到“数据选择”。真正危险的并不一定是显式有害数据，而是那些会把模型强行拉回 pretraining distribution 的高张力样本。

### 4.18 安全分类 SFT 的对照实验：模板 reason 一分不值，过拒不是阈值问题 (2026-10-28 新增)

**Task Format as a Factor in Adaptation**（[2610.33813](https://arxiv.org/abs/2610.33813)，Fiddler AI + SFU + Georgia Tech）是目前对"prompt 安全分类该怎么训"控制得最严的一组对照实验，33 页 / 18 表。

**设计**：Ettin **400M encoder/decoder 匹配对**（同一份 2T token、同一配方、同一 tokenizer、同为 28 层 hidden 1024，只在注意力模式与目标函数上不同）；LoRA $r=16$、$\alpha=64$、$\alpha/\sqrt{r}$ 秩稳定缩放，**8,114,176** adapter 参数 vs 全量 **396M**（约 50×）；**每 cell 15 颗种子**；**±2pp 等价边界事前固定**；分析按 hash 预注册。语料 **29,095 行**。

| cell | 格式 | regime | Aegis 2.0 | WildJailbreak | OR-Bench **过拒**↓ | toxic 召回↑ |
|---|---|---|---|---|---|---|
| 3 | 判定词 | LoRA | 78.7 | 55.7 | **66.0** | 81.8 |
| 5 | 判定**+理由** | LoRA | **82.7** | 69.0 | **29.1** | 88.4 |
| 8 | encoder head | 全量 | **84.6** | 69.6 | 27.1 | 92.7 |
| 11 | **8B（不训）** | — | 76.8 | **77.7** | **2.6** | **94.7** |

**结论一（算力决策）**：只训标签时全量领先 **2–3pp**；但**两个 regime 的学习率由同一套搜索选出后，encoder 上二者等价**。架构影响更大——encoder 比 decoder 高约 4pp。

**结论二（reason 消融，全文最锋利）**：LoRA 加理由 **+4.00pp**（CI [2.56, 5.44]），全量仅 +1.27pp，交互项 2.73pp 经 Holm/Bonferroni 仍存活，两个 reason cell 最终 **82.69 vs 82.60 → 等价**。但替换实验说清了收益来源：

| 替换成什么 | 域内 | 保留了多少 4pp | 过拒 |
|---|---|---|---|
| **固定句子（34 token）** | **78.2** | **0%（还低于 78.7）** | 58.1% |
| 换别条样本理由（不管标签） | 80.3 | 42% | 44.3% |
| 换同标签别条样本理由 | 81.1 | 60% | 40.7% |
| **这条样本自己那句话** | **82.7** | **100%** | 29.1% |

三条竞争假设（内容 / 与标签一致 / 长目标多算损失）**全部只被部分支持**；而**固定句子完全无效**——训练损失曲线解释了原因：固定句子几百步即被学会，之后几乎不产生损失；换来的理由无法从 prompt 预测，**损失一直停在 1.55**。

**结论三（过拒）**：OOD 上所有训练 cell 比 8B 低 **8.1–23.2pp**；**OR-Bench 过拒是 8B 的 10–23 倍**；且**ROC-AUC 排序本身差 0.026–0.343 ⇒ 换阈值救不回来**。但 **reason 目标把过拒从 66.0% 砍到 29.1%（−36.94pp），同时 toxic 召回反升到 88.4%**——不是靠少报换来的。

**两个评测纪律**：① 用**平衡准确率**而非准确率（ToxicChat 上普通准确率 92.7% 但平衡准确率 50%）；② 报 **ROC-AUC** 以区分"阈值偏"与"排序坏"。另有一个必须记的偏差：生成式 cell 只看前 **128 token**，而 **WildJailbreak 有 81.3% 的对抗 prompt 超过 128 token**（head cell 256 窗口仅 18.9% 超）。

### 4.19 护栏的跨接口不变表示：只造视图不加对比，F1 掉 20.5 (2026-10-28 新增)

**UniGuard**（[2610.30742](https://arxiv.org/abs/2610.30742)，Monash University + 澳国防科技组）把"护栏换接口就崩"诊断成两条同源限制：**泛化在接口间是碎的**（DynaGuard 强自定义策略、AgentDoG 强轨迹、PolicyGuard 强策略违规，各自只锚在自己的训练接口上），以及**接口漂移下置信度不可信**（护栏实际是**路由器**，路由依赖概率而非 top-1，**F1 高但概率与经验准确率不相关 = 作为路由器是坏的**）。

**方法**：1,000 条公开安全案例 × **5 种视图**（prompt / response / 多轮对话 / agent 轨迹 / 多 agent 轨迹）；attention pooling + 线性头；三个损失各管一件事——分类 CE、**监督对比**（正集 = 同 case 同标签的其他视图，负集 = 不同 case 或不同标签）、**非对称置信校准**（用同 case 同标签的其他视图估 cross-view 可靠性，同时罚过信与欠信，$\lambda_{\text{over}}$ 与 $\lambda_{\text{under}}$ 分开设）。

| 模型 | ATBench F1 / ECE | PolicyGuardBench | DynaBench |
|---|---|---|---|
| Qwen3Guard-Gen-0.6B（**基座**） | 9.83 / 49.20 | 4.26 / 41.35 | 56.67 / 39.50 |
| AgentDoG-4B | 71.10 / 33.62 | 60.64 / 46.30 | 65.92 / 44.72 |
| PolicyGuard-4B | 7.05 / 44.98 | **87.59** / 15.24 | 72.00 / 8.17 |
| GPT-5.2 | 66.52 / – | 81.79 / – | 76.90 / – |
| **UniGuard-0.6B** | **66.40 / 7.93** | 64.78 / **9.95** | 74.93 / **5.94** |

平均 **+45.12 F1、ECE 降 35.41**；**ATBench 与 GPT-5.2 基本持平（66.40 vs 66.52）**。专家模型全是偏科生，UniGuard 是唯一三项都稳的。

**消融给出了干净的分工**：**去掉对比学习**平均 F1 **−20.50**（ATBench −23.82、PolicyGuard −27.17）；**去掉非对称校准** F1 几乎不变但 **ECE 涨 +18.51 / +28.10 / +19.42**。⇒ **对比学习管"判得准不准"，非对称校准管"置信能不能用"，不可互替。** 通用校准三法（Temperature Scaling / Thermometer / Contextual）在三项 ECE 上全部不如非对称校准。

**保留性协议**：8 个原接口 benchmark 上平均 F1 只变 **−0.35**、ECE 只变 **−0.04**，无灾难性遗忘——这个检查成本极低，但能拦住"新数据把老能力冲掉"这类最难查的回归。

### 4.20 标签因子化只在长尾被补上时才成立：+0.001 与 −0.360 (2026-10-29 新增)

**AK_QMUL @ ArGuard**（[2610.36360](https://arxiv.org/abs/2610.36360)，**Queen Mary University of London**，ArabicNLP 2026 Shared Tasks）是**单骨干 4-bit QLoRA 拿下两个赛道的系统报告**，但对我们最有价值的是它那张三行消融表。

**配方（全可搬、单卡可跑）**：JAIS-6.7B + **4-bit NF4 双量化** + LoRA 全线性投影（$r$=16, $\alpha$=32, dropout 0.05）+ **因果 LM 取 last-token 隐状态 → 单层线性头** + **类加权 CE（权重 = 逆类别频率）** + 分层分组 7 折 + 3 epochs / lr $10^{-4}$ / max_len 192。

**B1（safe/unsafe）**：macro-F1 **0.984**，赛道第一。方言细分准确率 **93.6–99.8%**，且**预测不安全率紧密跟随真实率**（MSA 36.6→37.1、Syrian 71.7→71.7、Egyptian 91.3→91.6）。

**三行消融（本文的核心）**：

| 头 | 外部安全数据（AraSafe） | macro-F1 |
|---|---|---|
| 2 类（safe/unsafe） | 有 | 0.983 |
| **4 类（safety × register）** | **无** | **0.624** |
| **4 类（safety × register）** | 有 | **0.984** |

⇒ **因子化的净收益 +0.001（等于零）；但去掉长尾补数据，因子化直接崩 −0.360。**

原因是分布：四类里 `safe-MSA` 只占 **7.6%**（`unsafe-MSA` 40.6%、`unsafe-other` 39.3%、`safe-other` 12.5%）。四类头里一个格子饿着，argmax 会把本该属于它的样本系统性抢走，折叠回二元就成误判。补数据是从 AraSafe 人写 MSA 集（12,077 条）过滤出 **7,607 条**纯安全 MSA prompt，**只加进训练折**（长度阈值 + 方言标记词表过滤 + 跨 split 去重）。

**⇒ 对我们层级标签体系（L1–L4 + L2_30 独立维度）的直接结论**：**"层级越细越好"是未经验证的假设。** 拆成正交因子前，必须先统计每个格子的样本数；**任何一个格子低于阈值，先补数据再上联合头——顺序反了就是 −0.360。**

**B2（七类危害域）的分层表给出了第二个结论**：总体 macro-F1 **0.79**，但 **MSA 切片只有 0.70**（方言 0.88–0.95）；`adult_content` **0.98**，`Bully` **0.57**、**在 MSA 上只有 0.46**（方言上 0.81–0.97）。作者归因："**Bully 与 harassment、harm-to-others 语义重叠**"。

⇒ **两条迁移**：① **"最差类别"必须带切片报告**——总体 0.79 可以掩盖一个切片 0.46；② **最难的永远是最规范的那一档**（方言有强表面线索，MSA 只有干净的书面语义，表面特征帮不上忙）。**这与我们 PORN 好判 / VULG-HINT-EDGE 难判是同一结构性现象**——而这篇用 6.7B + QLoRA + 类加权 + 5 种子，最好的类 0.98、重叠类 0.57，说明**差距不是训练量问题**。

**一个未做的诊断（值得我们自己补）**：真实不安全率按方言极不均匀（MSA **36.6%** vs 方言 **71.7–91.3%**）⇒ **"方言"与"不安全"在数据里高度相关，因子化有学成"方言⇒不安全"捷径的风险**，论文没有做捷径诊断（如跨方言置换测试）。

### 4.21 拒答率是个被话术和位置污染的指标 (2026-10-29 新增)

**When Visual Evidence Is Insufficient**（[2610.37430](https://arxiv.org/abs/2610.37430)，**IIT Hyderabad**，VLM4RWD workshop）用**图像-问题对完全固定**的受控设计，把"拒答率"这个我们默认可靠的指标拆掉了。

**四类响应标签**：A（作答，**含带保留答案与同时含拒答语言的回答**）/ $R_E$（证据型）/ $R_S$（安全型）/ $R_G$（通用型），外加**独立**的 mixed-response 指示。核心分析工具是**同样本配对转移率** $T_{u \to v}^{c \to c'}$——它能区分"整体抬高"与"双向洗牌"，而只看 $\rho$ 的变化看不出来。

**设计上最聪明的一步**：四个策略条件里放了一个**故意错配的 C2（安全导向）**——被评问题**全是良性的**（视觉证据不足，不是有害请求），所以 C2 下出现拒答**只可能是安全策略外溢**。而 C2 也加了一段指令文本 ⇒ **C1/C3 相对 C2 的强效应，证明的是"策略语义在起作用"，不是"多加了提示词"**。

**关键数据**（总拒答率变化，相对 C0）：

| 条件 | 效果 |
|---|---|
| C1（证据型）/ C3（通用） | 全部 12 个"模型×位置"比较抬高 **18.4–45.2** 点，净证据型 +15.4–46.8，所有 CI 不含 0 |
| **C2（安全错配）** | 仅 **−2.3 到 +13.2**，六个区间里**三个含 0** |
| **指令位置（前置→后置）** | InternVL **−7.6 / −8.1**；**Qwen +14.9（方向相反）** |
| **同批样本二元翻转率** | **13.9–32.1%** |

**后训练那张表最该读方括号**（格式：C0/C1-prefix **[最大混合响应率]**，%）：

| 模型 | 未修改 | SFT | DPO | ORPO | SimPO |
|---|---|---|---|---|---|
| InternVL3-2B | 13.9/40.9 [1.8] | **87.7/99.7 [30.8]** | 40.4/75.1 [6.3] | 83.9/99.1 [33.2] | 20.0/48.2 [2.8] |
| InternVL3-8B | 26.6/65.4 [2.4] | 90.3/98.3 [22.8] | 31.1/70.4 [2.1] | 87.3/96.7 [13.4] | 27.7/68.2 [3.2] |
| Qwen2.5-VL-7B | 34.7/65.0 [5.3] | **94.9/99.9 [17.7]** | **88.7/92.8 [24.1]** | 94.2/99.6 [22.3] | 38.9/69.8 [7.9] |

⇒ **SFT 与 ORPO 把拒答推到 83.9–94.9%（C0）/ 96.7–99.9%（C1），但混合响应率同时升到 22.8–33.2%**——三分之一的回答**一边拒答一边还在尝试回答**。而 **DPO 极不稳定**（InternVL-2B 40.4% vs Qwen 88.7%），**SimPO 基本没用**。

**两个选择性控制都过了**：704 条良性描述请求**一条都没拒**（0/704 → 0/704）；MMMU 变化 **−2.15 到 +0.92**，所有区间含 0。

**对 T2I 输出侧图审的三条迁移**：

1. **AB 评测必须冻结 prompt**。同一模型、同一批样本，换同义话术能翻 18.4–45.2 点——我们两个图审模型走两套 system prompt 的 AB 结论里混着 prompt 差异，**而位置这种"实现细节"能让结论方向反转**。
2. **"违规判定率"必须配三样**：**理由分类**（是"内容违规"还是"我看不清"）、**混合响应率**、**良性样本误拒率**。
3. **C2 的错配设计可直接搬到标签体系上**：给分类器"涉及 X 就标 X"的指令，但测试集**根本不含 X**，看它是否仍然大量标 X。**这与我们做过的"极性盲"检查是同一族诊断**，且比它更直接——**它能解释 PORN/VULG 混淆的一个可能机制：模型在按指令词表打标而不是按图判边界。**

### 4.22 安全退化的数据"看起来是良性"：内容侧筛子结构上抓不到它 (2026-10-30 新增)

**SimpleLoRIF / SafeTulu**（[2610.37481](https://arxiv.org/abs/2610.37481)，**DatologyAI + UIUC**）把安全退化重写成**训练数据归因**问题，并给出了**第一条工业可用的成本曲线**。

**核心洞察**：微调会悄悄削掉安全对齐，**即使训练数据里没有一条看起来有害**（emergent misalignment）。这类数据看起来是良性的，所以标准内容过滤器（毒性过滤、LLM judge）**结构上抓不到**——它们看的是"内容说了什么"。需要的是**"这条样本会怎么改变模型"**的信号，也就是**梯度**。

**两处关键简化**：① **扔掉曲率修正**——只用排序（排名 → 删 top-p），不需要标定影响值、不需要跨模型比分数、不需要预测 loss 变化；② **只回传最后 4 个 transformer block**——选中 block 在网络顶部，反向在最浅选中 block 的输入梯度算完就停，**前向仍走完整网络**。

**压缩**：双边随机投影（$d_1=d_2=32$，在激活与输出梯度产生的当下就投影，**完整梯度矩阵从不被构造**）+ 秩-1 分解（$c=1$），每层存储 **1024 → 64 个 float**；打分用双线性型 $s=\sum_\ell (u^\top u)(v^\top v)$，不重构梯度。

**关键数据**：**939,343 条 / 8×H100 / 约 1 小时**；EM 检测 AUC **最高 0.865**；$N=4$ 最优（$N=2$ 掉到 0.65，$N=6/8$ 收益递减；投影维度对结果几乎无影响；token 截断"有效但有风险"；缩小嵌入模型"质量掉太多"）；删 20% 得 SafeTulu，**GCG ASR 最多 −22%**，跨 Qwen/Llama/Olmo，**胜过 LLM-as-a-judge 过滤和先前梯度法**。

**被删掉的样本画像（最该读的一节）**：反复出现的模式**没有一个是"看起来有害"的**——**工具执行失败**、**叙事算术**、**直接 coding 任务**。三者的共同点：**都在教模型"过程可以被讲述，而不必被做对"**。

⇒ **对我们**：我们的标签审计当前**完全是内容侧**的（看 `input_text` 像不像 PORN/VULG）。这篇给出了一个此前没考虑的解释：**那批样本的问题不在"它被标成了什么"，而在"它把模型往哪推"**。一条文本完全良性的样本，若梯度方向与"PORN 误报"对齐，它就在教模型多报 PORN，而任何基于内容的规则都看不见。**"胜过 LLM-as-a-judge"这一条也要正视**：我们的复判全押在 LLM 读内容上，在有梯度信号的前提下是次优的。

**边界**：只测 general safety 不测具体危害类型（我们的 PORN/VULG 是具体类目，不能自动下延）；只用 SafeRLHF 一个目标集（我们要换成自己的误报响应）；**删数据的风险不对称**（对照 4.20：去掉长尾补数据 **−0.360**）。

### 4.23 单标签基准把"合法分歧"判成了"标注错误" (2026-10-30 新增)

**ANT-A / ANT-OR**（[2610.32415](https://arxiv.org/abs/2610.32415)，**蚂蚁集团 + 哈工大（深圳）**，EMNLP 2026 Findings）指出：现有 LLM 标注基准的两个简化——**不给标注规范文档**、**每样本只给一个 gold**——**把"标注者分歧"和"标注错误"压成了同一个数**。

**七个数据集 × 1500 条 × 5 份独立人工标注，κ 跨度 38.77–83.50**：

| 数据集 | 模态 | 类数 | **Fleiss κ** |
|---|---|---|---|
| Disease Privacy Assessment（医疗隐私判定） | 文本 | **2** | **38.77** |
| Billing Scenario Classification | 文本 | 31 | **83.50** |
| Medical Entity Extraction | 文本 | 22 | 82.09 |
| Social Text Classification | 文本 | 15 | **44.62** |
| Image Attribution Recognition | 视觉-语言 | 3 | 58.59 |
| Image Classification | 视觉-语言 | 24 | 81.27 |
| Image Text Relevance | 视觉-语言 | 3 | 56.37 |

**排序不按类数，按"定义清晰度"**：κ 最高的两组都是**有客观锚**的（账单 31 类仍 83.50，实体边界可核）；最低的两组都是**判定型**的。**2 类任务的 κ 比 31 类还低 45 点**——推翻"类目多所以难"的直觉。视觉-语言三任务同样是"识别型高（81.27）、判定型低（56.37）"。

**ANT-OR 四个部件**：① 对比样本池（每条带质量分 $w$，按预测对错更新，检索打分 $\text{sim}\cdot w$）；② **判别维度池**——从 $(s_1^+,s_2^+,s^-)$ 三元组蒸馏"类目特定决策准则 + 适用场景"，与已有维度融合，**只保留 support count ≥ 2**；③ 维度–样本耦合注入（例子与规则**同时**给）；④ 错误归因到具体 agent 再改它的 prompt。**不训练任何模型**，agreement@≥2 **+4.5 点**，κ 与人类差距收进 **2 点以内**。

⇒ **对我们**：这条把"该改标签 / 该改定义 / 该补数据"从三选一变成**可判定**——若 VULG-HINT-EDGE 的 κ < 40，那"最差类别"该改写成"**该类目目前不可判**"。判别维度池正好补上 `full_check.py` 缺的那块：**单次 LLM 判断没有可依赖的判据，只能靠模型先验**。**边界**：5 份标注不等于真值（它优化"像人"不是"对"）；support count ≥ 2 对长尾格子可能把正确但少见的规则全过滤掉。

### 4.24 奖励作弊的 advantage 取决于"同组兄弟"：审计预算要按通过数排序 (2026-10-30 新增)

**Audit Where Hacks Pay**（[2610.35716](https://arxiv.org/abs/2610.35716)，**清华大学 REASONS Lab + Virginia Tech**）研究**固定强验证器预算下 GRPO 该怎么花**——**"少标签"而非"多算力"的路线**。

**核心洞察**：一条 rollout 的 advantage **取决于它的兄弟**。所以同一个被抓的作弊，可能推得动策略、可能推不动、也可能推得很猛。两个"自然"默认（随机审计 + 逆倾向修正；给被抓作弊"该得的强判决奖励"）都错在不考虑 GRPO 怎么把奖励变成更新。

**三条观察**：① 不做组内标准差归一化时，期望梯度**只通过"边际审计概率"和"修正值"**依赖设计 ⇒ **组内耦合审计改的是噪声，选择和修正改的是方向**；② 被抓作弊给 **$2b-a$**（关于失败奖励反射）能**精确抵消**"整组弱通过全是作弊"那一组的 advantage，给 $b$ 只是**清零**——差别在"不推"与"反向推"；③ 未抓到的作弊在**同组很少通过**时 advantage 最大 ⇒ **一个标签花在低通过数组上买到的修正最多**。

**LB 策略**：整组按弱通过数升序审计，直到 batch 弱通过总数的期望 $p$ 比例被检查完。**结果**：冻结面板上"留在作弊上的 advantage 质量"的**符号**预测作弊是否被压制，**33/39 次正确（含 13/16 预注册）**；LB 把作弊率打到近零，随机审计同预算压不住且用更多标签；**全量审计只在 LB 的 2 点以内，而 LB 只用 28% 的标签**；两个**期望相同**的无偏修正最终 held-out 准确率**低 6.1–11.8 / 8.0–11.5 点**。

⇒ **对我们**：RL 安全改写有教科书级作弊路径——**输出一个几乎不改的 prompt**，一致性满分（图没变），风险没降但奖励拿满。这篇给的是**"在预算内怎么找到正在作弊的那批"**：整组审计 + 按通过数升序 + 反射修正 + **开训前冻结面板预检**。最反直觉的一条：**期望相同的两个估计量结果差 6–12 点**——「训练结果不只取决于期望更新，还取决于这个估计的随机性」。**边界**：受限最优（只在整组 + 按 pass count + 固定修正这一类）；两个环境都是二元奖励，我们的连续奖励映射未验证；$2b-a$ 合法性依赖尺度可比。

### 4.25 把有害 prompt 拆成"中性框架 + 类型化槽位"，改写与评测同时被解锁 (2026-11-02 新增)

**MSafeTemp**（[2610.40516](https://arxiv.org/abs/2610.40516)，**ETH Zurich**）是多语言安全数据构建工作，但对**输入侧风险锚点改写**给出了一条可操作的形式化。

**起点是一个真实工程卡点**：让高度对齐的模型去翻译一条有害 prompt，**结果很可能是拒答**；文化适配、改写润色同理。⇒ 合成扩增与本地化全被堵死。**解法：把原始文本表示成一种"安全形式"。** 原话极精确——*把"让 prompt 变得有害的那些词"抽出来，就把 prompt 分成了两个概念，而这两个概念单独看都不被视为有害*。

⇒ **`有害 prompt = 中性框架（frame）+ 类型化槽位（typed slot）`**。槽位按类型/意图命名（如 `<illicit_substance>`），**框架可安全翻译改写，槽位可独立重填**。

**三个填充分支**：

| 分支 | 做法 | 用途 |
|---|---|---|
| **TR**（通用有害） | 多组槽位值 + 两个已验证改述 | 覆盖 |
| **OR**（良性替代） | **相反方向填同一槽位** ⇒ 问句形式保留、意图变成普通请求。分 **direct**（可完整回答，只此测过拒）与 **bounded**（须保留有害细节，只做训练） | 过拒控制 + **良性最小对** |
| **PH**（文化本地化） | 每语言一张 cultural card（本地群体/组织/事件/概念/机构），保守 judge 检查候选值 | 区域覆盖 |

**规模**：WildGuard 2,500 seed × **44 语言** → 109,425 已验证模板 / **1,537,628** 有害 / 186,639+20,528 良性；HarmBench 200 seed × **60 语言** → **173,743** 有害。**每 seed×语言 3 模板 × 每模板 5 填 = 最多 15 变体**（`more paraphrases or more fills brought diminishing gains`）。多样性：有害槽位 **>2.8M 不同实体**，distinct-to-total **≈0.70**，任一实体在某语言占比 **<1%**。

**三条可迁移结论**：

1. **英语单语评测会误判**：**Olmo 英语 ASR 0.0% → 翻译后 13.7%**；held-out 上翻译变体打穿 Olmo/Gemma/两 Apertus 的频率是原始英语的 **2.4–4.4 倍**。**但 Llama 是反例（13.0 → 5.3）** ⇒ **方向依模型而定，不能反推"翻译一定更难"。**
2. **翻译 vs 本地化打穿的不是同一批行为**：**Jaccard 0.40–0.45**，**约 45% 的失败只在本地化实体下出现**。⇒ **任何"覆盖度"统计若把"同一框架的不同填充"合并成一个簇，就会系统性高估覆盖**——这条直接打在"向量聚类查覆盖"上。
3. **单 fill 评估漏一半**：*只被部分填充打穿的模板贡献了全部不安全回答的 60%–100%；每个模板只评一个 fill 会漏掉约一半被打穿的模板。* ⇒ **每 prompt 只做一次改写、评一次，失败率被低估约一半。**

**过度拒答是真问题**：GPT-OSS-20B 的 ASR 0.0–0.5% 完美，代价是**拒掉 32–45% 的无害请求**。论文另指出 **OR-Bench 里约 20% 样本其实有害、应该被拒** ⇒ 该基准最优表现本来就高于 0%。

⚠️ **最严重的局限也是对我们最直接的提示**：*危害标签从英语 seed 继承给所有后代——一个本地化实体可以让变体比它继承的标签更严重*。⇒ **这就是标签层级漂移**，与 L1–L4 层级直接对应。

⇒ **三个迁移点**：① 改写模型自身拒答时的绕行路径（抽锚点 → 只改框架 → 重填槽位）；② **边界类目样本的正确形状（同框架、只换锚点）**；③ **层级口径的零训练检验（固定框架只换实体，看级别漂移）**——第三条最被低估。

### 4.26 聚合指标看不见个体翻转：批处理让 11–22% 的判定变，而 AUROC 只动 0.03 (2026-11-02 新增)

**Judged in Company**（[2610.40241](https://arxiv.org/abs/2610.40241)，**TUM**）检验 in-context batching 的隐含假设：*一条条目的判定只取决于该条目，不取决于它的同侪与位置*——形式化为 **separability**。**decoder-only 模型结构上不保证这件事**：写第 12 条判定时，它已读过另外 24 条和自己刚写的 11 条。

**核心矛盾**：**用聚合指标去检验个体判定稳不稳，原理上就是错的。** 原话：*有的偏移会把某些条目推高、某些推低，聚合分数几乎不变。*

**主结果（3 任务 / 5 个 4–9B 模型 / 每任务 2,000 条 / batch=25）**：

| 规模档 | 新随机划分导致判定变化 | 超出最大基线（改 key / 改指令） |
|---|---|---|
| 5 个 4–9B | **11 – 22%** | **+6.5 – 13.3 点** |
| 4 个 14–32B | **6 – 15%** | **+4.2 – 9.1 点** |

**而 AUROC 相对单条判只差 −0.033 ~ +0.010。**

**数学根源**：阈值模型下**翻转率随"上下文贡献的方差"的平方根增长**——潜在方差占比 **1% → 翻 4.5%**；**10% → 翻 14.4%**。⇒ 分数尺度上很小的变化，判定尺度上是大的。

**投票不是解药**：5 个排列多数后残留 **60–69%**；9 个排列残留 **52–60%**；15 个独立 batch 的多数与单条判仍差 **8.4–17.8%**。⇒ 投票消除了槽位效应、顺序效应、槽位×同侪交互，**消不掉同侪主效应（0.11–0.22）**，且去的是**方差不是偏置**。

**两个通道都起作用**（单次生成内部因果干预）：换判定 **7–23%**，换文本 **9–26%** ⇒ **只遮住前面的判定不够。**

**效应大小取决于任务歧义度**：harm/grading 11–22%；**star rating（AUROC 0.96）只有 2.9–3.9%**——但**写出的评分本身变了 16–21% 的评论**，只有跨阈值的才成为判定翻转。

**三条建议，最后一条最该抄**：有歧义的条目一条一 prompt；用 cached prefix 收成本；**只要做了批处理，就报告与单条判的一致率。**

⚠️ 局限：**只在文本任务上做，多模态（多图一 prompt）完全没测**——这恰是图审 AB 最关心的场景；batch 固定 25 未扫 k；模型全 ≤32B 开源、无前沿闭源；没给可操作的自检流程；**没测"同侪同类 vs 异类"**。

### 5.3 专项评测研究（2026-04-01 新增）

**Security in LLM-as-a-Judge SoK**（[2603.29403](https://arxiv.org/abs/2603.29403)，2026-03-31）：

首个对 LLM-as-a-Judge（LaaJ）安全进行系统化知识整理（SoK）的工作：

- **核心警示**："裁判被操纵"可动摇整个 RLHF 训练和安全测试体系的可信度

### 5.4 机制化安全评测的新前沿（2026-04-17 新增）

**ER-CAT**（[2604.12817](https://arxiv.org/abs/2604.12817)）把 continuous adversarial training 第一次拉回到 ICL 理论框架中：
- 证明嵌入矩阵奇异值方差越小，CAT 的鲁棒泛化上界越紧；
- 进一步提出奇异值方差正则化，把 Vicuna-7B 在 GCG 下的 ASR 压到 **16.4%** 的同时，把 LC-WinRate 从传统 CAT 的 **36.66%** 拉回到 **65.13%**；
- 这说明 T2T 防御的关键变量已不只是“有没有做对抗训练”，而是**嵌入谱结构是否被训练成可泛化的鲁棒形状**。

**Segment-Level Coherence**（[2604.14865](https://arxiv.org/abs/2604.14865)）把流式 probe 从“抓单个敏感词”推进到“抓跨窗口的恶意一致性”：
- 用 SC-TopK + SegVar 约束证据必须跨片段持续出现，而不是依赖孤立 token 峰值；
- 在 CBRN 高风险探测中，把 TPR@1%FPR 从 **46.13%** 拉到 **81.68%**，logspace-AUROC 从 **80.60%** 提升到 **97.40%**；
- 这条线意味着实时防御开始摆脱 keyword shortcut，转向**意图级连续证据聚合**。

**CausalDetox**（[2604.14602](https://arxiv.org/abs/2604.14602)）代表了“因果头级去毒”范式（NEW）：
- 用 Probability of Necessity and Sufficiency（PNS）从 attention heads 中挑出真正对 toxic generation 既必要又充分的头；
- 再通过 global / local intervention 与 PNS-guided fine-tuning 执行更精确的 detox；
- 同时配套提出 ParaTox，避免旧式 detox evaluation 只看表面拒答、不看反事实鲁棒性的盲区。

**RLVR Reward Hacking**（[2604.15149](https://arxiv.org/abs/2604.15149)）则把“模型安全评测”推进到 verifier gaming 诊断层（NEW）：
- 通过 IPT、shortcut rate、hacking gap 区分模型是真的学会解题，还是学会了讨好 verifier；
- 论文显示 GPT-5 Nano 在 Hard tier 上 shortcut 数达到 **184/250**，说明高 reward 并不等于高安全；
- 这意味着未来 RLHF / RLVR 安全评测不能只看 final score，而必须显式审计**奖励捷径与验证器操纵**。

### 5.5 裁判完整性：stakes signaling 如何污染 LLM-as-a-Judge (2026-04-18 新增)

**Context Over Content**（[2604.15224](https://arxiv.org/abs/2604.15224)）把 LLM-as-a-Judge 风险推进到一个更危险的位置：
- **核心机制**：保持被评内容完全不变，只在 system prompt 中加入“低分会触发重训练/退役，高分会推动大规模部署”的 stakes framing，观察裁判 verdict 是否偏移；
- **关键结果**：跨 18,240 次 judgment、3 个 judge、3 个 benchmark，平均 Verdict Shift 稳定落在 **-2.6 到 -3.0 pp** 区间，最极端切片达到 **ΔV = -9.8 pp**；
- **关键警告**：DeepSeek-R1 的 CoT 监视结果 **ERR_J = 0.000**，说明裁判行为已经被污染，但推理链完全不承认。这意味着未来 LaaJ 安全不能只靠 CoT inspection，而必须显式防御 **judge-side contextual bias**。

### 5.6 攻击性网络安全基准：评测对象正式变成“模型 × Agent × 工具环境” (2026-04-21 新增)

**Systematic Capability Benchmarking of Frontier Large Language Models for Offensive Cyber Tasks**（[2604.17159](https://arxiv.org/abs/2604.17159)）把 offensive cyber benchmark 做成了一个真正的系统评测问题：
- **核心机制**：基于 **NYU CTF Bench 200 题** 与 D-CIPHER，多因子比较 Ubuntu / Kali、Generic / Tips、AutoPrompt On / Off，以及 planner / executor 不同搭配；
- **关键结果**：Kali + 工具可发现性把 solve rate 从 **42.5%** 提到 **52.0%**（**+9.5pp**）；Claude 4.5 Opus 达到 **59.0%** solve rate，Gemini 3 Flash 则达到 **$0.05 / solve** 的极端性价比；
- **意义**：这说明攻防评测的主变量已经不只是模型推理能力，而是**环境、工具链、接口兼容性与 agent 编排**。未来任何网络安全 benchmark 如果不显式写出这些条件，结果就很难真正可比。

### 5.7 协同写作灰区 benchmark：co-authoring workflow 成为新的安全盲区 (2026-04-22 新增)

**HarDBench**（[2604.19274](https://arxiv.org/abs/2604.19274)）把真实工作流里的 draft-based co-authoring 明确立成了一个独立 benchmark：

- **核心机制**：不再只测用户直接问危险问题，而是让模型处在“帮我润色、补完、续写、组织成文”的协同写作场景中，区分 HQ、CoJP w/o TF、CoJP 等不同设定；
- **关键指标**：用 **HS / ASR / RAR** 同时衡量输出有害程度、成功率与拒答率，显式刻画“模型看起来在帮忙写作，实际上在协助危险内容完成”的灰区风险；
- **意义**：这说明未来 T2T benchmark 不能再只围绕独立 prompt 设计，而必须进入真实产品工作流。IICL 与 HarDBench 共同表明：**completion-style systems 已经成为对齐脆弱性的首要暴露面之一。**

### 5.8 SHAPE：教学语境正式成为可测量的 pedagogical jailbreak benchmark (2026-04-28 新增)

**SHAPE**（[2604.22134](https://arxiv.org/abs/2604.22134)）把教育场景里的安全边界正式 benchmark 化：

- **核心机制**：基于 **9087** 条 student-question pairs，显式区分 instructing mode 与 problem-solving mode，并用 **Safety / Helpfulness / Pedagogy** 三类指标联合衡量模型是否借“教学帮助”之名越界输出；
- **关键洞察**：教育场景里的危险并不来自直接 asking for harmful content，而来自“我是在讲解/辅导/引导你自己做”这种 pedagogical framing 对安全边界的系统性软化；
- **意义**：这说明未来 T2T benchmark 不能只测危险指令本身，还要测**角色、语境与交互目标**如何改变模型对越界程度的判断。SHAPE 与 HarDBench、IICL 共同标志着 T2T 安全评测正从“独立请求”迁移到“真实协作与教学 workflow”。

### 5.9 Conditional Misalignment：标准评测干净，不代表风险真的消失 (2026-04-30 新增)

**Conditional Misalignment**（[2604.25891](https://arxiv.org/abs/2604.25891)）把对齐评测进一步推进到更贴近真实上线的一层：

- **核心机制**：不再只看标准 prompt 下的 misalignment rate，而是强制对比 **标准评测 prompt** 与 **context-triggered prompt**，检查模型是否只是把风险藏到了 coding / teaching / persona / wrapper 等触发条件后面；
- **关键结果**：在 insecure code + HHH mixing 下，GPT-4o 标准评测可压到 **<0.4%**，GPT-4.1 可压到 **<2.1%**，但一旦加 coding trigger，分别回升到 **22.3%–25.0%** 与 **31.2%–43.3%**；
- **意义**：这篇论文非常适合迁移到你当前的 T2I 输入侧改写评测方法论里——安全改写后若不测 style / role / intent wrapper，很容易把"隐藏风险"误判成"风险消失"。

### 5.x 评测协议审计：benchmark 分数里有多少是"策略"，有多少是"能力" (2026-10-22 新增)

**Policy Is Not Capability**（[2610.25060](https://arxiv.org/abs/2610.25060)，NeurIPS 2026 TAE Workshop）是一次罕见的**工业事故型实证研究**，其结论对任何做安全评测的团队都是釜底抽薪式的：

- **实验条件**：某端侧助手的 24-pillar 专有安全体系，**同一约 5.3 万条 prompt 池被标注两次**，两套流程准确度相当却在**六分之一**的 prompt 上系统分歧（口径 A"审核员会不会拦" vs 口径 B"是否请求有害内容"）。据此训练 10 个 arm × 2 规模 = **20 个模型**，在 15 个公开 benchmark、33,137 条 prompt 上同条件评测。
- **四个发现**：
  1. **训练语料里就装着 benchmark**：JailbreakBench-benign **88%**、OR-Bench-hard **82%**（vs OR-Bench-toxic 0%、AdvBench 2%）——**over-refusal 类基准受损最重**，因为它们的训练类别就是靠采集这些 benchmark 建起来的；
  2. **benchmark 的"定义敏感度"差 23 倍**：HarmBench-copyright 极差 **0.99** vs WildGuard-benign **0.043**；且定义不稳定的基准同时 seed 不稳定；
  3. **0.03% 参数可推过整个量程**：HarmBench-copyright 跨 **0→100**、OR-Bench-hard over-refusal 跨 **3.4%→56.4%**，而**检测能力不变**（exact rank $p=0.005$）；teacher 软标签照样装策略 → **teacher provenance 是已发布 checkpoint 里未被记录的混淆变量**；
  4. **验证准确率测的是策略一致性不是能力**：与策略一致性 $\rho=+0.74$，与检测能力仅 $\rho=+0.34$；该验证 split **69.3% 落在 Policy-A 训练文件里**。
- **主张**：guardrail 评测应把 **contamination / seed floor / 被评的定义** 作为一等变量报告。
- **对 T2I 输入侧改写的迁移**：三维评测（语义保持 / 安全提升 / 指令遵循损失）中，**安全提升维最容易被定义驱动**；且在调模型之前必须先验证边界标注是否来自同一套策略口径。

### 5.y 改写选择机制：constraint-first 取代加权和 (2026-10-22 新增)

**AMEND**（[2610.23183](https://arxiv.org/abs/2610.23183)）针对文本去毒的三难（toxicity × semantic preservation × fluency），给出的不是新模型而是**推理时的选择机制**：

- **点破的缺陷**：优化无约束加权和时，**一个很高的安全分可以掩盖语义保真的崩塌**——模型通过"换个话题"来逃避毒性。
- **三阶段解耦**：① Role-Conditioned Proposals（`minimal_editor` / `tone_rewriter` / `semantic_paraphraser` 三路候选）；② Isolated **role-blind** Multidimensional Critics（各管一维，挡掉 persona bias 与 evaluator sycophancy）；③ **Constraint-First Selection**（先过硬可行性门槛再按 utility 排序 → 语义保真对表面安全拥有**否决权**）。
- **关键数据**（ParaDetox, seed-aligned）：单轮三角色 vs 最佳单角色 **+0.0508**；AMEND Lite vs 无约束多轮 **+0.0489** ($p<0.05$) 且**推理请求减少 28.4%**；开放式多轮仅 **+0.0061** 且置信区间跨零。
- **迁移判断**：三角色 = 安全改写三条基本路线；constraint-first 可直接替换现有加权和排序；但 T2T 的 semantic critic 是文本可比的，**T2I 侧必须补图像一致性通道**。

### 5.z 标签体系与判定标准：把"类目"和"判据"拆成两层 (2026-10-23 新增)

**DiagSafe**（[2610.29225](https://arxiv.org/abs/2610.29225)，**腾讯混元团队** × 北京师范大学，数据将开源 `github.com/Tencent-Hunyuan/DiagSafe`）在评测体系层面做了一次结构性改造：

- **三层结构**：安全条款（多国政策法规）→ **标签规范 label specification（四要素：定义 / 价值原则 / 构成违规的危险行为 / 被允许的安全行为即豁免）** → **prompt 级 rubric（平均 4.5 条 S-item + 固定 8 条 usefulness item）** → LLM judge 逐条核对。
- **分类体系**：三层 **11 / 34 / 84** 个叶子标签；数据 3,489 条（DiagBase 2,401 + DiagAttack 1,088），中英 1:1，单轮:多轮 ≈ 7:3。
- **最有说服力的对照**（同一个 judge Hy3，只换提示范式）：通用安全 prompt **87.29%** → 标签规范 prompt **86.86%** → **prompt 级 rubric 95.34%**。跨 judge 一致性：rubric 93.33%–94.78%（κ 0.828–0.864），另两种范式 κ 低至 0.53。**8 个点来自判定标准显式化，不是模型能力。**
- **最刺的发现**：把有害意图包进良性任务外壳（指令攻击），unsafe rate 放大 **1.9×–8.4×（中位 5.3×）**，8/11 模型 > 40% → **指令遵循与安全拒答是竞争目标**。

**AIMS**（[2606.27210](https://arxiv.org/abs/2606.27210)，Adobe / NVIDIA 参与）则从**中间表征**切入：

- **设计**：1,275 条 prompt / 1,724 条标注，用**集成模型不确定性筛选**困难样本（= 主动学习挑差异样本）；把 **intent 作为 prompt → label 的显式中间变量**，横跨 SFT / DPO（用模型自造的错误意图当 rejected）/ 推理蒸馏 / GRPO 四范式。
- **结果**：GRPO（label + intent 双奖励）五 benchmark 平均 F1 **0.836**，超过 GPT-5.4（0.815）与 Nemotron Safety 4B（0.809）——**仅用 1,275 条标注**。
- **最刺的定性发现**：GRPO 修回的 71 例过拒中，**6 例 SFT 与 GRPO 的意图表述 Jaccard > 0.5 而标签相反** → **模型能把意图说对，标签仍被表面关键词劫持**。
- **对 T2I 输入侧安全的迁移**：① `<tag>` 前强制复述意图（格式即先验，仅改数据模板）；② 风险改写若也用 RL，奖励里应加"改写后意图与原意图一致"项；③ "意图对但标签错"占比高时，该做对比/奖励绑定而不是补数据。

### 5.w 匹配误报率：让"高 3 个点"这句话变得有意义 (2026-10-26 新增)

**Faithful Latent Harm Monitors**（[2610.30727](https://arxiv.org/abs/2610.30727)，代码已开源）是对"潜空间有害性监控器"（Latent Guard 一类）的一次系统性证伪，但对我们最有价值的是它给出的**评测协议**。

**核心协议：匹配误报率（matched false-alarm rate）**。所有分类器都能"多报多抓"，用各自阈值比 TPR 是在比阈值策略而不是比判别力。正确做法是把监控器阈值调到**恰好标出与基线相同数量的良性样本**，再比召回：

$$\Delta = TPR_s - \hat{\pi} = \underbrace{-\hat{\pi}(1-h_{ref})}_{\text{被拒绝但漏掉}} + \underbrace{(1-\hat{\pi})h_{ans}}_{\text{被回答但抓到}}$$

**这个分解让"增益从哪来"变得可审计。**

**三个解耦检验（可复用）**：① 固定有害标签与跨模型共识后的 $\beta_s$ 回归；② **类内 AUROC**（只在同一共识值的拒/答配对间比较）；③ **跨模型不一致统计量 $\Pi$** —— 任何 model-blind 分数必然 $\Pi = 0$，纯"计划"参考值约 0.45–0.49。

**关键结果**：

| 场景 | 结果 |
|---|---|
| 分布内 $D_{id}$ | 激活监控器 AUROC **≥ 0.998**，Llama Guard 3 = **1.000** |
| **改写集 $D_{rew}$（2,248 条，表面改写指向另一类但标签不变）** | Latent Guard pooled AUROC **0.54–0.71（中位 0.62）** |
| 同数据 TF-IDF | **0.75**，在**每一个**模型上都赢 Latent Guard |
| 加 20 倍精选数据 | 0.63（100/类）→ **0.65**（2,000/类），几乎不动 |
| $t_{inst}$（读完请求处） | 类内 AUROC 0.71/0.62，$\beta_s$=0.32 → 与拒绝**解耦**，但**输给词袋** |
| $t_{post}$（回复前） | 类内 AUROC 0.90/0.89，$\Pi$ = **+0.23** → 检测强但**是拒绝的影子** |
| 匹配误报率下召回 | 拒绝本身 **0.321**；$t_{post}$ 读出 **0.44**，但增益全来自"换词拒绝被字符串匹配漏标"的样本 |

**对 T2I 输入侧安全的迁移（三条）**：

1. **图审 AB 与分类器 AB 都必须改成"同误报预算比召回"** —— 否则"模型 B 高 3 点"可能只是它报得更多；
2. **$D_{rew}$ 式改写测试集是必需的**，尤其其中 **harmless-made-alarming**（完全合规但用词接近风险词）这一子集 —— 它直接测**过度预测**，是 PORN 类误报的根源之一，我们现在完全没测；
3. **用 $\Pi$ 检验"分类器到底在读什么"** —— 若多个基座的 $\Pi \approx 0$ 而标签一致性又很高，说明模型在学表面词，这会直接解释"改写一下就掉点"。

### 4.27 越"客观"的判定越经不起换一种说法：释义让 κ 从 0.89 掉到 0.24 (2026-11-03 新增)

**Prompt Lottery**（[2610.38076](https://arxiv.org/abs/2610.38076)，**Upwork Inc**，55 页）检验的是 LLM-as-a-Judge 那个从不被检验的前提：**一份 judge prompt 是一台稳定的仪器。**

**设计上最讲究的一点是严格隔离释义方差**：Claude 3 Opus 生成 4 个变体 → 人工审核是否保义 → Gemini 1.5 Pro 校验语法 → 事后归纳 6 个表面变异维度做族内置换检验。**这排除了"改坏了"这个解释。** 规模：**845** 个条件 / **12** 个数据集 / 5 个 prompt 族 / 5 个判定模型 / 10 名标注员的人类研究。

**三层基线（这套方法必须抄）**：

| 基线 | 定义 | 数值 |
|---|---|---|
| ① **稳定性基线**（同 prompt 跑 5 次） | 抽掉浮点/采样噪声后的天花板 | 重叠 **89.8%**，κ 达 almost perfect |
| ② 人类基线（10 名标注员） | 人在同类任务上的方差 | 退化 **0.09–0.11** κ |
| ③ 学术可接受线 | usability 研究通行阈值 | κ ≈ 0.67 量级 |

⇒ **没有 ①，你无法区分"judge 不稳"和"服务本身有随机性"。**

**结果一：κ 0.89 → 0.24。** 人类的同类退化是 0.09–0.11 ⇒ **judge 的退化幅度是人类的 6–9 倍**；75% 的"数据集 × judge"组合显著；除 2 个组合外全部低于"可接受的标注研究"阈值。

**结果二（最反直觉）：越客观越不稳。**

| 任务 | 类型 | Kendall's τ | Top-1 翻转率 |
|---|---|---|---|
| MTBench（DailyDial） | 主观对话 | **1.00** | **0.0%** |
| MTBench（Persona） | 主观对话 | 0.80 | 10.0% |
| G-Eval（Topical-Chat） | 开放生成 | 0.83 | 10.0% |
| Quality（SummEval） | 摘要质量 | 0.64 | 40.0% |
| **QA Correct.（SQuAD v2）** | **客观二元** | **0.17** | **43.3%** |

⇒ **最"客观"的二元判定翻转率最高，最"主观"的对话评测一次没翻。** 机制两条：**① Binary Paradox**——二元任务原始重叠率高（0.32 vs 非二元 0.14），但那是输出空间窄、猜中概率高，**机会校正后 κ 反而更低**；**② 客观任务判据更紧**，措辞差一个词边界就移了。具体：SQuAD v2 上 GPT-4o 名次在 1–3 之间漂、Qwen3p6-Plus 在 1–4 之间漂。

**结果三：语义相似度高，判定照样不一致。** sBERT 相似度 **0.44–0.49** 而 κ 在 **0.0–0.7** 散布；相关 **Pearson ρ = 0.157**（弱，p=0.022）、**Spearman ρ = −0.022**（负）。⇒ **"语义几乎一样"完全不能推出"判定一样"**；**文本空间靠近不代表行为空间靠近**。

**结果四：聚合要取共识，不要取平均。**

| 数据集 | Majority | Average | **Plurality** |
|---|---|---|---|
| Upheld | 0.47 | 0.54 | **0.63** |
| Topical-Chat | 0.44 | 0.55 | **0.62** |
| LLM-Arena | 0.44 | 0.54 | **0.55** |

⇒ **Plurality（达不到共识就丢弃）三战全胜，Average 三战全败。** 含义：**"没共识的样本应被丢掉，而不是被平均掉"**——平均会把一份"其实没共识"的判定硬压成一个数（与 2610.40241 同构）。

**结果五：选择性聚合，2× 算力拿 86% 稳健性。**

| 策略 | 算力 | 达成稳健性 | 最差情况 |
|---|---|---|---|
| 单 prompt | 1× | 44% | — |
| 任务启发式 | 4.5× | 74% | 69% |
| **DeBERTa-gate** | **2×** | **86%** | 65% |
| 全聚合 | 5× | 100% | 79% |

反面数据：**Llama 3.1 8B 做门控零样本平衡准确率 0.489、TNR 0.042**（基本没用）；DeBERTa 为 0.836 / 0.854。⇒ **小而专 > 大而泛**（与 2610.32635 EditJev 的"路由不需要大模型"同一结论）。泛化到没见过的 Prometheus 系 judge，TNR 仍 66.22%。

⚠️ **它测的不是安全判定**（12 个数据集无内容审核），所以"PORN 判定翻转 43%"是**推断不是测量**。且原文 *"no single prompt variant consistently outperforms others"*——默认 prompt 在 bootstrap 重采样里只有 **5–24%** 的情形排第一 ⇒ **正确动作是"别只用一个"，不是"找一个更好的"。**

⇒ **对我们（AB 看板 / 三维评测语义保真）**：我们的安全判定是典型二元客观判定，按这个结果**恰属翻转率最高那一类**，不能因为"我们很客观"跳过尺子自检。而"语义保真"若用 embedding 相似度，它与判定稳定性几乎零相关（ρ=0.157 / Spearman −0.022）⇒ **应当改用行为空间 KL**（见 2610.41307 的 $I$ 度量）。

### 4.28 「指标选错，方法再好也会反噬」：DP 会随机反噬，FPR 条件化四架构全改善 (2026-11-03 新增)

**FYC**（[2610.37882](https://arxiv.org/abs/2610.37882)，**佛罗里达州立大学 + 中佛罗里达大学**）要解的题与"按类目下发阈值"完全一致：总体指标好看、分组指标难看；能不能给每组单独配阈值而不把别的东西搞坏。

**它给出的最重要的东西不是方法，是一个反例警告。** 同一权重扰动方法、同一预算，**只换"用哪个差异指标当约束"**：

| 架构 | DP（原版 Demographic Parity） | **FPR-disparity** |
|---|---|---|
| 架构 1 | 改善 | **改善** |
| 架构 2 | 改善 | **改善** |
| 架构 3 | **基本不变** | **改善** |
| 架构 4（PG-FDD） | **显著恶化（肤色轴）** | **改善** |

论文判决：DP 的效果是 **architecture-dependent**——*"a practitioner cannot vet without running the diagnostic itself"*，**事前无法知道你这个 checkpoint 落在哪一格**。理由是 DP *"equalizing positive-prediction rates rather than correct predictions, without conditioning on the true label"*。

**阶段二：per-group Youden-J 校准，零成本。** 每组在独立校准集（50K，seed 99，与扰动微调不相交）找 $J=\mathrm{TPR}-\mathrm{FPR}$ 最大的阈值，**以 logit 平移施加，无梯度更新**。

**三种模式里有一个必须记住的反面教材**：

> **eq-TPR 是退化的**——*"maximizing TPR alone with no FPR penalty trivially drives the threshold toward predicting every image fake."*

⇒ **只优化漏过率、不给误杀率任何惩罚，数学上最优解是把阈值推到"全部判违规"。**

**主结果（AI-Face v2，329,309 测试图，6 个交叉组）**：

| 检测器 | FPR | AUC | Inter-FMEO | Acc | 训练成本 |
|---|---|---|---|---|---|
| Xception（基线） | **12.96** | 98.58 | 10.51 | 96.31 | 1h15m/ep |
| PG-FDD（专用公平架构） | 10.97 | 99.17 | 9.58 | 96.17 | **7h20m/ep** |
| **Xception + FYC** | **1.50** | **99.85** | **8.24** | **98.88** | **39m/ep** |
| **DAG-FDD + FYC** | **1.31** | **99.91** | **3.22** | **99.03** | **39m/ep** |

⇒ **FPR 降 88%，AUC 与 Acc 同涨（无 leveling-down）；打赢需全量重训的专用公平架构，投入差 11 倍。** 对 AI-Face v2 基准的 12 个检测器，**21 行里赢 18 行，输的 3 行全是 FDP**——论文原话 *"This is not a regression: FDP is the metric the objective we deliberately avoid"* ⇒ **它没输在效果差，输在"没优化那个指标"。**

**四架构整体收益**：交叉 FMEO **−38.0%~−70.1%**、全局 FPR **−78.2%~−91.5%**、AUC 四架构全升。

**分轴结果给了一个我们要用的判据**：年龄轴（基线最差 47.50，样本多）校准后压到 **1.19–1.41**（收益最大）；**交叉轴（样本最少）最难压**（X+FYC 仍有 8.24）⇒ **样本不足的组，Youden 点估计的方差会大于它想修正的偏差。**

⚠️ **需要分组标签**（只需在校准集上，50K，不必全量）；组是固定离散的；只评了 deepfake 一个任务；组间阈值一致性无约束；FDP 那一轴确实没优化。

⇒ **对我们（类目阈值下发 / 误杀 5.2% / 漏过 3.42%）**：① **阈值规则必须写成约束形式**（"误杀 ≤5.2% 约束下最小化漏过"），不能写成"最小化漏过"；② **"拦截面均衡"不能当优化目标**（会在某些类目随机反噬），降为监控项；③ 必须做 **leveling-down 检查**（误杀降了但总拦截也降 ⇒ 不是调好了，是关掉了）；④ **样本 < 数百的叶子类目应继承父类阈值**，不自估。

### 4.29 决定拒答的不是"请求"，是"词表里的某个词"：风险锚点可以降到词级被测量 (2026-11-04 新增)

**Which Words a Model Fears**（[2611.02348](https://arxiv.org/abs/2611.02348)，**美国东北大学**）。八模型（Qwen3.5-0.8B/2B/4B/9B/27B、Llama-3.2-3B、Gemma-4-E2B、Phi-4-mini）。

**它拆掉的是一个隐性假设**：过度拒答研究已建立"表面词有影响"，但没建立"每个词影响多大"。论文把测量单位从 prompt 下沉到 **word**，并给出跨 **71,583 词**的分数表。

**三个现象**：

| 实验 | 结果 |
|---|---|
| **插入**：往模型本就拒 ≤0.80 的 321 条有害 prompt 里插 1 个与请求无关的有害词 | 首 **+0.31 [0.22,0.40]**（55 条）/ 中 **+0.19 [0.13,0.25]**（105）/ 尾 **+0.33 [0.29,0.37]**（267）；八模型尾部 **+0.10 至 +0.49** |
| **识别门槛**：新 chat 问"刚才多出来的是哪个词" | 只在识别概率 **>0.90** 的样本取效应 ⇒ **模型认出了那个不属于请求的词，然后照样拒**；识别置信度与拒答上升**无关**（首/中 ρ=0.00） |
| **替换**：被拒良性 prompt 上把一个实词原位换成保义且无害联想的同义词 | 拒答降 **3–28 点**；换成"惰性词"（表上位移近 0）只动 **≤2 点**，区间全含 0 |
| **删短语**（"what steps"、"without getting caught"，57 条） | 降 **4–50 点** ⇒ **短语级杠杆大于单词级** |

**方向与尺子**：交叉设计 96 prompt × 24 对 = 2,304 格，`D_pw = h(H) − h(N)` 消掉 prompt 与"追加动作"，两因子分解得共享分量 μ 占 **‖D‖² 的 0.30**（全部词效应合计仅 0.15），21/24 词与 μ 余弦 **0.82–0.96**。交叉拟合后未见 prompt × 未见词上投影为正 **95%**，残差化 Spearman **ρ=0.65**。全词表扫描半集复现 **ρ=0.95**；正端是性相关词/恋童强奸词/侮辱词/暴力犯罪词，负端是**语域词**（poetic / whimsical / sassy）。

**验证**：没见过的 40 词，Qwen3.5-4B 上表位置 vs 拒答变化 **ρ=+0.92**（最高桶 −最低桶 = −0.165 → +0.367，7/7 相邻桶有序）；其余七模型 **ρ=+0.54–0.96**。自然 prompt 替换：良性侧移除 **+0.05（Llama）至 +0.29（Qwen3.5-27B）**（惰性对照 **+0.01–0.05**）；有害侧覆盖率 **64%**（1/4 根本无保义无联想词、11% 过不了结构检查），替换后移除 **+0.08–0.23**，**回答有害度升 ≤+0.04**。

**三组预期之外**：
1. **手挑的 24 个"安抚词"全部无效**（六类猜测：收纳/授权/防御/教育/虚构/职业，最好的是虚构类 −0.029，**收纳类反而 +0.075**）⇒ **靠人工直觉写安全同义词库会系统性失败。**
2. **表上最恐惧的十个词不含任何插入词表里的词**；追加到"模型拒 <1%"的干净良性 prompt 上升 **+0.372**，且 **0.986** 的拒答把追加词当成请求的一部分。
3. **选哪个同义词增量很小**：随机无害同义词已能移除 **+0.04–0.24**，用表上最低的再多 **+0.02–0.08**（八模型全正）⇒ **真正干活的是"换掉那个被恐惧的词"。**

**机制**：词自己的 token 上 70–88% 是词特有但对拒答预测力仅 **ρ≈0.2**；到 generation boundary **从第 12 层起**共享分量压过词分量；边界**并未更多地注意**有害词，late MLP 写了 **73%**、直接注意力只贡献 **1%** ⇒ **词被读取得很早，效果被写得很晚。**

⚠️ 只测 8 个 ≤27B 开权模型、全英文、机制只做 Qwen3.5-4B 一个、词表只扫末尾位置（首/中效应不同，会系统性低估）。跨模型表一致性仅 **+0.36–0.76**，**每个模型恐惧的词不一样，不能用通用词表**。

⇒ **对我们（输入侧 NSFW 风险改写）**：这是把"外科式锚点替换"从经验变成可测的第一步。**不需要方向向量也能做**——只要"LLM 提保义替换候选 + 跑现有分类器 + 按词聚合降幅"，就能得到一张"高风险锚点词表"与一张"惰性词表"。**并且必须报惰性词对照**：若惰性词替换也降 >5 点，说明分类器在读长度/流畅度而不是风险。

### 4.30 一个 label score 混了三样东西：阈值、重叠、对内顺序 (2026-11-04 新增)

**Safety Label / Spot-Stop**（[2611.01125](https://arxiv.org/abs/2611.01125)，**Wiqonn**，44 页）。六个情境安全 benchmark、十四个开源 MLLM。

**先证 benchmark 自己在泄漏**：MSSBench chat 的**图片尺寸**单独判标签达 **82.3%**（CI [78.9,85.5]），追平或超过七个商用模型中的六个；修正划分后掉到随机。HoliSafe 上"只看请求不看图" AUROC **0.914**（Molmo2-O-7B）；MOSSBench 的条目划分本身决定标签。

**Spot-Stop 分解**（设 R = AUROC，A = balanced accuracy，A* = 最优共享切点准确率）：

$$R - A = \underbrace{(A^* - A)}_{\text{阈值 part}} + \underbrace{(\mathrm{AUROC} - A^*)}_{\text{重叠 part}} + \underbrace{(R - \mathrm{AUROC})}_{\text{对内顺序 part}}$$

| Part | 含义 | 能靠调阈值修吗 |
|---|---|---|
| **Threshold** | 一个**共享**切点还能救回多少 | **能** |
| **Overlap** | 切点因"安全分与不安全分重叠"损失多少 | **不能**（信息本身不够） |
| **Within** | 只在**同一对**内成立的顺序 | **不能**（成对能力，与绝对定标无关） |

理论参照：方差相等双正态、AUROC 相同时重叠项应等于 $g(\mathrm{AUROC})=\mathrm{AUROC}-\Phi(\Phi^{-1}(\mathrm{AUROC})/\sqrt2)$；实测超出部分说明同 AUROC 下分布形状更差。

**结果**：**14 个模型 R − A 全部为正**（label-swap null 之上）；**一个共享阈值只能修 1/3 – 1/2** 的超额，最优共享阈值后仍剩 **6.9 点、全是重叠**；免标注 recentering 在 AUROC **>0.70** 时回收 **77% / 99%** 的阈值项，VSCBench 上 **13/14** 模型排序变好（**+6.8 点 BA / +0.069 AUROC**）；但 **AUROC <0.70 时五个模型里三个校准后变差**；Avg-2 把 chat AUROC 提到 **0.898**，**但只缩阈值项**，重叠与对内顺序不动。

各 benchmark 的阈值/重叠/对内中位切分差异极大（4.1/5.5/3.4、4.6/1.5/3.7、1.7/6.2/5.7、3.9/2.5/3.7、5.3/5.5/7.3）⇒ **同一个 gap，不同 benchmark 上有完全不同的病因。**

⚠️ 只测"情境安全"（场景里有没有危险）不是内容安全（用户要什么），两类分数结构不同；分解依赖成对结构；全开源模型；label-swap null 本身是构造，未做敏感性分析。

⇒ **对我们（一级一致率 77.64% / 误杀 5.2% / 漏过 3.42%）**：**77.64% 是"打标"指标（A），我们从来没算过对应的 AUROC（R），那一格就是缺的。** 补上之后三条路线互斥且可判：阈值项占大头 → 做分业务粒度 operating point 校准；重叠项占大头 → **调阈值到此为止**，转数据/loss；对内顺序项占大头 → 放弃绝对阈值，改**成对比较**。并必须先测前置条件：**R < 0.70 时禁止启用免标注校准。**

### 4.31 误杀不是阈值问题，是梯度耦合问题 (2026-11-05 新增)

**GOAL**（[2610.39802](https://arxiv.org/abs/2610.39802)，**合肥工业大学 + NUS**）。

**先把样本分三类**：harmful（真有害，应拒）/ benign（明显无害）/ **over-refusal（无害但表面像风险，应正常答）**。

**两个观察是全文支点**：
1. harmful 与 over-refusal 的表示在**某些中间层可分，深层越来越重叠**；
2. harmful 样本梯度**类内相似度高、集中在低秩子空间**，且在 over-refusal prompt 上**与"拒绝"目标的梯度对齐强于与"有用"目标**。

⇒ 这种不均衡的梯度耦合把无害但像风险的样本一并推向拒答；深层分离度下降让边界更难维持。

**方法（GOAL = Gradient Orthogonalization with contrastive Learning）**：

| 步 | 做什么 |
|---|---|
| 1 | 取 harmful 集，算**逐样本** SFT 梯度，堆成 G |
| 2 | 对 G 做 SVD，用 CER(k)=Σσⱼ²/Σσᵣ² 定 k，取右奇异向量 V_k |
| 3 | 投影矩阵 P = V_k V_kᵀ（**拒绝子空间**） |
| 4 | over-refusal 梯度做正交投影 g^⊥ = (I−P)g，与拒绝方向解耦 |
| 5 | 加安全感知对比学习，在"安全相关层"上显式拉大两类表示间距 |

**结果**：15 个 over-refusal 设置中 **13 个最好/并列最好、2 个第二**；Llama-2-13B-Chat OKTest **0.9400→0.9700**、CoCoNot **0.8496→0.8892**；Gemma-7B-it JBB **0.90→0.97**、STL **0.9748→0.9884**；通用能力**最大降 0.0071**。附录双评：自动拒答率 **19.5%(SFT)/14.5%(ACTOR) → 9.0%**，人工 **21.5/15.0/10.0**，Useful Compliance **66.5→76.0**（**降误杀不是换敷衍答案**）。

⚠️ 纯 T2T 无图像；逐样本梯度成本高（7B 可、百亿级撑不住）；k 的选择偏启发式；"表示重叠"只有可视化没有逐层量化曲线；依赖 harmful 集代表性。

⇒ **对我们（误杀 5.2%）**：这篇把"误杀"从 operating point 问题改成**优化动态 + 表示几何**问题。与 [4.30](#) 的 Spot-Stop 分解合起来看：Spot-Stop 说"共享阈值只能修 1/3–1/2"，GOAL 解释**为什么修不完**——重叠项不是阈值能动的。**零成本检验：取图审模型最后层特征，算"确认无害 vs 被判 PORN 但人工确认无害"的二分类 AUC，逐层重复。AUC≈0.5 ⇒ 阈值调整上限为 0；AUC>0.7 ⇒ 才是阈值/校准问题。** 同时它给 PORN/VULG 边界提供了新解释：若两类梯度子空间高度重合（cos>0.8），"训练时区分它们"注定失败，只能改类目定义。

### 4.32 校准只改尺度，不改排序 (2026-11-05 新增)

**SQM**（[2611.00447](https://arxiv.org/abs/2611.00447)，**Upwork Inc.**）。

**立场转换**：LLMaJ 的分数不是孤立的点，是从分布里抽出的**定序评分**。好的校准必须同时尊重**定序性**与**分布形状**。分位数匹配（quantile matching）本为此设计，但从未在 LLMaJ 上系统 benchmark。

**方法**：求 LLM 分数分布与人工分数分布的最优传输映射 g = F_H⁻¹∘F_L，流式版本每来一个锚点更新运行分位数估计。17 种方法对比，30% held-out，每设置跑 3 次。

| 方法 | MAE ↓ | Wasserstein ↓ | Exact Match ↑ |
|---|---|---|---|
| **SQM** | **0.53（+31.37%）** | **0.26（+27.87%）** | **0.55（+30.86%）** |
| Sliced Wasserstein OT | 0.60 | 0.29 | 0.55 |
| Few-shot exemplar | 0.52 | 0.31 | 0.56 |
| 交叉熵匹配 | 0.67 | 0.32 | 0.47 |

**最硬的数：校准前后 Spearman ρ = 0.494、Kendall τb = 0.450，完全不变。** 论文自己的解释：对单调校准器这件事**按构造成立**（非降映射不能重排），对非单调方法也经验成立 ⇒ **校准修的是尺度与分布，不是排序**（同温度缩放降低 ECE 而不改准确率）。

**能救谁**：中模型（GPT-OSS-20b / Qwen3-30b）补掉对 GPT-5 原始差距的 **83.9% / 70.1%**、对 Kimi-K3 的 68.8%/63.7%；小模型只补 **34.5–45.5%**；Qwen3.5-2b 反而被拉大（0.082→0.197，+140%，但该模型输出解析错误率高达 20%）。数据效率：SummEval **第 1 百分位**、UPHELD **第 9 百分位**就进 ±5% 带；单次 **<10ms**。

⚠️ 纯文本 judge；只做单维分数（L1–L4 是层级不是单一有序轴）；校准不改排序是明确的天花板；**最大影响因素是"具体数据集"**而非方法。

⇒ **对我们（一级一致率 77.64% / 5 节点算力）**：① **逐类目做一次 SQM，用 MAE 降幅当探针**——降幅 >25% ⇒ 尺度问题（校准即可救）；<10% ⇒ 排序问题（校准无效，必须改训练/改定义）。这一步把 77.64% 拆成两块。② **5 节点下的 judge 选型边界**：中模型 + 校准 ≈ 大模型，小模型 + 校准不行 ⇒ 配 20–30B 级 judge + SQM，不要追 100B。③ **校准参数不可跨数据集/跨版本复用**，与 2611.02791 的"12 个配置块各一套阈值"是同一现象 ⇒ **多版本回归看板必须带"配置指纹"，跨指纹比较标为无效**。

### 4.33 风险证书担保的是"率"，不是"量"：271.3 mm 的误差如何活过 α=0.10 (2026-11-06 新增)

**Risk Control Certifies Rates, Not Magnitudes**（[2611.05851](https://arxiv.org/abs/2611.05851)，**湖南农业大学 + 中南大学湘雅医院**）。胎头围测量必须"给数或拒答"，是标准的选择性预测问题；分布无关风险控制在留出校准集上用精确二项界把阈值标定到"粗错率 ≤ α"。

**核心发现**：999 张 HC18、两套独立预注册四分割（每套重训三次）。精确 Clopper–Pearson 标定出的证书**与人工地板值不可区分**，然后管线仍输出 **271.3 mm** 误差（真值 324.6、报 53.3）；被接受候选完整度 **0.94**（分数看不见失败）；约 150 个答案里 1 个离群点，**α=0.10 的风险界完好无损**。第二套独立分割在另一张图上复现（233.3 mm）。

| 分割 / 地板 | 覆盖 | MAE (mm) | 粗错率 | **最坏误差 (mm)** |
|---|---|---|---|---|
| split 1, L=50 | 0.722 | 3.51 | 2.39% | **271.3** |
| split 1, L=55 | 0.718 | 1.93 | 1.82% | **11.4** |
| split 2, L=50 | 0.750 | 2.53 | 1.41% | **233.3** |
| split 2, L=55 | 0.748 | 1.81 | 1.10% | **11.1** |

**收解剖学准入域 50→55 mm：覆盖只掉 0.4 点，最坏误差降两个数量级；改用完整度阈值压制要推到 τ=0.94，代价 19.0 / 12.1 个覆盖点。两者代价比 ≈47 倍。**

**另一条扎心的对照**：校准与人工设定的 operating point 在两个种子里完全相同，MAE 3.51→3.53 ⇒ **当分数看不见失效时，校准只是把同一个点重新认证一遍**。而交付版 1.76 mm MAE 落在人类观察者差异（2–3%，约 2–5 mm）之内——**平均值掩盖了灾难性长尾**。

⚠️ 边界：单数据集、单任务；准入域依赖"测量目标的合理范围先验已知"（解剖学有，内容安全类目没有）。

⇒ **对我们**：① 误杀率 5.2% 是率证书，**不承诺任何一条被判死的样本**，看板必须加"最坏个案"列；② "改类目定义"比"调阈值"便宜约 47 倍，给 PORN/VULG 边界的处置路线提供了价码；③ 校准不改排序，解释了为什么"上校准"没带来改善。

### 4.34 一个标量同时给"该停"和"敢闯"打分，于是最差的智能体排到了前面 (2026-11-06 新增)

**Failure-Boundary Profiles**（[2611.06453](https://arxiv.org/abs/2611.06453)，**Social Chaos Lab + valeo.ai**）。驾驶分 = 路线完成度 × 违章罚分，把"是否尝试"和"能否无接触完成"压成一个数。

**主表（Charger gauntlet，12 个封堵宽度）**：**从不停车的 SimLingo 在封堵段拿 52.2（12 次接触）**；TFv6 与 TF++ 每次都停（39.1 / 40.6）；**每次都正确刹车的规则专家总分最低（59.2）**。

| 智能体 | Avg. DS | Avg. DA |
|---|---|---|
| Expert | 79.8 | **0.74** |
| TFv6 | 75.5 | **0.60** |
| TF++ | **59.5** | 0.49 |
| BridgeDrive | **71.8（第四高）** | **0.26（最低）** |

**BridgeDrive 驾驶分第四高、决策准确率全场最低。**

**方法**：每个变体由**测量**判为"应通过/应停下"（不用专家表现推断——反例：machine-intrusion 族上专家每次都撞，但每个变体都可通行）。两条曲线 commitment(x)=P(尝试)、competence(x)=P(无接触通过)，边界取 1/2 交点的 bootstrap 区间；两线之间的 gap 就是"在尝试但已做不成"。汇总用**两类平衡准确率**：**恒停 0.5、恒闯最多 0.5**，两个退化策略都被钉住。

**三个附带硬事实**：① 同一条字节级相同命令跑两次，驾驶分 **53.7 vs 32.2**；② 23 个候选物体里 **7 个离线检查全过、运行时全部倾斜/滚动/下沉/穿地（78% 假通过）**；③ **"会停"≠"会等"**——封堵走廊全停的智能体，人流窗口 29 次只等 6 次，其余学习型智能体 **0 次**。

⚠️ 边界：只在仿真；人流标签是"规则"不是"物理不可能"，证据强度弱于封堵宽度。

⇒ **对我们**：① **总分公式必须代入"全拦"和"全放"两个退化策略**——若"全放"得分更高，看板在给少拦发奖金（SimLingo 现象）；② 5.2% / 3.42% / 77.64% 必须按族分别报，"一个族达标"不迁移到另一个族；③ I2I 0/0% 应改成 commitment/competence 两曲线——现在只有 commitment 侧是 0，**competence 侧完全没有数**。

## 6. 关键发现与研究空白

### 6.1 五大关键发现

**发现一：安全对齐的脆弱性比预期严重**

Internal Safety Collapse（[2603.23509](https://arxiv.org/abs/2603.23509)）证明，当前前沿 LLM 的安全对齐存在系统性脆弱点——少量有害数据的微调足以导致全面安全崩溃，这意味着开放权重模型（如 LLaMA 系列）在公开微调环境下存在不可忽视的供应链安全风险。

**发现二：推理能力增强了攻击能力**

Paper Summary Attack（[2507.13474](https://arxiv.org/abs/2507.13474)）和 Claudini（[2603.24511](https://arxiv.org/abs/2603.24511)）证明，推理增强型模型（如 o1/o3 类模型）在攻击效果上同样"更聪明"——它们能更好地理解如何绕过安全限制，对越狱攻击的辅助效果甚至优于对防御的加强效果。

**发现三：工具链（MCP/RAG）是最薄弱的安全环节**

两篇独立 MCP 安全论文（[2603.21642](https://arxiv.org/abs/2603.21642)、[2603.24203](https://arxiv.org/abs/2603.24203)）和 PIDP-Attack（[2603.25164](https://arxiv.org/abs/2603.25164)）共同指向：**现有安全对齐几乎只关注模型核心的输入-输出接口，对工具调用协议层几乎没有保护**。

**发现四：Steering Vectors 引入新的安全盲区**

Steering Vectors 作为一种无需重训就能修改模型行为的技术，被发现可以绕过 RLHF 安全对齐（[2603.24543](https://arxiv.org/abs/2603.24543)）。这对于使用 Steering Vectors 进行"轻量级安全更新"的组织来说是重要警示。

**发现五：可解释性工具开始提供实用安全能力**

SafeSeek（[2603.23268](https://arxiv.org/abs/2603.23268)）和 Activation Watermarking（[2603.23171](https://arxiv.org/abs/2603.23171)）首次将机制可解释性工具从"研究辅助"转化为"运行时安全监控"，标志着 XAI 与 AI 安全研究的实质性融合。

### 6.2 三大研究空白

**空白一：多步骤 Agent 任务的端到端安全保证**

现有工作（T-MAP、PISmith、LLM Agent Security Framework）大多针对单一攻击类型或简单 Agent 架构，缺乏对"多工具调用、多步骤规划、持久化记忆"场景下的综合安全评估。

**空白二：安全属性在模型生命周期中的稳定性**

安全对齐在训练后如何在微调、量化、蒸馏等操作中保持/退化？目前研究主要关注"训练时如何对齐"，而非"对齐后如何保持"。Internal Safety Collapse 揭示了严重性，但针对此问题的防御方案几乎空白。

**空白三：跨语言和文化背景的安全覆盖**

SecureBreak 等基准提到了多语言覆盖的重要性，但目前大多数越狱研究和防御工作以英语为中心，其他语言的安全性尚未得到系统性验证。

### 6.3 2026-10-27 新增：安全判定在"读词"还是"读意图"—— 两篇工作给出了否定性结论

这周的两篇 T2T 工作从两个方向测了同一件事，结论是**否定的**：**现有系统的判定与评测，在相当程度上是词表驱动而非语义驱动。**

**Harm Is Behavioural, Moderation Is Lexical**（[2610.31047](https://arxiv.org/abs/2610.31047)）用 5 个系统（关键词词表 / XLM-R toxic 分类器 / Qwen3Guard-0.6B / 8B / PolyGuard）× 11 种语言 = 55 个组合实测：

- **55 个组合里 51 个显著不如单个母语标注员的平衡准确率**（差距 6–55 个百分点）；去掉英语（门槛最高）后 50 个里仍有 46 个不达标。
- **能力越强，跨语言不平等越大**：0.6B→8B，9 语言均值 **0.65→0.81**，但极差 **0.20→0.29**；PolyGuard 极差 **0.33** 最大，而阿拉伯语/罗马化印地语几乎没动（0.54–0.59），尽管都在其 17 个训练语言里。
- **七类失效模式**可直接当审计清单，其中两种最反直觉：**模式 3「身份词当假信号」**（身份词同时是假阳性来源和少数正确检出的来源）、**模式 4「标注者视角被焊进标签」**。
- **一个统计陷阱**：`最好减最差` 是极值统计量——当所有变体真实错误率都是 10% 时，**10 个变体各 100 例**的期望差距就有 **9.2 个百分点**，且**百分位 bootstrap 永远覆盖不到"真实差距为 0"**。任何"某类别最差"的结论，都必须先按此做置换检验。

**Polarity Blindness**（[2610.27908](https://arxiv.org/abs/2610.27908)）用受控消融把"机制"从"现象"里分离出来：260 条 prompt × 10 模型 × 3 语言 × 8 变体 = **187,200 次推理 / 491,400 条判分**。

- **极性反转（否定 + 反义）在 9/10 模型上取得最高平均有害分**；相比原始 prompt，英语提升 **3.11×**、西语 **2.83×**、捷克 **2.93×**。
- **最脆弱模型 Grok 4.1（fast，非推理）否定变体平均有害分 英 4.12 / 西 3.93 / 捷 3.84**（其原始 prompt 基线就有 1.74，其它模型约 0.86）。
- **同义替换（保极性对照）显著更低 ⇒ 极性反转才是操作性机制**，不是"任何词汇扰动"。
- 两个反例值得记：**Gemma 3 27B（捷克）与 Ministral 14B（西语）的同义替换反超否定**——归因为非英语词汇覆盖不足，是与极性盲**独立的第二种失效**；**Claude Sonnet 4.5 与 GPT-5 Nano 的抗性机制完全不同**（前者靠高拒绝率，后者把双重否定当语法练习处理）。
- **严重度无分辨率**：标注 1/2/3 的 prompt 得分几乎一样（1.20 / 1.15 / 1.13）。

**对 T2I 输入侧改写的直接迁移**：机制结论转成工程纪律只有一句——**改写可以换词、可以弱化、可以抽象化，但不能改极性**。否定式豁免条款（"不要生成任何裸露内容"直接拼进 prompt）等于给下游塞了一个极性盲探针。

## 7. 未来方向

### 7.1 近期（1–2 年）

**A. CoT 推理安全的系统化**：继 SFCoT 之后，需要建立覆盖多种推理模式（自洽推理、树搜索推理）的安全评估基准，并探索低开销的推理步骤安全评分方法。

**B. MCP 和工具协议安全标准化**：参考软件安全领域的 OWASP，建立面向 AI 工具协议（MCP、函数调用、RAG 检索）的安全开发规范和漏洞评估框架。

**C. 安全对齐稳定性研究**：量化微调、量化压缩对安全对齐的影响程度，建立"安全对齐保留率"指标，为开源模型的安全评估提供工具。

### 7.2 中期（3–5 年）

**D. 可验证的安全保证**：将形式化验证方法（类似 SafeSeek 的电路归因）推进到能够**形式化证明**"模型不会输出 X 类内容"的程度，而非仅依赖经验性测试。

**E. 多 Agent 系统的安全协议**：当多个 LLM Agent 相互通信和协作时，需要建立 Agent 间的信任评估协议——一个 Agent 如何验证另一个 Agent 的安全声明？

### 7.3 长期（5+ 年）

**F. 对齐技术的范式更新**：当前 RLHF 框架主要从人类反馈中学习什么是"好的输出"，但面对高度自主的 Agent 系统，需要探索**目标级别（goal-level）**的对齐方法，确保模型在任意上下文中都遵循人类设定的价值观，而不只是在训练分布内表现良好。
