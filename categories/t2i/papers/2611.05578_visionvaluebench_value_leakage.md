# 中性 prompt 也在表达取向，而且换语言改不了它

**论文主页**: https://arxiv.org/abs/2611.05578

## 一、背景与问题

### 动机

文化评测一直在数"图里有没有这个东西"：地标、服饰、器物、活动。论文指出这是**在测"画了什么"，不是在测"谁的取向"**。

它换了一个更狠的问法：**给一个"价值中立"的 prompt——不指定任何取向——生成器会不会自己填上一种取向？**

例子（原文）：

> "a teacher and students communicating in a classroom"

这句话没有说权威关系该怎么画。可以是老师讲课学生举手，也可以是老师俯身听学生说话。两种都符合 prompt，**但表达的是两种不同的权力距离**。

**生成器会在 prompt 留白的地方，用自己的稳定偏向填进去。** 论文把这件事叫 **visual value leakage**。

### 为什么这个结构和我们相关

我们的类目体系里有一批"看起来中性、却被判高风险"的 prompt。过去三轮我们给了三个解释（二维坐标、词驱动、组合性）。这篇给了**第四个**，而且不需要重新标注：

> 如果生成/理解模型在**中立输入上有系统性偏向**，那么"中立被读成风险"就不是标注错误，而是**模型先验**。此时调阈值只能移动截断点，改不动偏向的方向。

### 三条论断

1. 价值取向可以从图像里被**操作化并测量**（Hofstede 六维 × 4 语言 × 960 场景）。
2. 取向在**六个系统之间高度一致**——不是某个模型的偏好，是这一代 T2I 的共性。
3. **换语言几乎不改变取向（中位数位移 0.07），换地理线索只改变强度、基本不改变方向。**

## 二、核心方法

### 2.1 benchmark 构造

| 项 | 数 |
|---|---|
| 价值维度 | **6**（Hofstede：PDI / IDV / MAS / UAI / LTO / IVR） |
| 场景 | **960**（每维 160） |
| 语言 | **4**（英 / 中 / 印地 / 泰） |
| 地理线索 | 无 / US / China / India / Thailand |
| 系统 | **6**（MAI-2.6-Flash、FLUX.2[dev]、GPT Image 2、HiDream-O1、Nano Banana 2、Ideogram 4.0） |
| 每维最多图数 | 960（160 场景 × 6 条件） |

场景来自 CDEval 的文本价值题，被改写成**保留社会情境、去掉取向指定**的图像生成 prompt。这一步是全部构造的关键：**必须让同一个情境能被两种取向合理描绘**。

### 2.2 两套评审判据（这是本文最重要的部分）

| 判据 | 做法 | 成本 |
|---|---|---|
| **SAE**（Scenario-Anticipated Evaluation） | 先在场景层面预判"该取向会长什么样"，再去看图 | 低 |
| **IAE**（Image-Adaptive Evaluation） | 直接从图里找支持每个取向的视觉证据，自适应 | 高 |

两者都用**多智能体**做校验：证据是否 grounding 在图里、价值解读是否贴合场景，两票通过。

### 2.3 人类对齐

| 指标 | SAE | IAE |
|---|---|---|
| 与人类多数参考一致率（对两条参考） | 77.50% | **82.92%** |
| 与 IAE-H 一致率 | 67.50% | 80.42% |
| 评审者间平均一致率 | 78.58% | **87.25%** |
| Fleiss κ | **0.513** | **0.731** |
| 正/负一致率 | 41.3% / 86.1% | **68.9%** / 85.7% |

**IAE 的正例一致率 68.9% 对 SAE 的 41.3%**——差 27.6 点。这说明 SAE 大量**漏掉**了图上真实存在的证据。

## 三、技术细节

### 3.1 取向分数

每个系统在每维上得到一个 $S\in[-1,+1]$ 的取向分（+1 与 −1 是对立两极）。改变 prompt 的效果用 $\Delta S$ 表示，95% CI 由**按场景重采样**得到。

### 3.2 语言效应的量级

| 对比 | 中位数 $\lvert\Delta S\rvert$ |
|---|---|
| EN → ZH（无线索） | **0.07** |
| EN → HI | 0.07 |
| EN → TH | 0.08 |

**换语言不改变取向。** 少数符号翻转只出现在 IDV 维（该系统分数本就贴近 0）。

### 3.3 地理线索的效应

从 US 线索换到 China 线索，**位移主要发生在强度上，方向大体保持**。印度 / 泰国线索同样：抬高 PDI、降低 IDV，方向与 China 线索一致。

**一个额外的发现**：无地理线索时的取向剖面，**更接近 US 线索剖面而非 China 线索剖面**（Figure 12）。默认值本身就是一种取向。

### 3.4 改写器的效应（Appendix D.4）——本节对我们最关键

论文测了**带 prompt refiner / upsampler 的系统与不带时**的取向差。同一批 960 场景成对比较（每臂 5,760 张图）：

| 方法 | 维度 | $\Delta S$ [95% CI] |
|---|---|---|
| SAE | HiDream PDI | $+0.128\,[+0.057,+0.203]$ |
| SAE | HiDream UAI | $\mathbf{+0.602\,[+0.418,+0.786]}$ |
| SAE | FLUX UAI | $\mathbf{-0.246\,[-0.447,-0.041]}$ |
| IAE | HiDream UAI | $+0.539\,[+0.422,+0.649]$ |
| IAE | FLUX UAI | $-0.269\,[-0.353,-0.189]$ |

**HiDream 的 UAI 从 −0.357 翻到 +0.182**——**改写器把这一维的方向改反了。**

原文的案例（Figure 13）：prompt 说"一个人在家庭聚会与个人计划之间做出选择后付诸行动"，**HiDream 的 refiner 把它改写成"一个人面带喜悦站在山顶张开双臂"——把家庭那一支删掉了**。改写前只表达集体主义，改写后只表达个人主义。

## 四、实验与结果

### 4.1 六系统一致性（主结果）

| 维度 | 六系统共同方向 |
|---|---|
| PDI | 低权力距离（平等 > 等级） |
| IDV | 个人主义（自主 > 群体义务） |
| MAS | 关怀与生活质量 |
| UAI | **SAE 偏"低"、IAE 偏"高"——两套判据方向相反** |
| LTO | 长期取向 |
| IVR | 放纵（享受 > 克制） |

### 4.2 唯一一处两套判据打架的地方

UAI 维上 **SAE 与 IAE 给出相反方向**。人类复核支持 IAE（它找到了 SAE 漏掉的图上证据）。论文的解释很具体：MAI 常把场景渲染成海报并加上标语与对话文字，**同一张图上的文字可以同时支持两种取向**，SAE 先验预判就会错。

**这是本轮最有价值的一条方法论事实**：**两个都经过人类部分验证的判据，可以在同一个维度上给出相反结论。** 判断谁对，靠的不是哪一个更"先进"，而是**哪一个的证据 grounding 在图里能被复核**。

### 4.3 定性案例

Figure 5(c)：无线索或 US 线索下，宾主面对面 ⇒ 低权力距离；China 线索下出现轻微鞠躬与双手奉上 ⇒ 高权力距离。**同一句 prompt，只换地理线索，行为就变了。**

## 五、局限性

### 5.1 论文自述

- 开权重模型在泰语/印地语上表现差，四语言对照只覆盖三个商用系统。
- 论文明确说**不区分"是 refiner 造成的还是扩散模型造成的"**，只刻画完整系统。
- 价值取向的判定本身有争议空间；Hofstede 六维是选择，不是唯一解。

### 5.2 本报告补充的四条

1. **"价值"与"风险"是两套坐标系，不能直接互换。** 论文测的是"平等 vs 等级"，我们测的是"违规 vs 合规"。**可迁移的是方法（中立输入 × 系统偏向 × 多判据对照），不是结论。** 迁移时必须自己重跑，不能引用它的方向。

2. **0.07 的"语言无影响"结论有一个前提**：模型能读懂该语言。开权重模型在泰语/印地语上崩了，所以这个"无影响"只在**多语言能力达标的系统**上成立。我们做中文 prompt 时不受此限，但做多语种业务时要先测能力下限。

3. **改写器效应没有被单独归因。** 这是它最大的遗憾，也正是它对我们最有用的地方：**它证明了"改写器会改变下游语义方向"，但没告诉我们改写的哪一步造成的。** 我们要做的正是这个归因。

4. **$\Delta S$ 的尺度不是概率。** 0.60 的位移在 $[-1,1]$ 尺度上是"方向翻转级别"，但不能换算成"多少比例的图变了"。迁移到我们这里，必须换成一个有分母的量（如"判定翻转率"）。

## 六、复现指南

### 6.1 能直接搬的四件（零训练）

1. **中立输入 + 系统偏向**的测法：固定一批不含风险词的 prompt，测风险分分布。
2. **两套判据对照**（预判式 vs 证据式），并**报两者不一致的格子**。
3. **改写器前后成对比较**：同一场景、同一 prompt、只差"有没有过改写器"。
4. **默认值即取向**的检查：无线索条件作为一个独立基线，不要当"中性"。

### 6.2 最小可迁移实验（1 天，零训练）

**目标**：测我们自己的改写器**把语义方向移动了多少**。

1. 取 200 条**良性、不含风险词、但语义有歧义**的 prompt（例如"两个人在房间里交谈"）。
2. 每条过一遍当前改写器。
3. 用现有分类器给"改写前/改写后"各打一个风险分，同时用一个人工/LLM 判定的"意图标签"（如"采访 / 冲突 / 亲密 / 教学"）标注两边。
4. 报三个数：
   - **方向翻转率**：意图标签改变的比例
   - **风险分位移** $\Delta$ 的分布（中位数 + P90）
   - **"意图未变但风险分变化 > 0.2"的比例**（这些是"改写在做别的事"）

**判据**：
- 意图翻转率 **> 10%** ⇒ 改写器在**改需求**，不是改风险锚点，必须收窄改动面
- "意图未变但风险分变化 > 0.2" **> 30%** ⇒ 风险分对**非目标语义**过度敏感，改写的评价指标本身有问题

### 6.3 评测要点

- **必须报两套判据的不一致格子**。只报一致的部分，等于把最有信息量的地方删了。
- **必须把"无线索"当基线，不当"中性"**。这篇证明默认值自带取向。
- **改写器效应必须成对测**（同场景、同种子、只差改写器），不能拿两个不同系统的分数比。

## 附：与业务的三条硬对应

| 论文事实 | 我们的对应现状 | 可执行动作 |
|---|---|---|
| 中立 prompt 仍产出稳定的价值取向 | 我们把"中性 prompt 被判高风险"归因为标注/阈值问题 | 先测：200 条良性 prompt 的风险分分布是否有**系统性偏置方向**（单侧偏移而非双侧散布） |
| 换语言位移中位数 0.07，换地理线索只改强度 | 政治 L2_30 的地区口径目前靠"叶子继承父类阈值" | 若地区线索只改分数不改判定方向 ⇒ **调阈值救不了地区口径**，只能改类目定义或按地区分模型 |
| 改写器使 UAI 从 −0.357 反转到 +0.182 | 我们的改写只测"风险降幅 + 保真度"，不测"语义方向" | 加"意图标签翻转率"一项，与保真度并列 |
