## 一、背景与问题

### 动机

扩散模型会生成违规内容，所以有人做"机器遗忘"：把某个概念（裸露、暴力、某艺术家风格、某物体）从模型里抹掉，同时保住其它能力。现有三条路线各有硬伤：

| 路线 | 代表 | 硬伤 |
|---|---|---|
| **微调** | ESD、AC、SA、MACE、TRACE | 改的参数量大，且**取某一时间步的监督要跑完前面所有步**，优化代价与"实际改的模块"不匹配 |
| **模型编辑（免训练）** | RECE、ConceptPrune、SPEED | 依赖**神经元级定位**，而神经元是多义的（polysemantic），一个神经元编码多个概念 → 擦不准 |
| **推理时干预** | SLD、SAFREE、TraSCE、SAEUron | **可被绕过**（开源场景直接删掉外挂模块），且**每次都付推理开销** |

### 核心科学问题

这篇的真正问题不是"怎么擦"，而是两个更前置的问题：

- **C1**：SAE 的特征级干预很好用，但它是**外挂模块**（推理时操纵激活）。能不能把这种干预**内化进参数**？
- **C2**：概念表示**散布在多个 cross-attention block 上、且随去噪轨迹演化**。到底该改**哪一个 block**？改它的**监督信号**从哪来？

### 五条实证发现（这是全文最实用的部分）

作者先做了一轮系统实证，五条 Observation：

1. **神经元级定位不够**。ESD/UCE/ConceptPrune 能拿到不低的 FSR，但图像质量明显退化 → 粗定位伤到了目标概念之外的表示。
2. **推理时干预的代价被低估**。SDXL-Turbo 上实测额外推理开销：**SAFREE +14.4% / SAEUron +73.3% / TraSCE +125.8%**。按 A100 按需 $4/小时、原始时延 0.6848 s 折算，等于**每百万次生成多花 $110–$960**。而且这类干预会扰动中间表示、引入伪影。
3. **大规模微调低效**。只微调一个 cross-attention block 但**不跑完整去噪轨迹**，单次迭代训练时间降到原来的 **53.6%** → 说明相当一部分算力花在"轨迹依赖"上，而不是花在真正被更新的参数上。
4. **只看输出不够**。分类器判"概念还在不在"与人的感知会脱节：分类器分相近的图，人看差别很大。**需要内部表示层面的补充证据。**
5. **跨架构不通用**。多数方法是为 SD v1.4/1.5 设计的；搬到 SDXL-Turbo（1–4 步）直接退化（ESD 尤其明显）——**逐时间步干预的方法在少步采样下失效**。

### 为什么这篇对我们重要

我们的主线是"**不改生成模型、输入侧热更新改写**"。ConceptACP 是这条主线的**镜像范式**：改权重、不改输入。两者不是替代关系，边界很清楚：

- **输入侧改写**：能立刻上线、可回滚、可按 policy 热更新、不损模型能力；但**挡不住"改写后仍然违规"的残余**，也挡不住**直接调 API 绕过改写层**的场景。
- **权重侧擦除**：一次成本、零推理开销、**无法被 prompt 层绕过**；但**粗粒度不可回滚**（擦多了回不来）、**对"边界概念"天然不准**（因为概念表示纠缠）、且**改一次要重训/重部署**。

**结论：这两条线是纵深防御的两层，不是二选一。** 而 ConceptACP 的价值在于把权重侧的"该改哪里"从一个玄学问题变成了可测量的问题——这恰好也是我们判断"哪些概念适合擦、哪些只能改写"的依据。

## 二、核心方法

### （1）总体：SAE 不进推理链路，只用来造监督

关键设计选择：**不在推理时挂 SAE**。SAE 只承担一件事——**生成"概念已被抑制"的目标输出**，把这个目标输出当作微调的监督信号。

流程三段：

```
[特征定位] 用预训练 SAE 池 + 相关度打分 → 找出"最相关的一个 cross-attention block"及其特征集
     ↓
[造监督]   把这些特征的激活乘一个负的抑制因子 → 解码 → 得到 block 的残差更新
           → 与原 block 输入相加 → "概念已被擦除"的目标输出
     ↓
[局部微调] 只训这一个 block，用 (原输入, 目标输出) 对做监督；单次前向缓存激活，不重复去噪
```

### （2）特征定位：相关度打分 + 相对阈值

对 block $b$ 里的特征 $f$，在**含目标概念的数据集 $D_c$** 与**不含的数据集 $D_{\bar c}$** 上分别算平均激活，相关度定义为归一化的激活差：

$$r_{b,f} = \frac{\bar a_{b,f}(D_c) - \bar a_{b,f}(D_{\bar c})}{\sum_{f'} \bar a_{b,f'}(D_c)}$$

- 取**相关度最高特征所在的 block** 作为目标 block；
- 用一个**相对阈值** $\tau \cdot \max_f r_{b,f}$ 过滤弱相关特征（因为一个概念常分布在多个特征上）；
- **自动搜索**跨 SAE 池，不预先指定 block（区别于 SAEUron 为每个概念预设 block）。

**一个很关键的实证**：在 SDXL-Turbo 上，**抑制 down.2.1 的 feature #4913 就能去掉裸露**；但 Church 概念**抑制 top-5 最激活特征中的任何一个都不够**。也就是说"概念-特征"的对应关系**因概念而异**，单特征可解的概念与多特征纠缠的概念必须区别对待。**这直接预示了"边界概念更难擦"的根因。**

### （3）抑制强度：不是超参，是概念相关的

对最高分特征施加抑制因子 $\gamma$，其余特征按相对分数成比例抑制。$\gamma$ 太小擦不干净、太大会把无关内容一起毁掉或误激活别的概念。作者明确说 $\gamma$ **按经验设定、不同概念最优值不同**，并特别提醒：**全局风格类概念（如 VanGogh）不要用过大 $\gamma$**，因为风格影响整张图。

### （4）为什么"改一个 block"能成立

SDXL-Turbo 的 U-Net 里四个 cross-attention block 的分工（沿用 Surkov 等人的分析）：

| block | 负责 |
|---|---|
| `down.2.1` | **全局构图** |
| `mid.0` | 低层语义 |
| `up.0.0` | 结构细节 |
| `up.0.1` | **颜色与风格** |

所以在 `down.2.1` 上做擦除，动的是"这幅图里有没有这个东西"这个层级，而不是细节或配色。**这是"改得准"的结构性解释。**

## 三、技术细节

| 项 | 设置 |
|---|---|
| 主实验骨干 | **SDXL-Turbo**（1 步 = T1，4 步 = T4） |
| 迁移验证骨干 | SDXL（30 步）· SD v1.4（50 步） |
| 评测基准 | **EvalIGMU**，四个概念：Nudity / VanGogh / Church / Parachute |
| 指标 | **FSR**（forgetting success rate，越高越擦干净）· **CLIP Acc**（目标概念分类准确率，越低越擦干净）· **FID** |
| 生成量 | 每个 prompt 生成 5 张（Nudity/VanGogh 各 250 prompt、Church/Parachute 各 300 prompt → 1,250 / 1,500 张） |
| 微调数据 | ChatGPT 合成的每概念 50 条 prompt |
| 效率 | 单 block 局部微调，训练成本比"全轨迹"做法降 **46.4%** |
| 新增内部指标 | **FO Score**（Feature Overlap，前后 top 特征重叠）+ **FACS**（Feature Activation Correlation） |
| 对抗鲁棒性 | UnlearnDiffAtk 生成对抗 prompt 测 ASR |

**内部指标的意义**：FO Score 量"擦除前后最激活特征变了多少"，FACS 量"目标特征与无关特征的相关性怎么变"。**它把"擦得准不准"从只能看输出，扩展到能看内部表示** —— 这正好补上 Observation 4 的缺口。

## 四、实验与结果

### 4.1 主表（SDXL-Turbo，四概念平均）

| 方法 | T1 FSR↑ | T1 CLIP Acc↓ | T1 FID↓ | T4 FSR↑ | T4 CLIP Acc↓ | T4 FID↓ |
|---|---|---|---|---|---|---|
| SDXL-Turbo（未擦） | 17.80 | 93.72 | – | 5.52 | 95.08 | – |
| ESD | 17.20 | 93.58 | 0.61 | 28.16 | 87.18 | 37.53 |
| UCE | 41.48 | 79.92 | 21.16 | 31.70 | 83.92 | 25.01 |
| ConceptPrune | 38.78 | 70.36 | 27.34 | 45.02 | 62.00 | 37.41 |
| SAEUron | 43.68 | 79.00 | 27.85 | 22.86 | 70.68 | 27.79 |
| **ConceptACP** | **80.02** | **38.26** | 29.84 | **69.12** | **49.52** | 30.52 |

论文口径：T1 相比"最强基线" **FSR +36.34**、CLIP Acc −32.10；T4 **FSR +24.10**、CLIP Acc −12.48。

**逐概念看更有信息量**（T1 FSR）：Nudity **94.16** / VanGogh **95.92** / Church **84.40** / Parachute **45.60**。

→ **Parachute 明显最差**。作者的解释很实在：多数样本的降落伞被去掉了，但**残留碎片仍在**。这与前面的"多特征纠缠"呼应——**物体类概念（Church/Parachute）比语义类概念（Nudity）更难擦干净**，因为它们没有单一的高相关特征。

### 4.2 跨骨干迁移

| 骨干 | 方法 | 平均 FSR↑ | 平均 FID↓ |
|---|---|---|---|
| SDXL（30 步） | ConceptPrune | 77.90 | 197.32 |
| SDXL | **ConceptACP** | **89.20** | **43.35** |
| SD v1.4（50 步） | SAEUron | 97.40 | 266.78 |
| SD v1.4 | **ConceptACP** | 95.40 | 显著更低（论文表内逐项给出） |

**这里藏着全文最容易被忽略的一点**：SDXL 上 ConceptPrune 的 FSR 有 77.90 但 **FID 197.32**；SD v1.4 上 SAEUron FSR 97.40 但 **FID 266.78**。**高 FSR 可以靠把图彻底搞坏来换。** ConceptACP 在 SDXL 上是 FSR 89.20 + FID 43.35 —— **同时拿下两者，这才是真实收益**。判断擦除方法时，**FSR 单独看没有意义**。

同一逻辑也适用于 SDXL-Turbo T1：ESD 在 T4 的 Parachute 上拿到 FSR 82.80，但作者人工检查发现输出"密集、抽象、卡通化"，语义连贯性远不如 ConceptACP。**FSR 高 ≠ 擦得好。**

### 4.3 效率

- 训练成本比"全轨迹微调"降 **46.4%**；
- 单 block 但不跑全轨迹 → 单次迭代时间 **53.6%**；
- 推理开销 **0**（对比 SAFREE +14.4% / SAEUron +73.3% / TraSCE +125.8%）。

这条是权重侧路线唯一无争议的优势：**一次性成本，零推理开销，且不怕外挂被删。**

### 4.4 对抗鲁棒性（这是本文最该打问号的地方）

在 UnlearnDiffAtk 生成的对抗 prompt 上，ConceptACP 平均 ASR **第二好，仅次于 ConceptPrune**。作者自己也承认：这类攻击**跨骨干迁移性有限**，而且 UCE 在良性条件下擦除弱、在对抗条件下反而拿到 1 个最优 + 2 个次优，SAEUron 则相反 —— **评测的不一致说明这类对抗基准本身不可靠**，且**缺少 SDXL-Turbo 专用的对抗遗忘基准**。

## 五、局限性

1. **只在 U-Net 架构上验证**（SDXL-Turbo / SDXL / SD v1.4）。**MMDiT（SD3、FLUX）没有 cross-attention block 这个概念**，整套"block 级定位"需要重新定义。这是它对我们最直接的适用性边界。
2. **依赖预训练 SAE 池**。论文用公开 SAE，但目标概念若不在这些 SAE 的特征覆盖内，定位就失效。扩充 SAE 池本身有成本。
3. **$\gamma$ 手动设定、概念相关**。作者明确说"经验确定、不同概念不同"，这意味着**批量擦除多个概念时要做逐概念调参**，工程上不轻。
4. **多概念密集语义区会冲突**：与上周 SELECT 的 SEC 结论同源——一个待擦目标可能正好是另一个目标的"兄弟概念"，此时只能退化。
5. **改完不可回滚、不可按 policy 热更新**。policy 变了就得重擦。**这是它相对输入侧改写的结构性劣势。**
6. **FSR 的定义依赖分类器**，而 Observation 4 自己证明了分类器与人类感知脱节 —— 主指标与自己的方法论批评之间有一处张力。
7. **对抗鲁棒性证据弱**：只有 ASR 一项，且基准被作者自己指出跨骨干迁移有限。

## 六、复现指南

### 6.1 复现要点

```
1. SAE 池：公开的 SDXL-Turbo cross-attention block SAE（down.2.1 / mid.0 / up.0.0 / up.0.1）
2. 定位：r(b,f) = 归一化(含概念集平均激活 - 不含概念集平均激活)
        取最高分 block；特征用相对阈值 tau * max 过滤
3. 造监督：目标特征激活 × 负因子 gamma → SAE 解码 → 残差 → 加回原 block 输入 = 目标输出
4. 微调：只训该 block；单次前向缓存全部时间步激活，避免重复去噪
5. 评测：EvalIGMU 四概念，FSR + CLIP Acc + FID 三者必须同时报
```

### 6.2 复现风险点

- **必须同时报 FID**。只报 FSR 的擦除结果不可信（本文自己给出了 FID 197 / 266 的反例）。
- $\gamma$ 需逐概念调；全局风格概念（VanGogh）要用小 $\gamma$。
- SDXL-Turbo 只有 1–4 步，"逐时间步干预"类基线（ESD）在这个设置下天然吃亏，**跨方法比较要注意这个混杂**。
- EvalIGMU 每 prompt 生成 5 张，随机种子要固定。

### 6.3 对我们最有用的三件事

**（1）把"概念可擦性"变成可测量的量——用来决定"哪些概念走改写、哪些走擦除"**

ConceptACP 给了一个判据：**一个概念若集中在单一高相关特征上（如 Nudity 的 #4913），权重侧可擦；若分散在多个特征上（如 Church 需要抑制多个特征），权重侧擦不干净。**

**可落地动作**：对我们 PORN / VULG 两个一级类，分别抽 100 条训练 prompt，用一个现成的 SAE（或直接看 cross-attention 图）统计"概念相关特征数"。判据：
- 特征集中（≤3 个主导特征）→ **优先走权重侧或输入侧双保险**；
- 特征分散（>10 个）→ **只能靠输入侧改写**，别指望擦除。

这个结论能直接回答一个我们一直悬着的问题：**为什么 PORN 明确类擦除效果尚可，而 VULG-HINT-EDGE 反复是短板。** 大概率不是标注问题，是**后者的概念表示根本没有收窄**。

**（2）"边界概念"的困难是结构性的，不是数据不够**

Parachute（物体类）T1 FSR 只有 45.60，Church 84.40，Nudity 94.16。同一次训练、同一套超参，**差异完全来自概念的表示结构**。映射到我们的标签体系：**语义收窄的概念（明确性行为）好处理；语义弥散的概念（暗示、擦边、隐晦暴力）天然难。** 这与上周 SELECT 的"因果弥散度"结论是**两个独立证据指向同一件事**。

**（3）"零推理开销"这件事，只有权重侧能给**

我们输入侧改写的成本结构是**每次请求都付一次改写前向**。ConceptACP 的对照提醒我们：**改写层的时延预算必须被显式管理**。若改写模型是 7B 级别、每次请求多 300 ms，在 QPS 高的场景下，这个成本会逼着我们去问"哪些概念值得用常年成本换一次性成本"。

**建议的折中方案（对我们最现实）**：
- **高频、语义收窄、且政策稳定的概念**（如明确裸露）→ 权重侧擦除一次，省掉每次改写的开销；
- **低频、语义弥散、且政策常变的概念**（政治 L2_30 各层级、擦边暗示）→ 只能输入侧热更新，因为**policy 一变，权重侧就得重擦**；
- **两层叠加**：擦除把"底座风险"压低，改写处理"残余与边界"。**改写层不该承担它挡不住的那部分。**

*论文口径，不做数字外推。FSR / CLIP Acc / FID 均为 EvalIGMU 基准下的值。CLIP Acc 在本文语境中是"目标概念分类准确率"，越低表示擦除越彻底，不是通用能力指标。跨骨干的 FID 与 SDXL-Turbo 的 FID 不可直接比较。*
