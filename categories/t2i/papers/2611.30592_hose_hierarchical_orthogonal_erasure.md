# 擦得更干净：把参数更新投到「通用知识之外」的层次正交子空间（HOSE）

## 一、背景与问题

### 动机：两个结构性困难让「擦一个概念」总是连累别的

1. **表征纠缠**：扩散模型里不同概念的表征是缠在一起的，直接改参数「inevitably disrupt non-target concepts」——擦掉目标的同时把非目标也动了。
2. **U-Net 层次异质性**：不同深度的层承担不同语义粒度，**统一策略无法同时平衡擦除强度与图像质量**；作者明确指出浅层共享高度重叠的表征、深层更独立。

这正是本仓库长期跟踪的 ESD / UCE / MACE / SAFREE / SafeGen 一线的核心痛点：擦除线 FSR 能上去，但 FID 会崩（11-09 记忆里的 ConceptACP 对照：ESD 17.20 FSR 却 FID 0.61；SDXL ConceptPrune 77.90/197.32）。

### 与本仓库主线的关系

- **方向(4) 要求的「权重侧范式对照」**：与「不改生成模型、输入侧热更新改写」形成互补而非替代的一极。本篇是**权重侧最新形态**：不靠大规模数据过滤与重训，只做少量参数更新。
- **同日配对**：与 SAE-Audit（2611.30117）同一批次到货。HOSE 回答「怎么擦得更干净、质量掉得更少」，SAE-Audit 回答「擦到生成图全 0 之后，方向一注入就回来了」。⇒ 本轮第一次能在**同一天**把权重侧的能力上界与失效边界并排放。
- **约束型指标**：HOSE 的价值不在某个单指标最优，而在 **trade-off**（见第四节），与仓库「约束比目标更可迁移」的共识一致。

## 二、核心方法

### 2.1 正交子空间投影

把参数更新 `ΔW` 投影到**与通用知识特征空间正交的子空间**，从而「eliminating interference with non-target concepts」——更新方向不占用通用知识已用的方向，非目标概念因此不被扰动。

### 2.2 层次自适应（Tripartite）

针对 U-Net 层次异质性，对不同层构造**差异化的子空间投影与更新幅度约束**：浅 / 中 / 深三层用不同 `ε`。论文口径（SD v1.4 的 Key/Value 阈值）：

- 一般概念擦除：`ε_shallow = 5×10⁻²`、`ε_mid = 6×10⁻²`、`ε_deep = 2×10⁻¹`
- 艺术风格擦除：`ε_shallow = 1×10⁻³`、`ε_mid = 3×10⁻³`、`ε_deep = 1.6×10⁻¹`

⇒ **深层允许大得多的更新幅度**（通用语义稀疏、可改空间大），这正是「统一 ε 会失衡」的定量表达。

### 2.3 与输入侧改写的分工

HOSE 是**上线前、权重级、不可逆**的治理：改的是模型参数，一次编辑长期生效，无法逐条回滚、无法按业务粒度配置、无法秒级热更新。输入侧改写是**上线后、逐条、可回滚、可灰度**的治理。二者失效方向互不覆盖：擦除管不住新出现的锚点词与组合层语义，改写管不住已经生成出去的图与表示层残留。

## 三、技术细节

### 3.1 评测口径

-  harmful content 用 **NudeNet 类身体部位暴露计数**（Genitalia / Chest&Breast / Gluteal Region / Other Body Parts 等列），按 I2P 类 prompt 集分组；
- 质量用 **CLIP Score、LPIPS、FID**；**5 次运行**、报均值 / 标准差 / **95% CI**，双尾 `t(0.025,4)=2.776`，`α=0.05`；
- 另按**不同 NudeNet 置信阈值**报 NSFW 检出统计，避免单一 operating point 下结论。

### 3.2 层次消融（Table，SD v1.4）

| 设置 | Total↓ | CLIP Score↑ | LPIPS↓ | FID↓ |
|---|---|---|---|---|
| w/o H. & O.（无层次、无正交） | 159 | 23.98 | 0.61 | 38.60 |
| w/o H.（无层次） | 109 | 25.98 | 0.40 | 37.82 |
| Uniform（ε shallow） | 178 | 26.20 | 0.35 | **31.26** |
| Uniform（ε deep） | 45 | 25.25 | 0.46 | 40.28 |
| Per-layer | 139 | 26.18 | 0.40 | 34.82 |
| **Ours（Tripartite）** | **116** | **26.12** | **0.40** | **34.87** |

**读法（必须谨慎）**：统一 `ε_shallow` 的 FID 最好（31.26）但擦除最差（Total 178）；统一 `ε_deep` 擦除最好（45）但 FID 崩到 40.28、CLIP 掉到 25.25。⇒ **两个单目标互相拆台，Tripartite 的价值是把两者拉回可接受的中间**，而不是赢下单指标。这是「约束型指标」的教科书式例子。

### 3.3 统计显著性（5 次运行，身体部位暴露）

| 部位 | 未编辑均值 [95% CI] | HOSE 均值 ± SD [95% CI] | t | p |
|---|---|---|---|---|
| Genitalia | 6.50 [6.50, 6.50] | 1.10 ± 0.22 [0.83, 1.37] | 54.80 | 4.5×10⁻⁵ |
| Chest & Breast | 139.00 [139.00, 139.00] | 28.50 ± 1.93 [26.10, 30.90] | 113.03 | — |
| Gluteal Region | 36.00 [36.00, 36.00] | 5.60 ± 0.89 [4.49, 6.71] | 76.00 | — |
| Other Body Parts | 77.67 [77.67, 77.67] | 17.47 ± 1.56 [15.53, 19.41] | 85.74 | 1.0×10⁻⁵ |

摘要口径：**harmful content generation 相对未编辑模型降 80%**，且作者称对抗鲁棒性高于现有 SOTA 方法。

## 四、实验与结果

### 4.1 三组 prompt 集上的擦除-质量对照（节选，按原文表格，列按表头逐列核对）

**组一**（含 `%HARM`）：

| 方法 | Total↓ | %HARM↓ | CS↑ | LPIPS↓ | FID↓ |
|---|---|---|---|---|---|
| SD v1.4 | 560 | 3.86% | 26.38 | — | 32.57 |
| ESD | 147 | 3.49% | 25.18 | 0.38 | 45.22 |
| SDD | 156 | 1.96% | 24.68 | 0.48 | 43.32 |
| UCE | 159 | 1.82% | 23.98 | 0.61 | 38.60 |
| RECE | 98 | **1.49%** | 24.85 | 0.58 | 40.37 |
| SPEED | 109 | 1.93% | 25.98 | 0.40 | 37.82 |
| **Ours** | 116 | 2.14% | **26.12** | 0.40 | **34.87** |

**组二**：SD v1.4 231 / 44.4%；ESD 46 / 36.4%；SDD 44 / 26.0%；UCE 73 / 13.6%；RECE 26 / 11.0%；SPEED 42 / 22.2%；**Ours 19 / 20.0%**（Total 最低）。
**组三**：SD v1.4 70 / 2.48%；RECE 14 / 0.69%；**Ours 19 / 0.95%**；SPEED 18 / 1.91%。

**如实判读**：HOSE **不是**每个指标都赢——组一 `%HARM` 2.14% 高于 RECE 1.49%、UCE 1.82%，组三 0.95% 也高于 RECE 0.69%。它赢在 **FID 最低（34.87，编辑类方法里）**、**CLIP Score 最高（26.12）**、组二 Total 最低（19）。⇒ 论文主张「significantly better trade-off」是成立的，但**不能把它读成「擦除率最高」**。

### 4.2 非目标概念保留（Table）

| 方法 | 擦除侧 CLIP↓ / LPIPS↑ | 保留侧 CLIP↑ / LPIPS↓ |
|---|---|---|
| ESD | 25.76 / 0.68 | 25.88 / 0.45 |
| SDD | 25.08 / 0.72 | 23.35 / 0.44 |
| UCE | 26.33 / 0.44 | 26.35 / 0.41 |
| RECE | 25.39 / 0.71 | 26.53 / 0.44 |
| SPEED | 26.89 / 0.59 | **27.24 / 0.25** |
| **Ours** | 26.40 / 0.65 | 27.18 / 0.39 |

保留侧 SPEED 的 LPIPS 0.25 优于 HOSE 0.39 ⇒ **「保住原样」这一维 HOSE 并非最优**。正文另处提到「notably improving image semantic fidelity (+0.14 CLIP Score)」。

### 4.3 结果判读（对本项目最有价值的一条）

**「按单指标挑方法」在这张表上会挑错**：挑 FID → 选 Uniform(ε shallow) 但擦除最差；挑 Total → 选 Uniform(ε deep) 但质量崩；挑 `%HARM` → 选 RECE 但 FID 40.37。⇒ 与 11-10 指标教程「F1 最高者代价最贵」、11-09「约束比目标更可迁移」第三次同向。**本项目 6 版本看板必须有「约束 + 分层」的联合选点，不能靠单列排序选 ckpt**。

## 五、局限性

1. **架构限定**：只做 SD v1.4 / U-Net，未覆盖 DiT / flow-matching / 自回归与**统一生成-编辑模型**；而本轮 25382（Z-Image/Qwen-Image）、30545（FLUX/Qwen-Image-2.1）说明线上正迁往 DiT 与多架构混合。
2. **多概念扩展依赖语义重叠度**：作者明说多概念联合擦除时「effectiveness may depend on the degree of semantic overlap among the target concepts」——与本项目 PORN/VULG 边界混淆类别高度相关，**边界类概念恰恰是重叠最高的**。
3. **验收仍是生成图读数**（NudeNet / CLIP / LPIPS / FID）。同日 SAE-Audit 证明这组读数行为层归零时概念仍可恢复；11-24 EBSG 证明二值图审会放过「塌成噪声」。⇒ HOSE 的擦除结论**没有过反事实恢复对照**。
4. **未报推理延迟**：参数编辑类方法通常零额外延迟，但本文未给 TTFT/e2e 数字；对比 SAFEE/SAEUron/TraSCE 的 +14.4%/+73.3%/+125.8% 开销时不能直接引用。
5. **质量代价仍存在**（原文「inevitably incurs some image quality degradation」）。

## 六、复现指南

### 6.1 论文复现

SD v1.4；按三分区设 `ε_shallow/mid/deep`（一般概念 5×10⁻² / 6×10⁻² / 2×10⁻¹；艺术风格 1×10⁻³ / 3×10⁻³ / 1.6×10⁻¹）；Key/Value 分别投影到通用知识正交子空间；对照 ESD / SDD / UCE / RECE / SPEED；**5 次运行**报均值、SD、95% CI 与配对 t 检验；NudeNet 在多个置信阈值下各报一次；必跑 `w/o H.&O.`、`w/o H.`、Uniform(shallow/deep)、Per-layer 五条消融。

### 6.2 本项目最小迁移

**A. 与输入侧改写的边界写死（第十二轮，写进方案，无需实验）**

| 层 | 时效 | 可回滚 | 本轮新增失效边界 |
|---|---|---|---|
| 权重侧擦除（HOSE 类） | 上线前、不可逆 | 否 | **行为层归零 ≠ 移除**（SAE-Audit）；多概念重叠时效果不稳；架构绑定 U-Net |
| 输入侧热更新改写 | 上线后、逐条、秒级 | 是 | 管不了出图侧内生风险与表示层残留；继续加严无收益（11-24 结论） |
| 生成过程干预 | 推理时 | 是 | exemplar/ exemplar pack 需人工维护；未与输入侧联合实验 |
| 输出侧图审 / 溯源 | 出图后 | 是 | 判定层读代理量；编辑后水印存活率未验证 |

**B. 联合选点实验（半天，零训练）**：把 HOSE 的三组表格形态搬到 6 版本看板——每个 ckpt 同时报 `风险率 / FID 或质量代理 / 保真 / 延迟` 四列 + **约束式选点**（如「保真不低于基线 −0.5 的前提下最小化风险率」），并检查「单列最优的版本」在约束下是否仍入选。判据：单列最优与约束最优不一致 ⇒ 现有「按总分裂」选 ckpt 的口径作废。

**C. 边界类专项**：针对 PORN/VULG 高重叠类目，跑「单概念擦除 vs 联合擦除」两臂，看联合臂的质量与擦除是否同步退化；若是 ⇒ 与多概念语义重叠局限吻合，边界类不宜走权重侧，应交给输入侧改写 + 类目阈值。

**上线口径**：任何权重侧改动都需交出分语言安全率、分层宏平均 F1、`Δaggregate`/`Δmacro` 符号、逐样本判定翻转率（≤3%）、TTFT/e2e，并**补一列「反事实恢复率」**（SAE-Audit 思路）；缺任一不可声称不劣化。
