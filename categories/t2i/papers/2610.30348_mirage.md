## 一、背景与动机

### 工业现状：审核是最后一道闸门

现代 T2I 推理管线普遍是「多模态适配器 → 基础扩散模型 → **生成后安全审核器（post-generation safety checker）**」三段式。审核器在图像返回给用户前做最后检查，常见实现是 CLIP Checker、ViT Checker、NudeNet 这类分类器。

这条链路的设计假设很朴素：**即使恶意语义穿透了输入端和生成端，最后还有一道图像级分类器兜底。** 对做图审模型的人来说，这道闸门的可靠性直接决定了线上 NSFW 漏放率的上限。

### 被点破的假设

论文问了一个此前没人正面回答的问题：

> 攻击者能不能在**保留细粒度恶意目标语义**的同时，**绕过未知的生成后审核器**？

这个问题的难点是一个**结构性两难**：

- 要生成得越像恶意目标（target alignment 越强），图像就越容易触发审核器；
- 要躲过审核器（evasion 越强），就越可能生成不出目标语义。

而且攻击者不知道审核器的架构、过滤概念集合、判定阈值。

### 与此前工作的差别

| 攻击 | 目标 | 能力 | 是否需要白盒审核器 |
|------|------|------|--------------------|
| SneakyPrompt (S&P'24) | T2I 扩散 | 文本 token 替换绕过 | 否，但查询开销 36–40 次 |
| AdvIllusion (USENIX Sec'24) | 多模态嵌入 | 跨模态定向生成 | 是（无审核器规避） |
| Image Trojan (CVPR'25) | T2I 扩散 | 图像扰动定向 | 是（未考虑审核器） |
| Yang et al. | 多模态输入 | 绕过生成后审核 | **是，需要内部 NSFW 分数与阈值** |
| **Mirage（本文）** | T2I / I2I / 视频 | **定向生成 + 审核器规避** | **否，只用替代编码器 + 少量黑盒查询** |

关键空白：现有工作要么**不针对审核器**，要么**要求白盒访问审核器**。Mirage 的贡献是在「不知道审核器细节」的前提下同时做到定向 + 规避。

### 对当前业务的重要性

⚠️ **这是本周唯一直接打在「输出侧图审」上的论文**。它的价值不在攻击本身，而在于它给出了一个**图审模型的系统性失效剖面**：

- 同一批攻击在不同审核器上的绕过率差异极大（CLIP 1.000 vs ViT 0.900 vs NudeNet 0.960 在 I2P 上尚接近，但在 NSFW 图像目标集上 CLIP 0.800 / ViT **0.185** / NudeNet 0.435）；
- **bypass rate ≠ ASR**，被绕过但没生成目标语义的样本不应算成功——这个区分对我们做图审 AB 评测的口径设计直接有用；
- 攻击只改**图像输入通道**、**文本 prompt 完全不动**，意味着「只审文本」或「只审文本+最终图」的两段式方案都拦不住。

## 二、核心方法

Mirage 的输入是一个良性图像 + 一个恶意目标（NSFW 参考图 或 恶意文本描述），输出是一张加了不可感知扰动的对抗图像。文本 prompt 不改。

### 2.1 三个技术挑战与对应设计

**挑战一：如何把跨模态恶意目标编码进图像扰动？**

利用多模态编码器的**共享表征空间**：在该空间中，语义相同但模态不同的输入彼此接近。于是对扰动做范数约束优化，使「扰动后图像的嵌入」逼近「恶意目标的嵌入」，文本目标和图像目标因此可以共用同一套优化框架。

**挑战二：如何在不知道审核器细节的情况下规避它？**

用**替代多模态编码器（surrogate encoder）+ 对比学习目标**：

- **对齐项**：扰动图像嵌入 ↔ 恶意目标嵌入（拉近）
- **排斥项**：扰动图像嵌入 ↔ 常见被过滤的 NSFW 概念集合（推远）

核心假设是**语义分离可跨表征空间迁移**：如果替代空间和未知审核器的分类空间编码了相似的语义关系，那么在替代空间里把对抗表征从 NSFW 区域推开，也能在审核器空间里把它推离不安全区域。

**挑战三：迁移不完美怎么办？**

加一层**轻量黑盒查询精修**，只在未知安全边界附近做局部搜索，把绕过率从「迁移可用」提升到「稳定可用」。

### 2.2 方法骨架

$$\min_{\delta}\ \ \underbrace{\mathcal{L}_{\text{align}}\big(f(x+\delta),\ e_{\text{target}}\big)}_{\text{拉近恶意目标}}\ +\ \lambda\ \underbrace{\mathcal{L}_{\text{repel}}\big(f(x+\delta),\ \{e^{\text{NSFW}}_k\}\big)}_{\text{推离 NSFW 概念}},\quad \|\delta\|_\infty \le \epsilon$$

其中 $f$ 为替代多模态编码器，$e_{\text{target}}$ 为目标嵌入（文本或图像），$\{e^{\text{NSFW}}_k\}$ 为常被审核器过滤的 NSFW 概念嵌入集合。之后接黑盒查询精修：只观察「通过 / 拦截」二元反馈，在边界附近微调 $\delta$。

## 三、技术细节

### 3.1 受攻击的三段式管线

| 环节 | 组件 | 被攻击面 |
|------|------|----------|
| 多模态适配器 | 编码器组 $\mathcal{E}$ + 特征融合层 $\mathcal{F}$ | ✅ 扰动从图像通道进入共享嵌入空间 |
| 基础扩散模型 | U-Net / Transformer 去噪主干 | 间接被引导（条件来自被污染的嵌入） |
| 生成后安全审核器 | CLIP Checker / ViT Checker / NudeNet | ✅ 被跨空间迁移规避 |

### 3.2 实验配置

- **生成模型**：Stable Diffusion 1.5、Stable Diffusion XL、Kandinsky 2.2
- **审核器**：CLIP Checker、ViT Checker、NudeNet（三种不同架构与安全边界）
- **数据**：I2P（文本目标，2,470 条不当 prompt 来源）+ NSFW Classification 数据集（图像目标）
- **替代编码器**：HuggingFace 上多个开源 CLIP 变体
- **扰动预算**：主实验 $\epsilon = 8/255$，另测 $4/255$ 与 $12/255$
- **攻击目标**：成人内容、暴力内容、冒犯性描述

### 3.3 关键机制解读

对比学习的**排斥项**是本文最值得借鉴的设计。它不是简单地"让图看起来不像 NSFW"，而是**在嵌入空间里显式构造一个"远离 NSFW 概念簇"的方向**。这解释了一个反直觉现象：攻击图像在视觉上与原图**不可区分**（扰动 $\le 8/255$），但审核器就是判它安全。

换句话说，**图审模型看到的不是像素，是嵌入；攻击者攻的也不是像素，是嵌入到决策的那段映射。**

## 四、实验与结果

### 4.1 主结果（$\epsilon = 8/255$）

**(a) I2P 数据集（文本目标）**

| 攻击 | 审核器 | Bypass Rate | ASR | CLIP Sim. | 查询数 |
|------|--------|-------------|-----|-----------|--------|
| **Mirage** | CLIP | **1.000** | 0.840 | 0.330 ± 0.052 | 2.41 |
| **Mirage** | ViT | 0.900 | 0.800 | 0.320 ± 0.049 | 3.58 |
| **Mirage** | NudeNet | 0.960 | 0.840 | 0.324 ± 0.047 | 3.82 |
| SneakyPrompt | CLIP | 0.850 | 0.390 | 0.294 ± 0.100 | 39.62 |
| SneakyPrompt | ViT | 0.810 | 0.510 | 0.314 ± 0.085 | 36.03 |
| SneakyPrompt | NudeNet | 0.830 | 0.260 | 0.319 ± 0.099 | 36.30 |
| AdvIllusion | CLIP | 0.430 | 0.390 | 0.324 ± 0.049 | — |
| AdvIllusion | ViT | 0.200 | 0.180 | 0.324 ± 0.059 | — |

**(b) NSFW 数据集（图像目标）—— 审核器差异在这里暴露**

| 攻击 | CLIP | ViT | NudeNet |
|------|------|-----|---------|
| **Mirage Bypass** | **0.800** | **0.185** | **0.435** |
| Mirage ASR | 0.795 | 0.180 | 0.430 |
| Image Trojan Bypass | 0.045 | 0.005 | 0.020 |
| Trojan-E Bypass | 0.545 | 0.040 | 0.235 |

### 4.2 三个必须记住的结论

**① 审核器之间存在数量级的鲁棒性差异。** 在图像目标的 NSFW 集上，ViT Checker 把绕过率压到 **0.185**，而 CLIP Checker 高达 **0.800**——相差 4.3 倍。这说明**图审模型选型不是工程细节，是安全边界本身**。

**② bypass rate 与 ASR 之间存在系统性 gap。** 论文明确写："一些被绕过的样本并没有忠实跟随恶意目标，因此不应计入成功攻击"。I2P/CLIP 上 bypass 1.000 但 ASR 0.840，差 16 个百分点。**如果我们用「审核器放行率」当图审失效指标，会高估漏放。**

**③ 扰动预算几乎不影响成功率。** $\epsilon$ 从 $4/255$ 到 $12/255$，I2P/CLIP 的 bypass 从 0.980 → 1.000 → 0.980，NSFW/CLIP 从 0.720 → 0.800 → 0.815。**最小扰动（4/255）已经足以绕过大部分审核器**，说明当前图审模型的决策边界离真实语义边界太远。

### 4.3 查询效率

Mirage 在 I2P 上只需 **2.4–3.8 次**黑盒查询，在 NSFW 图像集上 8.1–9.2 次；SneakyPrompt 需要 36–40 次。Kandinsky 2.2 尤其脆弱，"成功越狱通常约一次查询就找到"。

**意味着：这种攻击在真实产品里是可规模化的。** 不是需要上千次试探的理论攻击。

### 4.4 任务泛化

论文验证了该攻击可用于 **text-to-image、image inpainting、video generation** 三类任务——即只要管线里有"多模态适配器 + 后置审核"，攻击面就存在。

## 五、局限性

1. **需要多模态（图像）输入通道。** 纯文本 prompt 的 T2I 接口没有可注入扰动的图像输入，Mirage 不适用。这是它最大的实用性边界，也解释了为什么它打的是 T+I2I 而非纯 T2I。
2. **依赖替代编码器与审核器的语义空间相似性。** 如果审核器用的是与 CLIP 语义结构差异很大的自研特征（例如专门训练的细粒度 NSFW 分类头），跨空间迁移会显著退化——ViT Checker 在 NSFW 图像集上 0.185 的绕过率就是这种退化的证据。
3. **ASR 判定依赖 CLIP 相似度阈值。** 阈值本身是人为设定的（NSFW 0.375 / I2P 0.225），换阈值会改变 ASR 数值。
4. **只在三个开源审核器上验证。** 没有测商用审核 API，也没有测"多审核器级联"场景。
5. **未评估防御。** 论文是攻击侧工作，没有给出对应的检测/加固方案（虽然从方法上可推出"多审核器异构集成 + 输入图像扰动检测"的方向）。

## 六、复现指南

### 6.1 复现要点

```
1. 环境：PyTorch + diffusers + transformers；HuggingFace CLIP 变体（ViT-L/14, ViT-bigG/14 等）
2. 生成模型：SD1.5 / SDXL / Kandinsky 2.2（diffusers 均支持）
3. 审核器：CLIP Checker（CLIP zero-shot NSFW 判定）、ViT Checker（微调 ViT 分类头）、NudeNet
4. 数据：I2P（文本目标）+ NSFW Classification 数据集（图像目标）
5. 攻击超参：ε=8/255，对比学习温度按 CLIP 默认，替代编码器选与目标管线同族
6. 评测：bypass rate（审核器是否放行）、ASR（放行且 CLIP Sim ≥ 阈值）、查询数
```

### 6.2 复现风险点

- 三个审核器的具体权重与阈值论文未全部开源，需自行对齐；
- NSFW 数据集的 CLIP Sim 尺度与 I2P 不同，**不能跨数据集比较 CLIP Sim 绝对值**；
- ViT Checker 的强鲁棒性依赖其训练数据，换一个 ViT 不保证复现 0.185。

### 6.3 对我们最有用的复现实验（不是复现攻击，是复现"审核器差异"）

**最小可行实验**：拿我们自己的图审模型 + 一个开源 NudeNet + 一个 CLIP zero-shot checker，在**同一批 500 张已知 NSFW 生成图**上比较三者的放行率。如果差异超过 20 个百分点，说明我们的图审 AB 评测必须做**审核器集成**而不是单模型上线。
