# 99.03% 与 88.55% 之间，隔着 10.5 个点的"分布外"

**论文主页**: https://arxiv.org/abs/2611.06000

## 一、背景与问题

### 动机

现有的"来源归因"数据集和系统，绝大多数瞄的是**架构签名**——区分 DALL·E 3 与 Midjourney v6 这种架构和生成管线都不同的模型。

但现实是：SDXL 有大量微调版本（Juggernaut XL、RealVis XL、DreamShaper、Animagine……），从动漫风到写实人像各有拥趸，也被大量用于滥用。**要追责、要溯源，就得区分"同一个骨架、只差微调"的版本。**

论文把这件事单独立成一个任务：

> **IntrAA-SD**（Intra-Architecture source Attribution for Stable Diffusion）：被区分的源模型**共享同一架构骨架，只因微调而不同**。

### 两条难点，都对我们成立

1. **微调不显著改变权重**，骨架完全一样，可用的痕迹极弱。
2. **分类器会学内容与风格**，而不是学微调留下的细微痕迹：

> 在我们数据集上训练的模型，可能学会把"动漫风输出"关联到 Animagine XL，因为它的训练图大多是动漫。

这就是**风格捷径**。它的后果在分布外输入上暴露：给 Animagine XL 一个写实 prompt，风格线索消失，分类器就崩。

### 三条论断

1. 同架构归因是一个**与架构级归因本质不同**的任务，现有架构级方法迁不过来（实测掉 17.4 点 vs 10.5 点）。
2. 需要一个**同时含 ID 与 OOD prompt 的基准**，否则无法测量"风格线索消失后还剩什么"。
3. 用**风格门控的 MoE** 可以把"风格"与"微调痕迹"两条通路分开走，而不是让一个分类头同时学两件互相污染的事。

## 二、核心方法

### 2.1 数据集 ISDB

| 项 | 数 |
|---|---|
| 图像总数 | **140K** |
| SDXL 微调版本 | **10**（SDXL Base、Juggernaut、RealVis、DreamShaper、Animagine、Counterfeit、ZavyChroma、Copax、Proteus、AAM Anime） |
| ID prompt 类别 | 15 |
| OOD prompt 类别 | 20（共 200 条 prompt） |
| 采样参数 | DPM++ SDE Karras，25 步，CFG 7.0，固定负向 prompt |
| 输出格式 | **95% JPEG**（模拟真实传播条件：野外的图至少被有损压缩过一次） |
| ID 种子数 | 40 |
| OOD 种子数 | 10 |
| 划分 | ID 按 80/20 分层划分，**prompt 不重叠**；OOD 全量只做评测 |

**95% JPEG 这个细节值得单独记**：它把"实验室里 99% 的归因准确率"和"野外的可用性"之间的距离显式化了。很多溯源系统在 PNG 上完美，在社交平台压缩后失效。

### 2.2 OOD 的两类

| 类型 | 例子 | 测什么 |
|---|---|---|
| **对抗型** | 刻意与微调模型调性相反的 prompt | 能不能忽略强烈的不协调风格、只看签名 |
| **域偏移型** | 文化场景、医学与科学影像、历史风格、水下、体育、时装；以及若干"细微域偏移"（与 ID 相似但要求完全不同的生成） | 风格线索中性化后的稳定性 |

### 2.3 基线框架：风格条件 MoE

三段：

1. **冻结 CLIP** 提取图像风格 → 作为 MoE 的**门控信号**（gating）；
2. **高分辨率 LoRA 适配的 DINOv2** 提取"微调痕迹"特征；
3. MoE 专家按风格门控加权，输出归因。

设计意图很明确：**让"风格"显式成为门控变量，而不是隐式混进分类特征。** 这样风格能帮忙（区分动漫系与写实系）但不污染（不会把"写实"本身当成某个微调的证据）。

## 三、技术细节

### 3.1 风格到底有多强的判别力

论文给了逐类风格画像（附录 Table 2，按风格类型分组的 MoE 门控权重），并明确结论：

> 从 Table 1 可以看出，风格能帮助区分部分微调，但单靠风格不足以在一般情况下定位到具体的微调生成器。

也就是：**风格是必要线索但不是充分线索**。这正好解释了为什么"纯风格分类器"在 ID 上能拿到不错的数，在 OOD 上会崩。

### 3.2 为什么现有架构级方法迁不过来

作者把现有架构级归因模型**在 ISDB 训练集上重训**，再在 ISDB 测试集上评：

| 方法 | ID | OOD |
|---|---|---|
| 现有架构级归因（重训后最佳） | 92.21% | **74.84%** |
| **IntrAA-SD 基线** | **99.03%** | **88.55%** |

两件事同时成立：
- 架构级方法在 ID 上也能到 92%——**说明 ID 分数本身不难刷**；
- 但 OOD 掉 17.4 点（92.21→74.84），比专门方法掉得多（99.03→88.55，掉 10.5 点）。

**"ID 高分"是这类任务最容易得到的假象。**

### 3.3 消融关注的三件事

论文做了框架组件、超参、损失函数的消融。三条设计判断值得记：

1. **冻结 CLIP 只做门控，不做特征**——如果让 CLIP 特征直接进分类头，风格就会污染判定；
2. **DINOv2 要 LoRA 适配且高分辨率**——痕迹在细节里，低分辨率会抹掉；
3. **MoE 而不是单头**——不同风格族的痕迹分布不同，单头会在族间相互干扰。

## 四、实验与结果

### 4.1 主结果

| 条件 | 准确率 |
|---|---|
| **ID 测试集** | **99.03%** |
| **OOD 测试集** | **88.55%** |
| 架构级方法（同数据重训）ID | 92.21% |
| 架构级方法（同数据重训）OOD | 74.84% |

### 4.2 三个必须一起读的数

1. **99.03% 不能单独引用**。同一个模型在 OOD 上是 88.55%，**掉 10.5 点**。
2. **"比现有方法高 6.8 点（ID）"是误导性的**。真正有意义的是 OOD 上的 13.7 点（88.55 vs 74.84）。
3. **ID 92.21% 说明这个任务的 ID 分数下限很高**。一个"错的"方法在同分布上也能到 92%——**这意味着任何只报 ID 的论文/系统都不能自证有效**。

### 4.3 混淆矩阵的位置

论文附录 §4.3 给了 OOD 集的混淆矩阵。这是判断"错了往哪错"的关键：如果错误集中在**风格相近的微调对**（如 Juggernaut 与 RealVis），说明模型在依赖风格；如果均匀分散，说明是随机失效。

论文原文提到 Fig. 1 的观察："有些对（如 M2 与 M3）比其他的更相似"——**这意味着难度在类对之间不均衡**，平均值会掩盖最难的类对。

## 五、局限性

1. **只做 SDXL 一族**。SD3.5、FLUX、Qwen-Image 的微调生态未覆盖。
2. **10 个微调版本是人工选的**，不代表真实分布（野外有成千上万个 LoRA）。
3. **未测"微调+LoRA 再叠加"**。真实滥用场景常是 base + LoRA 组合，本任务只区分单层微调。
4. **未测对抗攻击**。攻击者可以对图像做后处理（再压缩、裁剪、加噪）来逃避归因，论文只用了 95% JPEG 这一种"自然退化"。
5. **OOD 的 20 类由作者定义**，边界主观。
6. **与内容安全无直接关系**：论文不讨论"归因之后怎么处置"，只做归因本身。

## 六、复现指南

### 6.1 公开物

- 代码与数据集：https://github.com/mallikagarg/IntrAA-SD
- 数据集含 ID/OOD 两套 prompt 与 10 个微调的生成图

### 6.2 最小复现路径（迁移到"线上策略命中归因"）

1. **先量"ID vs OOD 落差"**（半天，零训练）。拿现有图审模型，在"训练分布内"与"分布外（新画风/新构图/新平台压缩）"两套样本上各算一次命中归因准确率。**落差 >10 点 ⇒ 当前归因不可用于线上追责。**
2. **做风格捷径自检**（半天）。把测试集按"画风"分组，看归因准确率是否与画风强相关。**如果"动漫"组准确率显著高于其他组，说明模型在查画风不在查签名。**
3. **加一层显式门控**（工程 1–2 周）。把"画风/构图"作为显式变量（门控或分层），而不是让分类头自己混着学。

### 6.3 迁移时最容易做错的三件事

1. **只报 ID 准确率**。92.21% 的"错误方法"证明了这条路会骗人。
2. **用 PNG / 无损图评测溯源**。真实链路至少一次有损压缩。
3. **把"风格相关"当成"模型识别力强"**。风格相关是捷径的证据，不是能力的证据。

## 附：与业务的三条硬对应

1. **"平均准确率"必须带分布口径**。这是本轮第三个同构例子（前两个是 exact-match 与输出级相关）：**99.03% 与 88.55% 是同一个模型的同一次训练**。我们的图审/改写指标也应固定报"ID / OOD 两列"，而不是一列平均。落地动作：**AB 看板每行加"分布外列"**（新画风、新平台压缩、新语种）。
2. **风格捷径是图审最可能的隐藏捷径**。图审模型完全可能学"这类图的画质/构图/色调 = 高风险"，而不是"图里有违规内容"。这与 11-02 的"depict vs enable"、10-30 的"referential vs fairness"是同一条线上的第三个变体。**可测判据**：把同一违规内容换画风（写实/动漫/插画），看判定是否翻转；翻转率 >20% ⇒ 在查画风。
3. **"微调不显著改变权重"这句话，对权重侧擦除是一记直击**。既然两个微调版本连归因都要专门设计才能分开，那么"擦掉一个概念"的权重改动，**在后续微调中同样容易被覆盖**——这与 AIG-NCII 的"open-weight + LoRA 可把概念装回"是同一事实的两面。**权重侧治理必须假设"下游会再微调"，因此它只能管上线前，管不了分发后。**
