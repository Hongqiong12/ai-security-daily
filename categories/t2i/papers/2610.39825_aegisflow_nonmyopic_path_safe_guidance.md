## 一、背景与问题

### 动机

扩散 / 流匹配模型在生成时经常要满足**硬约束**：编辑人脸时保持身份、机器人规划时避开障碍、生成时不许出现某类内容。现有的免训练做法是在每一步去噪时解一个**最小范数控制（min-norm controller, MNC）** —— 在当前这一步，找一个"刚好把约束拉回安全集"的最小修正量。

问题在于 MNC 是**短视（myopic）**的：它只看"这一步不越界"，不看"整条轨迹会走到哪"。后果是轨迹会**贴着安全集的边界飞**：

> 每一步都刚好合规，于是整条路径都悬在边界上。任何一点数值扰动、任何一次采样噪声，都可能把轨迹推出去；而且因为一直在边界附近，模型没法朝目标方向做更激进的优化 —— 目标对齐被白白牺牲掉。

这和我们改写管线里的一件事是同一个数学结构：**我们用编辑距离 / edit rate 上限约束改写幅度，让改写"尽量小"。最小改动 = min-norm。** 它的直接后果是：改写后的 prompt **长期贴着风险阈值**，稍一 paraphrase 就重新越界。论文把这个现象在生成侧量化了，并且给出了替代方案。

### 核心问题

1. 能不能把"路径安全"写成一个**全局**最优控制问题，而不是逐步投影？
2. 这个全局解能不能**有解析可算的近似**（否则免训练就不成立）？
3. 保持更大安全裕度，会不会反而**牺牲目标对齐**？

## 二、核心方法

### （1）把引导重写成带屏障的全局代价

生成过程写成受控动力系统 $\dot{x} = f(x,t) + u$，$u$ 是控制量（即引导项）。AegisFlow 定义代价泛函：

$$J(u) = \int_{t_0}^{T}\Big[\tfrac12\|u\|^2 + \lambda\, B(x,t)\Big]dt + \Psi(x_T)$$

- $B(\cdot,t)$ 是**时变屏障函数**，定义在安全集 $C_t = \{x : h(x,t) \ge 0\}$ 的内部，向边界发散
- $\Psi$ 是终点目标损失（图像任务里取 $\Psi(x) := -0.7\cdot \mathrm{CLIP}(x, c)$，$c$ 是目标文本）

关键差别：**屏障函数进了全局代价，而不是每一步的约束。** 因为 $B$ 在边界附近趋于无穷，任何**有限代价**的解都**天然**满足约束 —— 不需要事后投影，也不需要逐步屏障。

### （2）HJB 的可算近似

全局最优控制由 Hamilton–Jacobi–Bellman 方程给出：

$$-\partial_t V = \min_u\Big[\nabla V^\top (f+u) + \tfrac12\|u\|^2 + \lambda B\Big]$$

对 $u$ 取极小得 $u^* = -\nabla V$。但 HJB 一般不可解，而且加了屏障项之后从无强迫变成**有强迫**方程，更难。论文给出一个可算的近似来估 $\nabla V$，从而得到闭式控制量（Algorithm 1）。

### （3）图像任务里的安全集怎么定义

身份保持的安全集用**身份相似度** $h(x,t)$：用 sigmoid 把"与源图的身份距离"压到 (0,1)，取 $\kappa_B = 5$、$\delta = 0.15$。理论上给出一个可证的裕度：$h(T) \approx 0.825$，与实测一致。

## 三、技术细节

### 为什么 MNC 会贴着边界飞

MNC 解的是

$$u_{\text{safe}}(t) = \arg\min \tfrac12\|u\|^2 \quad \text{s.t.}\quad \dot h + \alpha(h) \ge 0$$

约束是**不等式、单步**。所以最优解永远落在约束的**等号**上 —— 也就是**边界上**。这不是实现问题，是**目标函数决定的**：最小化 $\|u\|$ 会把解推到可行域边界。

AegisFlow 改成在**整条路径**上累积屏障代价。屏障函数在靠近边界时陡增，所以最优解会**主动留出裕度**，而不是被动贴在边上。

### 计算代价的真相

| 数据集 | 方法 | 单次耗时（s） |
|---|---|---|
| CelebA-HQ | OC-Flow | 421.02 ± 25.56 |
| CelebA-HQ | OC-Flow + MNC | **518.26 ± 25.54** |
| CelebA-HQ | **AegisFlow** | **433.81 ± 25.57** |
| Maze2D | SafeDiffuser | 4.78 ± 0.42 |
| Maze2D | SafeFlowmatcher | 4.21 ± 0.39 |
| Maze2D | **AegisFlow** | **44.15 ± 1.96** |

这里有一个非常值得记的反差：**在图像任务上，AegisFlow 比 MNC 快 84.5 秒（−16.3%）**，因为 MNC 要每一步解一个 QP，而 HJB 近似是闭式的；**但在连续控制任务上它比专用方法慢 10 倍**（44.15 vs 4.21）。同一篇论文里，同一个方法在两种任务上一个"更快"一个"慢十倍"，说明**"全局 vs 短视"的账要按任务算，不能一概而论**。

### 屏障函数的形状

$$\text{图像任务}: B = -\log\sigma(\kappa_B(h(x,t) - \delta))\ \text{形式},\quad \kappa_B = 5,\ \delta = 0.15$$
$$\text{导航任务}: B(\tau,t) = \sum_{x\in\tau}\Big[(h_1(x)-t+\delta)^{-1} + (h_2(x)-t+\delta)^{-1}\Big],\quad \delta = 0.05$$

两个任务用了**不同族的屏障**（logistic vs 倒数），说明屏障的选择是**任务相关的工程项**，不是定理的一部分。

## 四、实验与结果

### 图像编辑（CelebA-HQ，文本引导 + 身份保持）

指令集 {old, smile, sad, angry, curly hair}；CLIP 测文本对齐，LPIPS 测结构保持，ArcFace 算 ID 相似度。

| 方法 | CLIP ↑ | LPIPS ↓ | ID ↑ |
|---|---|---|---|
| CG + RF | 0.292 | 0.346 | 0.643 |
| CG + LDM | 0.298 | 0.383 | 0.513 |
| DiffusionCLIP | 0.285 | 0.398 | 0.659 |
| StyleCLIP + e4e | 0.267 | 0.359 | 0.704 |
| FlowGrad + RF | 0.299 | 0.302 | 0.737 |
| OC-Flow | 0.302 | 0.207 | 0.732 |
| **OC-Flow + MNC** | 0.304 | 0.193 | **0.920** |
| **AegisFlow** | **0.309** | **0.188** | 0.901 |

**这张表最重要的读法不是"AegisFlow 三项都最好"，而是它和 MNC 的对照：**

- MNC 的 **ID 最高（0.920 > 0.901）**，但 CLIP（0.304 < 0.309）和 LPIPS（0.193 > 0.188）都更差
- 也就是说：**MNC 把"约束"做到了极致，代价是"目标"**。它把身份锁得最死，同时最没把"变老/微笑"改到位
- AegisFlow 主动**让出一点约束裕度**（ID 0.901 < 0.920），换来**更好的目标对齐和结构保持**，而且**更快**

论文对此的原话是：AegisFlow "maintains a larger safety margin and thus allowing more aggressive optimization towards the target prompt"。

### 约束满足的时序证据

Figure 4(a) 记录每个时间步的 $h(x,t)$：AegisFlow 的曲线**全程高于**MNC，说明它从早期就开始留裕度，而不是等到快越界才拉。这与"非短视"的表述一致 —— **提前留裕度**是多步视野的直接产物。

### 控制任务（Maze2D / D3IL Avoiding）

AegisFlow 同时取得最好的"到达目标成功率"和"安全率"。论文强调它在 rollout 早期就维持了更大的安全缓冲。

## 五、局限性

1. **图像任务只测了一个数据集（CelebA-HQ）、五条指令**，且都是"人脸属性编辑 + 身份保持"这一种约束形态。**"内容安全约束"从未被测** —— 论文里的"安全"是几何/身份意义的安全，不是内容合规意义的安全。这个迁移**没有实证支持**。
2. **控制任务上慢 10 倍**（44.15s vs 4.21s），论文自己归因为"求解强迫 HJB"，但这意味着它在**低延迟场景不可用**。
3. **屏障函数的选择是手工的**（$\kappa_B$、$\delta$、logistic vs 倒数），论文没有给选法，只说"aligned with empirical results"。换任务要重调。
4. **只做了免训练的推理期引导**，没有和"训练期约束"对比 —— 所以不能说"免训练够用"，只能说"免训练里它最好"。
5. **单机构三人工作，无工业界部署验证**；没有报告在真实产品流量上的表现。
6. 理论上只给了一个近似（$\nabla V$ 的估计），**没有误差界**，所以"有限代价 ⇒ 满足约束"这句话在近似下**并不严格成立**。

## 六、复现指南

### 环境
- 流匹配 / 扩散模型（论文用 OC-Flow、RF）
- CLIP（对齐）、LPIPS（结构）、ArcFace（身份）
- 代码：https://github.com/LiuKunpeng03/AegisFlow

### 最小复现路径
1. **先复现"贴着边界飞"这个现象**（不需要 AegisFlow）：在任意带约束的引导里，记录每步的 $h(x,t)$。如果 MNC 的曲线**紧贴 0 附近波动**而几乎不留正裕度，现象就成立。这一步零成本、纯记录。
2. **再把约束从"每步不等式"改成"整条路径的屏障代价"**，看裕度曲线是否整体上移。
3. **最后测"让出裕度换目标"的兑换率**：扫 $\delta \in \{0.05, 0.10, 0.15, 0.20\}$，画 (约束指标, 目标指标) 的帕累托前沿。论文只在 $\delta=0.15$ 报了一个点。

### 关键超参
- 图像任务：$\kappa_B = 5$、$\delta = 0.15$、$\Psi = -0.7\cdot\mathrm{CLIP}$
- 导航任务：$\delta = 0.05$、倒数型屏障
- MNC 基线：安全集相同，$\rho_t = 1$ 恒定

## 附：这条结论怎么搬到输入侧改写（本轮最重要的一次结构迁移）

我们的改写管线当前的两个硬约束是：

1. 风险分降到阈值以下
2. **编辑距离 / edit rate 不超过上限**（越小越好）

第 2 条在数学上就是 min-norm：**在"风险达标"这个可行域里，找改动最小的点。** 它的最优解落在**可行域边界**上 —— 也就是"风险刚好等于阈值"。

于是有三条可检验的推论：

| 推论 | 判据 | 若成立说明什么 |
|---|---|---|
| 改写后的风险分分布会**堆积在阈值紧邻的下侧** | 画改写后风险分直方图，看是否在阈值下方形成尖峰 | 我们在生产"刚好合规"的样本，而不是"安全"的样本 |
| 对这些样本做**同义 paraphrase**，越狱率会显著高于整体 | 抽 200 条"改写后风险分在阈值 −0.05 内"的样本，各做 3 个同义变体重测 | 最小改动改写的**鲁棒性最差** |
| 把约束改成"风险 ≤ 阈值 − δ"，允许 edit rate 略大，**误杀率不会变差** | A/B：δ=0 vs δ=0.15（风险分归一化后） | 留裕度不牺牲合规，可能还降低越界回潮 |

第三条对应论文的 ID 0.920 → 0.901：**让出一点约束裕度，目标指标反而更好。** 在我们的语境里，"约束"是风险分，"目标"是语义保真 —— 预测是**语义保真会变好，风险分仍在阈值内**。

**必须写明的边界**：论文的"安全"是几何意义（身份距离、障碍距离），**不是内容合规**。这条迁移是**结构同构**，不是实证结论。所以它是"值得做的一个实验"，不是"已经验证的方法"。
