## 一、背景与问题

### 动机

T2I 平台越来越依赖 watermark / provenance 来承接版权保护、来源证明和平台治理，但攻防两侧并不平衡：防御侧不断提出新水印，攻击侧却缺少足够强、足够系统的 removal 框架。结果就是很多 watermark paper 实际上只在“弱攻击者”设定下显得鲁棒。

### 核心科学问题

能否构建一个基于扩散模型的统一 attack framework，在尽量保持图像视觉质量的前提下，稳定破坏多种不同水印方案，并在训练阶段直接学习“去水印”而不是只做浅层图像扰动？

### 直觉洞见

传统 watermark attack 更像对图像“抖一抖、糊一糊、压一压”，赌水印会顺便坏掉；FMDiffWA 则像是专门学会“沿着频域里最容易伤到水印、最不容易伤到图像主体的方向动手”。对工业平台来说，这篇论文的重要性不在于鼓励攻击，而在于提醒：**只测 bit-level 鲁棒性已经不够，必须假设攻击者会显式训练一个去水印器。**

## 二、核心方法

**（1）FMDiffWA：频域调制扩散攻击框架**

作者提出 **FMDiffWA**，以带水印图像为条件输入，用条件扩散模型学习“接近无水印图像分布”的输出。它不是对现成图像做一次性后处理，而是把去水印攻击直接嵌入扩散采样过程。

**（2）FWM：频域水印调制模块（Frequency-domain Watermark Modulation）**

作者认为 watermark 在频域往往比在像素域更有结构性痕迹，因此在采样时显式使用 Fourier 频域先验：
- 对图像做傅里叶变换；
- 分别处理幅度（magnitude）与相位（phase）；
- 在幅度上做加权融合，在相位上保留更强结构信息。

核心目标是：尽量保图像主体结构，同时更定向地削弱水印痕迹。

**（3）动态扰动调节**

作者并不在所有采样步上施加同样强度的攻击，而是采用动态 schedule：
- 前期扰动更强，优先破坏水印；
- 后期扰动更弱，优先恢复视觉细节。

这本质上在“攻击强度”和“图像保真”之间做时间步层面的分工。

**（4）两阶段训练策略（PTS）**

作者发现仅靠标准扩散噪声预测不足以保证最终的 removal quality，因此使用两阶段训练：
1. **噪声估计阶段**：先学会稳定反向扩散；
2. **细化阶段**：直接对采样结果施加 L1 + MS-SSIM 监督，提升结构保真与视觉质量。

**（5）Patch-based 推理**

为了适应不同分辨率与显存限制，作者将输入图像切为重叠 patch，分别做噪声预测后再融合。这让方法不被固定分辨率绑死。

## 三、技术细节

### 条件扩散目标

给定带水印图像 I_w，模型学习生成接近无水印图像分布的输出 Î：

Î = G_θ(I_w)

第一阶段训练采用标准扩散噪声估计目标：

L_noise = E[||ε - ε_θ(x_t, t, I_w)||²]

其中模型在每个时间步预测噪声，从而学会反向去噪。

### FWM 模块

作者将图像频谱分解为：
- **A(·)**：幅度；
- **P(·)**：相位。

在采样阶段，对当前反向采样结果和前向过程保留信息做频域融合：

A_new = Φ_β · A(Ĩ_{t-1}) + (1 - Φ_β) · A(I_{t-1})

P_new = P(I_{t-1})

其中：
- `Φ_β` 是只在频谱中心非零的掩码；
- `β ∈ (0, 1)` 控制中心频域范围。

直觉上：
- 幅度更像低层统计与水印痕迹；
- 相位更像结构与语义骨架。

作者选择在这两部分上做不同处理，是为了在 removal 与保真之间取得更细粒度平衡。

### 动态扰动 schedule

扰动强度按时间步线性变化：

L(t) = L_min + (L_max - L_min) · t / T

其中：
- 早期 `t` 大时，攻击更强；
- 后期 `t` 小时，更偏向恢复质量。

### 二阶段细化损失

第二阶段使用：

L_ref = L_1 + L_ms-ssim

其中：
- `L_1` 提升像素级重建精度；
- `L_ms-ssim` 保持多尺度结构一致性。

### 关键超参

- PyTorch **2.1.0**
- GPU：**RTX 4090**
- 优化器：Adam，β₁ = **0.9**, β₂ = **0.999**
- batch size：**2**
- learning rate：**2e-5**
- 每张图随机切 **16** 个 **64×64** patch
- 总扩散步数：**T = 1000**
- 采样步数：**S = 10**
- 第一阶段迭代：**1×10^6**
- 第二阶段迭代：**3×10^5**

### 对当前业务的间接启发

虽然这篇论文不做 prompt rewrite，但它对你的业务有一个很强的评测启发：**不要把安全防线只定义为“攻击有没有成功”，而要看攻击成功后是否仍留下可检测、可审计、可归因痕迹。** 这和前一天那篇“forensic cost of watermark removal”是同一条工业主线的攻击侧补全。

## 四、实验设置与结果

### 数据集与评价指标

- 数据集：**CelebA / ImageNet**
- 总样本：**24,000** 张图像
  - 训练：**18,000**
  - 测试：**6,000**
- 图像尺寸：统一到 **256×256**
- 水印大小：**16×16**

### 水印方法覆盖

训练/测试覆盖 4 类代表性水印：
1. **LSB**（空间域）
2. **DCT**（频域）
3. **QPHFMs / PHFMs**（正交矩）
4. **HiDDeN_MP**（深度学习）

还额外测了未见过的水印算法：
- SIRD
- DFT
- PHTs
- IWRN

### 对比攻击方法

- Gaussian noise
- Speckle noise
- Salt & pepper noise
- Average filter
- JPEG compression
- RD-IWAN
- DiffWA
- HIWANet
- **FMDiffWA（本文）**

### 核心指标

- **PSNR**：视觉保真度（↑）
- **BER**：Bit Error Rate，越高表示提取出的水印错误越多、攻击越成功（↑）

### 主结果 1：本文方法兼顾高保真与高破坏

#### CelebA

| 水印方法 | FMDiffWA PSNR (↑) | FMDiffWA BER (↑) |
|----------|------------------:|-----------------:|
| LSB | **45.26** | **0.3203** |
| DCT | **43.41** | **0.3386** |
| QPHFMs | **42.18** | **0.2031** |
| HiDDeN_MP | **43.63** | **0.4495** |

#### ImageNet

| 水印方法 | FMDiffWA PSNR (↑) | FMDiffWA BER (↑) |
|----------|------------------:|-----------------:|
| LSB | **43.82** | **0.3327** |
| DCT | **40.16** | **0.3415** |
| QPHFMs | **40.45** | **0.2264** |
| HiDDeN_MP | **41.53** | **0.4562** |

对比趋势很明确：
- 传统攻击多数 PSNR 在 **27–34 dB**；
- 现有深度攻击大多在 **29–37 dB**；
- **FMDiffWA 稳定上到 40 dB+**，同时 BER 也更高。

也就是说，它不是靠把图像打坏来“顺手破水印”，而是真正学到了一条更精细的攻击路径。

### 主结果 2：泛化到未见过水印算法

作者强调 FMDiffWA 在未见水印上仍保持稳定破坏能力，说明它学到的不是某一种特定 watermark pattern，而是更通用的 watermark embedding 共性。

### 消融实验

作者对两个关键模块做了消融：
- **FWM**：频域调制模块
- **PTS**：分阶段训练策略

在 QPHFMs 上的代表性结果：

| 设置 | PSNR (↑) | BER (↑) | 说明 |
|------|----------:|---------:|------|
| 仅 FWM | 39.96 | 0.1896 | 攻击有效，但保真不足 |
| 仅 PTS | **48.65** | 0.0664 | 图像更好，但去水印弱 |
| **FWM + PTS** | 42.08 | **0.2084** | removal 与保真平衡最佳 |

这个消融很有价值，因为它明确说明：
- 只保图像质量，不够；
- 只追攻击成功，也不够；
- 工业上真正要看的永远是 trade-off。

### 超参实验

- 频域掩码尺度 **β = 0.6** 时整体最平衡；
- 采样步数 **S = 10** 最优；
- 当 S 再增大时，图像会开始过平滑。

### 关键发现

- watermark 攻击已经可以被训练成一个强生成模型，而不只是弱扰动；
- 频域先验对这种任务尤其关键；
- 未来 watermark defense 不能再只和 JPEG、noise 之类传统攻击比。

## 五、局限性分析

1. **攻击设置仍主要在受控数据集上验证**：CelebA / ImageNet 与真实平台传播链路之间还有距离。  
2. **当前只关注 bit-level watermark recovery error**：对 forensic detectability、平台侧 artifact 残留并未直接建模。  
3. **公开复现信息有限**：没有公开代码，细节更多依赖论文描述。  
4. **方法本身较重**：扩散式攻击比传统扰动攻击成本高得多，不适合所有攻击者设定。  
5. **与工业 provenance 系统耦合度有限**：现实系统常常叠加 badge、metadata、distribution shift 等额外信号，论文未覆盖。

## 六、复现指南

### 环境依赖

```bash
pip install torch torchvision diffusers pytorch-msssim opencv-python numpy scipy
```

### 核心代码框架

```python
class FMDiffWA:
    def forward(self, watermarked_img):
        latent = add_noise(watermarked_img)
        for t in reversed(range(self.steps)):
            pred = self.denoise(latent, watermarked_img, t)
            pred = self.frequency_modulate(pred, watermarked_img, beta=0.6)
            latent = dynamic_perturb_update(pred, t)
        return latent

    def refinement_loss(self, pred, clean):
        return l1_loss(pred, clean) + ms_ssim_loss(pred, clean)
```

### 复现步骤

1. 选择若干典型 watermark 算法，在训练集图像上嵌入固定大小水印。  
2. 第一阶段训练条件扩散模型做噪声预测。  
3. 第二阶段加入 L1 + MS-SSIM，对最终采样结果做细化监督。  
4. 在采样时启用 FWM 频域调制与动态扰动调节。  
5. 在 CelebA / ImageNet 上分别报告 PSNR / BER。  
6. 额外加入未见水印算法，验证跨水印泛化。  
7. 若要贴近工业评测，建议再加 forensic detectability 和平台重压缩鲁棒性。

### 对当前业务可迁移的部分

这篇论文不能直接迁成 prompt rewrite 方法，但能迁移出两个评测思路：
- **攻击者会训练专门的 remover，而不是只靠浅层 prompt trick**；
- **安全评测必须看 trade-off，而不是单指标最优**。

如果未来你要评估 rewrite 是否真的降低风险，最好也按类似思路看：
- 风险下降多少；
- 语义保真损失多少；
- 是否留下新的可审计 artifact 或异常模式。
