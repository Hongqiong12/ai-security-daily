## 一、背景与问题

### 动机：一个被默认了很久的假设错了

工业界训练 Prompt Enhancer（PE，把用户短 prompt 扩写成详细描述）的通行做法：从 dense caption 反向合成「像用户写的短 prompt」，构成 SFT 对，**隐含假设是「那些能让生成变好的 caption，也是好的监督目标」**。

本文直接用配对实验证伪：把 caption 按生成增益 Δq 分成最高 10K（`D_H`）与最低 10K（`D_M`），`D_H` 平均增益 **3.20**、`D_M` 只有 **0.13**（**约 25 倍**），但在**完全相同初始化与训练配置**下训出的两个 PE 模型，在 200 条留出短 prompt 上几乎打平。

作者解释：dense caption 里大量**图像专属细节**对「直接拿去生成」有用，但与**用户意图**弱相关；让 PE 学会复现这些细节是**冗余监督（redundant supervision）**，甚至会把改写带偏。

### 与本仓库主线的关系

这是本轮**唯一直接讲「输入侧改写器怎么训」**的工作，四条贴合：

- **方向(1) 输入侧改写 / 语义保真**：PE 与 safety rewriting 同属「改写 prompt 但保住用户意图」的动作族；本文给出「改写监督目标应只含意图相关成分」的可证伪判据。
- **改写强度分级 / 过度拒答**：`per-example deletion bound τ=0.4` 是**改写强度上界**的一个可直接借用的形态；「剪掉冗余反而更好」正面支持「能改则不拒、改写强度尽量下沉」。
- **方向(5) SFT 数据构建 / 训练数据清洗 / 重加权隐性代价**：本文证明「按生成增益筛样本」这个看似合理的数据筛选准则**在下游目标上失效**——与 11-08 Reweighting、11-04 Kling PE 的「从 caption 反向构造」形成直接对照。
- **语义保真度量**：四类 × 四生成器 × 四指标的表格，可搬成改写器多版本回归看板的最小模板。

## 二、核心方法

### 2.1 配对证伪实验

1. 用短 prompt `x` 与 dense caption `y` 分别喂固定生成器 `gθ`，以 **HPS v2** 量化生成增益 `Δq_i`；
2. 取增益最高与最低各 10K 对，构成 `D_H` / `D_M`；
3. 各自基于 **Qwen3.5-9B** 微调一个 PE 模型，**只改监督数据集**，最小化标准自回归 `ℓSFT(φ) = −E_D Σ_t log p_φ(y_t | x, y_<t)`（loss 只算目标 token）；
4. 同一批 **200 条留出用户 prompt** 上用四个指标评测：HPS v2、PickScore（prompt 条件偏好）/ MANIQA、VQ-R1（prompt 无关感知质量）。

### 2.2 P2E（Prune to Expand）：text-only 的嵌套剪枝

对每条 `(x_i, y_i)`，让 **LLM 同时看短 prompt 与 caption**，生成 **K=3 个嵌套剪枝候选**（目标约 20% / 40% / 60% token 删除，逐层删更多与意图无关的句子，**保留原句措辞与顺序**）；设 **per-example deletion bound τ=0.4**，在界内选删除比例最大的候选作为新监督目标 `ỹ_i`。

关键约束：**必须保留显式用户要求与信息性视觉结构**；用上界而非固定删除率，是因为句级删除是离散的（论文注：目标 60% 的候选实际可能只删掉 ≤40% token）。全过程 **text-only，不生成图、不做视觉打分、不增加推理开销**。

## 三、技术细节

### 3.1 高增益 ≠ 好监督（Table 1，Qwen-Image-2.1-Turbo）

| 段 | 方法 | HPS v2 | PicS | MIQA | VQ-R1 |
|---|---|---|---|---|---|
| 训练集直接生成 | `D_M` 短 prompt → dense | 29.58 → 29.71 (**+0.13**) | 22.50 → 22.45 | 0.630 → 0.658 | 4.005 → 4.010 |
| 训练集直接生成 | `D_H` 短 prompt → dense | 26.15 → 29.35 (**+3.20**) | 21.93 → 22.45 | 0.640 → 0.672 | 3.990 → 3.990 |
| 留出集 | w/o PE | 26.21 | 22.69 | 0.559 | 4.000 |
| 留出集 | Raw PE（未微调） | 26.73 | 22.63 | 0.556 | 4.015 |
| 留出集 | **Marginal-gain PE** | **27.13** | **22.76** | **0.573** | **4.050** |
| 留出集 | **High-gain PE** | **27.27 (+0.14)** | **22.81 (+0.05)** | **0.575 (+0.002)** | **4.050 (+0.000)** |

⇒ **25 倍训练增益差，换来的下游差只有 +0.14 / +0.05 / +0.002 / +0.000**，VQ-R1 完全持平。

### 3.2 探测冗余（Table 2）

| 方法 | HPS v2 | PicS | MIQA | VQ-R1 |
|---|---|---|---|---|
| Baseline（high-gain PE，未剪枝） | 27.27 | 22.81 | 0.575 | 4.050 |
| + LLM-only pruning | **26.46** | 22.53 | 0.570 | 4.015 |
| + Visual-guarded pruning | **27.59** | 22.77 | 0.574 | 4.035 |

⇒ **无约束删除会掉点**（−0.81 HPS），而有视觉结构守护的剪枝反而**升 +0.32**。这条极关键：**「剪枝增益」不是来自「删得多」，来自「保住了什么」**——直接对应改写强度分层（改哪些锚点，而非改多少字）。

### 3.3 主结果口径（Table 3）

- 评测：4 类（Landscape / Design / Portrait / General）× 每类 200 条 = **800 条留出 prompt**；
- 4 个视觉生成器：**Qwen-Image-2.1-Turbo / Z-Image-Turbo / MOSS-Image / BAGEL**；
- 两个 SFT 变体**配置完全相同，只换监督目标**（未剪枝 vs P2E 剪枝）；P2E 在跨类别、跨生成器上普遍优于常规 dense-caption SFT。

## 四、实验与结果

| 观察 | 数 | 含义 |
|---|---|---|
| `D_H` vs `D_M` 生成增益 | **3.20 vs 0.13（25×）** | 训练目标看起来差很多 |
| 下游 PE 差（留出集） | **+0.14 / +0.05 / +0.002 / +0.000** | 几乎打平 ⇒ 代理量失效 |
| 无约束 LLM 剪枝 | HPS **27.27→26.46（−0.81）** | 删错东西会掉点 |
| 视觉守护剪枝 | HPS **27.27→27.59（+0.32）** | 删冗余且保结构才涨 |
| 剪枝设置 | K=3，目标 20/40/60%，**τ=0.4** | 上界式强度控制 |
| 主结果覆盖 | 4 类 × 200 = **800** 留出 / **4** 生成器 | 跨生成器泛化有证据 |
| 推理开销 | **零额外**（text-only 改监督） | 不碰线上链路 |

**一句话**：**「生成增益」是「监督价值」的坏代理量**；而且修复方式不是换个更好的筛选指标，是**先删掉与用户意图弱相关的成分、并守住必须保留的结构**。

## 五、局限性

1. 主线是**美学/构图类 PE，不是安全改写**：四个指标全是偏好与感知质量，**没有安全率、没有 NSFW、没有误杀率/漏过率**；因此本文不能证明「剪冗余对安全改写有效」，只能作为监督设计的可迁移形态。
2. 剪枝判据由 LLM 主观判定「意图相关」，**未报标注一致性 / κ**，也未做「惰性句对照」（删无信息句是否同样涨），无法排除「只是变短了」的解释。
3. τ=0.4 是固定上界，未扫 τ 甜点、未报 edit rate / Levenshtein 约束、未测过度改写导致的指令遵循下降。
4. 未覆盖跨语言 / 中英混合、I2I 编辑指令、统一生成-编辑模型；未测统一模型下同一份改写同时作用于生成与编辑两条通路。
5. 未报训练成本节省的具体数值（只说无额外推理开销），未与重加权/降采样做对照，未验证多版本 ckpt 回归与分层宏平均背离。
6. 生成器含闭源/半开源（Qwen-Image-2.1-Turbo 等），跨版本风险漂移未测。

## 六、复现指南

**零训练第一优先（半天）**：把本项目改写器 SFT 数据按「意图相关成分」审计一遍——抽 200 条 `(原 prompt, 改写目标)`，让 LLM 标出与用户显式要求弱相关的句子，统计其 token 占比。判据：占比 >30% ⇒ 存在本文所说冗余监督；再跑「无约束删除 / 保结构删除」两版对照，看**语义保真与指令遵循**是否同向（本文 Table 2 的关键是无约束删除会掉 −0.81）。

**改写强度上界（1 天，零训练 + 轻训练）**：把 `τ` 做成 per-example 可配置上界，扫 τ∈{0.2,0.4,0.6}，同时报 **edit rate、Levenshtein 距离、原子要件保留率、安全率、误杀率**。判据：τ 增大后安全率不升而保真降 ⇒ 当前 RL/SFT 改写已经在做无效加严，**重心应转出图侧**（与 EBSG 三路对照合并做）。

**数据筛选准则审计（半天）**：检查现有 SFT 样本筛选/重加权是否用了「改写后风险分降幅」「生成增益」这类代理量。若用了，按本文做**配对证伪**：把样本按代理量最高/最低各分一组，同配置训两个小模型，同留出集比下游指标。判据：差值 <0.5 点 ⇒ 筛选准则无分辨率，别再调它的权重。

**跨语言对照臂**：中 / 英 / 中英混合三语各跑一遍（本文未覆盖），**禁止只报聚合指标**，必须报分语言 ASR 与分层宏平均。

**回归看板口径**：抄本文 4×4×4 表格形态，补上 ckpt / 训练配置 / 数据集版本 / 评测口径版本四元组与逐版本 P-R-F1 留痕；量化/加速前后另报安全率与分层 F1 不劣化对比。

**依赖**：Qwen3.5-9B 作 PE 基座；Qwen-Image-2.1-Turbo 用于算 Δq；指标 HPS v2 / PickScore / MANIQA / VQ-R1。数字均为论文口径，不做外推。
