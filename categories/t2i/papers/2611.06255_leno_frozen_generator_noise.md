# 生成器一行不改，只在初始噪声上学一个残差：奖励 +34%，而"跑偏多远"有可算的上界

## 一、背景与问题

### 动机

扩散/流模型的奖励对齐，主流做法是在**随机轨迹**上做优化（DRaFT、ReFL、DPO 系）。这套东西有两个前提：步数多、可微。少步确定性生成器（SDXL-Turbo、SANA-Sprint 一类）两个前提都不满足——它建模的是**一个区间上的平均速度**，而现有 RL 目标是为**瞬时速度 + 多步采样**写的。

另一条路是**初始噪声优化**：不动模型，只找一组更好的噪声 $z_T$。这对少步生成天然合适（无轨迹），但现有做法是**推理时逐样本搜索**——每个 prompt 都要搜一遍，成本爆炸。

### 本文的定位

把"逐样本搜噪声"**摊销成一个学出来的输运**，而且**保持预训练生成器完全冻结**。

这个设定与我们的"不改生成模型、输入侧热更新"在结构上同构：

| | LeNO | 本项目输入侧改写 |
|---|---|---|
| 改动位置 | 初始噪声 $z_T$ | 输入 prompt |
| 生成器权重 | **完全冻结** | **完全冻结** |
| 干预可回滚 | 是（关掉输运即恢复） | 是（关掉改写即恢复） |
| 奖励形态 | **标量、黑盒、不必可微** | **分类器分数，标量黑盒** |
| 需要在线渲图 | 训练时需，推理时否 | 评测时需 |

所以这篇的技术骨架可以整块搬，而不是只做类比。

### 三条论断

1. **少步模型的 RL 目标必须先在 $x$ 空间统一表达**，否则密度式/速度式/奖励式三种目标不可比。
2. **冻结生成器时，唯一能做正则的量是"相对先验的分布漂移"**，而这个量在"预测残差均值"上有一个可算的闭式上界。
3. **探索尺度有一个非平凡的甜点**：太小没有奖励对比，太大局部信用分配失效。

## 二、核心方法

### 2.1 目标：KL 正则的奖励最大化

$$\max_\theta\ \mathbb{E}_{z\sim q_\theta(\cdot\mid c)}[R(z;c)]-\lambda D_{KL}\big(q_\theta(\cdot\mid c)\,\|\,p_0\big)$$

$p_0=\mathcal{N}(0,I)$ 是原始初始噪声先验，$q_\theta$ 是学出来的修正后分布。这和"带参考策略约束的 RL"是同一个形状——**参考策略就是原始先验**。

### 2.2 关键一步：给 KL 找一个可算上界

$q_\theta$ 由输运隐式定义，KL 不可直接算。论文的做法：对高斯先验 + 保范投影，得到

$$D_{KL}\big(q_\theta(\cdot\mid c)\,\|\,p_0\big)\ \le\ \mathbb{E}_{z\sim p_0}\Big[D_{KL}\big(\mathcal{N}(\mu_\theta(z,c),\sigma^2 I)\,\|\,\mathcal{N}(0,I)\big)\Big]$$

而右侧高斯对高斯的 KL 有闭式，于是**退化成"预测残差均值的缩放平方范数"**：

$$\text{reg}\ \propto\ \|\mu_\theta(z,c)\|^2$$

这一条是全文最可迁移的部分。它给了"保真"一个**可计算、可微、有上界语义**的形式，而不是靠 CLIP 相似度这类代理指标硬凑。

### 2.3 Local GRPO

- 以 $z\sim p_0$ 为锚，在其邻域采 $K$ 个粒子 $z+\sigma\epsilon$
- 组内相对奖励做信用分配（GRPO 式，无需 critic）
- 加条件 KL 项把策略拉回零均值高斯参考
- $\beta$ 控制 KL 强度，与归一化奖励尺度对齐

### 2.4 x 空间统一（三阶段）

| 阶段 | 做什么 |
|---|---|
| **变换** | 把每个目标都写成 $x$ 空间（干净端）的策略预测，让密度式/速度式/奖励式可比 |
| **分解** | 每个目标的梯度 = **向参考的自回归 + 奖励增强**，方法差异退化为"选什么锚、给什么权" |
| **适配** | 少步模型上落地（few-step 的区间平均速度） |

这个"分解"很有意思：**所有 RL 目标在梯度层面都是同一个式子，只是锚和权重不同**。这直接解释了为什么不同 RL 配方在少步模型上会趋同。

## 三、技术细节

### 3.1 设置

- 生成器：**SDXL-Turbo**（主实验）、**SANA-Sprint**（迁移实验，0.6B）
- 训练奖励：aesthetic score、PickScore、ImageReward
- 评测奖励（含未参与训练的）：HPSv2、CLIPScore
- 推理开销：**2 NFE**（一次残差修正）；对比推理时方法 800 NFE
- 蛋白质：长度 60–128，每长度 10 个 backbone，每 backbone 8 条序列

### 3.2 状态依赖是必需的

消融：把 $\mu_\theta(z,c)$ 换成 $\mu_\theta(c)$（喂固定 dummy 噪声，架构不变，生成用真实噪声，训练流程不变）。

结果：**状态无关版本只在早期有一点点提升，然后迅速饱和；状态依赖版本全程持续上升。**

解释：共享修正会把多个噪声状态的奖励增强信号**平均掉**；条件在 $z$ 上才能为不同初始噪声给出不同的局部修正。

### 3.3 探索尺度 $\sigma$ 的甜点

| $\sigma$ | 现象 |
|---|---|
| ≤0.1 | 粒子贴近预测修正，**奖励对比弱、提升慢** |
| **0.2** | **最优** |
| >1.2 | **奖励增益崩塌，甚至转负**——随机扰动压过预测修正，粒子与锚的局部对应关系被破坏 |

这是一个"探索-局部性"的显式权衡，而且**上界是硬的**：超过 1.2 就不是"慢"，是"反向"。

## 四、实验与结果

### 4.1 单奖励优化主表（SDXL-Turbo）

| 方法 | 需奖励梯度 | NFE | Aesthetic↑ | PickScore↑ | ImageReward↑ |
|---|---|---|---|---|---|
| SDXL-Turbo（原始） | – | 1 | 5.339 | 21.932 | 0.761 |
| BoN（推理时） | ✗ | 800 | 5.714 | 22.993 | 1.201 |
| ψ-Sampler | ✓ | 800 | **5.945** | **23.182** | **1.421** |
| ZeNO | ✗ | 800 | 5.750 | 23.038 | 1.260 |
| GoldenNoise（摊销） | – | 1 | 5.359 | 21.908 | 0.762 |
| HyperNoise（摊销） | ✓ | 2 | 5.382 | 21.951 | 0.939 |
| **LeNO** | **✗** | **2** | **5.460** | **22.715** | **1.019** |
| **LeNO + BoN** | ✗ | **100** | **5.952** | **23.191** | **1.444** |

三条读数：

1. **只花 2 NFE 就拿到大部分增益**：ImageReward 0.761 → 1.019（+34%），且**不需要奖励梯度**（HyperNoise 需要，2 NFE 只到 0.939）。
2. **LeNO + BoN（100 NFE）在三项上全部超过 800 NFE 的 ψ-Sampler**（5.952/23.191/1.444 vs 5.945/23.182/1.421）。**摊销把"搜 800 次"压成"训一次 + 搜 50 次"**。
3. GoldenNoise 几乎不动（0.762），**离线监督学噪声基本无效**——奖励必须在环里。

### 4.2 迁移到未优化的组合基准（GenEval，SANA-Sprint）

| 模型 | 参数(B) | 时间(s) | Mean↑ | Single | Two↑ | Counting↑ | Colors | Position | Attribution↑ |
|---|---|---|---|---|---|---|---|---|---|
| SANA-Sprint | 0.6 | 0.2 | 0.67 | 1.00 | 0.68 | 0.60 | 0.85 | **0.40** | 0.47 |
| + HyperNoise | 0.9 | 0.3 | **0.71** | 1.00 | 0.75 | **0.67** | 0.84 | **0.48** | 0.53 |
| **+ LeNO** | 0.9 | 0.3 | 0.70 | 1.00 | 0.74 | 0.66 | 0.85 | **0.41** | **0.54** |

关键不是总分（0.67→0.70），而是**分项不一致**：

- LeNO 在 **Attribution 上更好**（0.54 vs HyperNoise 0.53）
- HyperNoise 在 **Position 上大幅更好**（0.48 vs LeNO 0.41）
- LeNO 的 **Position 几乎没动**（0.40 → 0.41，+0.01）

即：**同一个"多奖励"目标，两种摊销方式各自只迁走了不同的一部分能力**。总分 0.70 与 0.71 的差别掩盖了这个分工。

### 4.3 没有明显奖励作弊

作者报告：跨奖励迁移、留出质量指标、训练全程的 **within-prompt 多样性**都保持，未观察到质量/多样性换奖励。这一点很重要——因为"改噪声"最容易的作弊路径就是**把噪声推向让所有奖励模型都喜欢的少数模态**（多样性塌缩），而他们显式监控了它。

### 4.4 蛋白质

奖励是不可微、昂贵的（要设计序列 + 折叠 + 评估），HyperNoise 这类需要梯度的方法**直接不适用**。LeNO 只用标量奖励即可。这是"标量黑盒奖励"这一设定的最强论据。

## 五、局限性

1. **只验证了少步/确定性生成器**。多步随机采样下"初始噪声决定一切"的前提变弱。
2. **奖励仍是代理**。aesthetic/PickScore/ImageReward 都是有偏的偏好模型，论文只证明"没有多样性塌缩"，没证明"人类更满意"。
3. **KL 上界是上界，不是等式**。它约束的是"修正后分布离先验多远"，**不约束"语义是否保持"**——一个把图像改到面目全非但分布仍在先验附近的修正，上界完全允许。
4. **保范投影是技术前提**。换非高斯先验或非保范参数化，上界推导不成立。
5. **单次修正的上限**。2 NFE 拿到大部分收益，但绝对水平仍低于 800 NFE 搜索（1.019 vs 1.421）；要追平必须叠 BoN。
6. 蛋白质任务上与 HyperNoise 不可比（后者不适用），缺少同预算对手。

## 六、复现指南

```
代码：论文为 Preprint，未给出仓库地址（据正文，训练用 Local GRPO + 标量奖励）
主模型：stabilityai/sdxl-turbo
迁移模型：SANA-Sprint (0.6B)
奖励：aesthetic (Schuhmann) / PickScore / ImageReward / HPSv2 / CLIPScore
```

**最小复现（对我们直接有用）**

1. 先复现"**冻结生成器 + 输入端学残差 + KL 上界正则**"这条骨架，把生成器换成一个少步模型即可，奖励换成我们现成的风险分类器分数。
2. $\sigma$ 必须扫：0.05 / 0.1 / 0.2 / 0.5 / 1.0 / 1.5。判据：**σ>1.2 附近若出现增益转负，说明局部信用分配已失效**，这条对我们做 RL 改写时选"扰动幅度"直接可用。
3. 必做状态依赖消融（$\mu(z,c)$ vs $\mu(c)$）。判据：状态无关版本若早期饱和，说明**我们的改写策略如果只依赖 prompt 而不依赖"当前样本的具体风险分布"，同样会饱和**。
4. 必须监控 within-prompt 多样性。这是"改噪声/改 prompt"最容易被忽略的作弊通道。

**别照搬的地方**：本文的"保真"完全由 KL 到先验来定义。我们的"语义保真"是**意图保持**，不是**分布接近**——这两者可以背离（见下）。

## 附：与业务的三条硬对应

1. **这是"不改模型"范式最干净的一份公开证据**。冻结生成器、只在输入端学一个可回滚的映射、奖励是标量黑盒——三条都和我们一致。差别只在于干预变量是噪声而非 prompt。**所以"输入侧热更新"不是一个将就方案，它在公开文献里能拿到与权重侧同量级甚至更好的收益/成本比**（2 NFE 拿到 +34% 奖励，且超过 800 NFE 的推理时搜索）。

2. **保真必须写成"上界"，不能写成"相似度"**。本文的 KL 上界只约束"离先验多远"，明确**不约束语义**；这正是我们现有"CLIP 相似度当保真"的同一个病——它约束的是特征距离，不是意图。可迁移的形式是：**给改写器加一个"相对原 prompt 的分布漂移上界"作为正则项**，并在报表里写清"这个上界约束什么、不约束什么"。

3. **"总分不变、分项一升一降"是这一批工作的共同指纹**。LeNO 与 HyperNoise 在 GenEval 上 0.70 vs 0.71，但 Position 0.41 vs 0.48、Attribution 0.54 vs 0.53。对应我们的改写 AB：**只报三维加权总分，会把"位置/属性这类原子能力被换掉"藏起来**。这已经是本仓库连续多轮出现的同一个结论，这次有了"同一目标、两种实现"的对照版本。
