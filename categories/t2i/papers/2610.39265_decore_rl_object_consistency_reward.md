## 一、背景与问题

### 动机

多图合成（Multi-Image Composition, MICo）——用 2–6 张参考图，按指令合成一张新图，并要求每个参考物体在新图里保持身份。这是电商、虚拟试穿、品牌素材的核心能力，也是"图像一致性奖励"最干净的实验场。

论文的起点是一个**很硬的退化现象**：随着参考图数量增加，一致性断崖式下降。

| 参考图数 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|
| Qwen-Image-Edit2511 得分 | 8.41 | 6.99 | 7.09 | **4.98** | **3.64** |

5–6 张时分数掉到 5 以下，作者的描述是"定性上经常出现 collapse，模型保不住关键属性"。

### 核心判断

**SFT 只能给隐式监督。** 整体图的一致性是一个标量，模型不知道"是哪个物体没保住"。所以论文做了一件事：**把整体一致性拆成物体级一致性**，每个物体单独打分、单独回传。

> 论文原话大意：分解使每个必需物体的显式可测成为可能，缺失检测直接给零奖励，而不是依赖一个不可分割的整体分数。

这句话对我们做 RL 改写的"图像一致性奖励"是直接的：**整体奖励的一个标量，学不到"保住了 3 个丢了 1 个"和"4 个都保住了但都糊了"的区别。**

### 四条论断

1. 一致性必须**物体级**度量，整体标量不可学。
2. 物体级奖励需要**指令相关的物体集合**（不是图里所有物体）。
3. 奖励模型本身要**训练**（用 CoT 标注的单物体一致性数据），vanilla VLM 奖励信号太弱。
4. RL 能在 SFT 之上继续提升，且越大规模参考图收益越大。

## 二、核心方法

### （1）三阶段

| 阶段 | 做什么 | 关键设置 |
|---|---|---|
| SFT | 在多图数据集上微调 Qwen-Image-Edit2511 | 24,000 steps，32×H800，总 batch 128，lr 2e-5，AdamW |
| 奖励模型训练 | 用单物体一致性标注训 VLM 奖励（CoT 训练） | 见 §3.4 |
| RL 后训练 | **Diffusion NFT**（LoRA r=32，group size 16，lr 3e-4） | 32×H800 |

### （2）物体级奖励怎么算

1. **指令相关物体集合**：从指令 + 参考图中解析出"必须保住"的物体标签 `label_ij`（第 i 张参考图的第 j 个物体）。
2. **参考侧 grounding**：在参考图上用开放词表检测定位物体。
3. **生成侧 grounding**：在生成图上用 Grounding DINO 按同一 label 检测，取 top-1 框，裁剪出 G_ij。
4. **单物体打分**：把 (参考裁剪 R_ij, 生成裁剪 G_ij) 送进训练过的单物体一致性奖励模型。
5. **缺失惩罚**：如果物体在参考图有、生成图检测不到，**奖励直接记 0**。
6. **聚合**：S = (1/N) Σ s_ij，N 为有效参考物体数。

### （3）奖励聚合的写法

$$s^{ij} = \begin{cases} s_{obj}(\text{Resize}(R^{ij}),\text{Resize}(G^{ij})) & G^{ij} \neq \varnothing \\ 0 & \text{otherwise}\end{cases}$$
$$S = \frac{1}{N}\sum_{i,j} s^{ij}$$

**注意这里是算术平均，不是几何平均。** 一个物体丢失记 0，只会把总分拉到 1/N。如果 N=6，丢一个物体只掉 16.7%，模型仍有 83.3% 的奖励可拿。这是个可讨论的设计点（见 §5）。

### （4）为什么奖励模型要 CoT 训

vanilla VLM 直接问"这两个裁剪是不是同一个物体"，给出的分数**分布窄、区分度低**：整体一致性分长期趴在 0.5 以下，训练曲线几乎不动。用 CoT 训过的 VLM，分数稳定在 0.6 以上且随训练稳步上升。

## 三、技术细节

### 三个可验证的量

| 量 | 数值 | 含义 |
|---|---|---|
| vanilla vs 训练过的奖励 | 7.21 vs **8.16**（SFT 基线 7.05） | 奖励模型质量决定 RL 是否有效 |
| 6 张参考图 | 6.15 → **7.61** | 越难的地方 RL 收益越大 |
| 2 张参考图 | 8.41 → SFT 8.34（**掉**）→ 8.91 | SFT 在简单档反而退化，RL 才修回来 |

### "banned prompt"这个监控指标（值得单独记）

论文的 Figure 5 里有一条曲线叫 **banned prompt count**：一个 prompt 的样本如果已经拿到**又高又相似**的奖励，说明这个奖励信号已经被学会，就把该 prompt 从训练池里退役。

- vanilla 奖励：banned 数**恒为 0**（因为分数一直趴着，从没"学会"）
- 训练过的奖励：banned 数**随时间上升**

**这不是 reward hacking 指标，正好相反**——它是"课程进度"指标：衡量有多少 prompt 的奖励信号已经饱和。对我们 RL 改写有直接用途：**如果 banned 数长期为 0，说明奖励根本没被学进去，别调 loss 先查奖励**。

> 注意区分：昨天 Kling 那篇讲的是"接上生成器后保真掉"，那是奖励与目标错位；这篇的 banned 数讲的是"奖励可学性"。两者是两个不同的失效面。

### Table 3：RL 拿什么换了什么（本文最该记住的一张表）

| 指标 | base | + SFT | + DeCoRL | RL 相对 SFT |
|---|---|---|---|---|
| Prompt Following (PF) | 6.1495 | 8.7586 | **8.6865** | **−0.072（−0.8%）** |
| Subject Resemblance (SR) | 5.2378 | 7.0080 | **7.6393** | **+0.631（+9.0%）** |
| Naturalness | 5.0817 | 6.5355 | **8.0123** | **+1.477（+22.6%）** |
| Artifacts | 4.1208 | 5.7574 | **6.6362** | **+0.879（+15.3%）** |

**这张表才是重点。** 加 RL 之后：

- 主体相似度 +9.0%
- 自然度 +22.6%
- 瑕疵 +15.3%
- **指令遵循 −0.8%**

和昨天 Kling 那篇的"保真 4.45 → 4.38"是同一个现象：**用视觉/一致性奖励做 RL，会稳定地吃掉一点指令遵循。** 这次价码更便宜（0.8% 换 9%+22.6%），但方向一致。

### Table 4：奖励模型质量的决定性

| 奖励 | 2 | 3 | 4 | 5 | 6 | Overall |
|---|---|---|---|---|---|---|
| + SFT（无 RL） | 8.34 | 7.35 | 6.80 | 6.60 | 6.15 | 7.05 |
| + vanilla VLM 奖励 | 8.54 | 7.49 | 6.42 | 6.90 | 6.78 | 7.21 |
| + 训练过的 VLM 奖励 | 8.91 | 8.36 | 8.05 | 7.88 | 7.61 | **8.16** |

**vanilla 奖励只比不训 RL 高 0.16（+2.3%），训练过的奖励高 1.11（+15.7%）。** 差了将近 7 倍。

这条对我们的含义非常直接：**"接个 VLM 当奖励"这条路，用现成 VLM 基本无效，必须训。** 而"训奖励"的成本远低于"训生成模型"——这是一条算力受限下性价比最高的投入。

### 五个必须单独拎出来的数

1. **22.90 → 37.58 → 54.03**：MICo-Bench 上 SFT 拿 15 点，RL 再拿 16 点。**RL 的增量与 SFT 同量级**，说明 SFT 学不会的那部分确实需要奖励信号。
2. **3.64 → 7.61**（6 参考图）：baseline 最崩的地方，RL 涨幅最大（+109%）。难例上的收益远大于简单例。
3. **8.41 → 8.34**：SFT 在 2 图档反而**退步** 0.07。SFT 会在简单档过拟合多图模式。
4. **7.21 vs 8.16**：奖励从 vanilla 换成训练过的，涨了 0.95，比 SFT 带来的 0.83 还多。
5. **7.61 vs 8.69**：仍落后 Nano-Banana-Pro 1.08。开放式路线在"最少参考也最准"上仍输闭源。

## 五、局限性

1. **只测一致性，不测安全**：整篇没有风险类目、没有 NSFW、没有政策判定。一致性奖励与安全奖励是两个目标，直接迁移需要重做奖励定义。
2. **算术平均聚合**：丢失一个物体在 N=6 时只掉 16.7%，模型可以用"5 个极好 + 1 个丢掉"换高分。几何平均或 min 聚合会更严格（参见我们 10-29 的 E1 建议）。
3. **奖励依赖 grounding 质量**：Grounding DINO 检不到就记 0，等于把检测器的漏检直接变成训练噪声。
4. **算力门槛**：32×H800 做 SFT 与 RL。我们 5 节点做不到这个规模，只能做 LoRA 级复现。
5. **MICo 是小众任务**：多图合成的结论能否外推到"单图编辑的一致性"未验证。
6. **未报失败案例的比例**：定性图只给了成功例。

## 六、复现指南

### 最小复现路径（按对我们的价值排序）

1. **把"整体一致性"换成"锚点级一致性"**（零训练，半天）。现在 I2I 改写评估大概是"整图相似度"一个分。改成：主体锚点/操作锚点/目标区域锚点各一个分，任一锚点缺失记 0。看 0/0% 的样本里，是三个锚点全丢，还是只丢一个。
2. **训一个小奖励模型，别用现成 VLM**（有算力再做）。论文的 7.21 vs 8.16 说明这一步不能省。数据用"单锚点一致性标注"，CoT 格式，规模不用大。
3. **加 banned prompt 计数监控**。RL 训练时统计"奖励已饱和（高且方差小）的 prompt 数"。长期为 0 ⇒ 奖励不可学，停下来查奖励，别调超参。
4. **聚合方式对照**：算术平均 vs 几何平均 vs min，同批样本三版对照，看排序翻转率。这直接对应我们 10-29 的 E1。

### 关键超参

| 参数 | 取值 |
|---|---|
| SFT | 24k steps, batch 128, lr 2e-5, 32×H800 |
| RL | Diffusion NFT, LoRA r=32, group size 16, lr 3e-4 |
| 奖励聚合 | 算术平均，缺失记 0 |

## 附：与业务的三条硬对应

1. **为 RL 改写的"图像一致性奖励"提供了可落地的分解方式**：不要一个整体分，要"锚点级分数 + 缺失记 0"。这比整图 CLIP 分数更能定位"改写抹掉了什么"。
2. **给出了 RL 用一致性奖励换指令遵循的实测价码**：−0.8% PF 换 +9.0% SR。和 Kling 的 −1.6% 保真互为印证——**这个交换是结构性的，不是调参能消掉的**，所以三维评测必须把"指令遵循"单列，且不能被其他两维补偿。
3. **"奖励必须训、不能直接用现成 VLM"这条直接对上 5 节点算力现实**：训一个小奖励模型（几亿参数级）比训生成模型便宜一到两个数量级，是当前算力下最值得投的一笔。
