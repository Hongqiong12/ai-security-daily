## 一、背景与动机

### 表面问题与真实问题

HealBench 研究的不是 NSFW，而是"心理舒适度"（psychological comfort）——一个看起来离我们业务很远的维度。**但它的方法骨架与我们的问题是同构的**，这才是这篇值得精读的原因。

论文的核心观察：

> 一个图像可以既**语义对齐**、又**视觉精致**，却仍然在目标维度上失败。

对我们来说，这句话的直接翻译是：

> 一个改写后的 prompt 可以既**语义保真**、又**指令遵循**，却仍然在**安全维度**上失败（或反之）。

也就是说：**对齐 ≠ 质量 ≠ 目标维度**，三者必须分开测。这是三维评测的设计前提。

### 现有评测的三个缺口

| 缺口 | 表现 |
|------|------|
| 聚合分数掩盖维度失效 | 总分高的模型可能在某单一维度很差 |
| 缺目标维度 | Pick-a-Pic / T2I-CompBench / NTIRE 都测偏好、组合、质量，不测目标任务维度 |
| 反馈不可执行 | 只给分不给理由，无法反过来改 prompt |

HealBench 的对策是三条：**细粒度诊断维度 + 类别感知问题集 + 带 rationale 的反馈**。

### 与已有 benchmark 的位置

| Benchmark | 会议 | 范围 | 细粒度 | 目标维度专属 | 可优化 |
|-----------|------|------|--------|--------------|--------|
| Pick-a-Pic | NeurIPS'23 | T2I | ✗ | ✗ | 有限 |
| T2I-CompBench | NeurIPS'23 | T2I | ✓ | ✗ | ✗ |
| HATIE | CVPR'25 | Editing | ✓ | ✗ | 有限 |
| ICE-Bench | ICCV'25 | T2I+Edit | ✓ | ✗ | ✗ |
| **HealBench** | **AAAI'27** | **T2I+Edit** | **✓** | **✓** | **✓** |

## 二、核心方法

### 2.1 数据：30K 规模 + 92 子类

| 项 | 值 |
|---|---|
| 规模 | **30,000** 高质量图文对（从 100,000 候选中筛出） |
| 类目 | **19 大类 / 92 子类**，按"疗愈功能"归为 **6 个功能组** |
| 构造流程 | VLM 语义匹配 → 多个人类偏好模型 → 专家过滤 → 代表性样本引导增强 |
| 评测集 | **HealBench-Eval：1,095 例**（SigLIP 嵌入 + K-means 聚类选代表，保持整体分布） |
| 增强 | 每类取 HealScore top-10 与 reward-model top-10，用 Claude 重写 caption，再用 SD3.5-Large 合成 |

⚠️ 注意那个"用 Claude 重写 caption 再造图"的步骤——**这本身就是一个合成数据增强的样例：改写 caption 而不改语义，用于扩充训练集**。与我们的改写数据构造同源。

### 2.2 三维评分与 1:2:1 加权

每个（大类, 子类）对构造一套**类别感知问题集**：

$$\mathcal{Q}_c=\{q^c_{d,k} \mid d\in\{\text{sem},\text{heal},\text{qual}\},\ k\in\{0,1,2\}\}$$

- $q^c_{d,0}$：粗粒度问题（该类目的一般性）
- $q^c_{d,1},q^c_{d,2}$：细粒度补充问题（具体视觉/情感线索）
- 由 LLM 起草，**专家修订**去掉模糊、冗余、类目错配的题

每个问题 1–10 分，同维度求和：

$$s_d(I)=\sum_{k=0}^{2} r_{d,k}(I)$$

**总结分（关键设计）：**

$$\text{HealScore}(I)=s_{\text{sem}}(I)+2\,s_{\text{heal}}(I)+s_{\text{qual}}(I)$$

**目标维度（heal）权重是 2，两个支撑维度（sem / qual）各为 1。**

> 论文的原话是："1:2:1 的权重不是为了让总分好看，而是为了在诊断解释时**不掩埋失效的维度**。"

⚠️ **这是本文对我们最有价值的一条工程约束。** 我们做三维评测（语义保真 / 安全提升 / 指令遵循）时，如果三项等权相加，一个"安全提升 10 分但语义掉 10 分"的 rewriter 会被判成"没变化"。正确做法是：**目标维度加权加倍 + 三个维度分列报告，不允许只看总分。**

### 2.3 THS：从规则评分蒸馏出可训练 scorer

- 骨干：**BLIP 图文匹配**
- 融合表征：$h=[v;t;v\odot t]$（拼接 + 逐元素乘）
- 三个独立 MLP 头分别预测三个维度分
- 损失：$\mathcal{L}=\mathcal{L}_{\text{dim}}+\lambda\mathcal{L}_{\text{total}}$，其中 $\mathcal{L}_{\text{total}}$ 保证三维度与总分自洽

**为什么要这一步？** 因为规则 HealScore 需要 LLM 逐题打分，太贵。THS 把它蒸馏成一个前向一次的小模型，才能进 RL 奖励回路。

## 三、技术细节

### 3.1 数据筛选的多信号融合

构造阶段用了 4 个归一化信号的加权和做初筛：

$$r_{\text{overall}}=\tilde r_{\text{clip}}+\tilde r_{\text{aes}}+\tilde r_{\text{pick}}+\tilde r_{\text{hps}}$$

（CLIP 相似度 / LAION 美学 / PickScore / HPSv3）

再在每个细粒度子类内取 **top 33%**，兼顾质量与类目多样性。

⚠️ **这里有个反讽**：初筛用了四个通用 scorer 的加权，但后文 Table 6 证明这四个 scorer 在目标任务维度上几乎无效（Acc 0.50–0.56）。**初筛能用它们，评测不能。** 这个区分很重要。

### 3.2 评测规模

- 14 个代表性 T2I 模型
- 3 个子研究：客观评测 / 主观评测 / prompt-rewriting 干预 / THS 自动评分 / RL 微调
- 人类偏好对：1,500 对

## 四、实验与结果

### 4.1 HealScore 本身靠不靠谱（先看这个）

与人类偏好排序的一致性（1,500 对）：

| 排序来源 | Accuracy | Kendall's τ | Spearman's ρ |
|----------|----------|-------------|--------------|
| Claude-Haiku | 0.6831 | 0.3546 | 0.4319 |
| Claude-Sonnet 4-6 | 0.6933 | 0.3868 | 0.4711 |
| **人类** | **0.8012** | **0.4487** | **0.5448** |

⚠️ **必须诚实读这个数**：HealScore 与人类两两偏好的一致率是 **80.12%**，τ 只有 **0.4487**。也就是说**这个指标本身有天花板**——它不是一个"客观真理"，而是一个"比 VLM judge 更接近人类、但仍显著低于 100%"的近似器。

对做评测的人来说，这个诚实度值得学：**先报指标自身的人类一致率，再报用它测出来的模型分数。**

### 4.2 三维分离的证据

| 模型 | Text-Image 对齐 | Image Quality | **Heal Accuracy** |
|------|-----------------|---------------|-------------------|
| Playground v2.5 | 6.479 | 6.422 | **6.094** |
| SD 3.5 Medium | 6.321 | 6.075 | **5.884** |

两个强模型在"对齐"和"质量"上都 > 6.0，但在目标维度上掉到 **5.9–6.1**，且方差更大。

**结论：感知目标维度无法从对齐或质量推断出来。** 这直接支持"三维必须分列"。

### 4.3 类目级难度不均

- 最容易：Living Companionship（Sana-1.6B 29.624 / FLUX.1[dev] 29.759 / SD3.5 Large 29.057）
- 最难且模型依赖最强：**Shelter and Safety**、**Natural Restoration**
- **没有任何模型在全部 6 个功能组上占优**

### 4.4 prompt rewriting 作为干预（本文与我们最相关的一段）

**结论一：改写对**所有**被测 T2I 模型都有效**——Hunyuan-DiT、FLUX.1[schnell]、SD3.5 Large、SD3.5 Medium 全部提升，**增益最集中在目标维度（Heal Accuracy）**。

**结论二：改写对图像编辑同样有效**——Pix2Pix 与 SDXL-Pix2Pix 在总分与全部三个维度上都提升。

**结论三：改写的输入是"分数 + rationale"**，不是分数本身。这是它能改对 prompt 的原因——**反馈必须可执行**。

⚠️ **对我们的直接映射**：我们做 NSFW 风险改写时，如果只给 rewriter 一个"风险分"，它学不到"哪一段语义触发了风险"。HealBench 的做法是给**维度分 + 理由**，让改写有落点。这与昨天 PPAA/DSC 的"落到锚点"是同一个方向。

### 4.5 通用 scorer 在目标维度上基本失效（Table 6）

| Scorer | Accuracy | Kendall's τ | Spearman's ρ |
|--------|----------|-------------|--------------|
| PickScore | 0.5593 | 0.1525 | 0.2254 |
| LAION Aesthetic | 0.5507 | 0.1077 | 0.1595 |
| CLIPScore | 0.5413 | 0.1272 | 0.1882 |
| HPSv3 | 0.5013 | 0.0379 | 0.0595 |
| **THS（本文）** | **0.8527** | **0.7741** | **0.9223** |

**通用 scorer 全部贴近随机（0.50–0.56）。** 任务专属 scorer 到 0.8527。

⚠️ **直译到我们的 RL 改写**：如果奖励直接用 CLIP 相似度或通用 IQA 模型，**奖励信号里几乎不含有目标维度的信息**。我们在用 Qwen-Image 一致性做奖励——这属于"语义一致性"维度，**不含"安全性"维度信息**。必须补一个风险专属的 scorer 头。

### 4.6 THS 当奖励：Flow-GRPO 微调

SD 3.5 Medium 用 THS + CLIPScore 加权奖励做 Flow-GRPO：

| 指标 | Base | + Flow-GRPO |
|------|------|-------------|
| Overall | 24.16 | **25.67** |
| Semantic | 6.32 | 6.48 |
| **Heal** | 5.88 | **6.45** |
| Quality | 6.08 | 6.28 |

**增益最大的是目标维度（Heal +0.57），Semantic/Quality 只小幅上升。** 这说明奖励信号确实是"定向"的，没有一锅端。

⚠️ **口径提醒**：论文正文在叙述这段时出现过 "Overall 23.47 → 25.67" 的写法，与 Table 7 的 "24.16 → 25.67" 不一致。本文按 Table 7 取值，并标注此处存在正文/表格口径差异。

## 五、局限性

1. **指标自身天花板**：HealScore 与人类偏好 Acc 仅 0.8012、τ 0.4487，作为"评测标准"仍偏软。
2. **"heal accuracy" 是感知疗愈度，不是临床疗效**，作者明确声明不可外推为医学结论。
3. **类目体系是为"疗愈"设计的**（19/92），与内容安全类目无对应关系，**不能直接搬标签**，只能搬方法。
4. **THS 依赖 BLIP 骨干 + 类别文本输入**，换域需要重训；跨类别泛化未验证。
5. **RL 实验是"exploratory"**，只跑了一个基座（SD3.5 Medium）、一个配置，无多种子方差。
6. **数据增强用 SD3.5-Large 合成**，存在合成数据自我循环（模型评自己生成的图）。

## 六、复现指南

### 6.1 资源与规模

```
数据：HealBench 30K 图文对 + HealBench-Eval 1,095 例（论文署名 AAAI'27，数据集将随论文发布）
评测脚本：三维问题集按（大类, 子类）生成，需 LLM + 专家两段
THS 训练：BLIP backbone + 3 个 MLP 头，AdamW，backbone 与 head 分学习率
RL：SD3.5 Medium + Flow-GRPO，奖励 = w1·THS + w2·CLIPScore
```

### 6.2 我们该复现什么（最小集）

不要复现数据集。复现它的**三个结构决策**：

| 决策 | 我们的对应动作 | 成本 |
|------|----------------|------|
| 三维分列 + 目标维度 1:2:1 | 评测表改成三列分别报（语义保真 / 安全 / 指令遵循），**禁止只报总分** | 改表头，0 成本 |
| 任务专属 scorer 取代通用 scorer | 训一个"风险锚点命中"专用头（输入 = 改写前后对 + 原图），替代 CLIP 相似度单奖励 | 中等 |
| 反馈带 rationale 再改写 | rewriter 的输入从"风险分"改成"风险分 + 触发的锚点 span + 一句理由" | 小 |

### 6.3 复现风险点

- 三维问题集需要领域专家修订，纯 LLM 生成的问题会有类目错配；
- THS 的 $\lambda$ 平衡项敏感（论文未给具体值），需自行扫；
- 1,095 例 Eval 集规模偏小，单模型分数波动需报置信区间。
