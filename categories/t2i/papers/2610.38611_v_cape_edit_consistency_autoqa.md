# 编辑"改对了没有"这件事，人类 κ=0.77 判得动，VLM 上限只有 65%

**论文主页**: https://arxiv.org/abs/2610.38611
**领域**: I2I 指令式编辑的自动质量评估（AutoQA）/ 视觉一致性判定 / 细粒度失效模式分类学
**作者**: Iaroslav Melekhov†, Roberto Alcover-Couso†, Francesco Taioli, Daniel Coelho, Artur Bekasov, Virginia Fernandez Arguedas, Jose Miguel Grande Saiz（†同等贡献，Amazon）
**机构**: **Amazon**
**发布日期**: 2026-10-28（v1，cs.CV）
**分类**: benchmark
**模态归属**: T+I2I 指令式图像编辑 · **对齐 I2I 改写分流 0/0% 的判定侧缺口**

## 一、背景与问题

### 动机

生成式编辑已经能做背景替换、物体增删、姿态调整、虚拟试穿、重打光。但**验证这些编辑有没有破坏原物的内在属性**——几何、纹理、颜色、细粒度细节——基本还是个未解问题。

Amazon 的动机非常具体：电商产品图要从"生活场景图"（lifestyle）批量改成"影棚图"（studio：干净背景、无杂物、标准姿态）。这个转换在规模上做，人工抽检不可能。所以他们把这件事形式化成 **AutoQA**：

> 给定源图与编辑后的图，判定这次变换是否保持了原物的视觉一致性。

### 为什么这篇对我们直接命中 0/0%

我们现在的 I2I 改写分流是 **0/0%**——分流器一条都没命中。过去三轮我们一直在问"是改写坏了，还是编辑模型能力不足"。这篇论文给出了第三个选项，而且是最该先排除的那个：

> **可能是判定器根本判不动。**

论文的证据链很硬：

- 人类标注者三人多数表决，**Fleiss κ = 0.77**——**任务本身是良定义的**，人类判得动；
- 所有被测 VLM（4B 到 235B，开源 + 闭源）**准确率全部低于 65%**；
- 细粒度失效模式（纹理、光照、背景、色彩/材质）上，**所有模型接近随机**；
- Auto-prompt（IPC 迭代优化 prompt）只带来 **+3–5 点**，且对最强模型边际收益趋零。

⇒ **这不是"我们的改写不好"，也不是"编辑模型不行"，这是一个被判据本身卡住的任务。**

### 它同时还是"图审双模型 AB 评测"的一个现成反例

我们的旁路图审 AB 一直在比"两个模型哪个判定更准"。这篇说明：在一个**细粒度判定**任务上，比总准确率会得出完全错误的结论——Qwen3-8B 零样本在 V-CAPE-R 上是 **51.5% 准确率但 F1 只有 6.7%**。准确率看着像"接近随机"，其实是**退化成全部预测同一类**。F1 6.7% 才是真相。

## 二、核心方法

### （1）任务定义：AutoQA 四元组

每个样本是一个四元组：

```
(source image, ground-truth reference (可选), 编辑后图, 结构化的拒绝理由)
```

判定：`y ∈ {0,1}`——是否保持视觉一致性。

关键设计：**不止二分类，还给结构化的拒绝理由（rejection reason）**。这是本文对我们最有迁移价值的部分——它把"改错了"拆成可归因的几类，而不是一个笼统的 0。

### （2）两个互补子集

| 子集 | 规模 | 来源 | 用途 |
|---|---|---|---|
| **V-CAPE-R** | 20K 对（男女各半 50/50） | 真实电商 sofa 类目，经生成式编辑管线产出 | 真实性——反映实际部署会遇到的失效 |
| **V-CAPE-S** | 20K 对（50/50） | **ABO 3D 资产** + Blender 渲染，19 个额外类目 | 可控性——姿态/身份/外观可精确操纵 |

合计 **40K 源—目标对 / 27K 唯一图像**。

**V-CAPE-R 的生成管线（三阶段）**——这段设计值得细看，因为它把"选源图"从"生成"里拆了出来：

1. **Image Sourcing**：定义 `I* = S(𝓘, c)`，按与目标规格 `c` 的兼容性给候选图排序，选最合适的一张。理由写得很直白：**有遮挡、布局复杂、视角不利的源图会导致不可靠的生成**。把选图与生成解耦，鲁棒性立刻就上来了。
2. **Image Generation & Editing**：`Î = G(I*, p(c))`。这里用了**分阶段编辑**——先做外观归一化（清背景），再做几何变换（姿态对齐），**不混在一次编辑里**。理由是减少 artifact。
3. **Quality Assessment**：`y = Q(Î, r)`，人工在环，按预先定义的质量要求 `r` 判 0/1，并给结构化拒绝理由。

**V-CAPE-S 的负例构造**（这是它能做细粒度归因的原因）：不是等模型自己犯错，而是**主动构造三类受控负例**——

- 姿态错误；
- 类目不对；
- 同类目但**instance 不对**（同一个沙发类目下的另一件商品）。

这三类恰好要求模型分别推理**几何、语义、身份**三个层面。

### （3）标注协议

- **3 名独立标注者**判每张图（给源图 + 可选参考图 + 输出图）；
- 最终标签 = **多数表决**；
- **5 轮对齐训练**（同一批受训标注员池）；
- **Fleiss κ = 0.77**。

κ=0.77 这个数字是本轮所有论文里最高的一个"人类一致性"读数，也是本文全部论证的地基：**如果人类一致性只有 0.4，那 VLM 65% 就不能算失败**。0.77 说明任务清晰，VLM 就是不行。

### （4）拒绝理由分类学

| 子集 | 拒绝理由 |
|---|---|
| V-CAPE-R（6 类 + 1 通过类） | 几何失真 · 姿态错误 · 无关物体 · 背景不一致 · 纹理偏差 · 颜色/材质偏差 · （accept） |
| V-CAPE-S（3 类 + 1 通过类） | 姿态错误 · 类目错误 · instance 错误 · （accept） |

**这套分类学直接可以搬到我们的 I2I 分流输出**：现在我们的分流是"改写/不改写"二分（结果 0/0%），如果输出改成这 6+1 类，0/0% 立刻变成 7 个数。

## 三、技术细节

### 被测模型（四档规模）

| 档位 | 模型 |
|---|---|
| **small（4–8B）** | Qwen3-8B, Gemma 3, Gemma 4-4B, Mistral 3-8B |
| **medium（14–32B）** | Qwen3-32B, Gemma 4-31B, Mistral 3-14B |
| **large（128B+）** | Qwen3-235B |
| **proprietary（n/a）** | Claude（Sonnet / Haiku / Opus）, Nova（Lite 2 / Pro） |

全部走原生多模态或 chat 接口，**同一套图像输入、同一套输出解析**。

### 两种 prompting 制度

| 制度 | 做法 |
|---|---|
| **baseline** | 简明 prompt，描述任务 + 列出质量准则 |
| **auto-prompt** | 用 **Intent-based Prompt Calibration (IPC)** 迭代精化——用少量已标样本 + 自动合成困难边界样本 |

这个对照设计的目的不是"调好 prompt"，而是**证伪"只要 prompt 写对就行"这个假设**。

### 少样本 LoRA 微调

这是全篇对我们最实用的一个实验设计：

- 骨干：**Qwen3-VL-8B-Instruct**，LoRA；
- 采样：**分层**——每个拒绝理由类别取 N 条 + N 条 accept（N ∈ {1,5,10}）；
- 规模：V-CAPE-R 有 6 拒绝类 + 1 通过类 = 7N；V-CAPE-S 有 3 + 1 = 4N；**合计 11N** ⇒ 训练集只有 **11 / 55 / 110 条**；
- 固定随机种子 + 记录 index manifest，**严格排除出评测集**；
- **训练样本的 assistant 轮不是只给标签，而是给"五步推理协议 + CoT 理由"**：

```
五步协议：
 1. 识别产品类目
 2. 检查材质与颜色一致性
 3. 核对结构部件数量
 4. 评估配置与设计特征
 5. 检测违禁元素
```

这个"consistency prompt"设计的意图写得很明确：**让模型学一套结构化的评估程序，而不是记住表面模式**。

### 额外的独立探针：零样本朝向分类

AutoQA 里姿态/朝向是核心难点，所以作者把它**单独拆出来**测：

- V-CAPE-S：3 类（left / right / front）；
- V-CAPE-R：原标签（LEFT/RIGHT/FRONT/CORNER/OTHER）折成二分类（侧视 vs 正视）；
- 三类模型族对比：**对比式视觉语言模型**（CLIP / SigLIP2 / EVA-02-CLIP，用文本原型余弦）、**自监督视觉编码器**（DINOv2 / EUPE，最近质心）、**朝向专用模型**（OrientAnything / V2）。

这个探针的价值：**把"判定"和"感知"分开**。如果朝向都识别不准，那 AutoQA 失败就不是决策逻辑问题，是底层感知问题。

## 四、实验与结果

### 主结果：没有模型过 65%

| 指标 | 范围 |
|---|---|
| accuracy | 近随机（~50%）→ **63.5%** |
| F1 | 55% → **67%** |
| 所有规模档 | **accuracy 全部 < 65%** |
| auto-prompt（IPC） | **+3–5 点**，最强模型边际收益趋零，**部分情况无提升** |

并且观察到**退化行为**：若干模型出现"近全域拒绝"或"近全域接受"。

### 按拒绝理由拆：一条清晰的难度梯度

| 拒绝理由 | 最强模型的召回 |
|---|---|
| 几何失真 / 类目错误 / instance 错误（**粗粒度**） | 尚可恢复 |
| 纹理 / 光照 / 背景 / 色彩·材质（**细粒度**） | **全场接近随机** |

论文的表述：`a perceptual-fidelity gap that scale alone does not close`。

⇒ **这条梯度是我们做 I2I 要件分档的直接依据**：不要按 Operation 分档（加/删/换/风格），要按**"这个要件是不是细粒度视觉属性"**分档。粗粒度要件能判，细粒度要件判不了。

### 少样本微调：准确率几乎不动，F1 动了 56 个点

| 配置 | V-CAPE-R Acc | V-CAPE-R F1 | V-CAPE-S Acc | V-CAPE-S F1 |
|---|---|---|---|---|
| Qwen3-8B 零样本 | .515 ± .003 | **.067** ± .003 | .484 ± .003 | **.079** ± .002 |
| + N=1（11 条） | .521 ± .002 | .601 ± .004 | .532 ± .002 | .624 ± .003 |
| **+ N=5（55 条）** | **.529** ± .003 | **.628** ± .003 | **.551** ± .004 | **.683** ± .003 |
| + N=10（110 条） | .527 ± .003 | .617 ± .002 | .543 ± .002 | .681 ± .003 |

四个读数，每一个都值得单独记：

**第一：零样本 F1 = 6.7%，而准确率 = 51.5%。**
这是"退化"的教科书式读数——模型在**全部预测同一类**。如果只看准确率，会得出"接近随机但还行"的结论；F1 6.7% 才暴露真相。

⇒ **我们的图审 AB 评测如果只报 accuracy，就会把"全判 PORN"和"真的会分"混成同一个分数。** 必须并列 macro-F1。

**第二：11 条样本就把 F1 从 6.7% 拉到 60.1%。**
这几乎不是"学到了判定能力"，而是**学到了"不要全判一类"**。⇒ 少样本 LoRA 在退化基线上的增益，绝大部分来自**恢复类别先验**，不是恢复细粒度感知。这一点论文没点破，但从 N=1 就能到 0.601 这个数字能直接推出来。

**第三：N=5 最好，N=10 反而略降。**
55 条 → 110 条，V-CAPE-R 从 .529/.628 掉到 .527/.617，V-CAPE-S 从 .551/.683 掉到 .543/.681。论文的解释是：**不同缺陷类型之间所需的视觉准则可能相互冲突，样本一多引入异质例子反而互相干扰**。

⇒ 这条对我们很重要：**"补数据"不是单调收益**。如果我们的 PORN/VULG 边界样本补进去以后效果不动，可能不是"补得不够多"，是**补的这批之间准则冲突**。

**第四：V-CAPE-S 一致高于 V-CAPE-R。**
合成缺陷的视觉模式更系统、更好学；真实世界的质量问题更杂、更依赖语境。⇒ **用合成数据训图审会高估真实表现**，这个偏差在 few-shot 下最大（F1 差 5.5 点）。这一点我们在做"图审数据合成"时必须记住。

### 零样本朝向分类

单独拆出来的探针显示三类模型族在朝向识别上的分化（对比式 VLM / 自监督编码器 / 朝向专用模型），论文的结论是**姿态理解本身就不过关**，所以 AutoQA 的失败不能全归给决策逻辑。

## 五、局限性

1. **任务范围窄。** 只做了一类变换（lifestyle → studio），只做了**沙发**一个产品类目（V-CAPE-R）。论文自己列为 outlook 第一条。⇒ 65% 这个上限不能直接外推到所有编辑类型。
2. **V-CAPE-S 的负例是"构造的"，不是"模型自然犯的"。** 姿态错/类目错/instance 错这三类，跟真实部署里模型犯的错**分布不同**。
3. **无 judge 间一致性。** 三个标注者给了 Fleiss κ=0.77，但 AutoQA 只用了 VLM 直接判（没有 LLM-judge 层），所以不存在"judge 之间打不打架"的问题——**代价是没有可扩展的自动标注路径**。
4. **零样本朝向分类的三个模型族结果没有给出可比的统一数字**（Figure 6 只给了柱状图均值±std，正文没有逐模型表格）。⇒ 数字纪律：这里不做数字外推。
5. **F1 的跳变被归因为"学到了准则"，但没做消融。** N=1 就把 F1 从 6.7% 拉到 60.1% 这件事，论文没有解释（也没测"只训 accept 类"或"只训一个拒绝类"的对照）。⇒ 这个 60.1% 到底来自"恢复类别先验"还是"学到准则"，**论文没分清**。我在第四节给的判断是推论，不是论文结论。
6. **"结构化拒绝理由"的判定准确率没有单独报。** 论文说了有这套标注，但主表只报二分类。⇒ 那套分类学的实际可判定性**未被测量**。这对我们想直接搬来用是个风险。
7. **全部为单轮、单指令编辑。** 多轮编辑中的一致性累积失效（EditAgent 那篇的核心问题）没有覆盖。

## 六、复现指南

### 数据获取

- V-CAPE-R 的图像来自公开电商 listing，论文称**已取得源平台版权授权以释放数据**；
- V-CAPE-S 基于 **ABO（Amazon Berkeley Objects）数据集，CC BY 4.0**，公开可用：`https://amazon-berkeley-objects.s3.amazonaws.com/`；
- 数据集本身释放状态论文未明说（无 "will be released" 表述）。**V-CAPE-S 可以完全自行重建**（ABO 3D 资产 + Blender API + 1024×1024 渲染 + 前/左/右三视角）。

### 最小可复现路径（给我们自己用，1 天）

**目标不是复现数据集，是复现那个"判定上限"的诊断。**

```
Step 1  抽 200 条 I2I 三元组 (源图, 编辑指令, 输出图)
        —— 用我们自己链路上已经产出的真实样本，不要造
Step 2  3 名标注者独立判 "这次编辑改对了吗"
        —— 判据只有一条：指令要求的内容变化是否发生，且无关部分是否保持
Step 3  算 Fleiss κ
        —— 对标 0.77
Step 4  让当前 judge（同一份 prompt、同一版本）判同一批
Step 5  算 judge 与人工多数表决的一致率 / macro-F1
```

**判据表（这一段是本文对我们的全部价值）：**

| 人类 κ | judge 一致率 | 结论 | 下一步 |
|---|---|---|---|
| **> 0.7** | **< 65%** | **任务良定义，judge 能力不足** | **0/0% 是判据问题，改判据，别动改写模型** |
| > 0.7 | > 65% 但分流仍 0% | 判得动但阈值/口径错 | 改分流阈值与输出格式 |
| **< 0.4** | 任意 | **任务本身没定义清楚** | 先写"改对了"的判别要件，改判据之前先改定义 |
| 0.4–0.7 | 任意 | 中度二义 | 补判别维度 + 结构化拒绝理由 |

### 结构化拒绝理由的移植（半天，零训练）

把我们的 I2I 分流输出从"改写/不改写"改成 V-CAPE 式的理由分类：

| 理由 | 含义 | 该不该触发改写 |
|---|---|---|
| 几何失真 | 主体变形 | 否（这是下游编辑能力问题） |
| 姿态错误 | 朝向/角度不对 | 否 |
| 无关物体引入 | 多画了东西 | 视风险 |
| 背景不一致 | 背景被改坏 | 视风险 |
| 纹理偏差 | 细节丢失 | 否 |
| 颜色/材质偏差 | 属性被改 | 否 |
| **意图未实现** | 指令要求的变化没发生 | **是（这是改写的问题）** |
| **意图被抹掉** | 改写后指令不可执行 | **是（这是改写的问题）** |

**只有最后两行是改写侧的责任。** 只要把这两行和上面六行分开统计，0/0% 立刻从 1 个数变成 8 个数，而且能直接看出责任归属。

⇒ 这就是 10-30 记忆里"按要件覆盖分档"的具体实现形式，比我当时写的方案更可操作。

### 需要注意的实现坑

1. **报 macro-F1，不要只报 accuracy。** 零样本 51.5%/6.7% 这个组合是本篇最重要的一个警示。
2. **分层采样要按拒绝理由类别 × accept 类**，不是随机采样。否则长尾理由类根本进不了 few-shot 集。
3. **训练集的 index manifest 必须记录并排除出评测**。40K 对里 27K 唯一图像，源图重复，随机切分一定泄漏。
4. **合成子集（V-CAPE-S）与真实子集（V-CAPE-R）必须分开报。** 合并会把合成数据的系统性优势掩盖掉。
5. **不要用 N=10 那档做结论**。N=5 → N=10 是负收益，说明 55 条左右是这个任务的容量上限附近。

### 一句话结论

> **人类判得动（κ=0.77），模型判不动（<65%）。所以 0/0% 的第一嫌疑不是改写模型，是判据。**
