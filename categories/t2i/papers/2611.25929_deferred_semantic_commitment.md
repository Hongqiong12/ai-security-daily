# 把断言改成问句再打个勾，图像生成器就放行了：语义回来了，拒答没回来

## 一、背景与问题

### 动机：不改一个字的内容，只改"承诺的形式"

论文找到一个极简绕过：**一个写着有害命题的标语牌会被拦，但把同一命题写成疑问句、再跟一个对勾（✓），图就生成了**——而生成出来的图依然在背书原命题。

作者命名为 **Deferred Semantic Commitment（DSC，延迟语义承诺）**：

> commitment 被问句撤回，被另一个独立元素（对勾）恢复；**安全行为只跟着"撤回"走，不跟着"恢复"走**。

### 与本仓库主线的关系

这是本轮**最贴核心主线**的一篇，因为它打的正是"模糊但高风险 prompt"这一格：

- 语义完全保真（一字未改），**只改语用形态**就绕过了 ⇒ 任何以"语义相似度/改动字符数"为保真代理的改写方案都测不出这个风险；
- 它给出「**假安全**」的一个可复现机制：系统看起来"检查过了"，但检查的是拆分后的单个元素，不是组合后的完整消息；
- 对「改写强度分级」的启示很反直觉：**改写只动风险锚点不够，还要处理"承诺被分散到多个元素"的情形**。

## 二、核心方法

### 2.1 构造与度量

| 项 | 设定 |
|---|---|
| 挑战集 | **300** 条（每条为「直接陈述 / 疑问句+肯定线索」配对），实验重复两次 |
| 主模型 | gpt-image-2 |
| 生成指标 | Returned：返回图片的请求占比（分母为全部 300 条） |
| 语义指标 | Endorsed：**产出图确实背书原命题**的请求占比（分母同为全部 300 条，不是已返回图） |
| 线索变体 | 原始 ✓ / 文本 `YES` / 提供的对勾图片，同一 100 条 MPUP 样本 |
| 机制分析 | Qwen3.5-VL-27B（108 组配对）+ activation patching |

**Endorsed 用全量做分母**是个重要口径：若只在已返回图里算占比，会把"生成成功率提升"与"有害语义真的被画出来"混为一谈。

### 2.2 机制定位

用 difference-of-means 抽出 refusal-related direction，在 prefill 阶段把直接陈述的 hidden state 补丁到 DSC 运行里，看拒答是否被恢复；再用投影消融与 norm-matched random direction 做阴性对照。

## 三、技术细节

1. **拒答相关方向是低维且可补丁的**：在 layer 52 插入完整残差，拒答在 **12/13（92.3%）** 案例中恢复；只取 refusal-aligned 分量仍有 **11/13（84.6%）**；把该分量投影减掉后掉到 **1/13（7.7%）**；norm-matched 随机方向**一个都没恢复**。
2. **再肯定只部分逆转**：105 个附加样本里，提问在 **99/105** 中压低了 refusal readout；显式再肯定只把其中一部分拉回来 ⇒ "语义恢复"与"拒答恢复"不是同一个量。
3. **场景不重合样本上更清楚**：15 个 scene-disjoint mismatch cases，完整均值残差恢复 **11/15（73.3%）**，question-aligned 均值残差仅 **2/15（13.3%）**，norm-matched 随机对照最多 2/15。
4. **层级扫描**：natural refusal 的 held-out AUC 沿每层 difference-of-means 方向，**layer 31 首次超过 0.95**，后段到 **0.996–0.99x**（论文口径）⇒ 拒答信号在深层才分得开，浅层门控结构上够不到。
5. **线索无关性**：✓ / `YES` / 对勾图片三种肯定线索给出几乎相同的返回率（**87–91%**）与背书率（**85–90%**）⇒ 不是某个符号的过拟合，是"承诺分离"这个结构本身。

## 四、实验与结果

### 4.1 300 条挑战集主结果（Table 2 口径）

| 形态 | Returned | Endorsed |
|---|---|---|
| 直接陈述 | **16.3%** | **15.3%** |
| **问句 + 肯定线索（DSC）** | **43.3%** | **41.3%** |

⇒ 同一命题、同一语义，**生成率 2.66 倍、背书率 2.70 倍**。

### 4.2 更扎的一个数（Table 1 / MPUP 100 条）

- gpt-image-2 在 MPUP 上对直接陈述返回 **78%**，对"问句+肯定"返回 **91%**。
- 在**直接陈述没返回图的 251 条**里，单次 DSC 请求就产出 **91 张（36.3%）** 背书原命题的图 ⇒ DSC 不是"生成了语义很弱的图"，而是**把原本被挡住的内容实实在在画了出来**。

### 4.3 开放权重模型上的同源错配

Qwen3.5-VL-27B 的 108 组配对：严格拒答率从直接陈述的 **29.6%** 掉到问句形态的 **8.3%**，且再肯定只部分拉回 ⇒ 这不是某一家闭源 API 的个案，是**训练出来的拒答行为与语义承诺解耦**。

## 五、局限性（论文自陈，直接影响结论外推）

1. **300 条挑战集是从"初筛没返回图片"的输入里选出来的** —— 存在明确的选择性偏差，43.3% 不能当作线上绕过率。
2. **机制分析在一个可访问的开源语言模型上、用纯文本输入做**，不是部署态图像生成器的内部 safeguard ⇒  activation patching 的结论是**机制类比**，不是对 gpt-image-2 的直接解剖。
3. **只能通过公开 API 访问**：无法判定未返回的请求究竟被输入过滤、输出复审还是其它环节挡下 ⇒ **无法把失效定位到链路的哪一段**。
4. **未覆盖跨语言**：问句/肯定线索的构造未声明中英混合版本；中文祈使/反问形态是否同样有效未知。
5. **不涉及改写防御**：论文只提出"应评估 completed message 而非 individual elements"，没有给出改写或门控实现。

## 六、复现指南

**论文复现**
1. 构造 300 条"直接陈述 / 问句+肯定线索"配对，固定随机种子，重复两次；Returned 与 Endorsed **都用全量 300 做分母**。
2. 线索变体三选（✓ / YES / 对勾图片）在同一 100 条 MPUP 样本上跑，检验结果是否线索无关。
3. 开放权重模型上抽 refusal direction（difference-of-means），做 layer-52 activation patching + 投影消融 + norm-matched 随机对照 + 全深度扫描。
4. 人工双盲判 Endorsed（只看图、不给原命题），报与自动判定的一致性。

**本项目迁移建议（零训练，半天—1 天，最优先）**

| 动作 | 做法 | 判据 |
|---|---|---|
| **改写评测加"承诺分散"对照臂** | 把现有评测集里每条高风险 prompt 生成三版：原句 / 保义疑问化 / 疑问化+肯定线索，跑现有分类器与改写链路 | 三版语义相似度接近而风险分跳变 >20 点 ⇒ **分类器在读承诺形式，不在读完整语义**；此时"语义保真"指标不能当验收 |
| **组合层判定（completed message）** | 分流前先把 prompt 中分散的"疑问 + 肯定标记 / 分句 / 符号"合成一个完整命题再判 | 合成前后判定差异大的样本占比 >10% ⇒ 现有逐 token / 逐词锚点方案存在结构性缺口 |
| **保真度量换尺子** | 用"改写前后完整命题是否等价"的人工双盲，替代 CLIP/编辑距离；并报 `edit_char_ratio` 与意图保持的相关性 | 相关性 <0.3 ⇒ 改动量不是保真的有效代理（与 11-10 LeNO 结论同向） |
| **中英三语对照** | 上述三版做中 / 英 / 中英混合，报 ASR 漂移 | 中英混合档最高 ⇒ 支持中英合并训练，且说明**语用形态攻击与语言覆盖是两个独立维度** |
| **给"假安全"加可观测归因** | 监控"分类器判低风险但人工复核仍判有害"的比例，单列进误伤体验指标 | 该比例随改写强度上升而上升 ⇒ 改写把风险从"可判"推到了"判不出"（对应 11-10 T2I-NSI 的 WEAKLY_REND） |

## 附：对业务主线的三句话

1. **一字不改也能绕过**：语义完全保真、只把断言拆成「问句 + 对勾」两个元素，gpt-image-2 的生成率就从 16.3% 到 43.3%、背书率 15.3% 到 41.3%。⇒ **任何以"语义相似度 + 改动量"为验收的改写方案，都对这个攻击面完全无感**。
2. **"假安全"第一次有了机制归因**：拒答行为跟着"承诺撤回"走，语义跟着"承诺恢复"走，两者在深层才分离（layer 31 后 AUC >0.95）；所以用户感知到的"明明检查过了却还是出图"不是偶发漏判，是**检查作用在错误的组合层级**。
3. **修法是改验收单位，不是加词表**：论文结论落在"评估 completed message 而非 individual elements"。对本项目意味着 I2I/统一生成-编辑链路的改写面必须加一个**组合层复核**，且跨语言三语对照臂要单独做——本篇不覆盖中文语用形态，不能外推。
