## 一、背景与问题

### 动机

这不是安全论文。它解决的是"我想让生成器多出某种属性（复古褪色、油画、肌肉感、2D 日漫）"，而**用奖励模型做后训练会崩**。

论文把崩的方式拆成三个独立故障：

| 故障 | 机制 | 后果 |
|---|---|---|
| **真实数据 ≠ 生成器分布** | 奖励模型在真实 VAE latent 上训，却要给生成器的 final latent 打分 | 打分在生成器实际会走到的区域不可靠 |
| **属性监督被内容混淆** | 正负样本除目标属性外，主体/场景/构图/外观全不同 | 奖励模型学的是"相关内容"，不是目标属性 |
| **无界奖励最大化** | 分数越高越好，但没人说"多高才对" | 过优化：分数更高，画质更差，prompt 保真更弱 |

第三条是本轮对我们最关键的一条。原文的措辞是：

> "Unbounded reward maximization continues to favor larger scores without specifying which reward level corresponds to the intended visual outcome."

**换成我们的语言**：我们的改写奖励里，"风险分下降"和"语义保真"都是无界指标，优化器只被告诉"往下降/往上升"，没被告诉"降到哪儿就该停"。于是它会继续推，直到把语义推穿。

### 三条论断

1. 奖励监督的**构造**（谁进哪个池）和优化的**压力**（奖励推多远）是两个必须分开解决的问题，混在一起调不出结论。
2. 奖励上界不该是超参，应该在**真实正例的奖励分布上量出来**（分位数 + 半 IQR 宽度）。
3. 目标分更高 ≠ 更好：无界最大化能拿到 69.543 的目标分，但 VBench 掉到 0.5774；有界化只拿 68.722，VBench 0.5885。**多出来的 0.8 分是用画质换的。**

## 二、核心方法

### 2.1 两个部件

```
GARM（奖励监督构造）              TABO（优化压力控制）
├─ 生成器支撑匹配                  ├─ 平滑上界函数 B_a(R)
│  Base/Target 锚点对              │  = −η·softplus((T−R)/η)
│  → 五个互斥训练池                ├─ T_a = 真实正例奖励的 75 分位
└─ 内容匹配真实对比                └─ η_a = ½·IQR(真实正例奖励)
   target 字段掩码 + 结构化 tag
   + 视觉相似度 + 按 edge type 分位校准后几何融合
```

### 2.2 五池构造（Algorithm 1）

锚点对是这样造的：固定 checkpoint、固定采样配置、**固定随机种子**，只改目标条件：

$$x_i^B = G_{\theta_0}(c_i;\epsilon_i),\qquad x_i^T = G_{\theta_0}(T_a(c_i);\epsilon_i)$$

然后对每个真实样本算它到 Base / Target 支撑集的距离，各用**留一法邻域半径**独立校准 $\delta_B,\delta_T$（论文明确说共享半径会"对紧支撑太松、对散支撑太紧"）。五个池：

| 池 | 定义 | 作用 |
|---|---|---|
| $P_{\text{match}}$ | 真实正例，Target 支撑内 | 生成器相关的正例 |
| $P_{\text{cov}}$ | 真实正例，Target 支撑外 | 保多样性 |
| $N_{\text{hard}}$ | 从剩余负例里检索的**内容匹配**硬负例 | 局部属性边界 |
| $N_{\text{match}}$ | 负例，Base 支撑内或 $\rho_B\le\rho_T$ | 生成器相关负例 |
| $N_{\text{cov}}$ | 其余负例 | 保多样性 |

**一个细节值得抄**：负例构造是**不对称且有固定顺序**的——先剔除"Target 支撑内但 Base 支撑外"的灰色负例，再检索硬负例，最后才建匹配负例池。顺序反了，硬负例会被灰样本吃掉。

### 2.3 内容匹配的掩码

检索硬负例时，把**目标属性所在的整个字段**从语义匹配里删掉：$F_{-a}=F\setminus\{f_a\}$。这样"目标字段不能直接决定检索到的邻居"。

相似度 = 结构化 tag 的双向最佳匹配 + 视觉相似度，**按 edge type 各自估经验 CDF 再取分位**，最后加权几何平均融合。论文的理由：不同来源组合的相似度原始值本来就不可比。

### 2.4 TABO：一条有上界的软饱和

$$B_a(R;T_a,\eta_a) = -\eta_a\,\mathrm{softplus}\!\left(\frac{T_a-R}{\eta_a}\right),\qquad \frac{\partial B_a}{\partial R}=\sigma\!\left(\frac{T_a-R}{\eta_a}\right)$$

- $R\ll T_a$：$B_a\approx R-T_a$，**斜率 ≈ 1，方向不变**
- $R\to T_a$：斜率平滑降到 0.5
- $R\gg T_a$：边际收益 → 0

上界恰为 0。$T_a$ 与 $\eta_a$ 都**从真实正例量出来**，训练期间冻结。

### 2.5 TA-GRPO：为什么不能直接用 Flow-GRPO

标准 GRPO 的组内标准化 $A_i=(R_i-\bar R_G)/\mathrm{std}_G$ **会把 TABO 编进去的目标相关尺度洗掉**。TA-GRPO 的三处改动：

1. 先做 TABO 变换再算优势，且**除以固定阶段尺度 $v_k$ 而非当前组标准差**
2. 饱和中心 $T_{a,k}$ 走**生成器→目标的单调课程**（起点由生成器 Target 锚点的奖励分布定，终点是真实正例的 75 分位）
3. 视频侧加**时间步平衡**的信用分配

## 三、技术细节

### 3.1 数据与模型

| 项 | 设置 |
|---|---|
| 图像生成器 | Z-Image |
| 视频生成器 | Wan2.1-T2V-14B（VADER）/ Wan2.1-T2V-1.3B（TA-GRPO） |
| 图像属性 | Vintage Faded / Oil Painting / Muscular |
| 视频属性 | 2D Japanese anime |
| 图像数据 | Re-LAION-Caption19M 过滤后约 **60K** 图文对 |
| 视频数据 | 约 **5.5M** 带结构化 tag |
| 锚点对 | 5K（Vintage/Oil）、2.5K（Muscular）、5K（Anime） |
| 奖励模型 | 图像为**六层 latent ViT**；视频为局部空间 token + 时间注意力 |
| 评测集 | 每图像属性 300 prompt；Anime 200 prompt |
| 校准 | $T_a$ = 真实正例 logit 的 **75 分位**；$\eta_a$ = **½ IQR** + 小常数 |

### 3.2 一个容易忽略的工程点

奖励模型的输入，训练时是 $z^{VAE}(x)$（真实图编码），后训练时是 $z_\theta^{final}$（生成图的最终去噪 latent）。**两者同在 VAE latent 空间，但来自流水线的不同阶段**——这就是"分布错配"的准确位置。它省掉了解码再编码的开销，也把错配固定下来了。

### 3.3 独立评测器

论文反复强调：属性评测用**另外训的 RGB 评测器**（每属性一个，真实标注数据，held-out 验证），**从不作为优化奖励**。检查点选择用验证 prompt 上的 mean logit，且评测器的验证划分与检查点选择集分开。

## 四、实验与结果

### 4.1 五池消融（Table 2，Muscular）

| 方法 | Mean↑ | P20↑ | HPSv3↑ | PickScore↑ | VQA↑ |
|---|---|---|---|---|---|
| Base（参照） | 51.838 | 24.835 | 9.469 | 20.582 | 0.706 |
| Baseline（原样正负例） | 57.341 | 29.196 | 9.340 | 20.554 | 0.684 |
| Generated-only | 55.034 | 31.043 | 8.983 | 20.507 | 0.680 |
| Content-Matched-only | 57.445 | 29.880 | 9.427 | 20.564 | 0.700 |
| Support-only | 59.173 | 31.807 | 9.551 | 20.602 | 0.697 |
| **GARM** | **62.862** | **36.896** | **9.549** | **20.673** | **0.720** |

生成器对齐（Support）贡献 +1.8，内容匹配（Content）贡献 +0.1，**两者合起来 +5.5**——非线性叠加。

### 4.2 泄漏：单一部件会把副作用放大（Table 3）

中性 prompt 上的目标标签概率抬升（越低越好）：

| 方法 | Muscular | Oil Painting | Vintage Faded |
|---|---|---|---|
| Baseline | 0.011 | 0.043 | 0.046 |
| Generated-only | 0.002 | 0.026 | 0.040 |
| **Content-Matched-only** | **0.015** | **0.042** | **0.057** |
| Support-only | 0.020 | 0.042 | 0.050 |
| **GARM** | **0.002** | **0.036** | **0.029** |

**Vintage Faded 这一列是本轮最值得抄的一格：只加内容匹配硬负例，泄漏从 0.046 涨到 0.057——比什么都不做还差。** 内容匹配让它更准地认出"这个属性"，于是也更容易在中性 prompt 上误认。必须同时有生成器支撑匹配来约束它。

### 4.3 有界化的价码（VADER，Wan2.1-T2V-14B）

| 配置 | 目标 Mean↑ | P20↑ | VBench Mean | VideoScore2 Mean |
|---|---|---|---|---|
| Base（参照） | 59.263 | 43.430 | **0.6166** | 3.876 |
| 无界最大化 | **69.543** | **56.695** | 0.5774 | 3.9131 |
| **TABO（有界）** | 68.722 | 54.267 | 0.5885 | **4.001** |

三句话读完这张表：

1. 无界最大化确实能拿到**更高**的目标分（+0.82）和**更高**的 P20（+2.43）。
2. 代价是 VBench **再掉 1.1 个点**（0.5885 → 0.5774）。
3. **但两者都低于原模型**（0.6166）。有界化不是"白拿"，是"少亏"。

### 4.4 TA-GRPO（Wan2.1-T2V-1.3B）

| 指标 | Vanilla Flow-GRPO | TA-GRPO |
|---|---|---|
| 目标 Mean | 67.227 | **71.684** |
| P20 | 51.002 | **60.401** |
| VBench Mean | 0.5893 | **0.6286** |

这一次是**双赢**：目标 +4.5，P20 +9.4，VBench 也涨。原因是 TA-GRPO 改的是**归一化方式**，把被洗掉的尺度还回去了。

### 4.5 SFT 对照（Table 5）

SFT（只用真实正例，LoRA）在全局风格属性上有收益，但 Muscular 只有 50.460 vs Base 51.838——**局部细节属性 SFT 学不动**，必须靠负例监督。

## 五、局限性

### 5.1 论文自述

- 部分实验格 "not yet available"（Table 6 有 dash）。
- 锚点需要能通过条件请求的属性；不能条件化的属性走不了这条路。
- 结构化 tag 目前靠现成标注，无 tag 时要用 caption 替代，效果未测。

### 5.2 本报告补充的四条

1. **VBench 掉点没被正面处理。** 有界化相对无界化保住了画质，但相对原模型仍是 −2.8 点。论文用"more balanced outcome"表述，**没有回答"这 2.8 点换 9.5 点目标分是否划算"**。这个判断依赖业务，论文不该替你做，但也不该不提。

2. **"上界从真实正例量出来"这一步有隐含假设**：真实正例的奖励分布能代表"够好的生成结果"。在属性本身标注有噪声时（比如"肌肉感"这种主观属性），75 分位会系统性地偏低或偏高，**而论文没有给 $q_T$ 的敏感性分析**。

3. **泄漏指标定义得很窄。** Leakage = 中性 prompt 上目标 tag 概率相对 Base 的增量。它抓的是"目标属性外溢"，抓不到"目标属性挤掉了别的属性"。后者对我们更相关（改写把风险锚点换掉后，是否挤掉了用户真正要的东西）。

4. **课程起点依赖生成器锚点**，等于**先要有一批"生成器自己能做到的 Target"**。如果目标属性生成器几乎做不到（比如安全改写里"高风险概念完全不可见"），锚点集会退化，$T_{a,0}$ 失去意义。

## 六、复现指南

### 6.1 能直接搬的三件（都不需要训练）

1. **有界奖励的形状**：$B(R)=-\eta\,\mathrm{softplus}((T-R)/\eta)$，$T$ 取真实正例分位，$\eta$ 取半 IQR。可插进任何奖励。
2. **中性 prompt 泄漏指标**：固定一批与目标无关的 prompt，测目标分数的抬升。
3. **五池构造的顺序规则**：先剔灰样本 → 再检索硬负例 → 最后建匹配池。

### 6.2 最小可迁移实验（半天，零训练）

**目标**：验证我们现在的改写奖励是否"无界"且在过优化。

1. 取现有改写奖励的两个分量：风险分 $r_{\text{safe}}$、保真分 $r_{\text{sem}}$。
2. 在**真实人工改写的正例**（若没有，用"人工判定为可用"的改写样本）上算 $r_{\text{sem}}$ 分布，取 75 分位 $T$ 与半 IQR $\eta$。
3. 把奖励换成 $B(r_{\text{sem}})$，其余不变，**不动模型，只在离线打分上重算**。
4. 报三个数：① 改写样本里 $r_{\text{sem}}>T$ 的比例（这些是"已被推到目标以上还继续被奖励"的样本）；② 这些样本的 edit rate / 改动字符数；③ 换用有界奖励后，排序前 20% 的样本换了几个。

**判据**：若 $r_{\text{sem}}>T$ 的比例 **> 20%**，说明现在的奖励在**鼓励越过目标**，这就是 `over-refusal` 与 `语义崩塌` 同时出现的一个结构性解释。

### 6.3 数据构造要点

- **锚点对必须固定种子只改条件**。这条可以直接搬到"改写前后"的对照：同一 prompt、同一随机种子、只改风险锚点，得到"干净的双胞胎"。
- **target 字段掩码**：检索硬负例时把"风险类别字段"删掉，防止检索器直接按风险词找邻居。
- **池顺序不可交换**：灰样本先剔。

### 6.4 评测要点

- 必须同时报 **目标分** 与 **中性 prompt 泄漏**，只报前者会鼓励外溢。
- 必须报 **P20** 而不是只报 mean：Muscular 上 GARM mean 62.862 而 P20 36.896，**尾部远低于均值**——只看 mean 会以为属性稳定出现了。
- 评测器必须与奖励模型**架构独立**，且检查点选择集与评测验证集分开。

## 附：与业务的三条硬对应

| 论文事实 | 我们的对应现状 | 可执行动作 |
|---|---|---|
| $B(R)=-\eta\,\mathrm{softplus}((T-R)/\eta)$，$T$ 从真实正例量出 | 改写奖励无上界，优化器不知道"降到哪里该停" | 用真实可用改写样本的保真分 75 分位当 $T$，先离线重算排序看翻转 |
| Content-Matched-only 泄漏 0.057 > Baseline 0.046 | 我们只测"风险降了多少"，从不测"良性 prompt 风险是否被抬高" | 加"中性 prompt 泄漏"一项：固定 200 条良性 prompt，测风险分抬升 |
| 无界 69.543/0.5774 vs 有界 68.722/0.5885 | 我们的改写 A/B 只报风险降幅，不报保真代价 | 任何"风险降 X 点"必须同时报"保真降 Y 点"，否则不可决策 |
