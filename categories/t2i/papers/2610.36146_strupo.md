## 一、背景与问题

### 动机

T2I 输入侧改写（prompt optimization）的目标是双重的：**让出图更好看，同时不改变用户要的那个场景**。这两件事经常不同步。一个改写器可以把 prompt 从"一个女孩"写成"一个站在黄昏街头的女孩，逆光，浅景深，胶片颗粒"——画质飞升，但主体、属性、关系可能已经悄悄变了。

现有方法的评测口径把这个失败**藏起来了**：全局 CLIP 相似度、甚至大部分 prompt-image 一致性分数，对**局部语义错误极度不敏感**。论文 Fig.1 给的是教科书式例子——老虎的毛色错了、或者要的皇冠没了，全局相似度依然很高，因为"还是只老虎、还在草地上"。

### 核心科学问题

**"要保留什么"这件事，如果用一句自然语言说，模型学不会；如果用一个结构化表示说，它能不能学会？**

作者的答案是把**标定过的场景图（calibrated scene graph）**同时用在两个地方：
1. **条件**：告诉改写策略"这些是锚点，不能动"；
2. **奖励**：拿同一张图去核对"这些锚点还在不在"。

同一个表示既是输入也是监督——这是全文最重要的一句设计。

### 为什么这篇对我们重要

我们的安全改写要解决的是**同一个数学问题，只是换了个方向**。我们要求"把 NSFW 风险锚点改掉，但主体/动作/构图/意图不能变"，StruPO 要求"把风格细节改丰富，但主体/属性/关系不能变"。**两者都是"在保结构的前提下做局部改写"**，且都被同一个坑坑过——**用全局相似度当保真指标，会漏掉局部语义漂移**。

更关键的是它给出的**动作空间**：改写被形式化成 **删除 / 重排 / 插入** 三个 token 对齐的原子操作。我们的"外科式替换风险锚点"本质上就是这套动作空间的一个子集（删风险词 + 插安全同义词），**而这篇给出了这套动作空间怎么训、怎么评、失效在哪**。

## 二、核心方法

### （0）问题形式化：单步 contextual bandit

给定冻结生成器 $g$、用户 prompt $x$，学一个策略 $\pi_\theta$ 输出改写 $y$，使 $i_y \sim g(y)$ 更好看且保住 $x$ 的语义。标定场景图 $G_x = (O_x, V_x)$ 表示物体短语（含属性）与关系三元组。策略采样动作序列 $a \sim \pi_\theta(\cdot \mid x, G_x)$，确定性施加得 $y$，环境渲染 $i_y$ 返回标量奖励。目标：

$$\mathcal{J}(\theta) = \mathbb{E}_{x,a,i_y}[r_{x,y}]$$

"单步"指的是**一次完整改写 + 一次图像奖励**，不是 token 级解码步。

### （1）DSE：场景图抽取与标定（这篇最该抄的一步）

语言解析器先给出粗图 $\tilde{G}_x$，但纯文本解析会引入伪影——论文的例子很典型："a girl photographed with a **Leica lens**"，"Leica lens"会被解析成一个可见物体，其实它是拍摄条件。

DSE 的解法是**用一张图来判断哪些解析结果是伪影**：

1. 把解析出的元素分成 **text-core**（显式句法中心词、参与关系的实体）与 **auxiliary**（歧义名词短语，常描述风格/相机/介质）；
2. **auxiliary 元素需要视觉证据才能留下**，text-core 元素即使图里没画出来也强制保留；
3. 物体 grounding 用 GLIP，关系 grounding 用 BLIP 查裁剪区域，阈值 0.5。

物体集合：

$$O_x = \tilde{O}_x^{\text{core}} \cup \{o \in \tilde{O}_x^{\text{aux}} \mid o \in C_{\text{GLIP}}(i_x)\}$$

关系集合（$q_v = o_{\text{sub}} \oplus p \oplus o_{\text{obj}}$，$\gamma^v_{i_x}$ 是两端框的最小包围裁剪）：

$$V_x = \{v \in \tilde{V}_x \mid o_{\text{sub}}, o_{\text{obj}} \in O_x,\ v \in \tilde{V}_x^{\text{core}} \text{ 或 } P_V(\text{Yes} \mid q_v, \gamma^v_{i_x}) > 0.5\}$$

**这个非对称是关键**：缺失的**用户明确要求**的物体不许被扔掉（它是约束，后面还要优化），而歧义的风格短语可以被图否掉。一句话——**图只能否掉"你以为用户要的"，不能否掉"用户真要的"**。属性不做独立节点，而是以完整短语形式挂在物体标签上（"black hair"、"gold crown"、"blue king suit"），这样同一批属性短语既能进条件也能进 grounding 查询。

### （2）MHE：多模态混合编码

冻结 CLIP 文本编码器给 token 级特征 $f_{\text{text}}(x) \in \mathbb{R}^{l \times d}$；每个物体短语与序列化关系查询用同一编码器编码，取 `[EOS]` 作为图元素的初始表示；两层 GCN 在 $V_x$ 诱导的拓扑上传播，得 $f_{\text{graph}}(G_x) \in \mathbb{R}^{n \times d}$（$n = |O_x| + |V_x|$）。编辑器收到拼接表示 $f(x,G_x) = f_{\text{text}}(x) \oplus f_{\text{graph}}(G_x)$。

### （3）EAG：编辑动作生成器 —— 半自回归，刻意偏向保守

$x$ 是 token 序列 $\{t_j\}$，动作按固定顺序施加：

| 动作 | 形式 | 解码方式 |
|---|---|---|
| **删除** | 每个 token 采 $\delta_j \in \{0,1\}$，1 保留 0 删除，边界 token 固定 | 非自回归 |
| **重排** | 对保留序列预测后继分布 $\rho_j = k$，完整后继指派诱导一个置换 | 非自回归 + beam search |
| **插入** | 在重排后序列上自回归采样新 token 或 `[BOS]` 槽位标记，保留 token 按序填入 | 自回归 |

完整动作 $a = (\delta, \rho, \tau)$。作者自己对这套参数化的定性很克制：**"这是朝向保守编辑的归纳偏置，不是每个约束都被保住的硬保证；哪些编辑被强化由图像奖励决定。"** 这句话很实在——动作空间只**偏向**保守，不**强制**保真。

### （4）训练：SFT 热身 + 不确定性感知奖励 + 环境感知 GRPO

**SFT**：对配对数据 $(x,y)$ 做 token 对齐得到目标动作序列 $a^\star(x,y)$——未匹配的输入 token 是删除，保留的 token 是后继指针，未匹配的输出 token 是插入。

**奖励整形（Theorem 3.1，这篇的理论贡献）**：常用的离散结构分是 $\mathbb{E}_{z \in G_x}\mathbb{1}[P(z \mid i_y) \ge u]$，$u$ 是固定阈值。问题是**阈值附近的微小置信度变化会翻转某个约束的贡献，而远离阈值的改进拿到零分**。改成保留置信度：

$$R_s(I) = \frac{1}{K}\sum_{k=1}^{K} p_k(I),\quad K = |O_x| + |V_x|$$

定理 3.1 给出（$\Psi = \nabla_\theta \log \pi_\theta$）：

$$\|\widehat{\nabla}J(\theta;I) - \widehat{\nabla}J(\theta;I')\| \le \|\Psi(\theta;I) - \Psi(\theta;I')\| + \frac{\|\Psi(\theta;I)\|}{K}\|p(I) - p(I')\|_1$$

结论：**阈值化评分在 $u$ 处没有一致的有限 Lipschitz 界**，而平滑版把"策略分变化"与"grounding 置信度变化"分离，固定编辑时第一项消失。实际训练用单调 clipped-log 变换 $\phi(t) = [\log(\max\{t,\eta\})]_{c_{\min}}^{c_{\max}}$，保留有限 Lipschitz 常数。

结构化奖励：

$$r^{\text{con}}_{x,y} = \frac{\sum_{o \in O_x}\phi(P_O(o \mid i_y)) + \sum_{v \in V_x}\phi(P_V(\text{Yes} \mid q_v, \gamma^v_{i_y}))}{\max(1,K)}$$

注意 **GLIP 给物体置信度、BLIP 核关系裁剪区，所以原子一致性不经过 CLIP**——这是刻意的：CLIP 正是那个"看不出局部错"的评测器。

总奖励 $r = \alpha_1 r^{\text{con}} + \alpha_2 r^{\text{aes}} + \alpha_3 r^{\text{CLIP}}$（aes 用 Promptist 的 aesthetic predictor，CLIP 项只做全局正则）。

**环境感知 GRPO**：渲染本身有随机性，所以**先对环境采样求平均，再做组内归一化**。对每个 $x$ 采 $N$ 个改写 rollout，每个 rollout 渲染 $M$ 张图：

$$\bar{r}_i = \frac{1}{M}\sum_{j=1}^{M} r_{i,j},\qquad \widehat{A}_i = \frac{\bar{r}_i - \text{mean}_k \bar{r}_k}{\text{std}_k \bar{r}_k + \epsilon_A}$$

然后用带 KL 锚（对 SFT 参考策略）与熵正则的 clip 目标。**这个"M 次渲染先平均再比"是低成本高收益的设计**——它把"运气好的一张图"和"确实更好的一个改写"分开了。

## 三、技术细节

| 项 | 配置 |
|---|---|
| 生成器 | Stable Diffusion v1.5（默认）；迁移测试 SD v1.4 / SD v2.1 / FLUX.1-dev |
| 物体 grounding | GLIP-T |
| 关系核验 | BLIP-base，阈值 0.5 |
| 文本编码器 | CLIP ViT-L/14（冻结） |
| 编辑器初始化 | **BART-base** |
| 图编码器 | 2 层 GCN，hidden 768 |
| 可训参数 | **只有 GCN + 编辑策略**；grounding / CLIP / 生成器全冻结 |
| 优化器 | AdamW，lr $2\times10^{-5}$ |
| SFT | 约 50 epochs |
| RL | 24K prompt → 6K updates；每 context $N=4$ rollouts × $M=3$ images |
| 推理 | 图标定 + **一次策略前向**，无迭代 critique-rewrite 循环 |

**SFT 数据构造（144K 对）**：从 Lexica 收 **72K** 个优化后 prompt 当目标；每个目标按 Promptist 的做法反解出两种输入变体——(i) 去掉风格修饰的**语义骨架**，(ii) 该骨架的 **GPT-4o 改写**。SFT 用全量配对，RL 用训练集里抽的 24K 输入（**不给目标**）。

**评测集**：Lexica（in-domain）、DiffusionDB（in-domain）、COCO captions（out-of-domain），**各 2K prompt，三者互不重叠且与训练/验证/调参全隔离**。

**评测口径（重要）**：结构化一致性用**阈值化** grounding 评（不是训练时的平滑奖励），报 **OR**（object recall）、**RR**（relation recall）、**SGR** $=(\text{OR}+\text{RR})/2$。每个分数是 3 个匹配种子的平均。另加 Gemini-VQA（**只在 Lexica 上评，从不参与训练或选模型**）、TIFA、VQAScore、ImageReward、HPSv2.1。

## 四、实验与结果

### 主结果（SD v1.5）

| 方法 | Lexica AESΔ | Lexica OR | Lexica RR | Lexica SGR | Lexica Gemini | COCO AESΔ | COCO SGR |
|---|---|---|---|---|---|---|---|
| Template（近原始 prompt 参照） | 0.53 | 89.50 | 59.63 | 74.57 | 77.6 | 0.68 | 77.60 |
| Promptist | 0.48 | 89.55 | 61.25 | 75.40 | 79.5 | 0.80 | 77.33 |
| MagicPrompt | 0.46 | 89.50 | 61.67 | 75.59 | 78.1 | 0.67 | 74.14 |
| Human-crafted | 0.54 | 89.19 | 56.31 | 72.75 | 78.2 | – | – |
| VisualPrompter（无训练，迭代反馈） | 0.62 | 90.26 | 53.49 | 71.88 | 79.2 | **−0.36** | **83.26** |
| BeautifulPrompt | 0.57 | 85.70 | 39.85 | 62.78 | 73.8 | 0.69 | 58.59 |
| Rephrase (GPT-4o) | 0.44 | 88.38 | 55.52 | 71.95 | 78.6 | 0.67 | 78.74 |
| **StruPO** | **0.63** | **91.84** | **69.64** | **80.74** | **82.4** | **1.02** | 78.94 |

- **关系召回才是差异所在**：Lexica 上 RR 比最好的基线高 **7.96 点**，SGR 到 **80.74**；DiffusionDB 上 AESΔ / OR / RR / SGR 全项最好（0.91 / 92.94 / 65.49 / 79.22）。
- **OR 的差距远小于 RR 的差距**，这和方法取向一致：**保住物体词不等于保住物之间的关系**。
- COCO 上出现一个诚实的 trade-off：VisualPrompter 的 SGR 最高（83.26，靠 RR 76.01），**但美学分掉了 0.36**；StruPO 拿到最大的美学提升（**+1.02**）而结构一致性保持在与 GPT-4o 基线相当的水平。

### 跨主干迁移（不重训）

只用 SD v1.5 的反馈训练，直接评 SD v1.4 / SD v2.1 / FLUX.1-dev：

| 主干 | StruPO RR | 最强基线 RR | StruPO AESΔ |
|---|---|---|---|
| SD v1.4 | 61.82 | Promptist 60.64 | 0.68 |
| SD v2.1 | 61.57 | Promptist 59.57 | 0.46 |
| FLUX.1-dev | **62.43** | Promptist 53.41 | **1.14** |

FLUX 上 RR 高 **9.02 点**、美学提升也最大。作者的解读是学到的文本编辑可跨生成器复用。

### 人类评测（15 名标注员，全 2K Lexica prompt）

配对比较，**美学与语义一致性分开判**，允许平局（不做二次破平），多数票聚合。一致性中等：美学 Fleiss $\kappa=0.40$，一致性 $\kappa=0.43$。

- 对五个对比对象的**两个维度都是正胜−负差**；
- 一致性维度对 Promptist / VisualPrompter / few-shot GPT-4o 分别 **+9 / +10 / +7** 个百分点，平局占 23–37%，三个差的 95% CI 都不含 0；
- **关系越多优势越大**：$|V_x|$ 从 1 到 $\ge 3$，三组差分别从 +6→+16、+6→+17、+3→+14。

最后一条是全文最硬的证据：**优势恰好落在方法针对的那个难度轴上**，而不是均匀涨。

### 消融（Lexica）

| 变体 | AESΔ | OR | RR | SGR | 相对完整版 |
|---|---|---|---|---|---|
| **StruPO** | 0.63 | 91.84 | 69.64 | 80.74 | — |
| w/o DSE（不标定，用原始解析图） | 0.64 | 89.24 | 58.14 | 73.69 | **SGR −7.05** |
| w/o MHE（编辑器看不到图结构） | 0.65 | 89.25 | 61.41 | 75.33 | **SGR −5.41** |
| w/o EAG（换成自由自回归生成，图条件+奖励+GRPO 都保留） | 0.57 | 88.92 | 58.44 | 73.68 | **SGR −7.06** |
| w/o RL（只用 SFT） | 0.57 | 89.52 | 58.55 | 74.04 | **SGR −6.70** |
| w/o $r^{\text{con}}$（去掉结构化奖励，留美学+CLIP） | 0.68 | 89.19 | 61.08 | 75.14 | **SGR −5.60**，美学反升 |

**"w/o EAG" 这一行是全文最有信息量的负结果**：把局部编辑换成自由生成，**图条件、结构化奖励、GRPO 全都还在**，SGR 依然掉 7.06。也就是说——**动作空间本身在贡献，不只是"给了个更好的奖励函数"**。

**约束复杂度曲线**：物体数增加时所有方法的 OR 都掉，StruPO 掉得最少；关系数变化时通用改写方法剧烈波动，StruPO 在三个桶里都稳在 70% 左右的 RR。

## 五、局限性

1. **完全不涉及安全**。奖励里没有风险维度，评测里没有 NSFW/违规概念。它证明的是"结构保真可以训"，不是"安全改写可以训"。
2. **图表示的表达力有明确边界**（作者自己列的）：计数、遮挡、否定、情绪、隐喻、抽象意图都表达不了。**这几项恰好是内容安全里最难的边界**——"暗示性""擦边""隐喻式冒犯"全在这个表示覆盖不到的区域。
3. **保守编辑有时过头**。作者承认当 prompt 需要整体重写时，局部编辑太受限；长输入和密集场景分析里暴露了这一点。
4. **依赖外部 parser / grounding / VQA 模型质量**。这条对我们的算力现实是硬约束：DSE 每次要跑一次生成 + GLIP + BLIP，推理包含一次标定渲染。
5. **多图平均抬高离线成本**（$M=3$），且 RL 阶段每 context 要 $N=4$ 次改写。
6. **只覆盖英文 prompt 分布**，多语言未验证。
7. **迁移不等于消偏**：作者的措辞是"迁移不能移除底层生成器的能力或偏见"。

## 六、复现指南

### 可复现部分
- 全套依赖都是公开模型：GLIP-T / BLIP-base / CLIP ViT-L/14 / BART-base / SD v1.5。
- 数据管线可自建：**Lexica 抓 72K 优化 prompt → 反解语义骨架 → GPT-4o 改写骨架**，得到 144K 配对。这一步成本主要在 GPT-4o 调用，不需人工标注。
- **可训参数极少**（GCN + BART-base），单卡可跑；贵的是 RL 阶段的渲染（$N \times M = 12$ 次生成/context）。

### 关键实现顺序（建议）
1. **先只做 DSE，不训策略**。拿我们自己的数据跑"text-core vs auxiliary"分流，看**风险锚点落在哪一侧**。这一步零训练，且直接回答一个我们现在没答案的问题：**"擦边"这类词在解析器眼里是物体还是修饰**。
2. **再做 SFT-only**（w/o RL 是 74.04 SGR，只比 Template 的 74.57 低 0.53——说明纯模仿几乎不涨）。判据：如果 SFT 阶段就已经把我们关心的 recall 顶到接近 baseline，问题不在策略学习而在数据。
3. **最后接 RL，但把 $M$ 压到 2、$N$ 压到 4**。判据：$M=2$ 时组内排序与 $M=3$ 的一致率；若接近饱和，多渲染不值。

### 迁移到安全改写的具体做法
- **把 "$G_x$ 要保住的东西" 换掉**：不是物体+关系，而是 **主体 + 动作 + 场景类型 + 非风险属性**，风险锚点则明确排除在保留集之外。这一改，DSE 的非对称规则直接可用：**用户明确要求的主体不许被图否掉；风格/氛围类修饰可以被图否掉**。
- **把 $r^{\text{con}}$ 换成"锚点保留率"**：用同一套 grounding 管线核"改写后的图里主体/动作还在不在"。这比 CLIP 分数可靠，因为它**逐锚点**核，不是一个标量。
- **把 EAG 的三动作直接当改写算子**：删除风险词、重排语序降暗示性、插入安全同义限定。**w/o EAG 掉 7.06 这个结果支持"不要用自由生成做安全改写"**——自由生成会顺手把主体也改了。
- **Theorem 3.1 直接搬**：我们现在的一致性奖励如果是阈值化的（"相似度 > τ 算通过"），就存在同一个病——**阈值附近抖动翻转奖励，远离阈值改进不给分**。改成保留置信度的连续平均，是一行代码级别的改动。
