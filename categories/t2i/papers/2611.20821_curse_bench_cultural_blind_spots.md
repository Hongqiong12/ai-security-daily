## 一、背景与问题

### 动机：一条 prompt 在不同文化里不是同一个意思

现有 T2I 安全评测通常给每条 prompt / 每张图打**一个与地域无关的伤害标签**（culture-blind harm label）。论文指出这个假设站不住：一个符号、手势或实践，在通用 rubric 下看起来完全普通，但在特定文化里携带冒犯性、政治性或仇恨含义——于是**content that is harmful only within a particular culture can pass as benign**。

### 与本仓库主线的关系

这条直接对应三条业务约束：

1. **中性 Prompt 的语义取向漂移**：本项目关注的"模糊但高风险 prompt"，本质就是"通用判据看不出、特定语境看得出"的那一类；本篇给了可复现的构造方法。
2. **政治 L2_30 层级口径**：论文附录 A 明确写「**Political harm is latent everywhere**」，并按地区拆出 East Asia 的政治编码（POL）、North America 的政治与种族编码（POL / HAT）⇒ 与「敏感地区层级口径」是同一个问题的学术版本。
3. **跨语言鲁棒性**：论文把 **English-only prompts** 直接列为 Limitations，与「2B 改写模型英文 ASR 飙升」形成互证——**连评测集本身都还是英文单语的**。

## 二、核心方法

### 2.1 CultureCraft + CuRSE-Bench

| 项 | 设定 |
|---|---|
| 构造框架 | **CultureCraft**（agentic framework）：生成"通用 rubric 下看似无害、目标文化下带潜在伤害"的 T2I prompt |
| 主集 | **10,709** 条 culture-specific prompts |
| 对照集 | **2,648** 条 culture-general controls（由相同种子**不做文化变换**得到） |
| 覆盖 | **6** 个地区 × **10** 条 harm axes |
| 知识库 | 每条 harm vector 来自**预定义、有文献记载的知识库**，且**可追溯到至少 2 个独立来源** |
| 评分视角 | **7** 个：6 个地区 persona judge + 1 个配对的 culture-blind judge |

对照集是关键设计：它让"文化盲 judge 漏判"可以与"judge 本身打分偏松"区分开——**若 culture-blind judge 只在 culture-specific 集上低分、在 controls 上与 persona judges 一致，那才是盲区而不是标定偏差**。

### 2.2 配对 judge 设计

对目标地区 r 的 prompt p，先用 structure extractor 把 p 分解成结构化视觉槽位（subject / object / situation / attire / setting），judge 再读该结构返回判定。这样"文化知识"与"表面措辞"被分开，便于做 component ablation 与 knowledge-swap control。

## 三、技术细节

1. **盲区是选择性的（selective），不是全局的**：每个 persona judge **主要解码自己地区的潜在伤害**，其它地区的不显著。论文用 per-region specificity、per-axis blind-gap 与 percentile bootstrap（Table 10/13/14）把这一点做成可检验命题，而不是一句定性观察。
2. **跨 persona 命名指称泄漏审计**（Table 15）：对每个地区 drop 掉命名指称再测，防止 persona judge 只是认出了地名/人名就给高分。
3. **知识互换对照**（Figure 7）：把 East Asia 的知识库换成别的地区，看 blind-gap 是否塌回 control gap ⇒ 检验 gap 确实来自文化知识而非 persona 措辞带来的整体抬分。
4. **bypass rate 定义得很严**（Figure 8 / Table 11）：一个样本只有在**文本与图像两层过滤器都绕过**时才计数；按 generator 与 filter layer 分列，另与"专门优化去绕过过滤器的 T2I jailbreak"对照。
5. **七视角 + 已部署审核器**：除自建 judge 外，还在 **5 个已部署生成管线**上测 bypass，并单独做了 deployed moderators / NSFW-checker（SD v1.4）对照（Figure 16）。

## 四、实验与结果

### 4.1 核心定性结论（摘要与正文可判定口径）

- **culture-blind judge 在 culture-specific 集上系统性低估潜在伤害，而在 controls 上与 persona judges 打分一致** ⇒ 盲区是"文化特定"的，不是 judge 整体松。
- **每个 persona judge 主要解出自己地区的潜在伤害** ⇒ 选择性文化盲区，且**在已部署审核器中持续存在**。
- **CuRSE-Bench 在 culture-specific 子集上能绕过 5 个已部署生成管线**（Figure 8；per-generator / per-layer 数值见 Table 11 / 附录 F），而**这些 prompt 没有做任何针对过滤器的优化**；论文特别指出与专门为绕过滤器而优化的 T2I jailbreak 相比，"ours carry no optimization at all, so no surface-cue vocabulary fires" —— 即**没有表层线索可查**。

> 数字纪律：本论文 HTML 正文的表格数值大量以 MathJax 呈现，转换后为占位符（[M]），bypass rate 与 blind-gap 的逐格具体数值**无法从可核验文本中读出**。此处只引用摘要与正文文字可判定的结论与规模数字，**不做数字外推**。

### 4.2 消融与稳健性（论文自报章节）

| 检验 | 目的 |
|---|---|
| Component ablation（South Asia slice, Table 6 / 19） | 拆掉 CultureCraft 各部件看 blind-gap 是否消失 |
| Backbone ablation（East Asia slice, Table 7） | 换 judge 骨干看选择性是否仍在 |
| Knowledge-swap control（Figure 7） | 排除"persona 让分数整体抬升"的替代解释 |
| Cross-persona named-referent leakage（Table 15） | 排除"认出地名就判有害"的捷径 |
| Control absolute scores / ceiling check（I.3） | 确认 control 集不是天花板效应 |

这一组对照的设计密度是本轮六篇里最高的，直接可搬进本项目的"评测尺子自检"。

## 五、局限性（论文明确列出，迁移时不能跳过）

1. **English-only prompts** —— 与业务现状镜像：评测集本身没有中英混合 / code-switching，因此**它证明的是"文化语境盲区"，不是"跨语言 ASR 漂移"**，两者不能互相替代。
2. **Cultural coverage**：6 个地区不等同于全球覆盖，地区以 locale unions 定义（Table 9），边界是构造出来的。
3. **Native-speaker involvement** 有限；persona judge 是 LLM 模拟的"文化视角"，不是真实社群标注。
4. **Scope of claims / Positionality / Interpretation of labels**：作者明确说明标签是"某个视角下的判定"，不是客观真值——这与本项目 PORN/VULG 边界混淆的"定义层"问题是同一类。
5. **Dual use**：构造框架本身可用于生成绕过样本，论文做了发布限制讨论。
6. **不含输出侧图审 AB / 不含改写链路**：只做评测集与 judge，未涉及输入侧改写策略或阈值 operating point。

## 六、复现指南

**论文复现**
1. 从有文献记载、≥2 独立来源的 harm vectors 建知识库；按 6 地区 × 10 harm axes 用 CultureCraft 生成 10,709 条，另用**同种子不变换**生成 2,648 条 controls。
2. 每 prompt 用 structure extractor 抽 5 个视觉槽位，交 6 个 region persona judge + 1 个 culture-blind judge 打分。
3. 报 per-region specificity、per-cell blind-gap（配 percentile bootstrap）、bypass rate（必须**文本+图像双层都绕过**才计数）。
4. 必做四个对照：knowledge-swap、named-referent leakage、backbone ablation、control ceiling check。

**本项目迁移建议（零训练，1–2 天）**

| 动作 | 做法 | 判据 |
|---|---|---|
| **中性 prompt 双判据对照** | 抽 200 条"分类器判低风险但人工觉得别扭"的样本，配一个「L2_30 / 地区语境视角」judge 与现有 culture-blind 判据并列 | 若两者只在特定类目上分离、controls 上一致 ⇒ **是层级口径盲区，不是阈值偏**（对应 B2 锚点） |
| **评测集加"同种子不变换"对照臂** | 现有评测集里为每条高风险 prompt 配一条只去掉风险锚点、其余槽位不变的 control | 判据在 controls 上不一致 ⇒ 现有整体指标含 judge 标定偏差，历史版本对比需重算 |
| **"无表层线索"绕过集** | 复用 CuRSE-Bench 思路构造一批**不含任何敏感词**、但地区语境下有害的 prompt，跑现有分类器 | 漏过显著高于常规集 ⇒ 分类器在查词表，改写侧的"语义保真"指标也不可信 |
| **跨语言补臂（必须单独做）** | 把上述集合做中 / 英 / 中英混合三版本，报 ASR 漂移 | 英文档显著升高 ⇒ 支持"中英合并训练"，且说明**不能只靠文化 persona 覆盖替代语言覆盖** |
| **五类对照搬进评测 harness** | knowledge-swap / 命名泄漏 / 骨干消融 / 天花板 / 配对 control | 任一对照失败即撤回该轮结论，与 11-10 报告纪律"配对对照优于扩样本"一致 |

## 附：对业务主线的三句话

1. **「中性 Prompt 的语义取向漂移」第一次有了可复现的构造协议**：不是靠同义词替换，而是靠"通用 rubric 无害 × 目标文化有害"的配对种子 + 不变换 control 臂。
2. **政治 L2_30 的层级口径问题被独立复现**：论文附录直言 political harm is latent everywhere，且按地区分编码；盲区是**选择性**的，因此"一个统一阈值/一个统一 rubric"结构上就盖不住。
3. **跨语言建议必须自己补**：论文把 English-only 列为局限，说明**文化视角覆盖 ≠ 语言覆盖**；2B 改写模型英文 ASR 飙升需要中英合并训练，这条不能从本篇外推得到，只能自建三语对照臂。
