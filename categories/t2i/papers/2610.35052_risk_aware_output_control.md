## 一、背景与问题

### 动机

机器遗忘（MU）在过去几年几乎被一个目标统治：**参数空间不可区分性（parameter-space indistinguishability）**。意思是：遗忘后的模型，要在参数/行为上尽可能接近"用保留数据从头重训"的那个模型（retrained model, RT）。

这个目标是从**差分隐私**借来的——"观测者无法从输出区分'训过全量数据'和'删掉某点后训练'的模型"。它很干净、可证、可度量，于是成了事实标准。

本文的主张很硬：**这个目标是错位的。MU 应该追求的是"输出空间上带统计保证的风险控制"，而不是参数空间的相似度。**

### 四条反驳（本文的核心论证结构）

作者没有停留在立场宣示，而是把"不可区分性"的失效拆成四条：

**① 缺有意义的下游保证（Lack of meaningful guarantees）**
即使你能证明"与 RT 参数接近"甚至"与 RT 不可区分"，**这不转化出任何关于输出行为的保证**。参数或输入上的微小扰动可以造成输出的巨大偏离。实践中真正被关心的是：**遗忘之后，模型还多频繁地输出有害内容 / 泄露隐私**——而这跟参数距离没有单调关系。

**② 可伪造（Forgeability）**
已有工作证明：**即使完美不可区分性，也能被"遗忘证明"（unlearning proofs）本身构造破坏**。模型所有者可以向用户出示一份完整的参数更新历史、训练批次与对应关系，让人相信"数据没被用到"——而实际上用到了。**理想遗忘的证明可以被伪造，哪怕根本没有发生遗忘。** 于是不可区分性在实践中不是有效目标。

**③ 黄金标准本身不可靠（Unreliability of the retrained gold standard）**
这是对我们最致命的一条。即使你做到了参数层接近 RT，实践中仍然出问题：

> **生成模型被证明可以在从未被显式训练过的内容上复现受版权保护的素材**；采用保形预测（CP）的分类器，其预测集里**仍可能包含被遗忘的点**。

也就是说：**"与 RT 不可区分"并不蕴含"不再产生不期望的输出"。** 当模型能力泛化到遗忘集上，**输出层的保证是不可或缺的，因为它无法从参数层的不区分性推导出来。**

**④ 结论**
MU 需要的是：(1) 摆脱把 RT（或任何昂贵基线）当作终极标准；(2) 本身抵抗伪造；(3) 能在真实部署规模上成立。

### 提出的替代
一个**分布无关（distribution-free）的风险控制框架**用于输出层遗忘，并把**保形预测**恢复成它的一个规范特例。

### 为什么这篇对我们重要

我们这条线的核心设计是：**不改生成模型、只在输入侧热更新改写**。而对标的权重侧范式是 Concept Erasure / Machine Unlearning（ESD / UCE / SAFREE / SafeGen 一类）。

过去我们（和多数文献）把二者摆成"两条技术路线"，比 FSR、比 FID、比推理开销。这篇给的框架不一样：

**如果擦除的正确目标本来就是"输出空间的风险控制"，那么输入侧改写天然就是输出空间控制，而权重侧擦除是一个"要绕一大圈才可能达到输出控制"的手段。** 二者不是"两条平行的路线"，而是**"目标"与"一种代价高昂、且证不到目标的实现方式"**的关系。

这个重述，比"互补"更准确，也更好用：**它把输入侧改写的地位从"便宜的替代品"抬成"目标的直接实现"。**

## 二、核心方法

### 定位：这是一篇 position paper，方法在"重定义目标"

| 层次 | 内容 |
|---|---|
| **诊断** | 现范式（参数空间不可区分）继承自对抗鲁棒性/差分隐私，与该领域的真实运筹目标脱节 |
| **证据** | 理论结果（虽非为这个框架而写，但与该框架一致）+ 实证（生成模型对未见数据的复现、CP 预测集含被忘点） |
| **主张** | 以**部署模型输出上的统计保证**来定义与认证遗忘 |
| **落地** | 分布无关风险控制框架；**保形预测是它的规范特例** |

### 为什么"保形预测是特例"这句话重要

保形预测给出的是**边际覆盖保证**：在给定显著性水平 $\alpha$ 下，预测集以 $1-\alpha$ 的概率覆盖真值。把它当成遗忘的认证工具意味着：**你能给业务一句可兑现的话——"在 $\alpha$ 的风险水平下，输出落在不被允许区域的概率有上界"**。

这跟"我们擦除了这个概念"完全不是一个量级的承诺。后者是**机制声明**，前者是**风险声明**。业务方需要的是后者。

### 与权重侧擦除文献的关系

它不否定擦除技术本身（ESD / UCE / SAE 定位那一脉在"降低特定概念生成率"上确实有效），而是说：**这些方法报告的成功指标（FSR、FID、CLIP score）不能等价成"输出风险有界"，而后者才是需要被认证的东西。** 换句话说，问题不在方法，在**验收标准**。

## 三、技术细节

### 目标函数的形式差异

设遗忘集 $D_f$、保留集 $D_r$、某风险事件 $E$（如"输出包含被遗忘实体的可识别信息"）。

- **参数空间范式**：最小化 $\text{dist}(\theta_{\text{unlearn}},\ \theta_{\text{retrain}(D_r)})$，或在假设检验意义下让二者不可区分。
- **输出空间范式（本文主张）**：对部署分布 $\mathcal{P}$ 上的样本，控制
$$\Pr_{x \sim \mathcal{P}}\big[\,E(G_\theta(x)) = 1\,\big] \le \alpha$$
并在有限样本下给出**分布无关**的上界（即不假设 $E$ 的分布形式、不假设模型族）。

后者的关键工程性质：**它不需要一个"重训参考模型"**。而 RT 恰恰是最贵、最常拿不到的东西（部署后往往已无完整训练语料）。

### 三条"必须摆脱 RT"的理由（作者排序）
1. 规模：万亿参数、上百层，全量重训在算力上不可行；
2. 数据可得性：部署后通常不再保有完整原始语料，忠实重训**在实践上不可行**；
3. 参考模型的可信度：即使拿到 RT，"接近 RT"也不保证"没有不期望输出"（见上文③）。

## 四、实验与结果

**这是一篇 position paper，没有"我们的方法在 X 上比 baseline 高 Y 个点"这类主表。** 它的"结果"是四条论证的证据链：

| 论据 | 支撑 |
|---|---|
| 参数接近 ≠ 输出保证 | 参数/输入微扰 → 输出大偏离（引 [33, 37]） |
| 不可区分性可被伪造 | 构造"遗忘证明"的工作（引 [58]） |
| RT 不可靠 | 生成模型复现**从未显式训练过**的受版权内容（引 [22]）；CP 分类器预测集仍含被忘点（引 [1, 53]） |
| 输出控制可落地 | 分布无关风险控制框架；CP 作为特例 |

**口径说明**：本文不含自建实验的量化结果，本精读不构造任何"提升 X%"类数字。

### 一个必须承认的方法论短板
**它把 CP 当特例，但没有给出"如何在 T2I 上构造有效的风险事件 $E$ 与非一致性分数"的具体做法。** 对图像生成，"输出是否包含被遗忘概念"这件事本身就需要一个判定器——**而判定器的错误率会直接吃进覆盖率保证里**。这一点文中未展开，但对我们是最关键的一环（见第六节）。

## 五、局限性

1. **是立场文，不是方法文**。提出了框架方向，但没有可跑的实现与实验验证。
2. **风险事件 $E$ 的构造被当成已知**。在多模态/生成任务上，$E$ 的判定本身需要模型（VLM judge / 分类器），**判定器误差会破坏分布无关保证**——这是本文最大的隐式假设。
3. **"分布无关"假设了可交换性（exchangeability）**。真实流量有时间漂移、对抗演化（新的锚点词、新的越狱模板），可交换性被破坏后覆盖率保证会失效。这在安全场景是常态而非例外。
4. **没有讨论"擦除后能力损失"的量化**。输出控制可以把风险压到 0，代价可能是模型什么都不生成——作者承认需要"utility"维度，但没给权衡曲线。
5. **没有涉及 T2I/扩散模型的具体形态**。全篇是通用 ML 语言，扩散模型的"遗忘"是概念级而非样本级，映射并不平凡。

## 六、复现指南

### 这篇不需要"复现"，需要"改验收标准"

对我们最有价值的动作不是跑它的框架，而是**把我们自己的擦除对照实验的验收指标换掉**。

**可直接落地的三步（都不需要训练）**

**① 把"擦除率"换成"风险上界 + 覆盖率"**

现在权重侧对照的报法是 FSR（如 ESD 17.20 / ConceptPrune 77.90 / ConceptACP 89.20）配 FID。这套报法的隐含承诺是"我们擦掉了 X%"。按本文，应该报的是：

- 在风险水平 $\alpha$ 下，**留出集上风险事件的实际发生率**与**上界**是否匹配（覆盖率是否 ≥ $1-\alpha$）；
- 以及**同一 $\alpha$ 下，输入侧改写能达到什么**。

**判据**：若输入侧改写在同样 $\alpha$ 下的实测风险不高于擦除，而效用损失更小——则"擦除是必要的"这一前提在本业务上不成立。

**② 用"新锚点词"检验可交换性（半天，最关键）**

本文的分布无关保证依赖可交换性。安全场景的可交换性会被**新锚点**打破。做法：拿擦除后的模型，用**训练/擦除阶段从未出现过的同义锚点**（新造词、跨语言、隐喻）去探。**判据**：若新锚点上的生成率显著高于旧锚点，说明擦除学的是**词表**不是**概念**——这正是输入侧改写要接手的场景（改写能看到实际请求里的新词，擦除看不到）。

**③ 把"二者互补"写成可检验的分工，而不是修辞**

| 维度 | 权重侧擦除 | 输入侧改写 |
|---|---|---|
| 生效时机 | 上线前（一次性） | 上线后（热更新，分钟级） |
| 能看到什么 | 训练分布里的概念 | **本次请求的实际文本** |
| 管得住什么 | 已定义的概念族 | **新出现的锚点词/新话术** |
| 管不住什么 | 没训过也能组合出来的内容（本文③）、新锚点 | 已经生成出去的图 |
| 验收指标（按本文） | 应报输出风险上界，而非 FSR | 同上，且可对同一 $\alpha$ 直接对比 |

**这张表就是我们要的"互补关系与各自失效边界"**，而且每一行都能对应到本文的一条论证或我们已有的实测。

---

**一句话判断**：这篇没有给我们新方法，但给了我们**换掉验收标准的理由**——擦除的成功不该用"参数离 RT 多近"或"FSR 多高"来衡量，而该用"输出风险是否有统计上界"来衡量；而一旦这么定义，**输入侧改写不是擦除的廉价替代品，而是这个目标更直接的实现**。
