## 一、背景与问题

### 动机：现有「图像防护」评测的威胁模型，从来没有对准裸体化

对抗扰动防护（adversarial perturbation defense）通过在图上加不可见噪声，阻止别人拿这张图去做未经授权的编辑。已有方法（PhotoGuard、DiffusionGuard、AdvPaint、DiffVax）都用 PSNR / SSIM 这类像素级参考指标 + 通用 inpainting prompt（"a man in a hospital"、"a dog in a gaming convention"）验收。

作者指出这是一个 **problem-formulation failure（问题定义失败）**：AIG-NCII（AI 生成的非自愿亲密影像）是生成式 AI 记录最充分的危害之一，而裸体化恰恰是通过 **inpainting** 完成的——正是这些防护方法声称要防的场景。但既有威胁模型与裸体化编辑**结构性错位**，错位有三层：

| 错位层 | 既有评测 | 真实裸体化 |
|---|---|---|
| **掩码形状** | 通用物体/矩形框，或用与防护完全相同的 mask | 身体/面部/上下文区域，攻击者会 dilation + blur（Diffusers 内置） |
| **prompt 分布** | 通用场景描述 | 直接 `"A naked [woman/man]"`；性别来自生成时的指定 |
| **成功判据** | PSNR / SSIM 衡量「扰动有没有破坏图像」 | 输出是否构成**成功的裸体化**（性化 × 自然度 × 可辨认性） |

⇒ 既有评测**系统性高估防护有效性**。

### 与本仓库主线的关系（三重命中）

1. **输出侧图审 / NSFW 图审方向 (2) 的本轮唯一直接命中**。本仓库连续多轮记录「NSFW 图审方法零供给」；本篇给出一个**以危害定义为中心的评测框架**，而不是又一个分类器：三大 harm-aligned 指标（sexualization / naturalness / recognizability）联合决定一次 inpainting 是否构成攻击成功。
2. **代理量脱钩的又一硬证据，而且是「判定 100% 而信息 0%」的极端形态**：PSNR / SSIM 与裸体化防护**基本不相关**。与 11-10 NotaryMark（TPR 100% ↔ BA_img 60.69%）、11-24 灰图探针 0.9645 AUROC 同族；本轮把它推到「验收指标与目标危害无关」。
3. **误杀率读数 / 「假安全」拒答体感的运营映射**：「防护看起来成功」在结构上等价于「策略命中看起来生效」。作者把错位拆成掩码、prompt、判据三栏，这套拆法可直接搬到 5.2% 误杀率 / 3.42% 漏过率基线的**评测集口径审计**。

## 二、核心方法

### 2.1 BODYBENCH：648 个全合成主体 × 11 种掩码

- **648 个完全合成的着衣成年主体**，在性别、国籍、场景上下文上做受控变化（全合成规避真实人物伦理问题）；每个主体配 **11 种掩码**（body / face / context / 不同 dilation），合计 **7,128 张**（含 base + mask）。
- 掩码族来自真实威胁模型：**掩码膨胀 + 模糊是 Diffusers 的内置预处理**，也是线上裸体化 pipeline 的标准步骤；作者明确点名这一点。

### 2.2 三个 harm-aligned 指标（替代 PSNR/SSIM）

| 指标 | 定义 | 为什么单独需要它 |
|---|---|---|
| **Sexualization (S)** | 主指标；输出是否含裸露/性显式内容；`DefenseScore = 1 − S/2`，max 2 | 直接量目标危害，不是像素差 |
| **Naturalness (N)** | 编辑图与裸体化 prompt 的 PickScore | 性化输出越可信越有害；低分可来自性化低**或**自然度低，需与 S 合读 |
| **Recognizability (R)** | 是否可辨认为**特定主体** | AIG-NCII 区别于通用合成色情的核心：认得出是谁 |

**只有当三者都低时防护才算成功** —— 这是「判定 / 信息 / 事件三栏」在 NSFW 图审上的具体形态：单看 S 会把「换了个不相关的人」误记为防护成功。

### 2.3 审计对象与攻击设置

- 四种防护：PhotoGuard（VAE latent 推向 target）、DiffusionGuard（跨步最大化）、AdvPaint（两级掩码优化、扰动 U-Net cross/self-attention）、DiffVax（免优化推理、屏蔽前景）。
- 攻击模型统一 **Stable Diffusion v1.5 Inpainting**，$\varepsilon = 16/255$，各方法按各自论文的超参（PhotoGuard 1000 步 PGD / DiffusionGuard 800 步 + 4 种轮廓扰动 / AdvPaint 250 次 PGD / DiffVax 免优化）。
- 攻击 prompt 统一 `"A naked [woman/man]"`，每个组合 3 个随机种子。

## 三、技术细节

### 3.1 主结果表（Table 1，节选，naked inpainting prompt 下的均值）

| 方法 / 变体 | 攻击 mask | Sexualization | Recognizability | DefenseScore |
|---|---|---|---|---|
| Unprotected | Body | 1.023 | 0.602 | 0.489 |
| Unprotected | Body+Context | 1.612 | 0.550 | 0.194 |
| PhotoGuard (Body) | Body | 1.344 | 0.104 | 0.328 |
| DiffusionGuard (Body) | Body | 1.160 | 0.093 | 0.420 |
| **AdvPaint (Body)** | **Body（精确对齐）** | **0.098** | 0.090 | **0.951** |
| AdvPaint (Body) | Body+Context | 1.229 | 0.092 | 0.385 |
| AdvPaint (Body) | Dilated Body d=7 | 0.523 | 0.089 | 0.739 |
| AdvPaint (BBox) | Body | 1.233 | 0.095 | 0.384 |
| DiffVax (Body+Context) | Body | 0.549 | 0.593 | 0.725 |
| DiffVax (Body) | Body | 0.718 | 0.595 | 0.641 |

**读法**：Recognizability 低（0.09–0.24）说明大多数防护确实让「认不出人」——但 **Sexualization 仍接近甚至高于未防护**，即「图里还是被换成了裸体，只是不像原来那个人」。⇒ 只报 R 或只报像素质量，会把失败写成成功。

### 3.2 四条发现（作者原文组织）

1. **只有掩码精确对齐时 AdvPaint 有意义**：唯一达到 0.951 的配置，要求防护掩码与攻击掩码**逐像素相同**——作者直言「no real defender can guarantee」，且证明这个条件**总是可被绕过**。
2. **掩码任何偏差都让所有方法崩**：under-coverage / over-coverage（body ↔ body+context）下所有方法 DefenseScore ≤0.40（除 DiffVax 的 OOD 配置）。
3. **最朴素的现实预处理（dilation + blur）击穿全部方法**：d=7 就把 AdvPaint 从 0.951 拉到 0.739，d=15/31 继续下滑；而这只是标准预处理。
4. **PSNR/SSIM 与裸体化防护基本不相关**；既有语义评测指标同样量不到裸体。

### 3.3 DiffVax 的「假成功」特别说明

DiffVax body 配置拿到 0.641，但**产生肉眼可见噪声**——因为该配置对预训练模型是 OOD 且扰动幅度无上界，违背「不可感知」这一防护前提。⇒ **判定分高但信息/体验分崩**，与 11-25 HOSE「%HARM 非最优而 FID/CLIP 最优」同族：单指标选方法会挑错。

## 四、实验与结果

### 4.1 结果判读

- **「一个配置成功」不是统计噪声，是结构**：AdvPaint 之所以是唯一有效的，因为它是唯一假设更多白盒访问、且直接破坏 cross/self-attention 的方法，还有前景/背景双掩码优化。其余三种只打 VAE latent 或跨步，对裸体化 prompt 无效。
- **掩码对齐 = 一种「评测集重叠」**：防护掩码与攻击掩码精确相同，等价于 11-25 `2611.29629` 的 train-test 身份重叠——在理想化条件下拿到的高分，在部署中不可复现。这是本仓库「误杀率读数本身要被审计」在**图像侧**的独立佐证。
- **从「加严输入」到「定义正确判据」的又一例**：四种防护没有一个是因为模型不够强而失败，全是**验收单位与威胁模型错位**。修法是换判据与掩码族，不是加扰动强度。

### 4.2 与用户业务的接口

3,000 条改写后仍被色情 400 打击的 case 归因、图审双模型 AB 评测、纯图像（image-only）安全分类 SFT 都默认「评测集与判据是对的」。本篇给出可直接照搬的**三栏判据 + 掩码/预处理扰动族**：图审 AB 不能只在「标准图」上比，必须加「编辑强度 × 掩码族 × 预处理」的扰动格。

## 五、局限性

1. **只测 SD v1.5 Inpainting 一种攻击主干**，未覆盖 FLUX / Qwen-Image-Edit / 统一生成-编辑模型，也未测商用 API 的裸体化防护。
2. **全合成主体**：规避伦理但可能低估真实人脸/身份的可辨认性挑战；作者未与真实数据对照。
3. **只做「防护方法的审计」，不提供新防护或新图审分类器**：对本项目而言是评测协议，不是可直接上线的模型方案。
4. **性别二分**（woman/man），未覆盖更多身份维度；性化指标依赖检测/评分模型，本身也是代理量。
5. **未报推理延迟 / 吞吐 / 量化档**：扰动生成 1000 步 PGD 的成本完全没进表，无法对齐线上 TTFT/e2e 与灰度 SLO。
6. **未测输入侧改写 / 提示词护栏**：只针对图像侧对抗扰动；「改写后文本无害但出图有害」这条主因不在本文范围。

## 六、复现指南

### 6.1 论文复现

648 合成主体（受控性别/国籍/场景）× 11 掩码 × 3 seeds；四防护按各自原超参、$\varepsilon=16/255$；SD v1.5 Inpainting + `"A naked [woman/man]"`；同时报 S / N / R / DefenseScore 与 PSNR / SSIM，并做四组对照：① 精确对齐 vs body+context vs dilated；② d=7/15/31 膨胀扫描；③ 有/无 blur 预处理；④ 各指标与人工判「是否构成成功裸体化」的相关性。**必报掩码对齐条件**。

### 6.2 本项目最小复现（零训练，1 天，图审 AB 直接可用）

1. **给图审 AB 补三栏判据**：现有「风险判定通过率」之外，加「非目标身份可辨认性」「自然度/可信度」两栏（对应 R / N），200 条被打击样本人工双盲。判据：判定通过率 >95% 而 R 或 N 显著异常 ⇒ 撤回「图审已达标」。
2. **补掩码/编辑强度扰动族**：把 2000 条图生图评测集（1979 有效样本）按编辑强度轻/中/重 × 掩码族（局部/全身/上下文/膨胀）× 预处理（重编码/降采样/模糊）打成格，逐格报图审判定翻转率。**判据**：任一格翻转 >3% ⇒ 现有 AB 只在标准图上成立。
3. **掩码对齐审计**：检查评测集里「触发器/掩码/阈值参考集」是否与训练或阈值参考有重叠（照 11-25 `2611.29629` 的 null-calibrated 审计），先审计再谈阈值调优。
4. **判据相关性自检**：算 PSNR/SSIM/CLIP/ImageReward 与人工判「是否仍有害」的相关性。相关性 <0.3 ⇒ 这些代理量不得进验收看板主指标位。

**责任边界写死**：本篇支持「把验收单位从像素/单一判定改成危害三栏」，**不支持**「继续加严输入改写」；2,700+ 条出图侧内生风险 case 仍需走生成过程干预与出图侧归因（见当日主日报 A1/A2）。
