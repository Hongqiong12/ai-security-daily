# 过了十，"数词还管不管用"和"命中率是多少"是两个问题

**论文主页**: https://arxiv.org/abs/2611.06840
**领域**: T2I 计数能力 / 同噪声单因子对照 / 评测指标的可分辨性
**作者**: Liang Yue, Eric A. Vance
**机构**: University of Colorado Boulder
**发布日期**: 2026-11-04（v1，cs.CV）
**分类**: benchmark
**模态归属**: T2I 生图模型行为评测 · 评测指标的"可分辨性"检验方法

---

## 一、背景与问题

### 动机

数不清是 T2I 最顽固的失败之一，且**越大越差**：过十之后，开源闭源都很少精确。

但论文问的是一个更基础的问题：**过十之后，那个数词还在起作用吗？**

> 一个松跟随数词的模型和一个完全忽略数词的模型都很少精确，所以**精确匹配率无法区分它们**。

这是本轮最锋利的一条方法论论断，而且它不是靠"更好的模型"解决，而是靠**换测量方式**。

### 关键背景：噪声可能已经决定了数量

已有工作（Zhao et al.）发现：在合成计数数据上微调的模型里，**固定噪声倾向于给出同一个数量，不管 prompt 要多少**。如果数量是由噪声定的，数词还剩下什么作用？

### 三条论断

1. 每个模型对数字的跟随都有**一个射程（reach）**：射程内跟随，射程外只保留布局。
2. 射程外，**布局由粗尺度噪声固定，而数量由细尺度噪声决定**——重画"比八分之一更细"的噪声，能把大群体的数量推动到数词效果的**三分之二**。
3. **测量方式决定结论**：过十之后，exact-match 与 relative-error 几乎无法区分"跟随"与"忽略"，而"同噪声排序检验"可以。

## 二、核心方法

### 2.1 同噪声协议

采样是确定性的：**一个物体 + 一个起始噪声 = 一张图**。因此可以固定其他一切，只改一个因子：

| 干预 | 改什么 | 期望（若数词仍有效） |
|---|---|---|
| 改数字 | 12 → 25 | 同一噪声下，更大的请求应给出更多物体 |
| 换种子 | 固定数字，换噪声 | 对照组：数量变化应小 |
| 改数词拼写 | "twelve" → "12" | 对照组 |
| 加无关词 | 加一个与数量无关的修饰 | 对照组 |
| **只重画细尺度噪声** | 保留 >1/8 图幅的粗结构 | 对照：若数量由细噪声定，数量会动而布局不动 |

**判据**：如果数词还在引导人群，那么大请求应给出更多物体，且"新数字"应该把数量推得比"不动数量的改动"更远。

### 2.2 三个计数器 + 人

每张图用三个检测器计数；**3,088 张由从未见过 prompt 的人**独立计数（避免"照着 prompt 数"的确认偏差）。

人的计数还提供一个**参照噪声**：人的计数本身有方差，用它校准"数量变化多少才算真的变了"。

### 2.3 射程（reach）的定义

模型能跟随的请求范围。测量方式：对同一噪声下的成对图，看"更大请求是否给出更多物体"的比例。

- 射程内（2–8）：**80–99%** 的同噪声对（计数不同的那些）满足"更大请求给更多物体"；
- 射程外：这个比例落到噪声水平。

## 三、技术细节

### 3.1 五个模型，四条射程

| 模型 | 射程 |
|---|---|
| SD3.5-M | 十之后很快就停 |
| FLUX.1-dev | 十之后很快就停 |
| FLUX.2 [klein] | 松散跟随到 25 |
| Qwen-Image | 松散跟随到 25 |
| SDXL | （作为基线纳入） |

**"松散跟随到 25"不等于"能数到 25"**——它只是"比噪声估计器稍好"。

### 3.2 布局与数量的分离

射程外，SD3.5-M 的表现：

- 同一噪声下换一个新数字：**布局基本保持**（缩略图相关性高），但**数量变化与换随机种子相当**，且**方向不一致**；
- 只重画细于 1/8 图幅的噪声：**布局保持得一样好**，而大群体的数量被推动了**数词效果的三分之二**。

结论：**射程外，粗尺度噪声定构图，不定数量。**

### 3.3 数词确实到达了去噪器

作者做了机制侧检查：

- 大数可以在 SD3.5-M 的条件里按顺序读出；
- 在三个被测模型里，**数词在前几个去噪步起作用**。

但：

> 数词仍然到达去噪器并在最初几步起作用，但我们尝试的一切都没给它一个清晰的方向。

从放大数词到在计数人群上微调，都没能让大数字产生方向性。**"信号存在"与"信号有方向"是两件事。**

### 3.4 把数量"画"进噪声里

如果起始 latent 里放一个**带噪声的网格**（数量个物体的排布），SD3.5-M 在 **59%** 的图里画出了请求的数量（按人的计数），而**只靠 prompt 只有 4%**。

补充两条：
- 植入的数量能抵抗冲突的数词；
- 换个物体词会把网格重绘掉。

⇒ **数量可以作为一种布局被传递**，而随机噪声自带的布局不能。

## 四、实验与结果

### 4.1 主结果

| 现象 | 数 |
|---|---|
| 射程内（2–8）同噪声对满足"大请求给更多物体" | **80–99%** |
| 射程外，重画细噪声 vs 数词对数量的推动比 | **2/3** |
| 射程外，数词对数量的方向性 | **无** |
| 植入网格 vs 纯 prompt 的数量命中（人计） | **59% vs 4%** |
| 人计数的图 | **3,088** |

### 4.2 指标的可分辨性（本轮最重要的一张"负结果表"）

| 指标 | 过十之后能否区分"松跟随"与"忽略" |
|---|---|
| **exact-match** | **几乎不能** |
| **relative-error** | **几乎不能，甚至偏好常数猜 16** |
| **同噪声排序检验** | **能** |

> 过十之后，exact-match 与 relative-error 几乎不能把"跟随"与"忽略"分开，而"同噪声排序"可以。

**relative-error 偏好常数 16** 这一条尤其值得记住：一个**完全不看 prompt、永远输出 16** 的退化策略，在相对误差上能赢过真的在跟随的模型。这不是"指标不够好"，是**指标的方向错了**。

### 4.3 一条附带的能力结论

"数量作为布局"能工作，"数量作为 token"不能。这对**生图侧的可控性**有直接含义：想让模型画 20 个东西，把它画进 latent，别写在 prompt 里。

## 五、局限性

1. **只测五个开源模型**，闭源（GPT-Image、即梦、可灵）未测。
2. **计数本身是瓶颈**：三个检测器 + 人工，大群体的检测误差会与模型误差混在一起。论文用人的计数做参照噪声来缓解，但没有完全分离。
3. **只测"数量"这一个属性**。同样的"同噪声协议"没有推广到颜色、位置、材质等其他可控属性。
4. **"方向"的缺失是负结果**，论文没有给出让大数字产生方向的方法（微调也不行）。
5. **与安全无关**。论文不涉及任何内容安全维度，迁移是纯方法论的。
6. **射程的估计依赖成对样本量**：每个物体/数字组合的样本数有限，射程边界本身有不确定性，论文给了区间但没有做正式的边界检验。

## 六、复现指南

### 6.1 环境

- 五个开源模型 + 确定性采样（同 seed 同 prompt 必须复现同图）
- 三个计数检测器 + 人工计数子集
- 公开物：3,088 张人计数图（作者声明将发布）

### 6.2 最小复现路径（迁移到我们的评测集）

1. **做一个"同源对照"子集**（半天，零标注）。取现有评测集里 200 条，对每条固定图像（或固定 prompt + 固定种子），**只改标签维度**，生成 3 个变体。看模型的判定是否随该维度单调变化。
2. **算"退化策略基线"**（1 小时）。对每个指标，算出"永远输出多数类"的得分。**如果退化策略的得分接近或超过真实模型，这个指标在该数据集上不可用。** 论文的 relative-error 偏好常数 16 就是这个检查的结果。
3. **报"可分辨性"而不只报"绝对值"**（半天）。对每个指标，报它在"已知强弱两个模型"之间的差值。差值为 0 的指标，不管绝对值多好看，都不能用来做决策。

### 6.3 迁移时最容易做错的三件事

1. **用 exact-match 型指标做唯一验收**。我们的"一级一致率 77.64%"就是 exact-match 型。
2. **在标签分布不均衡的数据集上比 relative-error 类指标**。恒定策略会赢。
3. **假设"信号存在"等于"信号有效"**。论文证明数词到达了去噪器前几步，但没有方向。

---

## 附：与业务的三条硬对应

1. **77.64% 这个数需要一次"可分辨性"体检**。它是 exact-match 型指标。按论文的教训，要先回答两个问题：（a）"永远输出多数类"能拿到多少？（b）在"已知明显更差的旧版本"与"当前版本"之间，这个指标的差值是多少？**如果（a）接近 77.64%，或（b）差值 <2 点，那么这个数不能用来判断版本进步。**
2. **"同噪声"就是我们要的"同源对照"**。评测集应保证：同一张图（或同一 prompt + 同种子），只改一个标签维度。这样"模型在跟标签"与"模型在输出先验"才能分开。这条对图审 AB 与 I2I 改写评测都直接可用。
3. **数词"到达但没方向"是一个通用的失败形态**。我们的改写也可能"到达但没方向"：改写后的 prompt 确实变了（token 改了、长度变了、模型确实读到了），但风险方向没有变。**"改写生效"（token 变了）与"改写有效"（风险降了）必须分开测**——这正好是 I2I 0/0% 里缺的那一层。
