# Attractive Faces Skew Text-to-Image Reward Models and Leaderboards

**论文主页**: https://arxiv.org/abs/2610.28195
**领域**: T2I 奖励模型 / 偏好模型偏置审计
**作者**: Harvey Mannering, Zhiwu Huang, Adam Prügel-Bennett
**机构**: University of Southampton（作者既往单位，以论文正文为准）
**发布日期**: 2026-10-20（v1）
**分类**: attack（对奖励信号的污染攻击面）／benchmark（偏置审计协议）
**模态归属**: T2I 生成侧 + 奖励侧，直接作用于 RL 改写的奖励设计

---

## 一、背景与问题

### 动机

人类偏好模型（PickScore、MPS、HPSv2.1、HPSv3、ImageReward）现在承担了 T2I 生态里几乎所有"好/坏"的判断：
- 做**奖励函数**（RL 微调、AlignProp、DRaFT、ReNO）；
- 做**评测指标**（论文里的"我们的模型更好"）；
- 做**数据过滤**（训练集筛选）；
- 做**榜单排名**（LMArena 的 Elo）。

如果这些分数里混进了与任务无关的强相关因素，那么整条链路——训练、评测、排名——都会被同一个偏置污染。

### 核心科学问题

**偏好判断里，"图像质量"到底占多少权重？** 论文给了一个极尖锐的答案：对面部图像，**感知吸引力（perceived attractiveness）会覆盖图像质量**，即使是拿真实照片（保真度可控、甚至更高）与 AI 生成图对比，标注者仍然把"更漂亮的那张"判为"质量更高"。

### 为什么这篇对我们重要

我们的 RL 改写策略，奖励来自 Qwen-Image 类模型的**图像一致性**信号。所有这类"打分器"都有同一类风险：**它衡量的不是你要它衡量的东西**。

这篇论文提供的不只是"存在偏置"这个结论，而是**一整套可复用的偏置归因方法**：
1. 用**单属性编辑**（Diffusion Autoencoder 逐属性改）把"图像变了什么"控制成单一变量；
2. 看**奖励分数与编辑强度的相关系数**，谁是 top-1；
3. 用 **LASSO 正则化路径**看哪个属性"最后被剔除"，即谁是主导预测因子；
4. 用**真实图**（保真度恒定）排除"质量混杂"；
5. 用**引导生成**（ReNO / AlignProp / DRaFT）验证因果，而不只是相关。

这五步可以直接搬去审计我们的图像一致性奖励：**它到底在衡量一致性，还是在衡量"好不好看"？**

## 二、核心方法

### （1）用户研究（先证明人本身有这个偏置）

- 51 人参与，剔除 4 人（撤销同意/未完成），有效 **47** 人；
- 每人看 20 组、每组 4 张脸，随机分配 5 套图之一 → 共 **400** 张图；
- **关键设计**：一半图是真实 CelebA-HQ 照片，一半是 AI 生成（CelebA-HQ RelayDiffusion）。但参与者被告知"全是 AI 生成的"，因此他们的任务是"挑哪张生成得更好"。
- 因为真实图内部保真度可比（且天然比生成图更真实），**只用真实图内部的排序**就能把"保真度混杂"消掉。
- 每人另给每张脸打 3 个主观分（0–100）：可信度、熟悉度、**吸引力**。
- 两种指令措辞：**"图像保真/质量"** vs **"个人审美偏好"**。

统计：每人内部先对吸引力差取平均（保证观测独立），用单侧 Wilcoxon 符号秩检验 + Holm 校正。

**结果**：
- "保真度"指令：p = **0.0018**；"审美"指令：p = **0.0006**——两种措辞下都显著偏向更漂亮的那张；
- 两种措辞之间比较（Mann–Whitney U）：p = **0.028**——**"审美"措辞的偏置比"保真度"措辞更大**；
- 可信度也有同向但更弱的效应；熟悉度不显著。

### （2）榜单传染（Elo 模拟）

用用户研究的偏好数据做 **10,000 次 Elo 模拟**（初始 1500，K=64），两支队伍：
- A 队：**不那么好看的真实图**（平均吸引力 **34.1**）
- B 队：**更好看的 AI 生成图**（平均吸引力 **67.9**）

结果：**好看的 AI 队领先 ≈ 124 Elo 分**。

反向选择（更好看的真实图 63.5 vs 更差的 AI 图 53.7）：真实图只取得"微弱领先"。

**结论非常锋利**：决定胜负的是**相对吸引力**，不是图像来源。**一个只会生成更漂亮的脸、但质量更差的模型，可以在偏好榜单上赢过更强的模型。**

### （3）奖励模型审计（谁在给"漂亮"打分）

- 100 张 CelebA-HQ 底图（256×256），用预训练 **Diffusion Autoencoder（DiffAE）** 逐属性编辑，40 个属性 × 4 个编辑强度（−0.5 ~ 0.5）→ **16,000** 张合成图；
- 对每张图跑 7 个打分器：LAION-Aesthetics、CLIP（两个非偏好控制组）+ ImageReward、PickScore、MPS、HPSv2.1、HPSv3（五个偏好模型）；
- 算"奖励分数 vs 编辑强度"的相关系数。

**结果**：
- **5 个偏好模型里，4 个的 top-1 相关属性就是 "attractive"**（PickScore、MPS、HPSv2.1、HPSv3）；
- 两个**非偏好**控制组行为不同：LAION-Aesthetics 没有明显主导属性；CLIP 的强相关走的是**与女性关联的属性**（戴耳环、浓妆），而不是吸引力本身；
- 由于多数偏好模型是从 CLIP 微调来的，"吸引力成为 top-1"**是偏好对齐引入的，不是 CLIP 自带的**；
- **ImageReward 受影响最小**，且换成 LLM 生成的 caption 后偏置基本消除——作者的解释是它的标注指令**最少强调"个人偏好/审美"**，最强调"图文对齐、高保真、无害"。

### （4）排除"质量混杂"（真实图验证）

合成图的属性编辑可能顺带提了画质。所以换真实图（保真度恒定）再测：
- HPSv3 在 **SCUT-FBP5500**（1–5 连续美感分）上 r = **0.35**；
- 在 **CelebA-HQ**（二分类吸引）上 r = **0.35**；
- 说明偏置**不能归因于合成图的画质变化**。

再用 **LASSO 正则化路径**看谁最"顽固"：吸引力属性一直保留到 λ_L = **0.63** 才被剔除，是 HPSv3 分数**最强的预测因子**。

### （5）因果验证（引导生成会不会真的变漂亮）

这是最关键的一步——前面都是相关性，这里做干预：

- **微调路线**：SD v1.5 + AlignProp（奖励 = HPSv2.1，prompt 取自 HPD）；DDPM + DRaFT-K（K=1，奖励 = PickScore）。各训 3 epoch，每 epoch 生成 5,000 张（50 步）。
  → 两个模型的**平均预测吸引力随训练单调上升**，且生成人脸的**人口分布明显变年轻、更偏女性**。
- **引导采样路线**：ReNO + HPSv2.1，prompt 固定为 **"a photo of an unattractive face"**，优化 20 步，PixArt-α / SD-Turbo。
  → **奖励应该把图推向"更好的图文对齐"，结果把它推向了"更漂亮的脸"**。也就是说，**对齐过程直接抹掉了"生成不好看的脸"这个能力**——用户控制被剥夺。

这一段把"偏置"从"指标不干净"升级为"**能力被删除**"。

### （6）缓解：最小化互信息

目标行为定义得很清楚：**只有当 prompt 明确要求时，分数才应该依赖吸引力**。评测 prompt 没提吸引力，所以分数 S 应当与吸引力 A **独立**。

于是设计损失：

  L = I(A; S) + λ · d(S, S_hat)

用 **核密度估计（KDE）** 算互信息 I(A; S)；第二项约束修正后的分数不要偏离原分数太远（保住有用信号）；λ 做权衡。**不改图像**（吸引力是图像的主观属性），而是**改分数**——用一个简单的残差函数 S_hat = S − f(A) 之类的形式，便于往新域快速适配。

（论文正文把具体残差式放在公式里，此处不复述符号细节，只保留"改分不改图 + 互信息归零 + 保信号"这三个约束。）

## 三、技术细节

### 审计设计的三个可复用点

1. **单属性编辑 + 相关系数排序**：把"这张图变好了"拆成"哪个属性的强度变化"。这比"用两批图对比分数"精确得多，因为它控住了其他 39 个属性。
2. **正则化路径（LASSO λ 路径）替代特征重要性**：不用 SHAP 之类的近似，直接看"属性在多大 λ 下才被剔除"，天然带"顽固程度"排序。
3. **真实图作对照**：合成图的编辑总会带画质副作用，真实图（保真度恒定）是唯一能干净排除混杂的对照。

### 一个反直觉但重要的细节

**换更好的 caption 不能解决问题**。用 LLM 生成的 caption 后，相关性**降低但不消失**（ImageReward 是唯一例外）。这说明偏置不在"文本条件"，而在**分数本身的形成机制**——偏好对齐把"人喜欢什么"编码进去了，而人喜欢漂亮的脸。

### 量化汇总

| 项 | 数值 |
|---|---|
| 用户研究 | 47 有效参与者，400 图，p = 0.0018 / 0.0006 |
| 措辞效应 | "审美" vs "保真" p = 0.028 |
| Elo 模拟 | 好看的 AI 队 **+124 Elo** |
| 属性审计 | 16,000 张合成图；4/5 偏好模型 top-1 = attractive |
| 真实图相关 | HPSv3 r = **0.35**（两个数据集一致） |
| LASSO | attractive 保留至 λ_L = **0.63** |
| 生成干预 | AlignProp / DRaFT 训练中吸引力单调上升；人脸变年轻、更偏女性 |
| 用户控制 | ReNO 优化 "unattractive face" → 反而更漂亮 |

## 四、实验与结果

### 有效的地方

1. **因果链完整**：人 → 榜单 → 奖励模型 → 生成结果 → 能力删除。五段都做了，不是只报相关性。
2. **控制组设计到位**：LAION-Aesthetics（非偏好、纯美学）与 CLIP（非偏好、图文对齐）行为不同，恰好证明"吸引力 top-1"是**偏好对齐**引入的，而不是任何视觉模型的通病。
3. **真实图对照排除了最关键的反驳**（"是不是合成图画质差异导致的"）。
4. **ReNO 实验是全文最强的一击**：奖励的语义是"图文对齐"，实际行为是"变漂亮"，这是**奖励语义与奖励行为分离**的直接证据。
5. **缓解方案有明确的目标函数**（互信息归零 + 保信号），不是"多说几句注意公平"。

### 站不住 / 需要警惕的地方

1. **只在人脸域验证**。结论"吸引力覆盖质量"高度依赖人脸（人脸是吸引力偏置最强的刺激）。对**非人脸**（风景、物体、场景）是否有同类"单一属性主导"的偏置，论文没说。而这恰恰是我们业务的主战场（NSFW 场景多数不含人脸或人脸不是判定依据）。
2. **缓解方案的可迁移性弱**。互信息去偏需要一个**可测量的偏置属性** A（这里 A = 吸引力，有 DINOv3 微调的预测器）。对我们的图像一致性奖励来说，**"要消除的那个属性是什么"并不清楚**——这可能是"美观"、"饱和度"、"人脸占比"，也可能是"看起来更像训练集"，而这些都不是单一可测标量。
3. **Elo 模拟用的是本研究收集的偏好数据**（47 人、400 图），规模很小，模拟出的 124 分差更像是**机制演示**而不是对真实榜单的定量估计。
4. **"审美 vs 保真"措辞的效应虽然显著（p=0.028），但效应量没报**，无法判断实际可操作价值。
5. **没有测"去偏后的奖励是否还有用"**。互信息归零 + 保信号这两个目标本质冲突，λ 怎么选、去偏后 RL 训练效果如何，论文没给下游任务结果。

## 五、局限性

1. **单域（人脸）、单属性（吸引力）**，泛化性未知。
2. **样本量小**（47 人），用户研究的统计功效有限。
3. **去偏只在分数层做**，没有回到数据层（标注指令设计）做系统实验——虽然它提示了"ImageReward 因为指令强调保真而无偏"这条更根本的路径，但没验证"改标注指令能否系统性去偏"。
4. **未讨论安全维度**：吸引力偏置与 NSFW 风险的关系没碰。但有一个危险的隐含推论——如果奖励模型偏好"更年轻、更偏女性"的脸，那么在用偏好奖励做安全对齐时，可能**同时把生成分布推向更高风险的人像**（年轻化 + 女性化是 NSFW 风险画像的已知相关因子）。论文完全没提这一层，但对我们极其重要。
5. **没有开源去偏实现细节**（KDE 带宽、λ 搜索范围）。

## 六、复现指南

### 6.1 复现要点

```
1. 用户研究：4 张脸排序 + 3 个主观属性打分（可信/熟悉/吸引）；
   一半真实 CelebA-HQ、一半 RelayDiffusion 生成；两种指令措辞（保真 vs 审美）
2. 榜单模拟：10,000 次 Elo（init 1500, K=64），按吸引力分组构造两队
3. 属性审计：DiffAE 编辑 40 个 CelebA-HQ 属性 × 4 个强度 × 100 底图 = 16,000 图；
   算 reward 分数与编辑强度的相关系数；非偏好控制组用 LAION-Aesthetics + CLIP
4. 真实图对照：SCUT-FBP5500（连续美感 1–5）+ CelebA-HQ（二分类吸引），常数 caption
5. LASSO 路径：标准化属性 → 递增 λ_L → 记录每个属性被剔除的 λ
6. 因果验证：
   - AlignProp(SD1.5, reward=HPSv2.1, prompt 来自 HPD) 3 epoch
   - DRaFT-K(DDPM, K=1, reward=PickScore) 3 epoch
   - 每 epoch 生成 5,000 图（50 步）
   - ReNO(reward=HPSv2.1, 20 步) + prompt "a photo of an unattractive face"
   吸引力预测器：DINOv3 在 CelebA-HQ 上回归 0→1
7. 去偏：min I(A;S) + λ·d(S, S_hat)，KDE 估互信息
```

### 6.2 复现风险点

- DiffAE 的属性编辑强度是相对的，不同底图上的"−0.5"视觉幅度不一致，相关系数的绝对值不可跨数据集比；
- Elo 模拟对 K 值与配对顺序敏感，作者用随机化顺序缓解；
- 吸引力预测器（DINOv3 微调）本身的误差会传导到"平均吸引力"曲线；
- ReNO 的结论依赖"模型本来能画不好看的脸"，若底模已失去该能力则无法观察。

### 6.3 对我们最有用的最小实验（奖励审计）

**给现有 RL 改写的图像一致性奖励做一次"属性敏感性审计"**——不训练，只测：

1. 准备 100 张**内容相同、只在某一个属性上变化**的图对（可以用 Qwen-Image 以固定 seed 微调 prompt 生成，或用 img2img 做单属性编辑）。
2. 选 5 个候选属性：**语义内容一致性**（要它衡量的）、**美观度**、**饱和度/对比度**、**人脸占比**、**分辨率/锐度**（不希望它衡量的）。
3. 对每对图算奖励分差 ΔS，看 ΔS 与各属性变化量的相关。
4. 判据：**如果"美观度"或"锐度"的相关性 ≥ "语义一致性"的相关性，奖励信号就已经被非目标属性主导**——此时 RL 优化会往"更好看"而不是"更保真"走，改写的保真约束会被抵消。

这个实验的价值在于：**它能在不跑 RL 的前提下，提前判断奖励信号是否可用**。如果审计发现奖励被非目标属性主导，那再做 tag-weighted 或 edit-rate 约束都是在错误的地基上加码。
