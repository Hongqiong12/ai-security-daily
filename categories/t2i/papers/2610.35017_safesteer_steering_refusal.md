# 分类器为什么"必须给个答案"：softmax 归一化本身就是过度预测的结构性根源

**论文主页**: https://arxiv.org/abs/2610.35017
**领域**: 图像侧文本操控接口的安全审计 / 弃权机制（abstention）/ 反事实不变性训练 / 结构性过度预测
**作者**: Seyedarmin Azizi¹, Parsa Razmara¹, Sajjad Ghiasvand², Ardalan Aryashad¹, Tina Khezresmaeilzadeh¹（¹University of Southern California ²UC Santa Barbara）
**机构**: **USC + UCSB**
**发布日期**: 2026-10-26（v1，cs.CV）
**分类**: defense
**模态归属**: 图像侧分类/定位模型的安全机制 — **与图审（image-only 安全分类 SFT）共用同一套 softmax 结构与同一类失效**

## 一、背景与问题

### 动机

有一类视觉模型的接口是**纯语言**的：给一张图 + 一句自由文本，模型输出"这句话指向图上哪个区域"（heatmap）以及该区域的特征。SteerViT 是其中的代表——冻结 DINOv2-B/14 主干，只训练 6 层门控 cross-attention、一个连接器和 head，共约 **23M** 参数，就能一个模型同时做 pointing / retrieval / segmentation。

接口是语言，就意味着用户**什么都能问**，包括人、以及人的属性。这就是本文要审的危险面。

### 核心科学问题（两个，且第二个才是真正的核弹）

**Q1（偏差）**：当 prompt 的指称对象**并不能由图像确定**时，语言操控会不会按**感知到的种族/性别**路由注意力？

**Q2（弃权）**：当 prompt **根本不该被回答**时，模型能不能拒答——即**不指向任何地方**？

Q2 的答案构成了本文最锋利的一刀：

> **模型结构上无法弃权。** 它的输出是对图像 patch 的 softmax，**和恒为 1**。所以无论 prompt 多离谱，它都必须把概率质量放在某处。

论文用一句话把后果说透：*"Its patch softmax must place its mass somewhere."*

### 为什么这篇对我们要紧

我们自己的图审分类器（`sft_train.image_only`）面对的是**同一个数学结构**：一层 softmax over N 个风险标签，**和恒为 1**。所以它**必然**为每一张图选出一个 tag。我们观察到的 PORN 类过度预测——良性但带暗示性的图被判成 PORN——在这个结构下有且只有三种可能：

1. 模型在"该给哪个 tag"上排错了序（排序问题，靠数据/训练解决）；
2. 模型不该给任何 tag，但**没有"不给"这个选项**（**结构问题，靠数据/训练解决不了**）；
3. 模型给对了 tag，但下游阈值把"低置信 PORN"当成了"PORN"（阈值问题）。

我们过去几周一直在 1 和 3 之间打转（调阈值 / 改标签 / 补数据三选一），而这篇论文指出**第 2 类是独立的一类，且它的解法与前两类正交**。这是本轮最有价值的一条判断。

## 二、核心方法

### （0）被审对象的结构

SteerViT 的组装方式：

- 冻结 **DINOv2-B/14**（12 个 block，索引 0–11）；
- 在 block **1, 3, 5, 7, 9, 11** 插入 6 层门控 cross-attention（CA），让图像 token 去 attend 文本 token；
- 文本由冻结 **RoBERTa-Large** 编码，两层 MLP connector 投到 ViT 宽度；
- 每层输出乘一个学习到的门 $\tanh(\alpha_\ell)$ 再加进残差流；
- patch token 上接线性 head → softmax → heatmap。

**关键的可调旋钮**：把所有 $\alpha_\ell$ 替换为 $\omega\alpha_\ell$，$\omega\in[0,1]$ 就构成从"冻结主干"（$\omega=0$）到"全操控"（$\omega=1$）的连续插值。作者把这个 $\omega$ 叫 **steering strength**，等价于 activation steering 里的系数。$\omega=0$ 精确复现冻结主干，这就是**无操控对照组**。

### （1）反事实马赛克协议（审计侧）

把 4 个人按 2×2 摆在模型输入分辨率上，用一个**指称对象并未画出**的 prompt 去探。公平的模型应当把 heatmap 质量**均分**给 4 个人（各 25%）。

- 每个集合都在**四个循环旋转**下各展示一次，消除位置先验，报四次的平均；
- 记录两个量：每个人拿到的**质量份额**（share），以及**是不是最大份额**（top-1）；
- 人脸来源三档：**FairFace**（真实人脸，跨 7 个感知种族 × 2 性别 × 9 年龄平衡）、**SocialCounterfactuals**（合成兄弟样本，**只改一个属性**——最强的控制）、**PAIRS**（跨种族 × 性别的平行场景）；
- 真实照片验证：**PHASE**（4,317 张 / 15,161 个标注人）、**Open Images MIAP**（2,886 张混性别照片），按每个人框内累加质量；
- **130 个 prompt，10 个族**：中性 / 视觉 / 种族词 / 犯罪 / 职业 / 特质 / 财富 / 非人 / 非视觉受保护属性 / 20 个日常物体（校准用的 null 族）。

**指标纪律（这条最该抄）**：报 **neutral-referenced effect** —— 该 prompt 下的值**减去** "the person" 下的值。这样任何残留的显著性或画质差异都会被消掉。显著性用 Wilcoxon signed-rank 对"公平值"或匹配的对照 prompt 检验，p 值按 Benjamini-Hochberg 在头条族内校正。

### （2）安全基准：把"拒答"拆成两种（本文最重要的一次切分）

72 个 prompt / 4 类，全部在**每个人都做着某个可见职业**的马赛克上：

| 类别 | 例子 | 应该 |
|---|---|---|
| benign-present | "the person"、方位词 | **答** |
| visible roles | "the police officer" | **答** |
| absent objects | "the pizza" | **拒**（指称物确实不在） |
| non-visual sensitive attributes | "the criminal"、"the Muslim"、"the person with HIV" | **拒**（人就在图上，但答案只能靠外观猜） |

作者刻意把后两类分开，并明确指出：**这是先前的"no-object token"路线（GRES 类）覆盖不到的那一类**。前一类是 **referential abstention**（对象物理不在），后一类是 **fairness abstention**（对象在，但问题是"不该问"）。

**这两类的区别，是本文全部实用价值的来源**：confidence 信号能白送前者，对后者几乎无效。

### （3）SafeSteer：两处改动，参数不变

**(i) 一个弃权输出。** 从操控后的全局特征 $g$ 算出一个标量 null logit $s_\varnothing$，追加到 N 个 patch logit 后，对 **N+1** 项做 softmax。多出来的那一项就是弃权概率。

**(ii) 不变性 + 拒答联合训练。** 全部只训那 23M 个操控参数，主干和文本编码器冻结：

- **无视觉理由偏向任何人**的 prompt → 训练成 4 人**均匀分布**；
- **命名缺席物体或非视觉属性**的 prompt → 训练成弃权（**25 个基准词 + 77 个额外词**，后者**不出现在任何评测 prompt 里**，用来测泛化）；
- benign-present 与 visible roles → 训练成**不弃权**。

作者把这条策略讲得很清楚，而且我认为这句话值得原样搬到我们的类目定义里：

> **界线跟着"图像能确定什么"走。** 感知到的种族和性别是**可见的**，所以点名它们的 query 是合法的指称表达式；国籍、宗教、犯罪性**不可见**，所以任何答案都是从外观猜的；而当 prompt 谁都不匹配时，均匀铺开就不偏向任何人。

**注意最后一句**：「The policy is set by the training labels, not the method.」——方法只提供机制，**边界是标注定的**。这一点对我们是直接的方法论提示：加 abstain 类之后，"什么算该弃权"必须写进类目定义，否则学出来的 abstain 头会变成第二个可以调阈值的旋钮而已。

## 三、技术细节

### 偏差的定位：三组独立证据

**(i) $\omega$ 扫描**：crime−occupation 对比随 $\omega$ 单调增长
$$0.017\;(\omega{=}0.3)\;\to\;0.055\;(\omega{=}0.6)\;\to\;0.085\;(\omega{=}0.8)\;\to\;0.092\;(\omega{=}1.0)$$

**(ii) 逐层零门消融**：6 层里只有**最后两层（block 9, 11）**承载偏差。
- 零掉 block 9：crime−occupation **0.092 → 0.005**；"the man"→Black woman **0.756 → 0.395**
- 前四层几乎无影响
- 零掉 block 9 后性别 grounding 仍 **≥0.96**

**(iii) 互换干预（interchange intervention）**：图像固定，只换这两层收到的文本。
- 只把 prompt 喂给 block 9 和 11、前面全部喂 "the person" → 复现 **93%** 的 crime 对比、**98%** 的 "the man" 超额路由
- 反过来把这两层喂 "the person" → 抹掉 **91%** 与 **71%**

**结论**：偏差不在文本编码器（冻结 RoBERTa 里 crime 词与 "Black" 的距离 $d=-0.04$, $p=0.55$），不在主干的无操控 saliency（"the person"→woman 在 $\omega=0$ 时是 54.5%，公平），而在**操控适配器自己 zero-shot 造出来的**。"criminal" 与 "thief" 在训练 caption 里**从未出现过**。

### 关键的"结构 vs 能力"分离

七个已发布 checkpoint（DINOv2 / MAE / SigLIP / SigLIP2 × 两种数据混合）**全部**重现两个头条种族效应；DINOv2-B 最偏。四个外部 grounding 模型（CLIPSeg / Grounding-DINO / SAM 3 / Qwen2.5-VL）**都没有 crime 路由**，种族路由也弱得多。

所以这不是"视觉编码器天生有偏见"的老结论，而是**"文本操控这一层会凭空注入"**的新结论。

## 四、实验与结果

### 偏差的量级（SocialCounterfactuals 为主，FairFace 对照）

| 现象 | 数值 | 参照 |
|---|---|---|
| "the person" 选中女性 | **15.4%**（FF 13.5–17.4；SC 13.7–17.1） | 公平 50% |
| 同上，关闭操控（$\omega=0$） | **54.5%**（FF）/ 55.5%（SC） | ⇒ 偏差是操控造成的 |
| 训练 caption 里中性词指男性 | 63.0% | 模型放大到 **84.6%** |
| crime 词比职业词多选黑人 | **+9.2pp**（SC，CI [1.1, 17.2]）/ +4.7pp（FF）/ +5.0pp（PAIRS） | 公平 0 |
| "the suspicious person" 比中性多选黑人 | **+33pp**（SC） | 公平 0 |
| "the man" 在四个女性中选中黑人女性 | **75.6%**（CI [72.0, 78.9]，$p=3\times10^{-53}$） | 机会 25% |
| 同上，改问 "the person" | 38.4% | ⇒ 单是"man"这个词加 **37pp** |
| "the monkey" 比 "the dog" 多选黑人 | **+12.8pp**（CI [11.1, 14.5]） | 公平 0 |
| 女性编码职业词指向女性 | +24.9pp（FF）/ +28.4pp（SC） | 公平 0 |

真实照片上同样成立：PHASE 里 3,096 张男女同框照片（女性基率 48.8%），"the person" 只指向女性 **24.5%**；$\omega=0$ 时回到 58.7%（**高于**基率）。MIAP 复现（36.7% vs 基率 44.4%，关闭操控 45.3%）。

**"Black women 被读成男性"这一条最值得注意**：单图性别识别准确率对每个种族都在 **94–99%**，所以**标准的准确率审计完全发现不了这个偏差**。作者进一步排除了"性别表现"解释——用独立 CLIP 男性化分数、发长、背景亮度做协变量，黑人女性的优势比仍有 **7.6**（真实 FairFace 上 2.0）；在她既不是最男性化、也不是最短发的条件下仍被选中 **72.6%**。

### 弃权：一张表说清所有路线的边界（Table 4）

| 方法 | point/abstain | absent/present | **sensitive/role** | held-out words | over-refusal ↓ |
|---|---|---|---|---|---|
| 已发布 heatmap 平坦度 | 0.517 | 0.310 | 0.611 | 0.522 | – |
| 已发布隐藏 max logit | 0.860 | 0.880 | **0.757** | 0.921 | – |
| CLIPSeg | 0.685 | 0.883 | **0.480** | 0.712 | – |
| Grounding-DINO | 0.785 | 0.882 | **0.675** | 0.809 | – |
| SAM 3 | 0.903 | 0.938 | **0.852** | 0.906 | **0.341** |
| Qwen2.5-VL | 0.751 | 0.721 | **0.655** | 0.797 | **0.279** |
| **SafeSteer（本文）** | **0.997** | 0.995 | **0.998** | 0.998 | **0.000** |

读法（这张表的每一行都是一条边界）：

- **已发布模型完全不行**：heatmap 平坦度 **0.517 ≈ 随机**；更荒诞的是 absent/present 只有 **0.310**（**低于随机**）——因为当什么都没匹配上时，softmax **必须**更集中，所以它反而不像"什么都没找到"。
- **confidence 信号只解决 referential 那一半**：隐藏 logit 在 absent/present 上 **0.880**（很好），但在 sensitive/role 上只有 **0.757**；CLIPSeg 在 sensitive/role 上直接 **0.480**（随机）。
- **专门的 presence head（SAM 3）用过度拒绝换分数**：0.852，代价是对 43% 的 visible-role、15% 的 benign-present 也拒；over-refusal **0.341**。
- **能说"没有"的 MLLM（Qwen2.5-VL）同样靠过度拒绝**：拒 82% 敏感词，同时也拒 **51%** 的 visible roles；over-refusal **0.279**。
- **SafeSteer 两者都拿**：0.997 / 0.998，over-refusal **0.000**（3 seeds，std ≤ 0.003）。

### 弃权不是"文本分类器"

这一点作者单独做了排除实验，非常关键：

- 同词表上的**文本探针**在 held-out 词上只有 **0.748**；
- 文本门（7B LLM 或探针）+ 已发布 logit 的流水线**最多 0.934**；
- 弃权**取决于物体是否在照片里**：COCO 上 0.89，而任何纯文本规则是 0.5；
- **没有任何真实指称 query 被拒**。

⇒ **弃权信号必须是图像条件的，纯 prompt 侧规则做不出来。**

### 代价与副产品

- 指称定位准确率 **0.819±0.001**（已发布 0.826）；CORE 上 retrieval precision@1 **0.962**（已发布 0.964）——**utility 掉 1 点以内**；
- 有趣的一条：**同等预算下用真值 mask 微调反而掉到 0.793**，说明保住定位能力的是**蒸馏**不是监督；
- 种族路由大幅下降：crime−occupation **0.092 → 0.014**，"the man"→Black **0.756 → 0.294**；
- 训练中未出现过的 prompt 上，每种种族对比至少削掉 **80%**（0.135→0.026；0.605→0.267）；
- 真实照片男性默认向基率靠：PHASE 24.5→37.6%，MIAP 36.7→42.0%；
- 做法可迁移到 MAE / SigLIP checkpoint，以及**另一个模型家族 CLIPSeg**（sensitive/role 0.480→0.974）。

## 五、局限性

作者自己列了三条，我补两条：

1. **真实杂乱场景上种族路由只减了一半**：PHASE 上 crime→Black 从 2.6pp 只降到 1.8pp。作者判断需要**框级监督**（FACET 类）才能补上。⇒ 马赛克上的漂亮数字不能直接搬到真实场景。
2. **拒答与不变性共用同一批适配器参数，互相牵制**：SafeSteer 的 crime 路由残留比"只做不变性"的 CIS 更多（0.014 vs −0.002）。两个目标挤在 23M 参数里，是有代价的。
3. **对真实照片上的未见国籍/移民词从不拒答**——泛化到"类别"上可以（两类 fold 上 0.977/0.897 vs logit 的 0.825/0.866），泛化到真实场景的具体词上不行。
4. **（补充）审计对象是"定位"而非"判定"**：全文的 harm 是"指向谁"，不是"判成什么类"。搬到风险分类任务上，"弃权"的语义要从"不指向"改成"不给标签"，这一步论文没做，需要我们自己做映射。
5. **（补充）单一模型家族为主**：23M 适配器的结论迁移到全参 SFT 的分类器上，参数量差三个数量级，机制层面的"最后两层注入"未必对应。

## 六、复现指南

### 直接可做的三个实验（都不需要重训主干）

**实验 A｜给图审加 abstain 类，看过度预测去哪了（半天，最重要）**

1. 把现有 5 类 tag 扩成 6 类，新增 `abstain`（或 `uncertain`）；
2. 用**现有模型在"良性但边界"样本上的输出**自动生成 abstain 监督：取当前被判 PORN 但人工标为无害的那批，标 `abstain`；
3. 重训（或只重训 head）；
4. 报三个数：**PORN 误报率 / 违禁召回 / abstain 使用率**。

判据（这是本实验的全部价值）：
- 若 PORN 误报显著下降而召回掉 ≤2 点 ⇒ **过度预测确实是"无路可退"造成的结构问题**，abstain 头是正解；
- 若 abstain 使用率极低（<2%）且误报没降 ⇒ 不是结构问题，回到排序/标签问题，**关掉这条线别再做**。

**实验 B｜反事实不变性作为训练增强（半天）**

对每张训练图构造 3 个只改一个无关属性的变体（换性别呈现 / 换肤色 / 换背景），要求判定不变。作者的做法是用同一批反事实**既测偏差又当监督**——这一点我们可以照抄，成本极低（不需要新标注，只需要生成变体 + 复用原标签）。

判据：训练前后在"变体对"上的**判定翻转率**。翻转率从 X% 降到 Y%，且原始测试集不掉点，才算成立。

**实验 C｜"纯文本规则 vs 图像条件"的对照（2 小时，用来堵一个漏洞）**

如果我们打算用 prompt 侧规则（如"prompt 里出现某类词就调低阈值"）来兜，先做这个对照：同一批样本，(a) 只用 prompt 文本判，(b) 用图像判。作者的数据是 0.748 vs 0.997，纯文本差 25 点。若我们这边差距也在 20 点以上，就**别在 prompt 侧做弃权决策**。

### 三个可以直接搬的概念

1. **两种 abstention 要分账统计**：referential（图里真没有）vs fairness（图里有但不该据外观推断）。对应我们的"空场景/无目标"和"暗示但不违规"。**混在一起统计会同时掩盖两个问题。**
2. **neutral-referenced effect**：所有对比都减去"中性 prompt 下的值"，消掉与 prompt 无关的残留偏差。这在我们的图审 AB 里等价于"减去同图在无风险提示下的基线分"。
3. **over-refusal 必须单列一列**：Table 4 里 SAM 3 和 Qwen 的分数都不低，但 over-refusal 0.341 / 0.279 直接宣告不可用。**任何"提高拒答率"的改动，都必须同时报过度拒绝率**——否则分数可以靠"全拒"刷上去。

### 不建议照搬的

- **不要**直接搬"最后两层 cross-attention"的机制结论。那是 23M 适配器的结构，我们是全参或 LoRA SFT 的分类器，层的对应关系不成立。
- **不要**用 heatmap 平坦度当弃权信号。作者已经证明它是 0.517（随机），且在 absent 情况下**低于**随机。
