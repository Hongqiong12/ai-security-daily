## 一、背景与问题

### 动机：输入侧防线的隐含前提被拆掉了

过去所有 T2I 输入侧安全方案——本仓库连续十六周追踪的 **Prompt Rewrite / Prompt Sanitization / Safety Rewriting**，以及工业界的 prompt filter、黑名单、困惑度过滤、概念嵌入相似度过滤——都共享一个未言明的假设：

> **恶意概念以文本形式出现在 prompt 里，因此可以在文本侧被识别、替换或拦截。**

AnyBreak 直接攻击这个前提。它构造的攻击在推理时**只使用干净的文本 prompt 与一张对抗图像**（clean textual prompts + adversarial images at inference time），把恶意概念从文本模态搬运到图像模态：

| 防线 | 看到什么 | 判定 |
|---|---|---|
| prompt filter / 黑名单 | 干净文本，无敏感词 | 放行 |
| 困惑度过滤 | 自然语言，困惑度正常 | 放行 |
| 概念嵌入相似度过滤 | 文本与目标概念不相似 | 放行 |
| **输入侧 Prompt 改写** | **没有风险锚点可改** | **无操作可做** |
| 事后图审（Safety Checker） | 生成出的违规图 | 能拦（见 §4） |

论文原话：*"existing T2I defense leave critical cross-modal attack surfaces insufficiently addressed"*。

### 为什么这条链是本项目最该读的一篇

本项目的自研范式是「**不改生成模型、输入侧热更新改写**」+「输出侧旁路图审」。AnyBreak 同时给出了这两个环节的压力测试：

1. **对输入侧改写**：证明存在一整类样本，改写器在原理上无对象可改——不是改写写得不好，是风险根本不在文本上。这直接对齐任务里「图生图改写分流当前命中 0/0%」的链路缺口：**0/0% 里可能混着一批「文本侧本来就没有锚点」的样本**。
2. **对统一生成-编辑模型**：论文明确说 T2I 模型已同时具备 generation 与 editing 能力，攻击用对抗图像 + 干净文本走的是**图像条件通路**。统一模型下「同一份改写 Prompt 同时作用于生成与编辑两条通路」这一设定，恰好是这类攻击的靶面：文本侧改写对两条通路都生效不了，因为概念从图像通路进入。
3. **对输出侧图审**：Table III 给出了本仓库少见的「图审有效 / 图审被绕过」配对数字，是 AB 评测可以直接抄的对照设计。

### 已有工作的位置

论文 Table I 系统对比了已有 T2I jailbreak：QF（CVPR'23）、SneakyPrompt（S&P'24）、MMA-Diffusion、ADVI2I 等，按「攻击模态 / 威胁模型 / 时间成本 / 通用性」四列排。共同局限是**依赖文本侧对抗 prompt 或白盒假设**，因此会被 prompt filter 压住（论文 Fig. 2 专门画了过滤策略对既有方法的影响）。AnyBreak 的定位是：全黑盒、任意模型、任意恶意概念、干净文本。

## 二、核心方法

### 2.1 多尺度渐进语义对齐

攻击分两步：

1. **概念迁移（text → image）**：先用生成器把目标恶意概念从文本转成一张「目标图像」。
2. **像素级语义对齐**：在一组编码器下，对一张干净参考图像加对抗扰动，使它在多尺度特征上逐步对齐到目标概念的语义方向。论文给出理论分析：像素级语义对齐可以把潜变量分布**引导向 NSFW 数据流形**。

关键在「渐进 / 多尺度」：不是一次性把目标图贴上去，而是在生成过程中让干净图像的 latent trajectory 被持续牵引，因此 LPIPS 极低（0.0708，见 §4）而语义已经偏到不安全域。

### 2.2 跨模态攻击面

$$\text{clean text prompt} + \text{adversarial image} \xrightarrow{\text{latent steering}} \text{unsafe data manifold}$$

论文把恶意概念称为可在模态间「transfer」的量：文本侧只承载中性意图（composition / 风格 / 场景），恶意语义由图像侧承载。因此**文本与图像的联合审核**才是对的位置，而不是把两条通路各自当成独立 T2I 请求。

### 2.3 AnyBreak-V：绕过后置图审

增强版在对齐目标里加一个 **compensation term**，专门压制事后 safety checker 可检测的特征，同时保持生成质量。这是本轮最值得记的对照：**同一个攻击家族，加一个补偿项就能把图审拦截率从 97% 打到 53%（Table III）**。

## 三、技术细节

| 项 | 设定 |
|---|---|
| 威胁模型 | 全黑盒；无模型权重、无梯度、无白盒假设 |
| 输入 | 干净文本 prompt + 一张对抗图像；推理时不再需要恶意文本 |
| 数据集 | NSFW Data Scraper 的 "sexy" 类别 |
| 被测模型 | SD-1.5、SD-2、P2P（Table III）；主对比表用 SD-1.5 |
| 防御对照 | 无防御 / Gaussian Noise / Safety Checker / Negative Prompt |
| 指标 | ASR(%)、C-s（CLIP score，语义一致性）、LPIPS（扰动幅度） |
| 恶意概念 | Adult / Bloody / Violence / Horror / Racism（Table V） |
| 图像侧基线 | ADVI2I、MMA、MMA-Mask（去掉文本侧敏感词后的 MMA） |

**扰动强度是非单调的**（Table II，global alignment）：随相似度从 0.66 升到 0.85，ASR 依次 46.43 → 50.21 → 56.49 → **59.96** → 57.19。最后一档相似度最高但 ASR 反而掉，论文解释为过强扰动损伤图像质量。⇒ **攻击侧也存在"改写强度过大反而失效"的甜点**，与本项目「改写强度应尽量下沉」在形态上同构。

**基线对照的设计要点**：MMA-Mask 是「从 MMA 里移除文本级敏感关键词」的对照，用来隔离「文本侧敏感词」的贡献。结果 MMA 42.21% → MMA-Mask 22.21%，说明既有方法一半以上的效力来自文本侧关键词；而 AnyBreak 完全不需要文本侧关键词就到 84.51%。

## 四、实验与结果

### 4.1 主表：图审是唯一有效的那道，但可被补偿项绕过（Table III, SD-1.5）

| 方法 | 无防御 ASR | Gaussian Noise | **Safety Checker** | Negative Prompt |
|---|---|---|---|---|
| **AnyBreak** | **84.51%** | 81.25% | **2.78%** | 74.53% |
| **AnyBreak-V** | 53.54% | 52.84% | **46.61%** | 49.87% |

三条硬结论：

1. **输入侧文本防线全废**：Negative Prompt（典型的文本侧干预）只把 84.51 → 74.53，Gaussian Noise 81.25，几乎无效。
2. **输出侧图审是唯一有效防线**：84.51 → 2.78，压掉 96.7%。
3. **补偿项一加就破**：AnyBreak-V 在图审下回到 46.61%，是 AnyBreak 的 **16.8 倍**；代价是无防御 ASR 从 84.51 掉到 53.54（−30.97 点）。⇒ **绕过图审与攻击效力之间存在可量化的 trade-off，不是免费绕过**。

跨模型一致性：

| 模型 | AnyBreak 无防御 / 图审 | AnyBreak-V 无防御 / 图审 |
|---|---|---|
| SD-1.5 | 84.51 / 2.78 | 53.54 / 46.61 |
| SD-2 | 85.39 / 6.01 | 52.12 / 49.29 |
| P2P | 61.78 / 3.29 | 29.49 / 29.19 |

C-s 全程 0.24–0.26、LPIPS 0.017–0.089 ⇒ **语义保真与视觉扰动几乎没有被攻击破坏**，这正是图审难判的原因。

### 4.2 与图像侧基线的对照（Table IV, SD-1.5）

| 方法 | 无防御 ASR | 图审下 ASR | LPIPS（无防御） |
|---|---|---|---|
| MMA | 42.21% | 39.95% | 0.3937 |
| MMA-Mask | 22.21% | 19.64% | 0.3937 |
| ADVI2I | 62.82% | 10.27% | 0.1436 |
| **AnyBreak** | **84.51%** | 2.78% | **0.0708** |

⇒ **扰动最小（LPIPS 0.0708，是 MMA 的 1/5.6）而 ASR 最高**。任何基于「扰动幅度 / 图像异常」的检测器在这批样本上都会失效。

### 4.3 任意概念（Table V）

| 模型 | Adult | Bloody | Violence | Horror | Racism |
|---|---|---|---|---|---|
| SD-1.5 | 84.5 | 83.5 | 82.5 | 71.0 | 87.5 |
| SD-2.0 | 86.5 | 79.5 | 80.5 | 66.0 | 78.5 |

五类概念 ASR 66.0–87.5，无一类塌陷 ⇒ 「任意概念」的宣称有实测支撑，**不是只在色情类上过拟合**。注意 Racism / Horror 这类风险在本项目里对应政治/敏感地区与 VULG 边界以外的其他类目，说明风险锚点替换不能只针对色情词表。

## 五、局限性

1. **代码虽公开，但威胁模型偏理想**：实验主要在 SD-1.5 / SD-2 / P2P 上，未在闭源商用 API（GPT-Image、即梦、通义万相）上验证；闭源侧的「文本+图像」联合过滤可能在输入端就拦掉对抗图像。
2. **Safety Checker 用的是 CompVis 开源 checker**（参考文献 [5]），不是工业级图审。2.78% 这个数字不能直接外推到本项目的 `sft_train.image_only` 图审模型；反过来，46.61% 的绕过率也是对该 checker 的，不是对 VLM-as-judge 图审的。
3. **补偿项的代价被低估呈现**：AnyBreak-V 无防御 ASR 掉 30.97 点，论文未在摘要里提这个代价，只读摘要会以为「图审被免费绕过」。
4. **没有测输入侧改写器**：论文对照的是 prompt filter / Negative Prompt，没有测任何语义保真改写。因此「改写无效」是本项目的迁移推断，不是论文实测结论——需要在自己的链路上验证。
5. **未覆盖编辑指令改写**：攻击走图像条件通路，但没有构造「带编辑指令的 I2I 请求」这一形态，统一生成-编辑模型下的改写面仍是推断。

## 六、复现指南

**最小复现（论文设定）**

1. 数据：NSFW Data Scraper "sexy" 类别；干净文本 prompt 用中性描述。
2. 目标图像：用生成器把恶意概念转成图，取多尺度编码器特征作对齐目标。
3. 对抗图像：对干净参考图加扰动，多尺度渐进对齐；扰动预算做扫描（Table II 的 5 档），**不要直接取最大档**。
4. 推理：干净文本 + 对抗图像送入 SD-1.5，统计 ASR / C-s / LPIPS；四组防御分别跑。
5. AnyBreak-V：在对齐目标加 compensation term，重跑 Safety Checker 一列。

**本项目建议的迁移复现（零训练，1 天）**

| 步骤 | 动作 | 判据 |
|---|---|---|
| 1 | 从图生图评测集（1979 有效样本）里筛出「文本侧无风险词、但输出被判违规」的样本 | 若占比 >10% ⇒ 0/0% 分流里有相当一部分是「文本侧无锚点」，改写链路结构上够不着 |
| 2 | 把这类样本单列为 `image-born-risk` 桶，与 `text-anchor-risk` 桶分开报命中率 | 两桶命中率差距 >20 点 ⇒ 分流命中 0/0% 不是改写能力问题，是分流定义问题 |
| 3 | 输出侧图审 AB 加一组「带补偿项的对抗图像」攻击样本 | 若图审召回掉 >30 点 ⇒ 需在图审侧加跨模态一致性信号，纯 image-only 不够 |
| 4 | 统一生成-编辑模型下用同一份改写 prompt 分别跑生成通路与编辑通路 | 编辑通路残留风险显著更高 ⇒ 证明「一份改写覆盖两条通路」的假设不成立 |

## 附：对业务主线的三句话

1. **输入侧改写的失效边界第一次被明确画出**：干净文本意味着「无可改锚点」，这不是改写质量问题，是作用面选错了。
2. **输出侧图审是唯一有效防线但可被绕过，且绕过有 30.97 点代价**——AB 评测必须同时报「拦截率」与「绕过成本」，否则会把图审的价值和脆弱性都看错。
3. **I2I / 统一生成-编辑模型的改写面**：风险从图像通路进入时，文本改写对生成与编辑两条通路同时失效；当前分流 0/0% 应先把样本按「风险载体是文本还是图像」拆成两桶再谈命中率。
