# 两个模型的总分几乎一样，失败的位置完全不同

**论文主页**: https://arxiv.org/abs/2611.07132
**领域**: T2I 生成器审计 · 代理变量（proxy variables）· 分布距离 · 群内同质度

**机构**: 弗吉尼亚大学（University of Virginia）
**发布日期**: 2026-11-04（v1，cs.CV / cs.LG，12 页，AAAI 2026 版式）
**分类**: benchmark / t2i
**模态归属**: T2I 纯生成 · 审计与评测方法论

## 一、背景与问题

### 动机

T2I 偏差审计长期在做一件事：数每个族群出现了多少张，然后跟人口普查比。论文指出这条路有两个结构性缺陷：

1. **它需要一个"目标分布"假设。** 什么叫"公平"？论文原文说得很硬：*"What counts as an 'unbiased' text-to-image model is a normative question that we do not attempt to answer."* 而一旦你把它答了，审计就变成了"倡导种族配额"，在很多法域里直接不可用。
2. **它只在聚合层看。** 现有工作（Table 1 列了 9 篇）普遍"把输出里白/非白比例在全部 prompt 上平均掉，再跟普查比"。平均会**把单个 prompt 上的巨大偏差抹平**。

论文的解法是借反歧视法里的**代理变量**：用"看起来中性、但与受保护属性相关"的变量（职业 / 地理 / 姓氏）来间接暴露偏差，从而不需要对个体做种族分类、不需要预设公平标准。

### 三条论断

1. 代理变量审计在法理与技术上都能成立，且能暴露传统审计看不到的东西。
2. **分布距离（TVD）** 给一个可比的单数，但它假设了参考分布。
3. **群内同质度（cosine）** 抓到的是"画质差异/刻板化"，这类偏差在人口比例比较里完全不出现。

第 3 条是我们这轮最该抄的。

## 二、核心方法

### 2.1 流程

```
150 个 prompt（3 类代理 × 50 个变体）
   ↓ 每 prompt 生成 100 张
种族分类器 → 每 prompt 的分布
   ↓
① 与 US Census 比 → TVD（Total Variation Distance）
② CIELAB 采样肤色 → L*（亮度）/ h°（色相角）分布
③ CLIP(ViT-H-14) + InsightFace 嵌入 → 群内/群间 cosine
```

### 2.2 三个代理类

| 类 | prompt 模板 | 变体数 |
|---|---|---|
| 职业 | "A person who works as a [occupation]" | 50 |
| 地理 | "A person from [place]"（州/市/县级别） | 50 |
| 姓氏 | "A person with the last name [surname]" | 50 |

**地理细化到州、市、县**——论文自称是第一个量化"地理线索粒度"对输出影响的。

### 2.3 两个"不要假设公平"的指标

**TVD**：
$$\mathrm{TVD}(P,Q)=\tfrac12\sum_{x\in R}\lvert P(x)-Q(x)\rvert$$
范围 0（同分布）到 1（完全不重叠）。它仍需要一个参考分布（这里是普查），所以论文把它当"可比单数"，不当"公平判定"。

**同质度缺口（homogeneity gap）** = 群内平均 cosine − 群间平均 cosine。正值表示"同群之间比跨群更像"。分两种嵌入：

| 嵌入 | 抓什么 |
|---|---|
| CLIP ViT-H-14（LAION2B） | 整体外观、风格、构图 |
| InsightFace buffalo_l | 面部形态（只取检测分 > 0.85 的） |

**这个二分很重要**：构图同质与面部同质是两件不同的事，混在一起报会互相抵消。

## 三、技术细节

### 3.1 TVD 的三个用法

1. **总体**：一个数比模型。
2. **按代理类拆**：同一模型在不同代理上差异极大（见下）。
3. **按单个 prompt 拆**：论文反复强调这是它与前作的根本差别——"showing disparities ... broken down by individual prompt"。

### 3.2 肤色

不采用 Fitzpatrick 或 Monk 量表（论文引了这两者"对深色肤色分辨不足、印刷后失真"的批评），改用 **CIELAB 连续量**：亮度 $L^*$ + 红黄色度 $h^\circ$，从所有可见皮肤区域采样。

### 3.3 分类器与验证

论文用自动种族分类器（人工抽样核验 300 张）。作者自己承认分类器误差会传播，且 "Hispanic" 结果的可靠性偏低。

## 四、实验与结果

### 4.1 主表：TVD（Table 2）

| 模型 | Overall | Geography | Occupation | Surname |
|---|---|---|---|---|
| Flux Schnell | **0.310** [0.309, 0.320] | 0.299 | 0.330 | 0.302 |
| Imagen-4 Fast | **0.312** [0.311, 0.322] | 0.325 | 0.313 | 0.299 |
| Stable Diffusion 3.5 Large Turbo | **0.452** [0.448, 0.462] | 0.412 | 0.420 | **0.523** |

**Flux 与 Imagen 的总体 TVD 差 0.002——统计上分不开。** 但往下拆一格就全变了：

- Imagen-4 Fast 在**职业**代理上把白人过代表 **20%**，且是唯一在**地理**代理上持续过代表 Hispanic 的模型
- Imagen-4 Fast 的肤色更亮、更同质
- Stable Diffusion 在**姓氏**代理上 TVD 0.523，是全场最差的一格；但它的肤色多样性最好
- SD 在所有代理类上都离普查最远

⇒ **"哪个模型更公平"这个问题，在总体 TVD 上无解；在"哪个代理类 + 哪个方向"上才有解。**

### 4.2 单 prompt 的暴力例子

- "A person from Baltimore"：Imagen-4 Fast 的白人比例远超其他两个模型
- "A person with the last name Charles"（黑人比例高的姓氏）：三个模型都持续低代表
- "A person that works as a software developer"：三个模型都相对准（累计 TVD 0.25）——**因为真实世界里这个职业本来就这样**
- 姓氏类里 "Schmidt" / "Chen" / "Kim" 这种**国别相关性强**的姓氏，TVD 全部 < 0.1

**最后一组是本轮最锋利的一条**：姓氏类偏差的大小**取决于该姓氏与国别的相关强度**。相关强的（Schmidt=德、Chen=华、Kim=韩）就准；相关弱但黑人比例高的（Charles）就系统性低代表。

**换成我们的语言**：**代理变量越"干净"，审计越准；代理变量越"脏"，审出来的偏差里混着真实世界的分布。** 我们做类目阈值分组时，分组变量的"干净度"直接决定分组阈值的可信度。

### 4.3 同质度

同一 prompt 下两张不同地点的图（Oakland / Queens），面部嵌入 cosine **0.838**——**视觉上几乎一样的两张脸，配两个相距 4,000 公里的地名**。

论文把群内高相似解读为"刻板化信号"。这个指标**在人口比例比较里完全不可见**：两张图都"正确"地画了人，比例也没错，但它们是同一个人。

## 五、局限性

### 5.1 论文自述

- 参考分布是**美国普查**，不适用于全球分布（论文明确说：换成全球分布，亚洲人比例会高得多，SD 反而更接近）。
- 种族分类器有误差；Hispanic 结果可靠性偏低。
- 不做"公平"的规范性判断，因此**不给"通过/不通过"的结论**。
- 只做静态审计，不做干预后的复测。

### 5.2 本报告补充的四条

1. **单数指标的诱惑是本文自己都没完全避开的。** TVD 被写成"can be used to quickly compare models"，但它的前提（参考分布）恰恰是论文声称不预设的那个东西。**用 TVD 排名，就是在用一个隐式的规范标准排名。**

2. **100 张/prompt 是必要成本，不是浪费。** 要在单 prompt 上看出分布偏移，样本量必须够。我们做图审 AB 时如果每个 prompt 只出 1–2 张，**任何分布层面的结论都不成立**。

3. **"代理变量"这条路我们可以直接借用，且理由比论文更充分。** 论文借它来规避法域风险；我们借它来**规避"直接按风险类别分组导致的标签循环"**——用"中性但与风险相关"的变量（如 prompt 长度、句式、主体词的具体/抽象）分组，得到的阈值差异不会被"我们就是这么标的"污染。

4. **同质度缺口没有阈值。** 论文报了 gap，但没说多大算问题。迁移时必须自己定判据（建议：gap > 0.05 且群内 cosine 的 P90 > 0.9 才算刻板化）。

## 六、复现指南

### 6.1 能直接搬的三件（零训练）

1. **按单 prompt 拆分布**，不按聚合报。
2. **同质度缺口**（群内 − 群间 cosine）+ 双嵌入（整体 + 局部）。
3. **代理变量设计原则**：代理与目标的相关强度决定审计信噪比，先用"强相关代理"验证方法，再用"弱相关代理"看泛化。

### 6.2 最小可迁移实验（1 天，零训练）

**目标**：验证我们的分业务阈值差异是"真差异"还是"分组变量的脏度"。

1. 选 3 个叶子类目，每个取 100 条样本。
2. 用**两个代理变量**分组：(a) prompt 长度分位，(b) 主体词是"具体名词"还是"抽象描述"。
3. 每组算：误杀率、漏过率、AUROC。
4. 报一张 **3 类目 × 2 代理 × 3 指标** 的表。

**判据**：
- 若两个代理给出一致的分组差异方向 ⇒ 差异是**类目真实属性**，值得分阈值
- 若两个代理给出**相反**方向 ⇒ 差异来自分组变量本身（脏代理），**分阈值是在拟合噪声**
- 若某个代理下所有类目差异都 < 2 点、另一个代理下 > 10 点 ⇒ 只有后者是真信号

### 6.3 数据构造要点

- 每 prompt 生成量要足够（≥ 20）才能谈分布；谈单 prompt 偏移要 ≥ 100。
- 分类器要先做**已知集校准**（论文抽 300 张人工核验）。我们做图审 AB 时同理，judge 必须先过人工一致性。

### 6.4 评测要点

- **必须同时报总体与分格**，且分格必须能看出"方向"（过代表/低代表），不能只报绝对距离。
- **必须报一个"质量维"指标**（这里是肤色/同质度）。只报比例，等于假设"画得像不像"不重要。
- 参考分布的选择必须显式声明。换参考分布，排名会变（论文自己承认 SD 在全球分布下会更接近）。

| 论文事实 | 我们的对应现状 | 可执行动作 |
|---|---|---|
| 总体 TVD 0.310 vs 0.312，但失败位置完全不同 | 台按一级/二级/叶子下发阈值，看板只报总误杀 5.2% / 总漏过 3.42% | 加一列"分类目 TVD 型指标"：每个叶子类目的分数分布与全局分布的距离 |
