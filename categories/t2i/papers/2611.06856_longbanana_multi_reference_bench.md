## 一、背景与问题

### 动机

Agent 时代的图像生成不再是"一句话一张图"，而是**从一个大的参考库里检索证据、拒绝相似干扰项、绑定实体与关系、按约束构图**。这种任务的失败有个共同性质：

> 这些失败通常是**溯源错误**而不是渲染错误——系统可能画对了物体类别但抄错了参考图的外观，摆对了实体但违反了关系，或者交出一张精致构图却把硬负样本漏进了画面。

于是评测的核心问题变了：**怎么判断一张图是否是"从长上下文中正确合成"的？** 论文的回答是：不能靠整体分，必须靠**能定位错误的判据**。

### 三条论断

1. 任务应建模为**实体—关系图**，图的节点、边、整图约束分别对应三个评分维度（Content Fidelity / Relational Binding / Global Constraint Satisfaction）。**每个判据绑一个图单元**，错误才能定位。
2. 评测要**可审计**：判据要挂确定性工具（OCR、计数、布局、身份核验）并留证据链，而不是让 VLM 一句话打分。
3. **Agent harness 有增益但没有一个 harness 全面占优**；RPR（ReAct–Plan–Exec–Reflect）的收益是**harness 依赖的**，harness 不能可靠利用检索证据时反而引入漂移。

## 二、核心方法

### 2.1 基准结构

| 项 | 数 |
|---|---|
| 任务数 | **90** |
| 分类法 | **3 × 3** |
| 每任务参考图 | 约 **32** 张 |
| 每任务约束 | 约 **20** 条 |
| 每任务评测项 | 约 **50** 条 |
| **专家指定原子判据总数** | **4,670** |

任务是刻意设计的：要检索分散证据、拒绝干扰项、绑定实体与关系、再合成一张连贯图。**干扰项（hard negatives）与"无依据内容"规则是任务的一部分**，不是附加题。

### 2.2 三层图单元 → 三个评分维度

| 图单元 | 含义 | 评分维度 |
|---|---|---|
| **节点** | 必须出现（或必须不出现）的实体、属性、文本元素 | Content Fidelity |
| **边** | 绑定实体的空间、交互、顺序、局部外观关系 | Relational Binding |
| **整图约束** | 没有任何单节点/单边能捕获的场景级义务：布局、计数、时序状态、参考选择 | Global Constraint Satisfaction |

判据从图单元派生，**每条判据是原子且视觉可核验的**，且绑回唯一一个图单元。

### 2.3 LongBanana-Eval：agentic checklist judge

不是"给整图一个分"，而是：

1. 把每条判据路由到一个**带 rubric 的 critic**；
2. 判据若能用可执行检查解决，就**调用确定性工具**（OCR、计数、布局、身份）；
3. 记录**证据链**（evidence trace）供质控与复现。

打分：每条判据标签归一化为 [0,1]，取相关判据的均值，落到 0–5 分。另有一个 **P@70%**：难度加权分达到 70 的 case–subclass 任务占比，用来看"改进是分散在判据上，还是把更多任务推过了阈值"。

## 三、技术细节

### 3.1 标注协议：三段 + 15% 双标

| 段 | 做什么 |
|---|---|
| 一审 | 主标注 |
| 二审 | 复核 |
| 专家裁决 | 争议项裁定 |

一致性检验：**15% 的条目级判断（7,005 条）由两名标注员独立标注**。

| 指标 | 值 |
|---|---|
| exact agreement | **89.4%** |
| quadratic weighted κ | **0.83** |

人类参考标签池：**900 个生成输出 × 每 case 清单 = 46,700 条已复核判据标签**。

### 3.2 难度权重必须冻结

> 主比较里，每条判据的难度权重由固定参考系统池上的人类分数**计算一次、版本化、此后对所有系统保持固定**。

这是个容易被忽略的工程细节：**权重如果随被测系统变，跨版本比较就作废**。这与我们"配置指纹"的结论是同一件事的另一面。

### 3.3 十种生成条件

- Table 2 固定 Nano Banana 2，比较 2 个直接基线 + 3 个最小 harness + 它们的 RPR 变体；
- Table 3 固定 OpenClaw + RPR，比较 3 个图像后端；
- 共享配置（OpenClaw + RPR + Nano Banana 2）把两张表连起来，共 **10 个不同生成条件**。

两个直接基线值得注意：
- **FP-Direct**：全 prompt 直接生成，用一个 8 参考图的滑动窗口扫库存；
- **PD-Direct**：prompt 分解 + 整数规划排程，**特权访问构图用的实体—关系图**，最大化"锚点先于依赖"的关系数、最小化关系拉伸。

**PD-Direct 是一个很强的对照**：它拿到了构图图但拿不到评测清单，用来分离"结构信息"与"评测信息"的贡献。

## 四、实验与结果

### 4.1 judge 与人（Table 1，900 个输出 / 46,700 条标签）

| Judge | Pearson | Spearman | Kendall |
|---|---|---|---|
| VLM-as-judge（单次） | 0.8413 | 0.8248 | 0.6437 |
| **LongBananaEval（agentic checklist）** | **0.8707** | **0.8602** | **0.6727** |

**输出级相关系数只从 0.8413 涨到 0.8707（+2.9 点）。** 如果只看这张表，结论会是"agentic judge 有一点但有限的提升"。

但条目级：

> 在条目级，它把三元精确一致率提高了 **15.82 个百分点**，把两端相反的误差减少了 **19.28 个百分点**。

**这是本轮最该记住的一组数**：输出级相关 +2.9 点，条目级一致 +15.82 点。**同一个改进，用不同的分母看，差 5 倍。**

原因不难理解：输出级相关是"整图总分排序是否一致"，一个把若干判据判反的 judge，只要总分排序不乱，相关系数几乎不动。

### 4.2 生成结果的三条

1. **Agent harness 整体优于直接生成，但没有一个 harness 全面占优**：每个子类的最佳分分散在直接 prompting、最小 harness 与 RPR 之间。
2. **RPR 的收益依赖 harness**：只有当 harness 能可靠利用检索证据和修订反馈时才有帮助，否则**引入漂移**。
3. 图像后端比较（Table 3）显示后端与 harness 存在交互，换后端会改变 harness 的排名。

### 4.3 一个方法论副产品

作者在附录里做了 rank-stability 分析（附录 B），并把"审计—纠错"过程本身写进了论文。**标注错误被当作数据而不是丑闻**——这是让 89.4% 这个数可信的前提。

## 五、局限性

1. **规模小但稠密**：只有 90 个任务。作者的选择是"稠密而非海量"，代价是覆盖广度有限（3×3 分类法）。
2. **agentic judge 依赖外部工具与 agent 框架**，成本远高于单次 VLM 判定，且引入新的失效面（工具调用失败、路由错误）。
3. **需要 Claude Sonnet 4.6 作为 agent 模型**，可复现性受闭源模型版本漂移影响。
4. **89.4% / 0.83 是"两名标注员"的一致性**，不是与"真值"的一致性；对边界条目，两人一致也可能是两人同错。
5. **与安全无关**：整篇不涉及内容安全、NSFW、策略合规。迁移是评测方法论层面的。
6. **难度权重虽然冻结，但由参考系统池决定**，换参考池权重就变，跨论文不可比。

## 六、复现指南

### 6.1 公开物

- 90 个 case、参考图、实体—关系图、清单、专家标签、证据链
- 代码与数据：论文声明公开（见 §1 末尾链接）

### 6.2 最小复现路径（迁移到 I2I 评测集）

1. **先把评测集从"一条样本一个分"改成"一条样本 N 条原子判据"**（2 天，零训练）。每条判据必须满足：绑唯一图单元、可用是/否判定、最好能挂确定性工具（计数/OCR/位置/身份）。
2. **给每条判据找工具**（1–2 天）。能被工具判的（计数、文字、颜色、位置）交给工具；只有"关系"和"整图约束"留给模型判。
3. **抽 15% 做双标**（1 天）。报 exact agreement 与 QWK。**判据**：agreement ≥85% 且 QWK ≥0.8 ⇒ 标签可用；QWK <0.6 ⇒ 先改判据表述，不要改模型。
4. **验收 judge 时必须报条目级指标**（半天）。只报输出级相关会高估或低估改进 5 倍。

### 6.3 迁移时最容易做错的三件事

1. **用输出级相关系数验收 checklist judge**。0.8413→0.8707 看起来"没什么提升"，而条目级是 15.82 点。
2. **让权重随被测系统变**。论文明确冻结权重并版本化。
3. **把 harness 当免费增益**。RPR 在没有可靠证据利用时**引入漂移**——增加环节本身就是风险。

## 附：与业务的三条硬对应

1. **I2I 评测集 2000 条（1979 有效）应改成"原子判据 + 图结构"**。现在一条样本一个判定，等于把"主体对了但关系错了"和"主体错了"算成同一个错。改成节点/边/整图三层后，**0/0% 会自然变成一组可归因的数**（节点漏多少、边漏多少、整图约束漏多少）。
2. **图审 AB 评测必须加条目级指标**。我们的"一级一致率 77.64%"接近输出级口径。按论文的 5 倍差，**条目级的真实差距可能被严重低估**。落地动作：在现有 AB 看板上加一列"条目级三元一致率"与"两端相反错误率"。
3. **15% 双标 + QWK 0.83 是一个可抄的标注质量门**。我们的评测集目前没有公开的双标比例与 QWK。**在报任何版本对比之前，先把这两个数补上**——否则无法区分"模型变了"与"标注噪声变了"。
