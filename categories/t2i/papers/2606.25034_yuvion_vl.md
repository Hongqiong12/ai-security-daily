## 一、背景与问题

### 动机

平台每天处理数十亿图文样本，违规形态已经从"明显的色情/暴力图"转成**对抗性伪装**：小字水印嵌入、logo 局部变形、极端遮挡、上下文语义掩护（"这是新闻/教学/艺术"）、以及用扩散模型批量生产的规避样本。通用 VLM 在这类任务上有两个结构性缺口：

1. **知识密度不够**：判断一面旗帜变体、一个手势、一个组织徽记在某辖区是否违规，需要法规、文化、历史、政策条文的知识，而不只是"看得懂图"。
2. **安全对齐反而削弱了风险识别**：对齐过程压低了模型对敏感知识的表达意愿，导致它"不敢细说"，也就"判不准"。

### 核心科学问题

**能否把"内容安全"当成一个对抗性问题来建模，而不是一个分类问题？** 具体拆成三件事：
- 数据侧：如何系统性地生产带伪装策略的对抗样本；
- 训练侧：如何让模型学会**视觉上极相似但安全含义相反**的细粒度判别；
- 评测侧：如何分层验证"安全能力提升"没有用"通用能力崩塌"来换。

### 为什么这篇对我们重要

这是本月唯一一篇**由头部大厂安全团队直接给出的图审基座配方**，而且它的核心创新 C2FT（Confuse-then-Contrast Fine-Tuning）正好打在 PORN/VULG 边界混淆这个痛点上——它承认"单样本 SFT 给不出判别信号"，并且用**模型自身的混淆分布**去构造对比组。

## 二、核心方法

### （1）能力导向的数据体系（6 类，按训练阶段分工）

| 数据类别 | 内容 | 在训练中的角色 |
|---|---|---|
| 通用多模态 | caption / VQA / 多轮 / 数学 / OCR 文档 | 防灾难性遗忘，作正则项 |
| 领域知识 | 敏感人脸、风险文本 OCR、旗帜符号、logo、场景理解 + 知识对齐 QA | 建细粒度感知 + 注入政策知识 |
| 大规模真实安全业务数据 | 政治敏感、色情、暴力恐怖、欺诈、非法金融、赌博、骚扰、仇恨 | **核心风险识别能力，带层级标签 + 证据归因 + 政策引用** |
| 对抗数据 | 小字/水印规避、logo 变异、AI 生成图检测、上下文掩护 | 建模真实语义级规避 |
| 纯文本数据 | 文本安全语料 + 对抗文本（谐音、结构混淆、插字） | 跨模态知识迁移 |
| 领域推理 | CoT 轨迹、多步风险分析、结构化决策输出 | 深推理与知识调用 |

注意"大规模真实安全业务数据"那一栏的定语：**hierarchical risk categories + evidence attribution + policy references + structured decision outputs**。这不是"图 + 一个标签"，是"图 + 层级标签 + 证据 + 条款 + 结构化结论"。

### （2）三阶段训练

1. **知识增强继续预训练（CPT）**：风险概念跨模态对齐。冻结 ViT，只训 MLP connector + LLM。目标是让"视觉风险信号"接到"语义风险概念"上（色情元素、问题人物、旗帜/徽记→监管类别）。
2. **Instruct 后训练（SFT + C2FT）**：全参数更新（ViT + connector + LLM），多格式输出（二分类 / 层级标签 / 带证据的自由推理 / 结构化 JSON / 多轮追问）。
3. **Reasoning 后训练（Reasoning SFT + RLVR/GSPO）**：拒样 + 课程学习。

### （3）C2FT：这篇论文真正的贡献

**Confuse 阶段（挖混淆）**

对锚点样本 x_a（真值 y_a），模型预测错时计算混淆分：

  S_confuse(c | x_a) = Sim(e_pred, e_gt^c)

即"模型错判出来的那个类"与"候选类 c 的真值嵌入"的相似度；取分数最高的若干类组成动态混淆集 C_confuse。**这一步的关键是：混淆集不是人工列的，是模型自己当前搞混的类。**

然后做**特征检索 + Teacher Forcing 校验**取困难负样本：对来自混淆类 c 的候选 x_neg，只有当

  |P_TF(y_a | x_neg) − P_TF(c | x_neg)| < τ

才保留为"已验证困难负样本"——即模型对这张负样本到底是"锚点类"还是"它自己的类"信心差不多，说明它确实分不开。正样本按图文联合特征相似度检索。

**Contrast 阶段（跨图对比）**

把混淆对拼成统一的多图指令，视觉 token 直接拼接：

  X = [V_1; V_2; …; V_K; T]

自注意力天然允许图与图之间互相 attend，构成"显式跨图比较"的结构基础。损失用对比交叉熵：

  L_contrast = E[ L_CE(θ; [x_a, X_contrast], [y_a, Y_contrast]) ]

总目标是混合格式目标：

  L_total = ρ · E_single[L_CE(θ, x, y)] + (1 − ρ) · E_multi[L_contrast]，ρ = 0.3

**PAT（Progressive Anti-Shortcut Training）**：随机打乱对比图的顺序，并把多图样本与单图样本混合。作用是防止模型学到"位置捷径"（比如"第二张图总是安全的"）和固定 prompt 结构。

### （4）CoT 生产管线：双生成器仲裁（对我们最直接有用的一段）

用"后验约束"方式反推推理链：给定 {question, reference answer}，让生成器产出中间推理。然后做**级联一致性校验**：

- **第一道**：CoT 结论必须收敛到 reference answer，否则标记为候选失败样本（**注意：不是静默丢弃**）。
- **第二道**：对标记样本引入**第二个推理生成器**做交叉验证，用两个生成器的一致模式驱动仲裁：
  - 两个生成器**都**跟 reference 不一致 → **判定原始标注可能错**（噪声/歧义标签），触发人工复核并改标后再入池；
  - 两个生成器**彼此**不一致 → 判定为该样本本身认知不确定性高（不是标注缺陷），触发重采样 + 扰动解码下二次生成。

这是"LLM 辅助标签复判"的一个**可执行的仲裁判据**，而不是"让 LLM 再判一次"。

质检三维：efficiency（冗余度 + 与业务问题相关性）、consistency（规则校验 + LLM/VLM 语义对齐）、quality（分阶段事实性——图像描述、背景信息、逻辑推理各段分别判）。

### （5）三级递进评测 YVRE（58 个 benchmark）

- **Level 1 通用多模态**：只当护栏，聚合退化预算 ≤ 3 个百分点，超标必须回调后训练数据配比。
- **Level 2 公开安全 + 自建电商治理**：8 个公开集（Hateful Memes / MMHS / HOD / LlavaGuard / ProGuard / MM-SafetyBench / UnsafeBench / EVADE-Bench），加 4 个自建电商集（Logo / 品牌 / 品类 / 价格）。
- **Level 3 内部能力与业务（20+ 集，6 维）**：领域知识 / 视觉感知 / **AI 生成图检测** / **动态政策下的指令遵循** / 对抗鲁棒性 / 端到端审核归因。

其中两个维度值得单独记：
- **"动态政策下的指令遵循"**：把政策修订**直接注入 prompt**，看模型服从新条款还是记住训练时的旧条款。这是"政策漂移"场景的标准测法。
- **"政策无关的对抗鲁棒性"**：隐喻/暗示、编码语言、寓言图像、多轮诱导，要求在低误报前提下识破。

## 三、技术细节

### 对齐损失的取舍

Yuvion 没有做 image-level preference 对齐（不像 SafetyBPO 那类），它把安全能力压在**监督信号的结构化程度**上：层级标签 + 证据 + 条款引用 + 结构化输出。这是一个重要的路线选择——**它假设"判得准"来自"判得可解释"，而不是来自"判得像人类偏好"**。对图审场景，这个假设是合理的，因为审核要出的是可申诉的判定，不是偏好排序。

### RL 阶段的两个工程点

- **拒样代替随机采样**：先用第一阶段 SFT 模型对每个 prompt 做 N=5 次采样，算**奖励不一致度**作为不确定性度量，优先选不一致度高的**边界样本**进 RL。效果：只用 **6% 的数据**达到全量数据训练的水平。
- **课程学习防 reward hacking**：早期只训"不一致度 ≤ 80%"的中等难度样本，后期切到 > 80% 并同步抬高奖励标准。
- **多目标奖励解耦**：风险决策任务用结论准确率；grounding 任务用 IoU；复杂业务推理用"结论准确率 + CoT 与结论一致性"；格式要求高的任务额外加 schema 校验；主观任务用语义相似度；**所有任务统一加"CoT 与最终答案一致性"项**。

### 量化结果（论文口径，不做外推）

| 维度 | 结果 |
|---|---|
| 通用能力（23 集） | 相对 Qwen3-VL 骨干平均退化 2–3 点（8B/32B Instruct） |
| Level 2 公开安全（12 集均） | 8B：76.1（Instruct）/ 75.8（Reasoning）；32B：76.9 / 76.7。相对骨干 **+12.4 ~ +12.6**（8B）/ **+11.2 ~ +11.5**（32B） |
| 与超大模型对比 | Yuvion-32B 在 12 集均上超过 Qwen3.5-Plus、GPT-5.4、K2.5、Opus-4.6 |
| Level 3 内部（21 集均） | 32B：82.8（Instruct）/ 82.6（Reasoning）；相对骨干 Instruct **+8.6**、Reasoning **+11.3**（32B）；8B 为 +11.3 / +12.1 |
| AI 生成图检测（Macro F1） | 8B：73.6 vs 骨干 55.8（**+17.8**）；32B：74.1 vs 60.4（**+13.7**） |
| C2FT 消融 | C2M 换随机对比采样平均掉 **4.28 点**；去掉 PAT 掉得更多（GQA 尤甚） |

一个反直觉的观察被论文点名：**Qwen3-VL 的 Thinking 模式在 Level 3 部分指标上低于它自己的 Instruct 模式**——通用推理增强不等于审核能力增强。

### C2FT 的四个消融结论（可直接抄的设计经验）

1. 只堆对比图不够，**对比样本必须对准模型自己的混淆**；
2. Teacher Forcing 校验能过滤"视觉相似但不混淆"的假负样本；
3. PAT 不能省，否则模型学位置/格式捷径；
4. 困难负样本池扩大有收益但会饱和，过度放宽会引入噪声。

## 四、实验与结果

### 有效的地方

- 数据流水线确实能"造出"能力：8B 在 Level 3 上就能超过一堆 800B–1.5T 的闭源模型，说明**领域数据的结构化程度比参数量更决定审核能力**。
- C2FT 的消融设计干净：C2M/PAT 分别拆、随机对比做对照、Teacher Forcing 阈值 ω 做扫描。
- 三级评测里 Level 1 设"退化预算 ≤ 3 点"这个门槛，是个可复用的工程约束——不是"顺便报一下通用能力"，而是**当作 gate**。
- 拒样 + 课程学习的 6% 数据结论，对训练成本敏感的场景价值很高。

### 站不住 / 需要警惕的地方

1. **安全能力提升幅度大得不寻常**（内部集 +8.6 到 +12.1 点）。这些是**内部匿名 benchmark**，无法外部复现，且"内部标注质量"与"模型训练分布"同源——存在**评测-训练分布重叠**的风险。论文自己也承认 Level 2 用了 "unified binary safety-classification protocol"，分数不能跟原 benchmark 原始口径直接比。
2. **C2FT 的混淆集来自模型当前错误**，这在训练早期会放大已有偏置：如果模型一开始就把 PORN 判成 VULG，混淆集会持续围绕这两个类构造对比样本，可能**过拟合已有混淆方向**而漏掉未暴露的混淆。论文没有讨论"混淆集多样性退化"的问题。
3. **31B→32B 的绝对数字不可比**：表格里 32B 的提升幅度小于 8B，作者解释为骨干更强，但也可以解读为"安全数据的边际收益随规模递减"——这两者对"要不要上大模型做图审"的结论相反，论文没做区分。
4. **AI 生成图检测的提升（+13.7~17.8）**来自领域自适应训练，但训练数据里就包含"AI 生成的对抗样本"，所以这更接近"见过分布"而不是"学到伪造痕迹"。跨生成器泛化未验证。
5. **没有成本/延迟数据**。32B 全参数训练 + 多图对比推理，工程上代价没交代。

## 五、局限性

1. **闭源评测不可复现**：YVRE 的 Level 3 是内部集，58 个 benchmark 的具体构成没有全公开，"industry-leading" 无法独立验证。
2. **多图对比带来推理成本**：C2FT 训练需要 K 张图拼一条序列，训练显存和吞吐代价高；推理时是否需要多图输入，论文没有明确说清（若只在训练期用，则推理保持单图，代价可控；但这样对比信号只能"蒸馏"进参数）。
3. **混淆集是模型自指的**：用模型自己的错误定义训练目标，缺少外部锚点，存在自我强化风险。
4. **政策依从是单轮注入**：动态政策测法是"把修订注入 prompt"，没有测"政策在多轮对话中被逐步扭曲"的情形。
5. **未给出误报率-漏报率的完整工作曲线**：报的是 Accuracy / Macro-F1 / PR-AUC 类指标，对审核上线最关键的"固定误报下能抓多少"没有系统给出（这一点和同日的 Faithful Harm Monitors 正好互补）。

## 六、复现指南

### 6.1 可以复现的部分

```
1. 骨干：Qwen3-VL（8B / 32B），ViT + MLP connector + LLM 三段结构
2. CPT：冻结 ViT，仅训 connector + LLM；数据 = 通用图文 caption + 风险概念 caption
3. Instruct SFT：全参数；输入侧做指令改写/模板变化，输出侧多格式（二分类/层级/自由推理/JSON）
4. C2FT：
   - Confuse：对错判样本算 Sim(e_pred, e_gt^c)，取 top-k 类为 C_confuse
   - 困难负样本：Teacher Forcing 概率差 |P_TF(y_a|x_neg) − P_TF(c|x_neg)| < τ
   - 正样本：图文联合特征相似度检索
   - Contrast：多图 token 拼接 [V_1;…;V_K; T]，CE on 对比组
   - PAT：随机打乱图序 + 单图/多图混合 batch
   - 混合系数 ρ = 0.3
5. RL：N=5 采样算奖励不一致度 → 取边界样本 → 课程（≤80% 先训，>80% 后训）→ GSPO
6. 评测：Level1 设 ≤3 点退化 gate；Level2 unified binary protocol；Level3 六维内部集
```

### 6.2 复现风险点

- C2FT 的 τ、top-k、ρ、困难负样本池大小 ω 都影响很大（论文自己说 ω 放宽会饱和/引噪），需要在自己的数据上重扫；
- 多图拼接对显存要求高，8B 也需要注意 K 的取值；
- "风险概念 caption 数据"是 CPT 的关键，公开数据里没有，必须自建；
- 论文的数字全部基于内部数据，**不能把 +11 点当成我们换自家数据后的预期收益**。

### 6.3 对我们最有用的最小实验

**C2FT-lite（不换基座、不改训练框架）**：拿现有 Qwen3 5B SFT 模型，在 PORN/VULG 混淆样本上做一次"混淆集挖掘 + 多图对比 SFT"的增量训练：
- 用当前模型对训练集做一遍推理，取**被误判的 PORN/VULG 样本**作为锚点；
- 按 Sim(e_pred, e_gt^c) 确认混淆方向（大概会集中在 PORN↔VULG 与 VULG 内部 level2↔level3）；
- 每条锚点配 1 张同类真值图 + 1 张混淆类真值图，构造成"两图一答"的多图样本；
- 与现有 tag-weighted loss **并联**（tag_loss 只在锚点单图上算，对比损失在双图上算），ρ 先固定 0.3；
- 读数只看 **VULG-HINT-EDGE 的召回 + PORN 的误报**，其余不动。

这一步的判据很干净：如果 VULG-HINT-EDGE 召回涨但 PORN 误报也涨，说明模型在"混淆对"上是**对称迁移**（把边界整体推开）而不是"学到判别依据"——那就需要加 PAT 式的抗捷径约束，或回到 tag-weighted 的层级先验。
