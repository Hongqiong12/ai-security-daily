## 一、背景与问题

### 动机

生产环境里的 T2I 后训练通常是两段式的：**先 RL 做偏好对齐，再少步蒸馏做推理加速**。问题有两个：

1. **蒸馏会洗掉 RL 的收益**。两段式流程里，DMD 之类的方法要把分布匹配到一个**冻结的、与奖励无关的**基座模型上——这跟"把策略推向奖励偏好的输出"是**相互对抗**的目标。本文实测：**把官方 full-step LeapAlign checkpoint 顺序蒸馏到 8 步，HPSv2 从 0.4096 掉到 0.3978，PickScore 从 23.7239 掉到 22.9654。**
2. **少步 RL 的奖励看不见低层伪影**。这是本文真正的起点：直接在少步 rollout 上优化 RL（无需蒸馏）确实会逐步改善**结构连贯性**，但**低层噪声伪影会留下来**——因为任务奖励（比如 OCR 奖励、HPSv2 偏好分）对"网格状伪影、纹理噪声"这类缺陷**不敏感**。奖励一旦被满足，伪影就不再被惩罚。

### 核心科学问题

**当任务奖励已经饱和，谁还在盯着画面质量？**

作者的答案：**没有人在盯**。所以要**再造一个奖励**，专门盯低层保真度（fidelity），且这个奖励必须：
- **随策略演化而更新**（固定判别器会漏掉新出现的伪影）；
- **不能靠高层差异走捷径**（否则判别器学的是"风格/语义/布局"差异，不是"伪影"）。

### 为什么这篇对我们重要

我们的 RL 改写奖励来自 **Qwen-Image 一致性**这类学出来的分数。上周 Attractive Faces 那篇已经证明：**奖励的语义（图文对齐）与实际行为（变好看）可以脱节，并因此删掉能力**。AdvFidelity 从另一个方向给了同一结论的**量化版本**，而且它给的证据更狠——它的附录 B 直接测了六个主流奖励指标在"同一内容、只差伪影"的配对上怎么投票：

| 指标 | 参考图胜出率 |
|---|---|
| Aesthetic Score | **95.60%** |
| PickScore | **83.30%** |
| HPSv2 | **79.90%** |
| ImageReward | 48.20% |
| CLIPScore | 40.30% |
| **HPSv3** | **38.30%** |

也就是说：**HPSv3 在 61.7% 的配对上认为"有伪影的图"比"干净参考图"更好。** 一个被广泛用作 SOTA 偏好奖励的指标，在"只差伪影"这件事上基本是**反向**的。

对我们的直接含义：**我们的图像一致性奖励大概率也只测到了"内容对不对"，没测到"画面干不干净"。** 而后者恰恰是改写后用户最容易一眼看出来的退化。**这不是奖励偏置，这是奖励缺维。**

## 二、核心方法

### （1）总体：单一 RL 阶段完成"对齐 + 少步"，不要蒸馏

去掉 DMD、去掉蒸馏热身，在**推理时真正会用的采样预算下**跑 RL。总奖励：

$$r = r_{\text{task}} + \beta \cdot r_{\text{fid}}$$

- $r_{\text{task}}$：偏好奖励（HPSv2）或任务奖励（虚拟试衣用 DINO 相似度）；
- $r_{\text{fid}}$：**在线学出来的保真奖励**（判别器分数）；
- $\beta$：平衡系数（HPDv2 用 0.05，虚拟试衣用 0.01）。

沿用 LeapAlign 的 ReFL 家族做法：阈值化奖励损失，超过 margin $m$ 的样本不再继续拿奖励梯度（HPDv2 的 $m=0.55$，试衣的 $m=1$）。

### （2）保真奖励 = 在线更新的判别器

**架构**：冻结的 **DINOv2-Large** 编码器 + 轻量可训 MLP 头，取 **[CLS] token**（不用 patch token），在 RL 分辨率上评估。

**训练目标**：Bradley–Terry 损失，让"高质量参考 $x^+$"排在"当前策略重建出的配对负样本 $x^-$"之上：

$$\mathcal{L}_D = -\log \sigma\big(D_\psi(x^+) - D_\psi(x^-)\big)$$

**为什么必须在"局部"上打分**：[CLS] 是全局表示，对**局部缺陷**（网格纹、纹理噪点）不敏感。所以作者把同一个 [CLS] 打分头**同时作用在整图和随机裁剪区域**上（crop 尺寸 256 / 384，crop 级损失权重 0.3）。裁剪让局部缺陷占据更大输入占比，同时削弱"整体色调/边框效应"这类全局捷径。

**在线更新**：每次生成器更新后，**用当前策略重新生成负样本**，判别器做多轮更新（HPDv2 是 4:1，试衣是 2:1）。生成器更新时判别器冻结（梯度穿过它的分数），判别器更新时只训 MLP 头。

### （3）内容匹配的配对构造（这篇最巧的一步）

BT 损失会学**任何**能稳定区分正负的特征。如果正负来自不同图像分布，**风格/语义/布局差异就成了捷径**，判别器学到的是"这是哪个模型出的图"，不是"这图有没有伪影"。

解法：**负样本不是别的图，而是"当前生成器对参考图的重建"**：

1. 对参考图 $x^+$ 施加**中等强度噪声**（噪声水平从 $[0.2,0.4]$ 随机采）；
2. 让当前生成器从中等噪声出发，用 1–2 步完成剩余去噪 → $x^-$。

因为噪声中等，重建**大体保留了参考的风格与场景布局**，差异被压缩到**低层细节**上。于是判别器被迫去学"细节质量"。

（对比 Adv-GRPO：它用 Qwen-Image 的参考对比 SD3 的 rollout，**保真差异与源模型特性完全混淆**，风格/内容差异直接成为捷径。）

### （4）参考图从哪来（三种策略，工程上很实用）

| 策略 | 适用 | 本文用例 |
|---|---|---|
| **基座模型采样** | 基座的全步输出已覆盖目标视觉风格 | GenEval（用 50 步 FLUX.1-dev 输出） |
| **目标数据复用** | 有现成高质量真实图/生成图；RL 跟在目标域 SFT 之后时可复用 SFT 的真值图 | 虚拟试衣（用训练集的真实试穿图） |
| **目标域模型采样** | 基座覆盖不足、数据不可得 | HPDv2（用 50 步 HPSv2 对齐的 LeapAlign 采样 5 万对） |

**注意一个纪律**：参考集**一次性准备、可跨训练复用**；参考模型的分数与去噪轨迹**不参与训练**。作者还给了参考集与训练奖励的匹配度对照：HPDv2 原始图 HPSv2 均分 0.2583，而自采参考 0.3881 —— **参考集必须贴近奖励偏好的外观，否则保真监督会把策略往错的方向拉。**

## 三、技术细节

| 项 | HPDv2（偏好对齐） | GenEval（组合生成） | 虚拟试衣（生产任务） |
|---|---|---|---|
| 骨干 | FLUX.1-dev | FLUX.1-dev | **Qwen-Image-Edit-2511** |
| 采样步数 | 4 / 8，**无 CFG** | 4 / 8 | 8，无 CFG |
| 任务奖励 | HPSv2 | HPSv2 | **DINO 相似度**（服装一致性） |
| 保真参考 | 目标域模型采样（5 万对） | 基座采样（5 千对） | 目标数据复用（训练集真实图） |
| $\beta$ | 0.05 | – | 0.01 |
| margin $m$ | 0.55 | – | 1 |
| 判别器更新比 | 4:1 | – | 2:1 |
| 数据量 | 5 万训练 / 400 测试 prompt | 5 万训练 / 553 测试 prompt | 1,000 训 / 124 测 |
| 学习率 | 生成器 / 判别器分别设 | 同 | 均设同一 LR |

**评测**：HPDv2 报 HPSv2（域内）+ PickScore / ImageReward / UnifiedReward-Align / UnifiedReward-IQ（域外）；**HPSv3 单独着色只作参考**，理由是"它会给带少步伪影的图打误导性分数"——**用奖励审计的结论去约束自己的评测口径，这个自觉值得学**。虚拟试衣用 Gemini 3.5 Flash 打 Realism / Consistency / Alignment / Coherence 四维（1–10），**同一批图重复评 3 次取均值 ± std** 以抵消 MLLM 打分的随机性。

## 四、实验与结果

### 4.1 HPDv2 偏好对齐（FLUX.1-dev）

| 方法 | NFE | HPSv2 | PickScore | ImgRwd | UR-Align | UR-IQ |
|---|---|---|---|---|---|---|
| FLUX.1-dev（基座） | 50 | 0.3083 | 22.6970 | 1.0210 | 3.4428 | 3.4792 |
| LeapAlign（全步 RL） | 50 | **0.4096** | 23.7239 | 1.5105 | 3.4837 | 3.7284 |
| RTDMD（重训） | 8 | 0.3923 | 23.3059 | 1.4134 | 3.4779 | 3.7482 |
| **AdvFidelity** | 4 | 0.4055 | 23.6211 | **1.5164** | 3.4981 | 3.7338 |
| **AdvFidelity** | 8 | **0.4125** | **23.7685** | **1.5255** | **3.5024** | **3.7509** |

**8 步 AdvFidelity 在五个主指标上全部超过 50 步的 LeapAlign**（HPSv2 0.4096 → 0.4125）。在全部 50 步 RL 方法里，它在 HPSv2 / PickScore / UR-Align / UR-IQ 上领先（ImageReward 仍归 MixGRPO）。4 步时 HPSv2 与 PickScore 接近全步，ImageReward / UR-Align / UR-IQ 更高。

**这个结果的叙事很重要**：**"少步 = 掉点"这个默认假设被打破了**。前提是奖励必须覆盖"少步特有的退化"。

### 4.2 虚拟试衣（Qwen-Image-Edit-2511，真实数据）

- 8 步无 CFG 的 DINO 相似度 **0.7929**，**高于 40 步 LeapAlign + CFG 的 0.7874**；
- Gemini 四维（Realism / Consistency / Alignment / Coherence）**全部最高**。

这条对我们最直接：**它用的就是编辑模型 + DINO 相似度奖励 + 真实参考图**，几乎是我们 RL 改写链路的同构设置。

### 4.3 消融（HPDv2，8 步）

| 配置 | HPSv2 | 说明 |
|---|---|---|
| LeapAlign + 顺序 DMD（8 步） | 0.3978 | **蒸馏洗掉 RL 收益**（原 0.4096） |
| Vanilla AdvFidelity（冻结判别器 + 未配对负样本） | 0.3558 | 冻住的判别器跟不上策略演化 |
| + 在线判别器更新 | 更高（五项全升） | 自适应伪影有效 |
| + 目标域参考（target-anchored positives） | **0.3920** | 参考与奖励偏好匹配很关键 |
| + 内容匹配负样本 | **最高** | 去掉高层捷径后收益最大 |

**消融的排序值得记**：**参考集选错（0.3558）比没有保真奖励还糟**。保真奖励不是"加了就更好"，参考集错了会主动把策略往错方向推。

### 4.4 附录 B：奖励审计（本文最有迁移价值的部分）

构造 **1,000 组内容匹配配对**（正样本 = 50 步 HPSv2 对齐的 LeapAlign 输出；负样本 = 原 FLUX.1-dev 对中等加噪正样本做 1–2 步重建，必然带伪影），算**配对差分与正样本胜出率**。

结果已经在开头那张表里：**Aesthetic 95.6% / PickScore 83.3% / HPSv2 79.9% / ImageReward 48.2% / CLIPScore 40.3% / HPSv3 38.3%**。

两个必须注意的细节：
- **HPSv2 胜出率 79.9% 看起来不错，但平均配对差分是负的** —— 说明剩余 20.1% 的配对里，"伪影图得分更高"的幅度大到把均值拉翻了。**只看胜率不看差分幅度会误判。**
- **HPSv3 的胜出率 38.3%，即它在 61.7% 的配对上偏好带伪影的图。** 而 HPSv3 恰恰是被很多工作当作"更新更强"的偏好指标在用的。

## 五、局限性

1. **只在视觉保真（伪影）这一维做了审计**。对"语义一致性""图文对齐"没有做同样的配对审计——而我们的改写奖励主要靠的正是语义一致性。
2. **BT 判别器本质仍是一个学出来的模型**，它能被策略"适应"（在线更新既是优点也是风险：判别器和策略可能共同漂移）。
3. **参考集的可得性是硬前提**。HPDv2 这种"目标域模型采样"需要先有一个对齐好的模型，冷启动场景不适用。
4. **没有测安全维度**。这套方法优化的是"好看 + 干净"，**没有任何一项约束"不该生成的内容"**。它甚至可能让策略更擅长生成高保真违规图。
5. **单卡单域验证**：FLUX.1-dev + Qwen-Image-Edit-2511，未涉 MMDiT 之外的架构。
6. **HPSv3 的"不可靠"结论只在"少步伪影"这一特定混杂下成立**，不能推广成"HPSv3 整体不可用"。

## 六、复现指南

### 6.1 复现要点

```
1. 生成器：FLUX.1-dev（或 Qwen-Image-Edit 类编辑模型）
2. 保真判别器：DINOv2-Large（冻结）+ MLP 头（可训），取 [CLS]
3. 配对：x+ 参考图 → 加噪 U(0.2,0.4) → 当前策略 1~2 步重建 = x-
4. 判别器：BT loss，整图 + 256/384 裁剪（裁剪权重 0.3）双打分
5. 训练：r = r_task + β·r_fid；判别器每生成器步更新 4 次（试衣 2 次）
6. 采样：4 或 8 步，无 CFG；对照必须包含 full-step RL 与"RL+DMD"两条基线
```

### 6.2 复现风险点

- **参考集选错会主动伤害**（0.3558 < 不用的水平），必须先验证参考集的奖励匹配度。
- 噪声水平 0.2–0.4 是关键区间：太低重建太接近参考（差异不足），太高丢失内容（变成高层差异）。
- 判别器学习率与更新比需要匹配策略变化速度，太快/太慢都会失效。
- 评测**不要用 HPSv3 作为主指标**（论文已证明其在少步伪影上反向）。

### 6.3 对我们最有用的三件事

**（1）一个零成本的奖励审计实验（本周就能做）**

完全照搬附录 B 的构造，但把"少步伪影"换成"**改写前后的退化**"：

1. 取 500 组配对：**参考图 = 原 prompt 生成的原图**；**负样本 = 改写后 prompt 生成图**（内容应当一致，只可能差细节）。
2. 让我们的图像一致性奖励对每对打分，算**配对差分均值 + 正样本胜出率**。
3. **判据**：若胜出率落在 45%–55% 之间（接近抛硬币），说明**奖励对"改写引入的退化"完全不敏感**；此时 RL 优化的其实只是"内容相似度"，用户看到的画质退化不在优化目标里。
4. **必须同时看差分幅度**（HPSv2 的教训：胜率 79.9% 但均值为负）。

这个实验**不训练、不部署**，一天能出结论，而且直接决定"要不要给奖励加一维"。

**（2）如果要加保真维，照抄"内容匹配配对"这个构造**

我们不需要造一个新的美学模型。需要的只是：
- 参考图 = 改写前的原图（或原 prompt 的高步数输出）；
- 负样本 = **我们的生成器对加噪参考图的重建**；
- 判别器 = 冻结 DINOv2 + 小 MLP 头，整图 + 裁剪双打分。

**关键在于"内容匹配"这一步**：如果直接拿"改写前输出" vs "改写后输出"当正负样本，判别器会学到"prompt 的差异"而不是"质量的差异"（因为改写本身改变了文本条件）。**必须用同一个 prompt 下的重建配对。**

**（3）奖励缺维 vs 奖励偏置，是两个不同的问题**

- **奖励偏置**（上周 Attractive Faces）：奖励在测一个它不该测的东西（美观度），**方向错了**。解法是去偏（最小化互信息）。
- **奖励缺维**（本周 AdvFidelity）：奖励漏测了一个该测的东西（低层保真），**维度少了**。解法是加一个正交的奖励项。

我们的 RL 改写奖励**很可能同时中了两个**：既偏向"画面好看"，又缺"画面干净"。**先做（1）的审计确认是偏置还是缺维，再决定是去偏还是加维** —— 顺序反了会白训一版。
