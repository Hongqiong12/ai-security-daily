# 误杀不是阈值问题，是梯度耦合问题

**论文主页**: https://arxiv.org/abs/2610.39802
**领域**: 过度拒答（over-refusal）/ 安全对齐 / 梯度子空间 / 表示分离
**作者**: Chao Chen, Pengyang Shao, Wei Qin, Shijie Hao, Fei Shen, Richang Hong
**机构**: 合肥工业大学 · 新加坡国立大学（NUS）
**发布日期**: 2026-10-29（v1，cs.AI）
**分类**: defense / training
**模态归属**: T2T 安全对齐（迁移至分类模型误杀治理）

## 一、背景与问题

### 动机

三类样本的划分是本篇的基础：

| 类型 | 定义 | 正确行为 |
|---|---|---|
| harmful | 真有害 | 拒绝 |
| benign | 明显无害 | 正常回答 |
| **over-refusal** | **无害但表面像风险** | **正常回答（当前常被拒）** |

核心问题不是"怎么让模型更安全"，而是：**在安全监督本身正确的前提下，为什么 model 仍然会拒掉无害样本？**

### 两个观察（本篇的全部价值都在这两条）

**观察一（表示层）**：有害样本与过度拒答样本的表示，在**某些中间层可分**，但在**深层越来越重叠**。

**观察二（梯度层）**：有害样本的梯度有**高类内相似度**，且集中在**低秩子空间**；而且在 over-refusal prompt 上，这些梯度**与"拒绝"目标的梯度对齐强度，高于与"有用"目标的梯度**。

推论：

> 这种不均衡的梯度耦合会把过度拒答样本往"拒绝"侧推；同时深层表示分离度的下降让模型更难维持有害/无害的边界。

### 对我们最有冲击的一句

我们线上误杀 5.2%，长期被当作"阈值偏了"。这篇的立场是：**如果误杀样本与有害样本在深层表示上本来就重叠，那么任何阈值都无法把它们分开——阈值只能在一条已经混在一起的轴上切。**

这句话可以被检验（见 §6），而且检验成本很低。

### 四条论断

1. 过度拒答的根因在**优化动态**，不在标签质量。
2. 有害梯度是**低秩**的（可用 SVD 显式提取）。
3. 把 over-refusal 梯度对拒绝子空间正交化，可以解耦。
4. 光正交化不够，还要**显式加大两类表示的分离**（对比学习）。

## 二、核心方法

### （1）拒绝子空间怎么提

1. 取有害样本集 D_harmful，算**逐样本** SFT 梯度 gᵢ = ∇θ L_i。
2. 堆成矩阵 G = [g₁,…,g_N]ᵀ ∈ ℝ^{N×d}。
3. 对 G 做 SVD：G = UΣVᵀ。
4. 用 **CER(k)** = Σ_{j≤k} σⱼ² / Σ_{j≤r} σⱼ² 判断能量集中度，取前 k 个右奇异向量 V_k，k 使 CER 达到主导能量。
5. 投影矩阵 **P = V_k V_kᵀ**，即"拒绝子空间"。

### （2）正交投影

对 over-refusal 样本的梯度 g_or，去掉其在拒绝子空间上的分量：

**g_or^⊥ = g_or − P g_or = (I − P) g_or**

这样 over-refusal 的优化方向就与"拒绝"方向解耦，不再被拉着往拒答走。

### （3）安全感知对比学习

单靠正交化不够（附录讨论）：还需要显式把 harmful 与 over-refusal 的**表示推开**。加一个对比目标，在选定的"安全相关层"上拉大两类表示的间距。

### （4）安全相关层的选择

不是所有层都做对比。论文有专门一节（3.3.2 / 附录 C、J）讨论层的选择，结论是**只在安全相关层上做**才有效且不伤通用能力。

## 三、技术细节

### 三个可验证的量

| 量 | 含义 | 用法 |
|---|---|---|
| **CER(k)** | 前 k 个奇异值能量占比 | 判断"有害梯度是否真的低秩"。如果 CER(5) 就很低，说明不低秩，整条路不成立 |
| **V_k 的 k** | 保留的拒绝方向数 | 太小欠约束，太大把正常能力也正交掉了 |
| **表示分离度** | harmful 与 over-refusal 表示的间距 | 训练前后对比，是这套方法的直接读数 |

### 一个方法学细节值得抄

**逐样本梯度**而不是 batch 平均梯度。因为要提取的是"方向结构"（协方差/奇异值谱），batch 平均会把方向抵消掉。代价是显存与计算量——这也是为什么它只能在中小模型上做。

## 四、实验与结果

### Table 1（节选）：过度拒答缓解 + 安全保持 + 通用能力

| backbone | 指标 | 结果 |
|---|---|---|
| Llama-2-13B-Chat | OKTest 合规率 | 0.9400 → **0.9700** |
| Llama-2-13B-Chat | CoCoNot 合规率 | 0.8496 → **0.8892** |
| Gemma-7B-it | JBB 安全分 | 0.90 → **0.97** |
| Gemma-7B-it | STL 安全分 | 0.9748 → **0.9884** |
| Llama-2-13B-Chat | STL 安全分 | 0.9981（并列最好） |

- 15 个 over-refusal 设置里，**13 个最好或并列最好，2 个第二**。
- 通用能力：**最大下降 0.0071** 绝对准确率。

### 附录 O：人工 + GPT-5.1 双评

| 方法 | 自动拒答率 | 人工拒答率 | Useful Compliance |
|---|---|---|---|
| SFT | 19.5% | 21.5% | 66.5% |
| ACTOR | 14.5% | 15.0% | 70.0% |
| **GOAL** | **9.0%** | **10.0%** | **76.0%** |

**拒答率从 19.5% 砍到 9.0%，同时 Useful Compliance 从 66.5% 升到 76.0%。** 这两件事同时发生很关键：说明降误杀不是"把拒答换成敷衍回答"，而是真的答对了。

### 五个必须单独拎出来的数

1. **19.5% → 9.0%**：拒答率砍掉一半以上，安全分不降反升（Gemma JBB 0.90 → 0.97）。
2. **0.0071**：通用能力的最大绝对下降。这条路几乎不伤通用能力。
3. **13/15**：over-refusal 设置上的最优/并列最优数。
4. **+9.5 点**：Useful Compliance 的绝对提升（66.5 → 76.0）。
5. **深层重叠**：观察一的定性结论——这是"为什么阈值救不了误杀"的机制解释，但没有给出一个可比的数值（如线性可分性 AUC 的层间曲线）。

### 与"加 abstain 类"的关系

我们 10-30 提过 G1：加 abstain 类（N+1 softmax）来降 PORN 误报。这篇给了一个不同的介入点：

| 路线 | 改什么 | 成本 | 前提 |
|---|---|---|---|
| abstain 类 | 输出空间（多一个类） | 重训分类头 | 误杀样本在表示上**可分** |
| GOAL 式正交化 | 优化动态（梯度方向） | 重训 + 逐样本梯度 | 有害梯度**低秩** |

**如果深层表示已经重叠（本篇观察一成立），abstain 类在深层特征上找不到可分的空间，加类无效。** 而 11-04 那篇 2611.01512 又从另一个角度否证了 abstain：弃权分追踪的是局部标签方差而非新颖度。

三条独立证据指向同一个结论：**加弃权类大概率不是正确方向。**

## 五、局限性

1. **纯 T2T，无图像**：不涉及视觉、不涉及生图。迁移到图审需要假设"图像特征的害/无害边界有同样的梯度结构"——这个假设未验证。
2. **逐样本梯度成本高**：7B 级可以做，百亿级显存撑不住。我们 5 节点的现实下，只可能在分类头/最后几层做近似。
3. **CER 与 k 的选择偏启发式**：没有给"k 取多少最优"的敏感性分析（附录有部分）。
4. **只在过度拒答上验证**：没有验证"正交化会不会让真有害样本也被放过"的边界（JBB 涨了说明没有，但只测了一个方向）。
5. **依赖有害样本集的代表性**：D_harmful 若不含我们关心的 PORN/VULG 边界样本，提出的子空间就不是我们需要的子空间。
6. **未给"表示重叠"的量化曲线**：观察一是全文支点，但只给了可视化，没有逐层线性可分性数值。

## 六、复现指南

### 最小复现路径（按对我们的价值排序）

1. **先测我们自己的"表示重叠"**（半天，零训练）。取图审模型最后一层（或倒数第二层）特征，三类样本：确认有害 / 确认无害 / **被判 PORN 但人工确认无害**（这批已经有了，就是误杀 badcase）。做三件事：
   - 三类特征的类间距离矩阵；
   - 用二分类器分"无害 vs 误杀"的 AUC。**如果 AUC ≈ 0.5，说明在表示层就分不开 → 阈值调整的上限是 0，必须改训练。**
   - 逐层重复，看重叠是不是随深度加深（对应观察一）。

   这一步能一次回答"误杀 5.2% 该调阈值还是该改训练"。
2. **估有害梯度的秩**（1 天，小模型）。取 200 条确认有害样本，逐样本算最后几层梯度，SVD 看 CER(1)/CER(5)/CER(10)。如果 CER(10) 已 > 0.8，说明低秩成立，GOAL 路线可行。
3. **正交化只加在分类头上**（若 1、2 都成立）。不全模型做，只在最后的分类层/Adapter 上做，成本可控。
4. **别做 abstain**——除非第 1 步测出"误杀 vs 无害"的 AUC 明显高于 0.5。

### 关键超参

| 参数 | 取值 |
|---|---|
| k（拒绝子空间维数） | 由 CER 曲线定，论文未给单一推荐值 |
| 对比学习作用层 | 仅"安全相关层"（附录 C/J） |
| 梯度粒度 | **逐样本**，不可 batch 平均 |

## 附：与业务的三条硬对应

1. **给"误杀 5.2%"提供了可证伪的机制假设**：误杀样本与有害样本在深层表示重叠 → 阈值只能在混在一起的轴上切。**检验方法只要半天**，结论直接决定后续三条路（调阈值 / 改训练 / 改类目定义）走哪条。
2. **与 PGuard 的"图-文阈值 24/29 压地板"互相印证**：一个说"分数分布区分度差"，一个说"表示在深层重叠"。两篇从不同模态独立指向同一件事——**图审的误杀不是 operating point 问题**。
3. **给 PORN/VULG 边界类目的处理提供了新思路**：边界混淆的本质可能是"两类共享同一低秩方向"。如果 VULG 与 PORN 的梯度子空间高度重合，那么"区分它们"在训练时就注定失败——这与我们 10-30 提出的"VULG-HINT-EDGE κ 可能 <40、该类目暂不可判"的判断是同一条逻辑。
