## 一、背景与动机

### 动机

Text detoxification 要解决的三难（trilemma）**与输入侧安全改写完全同构**：

> **去毒率（toxicity removal） × 语义保真（semantic preservation） × 流畅度（fluency）**

而且失败模式也一模一样：

- **激进删除/掩码**：词表层的毒是没了，但说话人的核心意图也被拆了，还会引入生硬的不流畅；
- **保守修改**：残留了微妙/上下文性的毒性。

### 作者点破的机制性缺陷

**缺陷一：标量目标塌陷（collapsed scalar objective）**

seq2seq / reward-guided decoder 通常优化一个**无约束标量和**。实际后果是：

> **一个很高的安全分，可以掩盖语义保真的崩塌** —— 模型通过"换个话题"来逃避毒性。

这一点对做安全改写的人是刀刀见血：**如果你的 reward 是加权和，那 rewriter 一定学得会"改写最安全的方式 = 换个主题"。**

**缺陷二：单候选抹杀了策略多样性**

只生成一个候选，就看不到"保守局部替换"与"整体语用重构"这两条策略路线的差异。

**缺陷三：开放式多轮辩论的收益递减**

agentic / self-refine 类方法有多轮编辑，但开放式辩论会遭遇：feedback drift、role sycophancy、token 消耗无上界而收益快速递减。

### 对当前业务的重要性

⭐ **这是今天对"三维评测 + 改写选择机制"最有直接借鉴价值的一篇。**

它给出的不是新模型，而是一套**推理时的选择机制**：先生成多样的改写法，再用**互相隔离、角色盲**的评审打分，最后用**硬约束门**过滤后再排序。这套结构几乎可以原样搬到 T2I prompt 改写的 candidate selection 上。

## 二、核心方法

### AMEND（Agentic Multi-critic dEtoxificatioN with constrainteD selection）

把去毒拆成**三段解耦管线**：proposal → critique → selection。

### 阶段 1：Role-Conditioned Proposals（角色条件化提案）

同一个 base LM，用**三个互补角色**提示，生成三路候选：

| 角色 | 行为 | 对应改写策略 |
|------|------|-------------|
| `minimal_editor` | 精确的 span 替换 | **外科式锚点替换**（最小编辑） |
| `tone_rewriter` | 把攻击性转成坚定但文明的措辞 | **语气/风格降级** |
| `semantic_paraphraser` | 重构表述，刚性保留事实与立场 | **整体释义保义** |

> 💡 这三个角色正好对应安全改写的三条基本路线，且明确承认"没有哪一条在所有 case 上都对"。

### 阶段 2：Isolated Multidimensional Critics（隔离的多维评审）

三个独立评审，各自**只管一维**：toxicity / semantic preservation / fluency。

**关键设计：role-blind（角色盲）** —— 评审看不到候选是哪个角色生成的。

这直接挡掉两类污染：
- **persona bias**（评审偏好某个角色）；
- **evaluator sycophancy**（评审迎合生成器）。

### 阶段 3：Constraint-First Selection（约束优先选择）

> **不是优化无约束加权和，而是先过硬门槛，再排序。**

流程：
1. 先强制 **preservation 与 fluency 的硬可行性阈值**；
2. 只有满足这些不可协商条件的候选，才进入 utility 排序。

作者的原话很准：**"giving semantic fidelity veto power over superficial safety"** —— 语义保真对表面安全拥有**否决权**。

### AMEND Lite：有界控制回路

消融发现：开放式多轮辩论只有 **+0.0061** 增益，且**置信区间跨零**（等于没用）。

于是改成有界版：
- Round 1：完整三角色多样性；
- Round 2（**最多一次**）：仅当仍有残留毒性 span 时，调用 `minimal_editor` 做定向修复，并强制 **monotonic acceptance**（单调接受，不允许改差）。

## 三、技术细节

### 为什么"隔离 + 角色盲"是必要的

论文引用了一组 LLM-as-judge 的已知毛病：position bias、verbosity bias、self-preference。AMEND 的对策是结构性的而非提示性的：
- **隔离**（isolated）：每个 critic 只输出一个维度的分，不许它权衡；
- **角色盲**（role-blind）：切断来源信息；
- **显式决策轨迹**（explicit decision traces）：评估可复现。

这比"写一个更好的 judge prompt"要可靠得多。

### 为什么"约束优先"优于"加权和"

加权和允许维度间**无限制补偿**（safety 高就能买断 semantics 低）。硬门槛则把补偿关系截断：语义保真不达标，安全分再高也不录用。

这在数学上等价于把问题从 **scalarization** 改成 **constrained optimization**——正是多目标优化里处理"不可妥协约束"的标准做法。

### 与 Self-Refine / Multi-Agent Debate 的分工

Self-Refine 是单模型自诊断自改；ReConcile / debate 是多模型讨论投票。AMEND 采用的是 **selection-first 哲学**：生成阶段只要多样性，判断阶段只要隔离，控制器严格限制迭代次数。论文引用 MAMM-Refine 的结论支撑"verification benefits from isolation"。

## 四、实验与结果

### 实验设置

- 基准：**ParaDetox**（10,000+ 有毒英文句子与人工中和改写配对）；
- seed-aligned 实验（对照组同种子，这点在 agentic 论文里不多见）。

### 主要结果

| 对比 | 增益 |
|------|------|
| 单轮选择（三角色）vs 最佳单角色 | **joint metric +0.0508** |
| AMEND Lite vs 无约束多轮循环 | **joint score +0.0489**（$p < 0.05$），同时**推理请求数减少 28.4%** |
| AMEND Lite 冻结确认测试集 | joint score **0.6597 ± 0.0062** |
| 开放式多轮 vs 单轮 | 仅 **+0.0061**，置信区间跨零 |

### 结果怎么读

三个信号：

1. **角色多样性本身是有效归纳偏置**——不需要更复杂的模型，只需要"同时想三种改法"；
2. **约束优先 > 加权和**——这不是精度提升，是失败模式的结构性消除；
3. **多轮辩论被高估了**——收益不显著但成本高，有界单轮修复更划算。

第 3 点对业务的成本模型尤其重要：**多轮改写 loop 的钱大概率是白花的。**

## 五、局限性

1. **单作者、无机构信息、未在会议发表**，工程严谨性待验证。
2. **只在 ParaDetox（英文）上验证**，跨语言、跨风险类别未见。
3. **critic 仍是 LLM**，虽然做了隔离与角色盲，但 critic 本身的标定（与人类判断的相关性）没有报告。
4. **硬阈值的选值没有自适应机制**——阈值定多少、如何随风险等级变化，论文未展开。
5. **T2T 场景的"语义保真"是可文本比对的**；迁到 T2I 后，语义保真还要过"图像一致性"这一关，AMEND 的文本 critic 不能直接充当图像侧保真评审。
6. **三角色是手工设计的**，是否覆盖所有有效改写策略没有论证。

## 六、复现指南

### 最小复现路径

1. 准备 base LM 与 ParaDetox；
2. 写三个角色 prompt（`minimal_editor` / `tone_rewriter` / `semantic_paraphraser`），各生成 1 个候选；
3. 写三个 critic prompt，**输入中剔除候选来源信息**（role-blind），分别只输出 toxicity / semantic preservation / fluency 单一分；
4. 选择器：
   - 先按 preservation ≥ τ_sem 且 fluency ≥ τ_flu 硬过滤；
   - 存活候选按 utility（toxicity 为主）排序；
   - 若无候选存活 → 触发一次 `minimal_editor` 定向修复，强制单调接受；
5. 与"无约束加权和"做 seed-aligned 对照。

### 迁移到 T2I 输入侧安全改写的建议（本文核心价值）

| AMEND 构件 | T2I prompt 改写对应实现 |
|-----------|------------------------|
| `minimal_editor` | **风险锚点外科替换**（只动触发风险的最小 span） |
| `tone_rewriter` | **修饰语/强度降级**（如显式描写 → 含蓄表达） |
| `semantic_paraphraser` | **整体释义保义**（换场景/换构图但保主体） |
| toxicity critic | **安全分类器 / 风险等级判别器**（业务已有：level1–4 层级标签） |
| semantic critic | **prompt 语义相似度 + 图像一致性**（建议双通道，不要只用文本相似度） |
| fluency critic | **prompt 可生成性 / 指令遵循度**（生成图是否仍满足原始构图要求） |
| constraint-first selector | **先卡语义与指令遵循硬门槛，再按安全分排序** |
| AMEND Lite 有界回路 | **最多一轮定向修复**，禁止开放式多轮 |

**最该立刻试的一件事**：把现在 rewriter 的"加权和 reward"改成"**constraint-first**"。做法不复杂——在 candidate 排序时先按语义保真与指令遵循卡硬门槛，再按安全分排序。预期能直接压掉"换个主题式的安全改写"这类 badcase。

### 环境依赖

- 任意 instruct LLM（base 与 critic 可同一个模型）；
- ParaDetox 数据集；
- 无训练，纯推理时框架。
