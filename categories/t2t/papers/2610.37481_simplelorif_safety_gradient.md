## 一、背景与问题

### 动机

微调会悄悄削掉模型的安全对齐，**即使训练数据里没有任何一条看起来有害**。这个现象叫 **emergent misalignment（EM，涌现性错位）**：在"不安全代码"上微调，会让模型在**跟编程毫无关系**的领域也变得更容易给出恶意建议、欺骗、表达广泛错位的偏好；而同等规模的"安全代码"或"以良性教育目的框定的不安全代码"不会产生同样效果。

更麻烦的是：

- 这种数据**看起来是良性的**，所以标准内容过滤器（毒性过滤、LLM 安全 judge）**结构上抓不到**——它们看的是"内容说了什么"；
- 退化**不是均匀分布在整个数据集上的**，而是由**一小部分样本**驱动（He et al., 2024）。

于是问题被重新表述成一个**数据选择问题**：**如果能在训练前把那些样本找出来删掉，就能保住安全。**

### 核心洞察

**需要一个反映"这条样本会怎么改变模型"的信号，而不是"这条样本长什么样"的信号。**

梯度就是这样的信号——它描述"用这条样本训练，模型会往哪走"。

### 为什么这篇对我们要紧

我们的标签审计当前完全是**内容侧**的：看 `input_text` 像不像 PORN/VULG、表达规范不规范、有没有暗示性语境。我们反复纠结的一个现象是——**有些样本标签看起来完全对，训练完模型还是在那个类上错**。

这篇给出了一个此前没有考虑过的解释：**那批样本的问题不在"它被标成了什么"，而在"它把模型往哪推"**。一条文本完全良性的样本，如果它的梯度方向与"PORN 误报"的梯度方向对齐，它就在**教模型多报 PORN**，而任何基于内容的规则都看不见这件事。

这不是替代内容侧审计，是**补上一个维度**。而且它的成本在我们的算力范围内（见第四节）。

## 二、核心方法

### （0）任务形式化

给定参考模型 $\mathcal{M}$、目标行为集 $\mathcal{T}$（本文用 SafeRLHF 的不安全响应）、候选训练集 $\mathcal{D}$：

1. 把每条 $z\in\mathcal{D}$ 嵌入成"它诱导的梯度"的压缩表示；
2. 把 $\mathcal{T}$ 也嵌入；
3. 按**梯度对齐度**给 $z$ 打分；
4. 删掉对齐度最高的 $p$ 比例，得到净化后的数据集。

### （1）LoRIF：两级压缩，先把"每样本梯度"变成可存的东西

逐样本完整梯度在 LLM 规模上不可行。LoRIF 借了两个结构性事实：

**第一级：双边随机投影（来自 LoGRA）**

反向传播本来就把某层的权重梯度算成"前向激活 × 反向输出梯度"的外积和。所以可以在两个向量**产生的当下**就投影，而不必先组装出整个梯度矩阵：

$$M_\ell(z) = \left(\delta Y_\ell P^{\text{out}}_\ell\right)^\top \left(X_\ell P^{\text{in}}_\ell\right) \in \mathbb{R}^{d_2\times d_1}$$

$X_\ell$ 是该层对本文档所有 token 的输入激活，$\delta Y_\ell$ 是输出梯度，$P^{\text{in}}_\ell, P^{\text{out}}_\ell$ 是固定高斯矩阵。**完整的 $o_\ell\times i_\ell$ 梯度从不被构造出来。** 随机投影在期望上保内积，所以压缩后相似度信号仍在。取 $d_1=d_2=32$。

**第二级：秩-1 分解**

逐样本梯度有效秩很低。存 $M_\ell$ 的**前 $c$ 个秩因子** $M_\ell\approx u_\ell v_\ell^\top$（几次幂迭代得到），取 $c=1$（LoRIF 推荐值）：

$$\text{每层存储}\quad d_1 d_2 = 1024 \;\longrightarrow\; d_1+d_2 = 64 \text{ 个 float}$$

**打分是双线性型**（不重构梯度就算出 Frobenius 内积）：

$$s(z_{tr}, z_{te}) = \sum_\ell \left(u_\ell(z_{te})^\top u_\ell(z_{tr})\right)\left(v_\ell(z_{te})^\top v_\ell(z_{tr})\right)$$

### （2）SimpleLoRIF：两处简化

**简化一：扔掉曲率修正。** LoRIF 的打分是 $g_{te}^\top H^{-1} g_{tr}$，靠截断 SVD + Woodbury 恒等式才可算，结果拆成"普通梯度点积 + 曲率子空间内的修正项"。但本文**只用排序**（排名 → 删 top-p），不需要标定的影响值、不需要跨模型比分数大小、不需要预测删掉后 loss 怎么变。**纯粹的梯度相似度就够了。**

**简化二：只回传最后 4 个 transformer block。** 这是全文最实用的一刀。

式 3.1 是逐层定义的，式 3.2 对选中的层求和——所以**选哪些层就决定了要回传多深**。作者的消融四轴（投影维度 D、回传 block 数 N、每样本读多少 token、嵌入模型大小）：

| 轴 | 结果 |
|---|---|
| 投影维度 $D$ | 对 AUC 和速度都**几乎无影响**（可随便缩） |
| token 截断 | 有效但**有风险**，且难以泛化到长文档（放弃） |
| 缩小嵌入模型 | **质量掉太多**（放弃） |
| **回传 block 数 $N$** | **质量保住、成本大降** ⇒ 选 $N=4$ |

为什么 $N$ 这一刀特别划算：选中的 block 在**网络顶部**，所以反向传播在"最浅被选 block 的输入梯度"算完就停，**而前向仍然走完整网络**。$N=2$ 明显更差（AUC 0.65），$N=6$ 或 $8$ 收益递减。

### （3）嵌入质量怎么验

用一个数学基准做"检测 AUC"：把每条 train/test 数学题嵌入成 $(Q,A)$ 对（**问题 token 在 loss 里被 mask 掉**），逐样本梯度压成定长向量并 L2 归一化；每个测试题用"到训练集的最近邻余弦相似度"打分；AUC 衡量这个分数能否预测"该题在训练后**新变会做**"。

⇒ 嵌入空间里，测试项被放到了**真正改变了模型行为**的训练文档附近。

## 三、技术细节

### 规模

- 被嵌入的数据集：**939,343 条**（一个完整 post-training 集）
- 成本：**8×H100 约 1 小时**
- 存储：每层 64 个 float（$c=1$, $d=32$）

这个数字是本文最有工程价值的结论：**梯度归因从"小规模分析工具"变成了"可以对着整个 post-training 集跑的过滤器"**。

### 验证路径一：涌现性错位（EM）

在"不安全代码"上微调过的模型里，**不安全代码训练样本的梯度**与**微调后涌现的有害输出的梯度**对齐，且能与**严密匹配的安全代码样本**分开：

$$\text{AUC 最高 } 0.865$$

这条的意义：**表面内容相距极远的样本，可以在梯度空间里诱导相似的更新**。这就是"把安全退化当成训练数据归因问题"的合法性来源。

### 验证路径二：SafeTulu

- 取 Tulu 3，删掉**与 SafeRLHF 不安全响应梯度最对齐的 20%** 样本 → **SafeTulu**
- 在 Qwen / Llama / Olmo 三个家族上，**GCG 攻击成功率最多降 22%**
- **同时胜过** LLM-as-a-judge 过滤和先前的梯度过滤方法
- 通用、代码、数学、医疗基准上能力**基本保持甚至略有提升**

### 被删掉的样本长什么样（这一节最值得读）

作者对移除的样本做了定性与定量画像。反复出现的模式**没有一个是"看起来有害"的**：

| 模式 | 为什么它会推偏模型 |
|---|---|
| **工具执行失败**（tool-execution failures） | 模型在"任务失败 + 继续解释"的语境里学到"错误处理可以是叙述性的" |
| **叙事算术**（narrative arithmetic） | 用自然语言叙述计算过程而非严格推导，训练出"叙述优先于正确性"的倾向 |
| **直接 coding 任务** | 与 EM 的原始触发同源（不安全代码），但内容完全正常 |

三类模式的共同点：**它们都在教模型"过程可以被讲述，而不必被做对"**。而"叙述一个看起来合理的过程"恰恰是安全失守的通用形态——过拒（用一个听起来合理的理由报风险）本质上就是同一个毛病。

## 四、实验与结果

| 维度 | 结果 |
|---|---|
| 数据规模 | 939,343 条，8×H100 ≈ 1 小时 |
| 每层存储 | 64 float（$c=1$, $d=32$，未投影为 1024） |
| EM 检测 AUC | **最高 0.865**（不安全代码梯度 vs 涌现有害行为梯度） |
| 回传 block 数 | $N=4$ 最优；$N=2$ 降到 0.65 AUC；$N=6/8$ 收益递减 |
| 删比例 | 20%（附录有 removal fraction 扫描） |
| 安全收益 | GCG ASR **最多 −22%**，跨 Qwen / Llama / Olmo |
| 对比基线 | **胜过** LLM-as-a-judge 过滤、胜过先前梯度过滤法 |
| 能力 | 通用/代码/数学/医疗**基本保持或略升** |
| 交付物 | SafeTulu 数据集 + HuggingFace Space（可自定删除比例、可只筛某个子集） |

**"胜过 LLM-as-a-judge"这条要单独强调**：这说明**用 LLM 读内容判"这条样本安不安全"这条路，在有梯度信号的前提下是次优的**。而我们的标签审计恰恰全押在 LLM 读内容上（`full_check.py`）。这是一条需要正视的对照。

## 五、局限性

作者自己承认两条，我补三条：

1. **只测了 general safety**，没测具体危害类型或行为（如 sycophancy）。⇒ 我们的 PORN/VULG 是**具体类目**，"general safety"的结论不能自动下延。
2. **只用了 SafeRLHF 一个目标集**。目标集换了，删掉的 20% 就完全变了。⇒ 我们要用的话，目标集必须换成**我们自己模型的 PORN 误报响应**，而不是照搬 SafeRLHF。
3. **（补充）目标集本身可能是脏的**。如果 SafeRLHF 不安全响应里混了噪声，梯度对齐就会指向错误方向——而这一步没有交叉验证。我们要用的话，目标集必须是**人工确认过的**误报样本，不能用模型自己判的。
4. **（补充）"删 20%"是个粗粒度旋钮**。论文有扫描但没给"删多少最划算"的通用答案。我们的训练集只有 7W 量级，删 20% 就是 1.4W 条，成本可接受但要先确认删掉的不含关键长尾类（参见 2026-10-29 收录的 2610.36360：**长尾补数据掉 0.360**，删数据的风险是不对称的）。
5. **（补充）梯度空间的可解释性为零**。它能告诉你"这条样本在对齐方向上排第 3"，不能告诉你"因为哪句话"。所以它是**筛子不是审计报告**——筛完仍需人看。

## 六、复现指南

### 成本估算（对我们的 5 节点现实）

论文：93.9 万条 / 8×H100 / ≈1 小时。

我们的量级：7W 条，约为论文的 7.5%。并且**不需要 H100**——参考模型可以是我们要审计的那个 5B 模型本身（或同架构小模型），跑 QLoRA + 最后 4 个 block 的反向。粗略量级：

$$\frac{1}{8}\times\frac{7}{100}\times 1\text{h}\;\approx\;5\text{ 分钟}\;\text{（同卡型）}$$

即便按 5 节点里单卡 A100/80G 估，**十几分钟到半小时量级**是合理预期。这是本轮所有建议里**最符合算力现实**的一条。

### 最小实施步骤

**Step 1｜确定目标集 $\mathcal{T}$（成败全在这一步）**

不要用 SafeRLHF。用我们自己的：

- 从评测集里取**当前被判 PORN 但人工确认为无害**的样本（即 PORN 误报集）；
- 对每条取模型的**响应侧表示**（推荐用 `<tag>` 位置的隐状态梯度，或整个响应段的梯度）；
- 目标集大小 50–200 条即可（论文的目标集也不大）。

**Step 2｜算嵌入**

- 参考模型 = 待审计的 5B 模型，加载为 4-bit + LoRA（保证 backward 可跑）；
- 只回传**最后 4 个 block**；
- 投影 $d=32$，秩 $c=1$；
- 每条样本嵌入成 `[层数, 64]` 的向量并 L2 归一化。

**Step 3｜打分排序**

用式 3.2 的双线性型对每条训练样本与目标集算平均对齐度，降序排。

**Step 4｜看 top-k 的画像，不要急着删**

这是最关键的一步纪律。论文的价值一半在"能排序"，另一半在"**排在前面的样本长得不像有害**"。

打印 top 5% 的 `input_text` + 现有标签 + 人工判定，人工扫一遍，问三个问题：

- 这批里**人工标为"明确无害"**的占多少？
- 有多少落在我们已知的**边界档**（VULG-HINT-EDGE / PORN 暗示性）？
- 有多少**完全在我们现有清洗规则之外**（不是重复、不是脏字符、不是长度异常）？

**Step 5｜判据（决定后续路线）**

| top 5% 的构成 | 结论 | 下一步 |
|---|---|---|
| 主要是"良性但边界"，且与现有清洗规则**重叠** | 内容侧规则已经抓到了，梯度没带来新信息 | **停这条线** |
| 主要是"良性但边界"，但**规则完全没抓到** | 内容侧筛子有结构盲区 | 做小规模消融：删 top 5% 重训，看 PORN 误报是否下降 |
| 含大量**人工标为明确无害**的样本 | **现在的清洗规则在删错东西** | 立刻回查清洗规则，这条比调 loss 优先级高 |
| 与"表达规范度"切片强相关 | 是覆盖/定义问题，不是梯度问题 | 转去做 E3（表达规范度切片） |

### 与已有线路的关系（这条要写进方案）

它不是第五条平行主线，而是**给标签审计线加的一个正交维度**：

| 维度 | 看什么 | 已有做法 | 本文补的 |
|---|---|---|---|
| 内容侧 | 这条样本长什么样 | 规则清洗、LLM 复判、向量聚类查覆盖 | — |
| **梯度侧** | **这条样本把模型往哪推** | **无（空白）** | **SimpleLoRIF** |

两个维度的交集才有信息量。**只有内容侧，我们会一直在"标签对不对"上打转；加上梯度侧，才有机会回答"标签对了为什么还是错"。**

### 实现注意

- **不要**在前向时截断 token。论文试过，有效但"risky and unlikely to generalize"。
- **不要**缩小参考模型。论文试过，质量掉太多。
- **可以**缩小投影维度（$D$ 对结果几乎无影响），这是最安全的省算力点。
- 打分只用**排序**，不要试图把分数当"影响力度量"解释。
