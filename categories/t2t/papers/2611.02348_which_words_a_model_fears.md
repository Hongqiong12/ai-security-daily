# 决定拒答的不是"请求"，是"词表里的某个词"

**论文主页**: https://arxiv.org/abs/2611.02348
**领域**: 过度拒答（over-refusal）/ 拒答方向（refusal direction）/ 词表级风险锚点 / 输入侧改写的可测化
**作者**: Boyuan Zhang, Mohammad Zandsalimy, Shanu Sushmita（**Northeastern University**）
**机构**: **美国东北大学**（单机构，三人）
**发布日期**: 2026-11-02（v1，cs.CL）
**分类**: defense / input-side
**模态归属**: T2T 输入侧（迁移 T2I 输入侧 Prompt Rewrite 的锚点定位与替换规则）

---

## 一、背景与问题

### 动机

过度拒答的既有解释停在"表面上像风险的词会触发拒答"（XSTest / OR-Bench / FalseReject 这一系），注意力分析也指出"个别有害词是触发器"。这些工作建立了**"表面词有影响"**，但没有建立**"每个词影响多大"**。

论文要回答的是一个可以直接操作的问题：

> 一个 prompt 被拒了。**把哪个词换成它的哪个同义词，能让拒答降得最多？**

这个问法与我们的输入侧改写是同一个问题，只是被问在了 LLM 上。我们的改写管线当前的隐性假设是"风险来自整条 prompt 的语义"，于是用整条 prompt 做风险打分、用整条 prompt 的 edit rate 做保真约束。这篇把测量单位从 prompt 下沉到 **word**，并且给出了跨全词表（71,583 词）的分数表。

### 三个要先立住的现象

| 实验 | 做法 | 结果 |
|---|---|---|
| 插入 | 往 321 条模型本就拒 ≤0.80 的有害 prompt 里插 1 个与请求无关的有害词（词表 99 词），位置=首/中/尾 | 首 **+0.31 [0.22, 0.40]**（55 条）／中 **+0.19 [0.13, 0.25]**（105）／尾 **+0.33 [0.29, 0.37]**（267）；八模型尾部插入 **+0.10 至 +0.49** |
| 识别门槛 | 新开 chat 问模型"刚才多出来的是哪个词" | 只在识别概率 **>0.90** 的样本上取效应 —— **模型认出了那个不属于请求的词，然后照样拒** |
| 替换 | 在被拒的良性 OR-Bench Hard-1K prompt 上，把**一个实词**原位换成**保义且无害联想**的同义词 | 拒答降 **3–28 点**；换成"惰性词"（表上接近 0 的词）只动 **≤2 点**，区间全含 0 |
| 删短语 | 被定位到的是模糊短语而非单词（"what steps"、"without getting caught"，57 条） | 整段删除降 **4–50 点**，除 Llama 外区间均不含 0 |

第一条的细节值得单独记：插入位置效应**不是**"模型没看见"。识别置信度与逐 prompt 的拒答上升**无关**（首/中位置 Spearman ρ = 0.00，尾 +0.18）。这不是注意力漏掉，是**看见了也不影响判决**。

### 核心问题

1. 有没有一个**共享的、可定位的、因果的**方向，承载"这个词有害"这件事？
2. 这个方向能不能当**尺子**扫全词表，给每个词一个分数？
3. 这张表能不能**预测没见过的词、没见过的 prompt 上的行为**？

## 二、核心方法

### （1）读出位置：generation boundary（TBG）

不做 token 级归因，只读**一个位置**：assistant 第一个 token 之前的**最后两个 prefill token** 的 residual stream 输出。Qwen3.5 的模板里这是空 think block 的 `</think>` 加 `\n\n`；Llama / Gemma / Phi 没有 think block，取 assistant header 的最后两个 token。

选这个位置的理由是既有的：安全对齐的决策集中在这里。

### （2）交叉设计（crossed design）把"词"从"prompt"里剥出来

96 条 prompt × 24 对（有害词／等长中性词，如 bomb/garden、illegal/compass），每格做两次前向，取

D_pw = h(H,pw) − h(N,pw)

这一步同时消掉了"prompt 本身"和"追加一个词这个动作本身"。然后对 2,304 格做精确两因子向量方差分解：

D_pw = μ + A_p + B_w + I_pw

结果：**共享分量 μ 占 ‖D‖² 的 0.30，全部词效应加起来只有 0.15**；prompt 分量 0.32 被交叉设计抵消掉；24 个词里有 **21 个**的逐词平均方向与 μ 的余弦在 **0.82–0.96**。不同的有害词把边界状态往**同一个方向**推。

### （3）交叉拟合（cross-fitting）：方向和被测格互不沾边

prompt 和 word 各自做独立的四折划分，每个测试折的方向 μ_f 只用**对面矩形**重建。所以在"没见过的 prompt × 没见过的词"上，投影 ⟨D_pw, μ̂_f⟩ 在 **95%** 的格上为正（符号翻转 p < 10⁻⁴）；把投影和拒答变化都对 prompt+word 固定效应残差化后，Spearman **ρ = 0.65**。

### （4）当尺子用：全词表扫描

把 71,583 个候选词（全部单 token 词 + 50k 最高频英文词）逐个追加到 **48 条被过度拒答的 Hard-1K prompt** 末尾，读 TBG 位移在 μ̂ 上的投影，按 Hard-1K 上的标准差归一，对 48 条取均值 —— 这就是该模型的"恐惧表"。

- 两个互斥的 24 条 prompt 半集，**词序复现 ρ = 0.95**
- 正端是性相关词、恋童/强奸词、侮辱词、暴力犯罪词；负端是**语域词**：sardonic、shakespearean、poetic、sassy、whimsical
- `bomb` 在 Qwen3.5-4B 表上只排 **97 百分位**，在"干净良性表"上排 **70 百分位**

### （5）表引导的替换（这是对我们最直接可搬的一步）

1. **定位**：模型自己的表提名"最被恐惧的实词"；有害 prompt 上用方向做 leave-one-out 删除扫描定位
2. **起草与筛选**：DeepSeek-V4-Flash（T=0）提最多 10 个保义、无有害联想的替换词；过了结构检查后，**取表上位移最低的那个**（最"有勇气"的）原位替换
3. **对照**：把 prompt 里**最惰性**的词（表上位移近 0）换成同义词
4. 每条件 10 次采样，判拒答

## 三、技术细节

### 因果性：剂量单调

剂量单位是该模型自己的平均边界位移 μ。只在 prefill 阶段、在 TBG 两个位置写入。

| 写入 | 效应 |
|---|---|
| 在尾部插词文本上写 **−1.5** | 移除 **+0.09 至 +0.28** 的拒答，即插入升幅的 **41%（Llama）到 92%（Qwen3.5-0.8B / Phi）** |
| 在原文本上写 **+1.5** | 造出 **+0.04 至 +0.39** 的拒答（Holm p = 7×10⁻⁴） |
| 半剂量 | 同向、幅度更小；剂量单调的 bootstrap 概率 **0.99–1.00** |
| 正交的等范数随机方向 | 拒答变动 **≤ +0.02** |
| **KL 匹配**的随机方向（需要 **1.7–4.7 倍**剂量） | 八个模型里全部落后于本模型方向 |

Qwen3.5-4B 上另做交叉拟合检验，在 α* = 0.5（恰好抵消拟合出的共享分量）处：从有害词文本减 μ_f/2 移除 **+0.080 [0.043, 0.121]**，从中性词文本加 μ_f/2 增加 **+0.086 [0.041, 0.133]**。

### 换掉的是措辞还是实质？

在 288 格上，一个"实质遵从"标签镜像地跟着动（减 **+0.072**、加 **−0.082**）。**写这个方向换掉的是模型交付的内容，不只是措辞。**

### 词的反应发生在哪一层

- 在**词自己的 token** 上，差异有 **70–88%** 是词特有的，但对拒答的预测力只有 **ρ ≈ 0.2**
- 到 **TBG**，从**第 12 层起**共享分量压过词分量；右图给出"边界投影 vs 拒答变化"的 rank 相关随层的走势
- 机制上：边界**并没有**比中性孪生词更多地注意有害词；边界位移里 **late MLP 写了 73%**，直接注意力读词只贡献 **1%**

一句话：**词被读取得很早，但它的效果被写得很晚。**

### 表的性质

| 检验 | 数 |
|---|---|
| 从词输入 embedding 岭回归预测位移 | **ρ = +0.78**（71,583 词） |
| 从词的上下文无关 residual 状态预测 | **ρ = +0.84**（按词分组交叉验证） |
| 把词自己的上下文无关状态**投影到方向上** | **ρ 介于 −0.35 与 +0.04** |
| 跨模型表一致性 vs Qwen3.5-4B | **+0.36（Phi）至 +0.76（Qwen3.5-9B）**；彼此 +0.29 至 +0.81 |
| 八个表共同核心 | **60 个词**同时在八个表的 top 1%；**25 个**同时在 bottom 1% |

第三行是最反直觉的：**位移不是词自带的，是网络读完之后写上去的**。所以你不能"看词面猜风险"，只能"跑一遍模型量风险"。

## 四、实验与结果

八个 instruction-tuned 模型：Qwen3.5-0.8B / 2B / 4B / 9B / 27B、Llama-3.2-3B、Gemma-4-E2B、Phi-4-mini。Qwen3.5-4B 是开发模型（所有流程在它上面设计），其余七个是验证模型。

### 验证一：没见过的词，剂量响应

每模型从全表抽 40 个词（八个百分位桶各 3 个 + 16 个"两表打架"的词），追加到模型约半数会拒的**没见过的** prompt（Qwen3.5-4B 64 条，其余 32 条，良性有害各半）。

| 模型 | 表位置 vs 拒答变化（自身表） | 最高桶 − 最低桶 | 相邻桶有序 |
|---|---|---|---|
| Qwen3.5-4B | **ρ = +0.92**（干净良性表 +0.55） | −0.165 → **+0.367** | **7/7** |
| 其余七模型 | **ρ = +0.54 至 +0.96** | **+0.32 至 +0.71** | 5–7 / 7 |

插词位移对逐 prompt 拒答上升的预测：**ρ = +0.32 至 +0.77**，优于 **997 到 1000/1000** 个随机方向。

### 验证二：自然 prompt 里的替换（正文实验）

**良性侧**：Hard-1K 上多数模型会拒的 prompt + 100 条安全 XSTest，每模型 349–352 单元。

| 条件 | 移除的拒答 |
|---|---|
| 最恐惧词 → 表上最低位移的同义词 | **+0.05（Llama，其基线拒答 0.13）至 +0.29（Qwen3.5-27B）**，八个区间全不含 0 |
| 最惰性词 → 同义词（对照） | **+0.01 至 +0.05** |
| XSTest | 八个模型里七个显著 |

**有害侧**：OR-Bench Toxic 上模型会拒的 prompt + 100 条 XSTest 对照。

| 项 | 数 |
|---|---|
| 替换规则能覆盖的 prompt 比例 | **64%** |
| 覆盖不了的原因 | 约 **1/4** 根本不存在"保义且无有害联想"的词（自残、性、炸弹）；**11%** 三次重写仍过不了结构检查 |
| 替换后移除的拒答 | **+0.08 至 +0.23**，八模型全部 |
| 删除被定位的模糊短语（23 条） | **+0.17 至 +0.36** |
| 回答的有害度上升 | **≤ +0.04**（GuardReasoner-8B 判） |

### 三组"预期之外"的结论

1. **手挑的"安抚词"全部无效。** 作者从六类猜测（收纳/授权/防御/教育/虚构/职业）手工选了 24 个"勇气词"，**没有一类降低拒答**（最好的是"虚构"类 −0.029 [−0.091, +0.031]），而"收纳"类反而**升高 +0.075**。真正有效的是语域词（poetic / whimsical）—— 直觉错得离谱。
2. **表上"最恐惧的十个词"不含任何插入词表里的词**；把它们的位移换成行为，在 20 条"模型拒 <1%"的干净良性 prompt 上，拒答升 **+0.372 [+0.283, +0.468]**；而且 **0.986** 的拒答回答把追加词**当成请求的一部分**在处理。
3. **"选哪个同义词"的增量很小，但稳定。** 随机抽一个无害同义词也能移除 **+0.04 至 +0.24**；用表上最低的那个再多移除 **+0.02 至 +0.08**（八模型全正，Holm 显著 3/7），投影再多降 **0.12–0.21 sd**。**真正干活的是"换掉那个被恐惧的词"，选词的增量是二阶的。**

### 一条方法论上的连带结论

> 安全评测**必须控制词表**，因为一个 benchmark 的拒答率取决于它的 prompt 恰好用了哪些词。

## 五、局限性

1. **只测了 8 个 open-weight、≤27B 的模型**，没有闭源模型。表本身需要激活值，不能纯 API 拿；但插入与替换实验只需要采样，理论上能通过 API 迁移。
2. **全英文**。多语模型原则上每个语言一张表，跨语言的"恐惧"是否一致未测。
3. **机制分析只做了 Qwen3.5-4B 一个模型**，其余七个只有行为验证。
4. **词表扫描只用一个位置（prompt 末尾）**。首/中的位置效应显著不同（+0.31 / +0.19 vs 尾 +0.33），说明"末尾扫描"会系统性低估某些位置上的锚点。
5. **拒答、劫持、回答有害度全部由 LLM judge 标**。论文给了 κ ≥ 0.96 的 test–retest 与跨 judge 一致性，但 judge 与被判模型同源的风险没排除。
6. 表与行为的关系是**单向预测**，不是解释：论文自己承认位移是 late MLP 写的，而它预测不了"为什么是这个方向"。

## 六、复现指南

### 环境
- 8 个模型的 HF 权重；需要 residual stream 读取能力（forward hook 到指定层）
- 一个 drafting 模型（论文用 DeepSeek-V4-Flash，T=0）与一个 refuse judge
- 代码：https://github.com/zboyr/which-words-a-model-fears

### 最小复现路径（按投入排序）
1. **先做"插入实验"**（不需要方向）：99 词表 × 321 条 prompt × 3 个位置，每条件 10 次采样。只要看到尾部 +0.10 以上的拒答上升，就确认了"词级锚点"在你的模型上存在。
2. **再做交叉设计拟合方向**：96 × 24 = 2,304 格，两折前向。检查 ‖μ‖²/‖D‖² 是否在 0.25–0.35 之间（论文 0.30），21/24 词余弦是否 ≥0.82。
3. **最后做词表扫描**：71,583 词 × 48 条 prompt。这一步的算力是 71,583 × 48 次前向 —— 论文没说清是否做了批处理，实际落地要按 batch 摊。**建议先降到 5k 词 × 32 条 prompt 看半集复现 ρ 能否过 0.9**。
4. **替换实验**是性价比最高的一步：不需要方向也能做（用"随机无害同义词"当基线），只需要 drafting 模型 + judge。

### 关键超参
- 读出位置：assistant 首 token 前最后两个 prefill token
- 剂量：以本模型平均边界位移 μ 为单位；注册剂量 α* = 0.5
- 判定门槛：插入实验的识别门 **P > 0.90**
- 采样：每 prompt 10 次（表剂量响应 20 次）

### 迁移到 T2I 输入侧改写的注意事项
- 论文的锚点是**词**；T2I 里的锚点可能是**短语/构图描述**（"standing on the track"、"from above"）。用同一套"leave-one-out 删除扫描"可以在**任意可删单元**上做，不限于单词。
- 论文的"恐惧"是**拒答**；我们要的是**风险分**。方向可以换成"风险分类器最后一层 logit 的方向"，但这条路**没有在这篇里被验证过**，属于外推。
- 表是**逐模型**的：换 checkpoint 就要重扫。
