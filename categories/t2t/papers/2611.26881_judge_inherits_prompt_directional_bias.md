# judge 的偏置是单向的：偏向接受能虚高 29.5 点，偏向拒绝却不会对称下降

## 一、背景与问题

### 动机：judge 自己也是被几句 in-context 示例牵着走的冻结模型

LLM-as-judge 已是开放式输出评分的标准做法，但 judge 是**被少量 few-shot 示例引导的冻结 LM**，而这类模型会吸收示例的**标签平衡**，不会把示例当中性插图看。作者问：这个偏置会不会进入一条**多模态（视频问答）评测管线**，以及它以什么形态出现。

实验把 generator–judge 管线**完全冻结**，生成的答案固定不变，**只改 judge 的 Yes/No few-shot 示例平衡**（四套演示集），每个判定对照**两名标注员在每数据集 200 例上的人工共识**。

### 与本仓库主线的关系

- 直接对应方向(2)「**VLM-as-judge 图审 / 图审双模型 AB 对比评测**」与方向(5)「**评测集构建与多版本回归、实验台账可复现性**」：如果 AB 看板用 judge 打分，而 judge 的示例标签平衡没冻结，那么**版本间比较的是 judge 的示例，不是模型**。
- 「**inflation-only asymmetry**（只把分数往上抬、从不往下压）」是「假安全」在评测侧的镜像：**线上是"看起来安全其实没拦"，评测侧是"看起来准确其实没对齐人工"**。
- **单次示例抽样波动达 18 点，超过任意两套演示集之间的差异** ⇒ 本仓库 11-03 Prompt Lottery「换措辞让 κ 掉 6–9 倍」的同族证据，且给出便宜的修法（多次抽样 + 人工共识）。
- 与 11-05「数字绑定配置」、11-04「评测集五项冻结」合起来，构成「judge 配置指纹」的硬要求。

## 二、核心方法

| 项 | 设定 |
|---|---|
| 管线 | 冻结 generator → 冻结 **LLaMA-3.1-8B** 语义 judge（对照 ground truth 打 Yes/No） |
| 变量 | **仅** few-shot 示例的 Yes/No 平衡，四套：`S2=0.25`、`S4=0.50`、`S5=0.50`、`S3=0.75` |
| 数据集 | **NExT-QA**（Causal 48% / Temporal 29% / Descriptive 23%）、**MSVD-QA** |
| 人工基准 | 每数据集 **200 例**分层验证样本，两名标注员共识 |
| 报告量 | J%（judge 接受率）、C%（共识接受率）、Bias=J−C、FP / FN 原始计数、FP:FN 比 |

**关键控制**：生成答案固定 ⇒ 任何判定变化**只能**来自 judge 的 in-context 示例，不能推给生成器波动。另做**五次抽样分析**，量化单次示例抽取的方差。

## 三、技术细节

### 3.1 Table 2 的核心几行（数值为论文口径）

| 数据集 | 演示集 | Yes 比例 | J% | C% | Bias | FP | FN | FP:FN |
|---|---|---|---|---|---|---|---|---|
| NExT-QA | S2 | 0.25 | 55.5 | 56.5 | −1.0 | 40 | 42 | 1.0 |
| NExT-QA | S4 | 0.50 | 55.0 | 56.5 | −1.5 | 33 | 36 | 0.9 |
| NExT-QA | S5 | 0.50 | 55.0 | 56.5 | −1.5 | 33 | 36 | 0.9 |
| **NExT-QA** | **S3** | **0.75** | **86.0** | **56.5** | **+29.5** | **66** | **7** | **9.4** |
| MSVD-QA | S2 | 0.25 | 64.0 | 63.5 | +0.5 | 31 | 30 | 1.0 |
| MSVD-QA | S4 | 0.50 | 61.5 | 63.5 | −2.0 | 35 | 39 | 0.9 |
| MSVD-QA | S5 | 0.50 | 66.0 | 63.5 | +2.5 | 32 | 27 | 1.2 |
| **MSVD-QA** | **S3** | **0.75** | **83.0** | **63.5** | **+19.5** | **52** | **13** | **4.0** |

⇒ **平衡（S4/S5）与偏拒绝（S2）都贴在人工共识 ±2.5 点内**；只有**强偏接受**把接受率抬 **+29.5 / +19.5 点**，且误差形状**强烈单边**（FP:FN **9.4 / 4.0**，对比平衡档的 ≈1.0）。相反方向的偏斜**没有对应下降** ⇒ 偏置是 **one-directional / inflation-only**，不是对称噪声。

**后果**：在这种 judge 下，**报告的 benchmark 准确率只可能被推高、不会被压低**；平衡示例能消掉 inflation，但**消不掉 item-level 不可靠**，因此它补充而非替代人工验证。

### 3.2 五次抽样

单次示例抽取的结果**波动最高 18 点**，**超过任何两套演示集之间的差异** ⇒ 只跑一次抽取下的结论不可复现；这与本仓库「换 prompt 让 κ 从 0.89 掉到 0.24」「批处理让 11–22% 判定翻转而 AUROC 只动 0.03」形成同一条证据链。

### 3.3 分层口径的缺口

作者如实标注：MSVD-QA 的 200 例分层验证样本**低代表 How / When，完全不含 Where**（NExT-QA 给了语料级类别占比但 MSVD-QA 未报）⇒ **聚合 Bias 数字不能替代逐类目检查**，与「整体 F1 微涨而 L3 宏 F1 回退」同构。

## 四、实验与结果

| 观察 | 数 |
|---|---|
| 偏接受导致接受率跃升 | **+29.5 点**（NExT-QA）/ **+19.5 点**（MSVD-QA） |
| 平衡与偏拒绝 | 全部落在人工共识 **±2.5 点**内 |
| 误差形状 | FP:FN **9.4 / 4.0**（偏接受）vs **≈1.0**（平衡） |
| 对称性 | **无**：偏拒绝不产生对应下降 |
| 单次示例抽取波动 | **最高 18 点**，超过演示集间最大差异 |
| 人工验证规模 | 每数据集 **200 例**，双标注员共识 |

**最该抄的一句**：judge 的偏置**不是零均值噪声，是单方向抬高**；因此「用另一套 judge 复核」若也偏接受，会得到**同向虚高的一致**，而不是互相校验。

---

## 五、局限性

1. 非对称性只建立在**每数据集一套偏拒绝演示集**上，作者自承未画出完整曲线；靠平衡档误差与最高一致性佐证，但未追踪成函数。
2. 偏接受演示集**类别构成也不同**；虽有固定生成控制与逐类目上界做缓解，仍是潜在替代解释。
3. 只测 **LLaMA-3.1-8B 一个 judge**、两个视频 QA 数据集、Yes/No 二值判定；未测 L1–L4 序数等级、未测图像 NSFW/PORN-VULG 边界、未测中英混合。
4. 无安全率 / 误杀率 / 漏过率、无阈值 operating point、无 conformal 覆盖；不能直接当线上图审指标。
5. 未测量化 / 推理加速后的偏置漂移（与 27155 的量化判定 churn 可成对部署）。
6. judge 是文本判定器，本文没有测图生图链路的**像素级反馈缺失**（VEvo-Harness 指出的输入侧短板）。

## 六、复现指南

**图审 AB 的 judge 自检（半天，零训练，最优先）**：把本项目本地 AB 看板（文生图图审 / 图生图改写）中 judge 的 few-shot 示例冻结成**标签平衡的固定集**，另跑两臂：`偏接受 0.75` / `偏拒绝 0.25`，各跑**五次抽样**，对照人工双盲共识 200 例。报 J%、C%、Bias、FP:FN、以及**五次抽样的极差**。

**判据**：
- 偏接受臂 Bias **>+15 点** ⇒ 现有 AB 分数含 inflation-only 偏置，**历史版本对比作废重跑**；
- 五次抽样极差 **>10 点** ⇒ 单次 judge 结论不可复现，必须改多次抽样 + 中位数/Plurality 聚合；
- 双臂差异若**不对称** ⇒ 不能用「再换一个 judge 交叉验证」当修法（会同向虚高），必须回到人工共识基准。

**配置指纹（写进评测台账）**：judge ckpt / system prompt 版本 / few-shot 示例 ID 与标签平衡 / 抽样次数与种子 / 人工共识集版本 / 聚合规则。任一变更登记为 **calibration 事件**，与 ckpt、训练配置、数据集变更日志并列。

**分层口径**：Bias 与 FP:FN 必须按 `一级类目 × L2_30 叶子` 分格报；低样本类目（如本文 Where=0）明确标"不可判"而非并入聚合。与 27155 的量化翻转四栏合并成一张「不劣化验收表」。

**成对部署**：量化/加速迁移时同时跑本自检——27155 回答「判定集合换了多少」，本文回答「判定尺子本身有没有被示例带偏」；两者都过才算不劣化。

**依赖**：冻结 generator 与 judge；生成答案固定；每数据集 200 例双标注员共识；五次独立示例抽取。数字均为论文口径，不做外推。
