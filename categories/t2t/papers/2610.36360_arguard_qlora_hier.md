# AK_QMUL @ ArGuard: 一个 QLoRA 骨干打赢两个赛道 —— 标签因子化只在长尾被补上时才成立

**论文主页**: https://arxiv.org/abs/2610.36360
**领域**: 有害 prompt 二分类 + 七类危害域分类 / 4-bit QLoRA / 标签因子化 / 类别不均衡处理
**作者**: Ali Khairallah, Arkaitz Zubiaga
**机构**: **Queen Mary University of London**（ArabicNLP 2026 Shared Tasks，与 EMNLP 2026 合办；ACL Anthology 已收录）
**发布日期**: 2026-10-26（v1，cs.CL）
**分类**: defense
**模态归属**: 文生文（T2T）— 文本侧内容安全分类，**迁移价值：层级标签 + 长尾 + 低算力 SFT 三件事一次给全**

## 一、背景与问题

### 动机

部署一个助手，必须在回答**之前**判断这个 prompt 是不是在要危险的东西，而且要跨现代标准阿拉伯语（MSA）与五种方言判——**方言的表层形式差异远大于英语**。

ArGuard-2026 共享任务把它拆成两个问题，**同一个 prompt 池**：

- **B1**：safe / unsafe 二分类；
- **B2**：unsafe 里属于**七个危害域**的哪一个（adult_content、harm-to-others、Bully、self-harm、FraudandDeception、harassment、hate_speech）。

两个赛道都用 **macro-F1** 评分——**稀有类与常见类等权**，所以它奖励的是"各类别都均匀"而不是"平均准"。

### 核心科学问题

在**单卡、6.7B、4-bit 量化**的现实算力下，一个阿拉伯语中心骨干能不能同时拿下"粗粒度安全判定"和"细粒度危害分类"？以及——**标签结构该怎么设计**？

### 为什么这篇对我们重要

我们有三件事和这篇是同构的：

1. **我们的层级标签体系（L1–L4 递进 + L2_30 政治/敏感地区层级口径）就是"标签因子化"问题**——把 L1 与 L2 拆成两个正交维度联合预测，还是做成一条扁平的层级路径；
2. **我们的算力现实是从 6 节点缩到 5 节点**——这篇整篇就是在 4-bit QLoRA 单骨干上做的，是最贴的成本参照；
3. **我们的最差类别 VULG-HINT-EDGE 与这篇的 Bully 是同一类病**：**语义上与相邻类别重叠**，macro-F1 都栽在这里。

而且它给出了一个我们可能一直在犯的错的直接证据：**标签因子化本身不是收益，它需要一个前提——被因子化出来的那个最稀疏格子必须先被补数据，否则因子化会把分数打崩（0.984 → 0.624）。**

## 二、核心方法

### （0）一个骨干，两套头

两个提交**共享完全相同的骨干与训练配方**，只在**分类头、是否用外部数据增强、最终预测如何形成**上不同。

| | B1 | B2 |
|---|---|---|
| 头（类数） | **4** | 7 |
| 标签方案 | safety × **register（方言/标准语）** | 危害域 |
| 增强 | **AraSafe（安全 MSA）** | — |
| 种子 | 1 | **5（平均）** |
| 解码 | argmax → 折叠为二元 | 均值 softmax 的 argmax |

### （1）共享配方：因果 LM 的 last-token 线性头

**JAIS-6.7B**（阿拉伯语中心 decoder），**4-bit NF4 + 双量化 + bfloat16 计算 dtype**。LoRA 挂在**所有线性投影**上（$r=16$、$\alpha=32$、dropout 0.05），底座冻结。

因为 JAIS 是因果模型，**池化方式是取最后一层最后一个非 padding 位置的隐状态**，转 float32 过一个线性分类头。

训练：3 epochs，AdamW，lr $10^{-4}$，linear schedule + 5% warmup，batch 8，**最大序列长度 192**（覆盖几乎所有 prompt 不截断）。**损失是类加权交叉熵，权重取类别频率的倒数**——理由直给：**"稀有类不能被淹没，这直接关系到 macro-F1 目标"**。训练折用**分层分组 k 折（k=7）**，测试提交时在 train+dev 合并上重训。

### （2）B1：把标签按"方言寄存器"因子化

把每个 B1 标签拆成四类：`safe-MSA` / `safe-other` / `unsafe-MSA` / `unsafe-other`，训练头去预测这四类，推理时**对四个 logit 取普通 argmax，再按前缀折叠回二元**（两个 unsafe 子类都映射到 unsafe）。

**关键设计声明**：解码时**不做任何基于方言的后处理**，方言信息**只通过训练标签进入模型**。

**数据现实（这是全文最刺眼的一组数）**：B1 训练池（train+dev，**19,236** prompt）里 `unsafe-MSA` 占 **40.6%**、`unsafe-other` 占 **39.3%**，而 `safe-other` 只有 **12.5%**、**`safe-MSA` 只有 7.6%**。

于是补数据：从 **AraSafe** 的人写 MSA 集（12,077 条）里，保留非有害实例、丢掉短于 10 字符或命中方言标记词表的、与 train/dev/test 去重，得到 **7,607 条**纯 MSA 安全 prompt，**只加进训练折**（打 `safe-MSA` 标签），held-out 折不动，**增强只在最终测试重训时施加**。

### （3）B2：五种子 softmax 平均

同一个骨干换七类头，**不做方言因子化、不做增强**。训 **5 个同配置种子（42–46）**，**平均它们的 softmax 分布**，取均值的 argmax。作者明确说：**平均是唯一的集成手段——没有 stacking、没有 held-out meta-learner、没有逐类阈值**。

## 三、技术细节

| 项 | 配置 |
|---|---|
| 骨干 | JAIS-6.7B（阿拉伯语中心 decoder） |
| 量化 | **4-bit NF4 + 双量化**，bfloat16 计算 |
| LoRA | 所有线性投影；$r=16$，$\alpha=32$，dropout 0.05；底座冻结 |
| 池化 | 顶层**最后一个非 padding 位置**隐状态 → float32 → 单层线性头 |
| 优化 | AdamW，lr $10^{-4}$，linear + 5% warmup，**3 epochs**，batch 8，**max_len 192** |
| 损失 | **类加权 CE，权重 = 逆类别频率** |
| 验证 | 分层分组 k 折，**k=7** |
| 最终提交 | train+dev 合并重训 |
| 增强（B1） | AraSafe 人写 MSA 安全集 → 过滤（<10 字符、方言标记词）→ 去重 → **7,607 条** |
| 集成（B2） | 5 种子（42–46）softmax 平均 |
| 数据规模 | B1 训练池 19,236；B2 测试 5,979 条 unsafe |

**方言分布（测试集）**：MSA 5,331 / Syrian 1,030 / Egyptian 438 / Palestinian 348 / Moroccan 469 / Algerian 193。

**一个必须先看的分布事实**：**真实不安全率按方言极不均匀**——MSA 只有 **36.6%** 不安全，而五种方言是 **71.7% / 91.3% / 74.7% / 73.8% / 79.3%**。也就是说**"方言"与"不安全"在数据里高度相关**。这正是 B1 需要按寄存器因子化的统计学理由，也是它的风险来源（模型可能学到"方言 ⇒ 不安全"的捷径）。

## 四、实验与结果

### B1：方言维度表现（测试集）

| 方言 | n | 真实不安全% | 预测不安全% | 准确率% |
|---|---|---|---|---|
| MSA | 5331 | 36.6 | 37.1 | **98.8** |
| Syrian | 1030 | 71.7 | 71.7 | 97.7 |
| Egyptian | 438 | 91.3 | 91.6 | **99.8** |
| Palestinian | 348 | 74.7 | 74.4 | 99.1 |
| Moroccan | 469 | 73.8 | 75.9 | **93.6** |
| Algerian | 193 | 79.3 | 80.3 | 97.9 |

**macro-F1 0.984，B1 赛道第一。**

两个值得单独记的点：

1. **预测不安全率紧密跟随真实不安全率**（36.6→37.1、71.7→71.7、91.3→91.6），说明校准不坏；
2. **最弱的是 Moroccan（93.6%）**，一个只有 469 条样本的方言——**不是最难的类，是样本最少的类**。

### B1 消融：这是全文最重要的一张表

| 头 | AraSafe 增强 | macro-F1 |
|---|---|---|
| 2 类（safe/unsafe） | 有 | 0.983 |
| 4 类（safety × register） | **无** | **0.624** |
| 4 类（safety × register） | **有** | **0.984** |

**读法（关键）**：

- 因子化的**净收益几乎为零**：0.984 vs 2 类的 0.983，**+0.001**；
- 但**去掉增强，因子化直接把分数打崩 −0.360**（0.984 → 0.624）。

⇒ **因子化本身不是收益，它是一个"必须配套补长尾"的放大器**。当 `safe-MSA` 只占 7.6% 时，四类头里有三个格子被充分监督、一个格子饿着，模型会把那个饿着的格子随便填；而 argmax 只取最大 logit，**那个饿着的格子会系统性抢走本该属于它的样本**，折叠回二元就变成了误判。

**这对我们层级标签的直接含义**：如果我们把 L1 与 L2 拆成正交因子（或把 L2_30 单列一维），**就必须先确认每个格子有足够样本**，否则联合头的收益会被最稀格子的饥饿吃掉。**"层级越细越好"是个未经验证的假设。**

### B2：分层看，问题全在"标准语"和"语义重叠类"

| 类 | MSA | Syrian | Egyptian | Palestinian | Moroccan | Algerian | **All** |
|---|---|---|---|---|---|---|---|
| adult_content | 0.98 | 0.98 | 1.00 | 0.98 | – | 0.95 | **0.98** |
| harassment | 0.81 | 0.91 | 0.96 | 0.89 | 0.90 | 0.93 | 0.86 |
| hate_speech | 0.67 | 0.91 | 0.99 | 0.98 | 0.92 | 0.91 | 0.84 |
| self-harm | 0.69 | 0.96 | 0.96 | 0.88 | 0.89 | 0.95 | 0.80 |
| FraudandDeception | 0.63 | 0.96 | 0.88 | 0.81 | 0.88 | 0.83 | 0.74 |
| harm-to-others | 0.64 | 0.87 | 0.92 | 0.89 | 0.86 | 0.67 | 0.73 |
| **Bully** | **0.46** | 0.90 | 0.97 | 0.89 | 0.81 | 0.92 | **0.57** |
| **macro-F1** | **0.70** | 0.93 | 0.95 | 0.90 | 0.88 | 0.88 | **0.79** |
| n | 3501 | 1030 | 438 | 348 | 469 | 193 | 5979 |

**这张表是全文对我们最有价值的部分，有两条独立信息：**

1. **明确类好判，重叠类难判**：`adult_content` 聚在 0.95–1.00，`Bully` 只有 0.57。作者的原话：**"residual error concentrated in the Bully class, which overlaps semantically with harassment and harm-to-others"**。⇒ **与我们 PORN 好判 / VULG-HINT-EDGE 难判是同一个结构性现象：不是模型不够强，是类目定义在语义上相互包含。**
2. **聚合数字掩盖了切片崩塌**：总体 macro-F1 0.79 看着"还行"，但 **MSA 切片只有 0.70，比方言切片（0.88–0.95）低 18–25 点**。而 **Bully 在方言上是 0.81–0.97，唯独在 MSA 上是 0.46**。

⇒ **"最难的不是最不常见的表达，而是最规范、最需要靠语义边界而不是靠表面标记判断的那一档。"** 方言提供了强表面线索（口语化的侮辱词），MSA 提供的是干净的、书面化的、可以互相嵌套的语义——**表面特征帮不上忙，模型只能靠边界理解**。

## 五、局限性

1. **B2 方差未报告**。五个种子取了平均，但**没给单种子方差**——所以"平均带来多少收益"是个未知量。这是很关键的一项缺失：**如果单种子方差本来就很大，5 种子平均可能主要在降方差而不是提均值。**
2. **B1 的因子化收益实质为零（+0.001）**，但论文没有进一步追问"那为什么还要因子化"。可解释性/校准方面也未验证（因子化可能改善了某类别的校准，但没有校准指标）。
3. **方言与不安全率高度相关（36.6% vs 71.7–91.3%）**，因子化有可能学成"方言 ⇒ 不安全"的捷径，**论文没有做捷径诊断**（比如跨方言置换测试）。
4. **依赖共享任务私有数据**，ArGuard 数据未完全公开，B1/B2 结果不可直接复现。
5. **序列长度 192** 对长 prompt 会截断（作者称"几乎不截断"，但没有截断率统计）。
6. **只测阿拉伯语**，多语言可迁移性未知。
7. **B2 无增强/无因子化**，与 B1 的对比因此**不是纯消融**——两个赛道的系统在三个维度上都不同（头、增强、种子数），无法归因。

## 六、复现指南

### 可复现部分
- **配方完全可搬**：JAIS-6.7B + 4-bit NF4 + LoRA(r16, α32) + last-token 线性头 + 类加权 CE + 分层 k 折，这些是通用做法。
- **AraSafe 的过滤流程可照抄**（长度阈值、方言标记词表过滤、跨 split 去重）——这套"外部安全数据怎么清洗才敢加进训练折"的纪律，比模型本身更可复用。
- **5 种子 softmax 平均**是零成本的，可直接加。

### 关键实现顺序（建议）
1. **先做 B1 消融的三格对照**（半天，纯复用现有训练脚本）：① 扁平多类头；② 因子化头（无补数据）；③ 因子化头（补最稀格）。**判据：如果 ② 明显差于 ①，说明我们的标签体系在最稀格子上是饿的——先把数据补上，再谈层级收益。**
2. **再按"最规范切片"拆报告**：把我们的评测集按"表达规范度"（书面化/口语化/暗示性）分三档，看 VULG-HINT-EDGE 是不是**集中在最规范那一档**。判据：如果与这篇同构（MSA 0.70 vs 方言 0.93），那我们的问题不是数据量，是**边界定义在规范表达上不可分**。
3. **最后加 5 种子平均并报方差**。

### 迁到我们业务的具体做法
- **层级标签不要默认"越细越好"**。这篇给出了反例：4 类因子化在长尾未补时 **−0.360**。我们做 L1–L4 递进 + L2_30 独立维度时，要先算每个格子的样本数，**任何一个格子低于阈值就先补数据再做联合头**。
- **"类加权 CE = 逆频率"直接可用**，且作者点明了它和 macro-F1 目标的对应关系——我们如果用 accuracy 或加权 F1 做模型选择，就和 macro-F1 目标不一致。
- **B2 的分层报告格式直接搬**：现在我们的评测大概率只报总体 macro-F1，而这篇证明**总体 0.79 可以掩盖一个切片 0.46**。**"最差类别"必须带切片，否则就是在平均里藏问题。**
- **Bully/harassment/harm-to-others 三者重叠 ⇒ PORN/VULG 边界**：这篇的处理是"承认它难，报告它，不额外做特殊处理"。**这条可以被我们用来反驳"再多训几轮就能解决边界混淆"的假设**——他们用了 6.7B + QLoRA + 类加权 + 5 种子，最好的类 0.98，重叠类 0.57，**差距不是训练量问题**。
- **不要照搬的**：单骨干双赛道（我们是多任务但任务不同）、192 的序列长度（我们 prompt 更长）。

---

**一句话判断**：这篇真正的贡献不是"两个赛道第一"，而是**那张三行消融表**——**标签因子化 +0.001，去掉长尾补数据 −0.360**。它给我们的层级标签工作划了一条硬线：**结构越细，长尾越致命；先把最稀格子喂饱，再谈层级收益**。而 B2 的分层表则证明：**最难的永远是最规范的那一档，聚合分永远会把它藏起来。**
