## 一、背景与问题

### 动机

这是一篇**方法学教程**，不提出新模型。它做了一件很朴素但很少有人系统做的事：**固定预测，只改指标的算法，看结论怎么变**。

十五个受控场景（S1–S15），每个只变一个因子，输入文件全部公开，**205 项校验全过（202 项独立、3 项内部）**。

### 为什么这对我们重要

我们的报表有三个数字：**误杀率 5.2% / 漏过率 3.42% / 一级一致率 77.64%**。这三个数都是"某种口径下的结果"。这篇论文的作用是：**把"口径"这个词拆成 11 个可独立拨动的旋钮**，并给出每个旋钮的实测位移量。

### 三条论断

1. **同一个模型在同一批数据上，"准确率"这个数字可以完全没有信息量**（全负规则在 1% 患病率下拿到 0.990）。
2. **同一组分数，阈值选法不同 → 代价差 1.7 倍，而 F1 与代价的方向相反**。
3. **聚合层级不同 → 0.691 / 0.700 / 0.857 三个答案**。

## 二、核心方法

### 2.1 22 个混淆矩阵指标的"患病率编码地图"

把 22 个指标按**是否依赖类别患病率**分成两组：**11 个患病率无关**（TPR、TNR 这类固定类内率的），**11 个患病率相关**（PPV、F1、accuracy、MCC、κ 这类）。

这个二分是全文的骨架：**患病率相关的指标，跨数据集不可比**。

### 2.2 十五个场景，四块

| 块 | 场景 | 拨动的旋钮 |
|---|---|---|
| **A 混淆矩阵** | S1 准确率悖论 / S2 患病率漂移 / S3 F1·MCC·正类定义 / S4 多类平均 / S8 κ 与边际分布 | 患病率、正类指定、平均规则 |
| **B 概率质量** | S5 低患病率下的 ROC vs PR / S6 阈值与错误代价 / S7 区分度与校准 | 阈值规则、代价比 |
| **C 回归** | S9 离群点 / S10 近零目标 / S11 负 R² | 误差分布、目标量级 |
| **D 聚合与推断** | S12 小测试集 / S13 聚合层级 / S14 反算 / S15 软件约定 | 样本量、聚合单位、库选项 |

从场景反推出来的最小报告集（Table 18），每条都绑定一个场景：

## 三、技术细节

### 3.1 患病率效应（S1、S2）

固定 TPR=0.800、TNR=0.900、总数 10,000：

| 患病率 | Precision | Accuracy | F1 | MCC | κ |
|---|---|---|---|---|---|
| 0.500 | **0.889** | 0.850 | 0.842 | 0.704 | 0.700 |
| 0.100 | — | — | — | — | — |
| **0.001** | **0.008** | **0.900** | **0.016** | **0.074** | **0.014** |

- **Precision 从 0.889 掉到 0.008（111 倍）**，而敏感度、特异度、balanced accuracy 一个字都没变（BA 恒为 0.850）。
- **Accuracy 反而上升**（0.850 → 0.900），因为大负类的特异度高于敏感度。
- **F1 掉到 0.016，MCC 掉到 0.074，κ 掉到 0.014**。

推论：**"模型 A 比模型 B 准"这句话，如果不带患病率，在跨类目比较里没有意义**。我们的 L2_30 叶子类目患病率差异可能是几个数量级。

### 3.2 全负规则（S1）

患病率 0.010 时，**"永远判负"这条规则拿到 accuracy 0.990、balanced accuracy 0.500**。

这是本仓库已经反复用的"退化策略体检"的原始版本：**任何指标上线前先算全 0 与全 1 两个退化策略**。

### 3.3 阈值规则对比（S6）——本文对我们最有用的一张表

同一组分数，五个阈值规则，**阈值都在验证集上选，然后在同等规模的测试集（各 2,000 例，患病率 0.10）上评**。代价按误负成本 = 20 × 误正成本：

| 选阈值的规则（验证集） | 阈值 | TPR | TNR | PPV | **F1** | **每千例代价** |
|---|---|---|---|---|---|---|
| 默认 0.5 | 0.500 | 0.500 | 0.820 | 0.940 | 0.603 | 414.0 |
| Youden | 0.415 | 0.890 | 0.902 | 0.503 | 0.643 | 308.0 |
| **最大 F1** | 0.568 | 0.780 | 0.963 | 0.700 | **0.738** | **473.5** |
| **TPR ≥ 0.95** | 0.280 | 0.950 | 0.807 | 0.353 | 0.515 | **274.0** |
| 最小代价 | 0.353 | 0.920 | 0.867 | 0.435 | 0.591 | 279.5 |

**四条读数，每一条都能直接改我们的阈值决策**：

1. **F1 最高的规则，代价最贵**（F1 0.738 ↔ 473.5）。F1 最差的规则，代价最低（F1 0.515 ↔ 274.0）。**两个指标在这批数据上方向相反。**
2. **同一组分数，测试集敏感度可以从 0.780 到 0.950**（跨 17 个点）——全部是"合理"的选法。
3. **验证集最优 ≠ 测试集最优**：验证集上"最小代价"的规则，在测试集上 279.5，**高于** `TPR≥0.95` 约束规则的 274.0。
4. **`TPR≥0.95` 这条约束规则，在测试集上恰好达到 0.950**（约束被满足），代价 PPV 只有 0.353。

第 4 条特别值得注意：**用"敏感度下限"当约束时，测试集表现稳定；用"最小化代价"当目标时，测试集不稳**。这直接支持"把误杀率当硬约束、漏过当目标"的取向——**约束比目标更可迁移**。

### 3.4 区分度与校准（S7）

三个概率变体，**ROC-AUC 全是 0.825**，但校准斜率分别是 **2.08 / 1.04 / 0.52**，排序与决策完全一致。

即：**AUC 相同不蕴含概率可用**。斜率 2.08 意味着概率系统性偏"平"（欠自信），0.52 意味着偏"尖"（过自信）。**如果我们用分数直接做"风险等级"输出（L1–L4），斜率偏差会直接把等级分布压歪。**

### 3.5 聚合层级（S13）——三个答案

10 个参与者、700 个 segment：

| 聚合口径 | 值 | 95% 区间 | 区间方法 |
|---|---|---|---|
| **池化 segment 级准确率** | **0.857** | 0.829–0.881 | 朴素 Wilson（把 segment 当独立） |
| 同上，正确方法 | 0.857 | **0.677–0.916** | cluster bootstrap |
| 每参与者平均准确率 | **0.691** | 0.556–0.825 | cluster bootstrap |
| **参与者多数投票准确率** | **0.700**（7/10） | **0.348–0.933** | 精确 Clopper–Pearson |

**同一批数据，三个数：0.691 / 0.700 / 0.857。**

而且**区间宽度差 3 倍**：朴素 Wilson 给 0.829–0.881（宽 5.2 点），cluster bootstrap 给 0.677–0.916（宽 23.9 点）——因为前者**错误地把同一参与者的重复 segment 当成独立样本**。

最后一行是杀伤力最大的一句：**10 个参与者的多数投票 7/10，精确区间 0.348–0.933，无法与随机区分**。

### 3.6 反算与软件约定（S14、S15）

- 八个已报告的三元组在五折反算下，**取整与聚合顺序会造成不一致**。
- 同一批输入，换库的 `zero_division` / `labels` 选项，结果会变。

## 四、实验与结果

本文没有"实验"，只有 15 个受控场景 + 205 项校验。所有数字都可从公开输入文件重算。**这是它最大的优点**：不是"我们发现指标会骗人"，而是"这是 15 个可复算的位移量"。

论文自己划的边界很清楚：**这些场景隔离机制，不估计机制在已发表研究中的发生频率**；文献审计与真实数据演示被列为"未来协议，未执行"。

---

## 五、局限性

1. **全部是合成场景**。位移量是真的，但"我们的数据上会位移多少"仍需自测。
2. **没有真实数据演示**（作者明确列为未做）。
3. **代价比只试了 20:1 一个值**。不同代价比会改变"最小代价"规则的位置。
4. **S13 的 10 个参与者是极小的样本**——这既是它的论点（小样本区间宽），也是它的弱点（结论本身区间很宽）。
5. **没有覆盖多标签、层级标签、序数标签**。我们的 L1–L4 是层级 + 序数，比本文的二/多类更复杂，**本文的阈值表不能直接搬，只能搬方法**。
6. **没有覆盖 conformal / 风险控制**。上一轮 StreamLTT 已经证明那块也有自己的坑（换检验救不了错的定义）。

## 六、复现指南

```
论文提供全部场景输入文件与校验脚本（205 项检查，202 独立 + 3 内部）
场景：S1–S15，每场景只变一个因子
```

**最小复现（对我们最有用，全部零训练）**

1. **把 S6 那张表在我们自己的类目上重跑一遍**。做法：取一个叶子类目的现有分数与标签，用五种规则各选一个阈值（验证集选、测试集评），报 TPR/TNR/PPV/F1/代价。判据：**如果 F1 最优点的代价明显高于约束最优点，则现有"按 F1 选阈值"的流程需要换掉**。
2. **给每个类目补一行患病率**。判据：两个类目 F1 差 0.1，若患病率差 10 倍以上，这个差**不能归因于模型**。
3. **测一次聚合层级差**。我们的图生图评测集 2000 条（1979 有效）里，同一条 prompt 的多张图是"segment"、每条 prompt 是"participant"。**按图池化 vs 按 prompt 平均 vs 按 prompt 多数**，三个数会不一样。判据：若三者差 >5 点，则历史版本对比全部需要标口径。
4. **区间方法必须换**。同一 prompt 的多张图不独立，**朴素 Wilson 会把区间算窄 3 倍**——这会让我们把"没变化"看成"有变化"。

## 附：与业务的三条硬对应

1. **"误杀 5.2% / 漏过 3.42%"这两个数必须带三个附注**：① 每个类目的患病率（不同叶子类目差几个数量级，F1 不可跨类目比）；② 阈值是用什么规则选出来的（默认/Youden/最大 F1/约束/最小代价，五种）；③ 数据划分（验证集选的阈值在测试集上会漂，本文实测最小代价规则从"最优"漂成"次优"）。

2. **"用约束而不是用目标"被本文实测支持**。`TPR≥0.95` 这条约束规则在测试集上**恰好达标**（0.950），而"最小化代价"这条目标规则在测试集上反而更贵（279.5 > 274.0）。对应我们的取向：**把误杀率写成硬约束（≤5.2%），在约束内最小化漏过——这比"最小化加权代价"更可迁移**，因为约束在换数据集时仍然成立，目标函数的最优点会漂。

3. **序数校准（L1–L4）最大的风险不是排序，是斜率**。三个变体 AUC 全 0.825 而校准斜率 2.08 / 1.04 / 0.52。我们输出的是**等级**不是二分类，等级分布直接由斜率决定：斜率 2.08 会把大量样本压到中间档（欠自信），0.52 会把样本推到两端（过自信）。**所以"一级一致率 77.64%"必须与"等级分布"一起报**——一致率相同、等级分布不同，是两个完全不同的系统。
