# 越"客观"的判定，越经不起换一种说法

**论文主页**: https://arxiv.org/abs/2610.38076
**领域**: LLM-as-a-Judge 稳定性 / 释义不变性 / 评测仪器校准 / 多版本排序
**作者**: Ilija Subasic, Brett Levert, Andrew Rabinovich, Sajjad Pakdamansavoji, Zhao Chen（Upwork Inc）
**机构**: **Upwork Inc**（工业界）
**发布日期**: 2026-10-27（v1，cs.CL，55 页，CC BY 4.0）
**分类**: evaluation / benchmark
**模态归属**: T2T 迁移 — 评测仪器稳定性 · AB 看板口径 · 语义保真度量效度

## 一、背景与问题

### 动机

LLM-as-a-Judge 已经是评测的事实标准。它有一个几乎从不被检验的前提：

> **一份 judge prompt 是一台稳定的仪器。**

学界过去的努力都在"怎么把 judge 调得更准"——改评分细则、加角色描述、加 CoT、做多 agent 聚合。这些都是**有意的修改**，目的是提升准确率。

这篇问的是另一个问题，而且是更基础的那个：

> **两份经过人工验证、被确认"语义等价"的 judge prompt，会不会给出不同的判定？**

它把这个现象命名为 **Prompt Lottery（提示词彩票）**：*"prompt reformulations intended to preserve semantic content produce different LLMaJ judgments."*

### 我们为什么必须看这篇

因为我们有整整两条业务线压在这个前提上。

**① 本地 AB 评测看板（文生图图审 / 图生图改写）。** 看板上每个模型版本都对应一份 judge prompt。如果 judge prompt 的措辞本身就能翻排序，那"v6 比 v5 好 2 个点"这句话的性质就变了——它可能不是模型变好了，是这次抽到的 prompt 更好。

**② 三维评测里的"语义保真"。** 我们用一个度量来判断改写有没有改掉原意。这篇的结论是：**语义相似度高（sBERT 0.44–0.49）与判定一致性（κ 0.0–0.7）之间，相关性是 0.157，不显著。** 也就是说，**"语义保真"这个指标本身不保证任何东西。**

还有第三个，最刺人的：它发现**越"客观"的任务，排序越不稳**（后面有表）。

### 核心问题

1. 释义级改写会让 judge 的判定一致性掉多少？
2. 掉的这一截，会不会真的把模型排序翻过来？
3. 有没有低成本的补救？

## 二、核心方法

### （1）严格隔离"释义方差"

设计上最讲究的一点：**只改表面实现，不改任务语义**。

- 用 **Claude 3 Opus** 生成 **4 个释义变体**；
- 人工审核这些变体是否保住了原任务意图；
- 再用 **Gemini 1.5 Pro** 校验语法有效性；
- 事后归纳出 **6 个表面变异维度**（角色设定、指令句法、情境化、输出规格等），并做族内置换检验。

这一步的意义是：**它排除"改坏了"这个解释。** 如果变体真的等价，那判定差异只能归因于 judge 对表面形式的敏感。

### （2）三层基线（这个方法必须抄）

要证明"释义导致不稳"，得先证明"不释义就稳"。论文设了三条基线，从松到紧：

| 基线 | 定义 | 数值 |
|---|---|---|
| **① 稳定性基线**（同 prompt 跑 5 次） | 抽掉浮点/采样噪声后的天花板 | 重叠 **89.8%**，Cohen's κ / Fleiss' κ 达 **almost perfect** |
| **② 人类基线**（10 名标注员） | 人在同类任务上的方差 | 退化 **0.09–0.11** κ |
| **③ 学术可接受线** | usability 研究的通行阈值 | κ ≈ 0.67 量级 |

**没有 ①，你无法区分"judge 不稳"和"服务本身有随机性"。** 这一层是我们看板里完全没有的。

### （3）四个一致性指标

`Overlap`（完全相同判定的比例）、平均成对 `Cohen's κ`、`Fleiss' κ`、`Krippendorff's α`（跨全部释义）。

论文主用 κ，但同时报其余三个做交叉验证——这避免了"换一个指标结论就变"的老问题。

### （4）六个变异维度的置换检验

不是笼统说"措辞会变结论"，而是把变异拆成 6 个可分离的维度，做族内置换检验，看哪个维度贡献最大。这让结论从"措辞很重要"变成"**哪一类措辞最重要**"。

## 三、技术细节

### 规模

| 项目 | 数值 |
|---|---|
| 实验条件 | **845** 个 |
| 数据集 | **12** 个 |
| prompt 族 | **5** 个（每族 5 个变体：1 默认 + 4 释义） |
| 判定模型 | Kimi-K2.5、GPT-oss-120B、GPT-4o、Llama 3.3、Qwen3-VL |
| 人类研究 | **10** 名标注员 |
| 排序实验 | 4 个推理模型 × 5 个释义变体 × 100 样本/任务 × 3 折 |
| 释义生成 | Claude 3 Opus（生成）+ 人工审（语义）+ Gemini 1.5 Pro（语法） |

### 任务类型覆盖

客观题（QA correctness / groundedness）、主观对话（MTBench Daily / Persona）、摘要质量（SummEval）、开放生成（Topical-Chat / LLM-Arena）、语义对齐（UPHELD）。

### 聚合策略对照

`Average` / `Majority`（众数）/ `Plurality`（要求 κ≥ 阈值的共识）/ `Plurality+Avg`（未达共识时退回平均）。

外加一个**选择性聚合**方案：训一个小分类器（DeBERTa / RoBERTa / 逻辑回归 / SVM）判断"这条样本在多个 prompt 下会不会一致"，只对不一致的样本跑多 prompt。

## 四、实验与结果

### （1）一致性从"几乎完美"掉到"勉强可接受"

> **κ: 0.89 → 0.24**

论文原文：*"the agreement degraded from near-perfect (stability and human baseline) to fair (κ: 0.89 → 0.24), a drop substantially larger than the 0.09–0.11 degradation we observe in the human studies."*

换算一下：**judge 在释义下的一致性退化，是人类在同类任务上的 6–9 倍。** 原文的表述是 *"6-9× larger agreement degradation under prompt rephrasings than humans, falling below the generally accepted threshold in usability studies."*

另外两个数：

- **75% 的"数据集 × judge"组合**出现了显著差异；
- 除 2 个组合（NQ-Open Correct、SQuAD Correct）外，**所有组合的平均一致性都低于"可接受的标注研究"阈值**；即使是表现最好的 Krippendorff's α，也远低于人类基线与理论基线。

### （2）**反直觉的核心发现：越客观越不稳**

这是全文最该被记住的一张表。

| 任务 | 类型 | Kendall's τ | Top-1 翻转次数 | 翻转率 |
|---|---|---|---|---|
| MTBench（DailyDial） | 主观对话 | **1.00** | 0/4 | **0.0%** |
| MTBench（Persona） | 主观对话 | 0.80 | 2/4 | 10.0% |
| G-Eval（Topical-Chat） | 开放生成 | 0.83 | 1/4 | 10.0% |
| Quality（SummEval） | 摘要质量 | 0.64 | 2/4 | **40.0%** |
| **QA Correct.（SQuAD v2）** | **客观二元** | **0.17** | 3/4 | **43.3%** |

**最"客观"的 SQuAD v2 二元判定，排序翻转率最高（43.3%，τ 只有 0.17）；最"主观"的日常对话评测，翻转率是 0。**

具体到模型：SQuAD v2 上 GPT-4o 的名次在 1–3 之间漂，Qwen3p6-Plus 在 1–4 之间漂。**"哪个模型最好"这个结论取决于用哪份措辞。**

**为什么会这样？** 论文给了两个机制：

**① Binary Paradox。** 二元任务原始重叠率高（0.32 vs 非二元 0.14），但那是因为**输出空间窄，猜中概率高**；机会校正后的 Fleiss' κ 反而**更低**。原文：*"the output space constraint masks underlying instability rather than indicating true robustness."*

**② 客观任务的判据更"紧"，措辞的一个词就能改变边界。** 主观任务（"这段对话是否易懂"）有大量容忍空间，措辞变了结论还是那个；二元任务（"答案对不对"）只差一个词，边界就移了。

**对我们的直接含义，这条必须讲清楚：**

我们的安全判定是**典型的二元客观判定**（PORN 是/否、VULG 是/否）。按这个结果，**我们的 judge prompt 恰恰属于翻转率最高（40%+）的那一类**，而不是"客观所以稳"的那一类。

我们现在的 AB 看板，每个模型版本配一份 judge system prompt。**如果那几份 prompt 之间存在措辞差异（哪怕都是"我们自己写的、语义一样的"），那版本间的 2–3 个点差异，很可能落在措辞引起的方差里。**

### （3）语义相似度高，判定照样不一致

这是第二记重击：

> *"we observe sBERT similarities of 0.44–0.49 yet agreement (κ) ranges from 0.0 to 0.7"*
>
> 语义相似度与判定稳定性的相关：**Pearson ρ = 0.157（p = 0.022，弱），Spearman ρ = −0.022**

也就是说：**"这两份 prompt 语义几乎一样"完全不能推出"它们会给出一样的判定"。** 甚至 Spearman 是**负的**。

**对我们的直接含义：**

我们的"语义保真"度量（embedding 相似度、BLEU、LLM 打分）测的是**文本空间的距离**。这篇证明：**文本空间靠近，不代表行为空间靠近。**

而今天另一篇（ERASE）给的 `I` 度量，恰好是行为空间的：`KL(P(·|视图A) ‖ P(·|视图B))`。**两者不是同一个东西，而我们需要的是后者。**

### （4）聚合能救，但要选对聚合方式

与人工标注的 Pearson 相关（三个有人工标注的数据集）：

| 数据集 | Majority | Average | **Plurality** | Plur.+Avg |
|---|---|---|---|---|
| Upheld | 0.47 | 0.54 | **0.63** | 0.61 |
| Topical-Chat | 0.44 | 0.55 | **0.62** | 0.51 |
| LLM-Arena | 0.44 | 0.54 | **0.55** | 0.52 |

**Plurality（要求达到共识阈值，否则丢弃）三战全胜，且显著优于众数与平均。**

这个结论的方法论含义：**"达不到共识的样本应该被丢掉，而不是被平均掉。"** 平均会把一份"其实没共识"的判定硬压成一个数——这正是我们 10-30 那轮总结的失效机制。

### （5）选择性聚合：86% 的稳健性，60% 的成本削减

| 策略 | 算力倍数 | 达成稳健性 | 最差情况 |
|---|---|---|---|
| 单 prompt | 1× | 44% | — |
| 任务启发式 | 4.5× | 74% | 69% |
| **DeBERTa-gate** | **2×** | **86%** | 65% |
| 全聚合 | 5× | 100% | 79% |

**用一个小分类器（DeBERTa，平衡准确率 0.836，TNR 0.854）判断"要不要多跑几个 prompt"，2 倍算力拿到 86% 的稳健性。** 泛化到训练时没见过的 Prometheus 系 judge 上，TNR 仍有 66.22%。

一个反面数据：**Llama 3.1 8B 做门控时零样本平衡准确率只有 0.489、TNR 0.042**——基本没用。**小而专 > 大而泛**，这条和 10-28 我们记的"路由不需要大模型"是同一结论。

## 五、局限性

### 论文自述的

1. **释义变体由 LLM 生成**（Claude 3 Opus），4 个变体不能覆盖全部表面变异空间。
2. **人工审核只验证"是否保义"**，没验证"变体质量是否对称"。
3. **12 个数据集偏英文/通用任务**，没有安全/内容审核类任务。**这一点对我们最关键——它没测我们这类任务。**
4. **排序实验每个任务只 100 样本 × 3 折**，翻转率的置信区间较宽。
5. **它没说 judge 一定不可用**，说的是"单 prompt 评测不足以做模型排序"。这两句差别很大，引用时不能混。

### 我们引用时必须守住的边界

**① 它测的不是安全判定。** 12 个数据集里没有内容审核。所以"PORN 判定翻转率 43%"是我们的**推断**，不是它的测量。必须标为推断，并用我们自己的数据去验（见第六节）。

**② 它的"客观更不稳"结论有条件。** SQuAD v2 的特殊性在于：答案对错**只有一个词的位置**能决定，且模型间差距小（4 个模型挤在一起，τ 天然低）。我们的 PORN 判定类间差距可能大得多。**结论方向可信，量级不可直接照搬。**

**③ 它给的是"多 prompt 聚合"，不是"换更好的 prompt"。** 论文自己说：*"no single prompt variant consistently outperforms others across datasets"*，默认 prompt 的排名在 bootstrap 重采样里只有 **5–24%** 的情形是第一。**所以正确的动作是"别只用一个"，不是"找一个更好的"。**

## 六、复现指南

### 最小可跑版本（半天，零训练，直接打我们的看板）

**目标：量出我们自己 judge prompt 的"彩票方差"。**

1. **取现成的 judge system prompt**（图审那份或改写那份）。
2. **造 4 个释义变体**：自己写，或让强模型改，要求**只动表面**（换句式、换角色描述、换输出格式说明），**不动判据**。人工确认 5 份语义一致。
3. **同一批样本**（建议 300 条，覆盖 PORN 明确 / VULG 边界 / 干净三类），**5 份 prompt 各跑一遍**。
4. **算三个数**：
   - `Overlap`（5 份完全同判的比例）
   - `Fleiss' κ`（跨 5 份）
   - **`Top-1 翻转率`**（如果有 ≥3 个模型版本要排，就用这 5 份 prompt 各排一次，看第一名变几次）
5. **判据表**：

| 观察 | 判定 | 动作 |
|---|---|---|
| Fleiss' κ **≥ 0.8** | prompt 是稳定仪器 | 现有 AB 结论可用；只需在报告里附上这个数作为证据 |
| κ **0.6–0.8** | 轻度不稳 | 版本差异 < 3 点时不宣称优劣；加多 prompt 平均 |
| κ **< 0.6** | **仪器不可用** | **所有历史 AB 排名作废**，先修仪器再做模型对比 |
| **Top-1 翻转 ≥ 1 次** | 排序结论不稳 | 必须在看板上加"排名置信区间"，不能只报点估计 |

6. **再做一件事：测"语义保真"与"判定稳定"的关系**。对同一批改写对，同时算 ① embedding 相似度 ② 判定翻转率，看两者相关性。若相关性接近 0（论文是 0.157 / Spearman −0.022），说明**我们的语义保真指标对稳定性零信息量**，需要换。

### 实现坑

| 坑 | 处理 |
|---|---|
| 没有"同 prompt 跑 5 次"的稳定性基线 | 必须先做（论文：89.8% 重叠）。没有它，测出来的差异无法归因 |
| 变体改动了判据 | 那就不是释义方差，是任务方差，白测 |
| 只用 κ 一个指标 | 至少加 Overlap；二元任务上 κ 会被输出空间窄化掩盖 |
| 二元任务上直接看原始重叠率 | 会被 Binary Paradox 骗（重叠 0.32 > 非二元 0.14，但机会校正后更差） |
| 用平均聚合 | 论文：Plurality 三战全胜，Average 全输 |
| 用大模型做"要不要多跑"的门控 | Llama 8B 零样本 TNR 只有 0.042；用小的专训分类器（DeBERTa TNR 0.854） |

### 一句话带走

**在问"模型 v6 是不是比 v5 好"之前，先问"我的尺子换一种说法还准不准"。这篇的答案是：大概率不准，而且越是你以为客观的二元判定，越不准。**
