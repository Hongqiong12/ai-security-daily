## 一、背景与问题

### 动机：一个「unsafe」标签同时承担了两件事

现有 guard model 把每个用户 turn 打成「安全 / 不安全」，然后**下游处置直接绑在这个标签上**。作者指出这在心理健康语境里会崩：讲述「亲戚过去的伤害经历」与「我正要服药」被压成同一个 flag；**过去/第三方/正在进行/未来**的临床语境完全不同，却无法区分何时、该做哪种干预。

更关键的一句：**「因为『行动与否的边界』被绑在标签上，换一套临床策略就要重新标注数据 + 重新训练」**——这正是本项目「策略热更新 / 规则-策略分层 / 风险知识库与干预策略库注入」要解的工程问题。

### 与本仓库主线的关系（五重命中，`t14_policy_guard` 六周零供给后的首次实质供给）

1. **策略可配置护栏**：把 **harm characterization（what/who/when 三元组）与 intervention decision 分离**，策略以「临床医生策展的显式指令」写在**模型权重之外**，可编辑、可审计、无需重标注或重训 ⇒ 直接对齐 11-16 安全指令库评审与 SafePyramid 类「in-context policy guardrailing / configurable guardrail policy」。
2. **层级标签 / CoT tag-first / tag-weighted**：三轴 triplet + 分维加权评分 `3WS = λ_what·1[what] + λ_who·(src,tgt) + λ_when·c(·)`（what/who 高权、when 低权），与项目「L1-L4 递进、L2_30 层级口径、CoT tag-first、tag-weighted loss」几乎逐项对应。
3. **误杀率是硬约束 / 用户侧误伤体感**：原文明确「over-flagging 会触发不必要干预、打断对话、破坏信任、把用户赶走」——这是**「假安全」拒答体感**的学术表述；模型专门报告 **高 recall 下低 FPR**。
4. **规则-策略分层 / 召回降级**：可配置决策树把预测 triplet 映射到 safety protocol，可按司法辖区与演化的临床需求适配；与「词库 + 向量库混合召回、指令排序、命中优先级、降级兜底到拒答」同构。
5. **推理加速不劣化 / 短输出**：SFT on short reasoning rollouts + RL with **reasoning-length penalty**，把长 CoT 压成短输出，报告 **~10× 更低 median latency**（对齐 max_tokens 极小、TTFT/e2e 硬指标、`<reasoning>` stop 序列治理）。

## 二、核心方法

### 2.1 3W harm taxonomy（本文最可迁移的部分）

| 轴 | 内容 | 对项目的翻译 |
|---|---|---|
| **what** | 伤害的性质/类型 | 一级类目（PORN / VULG / 政治…） |
| **who** | 来源 → 目标（src, tgt）；自伤是「用户既是源又是目标」的一个配置，**不是单独类目** | 细粒度边界（PORN/VULG 混淆、主体/关系） |
| **when** | 时间阶段：过去 / 进行中 / 未来（区分 past/ongoing harm 与 future risk） | L1-L4 严重度 / ordinal 等级口径 |
| 先分 safe/unsafe | 情绪不适、宣泄、比喻性语言判**安全** | 中性 prompt 不误杀 |

**关键架构决定**：模型只输出 triplet，**不输出处置动作**；`triplet → safety protocol` 的映射是**可配置的、可能由临床医生策展的决策树**（Fig.1/§2）。⇒ 换策略 = 换映射表，**不动权重、不动数据、不动标注**。

### 2.2 分维加权评分 3WS

单一「triplet 完全匹配」太粗（一个维度不符就算全错）。作者给**部分匹配分**：`s(p,g) = λ_what·1[p_what=g_what] + λ_who·½(1[src]+1[tgt]) + λ_when·c(p_when,g_when)`，其中 `c` 对时间相邻类别给 0.5、完全匹配给 1。**权重可按业务重要性调**（what/who 高、when 低且更模糊）⇒ 与 tag-weighted loss / 类别加权训练同构。

### 2.3 MindGuard2 训练配方

- 底座 Qwen3.6-35B-A3B；**SFT on short reasoning rollouts → RL with reasoning-length penalty**（作者观察到 RL 会 steadily 拉长推理长度，故加罚）；
- 标签规模化：5 个开源 judge 组 panel 出 gold、teacher 出训练标签，**teacher 被排除在 panel 外**（模型永远不对着自己的监督被评测）；
- 另发布一个**纯合成数据训练版**，性能可比。

## 三、技术细节

### 3.1 数据（Table 1）

| 集 | 标注 | Turns | Unsafe % | Triplets | 公开 |
|---|---|---|---|---|---|
| RiskGov | judge panel + 临床医生 | 4,660 | 31.5 | 1,503 | ✓ |
| RealMHS | judge panel + 临床医生 | 8,896 | **5.5** | 572 | × |

真实场景 unsafe 患病率仅 5.5% ⇒ **低患病率下的 FPR 控制**是主要矛盾，与本项目误杀率 5.2% / 漏过率 3.42% 的运营约束同量级。

### 3.2 标注一致性（Table 2）

- safe/unsafe 判定的 **Fleiss' κ = 0.70**（RiskGov）/ 0.73（RealMHS），95% CI [0.57,0.77] / [0.59,0.86]；
- 两名标注者都判 unsafe 时，**what/who 两轴一致率 >89%**，但 **when 轴在 RealMHS 只有 0.53**（时间判断更模糊）⇒ **层级越细、越靠序数/语境的轴，人工一致率越低**，直接支持「when 给低权」与「L2_30 需单列人工一致率」。

### 3.3 主结果（Table 15 消融，Qwen3.6-35B-A3B 起）

| 变体 | BA(左) | R | FPR | 3W | Consist. | ECE | p50/p90 延迟 |
|---|---|---|---|---|---|---|---|
| Base | 0.81 | 0.78 | 0.16 | 0.72 | 0.887 | 0.110 | 2.80 / 6.78 |
| + SFT | 0.87 | 0.83 | **0.08** | 0.75 | 0.932 | 0.031 | — |
| **+ SFT → RL** | **0.91** | **0.95** | 0.13 | **0.90** | 0.974 | 0.056 | — |
| + SFT(w/o reasoning) | 0.88 | 0.88 | 0.12 | 0.80 | — | — | **0.26 / 0.40 s** |
| **+ SFT → RL（带 reasoning）** | **0.91** | **0.95** | 0.13 | 0.90 | — | — | **0.58 / 1.68 s** |

**推理的收益体现在 triplet 描述（3W 0.72→0.90）而非二分类（BA 0.81→0.91）**，且非推理模型更快（0.25s vs 0.58s median）⇒ **细粒度标签才需要推理，二分类不需要** —— 这直接支持「CoT tag-first 只对细粒度层开」。

### 3.4 效果与效率

- **balanced accuracy 与 GLM-5.3 相当，median latency 约低 10×**；
- 发布版（纯合成数据）Table 12：BA **0.91 / 0.91 / 0.92**，R 0.92/0.84/0.87，**FPR 0.09 / 0.02 / 0.03** ⇒ **高 recall 下低误杀**；
- 第三方五个安全数据集零样本泛化：五个都优于底座 BA 与 F1，主要来自 recall 提升、precision 略降（Table 14）；
- **置信度分箱**（Fig.12）：base 模型在 ≥0.94 置信区间实际正确率明显不足 ⇒ 「stated confidence」本身要先校准，与同日 `2611.33307` 的 over-confidence 结论**独立同向**。

## 四、实验与结果小结

| 结论 | 读数 |
|---|---|
| 策略与权重解耦可行 | 换临床策略只需改 triplet→protocol 映射，**无需重标注/重训** |
| 细粒度三轴可标注 | what/who >89% 一致，when 0.53（低权有依据） |
| 高 recall 低 FPR 可达 | 发布版 FPR 0.02–0.09，R 0.84–0.92 |
| 短 CoT + 长度惩罚有效 | RL 后 p50 0.58s，比大模型低 ~10× |
| 推理收益集中在细粒度 | 3W +0.18 而 BA +0.10 |
| 合成数据可替代 | 纯合成版 BA 0.91/0.91/0.92 可比 |

## 五、局限性与迁移边界

- **领域是心理健康文本**，非 NSFW / 政治 / 图像；PORN/VULG 边界与 L2_30 政治层级口径需自建映射表，不能直接搬标签。
- **策略可配置 ≠ 策略召回已实现**：本文给的是「映射表可编辑」，**没有词库 + 向量库混合召回、超时、拼接失败、命中优先级**等工程链路 ⇒ 项目侧仍需自建（A3）。
- **triplet→protocol 的映射由人策展**，若策略库与模型输出不同步会产生「旧策略判新 triplet」的静默错配，本文未给版本治理与降级事件规范。
- **无跨语言**（when 轴一致率已在单语内只有 0.53，跨语言预计更低）；**无 I2I / 图审 / 生成过程干预**。
- **延迟是 median 相对值**，未报 TTFT / e2e 绝对值 / TPOT / 超时率 / fp8-fp4 / 跨硬件 / serving setup 指纹。
- **可迁的是架构，不是量级**：κ、BA、FPR 都属该领域；可迁的是「**判定输出结构化描述、处置走权重外可编辑映射、分维加权评分、细粒度才开 CoT、按误杀体感调 operating point**」五条。

## 六、复现指南

1. **策略护栏最小实现（零训练，半天）**：把现网「类目 → 处置」硬编码拆成两段——① 分类器只输出结构化描述（`一级类目 / 主体-关系 / 严重度档`，对应 what/who/when）；② 一张**可热更新的映射表**把描述映射到「放行 / 改写 / 拒答 / 转人工」。验收：换一张策略表**不重训、不重标注**，且能回滚到上一版。
2. **分维加权 + 一致性体检**：对 `L1 × L2_30 × 严重度` 逐格报人工一致率（κ）；**一致率 <70% 的轴降权**（when 轴 0.53 的教训），并把该格列为「先修定义，不可单独调阈值」。
3. **误杀体感对照**：报高 recall 下的 FPR、不必要干预率、申诉回捞率；`误杀 ≤5.2%` 与 `漏过 ≤3.42%` 双约束下比较，只报单侧改善的不进看板；「假安全拒答」单列一类。
4. **CoT 只在细粒度层开**：二分类/一级类目走短输出（对齐 max_tokens 极小、`<reasoning>` stop、TTFT/e2e 硬指标），细粒度 triplet 才允许短 CoT，并配 reasoning-length penalty 与超时降级到拒答。
5. **召回侧工程留痕**：词库 + 向量库独立建表；指令 ≤3 条直拼、>3 条按相似度与阈值距离排序取 top3；命中优先级 敏感词匹配 > 向量库；词库与相似度服务显式配置超时；**拼接失败 / 召回超时 / 服务不可用三条降级路径各自留事件**（失败原因 + 版本 + 规则指纹）。补 TIDE Theorem 3：弱命中部件保留，不要只取 top-1。
6. **版本治理**：换策略表、换检测器、换评分协议、换评测集都登记为 calibration 事件；灰度 shadow → canary → 全量每步冻结同一评测单位与配置指纹，只换流量比例。

---

**对本项目的落点（一句话）**：**「判有害」与「怎么处置」必须是两层**——模型只输出结构化风险描述，干预走权重外可热更新、可审计的映射表；这是连续六周 `t14_policy_guard` 零可迁移之后**第一次有公开工作把「策略热更新 + 层级标签 + 误杀体感 + 短 CoT 延迟」做进同一个框架**，可直接当 A3「风险知识召回降级兜底」与 D1「tag-weighted 分层标签」的参考实现。
