# 批处理让 11–22% 的判定翻转，而 AUROC 只动 0.03：聚合指标看不见个体翻转

**领域**: LLM-as-judge 的批处理效应 / 判定可分离性 / 方差分解 / 判定器 AB 评测协议

**发布日期**: 2026-10-29（v1，cs.CL）
**分类**: benchmark
**模态归属**: T2T 判定器方法学 —— **直接迁移到图审双模型 AB 对比评测与三维评测的聚合口径**

## 一、背景与问题

### 动机

用一个语言模型给大量条目打分/分级/审核时，最常见的省钱办法是 **in-context batching**：把很多条目塞进一个 prompt，模型返回一个 JSON，每条一个判定。

这个做法被广泛推荐。论文引了两处依据：

- 厂商明确推荐用于"不需要实时的审核"（引 Anthropic 2026a）；
- 一项社会科学标注研究发现 **batch 25–100 条、每 prompt 最多 10 个编码变量，对多数当前模型是安全的：省 80%+ token 成本，损失不到 2 点准确率**（Pipal et al., 2026）。

### 被默认但从未被检验的假设

批处理建立在一个很少被明说的假设上：

> **一条条目的判定只取决于该条目本身，不取决于它的"同侪"（prompt 里的其它条目），也不取决于它在其中的位置。**

论文把它形式化成 **separability（可分离性）**。

**decoder-only 模型在结构上不保证这件事。** 论文的表述很直白：

> 当模型写第 12 条的判定时，它已经读过另外 24 条，以及自己刚写下的 11 条判定。

### 三个致命细节

**细节一：准确率是个糟糕的检验。**

> **有的偏移会把某些条目推高、某些推低，聚合分数几乎不变。**

这就是本文的核心杀伤力所在——**用聚合指标去检验"个体判定稳不稳"，在原理上就是错的。**

**细节二：翻转的置信度很高。**

论文 Figure 1 的例子：一条 SciEntsBank 的简答题（人类判"对"），Qwen3-4B 判：

| 条件 | 判定 | 置信度 |
|---|---|---|
| 单独判 | correct | 0.97 |
| 单独判，**重命名 key** | correct | 1.00 |
| 随机批 A，第 14/25 位 | **partial** | **1.00** |
| 批 A，重命名 key | partial | 1.00 |
| 批 A，**改写指令** | partial | 1.00 |
| 随机批 B，第 15/25 位 | **partial** | 0.85 |
| 随机批 C，第 8/25 位 | **correct** | 1.00 |

⇒ **改 key、改指令都不动，换一个 batch 就变。而且每次都高置信。** 这说明翻转不是"模型不确定"，是"模型很确定地给出了另一个答案"。

**细节三：这是纯结构问题，不是提示词问题。**

⇒ 我们调 prompt 调不出来。

### 为什么这篇对我们的图审 AB 是致命的

我们的旁路图审 AB 是"两个模型，同一批图，比谁判得准"。为了省成本，很可能**一次塞多张图**。

如果塞了，那本文的结论直接适用：

- **11–22% 的判定会随 batch 组成翻转**；
- 而 **AUROC 相对单条判只差 −0.033 ~ +0.010**；
- **两个模型的 AB 差异如果小于 11 个点，就完全可能是 batch 组成造成的**。

⇒ **我们过去所有批处理做的 AB 结论，都需要重新体检。**

## 二、核心方法

### （1）形式化：可分离性

**任务**：n 个条目，一个序数量表，一个判定阈值 τ。

**划分（partition）**：把条目分配到 k 条目的 prompt 里。

**条目 i 的上下文** `c = (s, N, ω)`：

| 符号 | 含义 |
|---|---|
| **s** | 它在 prompt 里的**槽位**（slot），文本跟在 key `cs:` 后面 |
| **N** | 它的**同侪集合**（membership），另外 k−1 条 |
| **ω** | 同侪出现的**顺序**（order） |

模型从左到右贪心解码写出一个 JSON，每条一个等级。

**定义 1（可分离）**：对所有条目 i 与其所有可能的上下文 c, c′，若 `Y_i(c) = Y_i(c′)`，则判定可分离。

这个定义**同时排除了"同侪干扰"和"自己槽位的影响"**。随机划分随机化了上下文。

### （2)生成过程与两个通道

```
p_θ(y|x) = ∏_{t=0}^{k-1} p_θ(y_t | x, y_<t)
```

槽位 t 的因子**可以**依赖：
- 其它槽位的文本 `x_{-t}` ⇒ **text channel（文本通道）**
- 它之前写下的判定 `y_<t>` ⇒ **verdict channel（判定通道）**

⇒ **两个通道都能起作用，后面用干预实验分别量化了。**

### （3）翻转率的精确分解

**命题 1**：两个独立随机划分给条目 i 不同判定的概率是 `2p_i(1-p_i)`。期望翻转率 `F_new = (2/n) Σ p_i(1-p_i)`，且 **`F_new = 0` 当且仅当判定可分离**。

⇒ 这是"翻转率"作为可分离性检验的合法性来源。

**命题 2（方差分解）**：设 `G(R) = ½𝔼(f(C) - f(C^(R)))²`（对判定 f 而言，G 是翻转概率的一半）。定义：

| 符号 | 含义 |
|---|---|
| `V_s = Var 𝔼[f \| s]` | **槽位**主效应 |
| `V_N = Var 𝔼[f \| N]` | **同侪集合**主效应 |
| `V_sN` | 槽位 × 同侪的交互 |
| `T_ω = 𝔼 Var(f \| s,N)` | **顺序**效应 |

则：

```
G({ω})      = T_ω
G({s,ω})    = T_ω + V_s + V_sN
G({N,ω})    = T_ω + V_N + V_sN
G({s,N,ω})  = T_ω + V_s + V_N + V_sN
```

这是 **Hoeffding(1948) / Sobol'(2001) 的方差分解**，用"重抽一个子集输入"作为它的标准估计量。

**四种实验条件**（相对基础划分 redraw 了哪些因子）：

| 条件 | ω | s | N |
|---|---|---|---|
| 保持槽位、重排其它 | ✓ | | |
| 重排整个 batch | ✓ | ✓ | |
| 保持槽位、换新同侪 | ✓ | | ✓ |
| **新的随机划分** | ✓ | ✓ | ✓ |

于是可以解出：
- 同侪主效应 `V_N = G_new − G_resh`
- 槽位主效应 `V_s = G_new − G_comp`
- 顺序 `T_ω = G_keep`

**关键的性质：没有任何分量可以是负数。** 这是估计量正确性的一个硬约束（论文说估计必须复现这一点，误差只在采样层面）。

### （4）潜在量表：把一个"依赖题目难度"的指标变成可比的

翻转率取决于**多少条目落在阈值附近**。为了跨条件、跨任务可比，论文用**阈值模型**：

**假设 1**：判定 = 潜在分数过阈值，`d_i(c) = 𝟙[z_i(c) > h]`；一个条目在两个上下文里的分数**二元正态、标准边际**。

令 ρ 为两次判定的相关系数（即两个判定的 **tetrachoric correlation**），**潜在不相似度 `D = 1 − ρ`**。

**命题 3**：两个判定不同的概率是

```
Ψ(h, ρ) = (1/π) ∫_ρ^1  e^{-h²/(1+r)} / √(1-r²)  dr
```

有双侧界：
```
(arccos ρ / π)·e^{-h²/(1+ρ)}  ≤  Ψ(h,ρ)  ≤  (arccos ρ / π)·e^{-h²/2}
```
且当 `D → 0` 时 `Ψ ≈ (√(2D)/π)·e^{-h²/2}`。

**这一条给出了全文最重要的直觉：**

> **翻转率随"上下文贡献的方差"的平方根增长。**

论文给的标定：

| 潜在方差占比 | 翻转的判定比例 |
|---|---|
| **1%** | **4.5%** |
| **10%** | **14.4%** |

⇒ **在分数尺度上很小的变化，在判定尺度上是大的。** 这就是"AUROC 几乎不动但 11–22% 判定翻转"的数学根源。

**推论（对多次采样/投票的打击）**：把分数在 M 个独立上下文上取平均，方差除以 M，但**翻转只除以约 √M**；多数投票除得更少。

### （5）投票能去掉什么、去不掉什么

**命题 4**：对 m 个独立排列取多数（BatchPrompt 的做法）——

- 收敛到 `𝔼[f | N]`，其方差是 `V_N`；
- 两个独立划分各做 m 个排列的多数投票，翻转概率随 m 严格下降，收敛到

```
F_∞ = Ψ( h/√(1−D_resh),  (1−D_new)/(1−D_resh) )
```

**`F_∞ > 0` 当且仅当 `V_N > 0`。**

⇒ **投票消除了槽位效应、顺序效应、以及槽位×同侪的交互，但消不掉同侪主效应（membership）。**

**命题 5**：投票去的是**方差**，不是**偏置**。而且给了一个不需要模型的无偏下界（式 4）：

```
(1/n) Σ_i B_i  ≥  P(X=3) − (1/3)·min{ P(U=1), P(U=2) }
```

其中 X 是"三个独立随机上下文里有几个与单条判定不同"的计数，U 是"有几个判为 1"的计数。

### （6）预注册的三道门

论文在跑之前固定了三个 pass/fail 判据：

| 门 | 检验什么 |
|---|---|
| **generality** | 效应是否跨任务、跨模型成立 |
| **membership** | 同侪主效应是否真的存在 |
| **mechanism** | 通过哪个通道起作用 |

⇒ **这个预注册动作本身值得学**：三个 gate 在看数据之前定好，避免事后挑结论。而 follow-up 的 14–32B 模型实验**明确标注"不在 gate 覆盖范围内"**——这种透明度很少见。

## 三、技术细节

### 实验设计

| 项 | 规格 |
|---|---|
| 任务 | **3 个**：社交媒体评论的有害性判定 / 简答题评分 / 评论星级 |
| 主模型 | **5 个开源 4–9B** |
| follow-up 模型 | **4 个 14–32B** |
| 每任务条目数 | **2,000**（同一批，在不同条件下重复评） |
| batch 大小 | **25** |
| 划分 | 3 个独立随机划分 |
| 基线 | 重命名 key / 改写指令 / 同样 prompt 逐条生成 |
| 硬件 | H200 NVL GPU |

### 干预实验（分离两个通道）

做法很精细：**在目标条目的数字被写出之前截断生成**，编辑 token，再读一次分布；**答案的其它 token（包括版式）保持原样**。

- **编辑之前条目的判定**（文本不动）⇒ 隔离 **verdict channel**；
- **替换同侪的文本**（判定不动）⇒ 隔离 **text channel**。

⇒ 这比"换个 batch 再看结果"要强得多，因为它是在**单次生成内部**做因果干预。

### 顺序效应的槽位不代表性（一个诚实的偏差披露）

"保持槽位、重排其它"这个条件只保留了 5 个指定槽位（0, 6, 12, 18, 24）的 400 条/划分，而且它们 24 个同侪里有 4 个原地不动，所以 `G_keep` 是顺序分量的**下界**。

更重要的是：**这些槽位不具代表性**——

| 槽位 | "保持槽位、重排其它"下的判定翻转率 |
|---|---|
| **第 1 个槽位**（模型在写任何判定之前） | **4.0%** |
| 其它指定槽位 | **9.9 – 11.8%** |

⇒ **第一个位置天然更稳，因为它还没被前面的判定污染。** 论文按随机划分的权重重新加权（首尾各 1/25，中间三个各 23/75）。

核对结果：五个模型在 harm+garding 上合并，**2,470 个判定里 11.0% 翻转**（494 个放置、467 个不同条目，每个都被五个模型评过；标准误 0.7，按 batch 聚类），对比加权指定槽位的 10.8%、不加权 9.6%。⇒ **加权方案对得上。**

## 四、实验与结果

### 主结果：翻转率与基线的对比

| 规模档 | 新随机划分导致的判定变化 | 超出最大基线的幅度 |
|---|---|---|
| **5 个 4–9B 模型**（harm + grading） | **11 – 22%** | **+6.5 – 13.3 点** |
| **4 个 14–32B 模型** | **6 – 15%** | **+4.2 – 9.1 点** |

**基线 = 重命名 key / 改写指令。** ⇒ **换 batch 的效应比换措辞大 6.5–13.3 点。**

**而 AUROC 呢：**

> **相对单条判，AUROC 只差 −0.033 到 +0.010。**

⇒ **这是全文的核心矛盾：个体判定翻转 11–22%，聚合指标几乎不动。**

### 分解：顺序和槽位占大头，但同侪也去不掉

| 分量 | 占潜在不相似度的比例 |
|---|---|
| **顺序 + 槽位** | **大部分** |
| 同侪主效应（保持槽位时） | 0.10 – 0.30（预注册口径 0.22 – 0.44，但该口径高估） |
| **同侪主效应（9 个排列全评的口径）** | **0.11 – 0.22** |

**投票残留（这是最能说明"投票不是解药"的数）：**

| 投票方式 | 残留翻转 |
|---|---|
| 5 个排列多数投票 | **60 – 69%** |
| 9 个排列多数投票 | **52 – 60%** |

⇒ **投 9 次，还剩一半以上。** 因为同侪主效应投票消不掉（命题 4）。

**阈值模型对这批数据的预测误差在一个点以内。**

### 批处理不只是"散开"，还在系统性偏移

| 度量 | 值 |
|---|---|
| 随机 batch 与单条判不一致 | **10.9 – 19.8%** |
| **15 个独立随机 batch 的多数** 与单条判仍不一致 | **8.4 – 17.8%** |

⇒ **即使投 15 次，仍有 8.4–17.8% 的判定与单条判不同。** 这不是噪声，是**系统偏置**。

### 两个通道都在起作用

| 干预 | 判定变化 |
|---|---|
| 换成另一个 batch 的**判定** | **7 – 23%** |
| 换成另一个 batch 的**文本** | **9 – 26%** |

⇒ **文本通道的影响略大于判定通道，但两者都显著。** 这意味着"把前面的判定遮住"这一个修法不够。

### 任务难度决定效应大小

| 任务 | 判定变化 | 备注 |
|---|---|---|
| harm / grading（**有歧义**） | 11 – 22% | – |
| **star ratings（容易）** | **2.9 – 3.9%** | 模型与真实评分的 AUROC 达 **0.96** |

但注意：star rating 上**写出来的评分本身变了 16–21% 的评论**，只是**跨过判定阈值的变化只有 2.9–3.9%**。

⇒ **两个读数要分开：连续值漂移很大，但只有落在阈值附近的才会变成判定翻转。** 这正是命题 3 的实践版本。

### 论文的建议（三条，最后一条最该抄）

1. **有歧义的条目，一条一 prompt 判。**
2. **用 cached prefix 把成本收回来**（serving 系统本来就跨请求复用缓存前缀）。
3. **只要做了批处理，就报告与单条判的一致率。**

⇒ 第 3 条是一个**几乎零成本的报告规范**，可以直接写进我们的评测 SOP。

## 五、局限性

1. **只在文本判定任务上做。** 三个任务（harm / 短答案评分 / 星级）全部是文本。**多模态（多图一 prompt）的批处理效应没有被测。** 这恰是我们最关心的场景，论文完全没覆盖。
2. **batch 大小固定 25。** 没有扫 k（k=5/10/50/100）的曲线。⇒ **不知道翻转率随 k 怎么变**，而这对成本-精度权衡是关键。
3. **模型全部是开源、≤32B。** 没有前沿闭源模型（GPT / Claude / Gemini）。⇒ 商用 API 是否同样受影响**未知**。
4. **没有给出"如何检测自己的批处理是否安全"的可操作流程。** 只给了结论与建议。⇒ 我们要自己把它转成一个体检脚本。
5. **第一个槽位的估计有已知偏差。** 论文自己承认 `G_keep` 是下界，且指定槽位不具代表性，靠重新加权补救。这个补正的正确性依赖"槽位权重可以按 1/25、23/75 近似"这个假设。
6. **14–32B 的 follow-up 实验"不在 gate 覆盖范围内"**，属于部分样本外检验。⇒ 大模型上的效应幅度可信度略低。
7. **没有涉及"同侪是同类 vs 异类"的对比。** 即：批里全是 PORN 图 vs 混着 VULG 图，效应是否不同？这对我们的场景（多类混批）是关键，论文没测。

## 六、复现指南

### 最小可复现路径（给我们自己用，**半天，最该先做**）

**实验：图审批处理体检**

```
输入：现有 AB 评测集 N=500 张图
条件 A（现状，若是批处理）：按原 batch 组成跑
条件 B：逐条单独跑（batch=1）
条件 C：重排 batch 内顺序（3 个不同随机划分）
```

**报三列：**

| 列 | 定义 |
|---|---|
| **个体判定翻转率** | 条件 A 与 B 的判定不一致比例 |
| **AUROC** | 两条件下的 AUROC 及差值 |
| **一致性** | A 与 B 的判定一致率（论文的推荐报告项） |

**判据表：**

| 翻转率 | 结论 | 动作 |
|---|---|---|
| **< 5%** | 批处理可接受 | 继续用，但报告里必须附一致率 |
| **5–15%** | 有干扰 | AB 差异 < 15 点则结论不可信，改单条 |
| **> 15%** | 严重 | **立刻停用批处理做 AB**，历史结论全部作废重跑 |

**特别检查（这一步最容易漏）：**
如果 AUROC 差值 < 0.03 **而**翻转率 > 10%，**不要以为"AUROC 稳就没问题"**——这正是论文的核心发现。

### 判定器 AB 评测协议补丁（可直接写进 SOP）

```
必报项（缺一不可）：
  · batch size
  · 单条判 vs 批量判的一致率          ← 本次新增
  · 3 个随机划分之间的判定翻转率       ← 本次新增
  · macro-F1（不能只报 accuracy，见 2610.38611）
  · κ vs 人类
```

**判定"AB 结论是否可信"的门槛：**

```
若 |模型A − 模型B| 的指标差 < 批处理翻转率
   ⇒ 结论不可区分，不能说"谁更好"
```

对标：翻转率 11–22%。

### 两个通道的干预（可选，1 天，用于定位原因）

如果体检发现翻转严重，想确认是"读同侪文本"还是"抄前面判定"：

```
干预 1（文本通道）：保持判定不变，把同侪的文本换成另一批的
干预 2（判定通道）：保持文本不变，把前面的判定换成另一批的
```

对标：文本通道 9–26%，判定通道 7–23%。两者都显著 ⇒ **只遮判定不够，必须改单条。**

### 投票能不能救？

**不能，而且别浪费算力。** 对标数据：

| 投票 | 残留翻转（相对新划分） |
|---|---|
| 5 排列 | 60 – 69% |
| 9 排列 | 52 – 60% |
| **15 个独立 batch**（与单条判的不一致） | **8.4 – 17.8%** |

⇒ **投 9 次还剩一半以上，投 15 次还有 8–18% 的系统偏置。** 同侪主效应投票消不掉（命题 4）。

**正确做法是单条判 + cached prefix 收成本**，不是投票。

### 需要注意的实现坑

1. **必须做"逐条单独判"的对照。** 没有这个对照，任何批处理结果都无法校准。这是最容易省掉也最不该省的一步。
2. **3 个独立随机划分是下限。** 单一划分的翻转率没有估计量方差，无法判断显著性。
3. **第一个位置的样本不能算进顺序效应。** 首槽翻转率 4.0% vs 其它 9.9–11.8%，混在一起会把顺序效应低估一半以上。
4. **任务越难效应越大。** 我们如果测的是"PORN 明确类"，可能翻转率很低；如果测"VULG 边界"，翻转率会显著更高。⇒ **必须分难易档报，不能合并。**
5. **连续值漂移 ≠ 判定翻转。** star rating 上评分漂了 16–21% 但判定只翻 2.9–3.9%。我们的 L1–L4 层级判定如果取最高级，就要看**跨级漂移**而不是等级分数的漂移。
6. **多模态场景（多图一 prompt）的效应论文没测，不能假设"文本上 11–22%，图像上也一样"。** 图像 token 更多、同侪干扰可能更强也可能被稀释——**必须自己测**。

### 一句话结论

> **用聚合指标去检验个体判定稳不稳，在原理上就是错的。想看批处理有没有害，只能逐条对照，然后报一致率。**
