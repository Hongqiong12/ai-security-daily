## 一、背景与问题

### 动机：conformal 校准只保证「不太可能放进危险」，不保证「不误杀」

一个 latent safety filter 从世界模型的 latent 判断动作是否安全；conformal calibration 把阈值设到「接受不安全动作的概率 ≤ δ」。但论文指出：**阈值校准好了，过滤器仍可能非常保守，拒绝大量安全动作**——而这取决于 latent 本身，与阈值无关。

### 与本仓库主线的关系（四个直接落点）

1. **「能改则不拒」的线上取向第一次有了数学下界**。用户明确要求误杀率是硬约束、改写强度尽量下沉而非直接拒答。本篇证明：**在同一表示下，误杀有一个由数据几何决定的最小值，调阈值/加规则都降不下去，只能换表示**。
2. **用户侧可感知误伤 /「假安全」拒答体感归因**：「我没写违规内容却被拒」不一定是阈值偏、词表过宽、模型太弱，而可能是**安全样本与危险样本落在同一个 cell 里不可分**。这给六层风控的「误伤体验层」补了一个结构性解释。
3. **per-category threshold / operating point 校准**：论文同时给 overlap 与 conformal bound，且强调两者**对任意 latent 都能算** ⇒ 可直接搬成分层阈值选点前的「可判性体检」。
4. **与同批 29629 配对**：一个说「误杀有结构性下界、由表示决定」，一个说「你读到的误杀率本身可能是评测集污染造成的」。两篇合起来 ⇒ **先审计评测集，再体检表示，最后才调阈值**。

## 二、核心方法

### 2.1 overlap 的定义与定理

把相似的 latent 与动作分组为 **cell**；一个「每 cell 只给一个判定」的过滤器，要拒绝某 cell 内所有不安全转移，**就必须连该 cell 内所有安全转移一起拒**。这部分安全转移占全部安全转移的比例称为 **overlap**。

**定理**：overlap 是「在数据里接受 0 个不安全转移」的前提下，这类过滤器**必须拒绝的最小安全转移比例**。

⇒ 这是**下界，不是经验观察**。任何「再调一次阈值」「再加一条豁免规则」都无法突破它；要降误杀只能改 `Φ`（表示/编码器）或改 partition（更细的 cell）。

### 2.2 双工具：overlap + conformal bound

- **overlap**：只需带标签的 logged transitions，度量表示的**可判性**；
- **conformal calibration**：给接受不安全动作的概率一个 δ 级证书；
- 作者强调「The certificate holds for every encoder at the same level δ, but **the overlap differs from one encoder to the next**」⇒ **证书一样，误杀差很多**。这是对「有证书就安全」的直接反驳，与 11-23「证书不作废但 operating point 会作废」同族。

### 2.3 三种表示设计对照

| 设计 | 做法 |
|---|---|
| Planner latent `z` | 安全标签在**世界模型之上**训分类器 |
| Jointly trained latent `z_ℓ` | 安全标签与**世界模型一起**训 |
| **Safety latent `z_s`** | 世界模型**旁边一个独立编码器** |

## 三、技术细节

### 3.1 主表（Table 1，logged transitions + 600 scene pairs，δ=0.02）

| 表示 | overlap（三种 partition 范围） | 校准过滤器拒安全动作 | goal 达成（Table 2） |
|---|---|---|---|
| Planner latent `z` | **0.96–0.97** | **0.302** | 0.39 |
| Jointly trained `z_ℓ` | **0.94–0.96** | **0.318** | 0.32 |
| **Safety latent `z_s`** | **0.44–0.46** | **0.161** | **0.72** |
| 无过滤器（参考） | — | 0.000 | 0.72 |
| Full state `x`（参考） | — | — | 0.74 |

⇒ **独立安全编码器把 overlap 砍到不到一半，误杀从 ~0.30 降到 0.161，任务达成率从 0.39/0.32 回到 0.72（与不设过滤器持平）**。这是「换表示 > 调阈值」的量化证据。

### 3.2 partition 粒度敏感性（必报项）

- `K_z = 50`：overlap 在 `z` 为 0.97–1.00、`z_s` 为 0.52–0.54；
- `K_z = 200`：`z` 0.84–0.86、`z_ℓ` 0.78–0.81、`z_s` 0.37。

⇒ **cell 粒度会改 overlap 读数**，所以任何「我们误杀率多少」的结论必须写明 partition 与 `K_z`。这正是用户要求的「分层口径 / 聚合层级口径」纪律。

### 3.3 δ 网格（Table 6，测试集上拒绝的安全动作比例，200 次校准抽样）

| 表示 \ δ | 0.002 | 0.005 | 0.01 | 0.02 | 0.05 | 0.1 | 0.2 |
|---|---|---|---|---|---|---|---|
| Full state `x` | 0.600 | 0.496 | 0.377 | 0.259 | 0.163 | 0.092 | 0.050 |
| Planner `z` | 0.668 | 0.555 | 0.402 | **0.302** | 0.195 | 0.105 | 0.041 |
| Jointly `z_ℓ` | 0.643 | 0.543 | 0.427 | **0.318** | 0.196 | 0.109 | 0.042 |
| **Safety `z_s`** | 0.280 | 0.247 | 0.205 | **0.161** | 0.114 | 0.072 | 0.044 |

δ=0.02 时 200 次校准抽样的 10–90 分位：`z` 0.26–0.34 / `z_ℓ` 0.28–0.36 / `z_s` 0.14–0.18。另：把分类器与编码器一起训时，`z_s` 的过滤器拒绝 0.194 的安全测试动作、能分开 0.79 的 scene pairs。

### 3.4 实验环境口径

PointMaze U 型 5×5 地图、7 个自由格、1 个额外墙格；观测为当前与前一帧 64×64 RGB + 本体状态；**16.8% 的 logged transitions 不安全**；每 episode 随机起点/目标/墙位置且各过滤器相同。

## 四、实验与结果

- **结论一**：在相同 δ 证书下，三种表示的误杀差近 2×（0.302 / 0.318 / 0.161），而**任务达成率差 2×以上**（0.39 / 0.32 / 0.72）。⇒ 「安全达标」的版本可能把帮助性砍掉一半以上。
- **结论二**：overlap 低者，其训出的过滤器也最不保守（作者明写「The overlap is therefore also the one whose trained filter is least conservative」）——**overlap 可以在部署前用 logged data 预测误杀**，不必上线试。
- **结论三**：作者自承「the overlap only describes the latent, and this filter is too coarse to deploy」⇒ overlap 是**体检量**，不是可上线过滤器。本项目应把它当作「阈值校准前的准入检查」，别拿它当线上策略。
- **与 11-24 judge 偏置的合流**：那篇说「尺子会单向抬分」，本篇说「证书一样但误杀差两倍」，29629 说「误杀读数本身被污染」⇒ **三篇共同要求：任何误杀率结论必须同时给「评测集审计 + 表示可判性 + 校准抽样分布」**。

## 五、局限性

1. **领域不是内容安全**：视觉导航 / 机器人规划，安全标签是物理碰撞，不是 PORN/VULG / 政治 L2_30 这类语义与社会语境标签；后者的人工一致率本身不齐（11-24 EBSG：sexual 93.0% vs harassment 70.0%），overlap 会更高。
2. **只比较 3 种表示设计、1 个环境**；未覆盖层级标签、序数等级、多语言。
3. **「每 cell 一个判定」是粗粒度假设**：真实分类器是连续打分，overlap 给的是这类过滤器的下界，不是精确误杀率。
4. **不算可部署过滤器**（作者自述），也未报延迟。
5. **δ 与 overlap 是两件事**：δ 控「放进危险的概率」，overlap 控「必须拒掉多少安全」；把两者混成一个「风险等级」会误用。

## 六、复现指南

### 6.1 论文复现

固定数据 `D` 与 `Z×U` 的 partition；算 `overlap_D0(Φ)` = 落在含不安全转移 cell 里的安全转移占比；conformal 校准取第 11 小分数对应 δ=0.02，`K_z ∈ {50,200}`，200 次校准抽样报 10–90 分位；δ 网格 {0.002…0.2} 各报一次；三种表示设计对照；任务侧报 backup / stopped / goals。

### 6.2 本项目最小迁移（零训练，半天，**最优先**）

**A. 阈值校准前的「可判性体检」**：把 L1 × L2_30 每个叶子类目当 cell（或按 embedding 聚类成 cell），用带标签的历史命中日志算 **overlap**：

| 用途 | 做法 | 判据 |
|---|---|---|
| 准入 | 报每类目 overlap + 样本数 + 人工一致率三元信息 | 某叶子 overlap >0.5 ⇒ **不许单独调阈值**，先补特征/换表示或继承父类阈值并写明降级口径 |
| 归因 | 对「我没写违规内容却被拒」的申诉样本，查其是否落在高 overlap cell | 申诉集中在高 overlap cell ⇒ 是表示问题，不是阈值偏，改规则无效 |
| 冻结 | overlap 必须写明 `K_z` / 聚类口径 / 数据集版本 | 换口径即换数，禁止跨版本直接比 |

**B. 与运营基线对齐**：现状误杀率 **5.2%** / 漏过率 **3.42%** / 一级一致率 **77.64%**。先按 29629 审计评测集重叠，再按本篇算 overlap，若两者都干净才进入阈值选点；**任何优化不得以降低帮助性换降风险**，双约束下比较，只报单侧改善不进看板。

**C. 改写分流专项（I2I 0/0% 的第七种可证伪归因）**：若 I2I 分流是「一个 cell 一个判定」式的粗粒度路由（只读文本通路 / 二分是否改写），则高 overlap 会**结构性**地把安全指令一起拒掉或一起放行。检验：用 2000 条评测集算分流的 overlap，若 >0.5 ⇒ 0/0% 不该靠换模型或加严改写解决，应改成**带分数的多候选排序**（11-27 记忆里 EditJev 的结论：2B 小模型就够做路由、94ms 开销）。

**上线口径**：任何新表示 / 新阈值 / 新量化档上线前，报 δ 网格下的误杀-漏过曲线 + overlap + 200 次校准抽样分位 + 分语言分层 F1 + 逐样本判定翻转率（≤3%）+ TTFT/e2e；shadow 与生效模式分列，只换流量比例不换尺子。
