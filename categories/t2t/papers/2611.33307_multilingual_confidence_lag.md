# 英文设的 95% 阈值，到泰米尔语只剩 90%：准确率掉了，置信度只掉一半

**论文主页**: https://arxiv.org/abs/2611.33307

## 一、背景与问题

### 动机：guardrail 阈值是「在英文上调的」，却直接用到所有语言

Decision models 是为「对每个 typed query 的每个选项返回一个概率」而微调的语言模型，**router 在置信度低于阈值时升级、guardrail 高于阈值时拦截**——也就是本项目「阈值下发 / 命中判定」的同一个动作。它们底座是多语言的，但排行榜**几乎全在英文上排**。本文用 **25 个开源 decision model × 17 个任务子类 × 14 种语言 × 25,626 条平行条目**，逐语言与英文配对比较。

### 核心发现（一句话）

**每个模型在每种语言上都掉准确率（马来语 −1.6 到泰米尔语 −7.8 点），但置信度只掉一半（−1.8 点均值）**：于是「英文上把错误率压到 5% 的阈值」，在非英文上悄悄放进了最多 10% 的错误。**不是模型变笨，是尺子没跟着走。**

### 与本仓库主线的关系（四重命中）

1. **2B 改写模型英文 ASR 飙升 / 中英合并训练**：本文给出可迁移的**机制级解释**——若阈值/判定在英文上校准，非英文侧的**过度自信**会让「判低风险」的样本系统增多，表现为 ASR 漂移；且作者证明**微调能修校准、修不回准确率** ⇒ 中英合并训练不是万能解。
2. **per-category threshold / operating point / conformal**：语言（60%）与底座（34%）解释了几乎全部准确率损失方差，而损失大小**与排行榜名次无关** ⇒ 必须 per-language 选 operating point，不能全局下发一个阈值。
3. **误杀率 5.2% / 漏过率 3.42% 双约束**：本文把「阈值在一个语言上达标」证明为不充分；这正是 11-25「误杀率基线本身要先被审计」与 11-26「体检尺子」之后的**第四种读数污染：语言维度上的校准漂移**。
4. **三维评测 / 分层宏平均背离**：25 模型 × 13 语言 = **325 个 model–language pair 全部掉准确率**，其中 **301 个过度自信上升**；聚合准确率微动而分层全退，是 `aggregate-vs-macro divergence` 的跨语言形态。

## 二、核心方法

### 2.1 平行条目协议（本文最可迁移的部分）

- **同 item 跨语言配对**（parallel items），控制题目难度差异；按 family 匹配后算 `ΔAcc`、`ΔConf` 相对英文的差，再在 families 上平均；
- 定义 **Gap = ΔConf − ΔAcc**（过度自信增长）：Gap=0 表示置信度跟着准确率走，Gap>0 表示置信度**滞后**；
- `Thr.`：在英文同一批 item 上把接受答案的准确率钉到 **95%** 的阈值 τ，再报告该 τ 在其它语言上接受的答案实际准确率；
- 每语言分数对 17 个子类做 **macro-average**（不是样本加权）——与本项目「分层宏平均」口径一致。

### 2.2 三条归因

| 归因 | 证据 |
|---|---|
| 语言与底座决定损失大小 | 嵌套方差分解：**语言 60% / base model 34%**，排行榜名次不解释 |
| 任务技能可跨语言迁移 | 英文任务数据能迁到泰米尔语；目标语言数据只在损失最大处补益 |
| 微调修校准易、修准确率难 | 全部 8 个 Qwen3.8 模型在泰米尔语掉 **13.6–17.8 点**，而英文仅掉 2.9–… |
| 温度缩放可修 ECE | **per-language temperature scaling（500 items）把 pooled ECE 4.1%→2.9%** |

## 三、技术细节

### 3.1 数据规模

| 项 | 值 |
|---|---|
| 模型 | 25 个 top-ranked 开源 decision model |
| 任务 | 7 大类 / 17 子类（情感、阅读理解与主题、意图与检索、安全/毒性等） |
| 语言 | 14 种（英语 + 8 种全球语言 + 5 种东南亚/南亚语言：印尼、越南、泰、马来、泰米尔） |
| 条目 | **25,626** 条；每个 benchmark–language cell ≤100 items |
| 翻译来源 | 64% 人工/原创、15% 作者机翻、21% LLM 翻译；**非平行集只进总分、不进跨语言 delta** |
| 校准 | 15 等宽 bin 的 ECE；per-language temperature scaling 用 500 items |

## 四、实验与结果

- **全部 325 个 model–language pair 准确率低于英文**（−1.6 到 −7.8 点）；**301 个 pair 过度自信上升**；
- 每语言温度缩放把 pooled **ECE 4.1% → 2.9%**（校准可修），但准确率损失仍在（能力不可修）；
- **方差分解**：语言 60% + base model 34% ≈ 全部；**排行榜名次不解释** ⇒ 换一个「英文排名更高」的模型救不了；
- **安全/毒性子类与其它子类的 Gap 形态不同**：最尖锐的 Gap 落在 Swahili safety 与 Tamil knowledge，而 **reasoning 子类 Gap 近零却照样掉准确率** ⇒ 过度自信不是跨任务均匀的，**必须按「语言 × 任务/类目」分格报**；
- 全部 23 个 benchmark–language pair 里模型显著劣于英文（12 个达显著）；
- 翻译来源敏感性：平行 family 覆盖 16–19 个（纯人工翻译 7–13 个），作者用配对 bootstrap CI 承认单 cell 噪声。

## 五、局限性与迁移边界

- **纯文本 decision model，无图像、无生成**：不测 T2I 出图侧、图审、NSFW、编辑指令；**可迁的是阈值校准协议，不是 ASR 数值**。
- **每个 benchmark–language cell ≤100 items**，单格噪声大，结论依赖跨 family/语言/模型的平均与配对 bootstrap；本项目 2000 条图生图评测集需自行确认每格 `N_eff`。
- **平行条目以翻译为主**（21% LLM 翻译），中英 code-switching **未覆盖** ⇒ 不能直接回答「中英混合」这一形态，D6 九格须自建。
- **未报 TTFT / 量化 / serving setup / 检测器版本**；per-language 温度缩放引入多套阈值，其上线后的版本治理本文不管。
- **无「改写」动作**：只判阈值，不做 prompt rewrite ⇒ 不能回答「语义取向漂移」，只能回答「判定阈值漂移」。
- **行为层修复 ≠ 能力修复**：温度缩放把 ECE 降下来，但准确率缺口还在 ⇒ 与 11-25「行为层归零不构成移除证据」同构：**校准合格不等于安全合格**。

## 六、复现指南

1. **D6 九格的现成协议（零训练，1 天）**：把「中 / 英 / 中英混合 × 三形态」九格改成**平行条目**（同义同难度跨语言配对），每格报 `ΔAcc`、`ΔConf`、**Gap = ΔConf − ΔAcc**、英文校准 τ 下的实际接受准确率、`n⁺`；**禁止只报聚合 ASR**。
2. **先修尺子再谈训练**：对九格各跑 per-language temperature scaling（500 items）看 ECE 是否下降；**若 ECE 降而 ASR 不降，则英文 ASR 飙升不是校准问题，中英合并训练才是主线**；若 Gap 主导且缩放后 ASR 回落，则先做 per-language 阈值下发，不启动重训。
3. **per-category operating point**：按「一级类目 × L2_30 × 语言」出阈值矩阵，英文阈值**不得直接下发**到非中文；把 Gap 与 `Thr. 实际准确率` 两列加进 11-26「七元组」构成**八元组**。
4. **误杀率基线重算**：5.2% / 3.42% 若只在中文上测，须按本文口径补非中文臂；「覆盖率不变而判定集合在换」（coverage churn）在跨语言上尤其要查稳定率。
5. **对照臂**：叠加 DSC 三版（语用形态）、CRIE-S 式中性 prompt 构造、HinT 非目标属性引入率（英文改写扩写幅度更大?）；每格同时跑「全量 vs 线上加速」排除生成过程语言敏感性（25382 guidance 项 1.66×）。
6. **留痕**：每格标注样本数 / 人工一致率 / 翻译来源 / `N_eff` / 检测器版本 / 温度缩放版本；换语言、换检测器、换评分协议都登记为 calibration 事件。

---

**对本项目的落点（一句话）**：**英文上调的阈值，在中文也只有 93.1% 的实际准确率，泰米尔语掉到 90.0%——因为置信度只跟着掉一半**。这是「2B 改写模型英文 ASR 飙升」最干净的机制级解释：先按语言分格做校准体检与 ECE/ASR 双臂对照，再决定要不要中英合并训练；**微调能修校准、修不回准确率**，别把两者混成一个指标。
