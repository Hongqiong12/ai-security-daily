## 今日概览

先说结论：**本周没有出现新的 T2I 改写方法，但出现了四篇把"归因"做成工程的文章——它们 collectively 回答了一个我们一直靠手感判断的问题：指标动了，到底是谁的贡献？**

拆开看，四条线索指向同一个方向：

1. **改写不定位锚点，净收益为负。** `IMPLICIT-Bench` 做了我们一直没做的消融：不给锚点信息直接改写，"偏置"降了 0.38 分，但"对齐率"掉了 11.1 个点，联合分 **−0.8**。给 oracle 锚点是 **+8.6**，给检索锚点（top-1 仅 40%）是 **+2.9**。**结论：改写增益的天花板由锚点定位精度决定，不是由改写模型能力决定。**

2. **输出侧图审的鲁棒性是审核器架构的函数，不是"有没有上审核"的函数。** `Mirage` 在同一批攻击下，CLIP Checker 绕过率 **0.800**、NudeNet **0.435**、ViT Checker **0.185**——差 4.3 倍。而且 bypass ≠ ASR：被放行的样本里有 16 个百分点并没有真的生成目标内容。**单模型图审上线 = 拿一个未标定的数字当安全边界。**

3. **判定标准显式化，比换更强的 judge 更有效。** 腾讯混元 `DiagSafe` 用同一个 judge（Hy3），只把提示从"通用安全 prompt"换成"prompt 级 rubric"，与人类一致率从 **87.29% → 95.34%**（+8.05）。这是"改 system prompt 结构"能拿到的量级，不需要重训模型。

4. **模型能把意图说对，却仍然让表面词决定标签。** `AIMS` 报了一个极刺的发现：GRPO 修回来的 71 例过拒里，有 **6 例 SFT 与 GRPO 生成的意图表述 Jaccard 重叠 > 0.5**——意图几乎一样，标签却相反。**这为我们的 PORN/VULG 混淆提供了一个机制级解释：不是"不懂"，是"没绑死"。**

一句话压缩今天：**T2I 安全这一周的主线从"造方法"转到了"查归因"——四个工作分别从锚点、审核器架构、判定标准、意图绑定四个角度，指出了我们现有 pipeline 里四个"看起来在动、其实没归因"的位置。**

## 一、T2I / T+I2I 论文（核心主线 · 4 篇）

### 1. Mirage — Targeted Jailbreaks Against Post-Generation Safety Checkers

**本地精读**: `categories/t2i/papers/2610.30348_mirage.md` · https://arxiv.org/abs/2610.30348
**机构**: Washington University in St. Louis · Virginia Tech | **2026-10-21** | cs.CR

- **论文定位**: 针对**生成后安全审核器**的定向越狱（输出侧图审失效分析）
- **攻击形态**: 只改**图像输入通道**（加 $\le 8/255$ 不可感知扰动），**文本 prompt 完全不动**
- **核心机制**: 在替代 CLIP 编码器的共享表征空间里，同时做两件事——**拉近**扰动图与恶意目标嵌入、**推离**扰动图与常被过滤的 NSFW 概念簇；语义分离**跨表征空间迁移**到未知审核器
- **关键数据（$\epsilon=8/255$）**:

  | 数据集 | CLIP Checker | ViT Checker | NudeNet |
  |--------|--------------|-------------|---------|
  | I2P（文本目标）Bypass | **1.000** | 0.900 | 0.960 |
  | NSFW（图像目标）Bypass | **0.800** | **0.185** | 0.435 |

- **两个必须记住的口径问题**:
  1. **审核器差异达 4.3 倍**（CLIP 0.800 vs ViT 0.185）→ 图审选型是安全边界本身；
  2. **bypass ≠ ASR**：I2P/CLIP 上 bypass 1.000 但 ASR 0.840，**16 个百分点的样本被绕过却未生成目标内容** → 用"放行率"当漏放指标会高估。
- **攻击成本**: I2P 上 2.4–3.8 次黑盒查询（SneakyPrompt 需 36–40 次）→ **可规模化**
- **我的判断**: 本周唯一直接打在输出侧图审的工作。它给我们的不是"要防这个攻击"，而是**图审 AB 评测必须做异构集成 + 必须分清 bypass 与 ASR** 这两条硬结论。

### 2. IMPLICIT-Bench — 改写有效性的归因实验

**本地精读**: `categories/t2i/papers/2609.24228_implicit_bench.md` · https://arxiv.org/abs/2609.24228
**机构**: The University of Melbourne | **2026-10-16**（v2）| cs.CV

- **论文定位**: T2I prompt rewriting 的**条件消融**（我们最缺的那块拼图）
- **核心设计**: 1,831 组 prompt 三元组（中性 / 刻板 / 反刻板，**场景固定**），每组配一个 KG unit（head, stereotype, anti-stereotype）；改写器分三种信息条件：**无锚点 / 检索锚点 / oracle 锚点**
- **关键数据（Qwen-Image）**:

  | 条件 | $\Delta S$（联合分） | 读法 |
  |------|---------------------|------|
  | **无锚点改写** | **−0.8** | 偏置降 0.38，但对齐率掉 11.1 点 → **净负** |
  | 检索锚点改写（top-1 40%） | +2.9 | 只拿到 oracle 的 1/3 |
  | **oracle 锚点改写** | **+8.6** | 上界 |
  | 删掉自身 unit 后检索 | **全部 12 组为负** | **锚点不跨 prompt 迁移** |
  | LLM-pair steering | **−12.6** | 偏置压到最低 1.01，但**对齐率崩到 23.2%** |

- **联合指标（可直接抄）**:
  $$S = 100 \cdot \mathrm{mean}_i\big[\,Y_i \cdot (1 - b_i/5)\,\big]$$
  画对了才拿分，画对了且不刻板才拿高分 → **天然惩罚"改得面目全非来降风险"**
- **我的判断**: ⚠️ **今天业务价值最高的一篇**。它用一组干净的数字证明了：**我们改写收益如果上不去，第一嫌疑是锚点定位，不是 rewriter 能力。**这个消融我们一周内就能做。

### 3. HealBench — 三维评分 + 1:2:1 加权 + 任务专属 scorer 作奖励

**本地精读**: `categories/t2i/papers/2610.27516_healbench.md` · https://arxiv.org/abs/2610.27516
**机构**: 华东师范大学 · Johns Hopkins · NUS
**会议**: **AAAI 2027** | **2026-10-19** | cs.CV

- **论文定位**: 细粒度多维 T2I 评测 + **把 prompt rewriting 当作干预手段来评测** + 训练专属 scorer 进 RL
- **规模**: 30,000 图文对 / 19 类 / 92 子类；评测集 1,095 例；14 个生成模型
- **三个可抄的结构决策**:
  1. **三维分列**：Text-Image 对齐 / 目标维度 / 图像质量，**目标维度权重加倍**：
     $$\text{Score}=s_{\text{sem}}+2\,s_{\text{heal}}+s_{\text{qual}}$$
     论文原话：1:2:1 是"为了在诊断解释时**不掩埋失效的维度**"
  2. **反馈必须带 rationale**：改写器的输入是"分数 + 理由"，不是分数本身
  3. **任务专属 scorer 取代通用 scorer**（见下表）
- **通用 scorer 在目标维度上基本失效**（Table 6，1,500 组偏好对）:

  | Scorer | Acc | Kendall's τ |
  |--------|-----|-------------|
  | PickScore | 0.5593 | 0.1525 |
  | LAION Aesthetic | 0.5507 | 0.1077 |
  | CLIPScore | 0.5413 | 0.1272 |
  | HPSv3 | 0.5013 | 0.0379 |
  | **THS（专属）** | **0.8527** | **0.7741** |

- **RL 定向性验证**: SD3.5 Medium + Flow-GRPO（奖励 = THS + CLIPScore），Heal 维度 5.88 → **6.45**，Semantic 6.32 → 6.48，Quality 6.08 → 6.28 → **增益集中在目标维度**
- **诚实度加分项**: 论文先报 HealScore 本身与人类偏好的一致性（Acc 0.8012、τ 0.4487），**再报模型分数**
- **我的判断**: 它同时证实了我们的一个隐患——**用通用一致性指标（CLIP / Qwen-Image 相似度）当奖励，信号里几乎不含安全维度信息**。必须补风险专属头。

### 4. LogicVal — 把"指令遵循"变成可判定问题

**本地精读**: `categories/t2i/papers/2610.24051_logicval.md` · https://arxiv.org/abs/2610.24051
**机构**: City St George's (UoL) · Toronto Metropolitan University · Flybits Labs · MIT Media Lab | **2026-10-16** | cs.AI

- **论文定位**: T2I 评测的**逻辑形式化**——prompt → ASP 约束 $C$，图像 → 场景图 $\widehat S(I)$，判定 $\widehat S(I)\models C$，**布尔答案、无需参考图**
- **九类约束**: Object-level C1–C3 / SubGraph-level C4–C7（含 $\exists\forall$、$\forall\exists$ 交替）/ Cardinality C8–C9；**71 个 ASP 模板**，可组合 $m\in\{1,3,6\}$
- **关键数据（GPT-Image-2 / Gemini-3-Pro-Image / FLUX.1-dev / Qwen-Image 中最优）**:

  | 能力 | 准确率 |
  |------|--------|
  | 单对象-属性约束 | **98%** |
  | 复杂条件多对象关系 | **53%** |
  | 单约束 prompt | **84%** |
  | **多约束同时满足** | **20%** |
  | 正确识别 UNSAT | **23%** |

- **两个工程细节值得直接借**:
  1. **反空真条款**：全称约束必须附"至少存在一个满足前件的对象"，否则"没画出来"在逻辑上为真 → **防止"该属性根本没出现所以没违规"的假通过**
  2. **UNSAT 的正确输出是空场景**：模型基本不会说"这要求没法满足"（只有 23% 识别率），它会硬画
- **我的判断**: 不能拿它测 NSFW（安全语义不可形式化），但**"约束集合 + 逐条判定 + 反空真"**这套形制可以直接搬到我们的"改写保真核验"上，尤其是"禁止用平均分掩盖组合崩盘"这一条。

### 5. DiagSafe — 84 标签三层体系 + prompt 级 rubric【⚠️ 腾讯混元】

**本地精读**: `categories/t2t/papers/2610.29225_diagsafe.md` · https://arxiv.org/abs/2610.29225
**机构**: 北京师范大学 · **腾讯混元团队（Hunyuan Team, Tencent）**
**资源**: 数据将开源 `github.com/Tencent-Hunyuan/DiagSafe` | **2026-10-21** | cs.CL

- **论文定位**: 细粒度安全评测体系（**本周边唯一腾讯署名的内容安全工作**）
- **核心结构（三层）**:

  ```
  安全条款（多国政策法规）
     → 标签规范 label specification（四要素）
        → prompt 级 rubric（4.5 条 S-item + 8 条 usefulness item）
           → LLM judge 逐条核对 → unsafe rate + 诊断轨迹
  ```

- **标签规范四要素（最关键）**: ① 精确定义 ② 价值原则 ③ **构成违规的危险行为** ④ **被允许的安全行为（豁免）**
- **规模**: 84 叶子标签 / 三层（11-34-84）；3,489 条（DiagBase 2,401 + DiagAttack 1,088）；中英 1:1；单轮:多轮 ≈ 7:3
- **关键数据（同一 judge Hy3，只换提示范式）**:

  | 范式 | 与人类一致率 |
  |------|--------------|
  | 通用安全 prompt | 87.29% |
  | 标签规范 prompt | 86.86% |
  | **prompt 级 rubric** | **95.34%** |

  跨 judge 一致性：rubric 范式 93.33%–94.78%（κ 0.828–0.864），另两种范式 κ 低至 0.53
- **最刺的发现**: **指令攻击（把有害意图包进良性任务外壳）把 unsafe rate 放大 1.9×–8.4×，中位 5.3×，8/11 模型 > 40%**
- **迁移价值（写清楚）**:
  - **可直接迁**：四要素标签规范 → 我们的 PORN/VULG 边界定义；rubric 化判定 → tag 分类的 system prompt 结构；类目级 unsafe rate → 分级标签评测
  - **不可直接迁**：它是 LLM 文本输出评测，不涉及图像；84 标签体系是通用安全，非 T2I 视觉语义
  - ⚠️ **反向警示**：如果我们的 rewriter 把 prompt 改写成"更明确的任务指令"，可能**降低**模型内生安全（指令遵循与安全拒答是竞争目标）

### 6. AIMS — 意图作为显式中间信号

**本地精读**: `categories/t2t/papers/2606.27210_aims.md` · https://arxiv.org/abs/2606.27210
**机构**: University of Groningen · Univ. Politehnica of Bucharest · **Adobe** · **NVIDIA** | **2026-10-16**（v2）| cs.CL

- **论文定位**: 安全分类器的训练范式（**intent 作为 prompt→label 的瓶颈变量**）
- **数据**: 1,275 条唯一 prompt / 1,724 条标注；**用集成模型不确定性筛样本**（= 主动学习挑差异样本）；开源 `jazhyc.github.io/aims-safety`
- **四范式共用同一信号**: SFT（先出意图再出标签）/ DPO（用模型自造的错误意图当 rejected）/ 推理蒸馏（意图条件 vs 纯推理）/ GRPO（奖励加"意图忠实度"项）
- **关键数据（五 benchmark 平均 F1）**:

  | 类别 | 最好成绩 |
  |------|----------|
  | 零样本 LLM | GPT-5.4 = 0.815 |
  | 专用 guard | Nemotron Safety 4B = 0.809 |
  | **本文 GRPO（label + intent 双奖励）** | **0.836** |

  **1,275 条标注，打赢了数据量差两三个数量级的对手。**
- **最刺的定性发现（直接解释 PORN/VULG）**: GRPO 修回的 71 例过拒中，**6 例 SFT 与 GRPO 的意图表述 Jaccard > 0.5 而标签相反** → **模型说对了意图，标签仍被表面词劫持**
- **迁移价值**:
  - 可直接迁：`<tag>` 前强制加一句意图复述（**只改数据模板，不改训练代码**）；GRPO 奖励加"意图忠实度"项；不确定性筛样本用于标注修正
  - 不可直接迁：它是文本分类，不含图像；4 点危害量级被压成二分类，与我们层级标签冲突

## 三、本周三条共识（跨论文综合）

| 共识 | 证据 | 对我们的含义 |
|------|------|--------------|
| **① 归因 > 调参** | IMPLICIT-Bench 的条件消融 / Mirage 的审核器对比 / DiagSafe 的同 judge 换提示 / LogicVal 的逐约束拆解 | 四个工作都在做同一件事：**把"总分变化"拆成可归因的因子**。我们下一步应该先建归因实验，不是先训模型 |

## 四、业务对齐研究板块

### A. 直接可迁移方法（按可落地性排序）

| 排序 | 来源 | 可迁移物 | 落地成本 |
|------|------|----------|----------|
| **1** | IMPLICIT-Bench | **联合指标 $S=100\cdot\text{mean}[\mathbb{1}(\text{保真})\cdot(1-\text{risk})]$** + 锚点条件消融（无锚点/检索锚点/oracle） | ⭐ 低（评测脚本改造） |
| **2** | DiagSafe | **标签规范四要素**（定义/原则/违规行为/**豁免行为**）→ 直接补 PORN 与 VULG 的边界文档 | ⭐ 低（写文档） |
| **3** | HealBench | **三维分列 + 目标维度 1:2:1 加权**；**禁止只报总分** | ⭐ 低（改报表） |
| **4** | AIMS | **在 `<tag>` 前强制复述意图**（改数据模板）；DPO 用"模型自造的错误意图"当 rejected | ⭐⭐ 中（重造数据） |
| **5** | LogicVal | **逐约束核验 + 反空真条款**（保真核验不允许平均分） | ⭐⭐ 中（写约束引擎） |
| **6** | Mirage | **图审 AB 评测改异构集成 + 分开报 bypass 与 ASR** | ⭐⭐ 中（评测协议） |

### B. 风险锚点（PORN/VULG 边界）处理启发

**启发一：把"豁免条款"写进标签定义，而不是靠调阈值。**
DiagSafe 的标签规范第 ④ 项是"被允许的安全行为"。我们的 PORN/VULG 混淆，很可能是两边都缺显式豁免——例如「医学/性教育/艺术史语境下的裸露描述」「暴力游戏/影视分级语境下的血腥描述」该归哪边，现在没有书面判据。**先补文档，再谈模型。**

**启发二：锚点必须逐 prompt 定位，不能靠类目模板。**
IMPLICIT-Bench 的 40% 检索命中率只拿到 oracle 的 1/3 收益，且**跨 prompt 不迁移**。这说明"PORN 类统一改写模板"注定低效。**需要的是锚点级（span 级）定位，不是类目级模板。**

**启发三：判别"意图对但标签错"与"意图错"是两类病。**
AIMS 的 6/71 案例说明模型可能已经理解意图，但仍让关键词覆盖决策。**如果我们的 badcase 里这类占比高，该做的是对比学习/奖励绑定（把标签绑到意图上），不是补数据。**

**启发四：过改会让"保真"崩塌，且崩塌是断崖式的。**
IMPLICIT-Bench 的 LLM-pair steering：偏置 3.39→1.01（看起来完美），对齐率 87.5%→23.2%。**风险降到底的配置往往是全场最差。** 必须在评测里把保真做成乘性因子，不能做加性惩罚。

### C. 三维评测设计启发（语义保持 / 安全提升 / 指令遵循损失）

| 维度 | 现在的做法 | 建议改成 | 依据 |
|------|------------|----------|------|
| **语义保持** | CLIP / 嵌入相似度 | **逐约束核验**（主体/数量/属性/关系/场景各一条）+ **反空真前置检查** | LogicVal：CLIP 类度量测不出数量、否定、关系；组合约束准确率仅 20% |
| **安全提升** | 风险分类器打分 | 分开报 **bypass（放行率）** 与 **有效拦截（放行且确实生成风险内容）** | Mirage：两者差 16 个百分点 |
| **指令遵循损失** | 人工 / MLLM 总评 | **按维度分列 + 目标维度 1:2:1 加权 + 报多维曲线而非单点** | HealBench：1:2:1 是为了不掩埋失效维度 |
| **联合分** | 加权和 | **乘性联合分 $S=100\cdot\text{mean}[\mathbb{1}(\text{保真}\ge\tau)\cdot(1-\text{risk})]$** | IMPLICIT-Bench：加性加权会让"过改"伪装成成功 |
| **评测可信度** | 不报 | **先报指标自身与人类的一致性（Acc / κ / τ），再报模型分数** | HealBench（0.8012 / τ 0.4487）/ DiagSafe（κ 0.864） |

⚠️ **一条硬约束**：**任何三维报告，如果只给总分不给分维度，视为无效报告。**

### D. 下一步实验建议（对照四条主线）

#### 【主线 1：tag-weighted loss】→ 实验 A：意图前置 + 豁免条款进 prompt

| 项 | 内容 |
|---|---|
| 改动 | ① `<tag>` 前强制加一句"用户意图是……"；② system prompt 里为 PORN/VULG 各加 4 条豁免条款（照 DiagSafe 四要素） |
| 依据 | AIMS（格式即先验，label-reward-only 都能到 0.809）+ DiagSafe（同 judge 换提示 +8.05） |
| 成本 | **只需重造数据模板 + 改 system prompt，不动训练代码** |
| 判据 | 在 PORN/VULG 混淆矩阵上，看 **VULG-HINT-EDGE 类的召回**是否上升，且 PORN 假阳不涨 |
| 风险 | 意图复述会增加输出长度 → 需监控 token 成本；train_with_custom_metric.py 的 tag_loss 权重配比可能要重调 |

#### 【主线 2：RL 改写】→ 实验 B：锚点条件消融（**优先级最高**）

| 项 | 内容 |
|---|---|
| 改动 | 三组对照：A=只给"改得更安全"；B=给检索到的风险锚点；C=给人工标注的真实锚点（oracle） |
| 依据 | IMPLICIT-Bench（−0.8 / +2.9 / +8.6） |
| 指标 | 联合分 $S=100\cdot\text{mean}[\mathbb{1}(\text{保真}\ge\tau)\cdot(1-\text{risk})]$，报 $\tau$ 的整条曲线 |
| 判据 | **若 C−B 的 gap 大（>3 分）→ 瓶颈在锚点定位，先做检索/分类，不要急着训 RL**；若 B≈C → 瓶颈在改写能力，去训 RL |
| 成本 | 低（不改模型，只改 rewriter 输入 + 评测脚本） |
| 备注 | 这个实验能一次性回答"我们改写收益的天花板在哪"，建议本周内做 |

#### 【主线 3：标签审计】→ 实验 C：不确定性筛样本 + 意图复判

| 项 | 内容 |
|---|---|
| 改动 | ① 用集成/多模型不一致度给训练集打分，取 top 差异样本（而非随机抽）；② 复判时**同时记录"意图描述"与"风险标签"**，两者分离存 |
| 依据 | AIMS（不确定性筛 1,275 条即够）+ DiagSafe（rubric 抽样 96.4% 合格率的质量校准做法） |
| 判据 | 复判后统计"意图对但标签错"的占比。**若该占比 > 30%，说明是绑定问题不是数据问题，应转去做奖励设计而不是继续清洗数据** |
| 成本 | 中（要跑多模型推理 + 人工复判） |
| 备注 | 与我们已定的"主动学习挑差异样本 → 标准文档+LLM 复判 → 向量聚类查覆盖"三步方案完全兼容，只是把"意图"加为独立字段 |

#### 【主线 4：输出侧图审】→ 实验 D：异构集成 + bypass/ASR 分离

| 项 | 内容 |
|---|---|
| 改动 | ① 拿 500 张已知 NSFW 生成图，同时过我们的图审 + 一个开源 NudeNet + 一个 CLIP zero-shot checker，比放行率差异；② 评测报表把"放行率"拆成 bypass 与"放行且确实含风险内容" |
| 依据 | Mirage（4.3 倍架构差异 + 16 点 bypass/ASR gap） |
| 判据 | **若三模型放行率差异 > 20 个百分点 → 图审必须做异构集成，单模型上线不成立** |
| 成本 | 低（不训练，只跑评测） |
| 备注 | 若要做攻击侧鲁棒性评估，可加一组 $\epsilon=4/255$ 的图像扰动测试——Mirage 证明最小扰动已足够绕过多数审核器 |

## 六、趋势信号

1. **T2I 输入侧改写这一周是"空窗"。** 15 路检索覆盖 138 篇 T2I 主题论文，**没有一篇提出新的 T2I 安全改写方法**。这与上周（CSTI / DSC / SCOPE / PPAA 四篇密集）形成明显反差。判断：该方向进入"消化期"，**下一波大概率出现在评测与归因层面**（本周已现端倪）。

2. **腾讯在内容安全评测侧的动作值得持续盯。** DiagSafe 是混元团队 + 北师大的合作，且明确开源数据。**84 标签体系 + 四要素标签规范**如果成为内部标准，会直接影响我们的类目定义口径。

3. **"归因实验"正在成为顶会级方法论。** 本周四篇 T2I 相关工作中，三篇（IMPLICIT-Bench / HealBench / LogicVal）的核心贡献都是"把指标拆开"，而不是"把分数推高"。这个趋势对我们有利——**评测方法论的门槛比模型训练低，但收益直接**。

4. **对抗鲁棒性仍是图审的软肋。** Mirage 用 $\epsilon=4/255$ 的最小扰动就能绕过 CLIP/NudeNet 类审核器（0.72–0.98），只有 ViT 类架构能把绕过率压到 0.18。**图审的架构选择已经是安全问题，不再只是工程问题。**
