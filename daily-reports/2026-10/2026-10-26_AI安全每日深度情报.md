## 今日概览

先说结论：**这是本月第一次出现"图审模型配方"级别的工业工作，而且它和"评测协议"这对组合打在同一个问题上——我们现在的图审 AB 分数不可信。**

三件事按重要性排：

1. **阿里安全 AGI Lab 开源了图审基座 Yuvion VL 的完整配方**，核心创新 C2FT 是"用模型自己的混淆去构造对比组"。它承认了一个我们摸索很久但没写下来的事实：**单样本 SFT 给不出边界判别信号**。量化结果：8B 模型在公开安全基准上比 Qwen3-VL 骨干 **+12.4** 点，内部业务集 **+11.3** 点，AI 生成图检测 **+17.8** 点 Macro-F1。

2. **Omni-UBench 用"掩码消融"证伪了护栏的判定依据**。把有害语义全换成等长占位符（空白图/静音）后，Qwen2.5-Omni-3B 仍有 **0.99–1.00 的召回**，平均误报 **0.87**。**它不是在读内容，是在读形状。** 这个方法可以直接拿来自查我们的图审到底在图上看什么。

3. **"匹配误报率"这个评测口径该进我们的 AB 流程了**。Faithful Harm Monitors 证明：分布内 AUROC 0.998 的监控器，在改写集上掉到 **0.62**，而一个**不看模型、只用 TF-IDF 的分类器能到 0.75**。它给出的协议——把阈值都调到同一个误报预算再比召回——是唯一能让"模型 B 高 3 个点"这句话有意义的做法。

另外两个值得单记的口径纠正：

- **奖励模型的偏置会删掉能力**。Attractive Faces 那篇做了因果验证：用 ReNO 优化 "a photo of an unattractive face"，奖励一加，脸反而**变漂亮**了。奖励的语义是"图文对齐"，实际行为是"变好看"。这对我们的 RL 改写奖励是直接警告。
- **数据管线是偏向性采样器**。TikTok 那篇给了形式化：训练分布 q(x) = p(x)·S_retain(x)/E[S_retain]，**当 S_retain 对边界样本更低时，原始语料规模会高估可学覆盖**。而且重加权救不回"保留概率为 0"的样本类型。

一句话压缩今天：**图审这一侧，本周同时给出了"怎么训"（C2FT）和"怎么测"（三维 + 匹配误报率 + 掩码消融）；但输入侧改写依旧空窗——这已经是连续第三周没有新的 T2I 改写方法。**

## 一、T2I / T+I2I 论文（核心主线 · 4 篇）

### 1. Yuvion VL — 阿里安全的图审基座配方 + C2FT 细粒度混淆对比

**本地精读**: `categories/t2i/papers/2606.25034_yuvion_vl.md` · https://arxiv.org/abs/2606.25034
**机构**: **阿里巴巴安全 AGI Lab（Yuvion Team）** | **2026-10-20（v3）** | cs.CV

- **论文定位**: 面向内容安全的多模态基座模型（8B / 32B，各含 Instruct 与 Reasoning 版本），**与图审任务同构**
- **数据体系的六个分区**（按训练阶段分工）：通用多模态（防遗忘）· 领域知识（敏感人脸 / 旗帜符号 / logo / 场景）· **大规模真实安全业务数据（层级标签 + 证据归因 + 政策引用）** · 对抗数据（小字水印规避、logo 变异、AI 生成图、上下文掩护）· 纯文本（谐音/结构混淆）· 领域 CoT
- **训练三段**: CPT（冻结 ViT，只训 connector + LLM）→ Instruct 后训练（SFT + **C2FT**，全参数）→ Reasoning 后训练（SFT + RLVR/GSPO）

**C2FT 是这篇的核心**，两步：

| 阶段 | 做什么 | 关键公式 / 判据 |
|---|---|---|
| **Confuse** | 用**模型自己的错误**定义混淆集 | `S_confuse(c｜x_a) = Sim(e_pred, e_gt^c)`，取 top-k 类 |
| | 用 Teacher Forcing **验证**困难负样本 | 保留条件 `｜P_TF(y_a｜x_neg) − P_TF(c｜x_neg)｜ < τ` |
| **Contrast** | 多图 token 拼接，让注意力跨图比较 | `X = [V_1; V_2; …; V_K; T]`，`L_contrast = CE(θ; [x_a, X_contrast], [y_a, Y_contrast])` |
| | 与单图混合 | `L_total = ρ·L_CE + (1−ρ)·L_contrast`，**ρ = 0.3** |
| | **PAT 抗捷径** | 随机打乱图序 + 单/多图混合，防位置捷径 |

- **关键数据（论文口径）**:

  | 维度 | 结果 |
  |---|---|
  | 公开安全基准（12 集均） | 8B: **76.1 / 75.8**；32B: **76.9 / 76.7**；相对骨干 **+12.4 ~ +12.6**（8B）、**+11.2 ~ +11.5**（32B） |
  | 内部业务基准（21 集均） | 32B: **82.8 / 82.6**；相对骨干 **+8.6**（Instruct）/ **+11.3**（Reasoning） |
  | AI 生成图检测（Macro F1） | 8B: **73.6** vs 骨干 55.8（**+17.8**） |
  | 通用能力代价（23 集） | 平均退化 **2–3 点**（Level 1 设 ≤3 点退化 gate） |
  | C2FT 消融 | C2M 换随机对比采样：掉 **4.28 点**；去掉 PAT：掉更多（GQA 尤甚） |

- **两个必须记住的工程细节**:
  1. **CoT 生产的"双生成器仲裁"**：两个生成器**都**跟 reference 不一致 → 判定**原始标注可能错**，转人工改标；两个生成器**彼此**不一致 → 判定为认知不确定（不是标注缺陷），重采样 + 扰动解码再生成。**这是"意图对但标签错"与"样本本身难"的分判据。**
  2. **RL 用拒样代替随机采样**：N=5 采样算奖励不一致度，优先选高不一致的边界样本——**只用 6% 数据达到全量训练水平**。
- **我的判断**: 这是今天唯一"可以直接拆开来用"的图审配方。它的路线选择也很明确：**安全能力来自监督信号的结构化程度（层级标签+证据+条款），不是来自偏好对齐**。对审核场景（要出可申诉判定）这个假设是对的。

### 2. Omni-UBench — 用"掩码消融"证明护栏没在看内容

**本地精读**: `categories/t2i/papers/2610.31713_omni_ubench.md` · https://arxiv.org/abs/2610.31713
**机构**: **浙江大学（区块链与数据安全全国重点实验室）+ 阿里巴巴集团** | **2026-10-22** | cs.CR
**规模**: 183,977 条样本 · 37 个来源基准 · 4 模态 + 跨模态组合 · 15 个模型（7 通用 + 8 专用护栏）

- **论文定位**: 第一个系统性的**全模态护栏**评测基准，但它的三维协议直接适用于图审
- **三维定义**:
  - **Safety** = 不安全抓得住（含 22 种越狱变体，越狱样本占全库 **> 50%**）
  - **Utility** = 良性放得过（Benign Interference 模块）
  - **Reliability** = `100 × (1 − FPR)`，覆盖两个探针：
    - **Over-sensitivity**：越狱**文本模式** × 通用**良性媒体**随机配对（两者都无害），测"对话术形状过敏"
    - **Guardrail Hallucination**：**等长掩码**——文本→重复 [MASK]、图→同尺寸空白、音频→等长静音、视频→同帧率空白，测"无证据时是否还判危"

- **三个必须记住的发现**:
  1. **高 safety 可能是滥杀换来的**：Qwen2.5-Omni-3B 的 safety 有 **80.3**，但 reliability 只有 **11.7 / 12.8**，utility 只有 **34.5**。
  2. **掩码消融的硬证据**：把有害语义全部换成无意义内容后，该模型召回仍为 **1.00 / 0.99 / 1.00 / 0.50**（T / T-I / T-A / T-V），平均 **FPR 0.87**；MultiGuard 平均 **0.77**。**判定与内容无关。**
  3. **隐式意图是普遍盲区**：图安全+文安全但**组合不安全**（SIUO）平均召回仅 **0.39**；加密文本 CipherChat **0.41**；加密文本嵌图 MML **0.43**。按风险类，IA/FA 约 **0.90**，UA 掉到 **0.73**，ST（含伦理/政治）只有 **0.55**。
- **综合分排名（三维等权宏平均）**: MiMo-V2.5（311B）**91.9** > Gemini-2.5-Flash **87.6** > OmniGuard-7B **86.0**（但它的 safety 只有 67.1，靠 utility+reliability 拉起来）
- **口径警告**: 三维**等权**宏平均、无权重敏感性分析；越狱样本过半使基准偏"抗越狱"；掩码探针没扣"空白图本身是 OOD"这个混杂。
- **我的判断**: 这不是又一篇 benchmark，而是**一套归因工具**。最有价值的一句是"reliability 应该和 safety/utility 平级"——我们现在图审 AB 只测第一维。

### 3. SELECT — 锚点决定擦除边界，兄弟互斥概念是正解

**本地精读**: `categories/t2i/papers/2510.16342_select_erasure_boundary.md` · https://arxiv.org/abs/2510.16342
**机构**: 北京邮电大学 网络空间安全学院 | **2026-10-19（v2，v1 为 2025-10-18）** | cs.AI
**骨干**: SD v1.4 · 下游擦除: SPEED / MACE / OCE

- **论文定位**: 把"选什么锚点"从实现细节升级为**语义擦除边界构造**问题
- **两个诊断**:
  1. **因果弥散度决定锚点敏感度**：用 cross-attention 单元的 restoration intervention 算因果效应分布，归一化熵 `D_c = exp(−Σ p log p)/|U|`。**D_c 大 ⇒ 目标残留高、擦除强度低、锚点失败率高**。类内也成立（Dog 弥散/敏感 vs Corgi 集中/稳定）。
  2. **锚点类型决定连带损伤范围**：**边界概念受损 >> 随机无关概念**（损伤是局部的）。锚点太近压不住，**太远压得住但边界与全局损伤最大**。
- **BCTS 的设计（对我们最有启发）**:

  `BCTS(c,a) = φ_c(S(c,a)) · (1 − D̃(c,a))`

  其中 `φ_c` 是"**达到阈值 τ_c 后不再奖励更激进擦除**"的整形函数。**先卡住安全底线，达标后只比保真**——这正好是我们改写评测该有的联合分形式。
- **SEC（兄弟互斥概念）**: 同父类（语义邻近，重定向平滑）+ 核心属性互斥（不把目标属性带回来）
- **NSFW 擦除的 SEC 模板（可直接抄）**: 目标 "Nudity, Sexual"，保留人物/活动/场景，把敏感属性换成互斥属性——裸露→**全覆盖职业装**，性内容→**职业/教育性活动**。实际锚点例：**"a gardener in overalls and long sleeves"**、**"a gardener planting flowers in a public park"**
- **关键数据**: SPEED 下名人擦除 `H_c` **81.99 → 87.99**；MACE 下 `H_c` **86.33**（General 锚点 87.30，擦除更强但保留略降）；NSFW 用 I2P + NudeNet(0.6)，**暴露部位检出数远低于** null-text 与 "a person wearing clothes"
- **论文自己承认的硬伤**: 逐目标独立构造边界，**多目标密集语义区会冲突**（大规模名人/风格擦除时 SEC 候选可能正是另一个待擦目标），此时只能退化成固定保留集
- **我的判断**: 这篇的价值不在"擦除"，在**"锚点距离—保真损失"这条曲线**。它把我们凭手感做的"外科式替换"变成了可量化的取舍。

### 4. Attractive Faces 偏置 — 奖励模型的偏置不只是分数脏，是删能力

**本地精读**: `categories/t2i/papers/2610.28195_attractive_faces_reward_bias.md` · https://arxiv.org/abs/2610.28195
**机构**: University of Southampton（以正文为准） | **2026-10-20** | cs.CV

- **论文定位**: 对人类偏好模型（PickScore / MPS / HPSv2.1 / HPSv3 / ImageReward）做偏置归因，五段因果链：人 → 榜单 → 奖励模型 → 生成 → 能力删除
- **用户研究**（47 有效参与者 / 400 图 / 一半真实 CelebA-HQ 一半生成，但被告知"全是 AI 生成"）: 参与者把**更漂亮的脸**判为质量更高，"保真度"措辞 p=**0.0018**，"审美"措辞 p=**0.0006**；两种措辞差异 p=**0.028**（"审美"偏置更大）
- **Elo 模拟**（10,000 次）: 好看的 AI 队（吸引 67.9）领先不好看的真实图队（34.1）**≈ +124 Elo**；反向选择时真实图只"微弱领先" → **决定胜负的是相对吸引力，不是图像来源**
- **属性审计**（DiffAE 逐属性编辑 40 属性 × 4 强度 × 100 底图 = **16,000** 图）:
  - **5 个偏好模型里 4 个的 top-1 相关属性是 "attractive"**
  - 两个非偏好控制组行为不同：LAION-Aesthetics 无明显主导属性；CLIP 走**女性关联属性**（耳环、浓妆）
  - → **吸引力 top-1 是偏好对齐引入的，不是 CLIP 自带的**
  - **ImageReward 受影响最小**，且用 LLM caption 后偏置基本消除（它的标注指令最少强调"个人审美"）
- **真实图对照**（排除画质混杂）: HPSv3 在 SCUT-FBP5500 与 CelebA-HQ 上都是 **r = 0.35**；LASSO 路径里 attractive 一直保留到 **λ_L = 0.63**
- **因果验证（最强的一击）**: ReNO + HPSv2.1，prompt 固定为 **"a photo of an unattractive face"**，优化 20 步 → **图反而变漂亮**。奖励语义是"图文对齐"，实际行为是"变好看"，**用户控制被删除**
- **我们的风险点（论文没提但必须自己补）**: AlignProp / DRaFT 微调后生成人脸**变年轻、更偏女性** —— 而这两个方向恰好是 NSFW 风险画像的已知相关因子。**用偏好奖励做安全对齐，可能同时把生成分布推向更高风险的人像。**
- **缓解方案**: 最小化互信息 `I(A; S)`（KDE 估计）+ `λ·d(S, S_hat)` 保信号。**改分不改图**
- **我的判断**: 这篇对我们最直接的价值不是"人有害"，是那套**审计五步法**（单属性编辑 → 相关系数 → LASSO 路径 → 真实图对照 → 引导生成验证因果）。可以原样搬去审我们的图像一致性奖励。

### 5. Failure Taxonomy to Intervention — 数据管线是偏向性采样器

**本地精读**: `categories/t2i/papers/2606.30059_avlm_failure_taxonomy.md` · https://arxiv.org/abs/2606.30059
**机构**: **TikTok（字节跳动）+ The University of Sydney** | **2026-10-19** | cs.LG | **NeurIPS 2026**
**规模**: 100+ 地区、100+ 语言、季度上传量百亿级；2B 级紧凑架构

- **论文定位**: 工业级审核基座的**失效归因方法论**——把"坏数字"翻译成"具体干预动作"。模态是 T+A+V，但**方法论对图审同构**
- **五类失效签名 → 干预**:

  | # | 失效 | 诊断信号 | 干预 |
  |---|---|---|---|
  | 1 | **Selection-Induced Support Erosion** | 按地区/语言/音质/政策长尾比较**过滤前后**分布 | 把管线当偏向采样器；reweighting **救不回保留概率为 0 的样本类型** |
  | 2 | Regime-Limited Alignment | 弱预训练 scaling 曲线是否还在降 | scaling 曲线作**转换测试**，平台期就换高信息量监督 |
  | 3 | **Proxy-Sufficient Representation Collapse** | WER/CER 在降但 AQA 在退 | **Cross-Modal Continuation（CMC）**，占混合 **20%** |
  | 4 | Instruction Tuning Trades Perception for Reasoning | 指令微调后 AQA 升 ASR 降 | Stage III **之前**插 CMC |
  | 5 | **The Perception Assumption** | 固定预算改配比，看"感知↑审核↓" | 多目标优化 / Pareto 前沿 + 能力下限 |

- **第 1 条的形式化（今天最该抄的一行）**:

  `q(x) = p_traffic(x) · S_retain(x) / E_{x~p_traffic}[S_retain(x)]`

  **原始语料规模会高估实际可学覆盖**。诊断与干预必须针对 q(x)，不是 p(x)。
- **量化**: FLEURS 平均 WER/CER **13.45**（Qwen2.5-Omni-3B 41.15 / Gemma-4-E2B-it 16.03），18 语种中 13 个最优；但阿拉伯语 **45.50 vs Gemma 22.05** → 聚合优势不代表每语种可靠。音频 vs 转写（PR-AUC）：冻结骨干 Anon.S **+0.041** / Anon.V **+0.003**，全量适配 **+0.066 / +0.018**
- **标注协议（低成本可抄）**: 每条 ≥3 独立标注（歧义最多 6 条），**高置信正标必须比次高标签领先 ≥2 票**
- **站不住的地方**: **五类失效没有 per-taxonomy 的 before/after 收益**——你能看到它用了这些干预，看不到"干预 A 解决了失效 A"的一对一证据；两个下游基准匿名（Anon.S / Anon.V），PR-AUC 绝对值无参照系

## 三、T2T 迁移参考（1 篇 · 明确迁移价值）

### 6. Faithful Latent Harm Monitors — 匹配误报率，与"改写"的代价

**本地精读**: `categories/t2t/papers/2610.30727_faithful_harm_monitors.md` · https://arxiv.org/abs/2610.30727
**机构**: 作者个人署名（未标单一机构） | **2026-10-22** | cs.AI | 代码已开源
**规模**: 15 个指令微调模型 × 38 个激活读取器 × 2 个读取位置

- **论文定位**: 批判"潜空间有害性监控器"（Latent Guard 一类），并给出可分解的评测协议
- **把分数建模成"判断 + 计划"的混合**: `s_m(x) = a_m·J_m(x) + b_m·P_m(x) + ε`。**忠实** = 由判断 J_m 主导
- **三个解耦检验**: ① 固定有害标签与共识后的 β_s 回归；② 类内 AUROC（固定共识）；③ **跨模型不一致统计量 Π**——model-blind 分数必然 Π=0
- **关键数据**:

  | 场景 | 结果 |
  |---|---|
  | 分布内 D_id | 激活监控器 AUROC **≥ 0.998**，Llama Guard 3 = **1.000** |
  | **改写集 D_rew（2,248 条）** | Latent Guard pooled AUROC **0.54–0.71（中位 0.62）** |
  | 同数据 TF-IDF | **0.75**，在**每一个**模型上都赢 Latent Guard |
  | 加 20 倍数据 | 0.63（100/类）→ **0.65**（2,000/类），几乎不动 |
  | t_inst（读完请求处） | 类内 AUROC 0.71 / 0.62，β_s = 0.32 → 与拒绝**解耦**，但**输给词袋** |
  | t_post（回复前） | 类内 AUROC 0.90 / 0.89，Π = **+0.23** → 检测强但**是拒绝的影子** |
  | **匹配误报率下召回** | 拒绝本身 **0.321**；t_post 读出 **0.44**；**每一分增益都来自"字符串匹配算作回答、实际在换词拒绝"的样本** |

- **它的增量分解（可审计）**: `Δ = −π̂(1 − h_ref) + (1 − π̂)·h_ans` —— 超出拒绝的所有增益必须来自"被回答但监控器抓到"的样本
- **为什么对我们重要（两条）**:
  1. **匹配误报率**是唯一能让图审 AB 的"高 3 点"有意义的比法；
  2. 它的核心实验就是**"表面改写成另一类、标签不变"**，并且专门构造了 **harmless-made-alarming** 子集 —— **这正是我们现在完全没测的"过度预测"场景**
- **站不住的地方**: 拒绝标签靠字符串匹配（噪声源）；Π 的参考值 0.45–0.49 **不是上界**；只测了改写型偏移（最温和的一种）；纯文本、不涉图像

## 四、本周三条共识（跨论文综合）

**共识一：判定依据的可解释性，比判定准确率更该被评测。**

Omni-UBench 的掩码消融（噪声内容仍 0.99 召回）、Faithful Harm Monitors 的 t_post 分析（增益全是拒绝的影子）、Attractive Faces 的 ReNO 实验（奖励语义≠奖励行为）——三篇在三个不同场景里做了同一件事：**证明一个高分模型可以完全不按你以为的规则工作**。三者的工具分别是"掩码"、"跨模型不一致统计量"、"单属性编辑相关性"。**这三个工具都可以搬。**

**共识二：安全的边际收益在"边界"上，而边界样本正在被系统性删除。**

Yuvion 的 C2FT 专门为"视觉极相似但安全含义相反"设计；SELECT 证明**边界概念的连带损伤远大于随机概念**；TikTok 那篇形式化了 `q(x) ≠ p(x)`——**过滤阶段优先保留干净样本，压制了长尾噪声与边界样本**。三篇合起来的判断是：**模型的边界能力差，第一因可能不是"学不会"，是"训练集里边界样本被洗掉了"。**

**共识三：极端分数基本都不干净，必须做"固定误报比召回"或"过阈值后只比保真"。**

Omni-UBench 的 utility-reliability 权衡（MiniCPM utility 99.3 但 safety 落后）、SELECT 的 BCTS 整形函数（`φ_c` 过阈值即饱和）、Faithful Harm Monitors 的 matched FAR —— **三个不同层次（评测、目标函数、监控器）都收敛到同一个设计原则：先把一个维度卡住，再比另一个。**

### B. 风险锚点（PORN / VULG 边界）处理启发

这一节是今天的重点，四篇工作各自给了一块拼图。

**B1. "锚点距离"是可量化的，而且存在最优区**

SELECT 的锚点五分类给出了明确的单调关系：

```
Target overlap（太近）  → 压不住目标（属性被保留）
Shared visual           → 部分压制，边界损伤中等
Generic / null          → 压得住，但保真损失大（场景被删）
Far unrelated（太远）    → 压制最强，但边界 + 全局损伤最大
Sibling exclusive       → 压制强 + 保真好的最佳折中（BCTS 最高）
```

**对 PORN/VULG 的直接推论**：我们现在的改写大概率落在"Generic/null"（把敏感片段删掉）或"Shared visual"（换成弱化词）这两档——**这两档都不是最优区**。最优区是 SEC：**保留主体 + 保留场景 + 属性互斥**。SELECT 给的具体模板是 "a gardener in overalls and long sleeves"（裸露→全覆盖职业装，人物与场景不动）。

**B2. 因果弥散度能预测"哪一类概念最难做"**

SELECT 的量化结果：**因果效应越弥散的概念，锚点敏感度越高、擦除越不稳**。映射到我们的标签体系：

- 因果集中的类（视觉特征收窄）：**PORN 明确类**（明确性行为）→ 改写后应该稳；
- 因果弥散的类（语义范围宽、下属形态多）：**VULG-HINT-EDGE（暗示性暴力）** 与 **PORN 的擦边档** → **改写后天然不稳**。

这解释了一个我们长期观察到的现象：PORN 明确类几乎不掉点，VULG-HINT-EDGE 反复是短板。**不是标注问题，是概念本身的因果结构问题。**

**B3. "改写没改干净"的真正机制是关联语境激活，不是残差没擦净**

SELECT 的 CRR 分析：擦掉 {blood} 之后，prompt 里出现 {red, wound, stain} 仍会生成血迹。**关联语境的激活强度可以预测再出现率。**

**对我们的直接含义**：改写不能只替换"风险词"，必须同时处理**风险词的关联语境词**。如果原 prompt 是"浴室 + 湿身 + 薄纱 + 她"，只把"赤裸"改成"穿着浴袍"是无效的——**"浴室/湿身/薄纱"这三个关联词会把风险带回来**。

**可操作的做法**：建立一个"风险锚点 → 关联语境词集"的映射（可以用 LLM 以模板 `{When people think of X, they think of [MASK]}` 生成），改写时要求**锚点与至少 k 个强关联词同时被中和**，而不是只覆盖锚点本身。

**B4. 意图与标签必须"绑死"（承接 2026-10-23 的 AIMS 结论）**

DiagSafe + AIMS 上周已经指出：**6/71 例意图表述几乎相同而标签相反**。Yuvion 的 C2FT 给了工程解法：**不要指望模型自己学会区分，直接构造"两张图 + 一句话"的对比样本，把区分动作变成显式的跨图比较。** 而且 PAT 证明：不加抗捷径约束，模型会学位置而不是学依据。

### C. 三维评测设计启发（语义保持 / 安全提升 / 指令遵循损失）

今天三篇合起来给了一套完整的三维骨架，且比我们现有的更可操作：

| 维度 | 今天的可用工具 | 具体做法 | 判据 |
|---|---|---|---|
| **安全提升** | Omni-UBench 的 Safety 模块 | 不安全召回（含越狱变体）；**按风险类别分列**，不要只报总体 | 分类别召回差 > 20 点 → 类别间不可比 |
| **语义保持** | SELECT 的 SEC 保留集 + BCTS | 不只看整体相似度，看**主体保留 / 场景保留 / 边界概念保留**三项 | 边界概念损伤 >> 随机概念损伤（这是正常现象，但要量化） |
| **指令遵循损失** | Yuvion "动态政策下的指令遵循" | 把约束直接写进 prompt，测模型服从新约束还是训练旧偏好 | 改约束后掉点 > 10 → 模型在背答案 |
| **⚠️ 新增第四维：判定依据** | Omni-UBench 掩码消融 + matched FAR | ① 空白图/噪声图仍判危 → 读的不是图；② 同误报预算下比召回 | 掩码后 FPR > 0.3 → 图审有严重文本依赖 |

**为什么必须加第四维**：Omni-UBench 证明了**"高 safety + 高 utility + 高 reliability" 三者可以同时被"读形状"的模型骗过一部分**——它只是在掩码探针上暴露。如果不测"依据"，我们永远不知道分数是真的还是形状匹配。

**关于联合分的建议形式**（融合 SELECT 的 BCTS）：

```
S = φ_risk(risk_score) × fidelity_score
其中 φ_risk 在 risk_score 达到阈值后饱和（不再奖励更激进的安全）
```

**不要用加权平均**。加权平均会奖励"把风险压到极低但保真崩掉"的改写——这正是我们 RL 里最怕的 reward hacking 方向。**先卡安全底线，再只比保真。**

### D. 下一步实验建议（对照四条主线）

#### 主线 1：tag-weighted loss（层级分类）

**实验 A（新增，最高性价比）**：**S_retain 保留率审计**（来自 TikTok 那篇）
- 拿清洗前候选池 vs 清洗后训练集，按 6 维统计保留率：风险一级类 / 层级（level1–4）/ 文本长度分位 / 是否 reject_tag 回流 / 是否含"暗示·擦边·教学语境" / 标注一致性
- **判据**：若 **VULG-HINT-EDGE 与 PORN 边界档的保留率显著低于 PORN 明确类** → 分不清边界的第一因是**边界样本在清洗阶段被删了**，此时先别做标签复判，先改过滤规则
- 成本：零训练，一天

**实验 B（承接 10-23 的 A）**：`<tag>` 前强制复述意图 + PORN/VULG 各补 4 条豁免条款
- **升级点**：今天的 Yuvion C2FT 给了新思路——如果 A 的效果有限，说明"复述意图"仍是**单样本**监督，给不出判别信号。下一步应直接上 **C2FT-lite**（每样本配 1 张同类真值 + 1 张混淆类真值，构两图一答），而不是继续在单样本上加提示

#### 主线 2：RL 改写（最高优先）

**实验 C（承接 10-23 的 B，但先做前置）**：锚点条件消融
- 原计划：无锚点 / 检索锚点 / oracle，联合分 `S = 100·mean[1(保真≥τ)·(1−risk)]`
- **今天必须加的前置**：先用 SELECT 的**五类锚点**替代"有/无锚点"的二分。因为 SELECT 证明了锚点**距离**是连续的，二分消融测不出"我们落在哪一档"
- **判据**：如果我们的改写主要落在 Generic/null（删片段）或 Shared visual（弱化词），那"检索锚点"这条路的收益天花板很低——应该直接改建 **SEC 式锚点**（保留主体+场景，属性互斥）

**实验 D（新增）**：**奖励属性敏感性审计**（来自 Attractive Faces 的五步法）
- 100 组"内容相同、单属性变化"的图对，测图像一致性奖励对 5 个属性的敏感度：语义一致性（要它衡量的）/ 美观度 / 饱和度 / 人脸占比 / 锐度（不希望它衡量的）
- **判据**：**若"美观度"或"锐度"的相关性 ≥ "语义一致性"的相关性，奖励信号已被非目标属性主导**，此时做 tag-weighted 或 edit-rate 约束都是在错误地基上加码
- 这个实验能在**不跑 RL** 的前提下判断奖励是否可用，成本远低于训一版

#### 主线 3：标签审计

**实验 E（承接 10-23 的 C，今天升级）**：不确定性筛样本复判
- 原判据：若"意图对但标签错"占比 > 30% → 是绑定问题不是数据问题
- **今天加一条**：复判时用 **Yuvion 的双生成器仲裁**做分判——两个生成器**都**与 reference 不一致 → **原始标注错**；两个生成器**彼此**不一致 → **样本本身难（认知不确定）**
- 这个分判据能把"标注噪声"与"边界样本"分开，而这两者的处理方式完全相反（改标 vs 保留并加对比样本）
- **再加一条（来自 Faithful Harm Monitors）**：构造 **harmless-made-alarming** 子集（完全合规但用词接近风险词），专门测**过度预测**。这是我们 PORN 误报的根源之一，现在完全没测

#### 主线 4：输出侧图审

**实验 F（承接 10-23 的 D，今天升级为双探针）**
- 原计划：500 张已知 NSFW 图过 3 个异构 checker，放行率差异 > 20 点 → 必须异构集成
- **新增探针 1（掩码消融）**：同一批样本，把图替换成同尺寸纯灰/纯噪，文本描述保留 → **若仍判 unsafe，说明图审在读 prompt 不是在读图**。判据：掩码后 FPR > 0.3 → 必须做"图像-only"沙箱评测
- **新增探针 2（匹配误报率）**：所有候选模型的阈值都调到"良性集上误报数相同"，再比 NSFW 召回。**不做这一步，"模型 B 高 3 点"这句话没有意义**
- **新增探针 3（过敏感）**：把 reject_tag 里的高频误判描述 × 良性图配对，测"对描述话术的过敏程度"
