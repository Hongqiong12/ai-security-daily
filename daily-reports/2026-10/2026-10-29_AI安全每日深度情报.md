而今天这批论文的价值不在"补上了空窗"，在于它们从六个完全不同的位置，指出了**同一类错误的六个具体坐标**。

**上周的结论是"机制装错了位置"；这周更糟一层——我们一直把六个"实际是变量"的东西，当成常数在用。**

1. **VLM 拒答（IIT Hyderabad）证明"指令措辞"不是常数。** 同一批样本、同一个模型，只换同义话术，总拒答率变 **18.4–45.2 个百分点**；只换指令位置，InternVL **掉 7.6–8.1 点**而 Qwen **涨 14.9 点——方向相反**。更狠的是：一个**故意错配**的安全指令几乎无效（−2.3 到 +13.2，一半区间含 0）——所以"加了安全指令"和"按安全语义判"是两件事。

2. **AK_QMUL（QMUL）证明"总体分数"不是常数尺度。** 总体 macro-F1 **0.79** 看着能用，切开一看：**MSA 切片 0.70，方言切片 0.88–0.95**；最难类 `Bully` 总体 **0.57**，但在方言上 0.81–0.97、**唯独 MSA 上 0.46**。**最难的永远是最规范的那一档，聚合分永远把它藏起来。** 而它那张三行消融表更值钱：标签因子化 **+0.001**，去掉长尾补数据 **−0.360**。

3. **MoI-Bench（UCL 等）证明"聚合方式"不是中性的。** 它把编辑任务拆成**16 操作 × 8 目标**的稀疏矩阵（64 子任务 / 1150 样本），判据用**加权几何平均**而不是算术平均，理由直给：**限制某一判据的高分去补偿另一判据的低分**。还有一条纪律：**能力缺失记 0 分且不移除样本**。

4. **DICE（Tel Aviv，S&P'27）证明"推理步数"不是常数。** FLUX Dev 从 50 步降到 8 步，图与"nudity"概念的 CLIP 相似度涨 **约 9%**；降到 16 步，已防御模型的 NudeNet 不安全率平均 **涨 10%**。⇒ **"降步数省算力"本身就是一次安全回退，而它不会出现在任何安全评审里。**

5. **LoRA 溯源（Edinburgh + Oxford）证明"溯源能不能成立"取决于分布接近度这个前提。** 五个 LoRA 域里 **Food101 失败**（与底模太像）。而"有监督归因"在闭集上 AUROC **1.000**、在开放世界留一域上崩到 **0.400**（比随机还差）。

6. **StruPO（浙大 + 腾讯 AI Lab）证明"动作空间"不是实现细节。** 把局部编辑（删除/重排/插入）换成自由生成，**图条件、结构化奖励、GRPO 全保留**，结构一致性 SGR 依然掉 **7.06**。⇒ **保真不是靠奖励逼出来的，动作空间本身就是一种保真机制。**

一句压一句：**这六篇分别说，指令措辞、总体分数、聚合方式、推理步数、分布接近度、动作空间——这六个我们默认"固定"的东西，每一个都在被测量之外悄悄改变结论。**

**本周必须记的一个事实（对我们最重要）**：StruPO 是**腾讯 AI Lab 参与**的工作，方向是"改写要保住什么"——但它保的是**物体与关系**，奖励里**没有安全维度**。这和上周 Qwen-Image-PE 的结论拼起来看：**头部公司在 T2I 输入侧改写上公开发表的，全是 enhancement / fidelity，没有一篇是 safety。连续两周，两个大厂，同一个空白。**

## 一、T2I / T+I2I 论文（核心主线 · 4 篇）

### 1. StruPO — 把"改写要保留什么"变成可训练的结构约束，且动作空间本身在保真

**本地精读**: `categories/t2i/papers/2610.36146_strupo.md` · https://arxiv.org/abs/2610.36146
**机构**: **浙江大学 + 腾讯 AI Lab + 中国电信 AI**（HTML 无 affiliation，据 PDF 首页作者块确认）| **2026-10-26** | cs.AI

- **论文定位**: T2I 输入侧改写的**结构保真**方法。这是我们这条线上**最该抄方法学的一篇**。
- **核心设计（一句话）**：把**标定过的场景图**同时用在两个地方——**当条件**告诉策略"这些锚点不能动"，**当奖励**拿同一张图核"锚点还在不在"。同一个表示既是输入也是监督。
- **DSE 的非对称规则（直接可用）**：解析出的元素分 text-core 与 auxiliary；**auxiliary（风格/相机/介质类歧义词）需要视觉证据才留下，text-core（用户明确要的物体/关系）即使图里没画出来也强制保留**。一句话——**图只能否掉"你以为用户要的"，不能否掉"用户真要的"**。
- **动作空间**：改写被形式化成 **删除 → 重排 → 插入** 三个 token 对齐的原子操作（前两个非自回归，插入自回归）。作者自己的定性很克制：**这是朝向保守编辑的归纳偏置，不是保真的硬保证**。
- **关键数据（SD v1.5，Lexica/2K）**：RR（关系召回）**69.64**，比最好基线高 **7.96** 点；SGR **80.74**；AESΔ **+0.63**；Gemini-VQA **82.4**（最高）。跨主干不重训：FLUX.1-dev 上 RR **62.43** vs Promptist 53.41、AESΔ **+1.14**。
- **人类评测**：15 标注员 × 2K prompt，美学 $\kappa$=0.40、一致性 $\kappa$=0.43；一致性优势对三个基线分别 **+9 / +10 / +7** 点；**关系越多优势越大**（$|V_x|$ 1→≥3，+6→+16）。
- **最有信息量的负结果（消融）**：w/o DSE **−7.05**、w/o MHE **−5.41**、**w/o EAG（换自由生成，图条件+奖励+GRPO 全保留）−7.06**、w/o RL **−6.70**、w/o 结构化奖励 **−5.60**。
- **我的判断**: 这篇的真正贡献不是"又一个 prompt 优化器"，而是**用消融把"保真"这件事分解成了三个独立可验证的来源**：结构表示（−7.05）、编码通路（−5.41）、**动作空间（−7.06）**。第三个最反直觉也最有用——**这说明我们做安全改写时如果放开自由生成、只靠奖励约束，即使奖励完全正确，也会掉 7 个点。**
- **边界很清楚**：计数、遮挡、否定、情绪、隐喻、抽象意图**全在它的表示之外**——而这恰好是 PORN/VULG 边界的主战场。

### 2. DICE — 加速是一个隐性安全旋钮，少步蒸馏把擦除方向转掉了

**本地精读**: `categories/t2i/papers/2610.36665_dice_fewstep_safety.md` · https://arxiv.org/abs/2610.36665
**机构**: **Tel Aviv University**（**IEEE S&P 2027** 接收）| **2026-10-27** | cs.CV / cs.CR

- **论文定位**: T2I **权重侧**概念擦除在少步蒸馏模型上的失效机制 + 修法。**给我们"输入侧改写"这条主张提供了最强的对照证据。**
- **现象一：学生比教师更不安全**。SD3.5 Large → Turbo，NudeNet **0.2432 → 0.3232**（相对 +33%），SD-Checker **0.5416 → 0.6646**；FLUX Dev → SCFM，**0.2562 → 0.3282** / **0.6108 → 0.7074**。**@5 指标下差距依然存在**——加速不只抬平均，还让"至少一次出问题"更可能。
- **现象二：步数是安全旋钮**。FLUX Dev 50→8 步，与 "nudity" 的 CLIP 相似度 **0.239 → 0.261（+9%）**；SD3.5 Turbo 8→1 步 **0.231 → 0.248（+7%）**。降到 16 步时**已擦除模型**的 NudeNet 平均 **+10%**。⇒ **降低步数是一次安全回退，且对已防御模型一样生效。**
- **机制诊断（三路独立证据指向同一原因）**：
  1. 少步模型速度场**更敏感**：配对 Lipschitz 比 FLUX Schnell/Dev = **4.78（z）/ 4.37（θ）**，SD3.5 Turbo/Large = **1.81 / 2.32**；轻蒸馏 SCFM 只有 1.01 / 1.07。且**高噪声端最敏感**，与全步模型趋势相反。
  2. 擦除方向**被旋转且被放大**：与教师方向的余弦只有 **0.30（SD3.5 Turbo）/ 0.07（FLUX Schnell）**，幅值膨胀 1.2–5×；**四个速度场范数相近 ⇒ 膨胀来自"抵消变差"，不是"预测变大"**。
  3. **CFG 烘焙是主因**：FLUX Dev 提高 guidance 1.0→3.5，$\|\delta\|$ 从 17.8 → 64.1（约 3.6×）。
- **方法 DICE**：$\mathcal{L} = \mathcal{L}_{\text{esd}} + \lambda_1\mathcal{L}_{\text{attn}} + \lambda_2\mathcal{L}_{\text{gen}}$，配两个改动——**直通路径重加噪**（$z = x_0 + \sigma_t(x_1 - x_0)$，$\sigma_t$ 均匀采，与推理调度解耦）+ **对擦除前 checkpoint 自蒸馏**（不用原始 FM 目标，因为那个目标在少步模型上初始就非零）。
- **关键数据**：SD3.5 Turbo 上 NudeNet **0.3232 → 0.0324**（既有最好 ESD 只能到 0.1504）；FLUX Schnell 上 **0.046**（既有方法 ≥0.161）；Ring-A-Bell 攻击下 FLUX Schnell **0.847 → 0.319**。
- **一个必读的反向消融**：FLUX SCFM 上去掉"直通路径重加噪"，NudeNet 反而更低（**0.0134 < 0.0526**）——**擦得更狠，但 HPSv2 也掉**。⇒ **单看安全率会得出反向结论，必须配质量指标读。**
- **我的判断**: 这篇给了"为什么必须做输入侧"最强的一条论据——**加速 → 方向退化（cos 0.07–0.30）→ 擦除失效**；而**输入侧改写不碰权重、不改 $v(z,c)$ 与 $v(z,\varnothing)$ 的抵消关系，因此不受这个失效模式影响**。同时它划出了输入侧的边界：**改写管不住已经生成出去的图，也管不住用户反复试探**（@5 指标正是这个）。

### 3. LoRA 溯源签名 — 只用出图的内在维度，黑盒判断"跑的是原模型还是被改过的 LoRA"

**本地精读**: `categories/t2i/papers/2610.36933_lora_provenance.md` · https://arxiv.org/abs/2610.36933
**机构**: **University of Edinburgh + University of Oxford** | **2026-10-27** | cs.LG

- **论文定位**: 开放世界下的**模型溯源**（IP 保护 + 问责）。**"输入侧改写不动权重"这条主张的合规侧配套证据。**
- **两个问题**：Problem I（负判别）——目标是不是"完全无关的模型"；Problem II（底模判别）——目标**就是**那个底模吗。**场景 II 正是我们最相关的：有人拿开源底模加 LoRA 做 NSFW，然后把责任推给底模方。**
- **方法桥**：白盒先证明 LoRA 对 score 场的扰动确实小于异族模型（Frobenius 余弦 + Gram 差）；黑盒化用**生成流形的局部内在维数直方图**（MADA 估计，$k$=50）当签名，再走假设检验（100 参考签名 + **2000 个零校准签名**，阈值 p < 0.001）。
- **关键数据**：Problem I **AUROC 0.855 / F1 0.800**；Problem II **AUROC 1.000 / F1 0.943**（开放世界 + 留一域）。
- **这张对比表最该读的是"错位"**：有监督归因（Nataraj19 / Wang20）Problem I **AUROC 1.000**，Problem II 崩到 **0.600**；频域方法 Giudice21 Problem II **AUROC 0.400——比随机猜还差**，因为频域特征**不能迁移到没见过的 LoRA 域**。
- **失效案例**：五个域里 **Food101 失败**（与底模分布太接近）。**作者没有给出"什么时候会失败"的先验判据**——这是方法可用性的最大缺口。
- **我的判断**: 这是一篇**边界比方法本身更有价值**的论文。它同时证明了"能检测"和"不比有监督归因更强"，真正的价值在开放世界的鲁棒性。对我们：**可以主动提供黑盒审计接口，把"我没改模型"从承诺变成可验证断言**；但 Food101 的失效提醒——**当适配域与底模太像时溯源会失效，而 NSFW 恰恰可能是那种"太像"的域**。

### 4. MoI-Bench — 用"操作 × 目标"二维矩阵拆评测，编辑任务的分数不该是一个标量

**本地精读**: `categories/t2i/papers/2610.37599_moi_bench.md` · https://arxiv.org/abs/2610.37599
**机构**: **UCL + 南京大学 + 香港理工大学 + 华东师范大学** | **2026-10-27** | cs.CV / cs.AI

- **论文定位**: 图像生成/编辑 benchmark 的**评测方法论**。**直接对齐我们 I2I 改写 0/0% 那个"没有可判的正例标准"的缺口。**
- **任务空间**：**16 个操作单元 × 8 类目标**，只取**适用组合**（不是机械笛卡尔积——`Addition × Body & Limbs` 被标 N/A，`Camera-view × Documents` 被改写成透视矫正）。最终 **64 子任务 / 1150 样本**。任务范围来自 **1000 人问卷**（最高频需求是人像修图、物体移除、照片修复、文字编辑）。
- **四条可直接抄的评测纪律**：
  1. **稀疏 rubric 立方体** $(o, t, c)$，每条目标 **always / sample-dependent / N/A** 三态；
  2. **条件先写后跑**——"完整/部分/失败"三档判据**在看不到模型输出之前**就构造好；
  3. **加权几何平均**聚合，明确理由是**限制跨判据补偿**（不能用一个维度的高分救另一个维度的低分）；
  4. **能力缺失记 0 且不移除样本**（生成专用模型因此落在 Q1，作者明说这是覆盖缺口不是质量差）。
- **双 judge 数据（AB 评测最该看的一组）**：总分排名 **Spearman ρ = 0.968**；人类与模型分 **ρ = 0.904**；**但作者自己写明"档位一致性不算独立验证"，因为阈值是用跨 judge 一致性反向校准的**。
- **一个反直觉结论**：Ovis-U1-3B 总分更高（0.66 vs 0.62），但 **DreamLite 的任务覆盖更高**（$C_{0.6}$：0.64 vs 0.59 / 0.42 vs 0.38）。⇒ **"平均质量"与"过的任务数"必须一起看。**
- **定性上区分了两种失败**：DreamLite 在"改成头像"指令下**保留了全身构图**（没听指令）；Ovis-U1 给出了要求取景**但改了人的外观**（听了指令没保身份）。**这正是 DP 两个子判据分别要抓的东西。**
- **我的判断**: 这篇的空白和它的贡献一样清楚——**三组判据（IF/VQ/DP）里没有"安全"，多语言只是零散案例**。所以它对我们的价值是**评测结构**，不是判据内容。四条纪律里，我们目前**一条都没完全做到**。

## 二、T2T 迁移参考（2 篇 · 明确迁移价值）

### 5. AK_QMUL @ ArGuard — 标签因子化只在长尾被补上时才成立

**本地精读**: `categories/t2t/papers/2610.36360_arguard_qlora_hier.md` · https://arxiv.org/abs/2610.36360
**机构**: **Queen Mary University of London**（ArabicNLP 2026 Shared Tasks / EMNLP 2026；ACL Anthology 已收录）| **2026-10-26** | cs.CL

- **论文定位**: 有害 prompt 二分类（B1）+ 七类危害域分类（B2），**单骨干、4-bit QLoRA、单卡可跑**。**这是最贴我们"6 节点缩到 5 节点"的成本参照。**
- **配方（全可搬）**：JAIS-6.7B + **4-bit NF4 双量化** + LoRA 全线性投影（$r$=16, $\alpha$=32）+ **last-token 线性头** + **类加权 CE（权重 = 逆类别频率）** + 分层分组 7 折 + 3 epochs / lr 1e-4 / max_len 192。
- **B1 结果**：macro-F1 **0.984**，赛道第一。方言细分准确率 93.6–99.8%，**预测不安全率紧密跟随真实率**（36.6→37.1、71.7→71.7、91.3→91.6）。
- **那张三行消融表（全文最重要）**：

  | 头 | AraSafe 增强 | macro-F1 |
  |---|---|---|
  | 2 类（safe/unsafe） | 有 | 0.983 |
  | 4 类（safety × register） | **无** | **0.624** |
  | 4 类（safety × register） | 有 | **0.984** |

  ⇒ **因子化净收益 +0.001（等于零）；但去掉长尾补数据，因子化直接崩 −0.360。** **"层级越细越好"是个未经验证的假设。**
- **B2 分层表（第二条硬信息）**：总体 macro-F1 **0.79**，但 **MSA 切片只有 0.70**（方言 0.88–0.95）；`adult_content` 聚在 **0.95–1.00**，`Bully` **0.57**、**在 MSA 上只有 0.46**（方言上 0.81–0.97）。作者原话：**"residual error concentrated in the Bully class, which overlaps semantically with harassment and harm-to-others"**。
- **迁移价值（三条，都已在我们主线上）**：
  1. **层级标签不要默认"越细越好"**——先把每个格子喂饱，再做联合头；
  2. **"最差类别"必须带切片报告**——总体 0.79 可以掩盖一个切片 0.46；
  3. **PORN 好判 / VULG-HINT-EDGE 难判不是训练量问题**——这篇用 6.7B + QLoRA + 类加权 + 5 种子，最好的类 0.98、重叠类 0.57，**差距是结构性的**。
- **一个额外的统计事实**：真实不安全率按方言极不均匀（**MSA 36.6% vs 方言 71.7–91.3%**）⇒ **"方言"与"不安全"在数据里高度相关，因子化有学成捷径的风险，而论文没做捷径诊断。**
- **不能迁的**：单骨干双赛道（我们多任务但任务不同）、192 序列长度（我们 prompt 更长）、B1 vs B2 不是纯消融（头、增强、种子数三个维度同时变）。

### 6. 视觉证据不足时的拒答 — "拒答率"是个被话术和位置污染的指标

**本地精读**: `categories/t2t/papers/2610.37430_vlm_refusal_instruction_sensitivity.md` · https://arxiv.org/abs/2610.37430
**机构**: **Indian Institute of Technology Hyderabad**（VLM4RWD workshop）| **2026-10-27** | cs.LG / cs.CV

- **论文定位**: MLLM 拒答行为的受控归因。**迁移价值：VLM-as-judge 图审的评测纪律 + "违规判定率不能当质量指标"的实证。**
- **设计上最聪明的一步**：四个策略条件里放了一个**故意错配的 C2（安全导向）**——被评问题**全是良性的**（视觉证据不足，不是有害请求），所以 C2 下出现拒答**只能说明安全策略外溢**。而 C2 也加了一段指令文本 ⇒ **C1/C3 相对 C2 的强效应，证明的是"策略语义在起作用"，不是"多加了提示词"**。
- **四类响应标签**：A（作答，**含带保留的答案与同时含拒答语言的回答**）/ $R_E$（证据型）/ $R_S$（安全型）/ $R_G$（通用型），外加**独立**的 mixed-response 指示。
- **关键数据（总拒答率变化，图像-问题对完全固定）**：
  - C1（证据型）与 C3（通用）在**全部 12 个模型×位置比较**里抬高 **18.4–45.2** 点，净证据型 +15.4–46.8；
  - **C2（安全错配）几乎无效**：**−2.3 到 +13.2**，六个区间里**三个含 0**；
  - **位置效应方向依模型而反**：C1 后置在 InternVL **−7.6 / −8.1**，在 Qwen **+14.9**；
  - **同一批样本的二元翻转率 13.9–32.1%**。
- **后训练那张表最该记的是方括号**（格式：C0/C1-prefix **[最大混合响应率]**）：
  - SFT 把拒答推到 **87.7–94.9% / 96.7–99.9%**，**但混合响应率同时升到 22.8–33.2%**；
  - **DPO 极不稳定**：InternVL-2B 上 C0 只有 40.4%，Qwen 上 88.7%；
  - SimPO 基本没用（20.0–38.9%，接近未修改）。
- **两个选择性控制都过了**：704 条良性描述请求**一条都没拒**（0/704 → 0/704）；MMMU 变化 **−2.15 到 +0.92**，全部含 0。
- **激活层**：21 个比较全正向（+1.1 到 +15.1，20/21 CI 不含 0），对随机/打乱方向额外 **+4.9–11.9**（12/12 不含 0），但转移里证据型只占 **42.6–81.6%**——作者自己说"**neither reason-pure nor monotonic**"。
- **迁移价值（三条）**：
  1. **图审 AB 评测必须冻结 prompt**——换同义话术能翻 18.4–45.2 点，我们两个模型走两套 prompt 的 AB 结论里混着 prompt 差异；
  2. **"违规率"必须配三样**：理由分类（是"内容违规"还是"我看不清"）、混合响应率、良性样本误拒率；
  3. **C2 的错配设计可搬到标签体系上**：给分类器"涉及 X 就标 X"的指令，但测试集**根本不含 X**，看它是否仍然大量标 X——**这与我们做过的"极性盲"检查是同一族诊断。**
- **不能迁的**：激活方向干预（我们做分类不是生成，没有"拒答"这个行为面）、C1 的措辞（是为"证据不足"设计的，不适用内容分级）。

## 三、本周三条共识（跨论文综合）

**共识一：所有"固定项"都在被测量之外改变结论，而且污染源可以被逐个定位。**

| 被当成常数的项 | 论文 | 它实际能变多少 |
|---|---|---|
| **指令措辞** | VLM 拒答 | 同义改写 → 18.4–45.2 点；样本翻转 13.9–32.1% |
| **指令位置** | VLM 拒答 | 前置/后置 → InternVL −8.1 vs Qwen +14.9（方向相反） |
| **总体分数** | AK_QMUL | 总体 0.79，MSA 切片 0.70、Bully@MSA 0.46 |
| **聚合方式** | MoI-Bench | 算术平均允许跨维补偿；几何平均下不许 |
| **推理步数** | DICE | 50→8 步，CLIP-概念相似度 +9%；16 步时已防御模型 +10% |
| **动作空间** | StruPO | 换自由生成，其他全保留，SGR −7.06 |

⇒ **这不是"又发现几个坑"，而是给出了六个可复用的自检点。** 任何一个"我们测得挺好"的结论，都该先过这六道关。

**共识二：`macro-F1` / `准确率` / `拒答率` 这类聚合量，系统性地偏袒"好判的那一档"。**

三篇独立工作的同一结论：
- AK_QMUL：总体 0.79 掩盖 MSA 0.70 与 `Bully`@MSA 0.46；
- MoI-Bench：单一总分掩盖"平均质量高但覆盖低"（Ovis-U1 vs DreamLite）；
- VLM 拒答：SFT 把拒答顶到 94.9%，同时 22.8–33.2% 是"又拒又答"的混合体。

⇒ **"我们的模型在 X 上表现好"这句话，在没写清切片、聚合方式、混合率之前，信息量为零。**

**共识三：权重侧与输入侧不是替代关系，而这周第一次把边界量化了。**

- **DICE**：擦除的失效不是"效果差"，是**方向错**（cos 0.07–0.30）。原因是蒸馏把条件分支与无条件分支改得不一样，而 ESD 假设两者一起优化。**⇒ 输入侧改写不碰权重，因此结构上不受这个失效模式影响。**
- **LoRA 溯源**：权重被动过是可检测的（Problem II AUROC 1.000），但**当适配域与底模太像时检测失效**（Food101）。
- **StruPO**：输入侧改写可以把保真做到 80.74 SGR，但**代价是它表达不了计数/否定/隐喻/暗示**——恰是 PORN/VULG 的战场。

⇒ **权重侧管"上线前"，输入侧管"上线后热更新"，溯源管"上线后被追责"。三层各管一段，互相不能替代。** 这条现在有数字了。

## 四、业务对齐研究板块

### A. 直接可迁移方法（按可落地性排序）

| 优先级 | 方法 | 来源 | 迁移动作 | 成本 |
|---|---|---|---|---|
| **1** | **锚点保留率奖励**（用 grounding 逐锚点核，不用全局相似度） | StruPO | 把 RL 改写的一致性奖励从"CLIP 相似度"换成"主体/动作/场景类型三个锚点的逐项 grounding 命中率"，**每项保留置信度而不是过阈值**（Theorem 3.1：阈值化评分在 $u$ 处无有限 Lipschitz 界） | 半天改代码，零训练 |
| **2** | **三动作改写算子**（删除/重排/插入，禁用自由生成） | StruPO | 把安全改写器的输出空间从"自由文本"约束成"对原 prompt 的原子编辑"，**保真由动作空间保证而不是靠奖励逼** | 需重训改写器，1–2 天 |
| **3** | **高/低风险切片双报** | AK_QMUL | 评测报告强制分切片：**表达规范度**（书面/口语/暗示）× **一级类目**，禁止只报总体 macro-F1 | 半天，零训练 |
| **4** | **几何平均三维聚合** | MoI-Bench | 语义保持 / 安全提升 / 指令遵循 改成加权几何平均，任何一维接近 0 直接把样本分打穿 | 半小时 |
| **5** | **@k 图审指标** | DICE | 图审评测从"单次判定"改成"k=5 次里任一次判违规即违规"，反映真实用户会重试 | 半天（多生成 4 张图） |
| **6** | **混合响应率审计** | VLM 拒答 | 统计安全分类输出里"同时含违规标签与安全描述"的比例 | 半天，零训练 |

**不推荐现在做的**：LoRA 溯源（我们的场景不需要自证，且校准集成本 2000×1000 不现实）、DICE 式的权重侧擦除（我们的模型不是蒸馏版，前提不成立）。

### B. 风险锚点处理启发（PORN/VULG 边界 + 政治 L2_30 层级 · 双锚点）

**B1. PORN/VULG 边界：AK_QMUL 的 `Bully` 给了我们一个几乎同构的参照。**

| | AK_QMUL `Bully` | 我们的 VULG-HINT-EDGE |
|---|---|---|
| 语义重叠对象 | harassment、harm-to-others | PORN（暗示性内容的两侧） |
| 总体分 | 0.57 | 最差类别 |
| **在"最规范"切片上** | **MSA 0.46**（方言 0.81–0.97） | **待测** |
| 作者归因 | "semantically overlaps" | 我们此前归因于"标签不准 + case 覆盖不足" |
| 作者用的手段 | 6.7B + QLoRA + 类加权 CE + 5 种子 | tag-weighted loss + 数据清洗 |

**这篇的意义在于**：它在一个**数据质量看起来没问题**（共享任务、多标注员、macro-F1 目标）的设定下，**用足量算力也只剩 0.57**。⇒ **这加强了我们此前的一个怀疑：VULG-HINT-EDGE 的低分可能不是标注错，而是"边界在规范表达上本就不可分"。**

但要小心一个反向推论：**AK_QMUL 的重叠类是"行为重叠"（欺负 vs 骚扰 vs 伤害他人），我们的是"程度重叠"（暗示 vs 明确）**。程度重叠理论上应该可分（有连续强度），行为重叠才是真的难分。**所以这篇不能直接给我们的低分开脱，但它给出了正确的验证路径：先按切片看，再决定该改标签还是改定义。**

**锚点侧的直接动作**：
- 用 StruPO 的 **DSE 非对称规则**过一遍我们的风险 prompt：**"擦边""暗示"这类词在解析器眼里是 text-core 还是 auxiliary？** 如果是 auxiliary，说明它会被图否掉——那我们的"风险锚点保留率"指标就从来没测到过它们。
- 用 **C2 错配设计**做锚点专测：给分类器一段"涉及 VULG 请标 VULG"的指令，测试集里**只放 PORN 明确样本**，看它是否仍然大量标 VULG。**如果会，说明它在按指令词表打标而不是按图判边界——这正是 PORN/VULG 混淆的一个可能机制，而且我们从来没测过。**

**B2. 政治 L2_30 层级：标签因子化的代价现在有数了。**

AK_QMUL 的三行表直接回答了我们层级设计的一个悬而未决的问题：**把 L1 与 L2_30 拆成正交因子，收益是多少？**

- 在长尾被补上时：**+0.001（等于零）**；
- 在长尾没补时：**−0.360（灾难）**。

⇒ **L2_30 独立维度只有在"每个格子都有足够样本"时才值得做。** 具体动作：
1. 先统计 **L1 × L2_30 × L3 × L4 的格子样本数**，把低于阈值的格子全标出来；
2. **对低于阈值的格子先补数据，再上联合头**——顺序反了就是 −0.360。

另加一条来自 MoI-Bench 的纪律：**rubric 适用性三态**。政治类判据里很多是 sample-dependent（"是否涉及特定地区"只在部分样本适用），现在大概率是全样本硬判——**这本身就是标签噪声的一个来源**。

### C. 三维评测设计启发（语义保持 / 安全提升 / 指令遵循损失）

**C1. 聚合必须改几何平均（最高优先级，半小时）。**
MoI-Bench 的理由可直接引用：**"geometric aggregation limits compensation for poor performance in one criterion group by high scores in others"**。我们现在的加权求和允许"安全分高"补偿"语义全崩"——**这正是 RL 改写奖励最可能的作弊路径**（Qwen-PE 上周也把奖励拆成"组内相对管区分度 + 绝对项管跑题"，同一个思路）。

**C2. 判据必须"先写后跑"。**
MoI-Bench 的纪律：**"完整/部分/失败"三档条件在看不到模型输出之前构造**，且**问题与条件在所有被测模型与 judge 间共享**。我们现在是跑完看结果再想怎么判——这是评测泄漏。

**C3. 能力缺失记 0，不移除样本。**
MoI-Bench：不支持的任务 $u_s = 0$ 但**保留在集合里**。我们现在的做法会把"无法处理"的样本剔除或单独统计，**等于在评测里悄悄原谅覆盖缺口**。

**C4. 三维必须带切片，且切片的维度要选对。**
AK_QMUL 证明单一切片（方言）就能把总体 0.79 切成 0.70 vs 0.93。我们的三维评测建议切片组合：**表达规范度 × 一级类目 × prompt 长度**。特别是**表达规范度**——这是 AK_QMUL 里唯一出现塌陷的维度。

**C5. AB 评测必须冻结 prompt + 报三个数。**
VLM 拒答给出的量化：同义话术翻 18.4–45.2 点、位置翻转方向依模型而反。所以图审 AB 要报：① 排序相关（Spearman，MoI-Bench 达 0.968 是良好水平）；② **ECE**（阈值无关）；③ **混合响应率**。且必须写明阈值是怎么校准的——MoI-Bench 自己承认"档位一致性不算独立验证"。

### D. 下一步实验建议（对照五条主线）

#### D1｜tag-weighted loss 线：reason 的"结构 vs 套话"分离（半天，零训练）

上周的 D1 是"reason 套话对照"（判 reason 有没有起作用）。这周 StruPO 给了一个**更强的版本**：区分**结构信息**与**文本信息**。

- **做法**：三条对照 —— A=模型自己写的 reason；B=同 tag 下**另一条样本**的 reason（换内容不换结构）；C=**固定套话**；**新增 D=保持原 reason 的"关系型语句"，但把物体/属性短语替换成同 tag 下别样本的**。
- **判据**：若 **D 掉得比 B 少** ⇒ reason 起作用的是**关系结构**而不是**具体词**；若 **D ≈ B** ⇒ 起作用的是具体词，那 reject_tag 改写**必须同步改写 reason 的实体**而不只是句式。
- **为什么现在做**：正在进行的标注修正流程（reject_tag 改写 + date 前缀）会同时改 reason。**这条实验直接决定改写的粒度。**

#### D2｜RL 改写线：奖励的"阈值化 vs 连续化"对照（半天，零训练）

StruPO 的 Theorem 3.1 给的是一个**可直接验证的数学主张**：阈值化评分在阈值 $u$ 附近无有限 Lipschitz 界，会导致奖励在 $u$ 附近抖动翻转、远离 $u$ 的改进拿零分。

- **做法**：把现有的一致性奖励做两版 —— 阈值版 $\mathbb{E}[\mathbb{1}(p \ge u)]$ 与连续版 $\frac{1}{K}\sum_k p_k$，**同一批 (原 prompt, 改写 prompt) 对，固定种子**，各跑 20 次，量**奖励方差**与**组内排序一致性**。
- **判据**：**连续版的组内排序一致率显著更高 ⇒ 直接把奖励换掉**；两版一致率接近 ⇒ 我们的奖励不在阈值敏感区，问题在别处（那就要查上周 D2 说的"奖励读取位置"）。
- **附带**：StruPO 的"**M 次渲染先平均再比**"几乎零成本（$M=2$ 就够），建议一起加——它把"运气好的一张图"和"确实更好的改写"分开。

#### D3｜标签审计线：按"表达规范度"切片，先判该改标签还是该改定义（半天，零训练）

AK_QMUL 的 B2 表给了明确的验证路径。

- **做法**：把评测集按**表达规范度**分三档（书面规范 / 半口语 / 强暗示隐喻），交叉一级类目，出一张 `macro-F1 × 切片` 表。
- **判据**：
  - 若 VULG-HINT-EDGE 的低分**集中在"强暗示隐喻"档** ⇒ 是**样本覆盖问题**，清洗 + 补 case 有效（继续现在的标注修正流程）；
  - 若低分**集中在"书面规范"档**（与 AK_QMUL 的 MSA 同构） ⇒ 是**定义边界问题**，改标签没用，必须**改类目定义或加可操作的判定细则**。
- **为什么这条最该做**：它能**一次结束**我们纠结了几周的"该调阈值 / 改标签 / 补数据"三选一——用一张表把三者的适用条件分开。
- **顺带**：把 `Bully`@MSA **0.46** 这个数字贴在方案里，作为"同类问题在别人数据上也只能到 0.46"的参照。

#### D4｜输出侧图审线：从"谁更准"改成"谁在什么条件下不稳定"（1 天）

综合 VLM 拒答（话术/位置敏感）+ DICE（@k）+ MoI-Bench（冻结 prompt、报 ECE）：

- **三个动作**：
  1. **话术自检**：同一 system prompt 做 3 个同义版本，跑同一批样本，量**判定翻转率**。判据：**> 5% ⇒ 任何 AB 结论不可信，先修 prompt 稳定性**。
  2. **位置自检**：风险判据前置 vs 后置，量翻转率。判据：**方向随模型翻转 ⇒ 结论不可跨模型外推**。
  3. **@5 重试指标**：同一 prompt 生成 5 张，任一张判违规即违规。判据：**@5 与单次的差 > 10 点 ⇒ 我们的安全率被单次采样高估了**。
- **报告格式改为三个数**：排序 Spearman + ECE + 混合响应率。

#### D5｜I2I 改写链路：针对 0/0%，这周终于有了两个可用工具（2 天，零训练）

**诊断先修正一句**：0/0% 很可能不是"改写做坏了"，而是**"改对了"从未被定义过**。MoI-Bench 的整个方法论就是为这件事设计的。

- **动作 ①（半天，最该先做）：按 Operation 分档，定位 0/0% 在哪一档**
  把 I2I 指令按 MoI-Bench 的四组操作分类：**局部编辑 / 全局编辑 / 理解式编辑 / 参考编辑**，看分流命中率是否集中在某一档。
  **判据**：若 0/0% 集中在**理解式编辑**（语义编辑、inpainting、outpainting）⇒ **不是改写坏了，是这类编辑本来就依赖对意图的推断，而改写抹掉了推断线索**。此时改写的目标函数要改（从"降风险"改成"降风险但保留可推断性"）。
  若 0/0% 在所有档都一样 ⇒ 才是分流器本身的问题。

- **动作 ②（1 天）：用"锚点保留率"替代"编辑是否成功"这个不可判的量**
  借 StruPO 的 DSE：对每条 I2I 指令抽出 **主体 + 操作 + 目标区域**三个锚点，改写后在**编辑输出图**上用 grounding 核这三项还在不在。
  **判据**：如果改写后锚点保留率 > 90% 但编辑仍失败 ⇒ 失败原因是编辑模型能力，不是改写；如果锚点保留率 < 70% ⇒ 是改写把编辑意图改没了，**这才是 0/0% 的真因**。
  **这一步的价值**：它把"0/0%" 从一个**无法归因的总数**拆成**两个可分别归因的数**。

- **动作 ③（半天）：分流从"二分"改成"带分数的两候选排序"，输出加一个"为什么改"**
  沿用上周 EditJev 的结论（2B 小模型 + 94ms 就够做路由）。这周补一条：**排序的输出必须带理由分类**（VLM 拒答的 $R_E$/$R_S$/$R_G$ 拆分法），至少区分"这条指令风险高"与"这条指令我看不懂"。**后者不该触发改写，该触发拒绝或澄清。** 这两类现在被混在一个 0% 里。

## 六、趋势信号

**信号一：评测正在从"报一个数"转向"报一组条件"。**

这周六篇里有三篇（MoI-Bench、AK_QMUL、VLM 拒答）的核心贡献都是**"这个分数在什么条件下才成立"**，而不是新模型。MoI-Bench 甚至明确拒绝单一排名，改成 Quality–Deployability 二维图谱；AK_QMUL 的分层表把总体 0.79 拆成 0.70/0.93；VLM 拒答把拒答率拆成四个理由类别 + 混合指示。

⇒ **"我们的模型在 X 上 0.9X" 这种句式，正在变成不可接受的汇报格式。**

**信号二：头部公司在 T2I 输入侧改写上，连续两周只发 enhancement / fidelity，不发 safety。**

- 上周：Qwen-Image-PE（Qwen Team / 阿里 + 北大）——四维 rubric 里**没有安全**；
- 这周：StruPO（浙大 + **腾讯 AI Lab**）——奖励里**没有风险维度**，评测里**没有违规概念**。

两家大厂、两周、同一个空白。**这既是窗口（没有现成配方可抄），也说明这条线在工业界仍是黑箱。** 而 DICE 那篇（S&P'27）恰好解释了为什么工业界可能更愿意做擦除而不是改写——**擦除有明确的验收指标（不安全率），改写没有**。**所以要做改写，第一步不是训模型，是先把验收指标建起来。**

**信号三："可验证性"正在成为安全治理的第三个维度。**

DICE（权重被动过 → 不安全率变）、LoRA 溯源（权重被动过 → 可检测）、StruPO（改写动过 → 保真可核）——三篇从三个角度指向同一件事：**"我说我安全"正在被"你能验证我安全"替代**。对我们：**输入侧改写的一个隐性优势是可审计**（每次改写都有原文与改后文可对账），这个优势目前没被写进任何方案里。

**信号四（跨周元判断，延续上周）：路由/门控层继续从大模型手里被拿走，但"判什么"比"谁来判"更紧急。**

上周的结论是"判走哪条路该用小而快、带校准的模型"（EditJev 2B/94ms、RubriX 28ms）。这周补上了前提：**你得先定义清楚在判什么**——MoI-Bench 花了整篇证明"编辑任务必须二维分解才可判"，VLM 拒答证明了"拒答率这个指标本身是坏的"。⇒ **先有判据，再谈模型规模。** 我们 I2I 的 0/0% 就卡在这一步：**没有判据，所以 0/0% 无法归因。**
