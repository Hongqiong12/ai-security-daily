## 今日概览

先说结论：**过去 7 天是近期 T2I 安全质量最高的一周之一——四篇直接相关工作里有三篇中了顶会，而且它们指向的是同一个尚未被命名的共识：「安全控制必须状态依赖，而不是条件依赖」。**

拆开看：

1. **输入侧控制正在从"判文本"转向"读生成态"。** `CSTI` 证明：CFG 原生就算了条件/无条件两个分支，这两个分支激活之差在 step 5/10/15 就已经携带强安全信号，几个通道统计量 + 一个线性头就能读出来。它不重建中间图、不改生成器、不需要攻击样本拟合。**这是把"风险打分"从 NLP 问题变成信号问题的第一步。**

2. **安全-保真权衡被正式识别为"控制结构问题"而非"调参问题"。** `DSC`（腾讯参与，NeurIPS 2026）指出：现有 training-free 引导让同一个 unsafe condition 同时兼任"避什么 / 信号源 / 干预量 / 持续多久"四职，一旦有害与良性语义纠缠就必然两边都不讨好。解法是把控制链拆成五段显式环节，全部由当前生成态驱动。**这篇是今天最该做方法映射的一篇。**

3. **Rewriter 的 RL 训练层出现了语义结构归纳偏置。** `SCOPE` 指出：图像级奖励被平摊到 subword 是结构性错配，真正的语义单元是 span（物体/数量/属性/关系）。让 rewriter 同时输出 semantic partition，span 内池化共享系数，GeneVal +9.48%、T2I-CompBench +7.62%，且**不需要额外 span 奖励、不需要额外渲染**。

4. **"保真"的度量方式在被重新发明。** `PPAA` 用相对相似度比替代绝对差，让阈值语义直接变成"保留 X% 语义"，一个值跨层通用；并且第一次明确定义了此前无人解决的空白——**同域近邻概念保留**（擦 Obama 时能不能保住 Will Smith）。

5. **T2T 侧两篇是纯粹的"方法论武器"。** `AMEND` 用 constraint-first 选择让语义保真对表面安全拥有**否决权**；`Policy Is Not Capability` 用一次工业事故证明**很多 benchmark 分数测的是"你训练在哪套策略上"而不是"你的检测能力"**。

一句话压缩今天：**T2I 安全正在从"要不要拦"进入"什么时候拦、拦多重、拦完还剩多少语义"的精密控制阶段；而与此同时，我们用来衡量这些的尺子本身还没有被校准。**

### 1. CSTI — When Guidance Becomes a Guard: Early Interception of Unsafe Inputs in T2I

**本地精读**: `categories/t2i/papers/2610.26452_csti.md` · https://arxiv.org/abs/2610.26452
**机构**: 湘潭大学 · 长沙理工大学 · 香港城市大学 · 华中科技大学 | **2026-10-19** | cs.CV

- **论文定位**: 生成中早期拦截（in-generation interception）/ 输入侧风险 gate
- **核心洞察**: CFG 在同一步已经算了条件分支与无条件分支，二者激活之差**在极早期就携带强安全信号**，且**紧凑通道统计量 + 线性读出**就够用。
- **方法三步**:
  1. 取固定中间 block 的条件激活 $H_t^p$ 与无条件激活 $H_t^\varnothing$，做差得**条件对比**；
  2. 在 step 5 / 10 / 15 压成通道统计量，拼多检查点表征；
  3. 线性概念头（**只用 canonical 概念 + 安全样本拟合，不用任何攻击样本**），阈值在**独立安全校准集**上选。
- **部署形态**: step 15 单次判定 → 命中则**终止生成**；未命中则**采样轨迹完全不变**。
- **关键数据**:
  - 5 个生成器（SD1.4 / SD1.5 / SDXL / SD3.5 Medium / Z-Image，覆盖 U-Net 与 Transformer）；
  - 4 个对抗攻击集合 + 2 个通用 NSFW 数据集；
  - 在 **matched 5% FPR** 下，六个基线中**整体最强**；
  - 拦截路径**延迟降低 60%+**，五个生成器一致。
- **我的判断**: 今天**与输入侧控制面最直接**的一篇。它暗示了一条明确路线：**风险判定可以不落在文本上，而落在"生成器对这条 prompt 的条件响应"上。** 对做 rewriter 的团队，CSTI 的风险分天然是 gate——低风险直接放行不改写，高风险才进改写。这正面解决 over-refusal 与无谓改写造成的语义损伤。

### 2. DSC — Decoupled Safety Control: A Safety-Control Algorithm for Training-Free Safety Guidance

**本地精读**: `categories/t2i/papers/2610.21569_dsc.md` · https://arxiv.org/abs/2610.21569
**机构**: 中国科学技术大学 · 复旦大学 · **腾讯（Tencent）** · 北京邮电大学 · 中国信通院
**会议**: **NeurIPS 2026 已录取** | **2026-10-15** | cs.CV

- **论文定位**: training-free 推理时安全引导的**控制结构**改造（plug-in）
- **点破的机制缺陷 —— 耦合安全控制链**: 同一个 unsafe condition $c^-$ 同时兼任四职：
  ① 指明要避开什么 ② 充当当前不安全信号 ③ 构造干预量 ④ 决定干预何时持续生效。
  unsafe 因素显式时好用；一旦**有害与良性语义在当前生成态纠缠**，就只能二选一：压太轻留残留，压太重伤保真。
- **解法 —— 五段显式状态依赖控制**:

  | 环节 | 作用 |
  |------|------|
  | runtime evidence extraction | 从**当前生成态**取证据，不从 $c^-$ 继承 |
  | control-state estimation | 估计当前需要多少干预 |
  | intervention routing | 决定走哪条干预路径 |
  | update construction | 依当前状态构造该步修正量 |
  | phase-aware execution | 按去噪早/中/晚相位收放干预 |

  原则：**不安全规格固定，运行时决策全部由当前生成态决定。**
- **实例化**: SLD（latent 空间代表）+ SAFREE（text/prompt 空间代表），基座权重全程不变。
- **我的判断**: ⚠️ **今天唯一有腾讯署名的 T2I 安全论文，且已中 NeurIPS 2026**，属明确工业界线索。但更重要的是它的**方法映射价值**——我们做"风险锚点外科替换"时面对的是同一个耦合问题：**一个风险标签同时决定了"要不要改 / 改哪里 / 改成什么 / 改到什么程度"**。DSC 的答案是把这些决策从标签里解耦出来，交给当前 prompt 的锚点分布。

### 3. SCOPE — Semantic Bounded Credit Optimization for Prompt Engineering in T2I

**本地精读**: `categories/t2i/papers/2610.22264_scope.md` · https://arxiv.org/abs/2610.22264
**机构**: 厦门大学（媒体分析与计算实验室）· University of Rochester | **2026-10-15** | cs.CV

- **论文定位**: **T2I rewriter 的 RL 训练方法**（LLM rewriter + 冻结图像生成器 + GRPO）
- **点破的错配**: 图像级单一奖励被**平摊到 subword token**，但真正的语义单元是**连贯 span**（物体 / 数量 / 属性 / 关系）。
- **方法**:
  1. rewriter **联合生成**增强 prompt **与其 semantic partition**；
  2. 在每个 span 内**池化 policy log-prob 偏移**，得到该 span 的**共享系数**去加权 span 内 token loss；
  3. **保留 completion 级单一 advantage** 不变。
- **成本**: ❌ 不需要额外 span 奖励 ❌ 不需要额外图像渲染 —— **纯目标函数层改动，零数据/零采样成本**。
- **关键数据**（vs vanilla GRPO，平均相对增益）:

  | 基准 | 增益 |
  |------|------|
  | **GeneVal** | **+9.48%** |
  | **T2I-CompBench** | **+7.62%** |

  消融证实：**语义边界**与**span 内池化**两者都贡献。
- **我的判断**: ⭐ **今天与业务技术栈最贴身的一篇。** 形态完全一致（LLM rewriter + 冻结生成器 + RL），且实验里就有 **Qwen-Image**（与业务奖励侧同生成器，复现基础现成）。它直指一个更深的点：**"语义保真"本质就是"不要在错误的语义单元上分配信用"。** 若把"性感→优雅"学成**一个 span 的替换**而非一堆 token 各自漂移，正是 SCOPE 的归纳偏置。

### 4. PPAA — Push–Pull Attentional Anchoring for Diffusion Concept Erasure

**本地精读**: `categories/t2i/papers/2610.27719_ppaa.md` · https://arxiv.org/abs/2610.27719
**机构**: VISTEC · Chulalongkorn University（泰国）
**会议**: **ECCV 2026 已录取（Spotlight）** | **2026-10-20** | cs.CV
**项目页**: https://push-pull-concept-eraser.github.io/

- **论文定位**: 概念擦除 / **擦除-保留权衡**
- **点破的空白（全文最有价值的观察）**: 现有方法能保住**宽泛通用域概念**（MS-COCO 普通物体），但保不住**同域近邻概念**——擦除 "Barack Obama" 时能不能同时保住 "Will Smith"？**这个问题此前没有被解决。**
- **方法**: 在 cross-attention 空间
  - **Push**：位移目标表示；
  - **Pull / Anchor**：用**有界余弦相似度约束**锚定"推多远"，防无界漂移。
- **关键创新**: 用 **relative similarity ratio** 而非 absolute difference —— 自适应阈值表示**"保留百分之多少语义"**，因此**单一阈值可跨层统一适用**。
- **实验**: SD v1.4 主实验 + **FLUX** 现代架构验证；概念类别覆盖 celebrities / artistic styles / **nudity** / IP。
- **我的判断**: **"风险锚点处理"最直接的概念级启发来源。** 业务做"外科式替换锚点、其余不动"，PPAA 做"推走目标、锚定尺度"——数学诉求完全同构。三个可搬的点见下方业务板块（相对比值做保真约束 / 同域近邻分层评测 / anchor 概念参数化）。

### 5. AMEND — Constraint-Guided Multi-Agent Text Detoxification with Isolated Critics

**本地精读**: `categories/t2t/papers/2610.23183_amend.md` · https://arxiv.org/abs/2610.23183
**作者**: Tianyu Wang | **2026-10-16** | cs.CL

- **论文定位**: 文本去毒（toxicity × semantic preservation × fluency 三难）的**推理时选择机制**
- **点破的缺陷 —— 标量目标塌陷**: 优化无约束加权和时，**一个很高的安全分可以掩盖语义保真的崩塌**——模型通过"换个话题"来逃避毒性。
- **三阶段解耦**:
  1. **Role-Conditioned Proposals**：同一 base LM 用三角色生成候选
     - `minimal_editor`（精确 span 替换）/ `tone_rewriter`（攻击性→坚定文明）/ `semantic_paraphraser`（重构但刚性保事实与立场）
  2. **Isolated Multidimensional Critics**：三个 critic **各管一维**（toxicity / semantic / fluency），且 **role-blind**（看不到候选来自哪个角色）→ 挡掉 persona bias 与 evaluator sycophancy
  3. **Constraint-First Selection**：**先过硬可行性门槛，再按 utility 排序** → 让语义保真对表面安全拥有**否决权**
- **AMEND Lite**: 消融发现开放式多轮辩论仅 +0.0061 且**置信区间跨零**。改为**最多一轮**定向修复（仅 `minimal_editor`，强制单调接受）。
- **关键数据** (ParaDetox, seed-aligned):

  | 对比 | 结果 |
  |------|------|
  | 单轮三角色 vs 最佳单角色 | joint metric **+0.0508** |
  | AMEND Lite vs 无约束多轮 | joint score **+0.0489** ($p<0.05$)，且**推理请求减少 28.4%** |
  | AMEND Lite 冻结确认集 | **0.6597 ± 0.0062** |

- **对 T2I 输入侧安全的迁移价值**:
  - ✅ **可迁**：三角色 = 安全改写三条基本路线（锚点外科替换 / 语气强度降级 / 整体释义保义）；constraint-first 选择 = 先卡语义与指令遵循硬门槛再按安全分排序；有界回路 = 最多一轮定向修复。
  - ⚠️ **不可直接迁**：AMEND 的 semantic critic 是文本可比的；T2I 的语义保真还要过"图像一致性"这一关，**文本 critic 不能充当图像侧保真评审**，必须补图像通道。
  - 💡 **最该立刻试的**：把 rewriter 的"加权和 reward"改成"constraint-first"——排序前先按语义保真与指令遵循卡硬门槛。预期直接压掉"换个主题式的安全改写"这类 badcase。

### 6. Policy Is Not Capability — Some Safety Benchmarks Measure Which Definition of "Unsafe" You Trained On

**本地精读**: `categories/t2t/papers/2610.25060_policy_is_not_capability.md` · https://arxiv.org/abs/2610.25060
**会议**: **NeurIPS 2026 Workshop TAE 已录取（Poster）** | **2026-10-18** | cs.LG/cs.AI/cs.CL/cs.CR

- **论文定位**: guardrail **评测协议审计**（诊断性工作，非方法性）
- **实验条件（一次工业事故）**: 某端侧助手的 24-pillar 专有安全体系，**同一约 5.3 万条 prompt 池被标注两次**，两套流程准确度相当但**六分之一的 prompt 不一致**，且分歧系统性：
  - **Policy A**：审慎审核员会不会拦？（moderation 口径）
  - **Policy B**：这是不是请求有害内容？
  - → 10 个训练 arm × 2 规模 = **20 个模型**，在 **15 个公开 benchmark、33,137 条 prompt** 上同条件评测。
- **四个发现**:

  | # | 发现 | 关键数字 |
  |---|------|---------|
  | 1 | 训练语料里就装着 benchmark | JailbreakBench-benign **88%**、OR-Bench-hard **82%**（vs OR-Bench-toxic 0%、AdvBench 2%）；**over-refusal 类受损最重** |
  | 2 | benchmark 的"定义敏感度"差 23 倍 | HarmBench-copyright 极差 **0.99** vs WildGuard-benign **0.043** |
  | 3 | **0.03% 参数可推过整个量程** | HarmBench-copyright 跨 **0→100**；OR-Bench-hard over-refusal 跨 **3.4%→56.4%**；**检测能力不变**（exact rank $p=0.005$）；硬标签 100% 为 Policy A 且全量微调的 arm 只拿 **17.3/100**；**teacher 软标签照样装策略 → teacher provenance 是未记录的混淆变量** |
  | 4 | 验证准确率测的是策略一致性不是能力 | 与策略一致性 $\rho=+0.74$，与检测能力 $\rho=+0.34$；该验证 split **69.3% 落在 Policy-A 训练文件里** |

- **主张**: guardrail 评测应把 **contamination / seed floor / 被评的定义** 作为一等变量报告。
- **对 T2I 输入侧安全的迁移价值**:
  - ✅ **可迁**：评测协议审计的五个动作（污染扫描 / 定义敏感度测量 / seed floor / teacher provenance / 验证集自查）可整体搬到 T2I 改写评测。
  - ✅ **对业务最关键的一条**：当前最差类别 VULG-HINT-EDGE 与 PORN/VULG 边界混淆，**在改模型之前应先验证边界标注是否来自同一套策略口径**。若口径本身不一致，改模型无解。
  - ⚠️ **不可迁**：未覆盖 T2I 专用 benchmark（T2ISafety / UnsafeBench）的定义敏感度，需自测。

## 四、趋势信号

1. **「安全控制状态依赖化」正在成为跨方法共识。** CSTI（决策来自生成态早期激活）、DSC（干预来自当前生成状态）、AMEND（选择来自隔离多维评审）三篇来自完全不同子领域，却在做同一件事：**拒绝让一个固定的、先验的不安全规格直接决定控制动作。** 这已经不是巧合，是范式转移。

2. **"保真"正在被重新度量。** PPAA 用**相对比值**取代绝对差；SCOPE 用**语义 span**取代 subword；AMEND 用**硬门槛**取代加权和；Policy 用**定义敏感度**取代裸分数。四篇都在说同一件事：**旧的那把尺子量不出我们真正关心的东西。**

3. **几何/比值形式正在取代标量强度调参。** PPAA 的相对相似度比、DSC 的 phase-aware、CSTI 的 conformal 式阈值标定——都是把"调多大力度"这个经验问题转成有语义的无量纲量。这是安全方法从 trick 走向工程的标志。

4. **多轮 agentic 改写被证伪（至少被严重质疑）。** AMEND 的消融显示开放式多轮仅 +0.0061 且置信区间跨零，成本却线性上升。**有界单轮修复 > 开放式辩论**。这条对控制推理成本有直接价值。

5. **工业界信号偏弱但质量高。** 本周腾讯署名仅 DSC 一篇（已中 NeurIPS 2026）；Anthropic / OpenAI / Google / Meta / Adobe / 字节未在近 7 天看到 T2I 安全新公开方法。反倒是**评测方法论的工业事故复盘**（Policy Is Not Capability）提供了最高密度的可操作信息。

### B. 迁移判断：能迁什么、不能迁什么

**✅ 能直接迁的（4 条）**

1. **语义 span 作为信用分配与诊断单元**（SCOPE）
   把 semantic partition 的定义从"物体/属性/关系"换成"**风险锚点 span / 修饰语 span / 场景上下文 span / 风格 span**"。训练日志里若**非风险 span 系数长期偏高**，就是 rewriter 在做无谓改写——比只看最终 edit rate 更早暴露问题，可直接作为**训练期 early warning**。

2. **constraint-first 取代加权和**（AMEND）
   现在 reward 若为加权和，rewriter 一定会学会"最安全的改写 = 换个主题"。改成硬门槛过滤后再排序，是这个失败模式的**结构性消除**，不是精度微调。

3. **相对比值形式做保真约束**（PPAA）
   现用 clamped normalized Levenshtein 是 **token 级绝对差**。可引入相对比值：改写前后在某语义空间（embedding / 风险分类器 logit）的相似度**比值**，阈值语义变成"**保留 X% 语义**"，跨类别、跨 prompt 长度可比。更进一步可做成 **span 级 edit budget**，对非风险 span 施加更强 edit 惩罚，取代全局一刀切。

4. **有界回路取代多轮迭代**（AMEND Lite）
   多轮改写辩论收益不显著但成本线性上涨。改成**最多一轮定向修复 + 单调接受**，与业务已在测的 history_turns 上下文融合方案需做成本-收益核算。

**⚠️ 不能直接迁的（3 条）**

1. **CSTI / DSC / PPAA 都在生成侧或权重侧，不是输入侧。** 它们能改变**改写必要性的边界**（哪些风险必须输入侧消解、哪些可留给生成侧控制面），但**不能替代 rewriter**。CSTI 是 gate 不是 rewriter。
2. **AMEND 的 semantic critic 是文本可比的。** T2I 的语义保真必须过"图像一致性"这一关，文本 critic 只能算一个通道，不能单独充当保真评审。
3. **SCOPE 只在质量基准（GeneVal / T2I-CompBench）验证。** 奖励换成安全分后，span 划分是否仍稳定（尤其当**风险锚点本身就是一个 span** 时）必须实测，不能直接假设成立。

### C. 评测设计启发：三维评测（语义保持 / 安全提升 / 指令遵循损失）

**C-1. 先给每一维标定"定义敏感度"（Policy Is Not Capability）**

在正式评测前做一个小网格：固定架构与优化器，只改标签来源，量化每一维的分数极差。

- 预期：**安全提升**维最容易被定义驱动（因为风险标签 = 策略）；**语义保持**维次之；**指令遵循损失**维相对最稳。
- 用途：极差大的指标标记为"定义驱动型"，**从跨版本比较中剔除或强制标注**。

**C-2. 语义保持维必须做分层，不能一锅端（PPAA）**

现有"整体语义相似度"是单层的。建议三层：

| 层 | 内容 | 为什么必须单列 |
|----|------|--------------|
| L1 通用域 | 普通物体/场景 | 现有指标已覆盖，最不敏感 |
| **L2 同域近邻** | 同一风险类别下的相邻子类型（如 PORN 内相邻子类、VULG 内相邻子类） | **PPAA 证明通用域指标看不见这类损伤，而这里恰恰最容易误伤** |
| L3 锚点级 | 非风险 span 是否被改动 | 直接对应"外科式替换"是否成立 |

**C-3. 安全提升维必须报告三个元数据（Policy Is Not Capability）**

评测报告固定加三行：**污染率 / seed floor / 被评的风险定义版本**（当前 level1–4 层级标签体系的版本号）。否则数字不可跨版本比较。

**C-4. 指令遵循损失维建议双通道（AMEND 迁移）**

- **文本通道**：改写后 prompt 是否仍包含原构图/主体/数量/关系要素；
- **图像通道**：生成图与原图（或原 prompt 生成图）的一致性 —— 业务已有 Qwen-Image 一致性奖励，可直接复用为评测指标而非仅作训练奖励。

**C-5. 三维的聚合方式：不要加权和（AMEND）**

三维不做 scalarization。采用：**语义保持与指令遵循设硬门槛 → 存活样本内按安全提升排序**。这样"安全分虚高但语义崩塌"的样本不会进入通过名单。

### D. 下一步实验建议（可直接开做，按性价比排序）

**实验 1（最高优先级，1–2 天）：把 reward 从加权和改成 constraint-first**

- 做法：不改模型，只改 candidate 排序逻辑。设定语义保真阈值 $\tau_{sem}$ 与指令遵循阈值 $\tau_{ins}$，先过滤再按安全分排序。
- 对比：原加权和 vs constraint-first，在同一批**模糊高风险 prompt** 上人工评估。
- 预期：**"换个主题式改写"类 badcase 显著下降**，安全分基本不掉。
- 数据来源：可复用现有 `ella_eval_badcase_0612.csv` 里的 badcase 做定向验证。

**实验 2（2–3 天）：span 级 rewriter 输出格式改造**

- 做法：在 rewriter 输出格式中加 semantic partition 标记（风险锚点 span / 修饰语 span / 场景 span / 风格 span），先只做**格式改造 + 日志统计**，不改 loss。
- 观测：统计"非风险 span 被改动的 token 占比"，与现有全局 edit rate 对比，看是否能更早定位无谓改写。
- 下一步：确认有信号后再上 SCOPE 的 span 内池化 loss。

**实验 3（1 天，纯审计，零训练成本）：PORN/VULG 边界的策略口径审计**

- 背景：当前最差类别 VULG-HINT-EDGE，PORN/VULG 边界混淆。
- 做法：**先别改模型**。抽 300–500 条边界样本，让两批标注者分别按两个口径标注：
  - 口径 A："审核员会不会拦？"
  - 口径 B："这是不是请求有害内容？"
- 判据：若两口径分歧率显著（Policy 论文中工业事故的分歧率是 **1/6**），则瓶颈在**标注策略**而非模型能力，应优先统一口径 + 重建边界集，而不是调 loss 权重。
- 附加动作：同步跑一次**验证集污染自查**（Policy 论文里作者就是这么发现自己的验证集 69.3% 落在训练文件里的）。

**备选实验 4（若算力允许）：CSTI 式 gate 的可行性探针**

- 做法：在现有生成器上 hook 中间 block，取 step 5/10/15 的条件/无条件激活差，看**业务自己的高风险 prompt 与良性 prompt 在这个表征上是否线性可分**。
- 用途：若可分，就得到一个**零训练成本的输入侧 gate**，可直接用于"低风险不改写"，正面降低整体 edit rate 与语义损伤。
