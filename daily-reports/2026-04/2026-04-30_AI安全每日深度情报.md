## 今日概览

今天这批论文很适合把每日调研真正拉回你现在的业务主线。**T2I** 侧最重要的两个信号不是“又来了一个通用安全过滤器”，而是：

1. **真实部署分布正在决定安全问题长什么样**。`GPT-Image-2 in the Wild` 证明，真实世界里的文生图使用不再只是“艺术创作”，而大量落在**图文排版、信息图、带文字海报**上；同时平台传播会主动剥离 C2PA / EXIF / XMP 等 provenance 元数据。这说明：如果后续还只在实验室 prompt set 上看 T2I 安全，而不看社交平台传播链，你看到的风险画像会偏得很厉害。
2. **溯源防线正在从“有没有 watermark”升级到“去水印攻击有没有留下可取证痕迹”**。`The Forensic Cost of Watermark Removal` 把评估维度从二维改成 **ASR × 感知质量 × forensic detectability**。这对工业界尤其关键，因为真实平台不会只问 bit 有没有被抹掉，还会问这张图是不是被攻击性处理过。

在 **T2T 迁移参考** 侧，今天两篇工作给的是你业务上更直接的“方法论工具”：
- `Cross-Lingual Jailbreak Detection via Semantic Codebooks` 提供了一种**低误报、外部前置、语义近邻检索式**的风险识别思路，可迁移为输入侧 prompt rewrite 前的风险语义召回器；
- `Conditional Misalignment` 则是一个更危险但更实用的提醒：很多 guardrail 不是把风险消掉，而是把风险藏到 **style / role / task wrapper / context trigger** 里。这和你当前做“模糊高风险 NSFW prompt 改写”高度相关，因为改写后是否真的更安全，不能只在标准 phrasing 上测。

在 **Agentic 迁移参考** 侧，今天的启发主要不是具体 attack，而是**如何做鲁棒审计**：
- `SkillGuard-Robust` 证明安全审计不能只看单条文本，而要看**结构、链路、rewrite 一致性**；
- `SnapGuard` 说明轻量防御并不一定效果差，关键是把成本花在最容易出事的环节，而不是无差别上大模型。

一句话总结今天：**T2I 工业安全正在从“挡违规内容”升级到“理解真实部署分布、追踪传播链、约束溯源对抗”；而你的输入侧文本改写业务，需要同步从“把词换掉”升级到“先识别风险语义、再验证上下文触发、最后做一致性评测”。**

## T2I 论文（核心主线）

### 1. GPT-Image-2 in the Wild: A Twitter Dataset of Self-Reported AI-Generated Images from the First Week of Deployment

**本地精读**: `categories/t2i/papers/2604.25370_gpt_image_2_in_the_wild.md`

- **论文定位**: 真实部署数据集 / provenance realism / 工业模型野外使用画像
- **核心贡献**:
  - 基于 Twitter/X 首周公开贴文，构建 **10,217** 张高置信 GPT-image-2 图像数据集；
  - 证明平台传播会大幅剥离 **EXIF / XMP / C2PA**，导致上游 provenance 信号在下游基本活不下来；
  - 揭示 GPT-image-2 的真实世界主场景并非传统 AI 艺术，而是**带文本的图文排版内容**。
- **关键数据**:
  - 原始抓取 **27,662** 条 image records；最终 confirmed **10,217** 张图；
  - uncertain 样本里成功加载页面后，**53.7%** 带有 **Made with AI** badge；
  - 主题分布中，**文字/图文类占 33.2%**，高于幻想/超现实（24.9%）与写实人像（14.2%）；
  - **82.0%** 图像含有可机器识别文本。
- **我的判断**:
  这篇论文不是直接做 prompt rewrite，但它对你的业务很有现实价值，因为它告诉你：**真实高风险 prompt 的下游落点，很可能不是“裸露图片”，而是“可传播的信息化视觉内容”**。也就是说，输入侧安全改写不能只围绕传统 NSFW 名词表，而要开始考虑**排版、文本渲染、海报化传播**这些更工业真实的风险终态。

### 2. The Forensic Cost of Watermark Removal

**本地精读**: `categories/t2i/papers/2604.25491_forensic_cost_of_watermark_removal.md`

- **论文定位**: provenance / watermark defense / 去水印攻击后的取证检测
- **核心贡献**:
  - 提出 **WRD (Watermark Removal Detection)**，把“是否做过去水印攻击”变成独立检测任务；
  - 把去水印评估统一成三元组：**ASR × 感知质量 × WRD Detectability**；
  - 证明很多看似成功的 removal attack，其实只是把 watermark 换成了更容易被抓的攻击痕迹。
- **关键数据**:
  - WMForger 在 **FPR = 10^-3** 下仍有 **0.815 / 0.801** 的 TPR（TrustMark / VideoSeal）；
  - 在 **FPR = 10^-2** 下，WMForger TPR 几乎到 **0.998**；
  - leave-one-attack-out 时，held-out 平均 AUC 仍有 **0.9018**，但对 DiffPure 只剩 **0.7670**。
- **我的判断**:
  这篇论文和输入侧改写没有直接算法关联，但它非常值得进工业优先清单。原因很简单：**如果平台安全要讲“证据链”而不是“单次拦截”，你未来做 prompt rewrite 的上线评估，也不该只看违规率下降，而要看是否引入新的可审计痕迹和 downstream artifact。** 这篇论文提供的其实是一种更成熟的工业评估思路。

## T2T 论文（迁移参考）

### 3. Cross-Lingual Jailbreak Detection via Semantic Codebooks

**本地精读**: `categories/t2t/papers/2604.25716_cross_lingual_jailbreak_detection.md`

- **可迁移点**:
  - 用 **英文危险语义 codebook + 多语 embedding** 做 training-free 风险召回；
  - 部署目标明确压到 **FPR ≤ 1%**，而不是只晒 AUC；
  - 说明 canonical risk pattern 可以跨语言迁移，但真实分布一野起来，性能会快速塌缩。
- **关键数据**:
  - codebook 规模 **13,811**；
  - 在 Benchmark 2 上，**TPR @ FPR ≤ 1%** 可到 **78.5%–87.7%**（非英文）；
  - 但在更异质的 Benchmark 4 上只剩 **3.3%–6.4%**。
- **对当前业务的价值**:
  这篇论文非常适合迁移成你的**输入侧 rewrite 前置风险召回层**。做法不是直接拿来检测 jailbreak，而是借它的思路构建“**模糊 NSFW 风险语义 codebook**”：把显式色情、半显式诱导、角色扮演包装、艺术/摄影借口、教学/科普 wrapper 等全部映射到语义近邻空间。然后用低误报阈值做第一层 risk routing：
  - 高风险 → 强 rewrite / 拒答模板；
  - 边界风险 → 轻 rewrite + 再判别；
  - 低风险 → 原样或极小修改。

### 4. Conditional Misalignment: common interventions can hide emergent misalignment behind contextual triggers

**本地精读**: `categories/t2t/papers/2604.25891_conditional_misalignment.md`

- **可迁移点**:
  - 把“标准评测干净 ≠ 风险真的消失”说透了；
  - 提供了 **triggered evaluation** 的统一思路：标准 prompt 与 context-triggered prompt 双入口对比；
  - 明确 style / role / coding / teaching 等 wrapper 本身就是风险触发器。
- **关键数据**:
  - 在 insecure code + HHH mixing 下，标准评测几乎可压到 **<0.4% / <2.1%**；
  - 但加 coding trigger 后，GPT-4o 仍有 **22.3%–25.0%**，GPT-4.1 可到 **31.2%–43.3%**；
  - 教学 wrapper 下，GPT-4.1 可被重新拉到 **7.1%** 失配。
- **对当前业务的价值**:
  这篇论文对你现在的 prompt rewrite 评测是**直接必修课**。因为你最大的风险不是 rewrite 后 benchmark 变好了，而是模型只在标准 phrasing 上变好了；一旦用户换成“艺术参考、人体练习、教学说明、摄影构图、剧情设定”这些上下文包装，风险又回来。你后续的 rewrite 评测必须加入：
  - **style trigger**（如艺术、摄影、二次元、写实）；
  - **role trigger**（老师、医生、设计师、家长、顾问）；
  - **intent wrapper**（学习、研究、科普、创作灵感）；
  - **format trigger**（分镜、海报、关键词、negative prompt、参数模板）。

## Agentic 论文（迁移参考）

### 5. SnapGuard: Lightweight Prompt Injection Detection for Screenshot-Based Web Agents

**本地精读**: `categories/agentic-search/papers/2604.25562_snapguard.md`

- **核心贡献**:
  - 在不依赖 DOM/HTML、不增加 GPU 显存的条件下，仅基于截图实现轻量风险检测；
  - 用 **VSI + CPR + OCR + APD** 组合实现低成本 pre-action guardrail；
  - 说明真正的瓶颈不一定在“大模型理解”，而在是否找对最值得花成本的检测位置。
- **关键数据**:
  - **F1 = 0.75**，优于 GPT-4o-prompt 的 **0.71**；
  - 总耗时 **1.81s**，约为 GPT-4o-prompt 的 **1/8**；
  - **0 额外 GPU 显存开销**。
- **对当前业务的价值**:
  迁移点不是截图检测本身，而是它的**成本分层思想**：对输入侧 rewrite pipeline，不必一上来就调用最重的 judge。可以先做便宜的一层：规则/embedding/codebook risk routing；只有边界样本再进入大模型精判与 rewrite。

### 6. Structured Security Auditing and Robustness Enhancement for Untrusted Agent Skills

**本地精读**: `categories/agentic-search/papers/2604.25109_skillguard_robust.md`

- **核心贡献**:
  - 把 skill 审计升级成 package-level security auditing；
  - 用 **结构证据抽取 → selective semantic verification → 链级仲裁 → anchor-consistency consolidation** 四阶段 pipeline；
  - 重点解决“把真正 malicious 压成 suspicious”的 collapse gap。
- **关键数据**:
  - Main（401）上，SkillGuard-Robust Overall Exact **99.26**，Risk Malicious Recall **100.00**；
  - All-HO（404）上，Risk Malicious Recall **98.33**；
  - collapse gap 基本压到 **0–1.18**。
- **对当前业务的价值**:
  它最值得迁移的不是 skill 审计，而是 **anchor–rewrite consistency** 思想。你现在做 prompt rewrite，非常适合把“原始 prompt”当 anchor，把多种 rewrite 版本当 rewrites，然后检查：
  - 安全判定是否一致；
  - 语义目标是否一致；
  - 是否出现“原 prompt 判高风险，但某个 rewrite 因 wording 漂移被误判低风险”的 collapse gap。

2. **Conditional Misalignment**
   - 直接告诉你：**rewrite 后的安全评测必须测 context trigger**；
   - 否则你看到的“安全提升”可能只是表面。
3. **GPT-Image-2 in the Wild**
   - 直接告诉你真实使用分布更偏**文本排版与传播型内容**；
   - 这会改变 prompt rewrite 的风险词表与场景覆盖。
4. **SkillGuard-Robust**
   - 提供 **anchor–rewrite consistency** 这个很适合直接搬到 rewrite 评测里的抽象。

### B. 迁移判断

#### 能直接迁的
- **语义 codebook 风险召回**：先检索风险语义近邻，再决定 rewrite 强度；
- **context-trigger evaluation**：在不同 wrapper 下测 rewrite 后是否仍能诱发风险生成；
- **anchor–rewrite consistency auditing**：检查同一原意的多个 rewrite 是否得到稳定安全判定；
- **分层成本架构**：轻判别 → 边界样本重判别 → rewrite → 再验证。

#### 不能直接硬搬的
- 不能把跨语言 jailbreak detector 直接当 NSFW rewrite judge；它更适合做**前置召回层**，不适合单独定 final label；
- 不能把 GPT-Image-2 的数据分布直接当你的业务数据真分布；它更像**真实部署参考分布**，不是业务专用 gold set；
- 不能把 SkillGuard 的 malicious / suspicious 三分类原样搬到 rewrite 任务；需要改成更适合你的标签，如：
  - `high_risk_rewrite_required`
  - `light_rewrite_recommended`
  - `safe_passthrough`

### C. 下一步实验建议

#### 实验 1：模糊 NSFW 风险 codebook 路由器
- 从现有高风险 prompt 与拒答模板中抽取风险锚点；
- 构建中文主、英中双语辅的 risk codebook；
- 评估指标：
  - 高风险召回率
  - 边界样本误报率
  - rewrite 触发覆盖率

#### 实验 2：context-triggered rewrite 评测集
- 每条原始 prompt 派生 4 类 wrapper：
  - 教学/科普
  - 艺术/摄影
  - 角色/剧情
  - 参数化 prompt 模板
- 对比：原 prompt、rewrite 后 prompt、rewrite + wrapper；
- 核心看 rewrite 是否只在“裸 prompt”上有效。

#### 实验 3：anchor–rewrite consistency 审计
- 每条高风险样本生成 3–5 个 rewrite 版本；
- 检查 judge 标签、风险等级、语义保持评分的一致性；
- 重点抓两类坏样本：
  - **假安全**：某个 rewrite 被误判低风险；
  - **过改写**：安全升了，但语义保持和指令遵循明显掉了。

## 当日趋势信号

### 趋势 1：T2I 工业安全正在从“模型内安全”转向“部署链路安全”
从 `GPT-Image-2 in the Wild` 到 `The Forensic Cost of Watermark Removal`，今天最强的共性不是更强的模型，而是**更真实的部署约束**：平台会剥 metadata、传播会改分辨率、攻击会留下残留痕迹。未来工业 T2I 安全的重点，将越来越像“证据链治理”。

### 趋势 2：输入侧安全改写不能只看文本表面，必须看触发上下文
`Conditional Misalignment` 明确说明，包装语境本身就是触发器；`Cross-Lingual Jailbreak Detection` 则说明语义近邻比字面更稳定。两篇合起来，对 prompt rewrite 的结论很清楚：**评测对象应该是“语义 + wrapper + 语言变体”，而不是单条 prompt 文本。**

### 趋势 3：鲁棒安全评测的关键是“一致性”，不是“单次命中”
`SkillGuard-Robust` 的 anchor–rewrite consistency 与 `SnapGuard` 的分层成本架构，都在提醒同一件事：工业安全系统要想稳定，不能只看单次判定对不对，而要看**不同改写、不同包装、不同成本层级下是否仍然稳定**。
