### 今日主题：判定的单位错了

前三轮依次是「部件合格 ≠ 组合安全」（11-23）→「分数没动，判定全换了」（11-24）→「钉死了输入，也钉不住出图」（11-25）。本轮六篇指向同一件事：**用「一个总数」判安全，本身就装错了单位**。

| 论文 | 被换掉的单位 | 换成的单位 |
|---|---|---|
| **HinT** | 整句 rewrite 后的文本 | 同一 slotted 模板下「修复 / 观测错误」两个 twin 的**速度差**；且须对齐槽位外 token states |
| **BODYBENCH** | PSNR / SSIM 单一像素代理量 | **性化 × 自然度 × 可辨认性**三栏；掩码形状 / prompt 分布 / 成功判据三层错位 |
| **TIDE** | 全图一个跳过阈值 | **每个指令部件自己的 compute budget**（Theorem 2：part-agnostic 规则无法保证异构预算） |
| **CRIE-Agent** | 「逐句 / 拆步执行」与 0/1 完整成功 | **最终编辑目标 + 四要件方向覆盖数**；完整成功率 0.0% 是判据无分辨率 |
| **VeriOrigin** | 单一水印判定 | **判定 / 信息（篡改定位）/ 事件（bit-exact 恢复）**三栏 |
| **Measurement Artifacts** | 基准分的变化 | **真实变化 + 仪器交互项**；检测器人工校准 + 评分协议对照 |

**对本项目最重的一句**：HinT 证明「**只改一个风险锚点**」在文本编码器里并不局部——单 slot 编辑会经注意力传播到全句 token，critic 在 **59%–74%** 的改写里加入未经要求的场景/光照。⇒ 「外科式替换风险锚点 + 语义保真」这套假设需要补一层**表示层一致性体检**；这与 11-25「重心转出图侧」不矛盾，而是把输入侧那一半的责任边界也钉死。

## 一、T2I / T+I2I 论文（核心主线 · 5 篇）

### 1. HinT：蒸馏「修正」而不是「改写」—— 输入侧语义保真的机制级反证

**机构**：**KlingAI Research（快手可灵）** + 复旦大学 + 华南师范大学 + 浙江大学｜**被测主干**：Qwen-Image-2512、SD3.5-M、FLUX.2-klein-base-4B（三种不同文本编码器）｜https://arxiv.org/abs/2611.31048

**问题**：VLM critic 为把修复说清楚，把 **10 词中位 prompt 扩写成 22–25 词**，并在 **59%–74%** 的修订里加入用户从未要求的场景、光照、措辞。只替换失败 span 会让 prompt 保持不变（原句本就写明想要的修复），所以「有意义的修订必须扩写整场景」——扩写本身带入未要求语义。

**机制（本轮最可迁移）**：① 单 slot 编辑会被文本编码器经双向/因果注意力**传播到周围所有 token**，「只改一个锚点」在 embedding 层不局部；② 整句改写的 teacher 更新方向与「改写漂移」$\Delta_{\text{drift}}$ 对齐（1,146 条 re-noised 失败样本的速度空间分解），压倒性的是漂移不是修复；③ 因此监督单位必须换成「同一 slotted 模板填修复 / 填观测错误」两个 twin 的**速度差**，并额外对齐槽位外 token states，共享的场景改写才相消。

**硬对照**：sunset-favoring critic 下两种基线产生 **45–97 个百分点**习惯接管、却只有极小或负的 GM 增益；sunset 出现率 **2.2% → 80%+**（冻结 teacher）/**98–100%（2 轮内，teacher 随学生更新）**，**HinT <4%**。三条独立反证：把改写加回目标 ⇒ 习惯回来且 alignment 不涨；prompt critic「克制改写」挡不住；强制最小编辑牺牲增益（FLUX.2 上 user-hindsight 崩到 10.4 EMA GM）。

**主结果**：GenEval2 held-out EMA GM 相对 base **+11.4 / +11.1 / +1.9 点**（45.3 / 30.7 / 25.4）；800 disjoint prompts 上 **49.0 GM（+17.2）**；零样本 GenEval / OneIG 三主干全涨；比标量奖励 RL（DiffusionNFT）高 **21.6 点**；训练时间 **+<4%**、**推理零开销**。

**局限**：组合对齐而非 NSFW/政治风险；需显式「错误+修复+槽位模板」三元组（线上只有原 prompt 与改写结果）；只测 rectified-flow，未覆盖统一生成-编辑 / I2I 双通路；无 TTFT/量化/serving setup。

**对本项目的落点**：**输入改写有效性上界归因补第五栏**——「改写引入的表示层漂移」。改写文本无害、字面改动极小，也仍可能全局改变条件分布。修法不是加严改写器，是补「非目标属性引入率」与「槽位外表示一致性」两个体检量。

### 2. BODYBENCH：防护成功率的读数几乎全是假的

**机构**：密歇根大学 + 普林斯顿大学｜https://arxiv.org/abs/2611.31774｜**11-25 新增批次**

**问题**：对抗扰动防护（PhotoGuard / DiffusionGuard / AdvPaint / DiffVax）都用 PSNR/SSIM + 通用 inpainting prompt 验收，而真实裸体化（AIG-NCII）恰是通过 inpainting 完成。作者判定这是 **problem-formulation failure**，错位三层：**掩码形状**（通用物体框 vs body/face/context + 攻击者 dilation+blur）、**prompt 分布**（"a dog in a gaming convention" vs `"A naked [woman/man]"`）、**成功判据**（像素差 vs 是否构成成功裸体化）。

**方法**：648 个全合成着衣成年主体 × 11 种掩码 = **7,128 张**；三个 harm-aligned 指标——**Sexualization（DefenseScore = 1 − S/2）/ Naturalness（PickScore）/ Recognizability（是否可辨认为特定主体）**，三者都低才算防护成功。攻击统一 SD v1.5 Inpainting、$\varepsilon=16/255$、每组合 3 seeds。

**读数**：仅 **AdvPaint body 变体在掩码精确对齐时**达 **0.951**（S 0.098 / R 0.090）；换成 body+context → **0.385**，dilation d=7 → **0.739**，BBox 变体 → **0.384**；PhotoGuard / DiffusionGuard 最好分别只有 0.403 / 0.420。DiffVax body+context 拿 0.725 但**产生肉眼可见噪声**（OOD + 扰动无上界），违背不可感知前提。**PSNR/SSIM 与裸体化防护基本不相关**。多数方法 R 降到 0.09–0.24 而 S 仍 ≥1.0 ⇒ 图里还是被换成裸体，只是不像原来那个人。

**局限**：只测 SD v1.5 Inpainting；全合成主体；只审计不提供新防护/新图审分类器；未报延迟/量化；未测输入改写链路。

**对本项目的落点**：**「掩码精确对齐」在结构上等价于评测集重叠**（11-25 `2611.29629`），理想化高分不可复现。图审 AB 必须补三栏判据 + 编辑强度/掩码族/预处理扰动格。

### 3. TIDE：一个全局阈值会先杀掉最细微的那个编辑

**机构**：印度理工学院德里 + **Adobe Inc., India**｜**被测主干**：FLUX.2 Klein 4B / Klein Base / **Qwen-Image-Edit-2511**｜https://arxiv.org/abs/2611.32407｜**11-25 新增批次**

一条指令常含多个编辑：放沙发让大量 token 大幅移动，给小杯子改色只让少量 token 轻微移动。**一个为速度调过的全局阈值会先冻结「慢而细」的编辑，用户要求的小改动直接消失**。

**方法**：TIDE 三阶段——① 用**非平衡最优传输**（4.2 ms，无需掩码/分割器/外部 VLM）把每个图像 token 绑到指令 part；② 只有当 token 的 drift **相对它自己所属 part** 足够小时才冻结（Proposition 1）；③ sparse engine 只算剩余 token。

**三条定理**：**Theorem 1** 全局阈值有精确代价，必然先破坏 drift 最小的部件；**Theorem 2** part-agnostic 规则**无法保证**异构 per-part 预算（决策必须看到部件身份）；**Theorem 3** 最优传输能保住 argmax 丢掉的弱部件。诊断很硬：**「token 的 drift 不 reveal 它服务于哪个 edit」**——信息本就在编辑器注意力里，只是没被用来分预算。

**读数**：全局阈值在 **89% 的 MICE-Bench 图像**上破坏至少一个编辑预算；TIDE 在 matched speed 下少丢 **48%（MICE-Bench，384→200）/ 最高 77%（LoMOE 8 steps）**，且 **2.09× → 2.20× 更快**；六个 benchmark 上 TIDE-fast **全部最快（2.20–2.24×）**；更接近 vanilla（LPIPS 0.291 vs 0.320），最差编辑对象 CLIP 21.94 vs 21.17；报了 **seed noise floor** 与人工复核。

**局限**：非安全任务；绑定依赖编辑器自身注意力（跨模块「改写器→冻结生图模型」不可直读）；Theorem 前提是可加误差，内容安全「一个部件漏过即整体失败」需重推；无 fp8/fp4 / 跨硬件 / serving setup 指纹。

**对本项目的落点**：**「改写强度分级下沉」第一次有了可证伪定理与「分档不牺牲延迟」的实测**；也是 I2I 0/0% 的**第八种可证伪归因：单一全局判定粒度**。

### 4. CRIE-Agent：直接编辑的完整成功率是 0.0%

**机构**：中山大学｜**被测主干**：Qwen-Image-Edit 2511、**Qwen-Image-2.1**、FLUX.2-klein-4B｜https://arxiv.org/abs/2611.27388

复杂编辑请求会**修订或撤销**前面的要求。直接一次性编辑读不出修订后的真实意图；拆成多步则早期被撤销的编辑已落到图上、视觉错误逐轮累积。作者洞察：**先把修订历史解析成一个「最终编辑目标」，让 planning 与 verification 共享它**，被撤销的请求根本不变成视觉编辑。

**CRIE-S**：10,000 条带**精确最终意图**标注的冗余编辑指令；评测 **对象正确性 O. / 属性准确率 A. / 空间关系 R. / 完整成功 S.**（全要件同时满足才算）。CRIE-Agent 微调 Qwen3-VL-8B-Instruct 折叠意图 → reference-first blocks（$k=2$，先建被引用对象）→ 验证器引导**从源图完整重执行**（带条件 layout hints）。

**读数（Table 1）**：三个后端直接编辑 O. 54–58 / A. 69–84 / R. 57–70，**S. 全部 0.0%**；既有编辑 agent 0–1.0%；**CRIE-Agent 抬到 27.5–50.0%**（Qwen-Image-2.1 **50.0%**、FLUX.2-klein-4B **27.5%**），五个后端 O./A./R. 全涨。⇒ 分层看还行、联合判据归零，是「整体-分层背离」的镜像；也第一次给 10-29 的「按方向覆盖数替代 0/1」提供公开实测支撑。

**局限**：非安全；Intent Agent 需 8B 微调（2B 改写模型现状需规则替代）；未明确跨语言；多轮验证 + 重执行会拉长 e2e（无延迟数据）；完整成功仍只到 27.5–50.0%，是必要非充分。

**对本项目的落点**：**I2I 0/0% 的第九种可证伪归因——验收判据没有可判的正例**；「冗余/撤销但字面中性」的指令也是 D6「中性 Prompt 语义取向漂移」对照臂的现成构造器。

### 5. VeriOrigin：编辑后水印还能读出多少

**机构**：北京理工大学 + 澳门理工大学 + 深圳北理莫斯科大学 + 宁波大学 + 深圳大学 + 中关村实验室｜https://arxiv.org/abs/2611.30523｜**兑现 11-25 日报「下轮优先精读」**

现有三范式各缺一角：鲁棒水印只有 provenance；versatile watermark（EditGuard / GenPTW）能定位但不能无损恢复；鲁棒可逆水印 RRW 能 bit-exact 恢复但不能定位。VeriOrigin 用 **XOnet**（Xnet/Onet 两个 CNN 子网络经 cross residual prediction 实现可逆）+ **两阶段训练**（先水印分支、后篡改定位分支）+ 推理期顺序嵌入，第一次把**判定 / 信息 / 事件**三栏做进同一框架。

**读数**：clean 定位 F1/IoU **0.995/0.990**（CocoGlide）、**0.995/0.991**（COVERAGE）、**0.974/0.950**（CASIA v2.0），显著高于 GenPTW 0.961/0.954 与 EditGuard 0.899/0.947；TGIF2 上 JPEG QF90 **0.960/0.929** → QF80 0.931/0.884 → QF70 **0.869/0.793**，EditGuard 在 blur/noise 上塌到 0.360/0.220。**Table 4 payload 位准确率**：tampered **1.000**、JPEG70 **0.949**、Gaussian σ23 **0.998**、resize 0.35 **0.999**、crop 30% 0.993；对照 GenPTW 0.974 / EditGuard 0.848（JPEG70）。`w/o wm` 对照臂显示**载荷最多花 2.3 F1 点**；无损通道 **bit-exact 恢复**。TGIF2 覆盖 6 个 inpainting 模型中的 5 个（FLUX.1 schnell/dev/Fill、SD2、Adobe Firefly）。

**局限**：主动保护前提（已流出的无保护图无效）；**不区分良性编辑与恶意编辑**（原文点名）；无损恢复仅在 lossless channel；未报延迟/量化；单图评测未覆盖 i2v/t2v。

**对本项目的落点**：**「编辑后水印存活率」终于有分档公开基线**；判定 100% 而信息/事件另报，可直接照搬进图审 AB 与被挡样本结构化事件。属**输出凭证层**（第五层），只证明「从哪来、哪里被改、原图是什么」，不阻止风险内容生成。

## 二、方法论迁移论文（1 篇）

### 6. Measurement Artifacts：量化后「安全率下降」有一半是尺子写的

**机构**：COMSATS University Islamabad + Middlesex University London｜https://arxiv.org/abs/2611.32848｜**模态**：T2T 小模型（135M–1.7B），作为量化/加速不劣化验收的**协议**迁移

把量化评测写成 $\Delta_{\text{measured}} = \Delta_{\text{true}} + \Delta_{\text{inst}}$：**在各精度下都相同的仪器误差只会缩小配对比较、不能创造或反转效应；与量化交互的仪器误差既能造出效应也能反转符号**，并被当作量化效应报告。固定 8 个模型 × float16 / LLM.int8() / NF4 × 相同 items，只变四个测量选择（拒答检测器 / 选择题评分 / 批处理 / 校准汇总）。

**读数**：两名标注者 100 条（含 10 条 XSTest 专测 over-refusal，κ=0.380/0.425）下，**baseline keyword detector 只召回 33.3% 的拒答**（印刷体撇号、长前言两种失败模式），corrected detector **80.0%/80.0%**。人工校准后 4-bit harmful compliance **+2.6 点**（WildGuard +3.0），而 detector 记的 refusal 降 **4.7 点** ⇒ 真实效应约为读数的一半到三分之二。2,000 条 HaluEval 上同一模型同一精度四种评分给出 **+9.8 / +0.8 / −13.6 / −7.3 点**，cloze 与 lettered 估计相关性 **ρ=0.10**（噪声天花板 ≈0.77）；NF4 在 **8/8** 模型显著改首选位置率（最多 +59.5 点）。**LLM.int8() 确定性但非 batch-invariant**：重排 batch 改变的答案是量化本身改变答案数的 **57–119%**，仅 padding 就改答案，8-bit 生成随 batch 顺序变化；激活保 float16 时消失，NF4 batch-invariant。ECE 80 个变化里 11 个显著（随机期望约 4）且方向不一致，两个最大「校准损失」其实是 response-bias 位移。

**迁移价值**：① 与 11-25 overlap 下界、评测集重叠污染并列的**第三种读数污染——测量仪器交互（可造出/反转效应）**，顺序固定「审计评测集 → 体检表示 → **体检尺子** → 约束式选点」；② 8-bit batch 依赖是**判定侧的 serving setup**，与生成侧 30545 合成「事件审计须同时记录生成侧与判定侧 batch/bit 宽/硬件」；③ 直接服务 2B 以下改写模型、qwen3.5 Pro5000 二阶段量化、fp8/fp4 降本的不劣化口径。**迁移边界**：可迁的是协议，不可迁的是所有量级；原文纯文本、全英文、无图审逐样本翻转率，也不含 TTFT/e2e/TPOT。

## 三、趋势信号

### 信号一：「外科式替换风险锚点」在表示层被正面证伪，输入侧责任边界钉死

HinT 的三条证据链——critic 59%–74% 修订加入未要求场景、单 slot 编辑经文本编码器传播到全句、改写漂移主导 teacher 速度方向——把本项目「只改风险锚点、不改原意」的假设从**工程直觉**变成**需要体检的物理约束**。⇒ 3,000 条 case 的归因在 11-25 四栏（生成过程 / 执行环境 / 权重残留 / 验收装置）之外补**第五栏「改写引入的表示层漂移」**；但仍**不支持回退去加严输入改写**——HinT 的修法是换监督单位（twin 速度差）与对齐槽位外表示，不是写更多改写规则。

### 信号二：判定单位从「一个总数」下沉到按部件、按栏、按仪器，且都有定理或人工校准撑着

TIDE **Theorem 2** 证明 part-agnostic 规则无法保证异构预算；BODYBENCH 证明三栏判据与单像素代理量不相关；VeriOrigin 把判定/信息/事件分栏并量化载荷代价 ≤2.3 F1；Measurement Artifacts 把读数拆成真实项与仪器项；CRIE-S 用「0.0% 完整成功」证明联合判据无分辨率。⇒ 「per-category threshold tuning / 分级处置策略 / 分业务粒度阈值管控」在本轮从**经验偏好**升级为**有可证伪依据的架构要求**。

### 信号三：I2I 0/0% 的第八、第九种归因同日到货，且都零训练可检验

### A. 直接可迁移方法

#### A1【最优先，零训练，1 天】输入改写有效性上界归因：四栏扩为**五栏**（新增表示层漂移）

**现状**：3,000 条改写后仍被色情 400 打击的 case，约 10 条属改写文本仍有害、约 **2,700+ 条为改写后文本无害但出图侧内生风险**。11-25 按四条机制拆：① 生成过程改写（CFG guidance）② 执行环境漂移（batch/GPU/精度）③ 表示层残留（SAE 方向）④ 判定层代理量。本轮按 HinT 补第五栏：

| 栏 | 判据 | 对应修法 |
|---|---|---|
| ① 文本复核仍有害 | 人工双盲判改写文本有害 | 输入改写（占比应极小，**其余预算冻结**） |
| ② 生成过程改写 | 同一改写后 prompt，全量 vs 线上加速，原子要件保留率差 >10 点而图像级质量分差 <2% | CFG guidance 项两分支重算 |
| ③ 执行环境漂移 | 同 prompt + 同 seed，solo vs batch / 全精度 vs fp8-fp4，图审判定翻转 >3% | 冻结 serving setup 指纹 |
| ④ 表示层残留 / 判定层代理量 | 反事实还原或注入方向后风险回来；灰图纯文本探针 AUROC ≥0.90 | 判定推理结构改造 + 表示层审计 |
| **⑤ 改写引入的表示层漂移（本轮新增）** | **非目标属性引入率 >10%**；或 (B) 只替换锚点词版与 (C) slot-twin 版判定差 <5 点 | **换监督单位（twin 速度差 / 槽位外表示对齐），不是写更多改写规则**（HinT） |

**判据**：② ③ ⑤ 任一栏占比 >20% ⇒ 「改写还不够严」这个归因正式作废，**不得再启动输入改写加严实验**。

#### A2【最优先，零训练，半天】出图侧生成过程干预：**五臂**保持不动输入、不动权重

固定**同一份改写后 prompt**，200 条「文本无害但被打击」样本：① 原样全量生成（batch=1、全精度）② 负向 prompt / CFG 安全引导 ③ 子概念 + 空间局部引导（EBSG）④ 仅对 guidance 误差大的 token 重算条件+无条件两分支（GuideCache 思路）⑤ 线上真实加速配置（缓存/少步/fp8-fp4 + batch>1）。**必报**：出图风险率、主体/属性/关系原子要件保留率、FID 代理、**图审判定翻转率**、单次 e2e 延迟。所有臂输入 prompt 完全相同。**判据**：④ 显著优于 ② 且保真不掉 ⇒ 重心在生成过程 guidance 项；⑤ 相对 ① 判定翻转 >3% ⇒ 加速链路本身就是风险来源。

#### A3【零训练，半天】风险知识召回降级兜底：本轮**零供给**，按自建口径落地（A4 沿用 + 补两条）

`t14_policy_guard` 5 篇逐篇核验 0 可迁移。11-16 安全指令库评审口径继续自建：

- **L0 词表精确匹配 > L1 向量库 top-k**（命中优先级不变）；指令 ≤3 条直接拼接，>3 条按相似度与阈值距离排序取 top3；
- 三条**降级路径各自留事件**：拼接失败 / 召回超时 / 词库或相似度服务不可用 ⇒ 整体降级到拒答，但必须带 `失败原因 + 版本 + 规则指纹`；
- **必须显式配置超时**（Proxy 侧 safe_word 二级服务）；
- **本轮新增（TIDE Theorem 3）**：**召回不能只取 argmax / top-1**——弱命中部件必须保留（最优传输类分配），否则长尾风险锚点会像细微编辑一样先被丢掉；
- **本轮新增（Measurement Artifacts）**：降级到拒答的判定必须计入「假安全拒答」体感指标，且**拒答检测器本身先做人工双盲召回审计**（33.3% → 80.0% 的差距说明读数可能是尺子写的）；
- 做「随机花预算 vs 按分数排序」对照（27268：随机 37.20 帧 vs 排序 2.35 帧）。

#### A4【零训练，半天】推理加速 / 量化不劣化验证：**六栏扩为八栏**

| 栏 | 指标 | 判据 |
|---|---|---|
| 判定 | 全精度 vs 量化后逐样本判定翻转率（按一级类目 × L2_30 分格） | >3% ⇒ 历史 AB 按版本重算 |
| 方向 | harmful / helpful flips **分列** | 两向抵消 ⇒ 聚合分假稳 |
| 中间 | 改写候选选择变化率 / 策略命中条目变化率 | 选择变化 ≫ 最终结论变化 ⇒ 决策层已换 |
| 尺子 | judge 示例标签平衡冻结 + 五次抽样 + 人工共识双盲 | Bias >+15 点或极差 >10 点 ⇒ 作废 |
| 生成侧语义 | 全量 vs 加速的原子要件保留率 / word accuracy / OCR 语义要件 | 图像级分几乎不动而要件掉 >10 点 ⇒ 加速在做静默改写 |
| serving setup | batch / bit 宽 / GPU / 缓存方法 / 步数，**写进事件审计必填字段** | 缺任一 ⇒ 该轮 AB 不可复现 |
| **测量仪器项（本轮新增）** | 测得变化 = **人工校准估计 + 检测器版本 + tipping-point 区间**；拒答检测器召回/精确率 | 召回 <80% ⇒ 误杀率按 corrected detector 重算 |
| **判定侧 batch 不变性（本轮新增）** | 重排 batch / 加 padding / 换 bit 宽的逐样本判定变化率 | LLM.int8() 类非 batch-invariant ⇒ 判定侧也必须报 serving setup 指纹 |

叠加 27339 的缓存探针口径（`prefill 增量 %`、batch=1 绝对延迟、图像不相交切分召回、跨评测集 AUROC）。**0.36% prefill 只证明探针便宜，不证明链路不劣化。** 8-bit 与 NF4 必须**分开报**（前者非 batch-invariant，后者改位置偏好）。

#### A5【零训练，半天】权重侧边界写死（第十三轮，方案层）

四层通路升级为**五层**（新增输出凭证层）：输入侧热更新改写（唯一支持秒级回滚/逐条回滚/分业务配置）· 权重侧概念擦除（SAE-Audit：行为层归零 ≠ 移除）· 生成过程干预（不动输入不动权重）· 输出侧图审与溯源（VeriOrigin 管不了输入策略、不判恶意意图）· **输出凭证层（bit-exact 恢复 + 篡改定位，只证明来源与改动，不阻止生成）**。**任一层单独宣称内容安全已解决即判越界**。新增验收：任何「已擦除 / 已消除」结论须过反事实恢复对照；任何「水印已达标」须报 payload 准确率 + 定位 F1 + 无损恢复率三栏。

**权重侧 vs 输入侧互补而非替代**：擦除是上线前的权重侧治理，改写是上线后的输入侧热更新；前者管不住新出现的锚点词，后者管不住已生成出去的图，也管不住表示层残留。HinT 进一步给出二者共有的失效面——**任何以「整句改写 / 全量替换」为形态的监督都会被文本编码器扩散**。

#### A6【验收口径，零训练，半天】判定 / 信息 / 事件三栏 + 用户侧误伤体感（本轮补两行）

| 体感 | 本轮机制证据 | 建议监控指标 |
|---|---|---|
| "我没写违规内容却被拒" | 23685 结构性 overlap；TIDE Theorem 1 单一阈值先杀细微部件 | 按一级类目 × 主题切片误杀率 + **每类目 overlap + 每部件预算达标率**；「没出图」与「被拒」分列；申诉回捞率 |
| "明明检查过了还是出图" | 30117 行为层 0.00 而恢复层 0.48–0.77；BODYBENCH PSNR 与防护不相关 | 分类器判低风险但人工双盲仍判有害的比例 + 反事实恢复率 + 三栏判据一致性 |

### B. 风险锚点处理启发（双锚点：PORN/VULG 边界 + 政治 L2_30 层级）

#### B1 PORN/VULG：本轮给出**第八种**解释 —— 「锚点替换在表示层不局部」

| 1 | **非目标属性引入率**：100 条 `VULG-HINT-EDGE` 改写前后人工标「场景/光照/数量/极性是否被新增」 | >10% ⇒ 现有语义保真指标结构性漏报 | 补第五栏进验收（A1） |

#### B2 政治 L2_30：分层口径的三个前置条件本轮补齐第三个

11-25 已给两个：overlap 随 cell 粒度 `K_z=50/200` 变化（**分层口径本身是变量**）、低 FPR 区读数被评测集重叠污染且**不跨模型抵消**。本轮 **Measurement Artifacts** 给第三个：**测量仪器（拒答检测器 / 评分协议 / batch）与量化交互能凭空造出或反转效应**，且方向不一致（HaluEval 3 升 3 降、BBQ 一升一降）。**TIDE Theorem 2** 再给一条定理级支撑：**part-agnostic 规则无法保证异构 per-part 预算** ⇒ per-category threshold 不是调参偏好，是必要条件。

| # | 做法 | 判据 | 含义 |
|---|---|---|---|
| 1 | 按 L1 × L2_30 逐格报 FPR、判定翻转率、**overlap**、`N_eff`、**检测器召回率** | 全局稳而某叶子翻倍 / 该叶 `N_eff` 或检测器召回不足 | 聚合口径掩盖子类劣化；继承父类阈值并写明降级口径 |
| 2 | 每类目标注 `样本数 / 人工一致率 / 是否低代表 / 评测集重叠率 / 检测器版本` 五元信息 | 某叶子 <200 样本、一致率 <70%、重叠率 >0 或检测器召回 <80% | 先修数据、表示与尺子，不可单独调阈值 |
| 3 | 报 L1–L4 等级分布与各级患病率 | 一级一致率相同而分布差 >10 点 | ordinal calibration 先于调阈值 |

#### B3 跨锚点共同结论

两个锚点这轮的答案都是：**先分清「判不出来」「判定装置在读代理量」「替换动作在表示层扩散」「读数本身被仪器污染」**。四者都不需要重新标注或重训，各半天到一天；且都指向同一句话——**不要在输入侧加码，先把验收单位与验收装置修干净**。

### D. 下一步实验建议（六条主线）

> 排序原则：先做零训练、能一次结束纠结的；算力按 **训练集群 6 节点 → 5 节点** 的现实排。**明确：本轮不再把重心放在加严输入改写。**

#### 主线①【tag-weighted loss / 层级标签】D1：L1 × L2_30 双列 + **五元信息** + 约束式选点（半天，零训练）

出 `AUROC × BA × 样本数 × 人工一致率 × **评测集重叠率 × overlap × 检测器召回率**`，按「识别型 / 判定型」二分；标出 <200 样本、一致率 <70%、overlap >0.5、检测器召回 <80% 的饿格子。依据 **VeriOrigin 载荷代价 ≤2.3 F1 点** 与 **TIDE 层次消融**：单列最优与约束最优不一致。做法：把 6 版本看板改成「五列 + 约束式选点」（如「保真不低于基线 −0.5 前提下最小化风险率」），检查单列最优版本在约束下是否仍入选。**判据**：不一致 ⇒ 现有按总分选 ckpt 的口径作废；判定型格加权后 F1 不升反降 ⇒ 降权而非加权重。

#### 主线②【RL 改写】D2：GRPO 与 SFT 线的奖励设计对比（1 天，零训练前置 + 轻训练）

**GRPO 线（devcloud `grpo1102_125`）vs SFT 多版本并行线**，同一张表报：

| 对比项 | GRPO 线 | SFT 线 | 判据 |
|---|---|---|---|
| 主奖励 | 安全率 | 监督信号 + tag-weighted loss | 安全率提升是否伴随语义保真下降 |
| 可验证奖励 | **G7 前置**：50 条高危 prompt × 原样/微改/真改写三版 | 不适用 | 原样一致性分显著更高 ⇒ 奖励可作弊，停 |

#### 主线④【输出侧图审与溯源】D4：五栏拆分 + **五臂生成过程干预**（1 天，推理为主，**明确不再加严输入改写**）

按 A1 把 **2,700+ 条**拆成五栏（新增改写表示层漂移）；按 A2 做**固定同一份改写后 prompt** 的五臂生成对照，每臂报出图风险率、原子要件保留率、图审判定翻转率、e2e；图审 AB 加 **BODYBENCH 三栏判据**（性化/自然度/可辨认性）与**编辑强度 × 掩码族 × 预处理扰动格**；按编辑强度轻/中/重分档测水印检出率，报 **VeriOrigin 三栏**（payload 位准确率 / 定位 F1 / 无损恢复率）与载荷代价。

**判据**：guidance 项重算臂显著优于纯 CFG 引导 ⇒ 生成过程干预是主修法；加速臂相对原样判定翻转 >3% ⇒ 先把 serving setup 写进事件审计；三栏判据一致性 <90% 或轻编辑档 payload <90% ⇒ 撤回「图审/水印已达标」；PSNR/SSIM/CLIP 与人工判「是否仍有害」相关性 <0.3 ⇒ 这些代理量不得进验收主指标位。

> **责任边界写死**：归因已明确 2,700+ 条源于出图侧 ⇒ **输入改写优化预算冻结**；输入侧只保留「文本复核仍有害」的极小比例修正与 A1 第五栏体检。**不再把重心放在加严输入改写**。

#### 主线⑤【I2I 改写链路（含统一生成-编辑模型改写面）】D5：0/0% 的**第八、第九种**归因（1 天，零训练，**优先级仅次于 D3**）

**背景**：I2I 改写分流命中 **0/0%**（输入侧色情模型灰度 **70%** 与改写分流 **0/0%** 并存）。九种归因：判据无分辨率 / 改写没写好 / 改写抹掉要件 / 分流只读文本通路（UNR 格）/ benchmark 允许单模态通关（灰图探针）/ 编辑前后对照被 batch 非确定性污染 / 粗粒度路由结构性 overlap / **本轮新增：单一全局判定粒度（TIDE Theorem 2，89% 破坏至少一个部件预算）** / **验收判据没有可判的正例（CRIE-S 五后端完整成功全 0.0%）**。

**可落地建议（针对 70% 灰度与 0/0% 并存）**：

1. **先修执行环境，不要重写改写器**：从 2000 条评测集抽 200 条，把「编辑前后其余保持原样」的判定强制改成 **solo-vs-solo 同 batch / 同精度 / 同 GPU 配置**；若命中率变化 ⇒ 0/0% 里有一部分是**对照本身不可判定**（30545 引言直接以 image editing 为例）。
2. **把分流从 0/1 改成带分数的多候选排序 + 按 $K$ 报方向覆盖数**：按指令部件数 $K=1/2/4/8$ 分档报命中率；若命中率随 $K$ 单调下降 ⇒ 第八种归因成立（贴 TIDE Theorem 1/2）。这条最贴 70% 灰度：灰度已在跑，先把输出从「是否改写」改成「每个部件一个改写强度分 + 2 候选排序」，即可在不重训的前提下让 0/0% 变成可观测的分布。
3. **四要件重打标替代二值判据**（CRIE-S）：人工标「主体 / 操作 / 目标区域 / 撤销项」，按「0 个 / 全部 / 均匀」三档定归因；「全部要件读出」占比高 ⇒ 下游编辑能力问题，不是改写问题。
4. **意图折叠前置**：构造「含撤销/修订但字面中性」的三语版本，比对「原样 / 规则折叠撤销项 / 折叠+分部件强度」三版命中率 ⇒ 折叠后升 ⇒ 0/0% 里有过时意图被当有效请求。
5. **统一生成-编辑模型的改写面**：固定一份改写后 prompt，分别走生成通路与编辑通路，报两通路风险判定差与四要件保留率差（AnimalFarm 三通路 66.6/68.0/75.3）。**判据**：差 >15 点 ⇒ 不能共用一份改写，必须按通路分流下发；差 <5 点 ⇒ 可共用但要把图文联合状态作为共同输入。本轮 `t9_unified_edit` 零供给，此项按自建口径落地。
6. **补灰图纯文本探针上界检验**（27339）：AUROC ≥0.90 ⇒ 验收集有词捷径，重写改写器无效。

**为什么这条最省钱**：全部是重打标 + 重跑现有链路 + 加两个探针 + 改输出格式，零训练、不重做评测集。
