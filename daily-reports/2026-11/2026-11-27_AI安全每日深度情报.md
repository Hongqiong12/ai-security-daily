### 今日主题：把「一个增益」拆开

前四轮依次是「部件合格 ≠ 组合安全」（11-23）→「分数没动，判定全换了」（11-24）→「钉死了输入，也钉不住出图」（11-25）→「判定的单位错了」（11-26）。本轮六篇指向同一件事：**连「涨了多少」这个数本身也装错了单位**。

| 论文 | 被当成的一个数 | 拆成的单位 |
|---|---|---|
| **Flow-GRPO 解剖** | GenEval 0.63→0.95 | 按**技能**拆：4 个是「锐化」（base 本就会，1 个 RL 样本 = 4–10 个 base 样本、pass@32 不动）、1 个是「解锁」（Δceiling +0.31） |
| **RL = Activation Steering** | RL 的奖励增益 | 按**参数自由度**拆：0.29M 常数向量（LoRA 的 1/65）恢复 **90.0–96.3%** ⇒ 多数增益不需要输入相关变换 |
| **PreserveReward** | 一个一致性/相似度分 | 按**证据**拆：局部细节 / 全局语境 / 是否符合编辑意图；且「必要修改 vs 意外改动」必须分栏 |
| **T2ISpec** | 一个 Overall 加速比 | 按 **topic × 难度**拆：AR ±20% 偏离；−42.0% work 只换 **1.0889×**；Overall 0.0000 掩盖 text +0.0233 / commonsense −0.0242 |
| **Lost in Translation** | 英文上调的一个阈值 τ | 按**语言**拆：τ 在中文只有 93.1%、泰米尔语 90.0%；置信度只跟着掉一半 |
| **What/Who/When** | 一个 unsafe 标签 | 按 **what / who / when** 三轴拆，且把「判定」与「处置」分到两层 |

**对本项目最重的一句**：`2611.33316` 与 `2611.26627` 从两个独立角度（样本覆盖 / 参数自由度）证明——**「安全率涨了」不能自动记成「改写策略变强了」**。若涨分主要是「锐化」或「常数可解释」，加训练、加数据、加轮次全是错修法；只有被判定为「解锁」的部分才需要动训练。这是 D2（GRPO vs SFT）启动前必须过的零训练闸门。

## 一、T2I / T+I2I 论文（核心主线 · 4 篇）

### 1. Flow-GRPO 按技能解剖：0.63→0.95 里，四个技能是「锐化」，一个是「解锁」

**机构**：North Carolina State University + Purdue University｜**主干**：SD3.5-M / Flow-GRPO｜https://arxiv.org/abs/2611.33316｜**11-26 新增批次**

**问题**：Flow-GRPO 把 SD3.5-M 的 GenEval 从 **0.63 抬到 0.95**，通行解读是「学会了组合生成」。作者用共享噪声种子下的 **pass@k**、逐个技能、训练中未出现的 prompt 追问：这 0.32 分有多少本来就在 base 样本里？

**两个可操作定义**：存在 $k^*\le32$ 且 ceiling 上升 ≤0.02 ⇒ **锐化**（只重排组内已有成功，推理侧 best-of-k + verifier 可买）；不存在 $k^*$ 且 Δceiling 明显 ⇒ **解锁**（需跨 prompt 共享方向累积，只能训练侧给）。

**硬读数**：四个技能（single/two objects、counting、colors）RL 的 pass@1 = 0.98/0.95/0.94/0.89，恰是 base 用 **4/10/8/5** 个样本能达到的水平，`pass@32` 最多动 **0.013**；best-of-4/16 回收 **76%/90–95%** 增益。空间关系则 base `pass@1 0.16→0.94`、`pass@32 0.76→1.00`（**Δceiling +0.31**），**31 个零覆盖 prompt 中 93% 被救**，`pass@128=0.89` 仍低于 RL 的 `pass@1=0.94`，best-of-4 只回收 **41%**。LoRA dial 显示关系技能 **ceiling 先动（0.60→0.82→0.96→1.00）而 pass@1 后动** —— 这是解锁的指纹。训练顺序对照（Run B）证明**锐化先到且到处都到（含未见对象），解锁晚到且按对象逐个到**，故「早期奖励上涨不构成技能已获得的证据」。

**局限**：单一 base / 单一算法 / 单一奖励；judge 既做奖励又做验收（无人工评测）；GenEval 六技能里四个没有 headroom，结构上无法观测解锁；不涉 NSFW / 跨语言 / I2I 双通路；无 TTFT / 量化 / serving setup。

**对本项目的落点**：**「安全率涨了」不是一个结论，先报 `k*` 与 Δceiling 判锐化/解锁**。锐化就把预算转 best-of-k + 图审 verifier；解锁才动训练配比 —— D2 的前置闸门，零训练一天可出结论。

### 2. RL 后训练就是 Activation Steering：常数向量恢复 90–96.3% 的奖励增益

**机构**：Virginia Tech + fal + Georgia Tech + **IBM Research**｜**主干**：SD3.5-M / FLUX.1-dev / Wan2.1-1.3B / Wan2.2｜https://arxiv.org/abs/2611.26627｜项目页 https://rl-is-steering.github.io

在冻结 base 的每个 block 输出上加一小组**固定 steering vectors**（对每个 prompt / token / seed 完全相同），共 188 个向量、**288,768 参数 = rank-32 LoRA 18.8M 的 1/65**。拟合目标是与 RL-tuned 模型的**速度预测对齐**（velocity matching），**目标函数里没有奖励、不需要采样循环**。

**主表（Table 1）**：六个 image ckpt 恢复 **90.0%（FLUX PickScore）/ 90.8%（SD3.5 PickScore）/ 94.4%（OCR）/ 95.2%（no KL）/ 95.9%（GenEval）/ 96.3%（DanceGRPO HPSv2.1）**；两个 video ckpt **89.8% / 111.9%**（>100% 表示拟合版在该奖励上超过 RL ckpt 本身，不等于复现其行为）。无训练的 mean-difference 基线只恢复 12.2–79.0% ⇒ **不是随便一个常数方向都行，拟合 scale 与注入位置才是关键**。反超对照：冻结生成器、只对 steering vectors 跑 Flow-GRPO，达 OCR-tuned 增益的 **104.6% / 103.6%**。

**理论关系**：LoRA $\Delta W=ba^\top$ 是「固定方向 × 输入相关权重」；steering vector 把那个权重**钉成常数** ⇒ 二者是同一自由度谱系的两端，不是两种东西。

**局限**：八个奖励全是质量/OCR/组合/偏好，**零安全语义**；只在 diffusion transformer / rectified-flow 验证；无 TTFT/量化/跨硬件/serving setup；拟合需拿到 RL ckpt 生成样本，线上「只有 base + 改写器」不能直接用；作者禁止把「恢复 90%」读成「RL 只做了这一步」。

**对本项目的落点**：与 Flow-GRPO 解剖构成**独立双证据**。若 `grpo1102_125` 的安全率提升主要落在「常数可解释部分」，则收益上限由**奖励稀疏 / 策略容量**决定而非模型规模，该改的是奖励密度（twin 速度差 / 逐 token 条件差，HinT）与验收单位，不是继续堆训练。0.29M 参数也是 6 节点→5 节点下最省的一条改进路径。

### 3. PreserveReward：一致性奖励必须能判「该改的改了、不该改的没动」

**机构**：**JD.com（京东）** + 中科大 + 华南理工 + 南京大学｜**被优化主干**：**Qwen-Image-2.1**｜https://arxiv.org/abs/2611.34446｜**11-26 新增批次**

指令式编辑的老问题是改了不该改的地方；现有 reward model 分不清「指令要求的修改」与「顺带发生的破坏」。作者用**双教师 On-Policy Self-Distillation**：local teacher 看匹配裁剪抓细节，joint teacher 看裁剪 + 全图判断变化**是否符合编辑意图**；两个防「教坏」机制——**minimum-KL 投影把教师分数分布校准到误差预算 0.01**、**按与 Score-MSE 梯度的对齐度路由教师，双负则跳过本次蒸馏**。额外局部证据**只在训练用，推理期零开销**。

**读数**：Table 1 上 PreserveReward-27B 达 **84.70% / 84.60% / 80.73%**（后两者为 OOD），9B 版 **80.60% / 78.93% / 76.61%** 超过所有开源 reward model 与多数更大 VLM；相对底座 Qwen3.5-9B **+40.80 点**。消融（Table 3）显示梯度路由「双负跳过」单项值 **+4.7 点**（75.90→80.60）。

**最扎的反例（Table 2）**：以 Qwen-Image-2.1 为 policy 做 RL，**EditScore-72B / RationalRewards / UnifiedReward 在 GEdit-v1 上反不如 Base（8.73/8.47/8.57 vs 8.86）**，而 KRIS-Bench 上 UnifiedReward 却涨到 3.85 —— **同一个奖励器在不同评测集上方向相反**。PreserveReward-27B 则三榜全涨（8.99 / 9.02 / **4.07** vs Base 8.86 / 8.83 / 3.67）。

**局限**：纯视觉一致性、零安全语义；不覆盖统一生成-编辑双通路；无跨语言、无延迟/量化/serving setup；迁移到安全分类需把人工参考分换成有害性双盲标注，且必须保留「双负跳过」而非硬选 top-1。

**对本项目的落点**：**「语义保真」不能是一个整体相似度**。三栏一致性（局部/全局/意图）是 I2I 0/0% 归因的现成验收量；双教师 + 梯度路由 + 「都不采纳」的降级形态，可直接搬进风险知识多路召回兜底（A3）。

### 4. T2ISpec：减了 42% 的活只快 1.09 倍，Overall 0.0000 掩盖两个方向相反的 topic

**机构**：密歇根大学安娜堡 + 斯坦福 + 宾大 + 俄亥俄州立 + 南洋理工 + Independent｜https://arxiv.org/abs/2611.29029｜**兑现 11-26 日报「下轮优先精读」**

1,400 prompts × **7 个渲染 topic** × 2 难度，强制 paired Target-only 下**同时报 latency / target work / quality**。三条主发现：① 聚合结果掩盖 topic 大差异（AR 偏离 **±20%**、diffusion/flow **±4%**；PathSpec 2.8283–3.8270× 跨度 35.31%）；② alignment / preference 与 prompt 约束满足可以不一致（换 evaluator 后 text topic 掉）；③ 大幅削减 target work 只换有限 latency —— **ADT-Tree −42.0% work → 仅 1.0889×**。

**最干净的背离样本**：ADT-Tree 在 Janus-Pro 上 Overall criterion **0.0000**、latency ratio **0.9949**，却掩盖 **text +0.0233 / commonsense −0.0242**。SpeCa 阈值 5→9 使 latency ratio 4.284→5.134，而 Easy **+0.0383** / Hard **−0.0517** ⇒ **单一阈值跨难度方向反了**（TIDE Theorem 2 同构）。免重训插件 TopicRoute 六组几何平均 **1.0308×** 且可迁到外部 DrawBench，但明确「quality 变化依 backend/topic/metric 而变」。

**局限**：只测加速与渲染质量、零安全语义；未报 TTFT/e2e 绝对值 / TPOT / 超时率 / fp8-fp4 / 跨硬件 / serving setup；TopicRoute 仅 1.0308× 量级且新增一个可能 misroute 的判定层。

**对本项目的落点**：**「加速了多少」也必须按类目 × 难度拆开报，并配「省了多少计算」与「安全率/分层 F1 掉没掉」两列**。这是 `Δaggregate` vs `Δmacro` 背离检测最干净的公开模板，直接服务量化/加速上线前不劣化验收。

## 二、方法论迁移论文（2 篇）

### 5. Lost in Translation, Not in Confidence：英文校准的 95% 阈值，中文只有 93.1%、泰米尔语 90.0%

**机构**：南洋理工大学 + 新加坡国立大学 + VinUniversity｜https://arxiv.org/abs/2611.33307｜**11-26 新增批次**｜**模态**：T2T decision models，作为**跨语言阈值校准协议**迁移

Decision models 是「对每个 typed query 的每个选项返回概率」的模型，router / guardrail **直接对概率设阈值** —— 与本项目「阈值下发 / 命中判定」是同一个动作。25 个开源模型 × 17 子类 × 14 语言 × **25,626 条平行条目**，同 item 跨语言配对控制难度，定义 **Gap = ΔConf − ΔAcc**。

**读数（Table 1，25 模型均值）**：全部 **325** 个 model–language pair 掉准确率（马来 −1.6 到泰米尔 **−7.8** 点），**301** 个过度自信上升；`ΔAcc 均值 −3.5` 而 `ΔConf 仅 −1.8`（**置信度只掉一半**）。英文上钉 95% 实际准确率的阈值 τ，搬到各语言后实际为 **泰米尔 90.0% / 斯瓦希里 90.6% / 中文 93.1% / 均值 92.6%**。全部 8 个 Qwen3.8 模型在泰米尔语掉 **13.6–17.8 点**。**per-language temperature scaling（500 items）把 pooled ECE 4.1%→2.9%**（校准可修），但准确率缺口仍在（微调修不回）。方差分解：**语言 60% + 底座 34%**，与排行榜名次无关；最尖锐的 Gap 落在 Swahili safety 与 Tamil knowledge，而 reasoning 子类 Gap 近零却照样掉分 ⇒ **必须按「语言 × 任务/类目」分格报**。

**迁移边界**：纯文本、无图像/生成/改写；每 cell ≤100 items 噪声大；**中英 code-switching 未覆盖**（D6 九格须自建）；未报 TTFT/量化/serving setup/检测器版本；**校准合格 ≠ 安全合格**（与 11-25「行为层归零不构成移除证据」同构）。

**迁移价值**：给「2B 改写模型英文 ASR 飙升」一个**机制级解释**——非英文侧的过度自信让「判低风险」样本系统增多；且证明**先做 per-language 校准体检再决定要不要中英合并训练**，别把「校准问题」和「能力问题」混成一个指标。

### 6. What, Who, and When：把「判有害」与「怎么处置」拆成两层，策略写在权重外

**机构**：**Sword Health** + Yale University + Instituto Superior Técnico｜https://arxiv.org/abs/2611.33263｜**11-26 新增批次**｜**模态**：T2T guard model，作为**策略可配置护栏架构**迁移

现有 guard model 把每个 turn 打成「安全/不安全」，**下游处置直接绑在标签上**；作者点破「因为行动边界被绑在标签上，换一套策略就要重标注 + 重训」。方案：模型只输出 **(what, who, when) 三元组**（伤害性质 / 源→目标 / 时间阶段；自伤是 who 轴的一个配置而非单独类目），`triplet → safety protocol` 的映射是**临床医生策展、可编辑可审计的决策树**。⇒ **策略热更新 = 换映射表，不动权重/数据/标注**。

**分维加权评分 3WS**：`λ_what·1[what] + λ_who·½(1[src]+1[tgt]) + λ_when·c(when)`，what/who 高权、when 低权 —— 依据是标注一致性：what/who **>89%**，而 **when 在 RealMHS 只有 0.53**（Table 2；safe/unsafe Fleiss' κ 0.70/0.73）。这是「层级越靠序数/语境的轴，一致率越低」的实测，直接对应 L2_30 层级口径与 tag-weighted loss。

**效率与误杀**：MindGuard2（Qwen3.6-35B-A3B）用 **short-rollout SFT → RL with reasoning-length penalty**；balanced accuracy 与 GLM-5.3 相当而 **median latency 约低 10×**；发布版（纯合成数据）FPR **0.09/0.02/0.03**、R 0.92/0.84/0.87。消融显示**推理收益集中在三元组（3W 0.72→0.90）而非二分类（BA 0.81→0.91）**，且非推理模型更快（0.25s vs 0.58s median）⇒ **细粒度标签才需要 CoT，二分类不需要**。原文明确 over-flagging「打断对话、破坏信任、把用户赶走」——「假安全」拒答体感的学术表述。

**迁移边界**：领域是心理健康文本，非 NSFW / 政治 / 图像；**只给「映射表可编辑」，没给词库+向量库混合召回、超时、拼接失败、命中优先级等工程链路**（仍需自建）；策略库与模型输出不同步会静默错配，本文无版本治理；无跨语言 / I2I / 图审 / 生成过程干预；延迟只报 median 相对值。

**迁移价值**：连续六周 `t14_policy_guard` 零可迁移后**首次实质命中**，一次给齐「策略热更新 + 层级标签 + 分维加权 + 误杀体感 + 短 CoT 延迟」五条，可作 A3 与 D1 的参考实现。

### A. 直接可迁移方法

#### A1【最优先，零训练，1 天】输入改写有效性上界归因：五栏保持，新增第六栏「奖励机制」

3,000 条改写后仍被色情 400 打击的 case，约 10 条属改写文本仍有害、约 **2,700+ 条为改写后文本无害但出图侧内生风险**。11-25 四栏 → 11-26 第五栏（改写引入的表示层漂移）→ 本轮补**第六栏「GRPO 增益机制」**：

| 栏 | 判据 | 对应修法 |
|---|---|---|
| ① 文本复核仍有害 | 人工双盲判改写文本有害 | 输入改写（占比应极小，**其余预算冻结**） |
| ② 生成过程改写 | 同一改写后 prompt，全量 vs 线上加速，原子要件保留率差 >10 点而图像级质量分差 <2% | CFG guidance 项两分支重算 |
| ③ 执行环境漂移 | 同 prompt + 同 seed，solo vs batch / 全精度 vs fp8-fp4，图审判定翻转 >3% | 冻结 serving setup 指纹 |
| ④ 表示层残留 / 判定层代理量 | 反事实还原或注入方向后风险回来；灰图纯文本探针 AUROC ≥0.90 | 判定推理结构改造 + 表示层审计 |
| ⑤ 改写引入的表示层漂移 | 非目标属性引入率 >10%；或「只替换锚点词」版与「slot-twin」版判定差 <5 点 | 换监督单位（twin 速度差 / 槽位外表示对齐），**不是写更多改写规则** |
| **⑥ GRPO 增益机制（本轮新增）** | 安全率提升中 `k*≤32 且 Δceiling≤0.02` 的占比；或「统一常数改写偏移臂」解释率 >80% | **锐化/常数 ⇒ 转 best-of-k + verifier 与奖励密度改造；解锁才动训练配比**（33316 / 26627） |

**判据**：② ③ ⑤ ⑥ 任一栏占比 >20% ⇒ 「改写还不够严」与「继续加 GRPO 训练」**同时作废**，不得再启动输入改写加严或改写器重训。

#### A2【最优先，零训练，半天 → 推理 1 天】出图侧生成过程干预：五臂保持，补「局部反事实」第六臂

固定**同一份改写后 prompt**，200 条「文本无害但被打击」样本：① 原样全量生成（batch=1、全精度）② 负向 prompt / CFG 安全引导 ③ 子概念 + 空间局部引导（EBSG）④ 仅对 guidance 误差大的 token 重算条件+无条件两分支（GuideCache 思路）⑤ 线上真实加速配置（缓存/少步/fp8-fp4 + batch>1）⑥ **局部反事实调制臂**（CALM 思路：匹配 unsafe–benign 锚点对，只把越界 token 最小投影到安全侧，并在去噪前 30% 步抑制 CFG residual 中的正向对齐分量）。**必报**：出图风险率、主体/属性/关系原子要件保留率、FID 代理、**图审判定翻转率**、单次 e2e 延迟、以及 **safety-adjacent benign 误伤率**（CALM 报 27.0% vs 一般 3.4%，这一栏直接对着 5.2% 误杀约束）。所有臂输入 prompt 完全相同。**判据**：④⑥ 显著优于 ② 且保真不掉 ⇒ 重心在生成过程 guidance 项；⑤ 相对 ① 判定翻转 >3% ⇒ 加速链路本身就是风险来源；⑥ 的 safety-adjacent 误伤 >10% ⇒ 该臂不得上线。

> **责任边界写死**：2,700+ 条源于出图侧 ⇒ **输入改写优化预算冻结**；输出凭证层（VeriOrigin）只证明来源与改动，不阻止生成。

#### A3【零训练，半天】风险知识召回降级兜底：本轮**首次有参考实现**，按 33263 重构两层

`t14_policy_guard` 4 命中、逐篇核验 **1 篇可迁移**（六周零供给终结）。在 11-16 安全指令库评审口径上做三处升级：

### B. 风险锚点处理启发（双锚点：PORN/VULG 边界 + 政治 L2_30 层级）

#### B1 PORN/VULG：本轮给出**第九种**解释 —— 「判得低风险」可能是阈值语言漂移，不是边界混淆

前八种：二维 depict/enable、少身份维、词驱动锚点、"太弱测不到"、承诺形式与定义层、判定层读主体/场景代理量、锚点被压制而非移除、替换动作在表示层扩散（HinT）。本轮新增：**33307 证明同一阈值在非英文/低资源语言上系统性过度自信（301/325 pair），`Thr.` 从 95% 掉到 90.0%** ⇒ `VULG-HINT-EDGE` 的一部分「边界混淆」可能既不是标注错、不是阈值偏、不是判定装置读代理量，而是**阈值在另一种语言/语用形态上根本不是同一个 operating point**。

| # | 做法 | 判据 | 结论 |
|---|---|---|---|
| 1 | 100 条 `VULG-HINT-EDGE` 按中/英/中英混合三版平行构造，各报 `ΔAcc / ΔConf / Gap` | 某语言 `Gap>0` 且 `Thr.` 掉 >2 点 | 先 per-language 重校准，不动标注、不动阈值全局值 |
| 2 | 槽位对照三版（A 整句改写 / B 只替换锚点词 / C 同模板 twin） | C 与 B 判定差 <5 点 ⇒ 单 slot 已扩散 | 改表示一致性体检（HinT），别调改写器 |
| 3 | 边界样本按「暗示性线索 vs 显式道具」分档报分歧率 | 分歧集中在暗示档 | 定义层问题，不是阈值偏 |
| 4 | 反事实恢复对照 | 行为层 0 而恢复 >0.2 | 压制而非移除，改表示或生成过程 |

**与前八种的关系**：第九种不取代前八种，但把「边界混淆」从「判不出来 / 读代理量 / 被压制 / 替换动作扩散」再推进到「**判定阈值的适用范围没被语言覆盖**」。

#### B2 政治 L2_30：分层口径的第四个前置条件

11-25 两个（overlap 随 cell 粒度变化、低 FPR 区评测集重叠污染不跨模型抵消）、11-26 一个（测量仪器交互可反转符号）。本轮 **33307** 给第四个：**阈值在语言维度上不迁移，且损失大小由语言（60%）与底座（34%）决定、与排行榜名次无关**。**T2ISpec** 再给第五条：**同一阈值跨难度方向可反（Easy +0.0383 / Hard −0.0517）**；**33263** 给第六条：**层级越靠序数/语境的轴人工一致率越低（when 轴 0.53 vs what/who >89%）** ⇒ per-category threshold 不是调参偏好，是多层必要条件。

| # | 做法 | 判据 | 含义 |
|---|---|---|---|
| 1 | 按 L1 × L2_30 × **语言** × 难度逐格报 FPR、判定翻转率、overlap、`N_eff`、**检测器召回率** | 全局稳而某叶子翻倍 / 该叶 `N_eff` 或检测器召回不足 | 聚合口径掩盖子类劣化；继承父类阈值并写明降级口径 |
| 2 | 每类目标注 `样本数 / 人工一致率 / 是否低代表 / 评测集重叠率 / 检测器版本 / 语言` **六元信息** | 一致率 <70% 的轴降权（when 0.53 的教训） | 先修定义与数据，不可单独调阈值 |
| 3 | 报 L1–L4 等级分布与各级患病率 | 一级一致率相同而分布差 >10 点 | ordinal calibration 先于调阈值；低患病率格（RealMHS 5.5%）单独选 operating point |

> **顺序写死**：**① 审计评测集（重叠）→ ② 体检表示可判性（overlap）→ ③ 体检尺子（检测器/评分协议/仪器交互）→ ④ 体检语言与难度适用范围（Gap / 阈值方向）→ ⑤ 才做约束式选点与 conformal 认证**。任何一步没做就调阈值，结论不进看板。

#### B3 跨锚点共同结论

两个锚点这轮的答案都是：**先分清「判不出来」「判定装置在读代理量」「替换动作在表示层扩散」「读数被仪器污染」「阈值根本没覆盖这个语言/难度」**。五者都不需要重新标注或重训，各半天到一天；且都指向同一句话——**不要在输入侧加码，先把验收单位、验收装置与适用范围修干净**。

#### C2 阈值 operating point：五步顺序 + 八元组

顺序写死：**① 评测集重叠审计（null-calibrated + 2×2 + size-matched control + `N_eff`）→ ② 表示可判性体检（overlap + `K_z` 口径 + 200 次校准抽样分位）→ ③ 尺子体检（检测器召回/精确率 + 评分协议相关性 + 仪器交互项）→ ④ 语言与难度适用范围体检（Gap / per-language temperature scaling / 方向一致性）→ ⑤ 约束式选点与 conformal 认证**。七元组扩为**八元组**（加「语言 / 难度 / 温度缩放版本」）：阈值、选择规则、数据划分、代价比、模型规模/量化器、评测集重叠审计版本 + serving setup 指纹、检测器与人工校准版本、语言与难度口径。

#### C3 Conformal 覆盖稳定性：本轮补「覆盖在哪个语言上成立」

- 11-08 Coverage Hides Churn：覆盖 ≤0.01 变而 60–67% 图像改判；
- 11-24：准确率 0.03 点不动而 1.1–12.3% 成对翻转；
- 11-25：IJB-C 在 FMR=10⁻⁶ 只有 2.7M 有效独立比较；

**整体指标与分层宏平均背离的检出（aggregate-vs-macro F1 divergence）**：先钉分母与评测集审计 → 出 `版本 × 一级类目 × L2_30 × 语言` 的 F1/FPR/翻转率/**overlap/检测器召回/Gap** 矩阵 → 算 `Δaggregate` 与 `Δmacro` 符号与差值 → `Δaggregate>0 而 Δmacro<0` ⇒ 子类劣化被掩盖，不予上线 → 逐格定位 → 留 ckpt / 训练配置 / 数据集版本 / 评测口径 / **量化器、检测器版本、serving setup、语言与温度缩放版本** 八元组。**T2ISpec 的 Overall 0.0000 掩盖 text +0.0233 / commonsense −0.0242 是最干净的公开模板。**

**跨评测集泛化缺口**：eval_not_include / OOD 集另报，同 ckpt 跨集 F1 差 >10 点 ⇒ 结论只在单集成立（对齐 PSI 新评测集 F1 **−1.96pp** 与 L3 宏 F1 连续两周退化）；换评测集、换检测器、换评分协议、**换语言/温度缩放**都必须登记为 calibration 事件。

#### C5 灰度 / 观察模式前后口径一致性

六层风控框架沿用，本轮在「拦截能力层」加**语言 × 类目 × 难度分格 FPR 与 `Gap`**；「风险态势层」加**常数臂解释率与非目标属性引入率**；「全链路专项层」加**Δwork/Δlatency 落差**；「技术健康 SLO 层」加**短 CoT 占比与 reasoning-length 超时率**；「误伤体验层」加**每语言过度自信 pair 占比、非中文申诉样本回捞率与「假安全」拒答体感类**。

**硬要求不变且收紧**：shadow → canary → 全量每一步**冻结同一份评测单位、聚合口径、阈值规则、judge 示例集与配置指纹、检测器版本、batch/精度/硬件、语言与温度缩放版本**；只换流量比例，不换尺子，也不换执行环境。观察模式（只记不拦）与生效模式分列。**策略表热更新本身也是一次 calibration 事件**（33263），必须走同一套灰度口径。

### D. 下一步实验建议（六条主线）

> 排序原则：先做零训练、能一次结束纠结的；算力按 **训练集群 6 节点 → 5 节点** 的现实排。**明确：本轮不再把重心放在加严输入改写；且在动任何训练之前先过 A1 第六栏的「增益机制」闸门。**

#### 主线①【tag-weighted loss / 层级标签】D1：L1 × L2_30 双列 → **三轴 + 权重可审计 + 策略表解耦**（半天，零训练）

出 `AUROC × BA × 样本数 × 人工一致率 × **评测集重叠率 × overlap × 检测器召回率 × 语言**`，按「识别型 / 判定型」二分；标出 <200 样本、一致率 <70%、overlap >0.5、检测器召回 <80% 的饿格子。本轮按 **33263** 升级：把标签拆成 `(what, who, when)` 三轴并给**分维权重**（what/who 高、when 低，依据人工一致率 >89% vs 0.53），评分用**部分匹配 3WS** 而非「全对才算对」；**处置动作从标签里拿掉**，改由可热更新映射表承载。做法：6 版本看板改成「五列 + 约束式选点」（如「保真不低于基线 −0.5 前提下最小化风险率」），检查单列最优版本在约束下是否仍入选；再加一臂「换一张策略表、不重训」，验证误杀 5.2% / 漏过 3.42% 能否只靠策略表移动。**判据**：不一致 ⇒ 现有按总分选 ckpt 的口径作废；判定型格加权后 F1 不升反降 ⇒ 降权而非加权重；换策略表后双约束同向改善 ⇒ 优先上线策略表而非新 ckpt。

#### 主线②【RL 改写】D2：GRPO 与 SFT 线的奖励设计对比 —— **先过零训练双闸门**（1 天，零训练前置 + 轻训练）

**闸门（本轮新增，必须先做）**：对 `grpo1102_125` 与 SFT 各版本，50 条高危 prompt × n=32 共享种子，按「文本无害 / 出图无害 / 原子要件保留」三技能分别报 `k*`、Δceiling、零覆盖拯救率、best-of-4/16 回收率；另做「统一常数改写偏移臂」看能解释多少安全率差。**若锐化或常数可解释占比 >80% ⇒ 不启动任何 GRPO 重训**，把预算转 best-of-k + 图审 verifier 与奖励密度改造（33316 / 26627）。

通过闸门后的对照表：

| 对比项 | GRPO 线 | SFT 线 | 判据 |
|---|---|---|---|
| 主奖励 | 安全率 | 监督信号 + tag-weighted loss | 安全率提升是否伴随语义保真下降 |
| 可验证奖励 | **G7 前置**：50 条高危 prompt × 原样/微改/真改写三版 | 不适用 | 原样一致性分显著更高 ⇒ 奖励可作弊，停 |

| **奖励密度** | 标量安全率 | **twin 速度差 / 逐 token 条件差**（HinT） | 标量显著落后 ⇒ 收益上限受奖励稀疏限制 |
| **图像一致性奖励（本轮新增）** | 加 PreserveReward 式**三栏一致性**（局部/全局/意图对齐） | 同左 | 与「必要修改 vs 意外改动」分开后安全率是否仍涨 |
| **奖励器跨集方向（本轮新增）** | 换第二个评测集复测 | 同左 | **两集方向相反 ⇒ 奖励器不合格，该 ckpt 不进对比**（Table 2 实证） |

#### 主线③【标签审计与阈值校准】D3：**五步顺序**（半天，零训练，**最优先**）

① **评测集重叠审计**（29629）：对 2000 条图生图评测集（1979 有效样本）、PSI 评测集、训练集、阈值参考集做 embedding 近重复 + 词面 n-gram，null-calibrated 把审计假阳性率钉 0.1%，抽 100 条人工双盲复核，2×2 + size-matched random control，按每叶子算 `N_eff` 与最小可解析误杀率；② **表示可判性体检**（23685）：逐类目算 overlap 并钉死 `K_z` 口径，200 次校准抽样报 10–90 分位；③ **尺子体检**（32848）：100 条改写/拒答输出两人独立双盲标四类（含「假安全拒答」体感类），算 κ 与检测器召回/精确率，**召回 <80% ⇒ 5.2% 误杀基线按 corrected detector 重算**；④ **语言与难度适用范围体检（本轮新增，33307/29029）**：按中文/英文/中英混合平行条目报 `Gap`、`Thr. 实际准确率`、per-language temperature scaling 前后 ECE，并按 Easy/Hard 报阈值方向；**中文 τ 掉 >2 点或方向相反 ⇒ 英文阈值不得全局下发**；⑤ 才做约束式阈值选点 + conformal 认证，并补 6 版本看板的实际 FPR、逐样本翻转矩阵、judge 尺子体检（A4）。**判据**：任一版本出现「AUROC 稳而 FPR 漂」「准确率稳而逐对翻转 >3%」「judge Bias >+15 点」「评测集重叠率 >0」「检测器召回 <80%」「`Gap>0` 且 `Thr.` 掉 >2 点」，历史 AB 按版本重算。

#### 主线④【输出侧图审与溯源】D4：六栏拆分 + **六臂生成过程干预**（1 天，推理为主，**明确不再加严输入改写**）

按 A1 把 **2,700+ 条**拆成六栏（新增 GRPO 增益机制）；按 A2 做**固定同一份改写后 prompt** 的六臂生成对照（新增局部反事实调制臂，报 safety-adjacent benign 误伤率），每臂报出图风险率、原子要件保留率、图审判定翻转率、e2e；图审 AB 加 **BODYBENCH 三栏判据**（性化/自然度/可辨认性）与**编辑强度 × 掩码族 × 预处理扰动格**；按编辑强度轻/中/重分档测水印检出率，报 **VeriOrigin 三栏**（payload 位准确率 / 定位 F1 / 无损恢复率）与载荷代价 ≤2.3 F1 点。

**判据**：guidance 项重算臂或局部反事实臂显著优于纯 CFG 引导 ⇒ 生成过程干预是主修法；加速臂相对原样判定翻转 >3% ⇒ 先把 serving setup 写进事件审计；三栏判据一致性 <90% 或轻编辑档 payload <90% ⇒ 撤回「图审/水印已达标」；PSNR/SSIM/CLIP 与人工判「是否仍有害」相关性 <0.3 ⇒ 这些代理量不得进验收主指标位；局部反事实臂 safety-adjacent 误伤 >10% ⇒ 不上线。

> **责任边界写死**：归因已明确 2,700+ 条源于出图侧 ⇒ **输入改写优化预算冻结，且不再把重心放在加严输入改写**；输入侧只保留「文本复核仍有害」的极小比例修正与 A1 第五/六栏体检。

#### 主线⑤【I2I 改写链路（含统一生成-编辑模型改写面）】D5：0/0% 的**第十种**归因（1 天，零训练，**优先级仅次于 D3**）

**背景**：I2I 改写分流命中 **0/0%**（输入侧色情模型灰度 **70%** 与改写分流 **0/0%** 并存）。十种归因：判据无分辨率 / 改写没写好 / 改写抹掉要件 / 分流只读文本通路 / benchmark 允许单模态通关 / 编辑前后对照被 batch 非确定性污染 / 粗粒度路由结构性 overlap / 单一全局判定粒度（TIDE 89%）/ 验收判据没有可判的正例（CRIE-S 全 0.0%）/ **本轮新增：一致性判据无法区分「必要修改 vs 意外改动」**（PreserveReward 指出 reward model 会把两者一起打分，Base 39.80% 的成对准确率说明通用 VLM 几乎判不了）。

**可落地建议（针对 70% 灰度与 0/0% 并存）**：

1. **先修执行环境，不要重写改写器**：从 2000 条评测集抽 200 条，把「编辑前后其余保持原样」的判定强制改成 **solo-vs-solo 同 batch / 同精度 / 同 GPU 配置**（30545 引言直接以 image editing 举例）。
2. **把 0/1 判据换成成对一致性 + 三栏**：同一源图 + 同一指令下比两个输出谁更少动非目标区域，按**局部细节 / 全局结构 / 意图对齐**三栏报（PreserveReward），并按「该改的改了吗 / 不该改的动了吗」分列；**三栏任一格无分辨率即先把 0/0% 记为「验收失败」而非「改写无效」**。
3. **把分流从 0/1 改成带分数的多候选排序 + 按 $K$ 报方向覆盖数**：按指令部件数 $K=1/2/4/8$ 分档报命中率；若命中率随 $K$ 单调下降 ⇒ 第八种归因成立。贴 70% 灰度：灰度已在跑，先把输出改成「每个部件一个改写强度分 + 2 候选排序」，不重训即可让 0/0% 变成可观测分布。
4. **四要件重打标 + 意图折叠前置**：人工标「主体 / 操作 / 目标区域 / 撤销项」，构造「含撤销/修订但字面中性」三语版本，比对「原样 / 规则折叠撤销项 / 折叠+分部件强度」三版命中率。
5. **统一生成-编辑模型的改写面**：固定一份改写后 prompt，分别走生成通路与编辑通路，报两通路风险判定差与四要件保留率差（AnimalFarm 三通路 66.6/68.0/75.3）；**判据** 差 >15 点 ⇒ 不能共用一份改写，必须按通路分流下发。本轮 `t9_unified_edit` 零供给，此项按自建口径落地。
6. **补灰图纯文本探针上界检验**（27339）：AUROC ≥0.90 ⇒ 验收集有词捷径，重写改写器无效。
7. **召回侧弱命中保留**：按 PreserveReward 梯度路由 / TIDE Theorem 3，分流召回不要只取 top-1；两路与参考目标冲突时允许「都不采纳」并留事件，避免长尾部件被先丢。

**为什么这条最省钱**：全部是重打标 + 重跑现有链路 + 加两个探针 + 改输出格式，零训练、不重做评测集。

#### 主线⑥【多模态视频扩展】本轮**不给建议**

`t10_video_safety` 仅 2 命中，均非生成安全；11-26 批次的 2611.31354（有害短视频治理证据框架，审核侧）与 2611.31301 MOZAIC（音视频 deepfake benchmark）留候选观察；Activation Steering 虽测了 Wan2.1/2.2，但**六个公开 video RL ckpt 里只有两个在对比奖励上相对 base 有正增益**，作者据此把 video 结论严格限到这两个 —— 属训练机制而非视频内容安全。按用户口径「仅在出现强相关工作时给建议」，**本轮不新增视频策略建议**；AIGC 全模态策略命中事件落表中 i2v/t2v 输入/输出字段继续对齐。

#### 跨语言专项【针对 2B 改写模型英文 ASR 飙升】D6：三语 × 三形态九格 + **置信度滞后臂**（1 天，零训练 + 训练排期）

**本轮判断**：`t11_multilingual` 首次有直接可迁移的机制证据（33307）。语言覆盖 / 文化语境 / 语用形态 / 生成过程实现 / 表示层扩散之外，补**第六维「置信度滞后」**。

1. 把三版对照扩成 **中 / 英 / 中英混合（code-switching）× 三形态 = 9 格**，改**平行条目**构造（同义同难度跨语言配对），每格报 `ΔAcc / ΔConf / **Gap=ΔConf−ΔAcc** / 英文 τ 下实际接受准确率 / n⁺`，**禁止只报聚合 ASR**；
2. **必含「中性 Prompt 的语义取向漂移」对照臂**（CRIE-S 式冗余/撤销构造），看分数分布是否系统性偏移；
3. **本轮新增第 4 臂（校准 vs 能力分离）**：每格跑 per-language temperature scaling（500 items），报缩放前后 **ECE 与 ASR 两条曲线**；**ECE 降而 ASR 不降 ⇒ 是能力缺口，支持中英合并训练；ASR 随 ECE 一起回落 ⇒ 是校准问题，先做 per-language 阈值下发，不启动重训**（33307 明确微调修校准易、修准确率难）；
4. 保留表示层扩散臂（HinT 非目标属性引入率，看英文档改写扩写幅度是否更大）与生成过程语言敏感性臂（25382 guidance 项占比中英 1.66×，中文恢复多于拉丁文本）；各格同时跑「全量 vs 线上加速」；
5. 若英文档 ASR 显著高于中文档 ⇒ 支持**中英合并训练**，但训练前先做两件零训练事：① 检查英文训练样本是否集中在显式风险词（补「无表层线索 + 文化特定」样本）；② 检查是否把疑问/肯定语用形态当低风险（DSC 思路）；
6. 合并训练后**必须报分语言 ASR、分层宏平均、逐样本判定翻转率、检测器召回率、`N_eff`**，禁止只报聚合 ASR；叠加 27155 的小模型脆弱窗口占用率（2B 约 25%）与 32848 的 135M–1.7B 量化测量伪影，单列，禁止与 8B 共用不劣化结论。
