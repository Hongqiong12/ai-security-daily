## 一、T2I / T+I2I 论文（核心主线 · 4 篇）

### 1. Text Lives in the Guidance：输入一个字没改，图里的字被换了

**机构**：北京师范大学 + 北京交通大学（PDF 首页脚注确认）｜**被测主干**：Z-Image 6B、Qwen-Image 20B（阿里系真 CFG DiT）｜https://arxiv.org/abs/2611.25382

**问题**：DiT 特征缓存用 ImageReward / CLIP / FID 验收，不检查渲染文本是否还是原来那份。Z-Image 上 TaylorSeer 在 **2.9× fewer FLOPs** 时把 word accuracy 从 **62% 压到 46%**（0.621→0.464），而图像级质量分几乎不动。

**机制（本轮最可迁移的部分）**：把缓存误差沿 CFG 拆开，输出 `v̂ = v_uncond + w·(v_cond − v_uncond)`，文本 token 上 **guidance term 占比是背景的 1.66×（中英一致）**，而缓存对这一项外推最差、误差被 guidance scale 放大。三条硬对照：

- **同等算力只减采样步数**，恢复 **83% 丢失的 prompt fidelity / 90% 丢失的 word accuracy** ⇒ 损失来自「缓存怎么预测跳步」，不是算力；
- **消融**：plain cache 0.386 / **只重算无条件分支 0.235（更差）** / 只重算条件分支 0.481 / **两分支都重算 0.532** / OCR 真值框 oracle 0.511 ⇒ 信号是两分支的**差**，动它必须成对动；
- **架构决定幅度**：Qwen-Image 把 guided output 按 conditional norm 重缩放封顶 `‖w·e_g∥`，同样缓存下丢文本更少；**关掉重缩放后损失翻倍（0.169 vs 0.084）**；512² 损失 −0.220 vs 1024² −0.172。

**GuideCache**：按 guidance share ρ 选 `r` 比例 token 重算两分支，`r=10%` 在 **2.46× fewer FLOPs** 下把 46%→61%（恢复约 **91%**，Qwen-Image 约 **73%**）；13 anchors 3.85× 时 TaylorSeer 掉到 **0.124 / 0.057**，加 GuideCache 回 **0.388 / 0.334**；`r=5%` 就拿到大部分收益。

**跨语言**：LongText-Bench 含 320 条中英 prompt；文中明确「中文恢复多于拉丁文本，Qwen-Image 同一顺序」⇒ **同一加速配置下中英退化与恢复幅度不同，禁止只报聚合**。

**局限**：只适用**真 CFG**（不适用 guidance-distilled 模型）；OCR 只查字符不查排版；**没测风险语义、没报 TTFT/e2e**；未覆盖 I2I / 统一生成-编辑模型。

**对本项目的落点**：这是「出图侧内生风险」的**机制级证据**——改写后文本无害，生成过程仍可改写输出语义，且现有验收看不见。修法在生成过程（guidance 项），不在输入改写。

### 2. Reproducible by Seed? Not on GPUs：固定 prompt 和 seed 也固定不住图

**机构**：马德里理工大学 + 电子科技大学（成都）｜https://arxiv.org/abs/2611.30545

**问题**：所有依赖生成图的比较都默认「同 prompt + 同 seed = 同图」。作者在 **6 个模型 × 4 精度/量化 × 3 GPU** 上逐条证伪，且所有 replay control **bit-exact**，因此变化不是采样噪声：

| 模型 / 精度 | SSIM vs batch-1 | 备注 |
|---|---|---|
| Emu3.5 bf16 / int8 | **0.580 / 0.551** | 10 条 prompt 全变 |
| Janus-Pro-7B bf16 sampled / greedy | **0.261 / 0.229** | 贪心反而更差 |
| Qwen-Image-2.1 bf16 / fp8(H100) | 0.873 / 0.811–0.863 | 低精度放大 |
| HiDream-O1 fp8 stage 10/25/100 | 0.748 / 0.731 / 0.686 | 逐步递降 |
| FLUX 3 Klein bf16 / int8 | 0.998–0.999 | **唯 fp8 破例 0.829 / 0.855** |
| 扩散 bf16（若干） | 0.96–0.98 | 结构相近但**每张都变** |

**所有列出的模型 bit-identity 全为 0.0**。跨 GPU 差异与同 GPU 内 batch 效应**同一量级**（LPIPS 0.355–0.383 vs 0.347–0.381）。机制是归约顺序随张量形状改变、8-bit 把微小数值差放大成可见差异；作者明确 **batch-invariant execution 仍是开放问题**。

**作者原文结论（几乎是为本项目看板写的）**：「seeds do not make results reproducible, benchmarks … that mix batch sizes or hardware can be biased, and **safety audits and A/B tests on generated images need the serving setup reported**」。引言还直接以 **image editing「改一个对象、其余保持原样」** 为例 ⇒ **I2I 0/0% 的第六种可证伪归因：编辑前后对照被 batch 非确定性污染，「改对了」永远无法被判定**。

**局限**：只测像素/结构相似度，**没测图审判定翻转率**；未覆盖统一生成-编辑模型 / 视频 / 线上连续批处理实现；无 fp4 档。

### 3. SAE-Audit：输出里看不见 ≠ 模型里没有

**机构**：上海人工智能实验室 + Mila + McGill + 大阪大学｜https://arxiv.org/abs/2611.30117

**问题**：概念擦除的验收只在生成图上量「目标抑制 / 非目标保留」，但**图里没有不能证明模型里没有**。SAE-Audit 用原模型激活学共享 SAE 表示，找出擦除后响应变弱的特征，把原模型导出的**稀疏方向注入编辑后模型**（方向在测试 prompt 间固定、不改权重不改 prompt），在 held-out 场景族上评估恢复。

**读数（6 种擦除器 × 4 域，strict ASR）**：

- **NSFW nudity**：原模型 **0.91** → 擦除后 **0.00** → 注入后 **0.71/0.48/0.59/0.74/0.77**，随机对照 **≤0.06**；
- 对象域（cat / bicycle）恢复最强（0.74–1.00），风格与版权域最难（Monet 全 0.00）⇒ **PORN/VULG 这类视觉锚点恰在「最容易恢复」一侧**；
- Table 2（67 cells）：Erased no intervention 全 **0.00**；Ours 总体 **0.40 / nudity 0.66**、恢复 **38** 格；Reverse-SAeUron 0.35；Energy-matched random 0.02；Wrong-concept circuit 0.04；Noise probe 0.04 ⇒ 三条反证伪对照都趴着；
- **31/40 恢复格**同时满足 CLIP scene consistency（对象+nudity 21/26）⇒ 不是塌成噪声换来的；
- **Seurat relabel check**：冻结 CLIP artist head 靠表面统计判风格，加一个更具体的竞争描述后 ours 从 **0.94→0.19**、**0.78→0.22**，12/16、11/18 图被改判 pointillist ⇒ **检测器本身是代理量**（11-24 judge 单向偏置的第三次同族证据）；
- 仅 SAE round-trip 就对 UCE/cat 给 **+0.16~+0.34** 恢复；跨模型选中特征 pooled top-10 Jaccard **0.154**，恢复仍成立。

**局限**：白盒前提（需激活与 SAE）；人工评测只覆盖 1 个样本；FLUX 只测单概念单擦除器；「擦除后保留多少目标信息」原文明确 **remains unresolved**；未测输入改写 / 输出图审 / 统一模型。

**边界结论（第十二轮）**：权重侧擦除是**压制不是移除**。同日 HOSE 给出的所有生成图读数，都没有过「反事实恢复」这一关。

### 4. HOSE：层次正交子空间，把更新投到通用知识之外

**机构**：上海大学 + 中国科学技术大学｜https://arxiv.org/abs/2611.30592

**方法**：① 把参数更新投影到与通用知识正交的子空间，消除对非目标概念的干扰；② 针对 U-Net 层次异质性做 **Tripartite 分层自适应**——SD v1.4 一般概念 `ε_shallow/mid/deep = 5×10⁻² / 6×10⁻² / 2×10⁻¹`，艺术风格 `1×10⁻³ / 3×10⁻³ / 1.6×10⁻¹`（深层允许大得多）。摘要口径：**harmful content 相对未编辑模型降 80%**，对抗鲁棒性优于 SOTA。

**层次消融（关键，约束型指标）**：Uniform(ε shallow) Total **178** 但 FID **31.26** 最好；Uniform(ε deep) Total **45** 最好但 FID **40.28** 崩、CLIP 25.25；**Ours(Tripartite) Total 116 / CLIP 26.12 / FID 34.87**。⇒ 两个单目标互相拆台，**HOSE 赢的是 trade-off，不是单指标**。

**与基线对照（必须如实读）**：组一 `%HARM`：SD v1.4 3.86% / ESD 3.49% / UCE 1.82% / **RECE 1.49%（最低）** / Ours **2.14%**；但 Ours 的 **CLIP 26.12 最高、FID 34.87 为编辑类最低**；组二 Total：RECE 26 / **Ours 19（最低）**。非目标保留侧 SPEED 的 LPIPS **0.25** 优于 Ours 0.39。**不能把 HOSE 读成「擦除率最高」**。

**统计留痕**：5 次运行、95% CI、配对 t 检验；Genitalia 6.50→1.10（p=4.5×10⁻⁵）、Chest&Breast 139.00→28.50、Gluteal 36.00→5.60、Other 77.67→17.47；按多个 NudeNet 置信阈值各报一次。

**局限**：只做 SD v1.4 / U-Net，未覆盖 DiT、flow-matching、**统一生成-编辑模型**（与本轮 25382/30545 的线上架构不同代）；多概念效果依赖目标概念语义重叠度（**PORN/VULG 边界类恰是重叠最高**）；验收仍全是生成图读数；未报推理延迟。

## 二、方法论迁移论文（2 篇）

### 5. Measuring the Conservatism of Latent Safety Filters：误杀不是模型不够强，是表示逼的

**机构**：UCSD + San Diego State University（PMLR 2027）｜https://arxiv.org/abs/2611.23685

把相似 latent 与动作分到 **cell**；一个「每 cell 一个判定」的过滤器要拒绝 cell 内所有不安全转移，**就必须连里面所有安全转移一起拒**。这部分占比叫 **overlap**，作者**证明它是「接受 0 个不安全转移」时必须拒绝的最小安全转移比例**——是下界，不是经验观察。

| 表示 | overlap | 校准过滤器拒安全动作（δ=0.02） | 任务达成率 |
|---|---|---|---|
| Planner latent `z` | **0.96–0.97** | **0.302** | 0.39 |
| Jointly trained `z_ℓ` | 0.94–0.96 | 0.318 | 0.32 |
| **独立 Safety latent `z_s`** | **0.44–0.46** | **0.161** | **0.72**（= 不设过滤器） |

δ 网格（0.002→0.2）下 `z` 拒安全 0.668→0.041、`z_s` 0.280→0.044；`K_z=50` 时 overlap `z` 0.97–1.00 / `z_s` 0.52–0.54，`K_z=200` 时 0.84–0.86 / 0.37 ⇒ **cell 粒度会改读数，必须报 partition**。

**迁移价值**：① 「能改则不拒」第一次有了数学下界——**调阈值降不下去，只能换表示**；② 用户侧「我没写违规内容却被拒」的体感，可能是安全与危险样本落在同一 cell 不可分，不是阈值偏；③ 与 29629 配对：先审计评测集、再体检表示、最后才调阈值。**局限**：原文是视觉导航 / 物理碰撞标签，非内容安全语义；overlap 是体检量，作者自承「this filter is too coarse to deploy」。

### 6. Contamination at the Operating Point：你读到的误杀率本身可能是假的

**作者**：Fu Dai, Kamal Taha, Naoufel Werghi, Maregu Assefa（**PDF 首页未列机构，不做外推**）｜https://arxiv.org/abs/2611.29629

先前工作把 train-test 身份重叠造成的乐观偏差量成「最多 +1.01pp 的加性小偏差」。本文证明它是**随 operating point 下降增长的乘性误差**：

- null-calibrated 审计（masked-self null，`β=0.1%` 构造性假阳性率）相对 WebFace42M 标出 **88.6% MS1MV3 身份**、**14.3% IJB-C subjects**（510/3,567），尽管 WebFace260M 已发布 de-overlap 并点名 IJB-C；人工复核 100 个确认 **69.2%** ⇒ 残留重叠 **~9.9%**；
- **固定模型权重，只从测试集删重叠身份**：FNMR 抬 **3.6×（FMR=10⁻⁴）/ 6.3×（10⁻⁵）/ 13.9×（10⁻⁶）**，同规模随机删除无此效应；机制是 impostor tail 变短 → 阈值左移；
- 偏差**不跨模型抵消**，把「本模型 vs 公开基线」的表观优势**削掉一半**；
- IJB-C 在 FMR=10⁻⁶ 只有 **2.7M 有效独立比较**，低于 `10/FMR` 报告规则；推导最小可报告 FMR ≈ **6×10⁻⁵**；用 audited zero-overlap 的 real-face 协议可解析到 10⁻⁸；
- 2×2（de-overlap × dedup `T=0.70`）+ size-matched random control、`B=2000` bootstrap。

**迁移价值**：误杀率 5.2% / 漏过率 3.42% 基线**必须先做评测集重叠审计**；per-category threshold 在低 FPR 叶子格最危险；6 版本看板若共用被污染评测集，**版本排序可能整体失真**。**局限**：人脸验证不是内容安全；审计需训练语料已知，闭源模型不可直接照搬；3.6×–13.9× 不可当本项目偏差量级，只能当方向与协议。

### 信号一：出图侧内生风险从「一个现象」拆成「四条可分别检验的机制」

### A. 直接可迁移方法

#### A1【最优先，零训练，1 天】输入改写有效性上界归因：把 2,700+ 条 case 从三栏升级为**四栏**

**现状**：3,000 条改写后仍被色情 400 打击的 case，仅约 10 条属改写文本仍有害、约 **2,700+ 条为改写后文本无害但出图侧内生风险**。上一轮按「文本复核仍有害 / 图审判有害但人工无害 / 图审放行但人工判有害」三栏拆。本轮按四条机制加栏：

| 栏 | 判据 | 对应修法 |
|---|---|---|
| ① 文本复核仍有害 | 人工双盲判改写文本有害 | 输入改写（占比应极小，**其余预算冻结**） |
| ② **生成过程改写** | 同一改写后 prompt，全量生成 vs 线上加速配置，原子要件保留率差 >10 点而图像级质量分差 <2% | **CFG guidance 项两分支重算**（25382） |
| ③ **执行环境漂移** | 同一改写后 prompt + 同一 seed，solo vs batch / 全精度 vs fp8-fp4，图审判定翻转 >3% | **冻结 serving setup 指纹**（30545） |
| ④ 表示层残留 / 判定层代理量 | 反事实还原主体或注入方向后风险回来；灰图纯文本探针 AUROC ≥0.90 | 判定推理结构改造 + 表示层审计（30117 / 27339） |

**判据**：② ③ 任一栏占比 >20% ⇒ 「改写还不够严」这个归因正式作废，**不得再启动输入改写加严实验**。

#### A2【最优先，零训练，半天】出图侧生成过程干预：从三臂扩为**五臂**（明确不动输入、不动权重）

固定**同一份改写后 prompt**（沿用 11-24 A3 的钉死约束），200 条「文本无害但被打击」样本：① 原样全量生成（batch=1、全精度）② 加负向 prompt / CFG 安全引导 ③ 按子概念 + 空间局部引导（EBSG）④ **仅对 guidance 误差大的 token 重算条件+无条件两分支**（25382 GuideCache 思路）⑤ **线上真实加速配置**（缓存/少步/fp8-fp4 + batch>1）。

**必报**：出图风险率、主体/属性/关系原子要件保留率、FID 代理、**图审判定翻转率**、单次 e2e 延迟。
**判据**：④ 显著优于 ② 且保真不掉 ⇒ 重心在生成过程 guidance 项；⑤ 相对 ① 的判定翻转 >3% ⇒ **加速链路本身就是风险来源**，先修 serving setup 再谈别的。所有臂输入 prompt 完全相同。

#### A3【零训练，半天】风险知识召回降级兜底：本轮**零供给**，按自建口径落地（A4 沿用 + 补两条）

### B. 风险锚点处理启发（双锚点：PORN/VULG 边界 + 政治 L2_30 层级）

#### B1 PORN/VULG：本轮给出**第七种**解释 —— 「锚点被压制而非移除，且恰在易恢复侧」

前六种：二维 depict/enable、少身份维 (S,I)、词驱动锚点、"太弱测不到"、承诺形式与定义层、判定层读主体/场景代理量。本轮新增：**30117 的 nudity 域是四个域里恢复最强的之一**（0.48–0.77，随机对照 ≤0.06），而 30592 明说多概念效果依赖目标概念语义重叠度——**PORN/VULG 边界类恰是重叠最高的类别**。⇒ `VULG-HINT-EDGE` 的混淆可能是「边界锚点在表示里被压制、一有条件变化就回来」，而不是标注错或阈值偏。

三条零训练判据（成本递增）：

| # | 做法 | 判据 | 结论 |
|---|---|---|---|
| 1 | 100 条 `VULG-HINT-EDGE` 跑「原句 / 反事实还原主体 / 灰图纯文本探针」三版 | 反事实版召回显著升、灰图探针 AUROC ≥0.90 | 代理量驱动，改判定推理结构 |
| 2 | 边界样本按「暗示性线索 vs 显式道具」分档报分歧率 | 分歧集中在暗示档 | 定义层 / 暗示强度问题，不是阈值偏 |
| 3 | **反事实恢复对照**（本轮新增）：固定方向/语境扰动后看风险是否回来 | 行为层 0 而恢复 >0.2 | **压制而非移除**，改表示或生成过程，别改类目定义 |

**与前六种的关系**：第七种不取代前六种，但把「边界混淆」从「判不出来」与「判定装置读代理量」再推进到「**锚点本体还在，只是没被激活**」。

#### B2 政治 L2_30：本轮的关键是「分层口径的两个前置条件」

三条硬证据：**23685** 的 overlap 随 cell 粒度 `K_z=50/200` 明显变化（`z` 0.97–1.00 → 0.84–0.86）⇒ **分层口径本身就是变量**；**29629** 证明低 FPR 区读数被重叠污染且**不跨模型抵消**（把表观优势削一半）⇒ 共用评测集的多版本排序可能整体失真；**30117** 的 Seurat relabel（0.94→0.19）⇒ 检测器换一个更具体的竞争描述就整体换边，子类可判性不齐。

| # | 做法 | 判据 | 含义 |
|---|---|---|---|
| 1 | 按 L1 × L2_30 逐格报 FPR、**判定翻转率**、**overlap** 与 `N_eff` | 全局稳而某叶子翻倍 / 该叶 `N_eff` 不足以支撑目标误杀率 | 聚合口径掩盖子类劣化；**继承父类阈值并写明降级口径** |
| 2 | 每个类目标注 `样本数 / 人工一致率 / 是否低代表 / 评测集重叠率` 四元信息 | 某叶子 <200 样本或一致率 <70% 或重叠率 >0 | 先修数据与表示，不可单独调阈值 |
| 3 | 报 L1–L4 等级分布与各级患病率 | 一级一致率相同而分布差 >10 点 | ordinal calibration 先于调阈值 |

> **为什么不是再调一次阈值**：23685 证明误杀有表示决定的下界、29629 证明读数被污染、30117 证明检测器会换边 ⇒ **先审计评测集、再体检表示可判性、最后才认证阈值**。

#### B3 跨锚点共同结论

两个锚点这轮的答案都是：**先分清「判不出来」「判定装置在读代理量」「锚点只是被压制」「读数本身被污染」**。四者都不需要重新标注或重训，各半天到一天；且都指向同一句话——**不要在输入侧加码，先把验收装置修干净**。

### C. 三维评测设计启发

#### C1 三维聚合：补第六维「执行环境一致性」

现有三维「语义保持 / 安全提升 / 指令遵循」+ 11-23 组合层生效 + 11-24 代理量纯度，本轮补：

| 维度 | 现有 | 本轮新增 |
|---|---|---|
| 语义保持 | 原子要件保留率 | **加速前后 OCR/语义要件保留率差**（25382） |
| 安全提升 | 图文联合状态判定 | **反事实恢复率**（30117）+ **跨 batch/精度判定翻转率**（30545） |
| 指令遵循 | 逐通路要件保留率差 | 编辑前后「其余保持原样」在 solo-vs-solo 下的达标率 |
| 代理量纯度 | 灰图探针 AUROC / 逐对翻转率 / judge Bias | **检测器换竞争描述后的换边率**（0.94→0.19） |
| **执行环境一致性** | — | **serving setup 指纹一致率 + 同 seed 跨 batch SSIM/判定翻转** |

**判据**：若三维总分上升而任一新增维度恶化 >10 点 ⇒ 这次上升不可信，不予上线。

#### C2 阈值 operating point：三步顺序固定 + 六元组

延续 11-24 C2（阈值、选择规则、数据划分、代价比、模型规模/量化器），本轮把顺序写死：**① 评测集重叠审计（29629：null-calibrated + 2×2 + size-matched control + `N_eff`）→ ② 表示可判性体检（23685：overlap + `K_z` 口径 + 200 次校准抽样分位）→ ③ 约束式选点与 conformal 认证**。四/五元组扩为**六元组**（加「评测集重叠审计版本 + serving setup 指纹」）。

#### C3 Conformal 覆盖稳定性：本轮补「该 operating point 能不能报」

- 11-08 Coverage Hides Churn：覆盖 ≤0.01 变而 60–67% 图像改判；
- 11-24：准确率 0.03 点不动而 1.1–12.3% 成对翻转、selection 变 5–8× 于 answer；judge 单次抽样波动 18 点；
- **本轮 29629：IJB-C 在 FMR=10⁻⁶ 只有 2.7M 有效独立比较，低于 `10/FMR` 规则，最小可报告 FMR ≈6×10⁻⁵** ⇒ **低于下限的读数不是准确，是不可解析**。

⇒ 「覆盖稳定」必须同时钉死五件事：评测单位、聚合口径、区间方法、判定装置配置指纹、**有效独立样本数与最小可解析 operating point**。

#### C4 多版本回归口径（6 个模型版本迭代看板）+ 背离检出 / 退化留痕 / 泛化缺口

在 11-24 C4 八条上补四条：

| # | 本轮新增 | 依据 | 判据 |
|---|---|---|---|
| 9 | **评测集重叠审计版本列 + `N_eff` 列** | 29629 偏差不跨模型抵消、会压缩版本间差距 | 共用被污染评测集 ⇒ 版本整体排序重算 |

| 11 | **serving setup 指纹列**（batch / bit 宽 / GPU / 缓存 / 步数） | 30545 serving setup 决定出图 | 字段缺失 ⇒ 该版本不可复现 |
| 12 | **反事实恢复率列** | 30117 行为层 0 ≠ 移除 | 恢复 >0.2 ⇒ 只记「压制」 |

**整体指标与分层宏平均背离的检出**（沿用并前置）：先钉分母与评测集审计 → 出 `版本 × 一级类目 × L2_30` 的 F1/FPR/翻转率/**overlap** 矩阵 → 算 `Δaggregate` 与 `Δmacro` 符号与差值 → `Δaggregate>0 而 Δmacro<0` ⇒ 子类劣化被掩盖，不予上线 → 逐格定位 → 留 ckpt / 训练配置 / 数据集版本 / 评测口径 / **量化器与 serving setup** 五元组。

**严重退化 ckpt 根因留痕**（S1461 L3 宏 F1 10.53% → lr03 修复 86.02%）：除学习率敏感性、训练稳定性、分层崩溃、量化器/硬件/精度外，本轮补**第五维「执行环境」**（30545 证明同 ckpt 换个 batch/GPU 图就变）。

**跨评测集泛化缺口**：eval_not_include / OOD 集另报，同 ckpt 跨集 F1 差 >10 点 ⇒ 结论只在单集成立；换评测集必须登记为 calibration 事件。

### D. 下一步实验建议（六条主线）

> 排序原则：先做零训练、能一次结束纠结的；算力按 **训练集群 6 节点 → 5 节点** 的现实排。**明确：本轮不再把重心放在加严输入改写。**

#### 主线①【tag-weighted loss / 层级标签】D1：L1 × L2_30 双列 + **四元信息** + 约束式选点（半天，零训练）

出 `AUROC × BA × 样本数 × 人工一致率 × **评测集重叠率 × overlap**`，按「识别型 / 判定型」二分；标出 <200 样本、一致率 <70%、overlap >0.5 的饿格子。依据 30592 的层次消融（Uniform shallow FID 31.26 但 Total 178，Uniform deep Total 45 但 FID 40.28）⇒ **单列最优与约束最优不一致**。做法：把 6 版本看板改成「四列 + 约束式选点」（如「保真不低于基线 −0.5 前提下最小化风险率」），检查单列最优版本在约束下是否仍入选。**判据**：不一致 ⇒ 现有按总分选 ckpt 的口径作废；判定型格加权后 F1 不升反降 ⇒ 降权而非加权重。

#### 主线②【RL 改写】D2：GRPO 与 SFT 线的奖励设计对比（1 天，零训练前置 + 轻训练）

**GRPO 线（devcloud `grpo1102_125`）vs SFT 多版本并行线**，同一张表报：

| 对比项 | GRPO 线 | SFT 线 | 判据 |
|---|---|---|---|
| 主奖励 | 安全率 | 监督信号 + tag-weighted loss | 安全率提升是否伴随语义保真下降 |
| 可验证奖励 | **G7 前置**：50 条高危 prompt × 原样/微改/真改写三版 | 不适用 | 原样一致性分显著更高 ⇒ 奖励可作弊，停 |
| 奖励上界 | 从真实正例分布 75 分位量出（GARM） | 由标注分布定 | 上界以上增益是否转负 |
| 多目标 | 安全率 × 语义保真 × 指令遵循，**几何平均**禁跨维补偿 | 同左 | 任一维接近 0 直接打穿样本分 |

**本轮新增（对 reward hacking 的两条硬约束）**：① 参照 30117 的 **Seurat relabel**——奖励里的「检测器分」换一个更具体的竞争描述就整体换边（0.94→0.19），因此**奖励验证面板必须含「换判据」对照臂**，不能只换抽样；② 参照 25382——**「改写后风险分降幅」这类代理量本身可能不是好奖励**，因为加速/生成过程可以在不改一个字的情况下改写出图语义；必须配**生成后原子要件保留率**作为奖励的对应量。另与 AnimalFarm 的 GRPO 四分项（0.7/0.1/0.1/0.1）做结构对照，检查是否把「格式合规」误当「安全」；DSC 三版对照、平均改动字符数、edit rate / Levenshtein / 图像一致性奖励配齐；**RL 与 SFT 共用同一评测口径版本号 + serving setup 指纹**。

#### 主线③【标签审计与阈值校准】D3：三步顺序（半天，零训练，**最优先**）

① **评测集重叠审计**（29629）：对 2000 条图生图评测集（1979 有效样本）、PSI 评测集、训练集、阈值参考集做 embedding 近重复 + 词面 n-gram，null-calibrated 把审计假阳性率钉 0.1%，抽 100 条人工双盲复核，2×2 + size-matched random control，按每叶子算 `N_eff` 与最小可解析误杀率；② **表示可判性体检**（23685）：逐类目算 overlap 并钉死 `K_z` 口径，200 次校准抽样报 10–90 分位；③ 才做约束式阈值选点 + conformal 认证，并补 6 版本看板的实际 FPR、逐样本翻转矩阵、judge 尺子体检（A4）。**判据**：任一版本出现「AUROC 稳而 FPR 漂」「准确率稳而逐对翻转 >3%」「judge Bias >+15 点」「评测集重叠率 >0」，历史 AB 按版本重算。

#### 主线④【输出侧图审与溯源】D4：四栏拆分 + **五臂生成过程干预**（1 天，推理为主，**明确不再加严输入改写**）

按 A1 把 2,700+ 条拆成四栏（新增生成过程改写 / 执行环境漂移两栏）；按 A2 做**固定同一份改写后 prompt** 的五臂生成对照（原样 / CFG 安全引导 / 子概念+局部引导 / **guidance 项两分支重算** / **线上加速配置**），每臂报出图风险率、原子要件保留率、图审判定翻转率、e2e；图审 AB 加 `NR` 塌陷档与三退化探针基线；按编辑强度轻/中/重分档测水印检出率（本轮 2611.30523 VeriOrigin 提供「溯源 + 篡改定位 + 无损恢复」形态，见候选观察）。

**判据**：guidance 项重算臂显著优于纯 CFG 引导 ⇒ 生成过程干预是主修法；加速臂相对原样的判定翻转 >3% ⇒ **先把 serving setup 写进事件审计**，再谈模型；判定组 ≥95% 而信息组 <70% 或 NR >5% ⇒ 撤回「图审已达标」；轻编辑档水印就 <90% ⇒ 水印方案比公开基线（≥99% @10⁻⁶ FPR）更脆。

> **责任边界写死**：归因已明确 2,700+ 条源于出图侧 ⇒ **输入改写优化预算冻结**；输入侧只保留「文本复核仍有害」的极小比例修正。本轮四栏归因把「出图侧」进一步拆成可分别干预的机制，不再笼统归给生成器分布。

#### 主线⑤【I2I 改写链路（含统一生成-编辑模型改写面）】D5：0/0% 的**第六、第七种**归因（1 天，零训练，**优先级仅次于 D3**）

**背景**：I2I 改写分流命中 **0/0%**（输入侧色情模型灰度 **70%** 与改写分流 **0/0%** 并存）。七种归因：判据无分辨率 / 改写没写好 / 改写抹掉要件 / 分流只读文本通路（UNR 格）/ benchmark 允许单模态通关（灰图探针 0.9645 AUROC）/ **本轮新增：编辑前后对照被 batch 非确定性污染**（30545）/ **粗粒度路由的结构性 overlap**（23685）。

**可落地建议（针对 70% 灰度与 0/0% 并存）**：

1. **先修执行环境，不要重写改写器**：从 2000 条评测集抽 200 条，把「编辑前后其余保持原样」的判定强制改成 **solo-vs-solo 同 batch / 同精度 / 同 GPU 配置**；若命中率变化 ⇒ 0/0% 里有一部分是**对照本身不可判定**，属于评测执行环境问题（30545 引言直接以 image editing 为例）。
2. **把分流从二分改成带分数的多候选排序**：算分流的 overlap（23685）；若 >0.5 ⇒ 「一个 cell 一个判定」的路由会结构性把安全指令一起拒/放，应改为 2 候选排序 + 输出分数（沿用 11-27 EditJev：2B 小模型够用、94ms 开销）。**这条最贴 70% 灰度**：灰度已在跑，先把输出从「是否改写」改成「改写强度分」，即可在不重训的前提下让 0/0% 变成可观测的分布。
3. **统一生成-编辑模型的改写面**：固定一份改写后 prompt，分别走生成通路与编辑通路，报两通路风险判定差与原子要件保留率差（AnimalFarm 三通路 66.6/68.0/75.3）。**判据**：两通路差 >15 点 ⇒ 不能共用一份改写，必须按通路分流下发；差 <5 点 ⇒ 可共用但要把图文联合状态作为共同输入。本轮 `t9_unified_edit` 零供给，此项按自建口径落地。
4. **补灰图纯文本探针上界检验**（27339）：AUROC ≥0.90 ⇒ 验收集有词捷径，重写改写器无效。

**为什么这条最省钱**：全部是重打标 + 重跑现有链路 + 加两个探针 + 改输出格式，零训练、不重做评测集。

#### 主线⑥【多模态视频扩展】本轮**不给建议**

`t10_video_safety` 仅 2 命中：2611.27268（上轮已引用的预算式流式安全验证）与 2611.28099 VidRouteBench（**成本-质量路由 benchmark，不是安全工作**）。按用户口径「仅在出现强相关工作时给建议」，**本轮不新增视频策略建议**。AIGC 全模态策略命中事件落表中 i2v/t2v 输入/输出字段继续对齐；等 i2v/t2v 落表 >1000 条且出现强相关公开工作，再评估是否单独建视频策略。

#### 跨语言专项【针对 2B 改写模型英文 ASR 飙升】D6：三语 × 三形态九格 + **生成过程语言敏感性臂**（1 天，零训练 + 训练排期）

**本轮判断**：`t11_multilingual` 无跨语言安全改写；但 25382 给出中英对照的**生成过程**证据（guidance 项占比中英 alike **1.66×**，而中文恢复多于拉丁文本、Qwen-Image 同一顺序；关掉 conditional-norm 重缩放后损失翻倍），30925 PRIMEAPE 证明**聚合性能掩盖语言与准则差异**，24383 MuDAS 证明**Macro-F1 接近而错误模式相反**。⇒ 语言覆盖 / 文化语境 / 语用形态 / **生成过程实现**是四个独立维度。

1. 把三版对照扩成 **中 / 英 / 中英混合（code-switching）× 三形态 = 9 格**，报每格 ASR 漂移与改写后风险残留率；
2. **必含「中性 Prompt 的语义取向漂移」对照臂**：同一中性句三语下跑现有分类器，看分数分布是否系统性偏移；
3. **本轮新增第 4 臂**：9 格各自再跑「全量生成 vs 线上加速配置」，报**分语言原子要件保留率**——若英文档在加速下退化显著更大，则英文 ASR 飙升可能**不全在输入侧**，而是 guidance 项的语言敏感性；此时中英合并训练解决不了，要先修生成过程；
4. 若英文档 ASR 显著高于中文档 ⇒ 支持**中英合并训练**，但训练前先做两件零训练事：① 检查英文训练样本是否集中在显式风险词（补「无表层线索 + 文化特定」样本）；② 检查是否把疑问/肯定语用形态当低风险（DSC 思路）；
5. 合并训练后**必须报分语言 ASR、分层宏平均与逐样本判定翻转率**，禁止只报聚合 ASR；叠加 27155 的**小模型脆弱窗口占用率**（2B 约 25%）单列，禁止与 8B 共用不劣化结论。

| 必报项 | 口径 | 判据 |
|---|---|---|

| TTFT / e2e / TPOT / 超时率 / 降级率 | shadow 与生效模式分列 | 只换流量比例不换尺子，也不换执行环境 |
| 评测集健康 | 重叠审计版本 + `N_eff` + 最小可解析误杀率 | 低于下限的 operating point 不予报告 |
| 留痕事件 | ckpt、量化器/bit 宽、硬件、batch、训练配置、数据集版本、评测口径版本、阈值规则、judge 指纹 | 缺任一不可声称可复现 |

## 附：今日一句话结论

**六篇把「出图侧内生风险」从一个现象拆成四条可分别检验的机制：生成过程经 CFG guidance 项静默改写语义、执行环境（batch/GPU/精度）在同 prompt 同 seed 下换图、权重侧擦除只是压制而非移除、验收装置既有误杀的结构性下界又可能被评测集重叠污染。**

对本项目的落点只有一句：**别再往输入侧加码了，而且连「出图侧」也别再当成一个黑盒**。先把「四栏归因、五臂生成过程干预、serving setup 指纹进事件审计、评测集重叠审计先于阈值调优、反事实恢复对照」这五层补进验收，再把 2,700+ 条 case 从「改写还不够严」改写为「风险长在生成过程、执行环境与表示层」；否则 I2I 0/0% 会继续被写成「改写没写好」，而误杀率 5.2% 这个硬约束可能连读数本身都还没被审计过。
