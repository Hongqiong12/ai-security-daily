## 一、T2I / T+I2I 论文（核心主线 · 4 篇）

### 1. EditSafetyBench：编辑器在读文字，没在读图

**2611.26569** | CISPA Helmholtz + 港科广 + 港科大 | [精读](../../categories/t2i/papers/2611.26569_editsafetybench_text_aware_vision_blind.md)

**问题**：指令式图像编辑有两条输入通路（上传图 + 编辑指令），但现有安全机制多半从单模态管线继承。论文构造 **5,940** 个 image-instruction 配对（**11** 风险类目 × safe/unsafe 图片 × **3** 编辑意图），测 Gemini / GPT / Qwen API / Qwen Local 四个系统。

**核心设计**：把"图片安全"与"指令意图"做成 2×3 析因格子，用三个指标并列——**UIR**（恶意指令拒答）、**UNR**（风险图 + 中性指令拒答）、**SOR**（安全图误拒）。只看 UIR 会说"很安全"，只看 UNR 会说"没防护"，并列才看得出是**通路错配**。

**硬数字**：

- Gemini UIR **87.1%** / UNR **24.2%** / SOR **14.0%**；GPT **81.6% / 22.4% / 11.5%**（差 3.6 倍）。
- 图审核分**由视觉主导**（Unsafe+Neutral **0.195** > Safe+Unsafe-Intent **0.113**），而**放行率由文本意图主导**：unsafe-intent 指令下图片安全与否只差 **0.4%（Gemini）/ 0.2%（GPT）**，换中性指令才拉开到 13.6% / 15.7%。⇒ **风险图已经被认出来了，决策层没读。**
- GPT 放行 **70.4%** 的不安全政治内容编辑，Gemini 只放行 **34.8%**。
- GPT 对 U02 拒 **100%**、U01 只拒 **33%**，而两者**文本审核分完全相同（0.063）** ⇒ 关键词触发，不是语义理解。
- 性内容**视觉敏感性最强**（成熟 NSFW 识别的外溢收益）；SOR 在主题中性安全图上从 14.0% 降到 **3.6%** ⇒ 误伤是主题聚集型的。

**最该抄进方案的一段**：论文 Discussion 明确写 **"benchmark characterizes system behavior but does not prescribe a single correct answer"** —— 对"暴力图上说调亮度"该拒还是该放，**取决于部署语境**；作者建议 `policy-adaptive image guardrail + intent-aware decision logic`，让风险降低型编辑可放行。这是公开文献里第一次正面讨论「能改则不拒」的前提，而不是把它当标注噪声。

**局限**：黑盒系统级，拆不开输入过滤/输出复审各占多少；UNR 的 24.2% **不能直接当缺陷率**（含按策略本就该放行的）；**没有测"把编辑指令改写成安全等价物"** ⇒ 0/0% 链路仍空。

### 2. CuRSE-Bench：通用 rubric 判它无害，六个地区 persona 判它有害

**2611.20821** | KAIST | [精读](../../categories/t2i/papers/2611.20821_curse_bench_cultural_blind_spots.md)

**问题**：T2I 安全评测通常给每条 prompt 打**一个 culture-blind 伤害标签**，于是"只在特定文化里有害"的内容会以 benign 通过。

**方法**：CultureCraft（agentic 框架）构造"通用 rubric 下看似无害、目标文化下带潜在伤害"的 prompt → CuRSE-Bench **10,709** 条 culture-specific + **2,648** 条 culture-general controls（**同种子不做文化变换**）；覆盖 **6 地区 × 10 harm axes**，每条 harm vector 出自有文献记载的知识库、可追溯 **≥2 个独立来源**；**7 个评分视角**（6 地区 persona judge + 1 配对 culture-blind judge）。

**结论**：culture-blind judge 在 culture-specific 集上**系统性低估**潜在伤害，而在 controls 上**与 persona judges 一致** ⇒ 是**选择性盲区**不是整体打分松；每个 persona judge 主要解出自己地区的伤害；盲区**在 5 个已部署生成管线中持续存在**，且这些 prompt **没有做任何针对过滤器的优化**（"no surface-cue vocabulary fires"）。

**为什么对照设计值钱**：knowledge-swap control（排除 persona 让分数整体抬升）、cross-persona named-referent leakage audit（排除认出地名就判有害）、backbone ablation、control ceiling check、per-cell blind-gap + percentile bootstrap —— 五组配对对照，比扩样本量便宜且直接（延续 11-08 "识破捷径靠配对对照"）。

**局限（对业务最关键的一条）**：论文把 **English-only prompts** 明确列为 Limitations ⇒ **文化视角覆盖 ≠ 语言覆盖**，2B 改写模型英文 ASR 飙升不能靠 persona judge 解决，必须自建中/英/中英混合三语对照臂。附录 A 另直言 **"Political harm is latent everywhere"**，并按地区拆政治编码，与 L2_30 层级口径是同一问题。

> 数字纪律：本文 HTML 表格数值多为 MathJax 占位符，bypass rate / blind-gap 逐格数字无法从可核验文本读出，**不做外推**；只引用摘要与正文文字可判定的结论与规模数字。

### 3. DSC：把断言改成问句再打个勾，语义回来了，拒答没回来

**2611.25929** | 夏威夷大学马诺阿分校 + 独立研究者 | [精读](../../categories/t2i/papers/2611.25929_deferred_semantic_commitment.md)

**本轮最贴核心主线的一篇**。一个写着有害命题的标语牌会被拦，但把**同一命题**写成疑问句、再跟一个 ✓，图就生成了——而生成出来的图**依然在背书原命题**。作者命名 **Deferred Semantic Commitment**：commitment 被问句撤回、被另一元素恢复，**安全行为只跟"撤回"走**。

**300 条挑战集（Table 2）**：直接陈述 Returned **16.3%** / Endorsed **15.3%**；问句+肯定线索 **43.3% / 41.3%**（2.66× / 2.70×）。MPUP 100 条上 78% → **91%**；在**直接陈述没返回图的 251 条**里，单次 DSC 就产出 **91 张（36.3%）** 背书原命题的图 ⇒ 不是"生成了语义很弱的图"。

**机制**：Qwen3.5-VL-27B 108 组配对，严格拒答 **29.6% → 8.3%**，再肯定只部分拉回；layer-52 activation patching 用完整残差恢复拒答 **12/13（92.3%）**，只取 refusal-aligned 分量 **11/13（84.6%）**，减掉该投影掉到 **1/13（7.7%）**，norm-matched 随机方向**一个都没恢复**；natural refusal 的 held-out AUC **layer 31 才首次 >0.95**。✓ / `YES` / 对勾图片三种线索结果几乎一致（87–91% / 85–90%）⇒ 不是某个符号过拟合，是**承诺分离**这个结构。

**对改写的杀伤力**：语义**一字未改**、改动量近零，因此任何以「语义相似度 + edit_char_ratio + 锚点覆盖率」为验收的改写方案，**对这个攻击面完全无感**。论文结论落在 "assess the completed message rather than its individual elements" —— **修法是改验收单位，不是加词表**。

**局限**：300 条是从"初筛没返回图"的样本里选的（选择性偏差，43.3% 不是线上绕过率）；机制分析在开源 LM 纯文本上做，不是部署态图像生成器内部；无法定位是哪一层拦的；**未覆盖中英混合语用形态**。

### 4. Tripwire-WM：拒了伪造却没留下证据

**2611.25226** | 滑铁卢大学 + Vector Institute + KTH | [精读](../../categories/t2i/papers/2611.25226_tripwire_wm_forgery_evident.md)

**问题**：水印要同时做到低 FPR 判定准、内容保真处理下鲁棒、不可检测、**抗伪造**。第四条常被忽略：拿到一张带水印图 + 代理模型，就能把水印印到任意图上，把有害内容错误归因给某模型。更隐蔽的缺口是——**一次被当成"未加水印"拒掉的伪造，不留任何尝试痕迹**，与海量无水印自然图混在一起。

**方法**：符号型水印只用初始潜噪声的**符号**，**幅度是空闲信道**。Tripwire-WM 用 distribution-preserving embedding 把图的**语义提交到幅度**；伪造图能带有效水印，但 commitment 与内容对不上 ⇒ 检测器**既 reject 又 report**。基座 PRC / Gaussian Shading++，可证明保持不可检测性。

**结果（MS-COCO，10⁻⁶ FPR）**：imprinting 伪造接受 **0%**（SemBind 最高 **55.0%**）且全部报告为伪造；reprompting 最多接受 **1.8%**（SemBind **46.2%**）；真图接受 **≥99%**；鲁棒性与基座持平，FID/CLIP 分列。外部异常检测器 G-Cos 只标 **19.7–24.0%**、PGID-F 只标 **18.6–39.7%** 的伪造，且常见处理后误报真图 ⇒ **"加一层外部检测器"再次被证伪**（与 11-10 Jev 同级）。

**与 11-10 NotaryMark 合起来**：NotaryMark 给「判定 100% 而信息 60.69%」，本篇给「拒了却没记录发生过」⇒ **判定、信息、事件是三个独立的量**，图审 AB 至少三栏。

**局限**：测的是失真/再生/imprinting/reprompting，**未覆盖多轮指令式编辑后水印存活率**——本项目最关心的那格仍需自建 AB；闭源 API 不给潜变量时 commitment 不可验；哈希网络自身是攻击面。

## 二、方法论迁移论文（2 篇）

### 5. Operating-Point Failure：AUROC 一动不动，误杀率涨了 15 倍

**2611.19216** | 韩国国民大学（IEEE TDSC 投稿，27 页）| [精读](../../categories/t2t/papers/2611.19216_operating_point_failure_frozen_guardrail.md)

冻结护栏探针与阈值（目标 1% 良性误报），跨 **18 cells / 16 次公开 LM 更新**测 operating point；Phase 2 为**预注册**且换了更新类型与输入格式。

| 观察 | 数 |
|---|---|
| Phase 1 fail closed | **8 / 9** cells |
| **最大 FPR 上升** | **1.01% → 15.12%** |
| 同批 **AUROC 变化** | **≤ 0.0058** |
| staleness 判据 | **一个都没判 stale**；由其导出的规则只标出 **0.019** 的 layer cells |
| label-free rate estimate（只读两矩） | 标记 **0.918** 受损 cells、清除 **0.898** 未受损 cells |
| 两矩模型 | 63 个预注册 cells 中 **0.905** 解释到 1.5 倍因子内；漂移的 22 cells 中 **0.773** |
| **用存储良性 prompt 重设阈值** | 9/9 恢复目标，均值 **0.96–1.02×**，**无需新标签** |
| 参考集投毒 **1%** | 最多只剩 **0.017** 有害 prompt 被标记 |
| 攻击者控制更新 | **3/5 seeds** 压低三个目标类目之一；**两种无标签检查都漏过** |

**最扎的一行**：`AUROC ≤0.0058` 与 `FPR 1.01% → 15.12%` 同时成立。任何只盯排序指标的看板都会把这次事故判成"模型没变化"。

**迁移**：版本升级必须登记为 **calibration 事件**；多版本看板补「实际 FPR」列；参考集要防污染并保留 post hoc 带标签检查；**全局 FPR 稳定而某叶子类目 FPR 翻倍**正是「整体 F1 微涨而 L3 宏 F1 回退」的机制解释。

### 6. Risk-certified Prompt Optimization：别优化平均分，优化约束下的放行率

**2611.20156** | Capgemini + 埃夫里-瓦尔德松大学 + CentraleSupélec + ENSIIE | [精读](../../categories/t2t/papers/2611.20156_risk_certified_prompt_optimization.md)

把护栏 system prompt 选点写成 `max 良性放行率  s.t.  missed-attack rate ≤ α`，并要求**有限样本统计控制**。现实约束：部署态护栏常只暴露**二值 flag / 粗粒度 severity**，不给连续分数 ⇒ 常规 conformal 用不上。

- **CPS**：固定候选池 → Learn-then-Test + Bonferroni + **Clopper–Pearson 上置信界**认证 → 在通过认证的候选中选效用最高者。
- **CRISP**：把风险反馈接进自适应搜索，**hard example-guided rewriting** + **reusable-holdout + Guess-and-Check**，两动作 `ImproveUtility`（针对当前被过度拦截的良性样本改写）/ `ReduceRisk`（针对风险样本改写）；certified / uncertified 两种群。
- 技术核心：**固定数据、生成假设**下的有效性——CRISP 从不直接访问 holdout，只能通过 GnC 的受限输出，从而保住证书（与 anytime-valid / e-process 式自适应 LTT 方向相反）。
- 四个数据集（BIPIA / Deepset / SPL / SID），train / certify / test 三份互斥；结论：**留出测试上持续遵守目标 missed-attack level，效用随 α 放宽而提升；固定池产不出可认证高效用候选时 CRISP 尤其有用**。

**与第 5 篇成对**：19216 回答「**什么时候必须重选**」（两矩无标签信号），本篇回答「**重选时怎么认证**」。两篇必须一起落地。

**边界**：α 约束的是**风险率**，不是 conformal 的**覆盖率**（"保证必须绑定量"判据再次生效）；单一 α，无 per-category 阈值；双约束（误杀 5.2% + 漏过 3.42%）与叶子类目降级口径必须自建。

## 三、趋势信号

### 信号一：本轮的共同机制是「检查的作用层级装错了」

六篇的修复动作**没有一个是把模型变强**，全部是**把验收往上抬一层**：从文本意图 → 图文联合状态（26569）、从通用 rubric → 地区语境（20821）、从单个元素 → 完整消息（25929）、从水印判定 → 伪造事件（25226）、从排序 → operating point（19216）、从平均性能 → 显式约束（20156）。

> **报告纪律（写进 Landscape 热点三十）**：**「任何只在单个部件 / 入口 / 平均值上做的验收，都必须补一个组合层的生效指标。」** 配六条配对对照模板：图文析因格 / 不变换 control 臂 / 承诺分散对照 / reject-vs-report 双列 / 排序-vs-操作点双列 / 效用-vs-约束双列。

### 信号二："空窗"的口径必须拆开写

过去十五周写的是「整批供给为零」。本轮 3849 篇里 **NSFW 严格词边界 3 命中、审核 26、阈值 39、水印 13**，但 `t2_prompt_rewrite` 仍严格 0、`t10_video_safety` 0。⇒ 正确表述是：**改写方法零供给，评测与护栏有供给**。若继续写"整批零供给"，会把本轮 4 篇可迁移工作一起否定掉。

### 信号三：约束型指标第三次独立胜出，且这次有了"证书"

11-10 指标教程（TPR≥0.95 在测试集恰好达标，最小代价目标漂成次优）→ 11-10 Jev（匹配 4% 误杀预算后分级只差 0.7 点）→ 本轮 20156（有限样本证书下的风险约束选点）。同时 19216 补上反面：**约束一旦冻结、上游变了，证书不作废但 operating point 作废** ⇒ 约束必须配"重选触发信号"。

### 信号四：I2I 0/0% 第一次拿到「该分流的格子」的公开定义

26569 的 2×3 析因设计把「风险图 + 中性指令」单独做成 UNR 格，并给出 22–24% vs 81–87% 的通路错配实测。⇒ **0/0% 不再是"全世界都没公开做"的纯空白**（11-08 的结论需修正为：**改写方法仍空白，但该分流的输入状态已被公开刻画**）。这也给统一生成-编辑模型（HiUni 26107 / DecoEdit 19121 / WeLM-Image 一脉）的"同一份改写 Prompt 同时作用于生成与编辑两条通路"提供了可测的两格结构。

### 信号五：跨语言与"文化语境"是两个独立维度

20821 明确 English-only；25929 未覆盖中英混合语用形态；另有 2611.18601（语言风格改写让 ASR 在 **<6% 与 80%** 之间摆动）作为候选观察。⇒ **persona/文化覆盖不能替代语言覆盖**；语用形态攻击（DSC）与语言漂移必须各建一条对照臂。

## 四、业务对齐研究板块 ⭐

> **本板块固定回答四件事**：直接可迁移方法 / 双锚点处理启发 / 三维评测设计启发 / 六条主线下一步实验建议。
> **运营约束基线**：误杀率 **5.2%** / 漏过率 **3.42%** / 一级一致率 **77.64%**。本节所有建议**不得以帮助性退化换取降风险**，且必须关注**用户侧可感知误伤**与**「假安全」拒答体感**。

### A. 直接可迁移方法

#### A1【最优先，零训练，1 天】把 I2I 0/0% 拆成 2×3 析因格子 —— 来自 EditSafetyBench

**现状**：图生图改写分流命中 **0/0%**，与"输入侧色情模型灰度 70%"并存；过去多轮归因为「判据无分辨率 / 改写没写好 / 改写抹掉要件」。

**可迁移**：26569 的 UNR 格证明还有第四种——**分流只读文本通路，风险在图片侧时根本没进判定**。

**做法**：现有 2000 条图生图评测集（1979 有效样本）按「源图风险（safe/unsafe）× 指令意图（unsafe-intent / neutral / risk-reducing）」重打成 6 格，每格分别报：改写分流命中率、改写后安全率、误杀率、人工双盲残留率。

**判据**：

| 观测 | 结论 | 修法 |
|---|---|---|
| 命中几乎全在「安全图 + 恶意指令」格，风险图两格接近 0 | **分流是文本单通道的** | 接图审分到决策层；补图文联合判定，不是重写改写器 |
| 六格都接近 0 | 判据无分辨率 | 回到原子要件覆盖率分档 |
| 「风险图 + 中性指令」格误杀显著高于全局 | 误伤主题聚集 | 按类目做阈值，不做全局调阈值 |

> 26569 的 SOR 在主题中性图上从 14.0% → 3.6%，说明**误伤集中在风险相邻主题**，这条可直接用于误杀率 5.2% 的分层拆解。

#### A2【最优先，零训练，半天】加「组合层复核」而不是加词表 —— 来自 DSC

**现状**：改写验收看语义相似度 + 改动量 + 锚点覆盖率。

**可迁移**：DSC 是**语义一字未改、改动量近零**，却把生成率从 16.3% 抬到 43.3% ⇒ 现有三维全部测不到它。

**做法**：分流前把 prompt 中分散的「疑问 + 肯定标记 / 分句 / 符号 / 引用」合成为**一个完整命题**再判；评测集为每条高风险 prompt 生成三版（原句 / 保义疑问化 / 疑问化+肯定线索），跑现有分类器与改写链路。

**判据**：三版语义相似度接近而风险分跳变 **>20 点** ⇒ 分类器在读承诺形式不在读语义，此时"语义保真"指标**不可作为验收**；合成前后判定差异样本 **>10%** ⇒ 现有逐词锚点方案存在结构性缺口。

#### A3【最优先，零训练，半天】6 版本看板补「实际 FPR」列 —— 来自 Operating-Point Failure

**做法**：每个 ckpt 在同一批**冻结良性样本**上算部署阈值下的实际误杀率，与 AUROC / macro-F1 并列；每次图审 / 改写模型版本变更强制落一条 `冻结阈值 / 重设阈值 / 未重设` 三态 + 校准集指纹。

**判据**：出现「AUROC 变 ≤0.01 而 FPR 翻倍」⇒ **历史 AB 结论按版本重算**（本篇实测 1.01% → 15.12%）；未重设而 FPR 已漂 ⇒ 该版本指标不可与前一版直接比。

#### A4【低成本，零训练，1 天】约束式阈值选点 + 重选认证 —— 来自 Risk-certified Prompt Opt

**做法**：把 L2_30 叶子类目的选点规则从「最大 F1」改成「**误杀 ≤5.2% 约束下最小化漏过**」，用固定良性集做 Clopper–Pearson 上界认证，报 **（阈值、选择规则、数据划分、代价比）四元组**；把 SFT 线多个改写版本 / 多个模板当候选池，逐一认证后才比语义保真。

**判据**：出现「保真更高但认证不过」的候选 ⇒ **当前 AB 看板在用效用掩盖风险**；把 A3 的两矩无标签信号当"该重选了"的触发器，本篇当"怎么重选"的执行器，**两篇成对部署**。

#### A5【验收口径，零训练，半天】图审 AB 拆成「判定 / 信息 / 事件」三栏 —— 来自 Tripwire-WM + NotaryMark

| 组 | 指标 | 回答什么 |
|---|---|---|
| 判定 | TPR / FPR / 误杀率 | 能不能识别风险 |
| 信息 | 细类目混淆矩阵、PORN/VULG 边界 F1、L2_30 叶子准确率 | 判对了哪一类 |
| **事件** | 拦截 / 改写 / 申诉 / 复核的**落表率与可追溯 ID** | 发生过什么、能否复盘 |

**判据**：判定接近满分而事件栏缺失 ⇒ **策略命中事件审计是空的**；所有被挡样本（含被当成"未命中策略"的）都要写结构化事件，带版本、阈值、规则指纹。参照本篇：被拒却不报告的伪造在 SemBind 上最高占 46%。

#### A6【评测集构建，零训练，1 天】不变换 control 臂 + 五组配对对照 —— 来自 CuRSE-Bench

**做法**：为每条高风险 prompt 配一条**只去掉风险锚点、其余槽位不变**的 control；五组对照常驻 eval harness：不变换 control / knowledge-swap / 命名指称泄漏 / 骨干消融 / 天花板检查。

**判据**：判据在 controls 上就不一致 ⇒ 现有整体指标含 judge 标定偏差，历史版本对比需重算；任一对照失败即撤回该轮结论。

#### A7【策略可配置护栏，零训练】规则-策略分层与热更新口径 —— 来自 20156 + 19216

对应 t2t-integration 接入台「按一级/二级/叶子类目勾选 + 阈值下发」：

- **L0 规则层**（词表 / 排除项正向化）：改动最小、可秒级热更新，但**对 DSC 式组合攻击无效**；
- **L1 策略层**（α 约束下的认证选点）：按类目下发，需 certification split，**版本升级必须重新认证**；
- **L2 知识层**（风险知识库 + 干预策略库注入）：文化/地区语境与政治层级口径，必须带 region / locale 标签，且**不能替代语言覆盖**。
- 每次热更新落一条事件（版本、阈值、规则指纹、认证集指纹），供 PSI 与分布漂移监控。

#### A8【方案写死，无需实验】权重侧 vs 输入侧第十轮边界：互补，非替代

本轮权重侧有供给但全部落在候选观察：`2611.24220`（擦除在下游 DreamBooth / LoRA / Custom Diffusion 微调后被**恢复**）、`2611.20625 / 2611.20623`（**necessity-driven 选择性激活 + 局部外科式抑制 + 细粒度子概念分解**，原文批评现有方法"monolithic"）、`2611.25640`（证明全局与任务条件线性 guardedness **不可同时成立**）、`2611.18701`（hard-negative 微调究竟教会了什么，含灰图对照与多种子）。

| 层 | 管什么 | 明确失效边界 |
|---|---|---|
| **权重侧擦除** | 上线前把概念概率压低、极少数不可逆概念 | 对下游微调回装无管辖权（24220）；缺"只擦这个"的精度；连自己的 loss 都不能当验收 |
| **输入侧热更新改写** | 上线后逐条可回滚、可分业务配置、可灰度 | 管不了已生成出去的图；**对组合层语义（DSC）与视觉通路（UNR）会漏**；中英混合鲁棒性未解 |
| **输出侧图审 / 溯源** | 已生成图的判定、信息、事件与归因 | 管不了输入侧策略；编辑后水印存活率未验证 |

⇒ **三者的失效方向互不覆盖，任一层单独宣称"内容安全已解决"即判越界**。本轮唯一交集仍是「定位」：权重侧先定位再擦除，输入侧先抽锚点再改写，输出侧先定位再复核。

### B. 风险锚点处理启发（双锚点：PORN/VULG 边界 + 政治 L2_30 层级）

#### B1 PORN/VULG：本轮给出**第五种**解释 —— "检测器够用，问题在定义层与承诺形式"

前四种：二维 depict/enable（11-02）、少身份维 (S,I)（11-03）、词驱动锚点（11-04）、"太弱测不到"（11-10）。

**本轮新增证据**：26569 报「**性内容是视觉敏感性最强的一类**，受益于成熟 NSFW 识别」；同一批系统里政治内容跨厂商差近一倍（70.4% vs 34.8%）。⇒ **PORN 类不是检测器能力不足，VULG-HINT-EDGE 的混淆更可能出在「什么算暗示」的定义与「承诺是否被分散」的形式上**（25929 的 DSC、24383 的标注分歧）。

**三条判据（全部零训练，成本递增）**

| # | 做法 | 判据 | 结论 |
|---|---|---|---|
| 1 | 抽 100 条 `VULG-HINT-EDGE`，做「原句 / 保义疑问化 / 疑问化+肯定线索」三版对照 | 风险分跳变 >20 点而语义相似度几乎不变 | **承诺形式驱动**，改类目定义无效，需组合层复核 |
| 2 | 同批样本按 CuRSE-Bench 方式配不变换 control，跑 culture-blind 与 L2_30 视角双判据 | 两者只在特定类目分离、controls 一致 | **层级口径盲区**，非阈值偏 |
| 3 | 100 条"改写后判低风险"样本做人工双盲（只看图不给 prompt） | 人工残留率 − 分类器残留率 >10 点 | 口径问题（延续 11-10 A2） |

**与前四解释的关系**：第五种不取代前四种，但给了一个**不需要重新标注、也不需要改类目树**的入口——先测"是不是承诺形式在动"，半天可结束。

#### B2 政治 L2_30：本轮的关键是「选择性盲区」与「跨系统不一致」

**三条硬证据**：20821 附录直言 political harm is latent everywhere、按地区拆编码；26569 同风险类目 GPT 放行 70.4% / Gemini 34.8%；19216 攻击者可在 3/5 seeds 定向压低三个目标类目之一而**两种无标签检查都漏过**。

| # | 做法 | 判据 | 含义 |
|---|---|---|---|
| 1 | 按 L1 × L2_30 逐格报 FPR，不只报全局 | 全局 FPR 稳而某叶子翻倍 | **聚合口径掩盖子类劣化**（整体 F1 微涨 / L3 宏 F1 回退的机制） |
| 2 | 对叶子类目做「通用 rubric vs 地区语境视角」双判据 | 只在特定类目分离 | 层级口径需带 region / locale 标签，统一 rubric 结构上盖不住 |
| 3 | 报 L1–L4 等级分布与各级患病率（延续 11-10 B2） | 一级一致率相同而分布差 >10 点 | 两个系统在输出不同形状，**ordinal calibration 先于调阈值** |

> **为什么不是再调一次阈值**：19216 证明排序（AUROC）不变时阈值调整只能平移 operating point；20156 证明约束要显式认证。⇒ **先钉死等级形状与分层口径，再认证阈值**。

#### B3 用户侧可感知误伤与「假安全」拒答体感：本轮第一次有可观测归因

| 体感 | 本轮机制证据 | 建议监控指标 |
|---|---|---|
| "我没写违规内容却被拒" | 26569 SOR **14.0% / 11.5%**，且主题中性图上降到 **3.6%** ⇒ 误伤**主题聚集**，不是全局过度拒答 | 按一级类目 × 主题切片的误杀率；误伤申诉回捞率 |
| "明明检查过了还是出图" | 25929 DSC：拒答只跟"承诺撤回"走，语义跟"恢复"走，**深层（>layer 31）才分离** | 分类器判低风险但人工复核仍判有害的比例；随改写强度的斜率 |
| "改完意思变了/被敷衍" | 26569 的 risk-reducing 意图档放行率与 neutral 几乎相同（≥82%）⇒ 系统没用这一档 | 改写前后原子要件保留率（主体/属性/关系）+ 用户意图满足率 |

**硬约束**：以上任何优化**不得以降低帮助性换降风险**。判据写死——`误杀 ≤5.2%` 且 `漏过 ≤3.42%` 双约束下比较，只报单侧改善的一律不进看板（延续 11-08 Reweighting 的"另一侧是不是在变差"）。

#### B4 跨锚点共同结论

两个锚点这轮的答案都是：**先分清「判不出来」和「检查作用在错的层级」**。PORN/VULG 是承诺形式与定义层，L2_30 是地区语境与分层口径；**两条都不需要重新标注**，各半天到一天。

### C. 三维评测设计启发

#### C1 三维聚合：补第四维「组合层生效」

现有三维「语义保持 / 安全提升 / 指令遵循」全部是**单件级**指标，对 DSC（语义一字未改）、UNR（风险在图不在文）天然无感。

| 维度 | 现有 | 建议新增 |
|---|---|---|
| 语义保持 | CLIP / LLM judge | 保留，另加「完整命题等价」人工双盲 |
| 安全提升 | 分类器风险分 | 保留，另加图文联合状态判定 |
| 指令遵循 | 要件匹配 | 保留，另加主体/属性/关系三元保留率 |
| **组合层生效** | — | **completed-message 复核通过率 + 图文两通路一致性** |

**判据**：若三维总分上升而组合层通过率下降 >10 点，则这次上升**不可信**——它是把难判样本推出去了，不是把风险降下来了（与 11-10 "可测性"第四维互补，可合并成一张表）。

#### C2 阈值 operating point：约束 + 四元组 + 认证 + 重选触发

| 现状 | 建议 |
|---|---|
| 报一个阈值 + 一组 TPR/TNR | 报 **（阈值、选择规则、数据划分、代价比）四元组** |
| 按 F1 / 加权代价选点 | 按 **误杀 ≤5.2% 与漏过 ≤3.42% 双约束**选点，Clopper–Pearson 上界认证 |
| 一次选定长期冻结 | 版本升级登记为 **calibration 事件**，两矩无标签信号触发重选 |
| 全局一个阈值 | 按一级/二级/叶子类目下发；样本 <200 的叶子继承父类阈值并写明降级口径 |

依据：20156（约束证书）、19216（冻结阈值 1.01%→15.12%）、11-10 指标教程（F1 最高者代价最贵 473.5 vs 274.0）。

#### C3 Conformal 覆盖稳定性：先分清约束的是哪个量

- 20156 的 α 约束的是**风险率（missed-attack）**，不是 conformal 的**覆盖率**；两者不可互相替代（"保证必须绑定量"判据）。
- 11-08 Coverage Hides Churn：覆盖 ≤0.01 变化而 **60–67% 图像改判**；撤销 8.4–52.7% vs 新增 0.1–2.5% ⇒ **coverage churn 必须单独监控**。
- 11-10 指标教程 S13：池化 / 平均 / 多数三口径给 **0.691 / 0.700 / 0.857**，朴素区间比 cluster bootstrap 窄 **3 倍**。

⇒ **"覆盖稳定"必须同时钉死三件事**：评测单位（图 / prompt / 批次）、聚合口径（池化 / 平均 / 多数）、区间方法（是否处理组内相关）。缺任一，这句话不成立。本轮候选观察 `2611.22646`（硬覆盖约束的不可避免效率代价）、`2611.25342`（marginal 覆盖 ≈0.90 而 violation 类十折均值仅 **0.37**，Mondrian 0.89–0.92）可继续深挖。

#### C4 多版本回归口径（6 个模型版本迭代看板）

| # | 要求 | 依据 | 不做会怎样 |
|---|---|---|---|
| 1 | 每个版本报**实际 FPR**（冻结良性样本） | 19216：AUROC ≤0.0058 而 FPR 15 倍 | 版本间比的是排序不是决策 |
| 2 | 每个版本报**判定 / 信息 / 事件**三栏 | 25226 + NotaryMark | 二分类器冒充图审、审计空洞 |
| 3 | 每个版本带**配置指纹**（ckpt / 训练配置 / 数据集变更日志 / 阈值规则 / 评测口径版本号） | 11-05 数字绑定配置 | 跨配置比较被当成模型比较 |
| 4 | **逐版本 P-R-F1 留痕 + 分层宏平均** | 19216 定向类目攻击 | 见下 |
| 5 | 每个版本报**评测单位与聚合口径** | 指标教程 S13 | 比的是口径不是模型 |

**整体指标与分层宏平均背离的检出方式（本轮新增，可直接落地）**：

1. 固定分母：所有版本用**同一评测集、同一聚合口径、同一阈值规则**；
2. 出 `版本 × 一级类目 × L2_30 叶子` 的 F1 / FPR 矩阵，而不是只出一行总分；
3. 同时算 `Δaggregate = F1_v − F1_{v-1}` 与 `Δmacro = macroF1_v − macroF1_{v-1}`，**报二者符号与差值**；
4. **判据**：`Δaggregate > 0 而 Δmacro < 0` ⇒ 判定为"子类劣化被聚合掩盖"，该版本**不予上线**；再看逐格 FPR，定位到具体叶子类目（19216 证明全局 FPR 可稳而某类目被压掉）；
5. 每一步都留 `ckpt / 配置 / 数据集版本 / 评测口径版本` 四元组，供复现。

#### C5 灰度 / 观察模式前后口径一致性（shadow / canary 分阶段放量）

对应六层风控指标框架（业务结果 / 拦截能力 / 风险态势 / 全链路专项 / 误伤体验 / 技术健康）：

| 层 | 灰度前后必须同口径的字段 | 本轮新增要求 |
|---|---|---|
| 业务结果 | 放行率、改写触发率、用户意图满足率 | 与 A/B 看板共用同一批冻结良性样本 |
| 拦截能力 | 误杀率 5.2% / 漏过率 3.42% / 一级一致率 77.64% | **双约束联合报**，禁止单侧改善进看板 |
| 风险态势 | **PSI / 分布漂移**、类目 prevalence | 换 prompt 体制（显式/非显式/图像条件）三套都测，差 >20 点则该版本不可单集验收 |
| 全链路专项 | 图文两通路一致性、组合层复核通过率、coverage churn | 新增「承诺分散」对照臂命中率 |

### D. 下一步实验建议（六条主线）

> 排序原则：先做零训练、能一次结束纠结的；算力按**训练集群 6 节点 → 5 节点**的现实排。

#### 主线①【tag-weighted loss / 层级标签】D1：L1 × L2_30 双列 + 饥饿格子检查（半天，零训练）

**做法**：出 `AUROC × BA` 双列表，按「识别型 / 判定型」二分（11-02 结论：判定型加权只放大噪声）；统计 L1×L2_30×L3×L4 每格样本数，标出 <200 的饿格子。

**判据**：饿格子存在 ⇒ **先补数据再上联合头，顺序反了就是 −0.360**（11-03 AK_QMUL）；「判定型」格加权后 F1 不升反降 ⇒ 该类目降权而非加权重。

#### 主线②【RL 改写】D2：GRPO 与 SFT 线的奖励设计对比（1 天，零训练前置 + 轻训练）

**GRPO 线（devcloud `grpo1102_125`）** vs **SFT 多版本并行线**，必须在同一张表上报四件事：

| 对比项 | GRPO 线 | SFT 线 | 判据 |
|---|---|---|---|
| 主奖励 | 安全率 | 监督信号 + tag-weighted loss | 安全率提升是否伴随语义保真下降 |
| 可验证奖励 | 需验证"不改"能否拿高分 | 不适用 | **G7 前置**：50 条高危 prompt × 原样/微改/真改写三版，原样一致性分显著更高 ⇒ 奖励可作弊，任何 loss 调整先停 |
| 奖励上界 | 从**真实正例分布 75 分位**量出（11-09 GARM） | 由标注分布定 | 上界以上是否出现增益转负（11-10 LeNO σ>1.2 反号） |
| 多目标 | 安全率 × 语义保真 × 指令遵循，**几何平均**禁跨维补偿 | 同左 | 任一维接近 0 直接打穿样本分 |

**本轮新增必做**：把 **DSC 三版对照**塞进奖励验证面板——若「问句+肯定」在语义相似度不变时安全分大幅下降，则**当前奖励在读承诺形式，reward hacking 有一条零成本路径**；同时监控**平均改动字符数**（8 字→1 字 = 作弊率在升）、**图像一致性奖励**（Qwen-Image 类）、**edit rate 约束**与 **Levenshtein 距离约束**是否配齐。**RL 与 SFT 两条线共用同一评测口径版本号**，否则对比无效。

#### 主线③【标签审计与阈值校准】D3：认证式选点 + 实际 FPR 体检（半天，零训练，**最优先**）

三件事一起做：① 约束式阈值选点 + 四元组（A4）；② 6 版本看板补实际 FPR 与两矩无标签估计（A3）；③ 参考集来源审计 + 1% 投毒演练（19216：投毒后最多只剩 0.017 检出）。

**判据**：任一版本出现「AUROC 稳而 FPR 漂」⇒ 历史 AB 按版本重算；参考集含 ≥1% 有害样本 ⇒ 该次重设作废。

#### 主线④【输出侧图审与溯源】D4：判定/信息/事件三栏 + 编辑后水印存活率分档（1 天，推理为主）

**做法**：图审 AB 加事件栏（A5）；按编辑强度轻/中/重分档测水印检出率，同时报 FID 代理；按 AIGC detection 与 provenance 两条通路分列。

**判据**：判定组 ≥95% 而信息组 <70% ⇒ 撤回"图审已达标"（11-10 H3）；轻编辑档就掉到 <90% ⇒ 水印方案比公开方法更脆（25226 的 ≥99% @10⁻⁶ FPR 是基线）。**"加一层外部检测器"先做匹配 FPR 预算对照**（G-Cos 19.7–24.0%，不显著就不加）。

#### 主线⑤【I2I 改写链路（含统一生成-编辑模型改写面）】D5：0/0% 的第四种归因（1 天，零训练，**优先级仅次于 D3**）

**背景**：I2I 改写分流命中 **0/0%**（输入侧色情模型灰度 **70%** 与改写分流 **0/0%** 并存）。本轮新增第四种可证伪归因：**分流只读文本通路**（26569 UIR 81–87% vs UNR 22–24%）。

**做法（A1 + A2 合并，2 天，零训练）**：

1. 2000 条评测集按 2×3 析因重打标，报 6 格命中率 ⇒ 定位是「分流单通道」还是「判据无分辨率」；
2. 对"风险图 + 中性指令"格单独跑图审分，与最终决策对照 ⇒ 若审核分高但放行，**决策层没读图审输出**（26569 的 0.195 vs 0.113 同构）；
3. 对每格做 DSC 式组合层复核，看「承诺分散」是否也贡献 0%；
4. **统一生成-编辑模型的改写面**：HiUni（26107）/ DecoEdit（19121）/ WeLM-Image 一脉把理解与生成放进共享视觉空间，因此**同一份改写 Prompt 会同时作用于生成与编辑两条通路**。做法：固定一份改写后 prompt，分别走生成通路与编辑通路，报两通路的风险判定差与原子要件保留率差。
   **判据**：两通路差 >15 点 ⇒ **不能共用一份改写**，必须按通路分流下发；差 <5 点 ⇒ 可共用，但要把"图文联合状态"作为共同输入。

**为什么这条最省钱**：四种归因全部是**重打标 + 重跑现有链路**，零训练、不重做评测集。

#### 主线⑥【多模态视频扩展】本轮**不启动**

`t10_video_safety` 返回 **0**，3849 篇全批池无强相关视频生成安全工作。按纪律（仅在出现强相关工作时给建议）：**继续观察，等 i2v/t2v 落表 >1000 条再评估**；AIGC 全模态策略命中事件落表中的 i2v/t2v 输入与输出落表先保持字段对齐，不新增策略。

#### 跨语言专项【针对 2B 改写模型英文 ASR 飙升】D6：三语对照臂 + 中英合并训练（1 天，零训练 + 训练排期）

**本轮判断**：20821 明确 English-only、25929 未覆盖中英混合语用形态、2611.18601（语言风格改写使 ASR 在 <6% 与 80% 间摆动）⇒ **语言覆盖、文化语境、语用形态是三个独立维度**，不能互相替代。

**做法**：

1. 把 A2 的三版对照扩成 **中 / 英 / 中英混合（code-switching）** 三语 × 三形态 = 9 格，报每格 ASR 漂移与改写后风险残留率；
2. **对照臂必须含"中性 Prompt 的语义取向漂移"**：同一中性句在三语下跑现有分类器，看分数分布是否系统性偏移；
3. 若英文档 ASR 显著高于中文档 ⇒ **支持中英合并训练**，但训练前先做两件零训练事：① 检查英文训练样本是否集中在"显式风险词"（若是，补"无表层线索 + 文化特定"样本，CuRSE-Bench 思路）；② 检查是否把"疑问/肯定"语用形态当成了低风险（DSC 思路）；
4. 合并训练后**必须报分语言 ASR 与分层宏平均**，禁止只报聚合 ASR（防止整体变好、英文子类劣化）。

#### 算力约束下的取舍（6 节点 → 5 节点）

| 类别 | 条目 | 算力 |
|---|---|---|
| **零训练（8 条）** | D1 / D2 前置面板 / D3 / A1–A8 的抽检类 / D5 / D6 对照臂 | **0 GPU** |
| 轻训练 / 推理为主 | D4（水印与图审评测）、D6 的中英合并训练数据准备 | 推理为主 |
| 重训练（本轮**不建议启动**） | RL 改写重训、tag-weighted 重训、中英合并训练 | **等 D3 / D5 结论** |

⇒ **本轮全部建议优先零训练，约 4–5 天可完成，不占 5 节点集群**。在 D3（阈值与版本口径）与 D5（0/0% 归因）出结论前，不建议启动任何重训——这两条会直接改变"训什么、用哪份评测集验收"。低算力约束下可沿用 LoRA/QLoRA、蒸馏小模型、packing/ZeRO、类别不均衡重采样，但**重采样前先看 11-08 Reweighting 的隐性代价**（组间差距收窄 74% 靠恶化该组、每万人多漏 82 例）。
