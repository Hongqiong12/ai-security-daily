## 一、T2I / T+I2I 论文（核心主线 · 4 篇）

### 1. TailSteer：多轮编辑的漂移，一次末端干预就能压住——但全程用会毁掉它

**（商汤研究院 + 港中文 MMLab + 上海 AI Lab，2026-11-04，cs.CV）**
精读：`categories/t2i/papers/2611.06741_tailsteer_multiturn_edit_drift.md`

#### 它解决了什么

单轮编辑分数很高，多轮会崩——因为每轮输出成为下轮输入，小的非预期改动被反复放大。

现有两条路都有代价：多轮数据训练会改动预训练先验；推理期 preservation 模块（FreqEdit / VAE-LFA / ConsLoRA）**实测显著拉低单轮编辑能力**。

TailSteer 走第三条：**只在最后一次训练阶段动手，只改轨迹尾部。**

#### 方法三件事

1. **保真目标不用人工标注**——"没有被要求改变的内容"就在源图里。identity editing 给全图监督，local editing 用源图与 rollout 终点的差异自动导出 mask。
2. **三区段速度混合**：prior region 硬匹配冻结基座的速度（一个字都不许改），transition region 渐进混合，tail region 做校正。
3. **在策训练**：训练状态由正在训练的模型自己 rollout 得到，避免状态分布错位。

#### 本轮最该带走的一条实证

50 步采样，FLUX.2 [klein] Base 9B：

| 配置 | 5 轮后 | 20 轮后 |
|---|---|---|
| 全 50 步用基座 | 可见面部退化 | 继续恶化 |
| **49 步基座 + 1 步微调** | 明显减轻 | **视觉稳定** |
| **50 步全用微调模型** | — | **去饱和、过度平滑、丢细节** |

**同一个监督信号：单点用有效，全程用会毁掉先验。** 原因是参数在所有时间步共享，末端训练会扰动早期动力学。

#### 代价表（Table 1，FLUX.2 [klein]）

| 配置 | GEdit-EN | GEdit-ZH | RISE Acc | ImgEdit |
|---|---|---|---|---|
| Base | 7.47 | 7.42 | 14.17 | 4.20 |
| FreqEdit | 7.20 (−0.27) | 7.18 (−0.25) | 11.11 (−3.06) | 4.09 (−0.12) |
| ConsLoRA | 6.58 (−0.89) | 6.43 (−0.99) | 9.44 (−4.72) | 3.86 (−0.34) |
| **TailSteer k_s=46** | **7.52 (+0.05)** | 7.39 (−0.04) | 13.61 (−0.56) | 4.19 (−0.02) |

**推理期模块的单轮能力代价是 3–5 倍于"改在训练末端"。** 这是"改在哪一层"的价码表。

#### 多轮漂移（Table 2，FLUX.1 Kontext [dev]）

| 配置 | MSE-Bench SR@5 | COA | PSNR@10 | SSIM@10 | LPIPS@10 |
|---|---|---|---|---|---|
| Base | 16.00 | 34.77 | 18.64 | 0.585 | 0.388 |
| FreqEdit | **10.00 (−6.00)** | 36.82 (+2.04) | 17.20 (−1.44) | 0.519 | 0.278 |
| VAE-LFA | **10.00 (−6.00)** | 35.07 (+0.30) | 19.65 (+1.01) | 0.602 | 0.363 |
| **TailSteer k_s=25** | **17.00 (+1.00)** | 34.84 (+0.07) | **21.02 (+2.38)** | **0.672** | **0.257** |

三个数必须一起读：FreqEdit 的**编辑成功率掉 6 点**，但**内容一致性反而 +5.22**（87.46→92.68）——因为它改得少了。**只看"一致性"，FreqEdit 最好；但它是靠"不编辑"换来的。**

论文为此专门设计了 Add & Preserve：框外测漂移（PSNR/SSIM/LPIPS@10），框内测完成度（COA）。原话是"把漂移和编辑完成度分开测，从而区分真正的保真收益与仅仅压掉了被请求的编辑"。

#### 两个反直觉结论

- **最优校正位置不在最末**，而在"较早或中间的 onset"（四个 backbone 各扫了三档）。
- **漂移有第二个来源**：轮间反复 VAE 重建。latent feedback 单独用收益有限，叠上 TailSteer 后 turn-10 的 PSNR 相当于标准反馈的 turn-5。**只修模型侧，链路侧还在漏。**

#### 对我们意味着什么

**这是本轮对 I2I 改写 0/0% 最有解释力的一篇。** 如果我们的改写把编辑意图压掉了，风险指标会变好、内容一致性会变好——正是 FreqEdit 的形态。**必须引入 COA 式的独立分母，才能区分"改得安全"与"改没了"。**

### 2. Number Words Past Ten：命中率分不出"跟得松"和"根本不跟"

**（University of Colorado Boulder，2026-11-04，cs.CV）**
精读：`categories/t2i/papers/2611.06840_number_words_past_ten_t2i.md`

#### 它问的问题

数不清是 T2I 最顽固的失败，过十更差。但论文问的是一个更基础的问题：

> 过十之后，那个数词**还在起作用吗**？

以及由此推出的方法论结论：

> 一个松跟随数词的模型和一个完全忽略数词的模型都很少精确，所以**精确匹配率无法区分它们**。

#### 同噪声协议

采样确定性 ⇒ 一个物体 + 一个起始噪声 = 一张图。于是可以固定一切、只改一个因子：

| 干预 | 期望（若数词仍有效） |
|---|---|
| 改数字（12→25） | 同噪声下，更大请求给更多物体 |
| 换种子 | 对照组 |
| 改数词拼写（twelve→12） | 对照组 |
| 加无关词 | 对照组 |
| **只重画细于 1/8 图幅的噪声** | 数量动、布局不动 |

**判据**：如果数词还在引导人群，"新数字"应该把数量推得比"不动数量的改动"更远。

3,088 张图由**从未见过 prompt 的人**计数（排除照 prompt 数的确认偏差）。

#### 结果

| 现象 | 数 |
|---|---|
| 射程内（2–8）同噪声对满足"大请求给更多物体" | **80–99%** |
| 射程外，重画细噪声 vs 数词对数量的推动比 | **2/3** |
| 射程外，数词对数量的方向性 | **无** |
| 植入网格 vs 纯 prompt 的数量命中（人计） | **59% vs 4%** |

射程：SD3.5-M 与 FLUX.1-dev 十之后很快就停；FLUX.2 [klein] 与 Qwen-Image 松散跟随到 25。

数词**确实到达了去噪器**（可在条件里按顺序读出，前几步起作用），但"从放大数词到在计数人群上微调，都没能让大数字产生方向"。

**"信号存在"与"信号有方向"是两件事。**

#### 指标可分辨性（本轮的"负结果表"）

| 指标 | 过十后能否区分"松跟随"与"忽略" |
|---|---|
| exact-match | **几乎不能** |
| relative-error | **几乎不能，甚至偏好常数猜 16** |
| 同噪声排序检验 | **能** |

**"永远输出 16"的退化策略在 relative-error 上能赢过真的在跟随的模型。** 这不是"指标不够好"，是指标方向错了。

#### 对我们意味着什么

我们的"一级一致率 77.64%"是 exact-match 型指标。**先算"永远输出多数类"能拿多少分**——如果接近 77.64%，这个数就不能用来判断版本进步。

### 3. LongBanana：4,670 条原子判据，和它换不来的那 15.82 个点

**（快手可灵 AI 研究院 + 华南师大 + UBC + Vector + CMU + 滑铁卢 + 清华 + 港科大 + 港大，2026-11-04，cs.CV）**
精读：`categories/t2i/papers/2611.06856_longbanana_multi_reference_bench.md`

#### 它解决了什么

Agent 时代的图像生成要"从大参考库里检索证据、拒绝相似干扰项、绑定实体与关系、按约束构图"。这些失败的性质是：

> 这些失败通常是**溯源错误**而不是渲染错误——画对了物体类别但抄错了参考图的外观，摆对了实体但违反了关系，或者交出精致构图却把硬负样本漏进画面。

所以评测必须是**能定位错误的判据**，不是整体分。

#### 结构

| 项 | 数 |
|---|---|
| 任务 | **90**（3×3 分类法） |
| 每任务参考图 / 约束 / 评测项 | ~32 / ~20 / ~50 |
| **专家指定原子判据** | **4,670** |
| 人类复核判据标签 | **46,700**（900 个输出） |
| 双标子集 | **7,005 条（15%）** |
| 双标一致性 | exact **89.4%** / QWK **0.83** |

三层图单元 → 三个维度：节点→Content Fidelity，边→Relational Binding，整图约束→Global Constraint Satisfaction。每条判据绑唯一图单元，能挂确定性工具（OCR / 计数 / 布局 / 身份）就挂工具，并留证据链。

#### 最重要的一组数

| Judge | Pearson | Spearman | Kendall |
|---|---|---|---|
| VLM-as-judge（单次） | 0.8413 | 0.8248 | 0.6437 |
| **LongBananaEval（agentic checklist）** | **0.8707** | **0.8602** | **0.6727** |

**输出级只涨 2.9 个点。** 但条目级：

> 三元精确一致率 **+15.82 个百分点**，两端相反的误差 **−19.28 个百分点**。

**同一个改进，换一个分母看，差 5 倍。** 原因不难理解：一个把若干判据判反的 judge，只要总分排序不乱，输出级相关系数几乎不动。

#### 两个工程细节值得抄

1. **难度权重必须冻结**：由固定参考系统池计算一次、版本化、此后对所有系统保持固定。权重随被测系统变，跨版本比较就作废。
2. **审计与纠错过程本身写进论文**（附录 B 的审计—纠错结果与 rank-stability 分析）。标注错误被当作数据，这是 89.4% 可信的前提。

#### 对我们意味着什么

I2I 评测集 2000 条（1979 有效）现在是一条样本一个判定，等于把"主体对了但关系错了"和"主体错了"算成同一个错。**改成节点/边/整图三层后，0/0% 会自然变成一组可归因的数。**

### 4. IntrAA-SD：99.03% 与 88.55% 之间，隔着 10.5 个点的"分布外"

**（IIT Kharagpur，2026-11-04，cs.CV）**
精读：`categories/t2i/papers/2611.06000_intraa_sd_finetune_attribution.md`

#### 它立了什么任务

现有"来源归因"绝大多数瞄的是**架构签名**（DALL·E vs Midjourney）。但 SDXL 有大量微调版本（Juggernaut XL、RealVis XL、DreamShaper、Animagine……），**同骨架、只差微调**。论文把这件事单独立成任务 IntrAA-SD。

两条难点：微调**不显著改变权重**；分类器会**学内容与风格**而不是微调痕迹。

> 在我们数据集上训练的模型，可能学会把"动漫风输出"关联到 Animagine XL，因为它的训练图大多是动漫。

这是**风格捷径**，在 OOD 输入上暴露：给 Animagine XL 一个写实 prompt，风格线索消失，分类器崩。

#### 数据与结果

140K 图 / 10 个 SDXL 微调 / 15 个 ID 类 / 20 个 OOD 类（200 条 prompt）/ 25 步 DPM++ SDE Karras / CFG 7.0 / **95% JPEG** / ID 40 种子、OOD 10 种子 / ID 按 80-20 分层且 prompt 不重叠。

| 方法 | ID | OOD |
|---|---|---|
| 现有架构级归因（在 ISDB 上重训的最佳） | 92.21% | **74.84%** |
| **IntrAA-SD 基线（风格门控 MoE）** | **99.03%** | **88.55%** |

三个数必须一起读：

1. 99.03% 不能单独引用——同一模型 OOD 掉 **10.5 点**。
2. 真正有意义的差距是 OOD 上的 **13.7 点**（88.55 vs 74.84），不是 ID 上的 6.8 点。
3. **"错误的方法"在 ID 上也能到 92.21%**——说明 ID 分数下限很高，任何只报 ID 的系统都不能自证有效。

#### 方法设计的三条

冻结 CLIP **只做门控不做特征**（否则风格污染判定）；DINOv2 要 **LoRA 适配 + 高分辨率**（痕迹在细节里）；用 **MoE 而不是单头**（不同风格族痕迹分布不同）。

#### 对我们意味着什么

风格捷径是图审最可能的隐藏捷径：模型可能学"这类图的画质/构图/色调 = 高风险"，而不是"图里有违规内容"。**可测判据：同一违规内容换画风，看判定是否翻转。**

### 5. Risk Control：风险证书担保的是"率"，不是"量"

**（湖南农业大学 + 中南大学湘雅医院，2026-11-04，cs.AI）**
精读：`categories/t2t/papers/2611.05851_risk_control_rates_not_magnitudes.md`

#### 它问了什么

> 选择性预测的有限样本保证界定了粗错的**率**，不是它们的**量**。

在 999 张 HC18 图像、两套预注册四分割（每套重训三次）上，用精确 Clopper–Pearson 标定完整度阈值：

- 得到的证书**与人工地板值不可区分**；
- 管线仍输出 **271.3 mm** 误差（真值 324.6，报 53.3）；
- 被接受的候选完整度 **0.94**——**分数看不见这个失败**；
- 约 150 个答案里 1 个离群点，**α = 0.10 的风险界完好无损**；
- 第二套独立分割在另一张图上复现（233.3 mm）。

#### 最关键的一张表（Table 2，冻结测试）

| 分割 / 地板 | 覆盖 | MAE (mm) | 粗错率 | **最坏误差 (mm)** |
|---|---|---|---|---|
| split 1, L=50 | 0.722 | 3.51 | 2.39% | **271.3** |
| split 1, L=55 | 0.718 | 1.93 | 1.82% | **11.4** |
| split 2, L=50 | 0.750 | 2.53 | 1.41% | **233.3** |
| split 2, L=55 | 0.748 | 1.81 | 1.10% | **11.1** |

**把解剖学下限从 50 抬到 55 mm：覆盖只掉 0.4 个点，最坏误差降两个数量级。**

对照：用完整度阈值压制同一批错误要推到 **τ = 0.94**（分数范围极端），代价 **19.0 / 12.1 个覆盖点**。

**两者代价比 ≈ 47 倍。**

#### 三条可执行结论

1. **风险控制是集体性质**：认证过的 operating point 仍然可以灾难性地错一次。
2. **有效的参数是准入域（admissibility region），不是分数阈值**。作者原话：有效的保障"应来自解剖学，而不是调参"。
3. **校准与人工设定等效**：MAE 3.51→3.53，两个种子里 operating point 完全相同。

第 3 条对我们尤其扎心：**它解释了为什么"上校准"在我们这里没有带来改善——当分数看不见失效时，校准只是把同一个点重新认证一遍。**

#### 一个"安慰剂式达标"

交付版 **1.76 mm MAE 落在人类观察者差异（2–3%，约 2–5 mm）之内**。只报 MAE，系统看起来已经达到专家水平。但它同时掩盖了灾难性粗错。

**这是"平均值掩盖长尾"的教科书案例，而且发生在医疗场景。**

### 6. Failure-Boundary Profiles：一个标量同时给"该停"和"敢闯"打分

**（Social Chaos Lab + valeo.ai，2026-11-04，cs.RO）**
精读：`categories/t2t/papers/2611.06453_failure_boundary_profiles.md`

#### 它指出的结构错误

CARLA 类基准用 **Driving Score = 路线完成度 × 违章罚分** 排名。这个标量把两个不同问题压成一个：**是否尝试这个动作**，以及**能否无接触完成**。

后果（Table 1，Charger gauntlet，12 个封堵宽度）：

| 智能体 | 全部 DS | **封堵宽度 DS** | 停下次数 | 接触次数 |
|---|---|---|---|---|
| PlanT 2.0 (ckpt1) | 72.5 | 44.0 | 3 | 6 |
| HiP-AD | 71.5 | 39.2 | 11 | 1 |
| **SimLingo** | 67.8 | **52.2** | **0** | **12** |
| TF++ | 65.6 | 40.6 | 12 | 0 |
| TFv6 | 64.3 | 39.1 | 12 | 0 |
| BridgeDrive | 62.7 | 36.1 | 0 | 12 |
| **Expert（规则专家）** | **59.2** | 37.8 | **12** | **0** |

**从不刹车的 SimLingo 在封堵宽度上得分最高（52.2）；每次都正确刹车的专家总分最低（59.2）。**

#### 方法：变体带证书 + 两条曲线

每个场景族固定一条**被测量的轴**，每个变体由测量判为"应通过/应停下"——**不是用专家表现推断**。论文给了反例：machine-intrusion 族上专家每次都撞，但每个变体其实都可通行；用专家做检查会把这族标成"全部封堵"。

每个智能体两条曲线：

    commitment(x) = P(尝试通过 | x)
    competence(x) = P(无接触通过 | x)

边界 = 曲线与 1/2 的交点（四种情况分别处理，都带区间）。**commitment 与 competence 之间的 gap，就是"还在尝试但已经做不成"的那段轴**——这就是失败画像。

汇总指标是**两类平衡准确率**：

> 恒停的智能体得 0.5；恒闯的智能体最多 0.5。

**两个退化策略都被钉在 0.5 及以下**——这正是修"只压漏过 ⇒ 最优解是全拦"的正确答案。

#### 结果：相似总分掩盖不同失败

| 智能体 | Avg. DS | Avg. DA [95% CI] |
|---|---|---|
| Expert | 79.8 | **0.74 [0.67, 0.81]** |
| TFv6 | 75.5 | **0.60 [0.53, 0.68]** |
| PlanT ckpt1 | 72.6 | 0.56 |
| PlanT ckpt3 | 71.4 | 0.50 [0.50, 0.50] |
| TF++ | **59.5（最低）** | 0.49 |
| PlanT ckpt2 | 70.4 | 0.47 |
| HiP-AD | 70.4 | 0.44 |
| **SimLingo** | 63.0 | **0.28** |
| **BridgeDrive** | **71.8（第四高）** | **0.26（最低）** |

**BridgeDrive 驾驶分第四高，决策准确率全场最低。TF++ 驾驶分最低，决策准确率反而中游。**

#### 三条必须带走

1. **"会停"不等于"会等"**：在封堵走廊上可靠停下的智能体，人流窗口 29 次里只有 6 次等待，其余学习型智能体 **0 次**。**同一个"安全行为"在不同族上不共现。**
2. **CARLA 不可重复**：同一条字节级相同的命令跑两次，驾驶分 **53.7 vs 32.2**。正确做法不是"修到可复现"，而是**把方差放进区间**。
3. **离线检查过不了物理**：identity ladder 的 23 个候选物体里，**7 个通过全部离线检查但在运行时物理下倾斜/滚动/下沉/穿地**。**78% 的"离线通过"是假通过。**

## 三、趋势信号

### 信号一：评测正在从"一个总分"退到"两条曲线 + 一个可行域"

今天最一致的一组动作：**把标量拆成"行为"与"能力"两条轴，再用一个"退化策略被钉住"的汇总指标收口。**

| 论文 | 标量 | 拆成 |
|---|---|---|
| Failure-Boundary | Driving Score | commitment × competence + 平衡准确率（恒停/恒闯 = 0.5） |
| Risk Control | 粗错率证书 | 粗错率 × 最坏误差，约束从阈值换到准入域 |
| TailSteer | 单轮编辑分 | 框外漂移 × 框内完成度（COA） |
| LongBanana | judge 相关系数 | 输出级 × 条目级（差 5 倍） |

**共同点：每一个拆分都要求"新增一个分母"，而新增分母的成本远低于换模型。**

### 信号二：'退化策略基线'应该成为所有指标的强制项

今天出现了三个互相独立的退化策略胜出案例：

| 退化策略 | 在哪个指标上胜出 |
|---|---|
| 永远输出常数 16 | relative-error（Number Words） |
| 从不停下 | 封堵段的 Driving Score（52.2 最高） |
| 不改（少编辑） | 内容一致性 CC（87.46→92.68） |

**这三件事的共同机制：指标的分母里混进了"没做事"这一类，而"没做事"在多数指标上不吃罚分。**

**落地动作**：任何新指标上线前，先算"全 0 策略"和"全 1 策略"的得分。**如果任一退化策略得分不低于真实模型，指标作废。**

### 信号三：'改定义'正在被证明比'调阈值'便宜一个数量级

Risk Control 给了本轮唯一一个**成本比**：收准入域 0.4 个覆盖点 vs 压阈值 19.0 个覆盖点（≈47 倍）。

这与前几轮的结论方向一致但更硬——之前我们只知道"调阈值没用"，现在知道**改定义有多便宜**。

需要注意的边界：论文的准入域是**物理上可能的范围**（解剖学），是客观的；我们的类目适用域是**标注规范约定的条件**，是约定的。约定也能用，但必须**先冻结再评测**，否则就是拿测试集调定义。

### 信号四：多轮/多级链路的漂移，至少有两个独立来源

TailSteer 自己承认：模型侧 rollout 是漂移源之一，**轮间反复 VAE 重建**是另一个；只修模型侧，色偏仍在。

Failure-Boundary 侧的同构版本：**"会停"与"会等"不共现**——一个族上的达标不迁移到另一个族。

⇒ **链路越长，单点修复的收益越会被其他环节吃掉。** 这对我们"改写 → 编辑 → 后处理"的多级 I2I 链路是直接警告。

### B. 风险锚点处理启发（双锚点：PORN/VULG 边界 + 政治 L2_30 层级）

**运营约束基线：误杀率 5.2% / 漏过率 3.42%。**

#### B1. 先给两个锚点各算一个"最坏个案"

Risk Control 的核心教训是：**率证书不承诺个体**。我们现在只有率，没有个案。

**具体做法（2 小时，零训练）**：

1. 从当前被判 PORN 但人工确认无害的样本里，**取"模型置信度最高"的 20 条**；
2. 从被判政治 L2_30 但人工确认无害的样本里，同样取 top-20；
3. 人工看这 40 条，判"错到什么程度"（可接受 / 明显错 / 离谱）。

**判据表**：

| 观察 | 结论 | 下一步 |
|---|---|---|
| top-20 里"离谱"占比 ≥20% | **率指标已不可用于决策** | 必须加最坏个案列，且优先修这一族 |
| 全是"可接受"级 | 5.2% 是分散的小错 | 继续调阈值有意义 |
| 集中在 2–3 条上反复出现 | 是**特定模式**误杀，不是分布问题 | 走规则修复，不需重训 |

**这一条能一次回答"5.2% 到底要不要继续压"**——如果最坏个案是可接受级，压率的边际收益很低；如果有离谱个案，压平均率根本没用。

#### B2. PORN/VULG 边界：现在是"改定义 vs 调阈值"的价码问题

Risk Control 给的价码比是 **47 倍**（0.4 覆盖点 vs 19.0 覆盖点）。把它翻成我们的语言：

| 动作 | 代价 | 何时有效 |
|---|---|---|
| **改类目定义**（写清"这一类在什么条件下才成立"） | **个位数覆盖点** | 失效族能被一句必要条件圈出去 |
| 调阈值 | 两位数覆盖点，且可能推不到 | 失效是"分数分布偏"而非"定义缺失" |
| 加同类数据 | 1–2 周训练 | 失效是"没见过这种形态" |
| 改判别维度 | 2–4 周 | 失效是"两个类在表示上重叠" |

**顺序建议**：先做 B1（找最坏个案）→ 若最坏个案集中在"某类语境"，**先试改定义**（成本最低）→ 不行再调阈值。

这与前几轮的结论是连续的（11-05 的"先测方向是否重合"、10-30 的"识别型/判定型二分"），**但这一轮第一次给出了"改定义有多便宜"的量级**。

#### B3. 政治 L2_30：两曲线而不是一个一致率

Failure-Boundary 的教训：**"会停"不等于"会等"**。翻成我们的语言：**"在 A 类拦截准确"不等于"在 B 类拦截准确"**，而且**同一个类目下"拦得住"不等于"拦得对"**。

所以 L2_30 内部应该画两条曲线（横轴 = 阈值）：

    commitment(τ) = 拦截率
    competence(τ) = 拦截且理由与标签一致的比例

**两条线的 gap 就是"在拦但拦不对"的区间。** 现在只有一条线（一致率），所以看不见这个区间。

判据：

| 观察 | 结论 |
|---|---|
| gap 在低阈值区最宽，高阈值区收窄 | 低阈值在乱拦，收阈值能救 |
| gap 全程都宽（>15 点） | **不是阈值问题，是判别维度不足**，走 B2 的"改判别维度" |
| gap 很窄但整体 competence 低 | 排序问题，走标签审计 |

#### B4. 误杀 5.2% / 漏过 3.42% 的联合约束，该换一个形式

11-05 给的方案是"两级级联"。今天补一条更基础的检查：

**把总分公式写出来，代入"全拦"和"全放"两个退化策略。**

- 如果"全放"得分更高 ⇒ **总分在给少拦发奖金**（Failure-Boundary 的 SimLingo 现象）。此时任何调阈值都是在优化一个错误的目标。
- 如果"全拦"得分更高 ⇒ 总分在给多拦发奖金。此时 5.2% 会被系统性推高。
- 如果两者都低于真实模型 ⇒ 总分至少在方向上是健康的，可以继续用。

**这个检查只要 10 分钟，却能证伪整个看板。** 上一轮我们没做。

### C. 三维评测设计启发（含阈值 operating point 与多版本回归口径）

#### C1. 三维的第三个维度要改：从"指令遵循"改成"编辑是否真的发生"

TailSteer 的 Add & Preserve 给了一个更干净的第三维定义：

| 维度 | 现在在测什么 | 应该测什么 | 依据 |
|---|---|---|---|
| 语义保真 | 整图相似度 | **框外/非目标区域**的一致性（PSNR/SSIM/LPIPS） | TailSteer：整图相似度会被"少编辑"刷高 |
| 安全 | 分类器分 | 分类器分 + 校准后分，两者都报 | Risk Control：校准等效于人工设定 |
| **编辑完成度** | **指令遵循（单向相似度）** | **COA 式：编辑历史里每条要求是否达成** | TailSteer：SR@5 −6.00 说明"保真"能被"不编辑"伪造 |

**关键改动**：把"保真"和"完成度"**分开测**，因为它们的失效方向相反——保真高了可能是没改，完成度高了可能是乱改。

#### C2. 聚合方式：加一条"退化策略不许通过"

延续 10-29 的 E1（几何平均）。今天补一条更硬的：

**任何聚合方式，都要先过"两个退化策略"这一关**：

    score(全拦) < score(真实模型) 且 score(全放) < score(真实模型)

Failure-Boundary 的做法值得抄：**用两类平衡准确率**，天然把恒停/恒闯钉在 0.5。

#### C3. 阈值 operating point 的选择口径：从"一个点"改成"两条曲线的交点 + 一个可行域"

11-05 给的是"PR 曲线 + 约束域"，今天要补的是**两条曲线**：

1. 扫阈值，画 commitment(τ) 与 competence(τ)；
2. 标出误杀 = 5.2%、漏过 = 3.42% 两条约束线；
3. **看三条线的相对位置**：

| 情况 | 特征 | 处置 |
|---|---|---|
| competence 在约束域内穿过 0.5 | 两线交点落在可行域 | 直接取交点 |
| competence 全程低于 commitment 且 gap >15 点 | "在拦但拦不对" | 判别维度不足，走 B2 改维度 |
| commitment 在约束域内不下降（贴天花板） | 拦不住的族 | 该族单独处置，不要合并进总分 |

**第三种情况是 PGuard 的 24/29 压地板现象的两曲线解释**：阈值推到底，commitment 还是降不下来——因为那一族的 competence 根本不随阈值变。

#### C4. 多版本回归口径：加"两列"，不是加"一行"

今天的三篇各贡献一列：

| 新增列 | 为什么 | 依据 |
|---|---|---|
| **最坏个案** | 平均率对个体免疫 | Risk Control：271.3 mm 在 α=0.10 内 |
| **分布外列（OOD）** | 平均准确率掩盖分布外崩塌 | IntrAA-SD：99.03 vs 88.55 |
| **条目级列** | 输出级相关低估改进 5 倍 | LongBanana：+2.9 vs +15.82 |

**看板改造（半天）**：每个版本一行，但现在每行要有 5 组数：ID / OOD / 条目级 / 最坏个案 / 退化策略基线。

**跨版本比较的判据**：

| 观察 | 结论 |
|---|---|
| ID 涨、OOD 跌 | 过拟合评测集，不许发布 |
| 条目级涨、输出级不涨 | 真实改进，但整体排序未变（可接受） |
| 输出级涨、条目级不涨 | **可疑**：可能是聚合方式变了而非判断变了 |
| 最坏个案变差但平均变好 | **不可发布**，最坏个案优先 |

### D. 下一步实验建议（六条主线）

#### D1. tag-weighted loss 线

**D1-a（半天，零训练，最该先做）：退化策略体检。**

对现有分类器，算三个分：真实模型 / 全拦 / 全放。用一级一致率 + 误杀 + 漏过三个指标各算一遍。

**判据**：全放得分 ≥ 真实模型 ⇒ 当前指标在奖励少拦，tag-weighted 的加权方向可能整体错了（把权重加在了"更容易分开的类"上，而不是"更容易混的类"上）。

**D1-b（半天）：加权对象的重新定义。** 延续 11-05 的 D1-a（测 PORN/VULG 梯度方向余弦）。今天补一个更便宜的替代：**用"最坏个案占比"代替"类目加权"**——如果 top-20 置信样本里有 6 条是同一模式，直接写规则，不用改 loss。

#### D2. RL 改写线

**D2-a（半天，零训练，前置）：用 TailSteer 的"单点 vs 全程"做改写粒度的直接对照。**

取 100 条需改写的 prompt，做三臂：
- A：整条重写（当前做法）；
- B：**只在风险锚点处替换**，其余 token 一字不动；
- C：不改写，只做 resample（同 prompt 换种子重生成）。

**判据**：

| 观察 | 结论 |
|---|---|
| B 的保真显著高于 A，风险降幅不低于 A | **改写应该收窄到锚点级**，这是最省的做法 |
| A 保真崩、风险也没多降 | 整条重写是负收益，应当停掉 |
| C 与 A 相当 | 改写没有制造新信息，只是在赌运气（延续 11-03 RetryRoute 结论） |

**依据**：TailSteer 的 49+1 步有效、50 步全用反而过平滑。**单点干预优于全面接管，这是有实测价码的。**

**D2-b（1 天）：把"保真"拆成"框外漂移"与"框内完成度"。** 用 A5 的保真 mask（"用户没要求改的部分"）自动生成判据。判据：如果当前改写的"保真"分数高但"完成度"低 ⇒ 我们的改写正在做 FreqEdit 那件事（靠少编辑换保真）。

#### D3. 标签审计与阈值校准线

**D3-a（2 小时，零训练）：算两个锚点的最坏个案。** 见 B1。

**D3-b（半天）：算"改定义"的价码。** 挑一个误杀集中的叶子类目，做两个版本：
- 版本 1：原定义 + 调阈值；
- 版本 2：**加一条必要条件**（例："PORN 必须可见性器官或性行为"），阈值不动。

比较误杀、漏过、覆盖（该类目可判定样本占比）三个数。

**判据**：如果版本 2 的误杀降幅 ≥ 版本 1 的 3 倍，且覆盖只掉 <2 点 ⇒ **改定义是正解**，按此推广到其他边界类目。这直接复现 Risk Control 的 47 倍价码比。

**D3-c（半天）：L2_30 两曲线。** 见 B3。

#### D4. 输出侧图审线

**D4-a（1 天）：条目级 AB 指标。** 在现有 AB 看板上加"条目级三元一致率"与"两端相反错误率"。做法：把现有判定拆成 3–5 条原子判据（内容存在性 / 内容性质 / 语境豁免 / 呈现方式），逐条判。

**判据**：如果条目级差值与输出级差值的比值 >3，说明当前 AB 看板严重低估版本差异，历史结论要重算。

**D4-b（半天）：风格捷径自检。** 同一违规内容换成写实/动漫/插画/低分辨率四档，看判定翻转率。**翻转率 >20% ⇒ 图审在读画风**（IntrAA-SD 的捷径的图审版本）。

**D4-c（半天）：最坏个案列。** 对图审，取"判违规且置信最高"的 20 条人工复核。判据同 B1。

#### D5. I2I 改写链路（针对当前 0/0% 的现状）

**必须先承认一件事**：连续十二周零供给，意味着**这个问题在公开文献里没有答案**。所以这里的建议不是"抄一篇论文"，而是"用今天六篇的方法论把 0/0% 拆开"。

**D5-a（半天，零训练，最优先）：把 0/0% 拆成 commitment 与 competence。**

当前 0/0% 只说明"没有一条被判定为需要改写"（commitment = 0），**完全没有 competence 侧的数**。

具体做法：取 200 条人工判定"应当改写"的 I2I 指令，跑当前链路，记录四件事：

| 记录项 | 含义 |
|---|---|
| 是否进入改写分支 | commitment |
| 改写后编辑是否仍能完成 | competence |
| 改写后风险是否真的降低 | 有效性 |
| 改写改动了哪些 token | 干预粒度 |

**判据表**：

| 观察 | 结论 | 处置 |
|---|---|---|
| 进入改写率 ≈0% 且人工认为应改 >30% | **分流器坏了**，不是改写器坏了 | 修分流阈值/规则，不动改写模型 |
| 进入改写 >0% 但编辑完成率崩 | 改写抹掉了意图 | 收窄到锚点级（D2-a） |
| 进入改写 >0%、编辑能完成、风险没降 | 改写在改措辞不是改锚点 | 换锚点表（10-29 的词级锚点实验） |

**这四行表能一次把 0/0% 变成 4 个数**，而且全部零训练。过去五轮的 I2I 建议都停在"再拆一层"，缺的正是这个"分流器 vs 改写器"的二分。

**D5-b（1 天）：保真 mask 零标注化。** 用 TailSteer 的思路：从编辑指令里自动解析"未请求改变的区域"，作为保真判据。判据：自动 mask 与人工标注 mask 的 IoU >0.7 ⇒ 可替代人工，评测集可从 1979 条扩到全量。

**D5-c（2 天）：多轮视角。** 现在评测只做单轮。按 TailSteer 的方法，对同一张图连续做 5 轮编辑，测累积漂移（框外）与完成度（框内）。**判据**：如果单轮命中率 >0 而 5 轮后完成度 <50%，说明单轮评测高估了链路能力。

#### D6. 多模态视频扩展

本轮 `d4_video_generation_safety` 返回 **3 篇**（均为能力型，非安全），`d5_video_temporal_risk` 若干但离题。**没有强相关工作，按任务要求不给扩展建议。**

沿用 11-04 的判断：**先把三条图像侧规则（框外漂移 / 框内完成度 / 两曲线）搬到图像，等 i2v/t2v 落表 >1000 条再评估。**

### E. 权重侧 vs 输入侧：互补关系与各自失效边界（第六轮加固）

今天 IntrAA-SD 给了一条新证据，把边界说得比前几轮更清楚。

**新证据**：两个 SDXL 微调版本（Juggernaut / RealVis）**连专用归因系统都只能做到 88.55%（OOD）**。论文明确写了原因——**微调不显著改变权重**。

把它推到擦除：如果两个微调之间的权重差异小到需要专门设计 MoE 才能分开，那么"擦掉一个概念"的权重改动，**在下游再微调时同样容易被覆盖**。这与 AIG-NCII 的"open-weight + LoRA 可把概念装回"是同一事实的两面。

#### 六轮累积的分工判据（更新版）

| 场景 | 该谁管 | 依据 |
|---|---|---|
| 新出现的风险锚点词（周级） | **输入侧改写** | 权重侧要重训，赶不上 |
| 极少数不可逆概念（上线前治理） | **权重侧擦除** | 输入侧挡不住已经生成出去的图 |
| 已经生成出去的图 | **输出侧图审** | 两边都管不到 |
| **分发后的下游微调** | **谁都管不到** | IntrAA-SD：微调差异小到需专门设计；AIG-NCII：LoRA 可回装 |
| **边界类目（PORN/VULG）** | **两边都无效，必须改定义** | Risk Control：改定义比调阈值便宜 47 倍 |

**第六轮的新增一行是"分发后的下游微调"。** 前五轮的结论是"互补不可替代"，今天要补一句更冷的：**两边都只覆盖"上线前 + 上线时"，对"上线后被人拿去微调"都没有管辖权。** 这一层只能靠**归因 + 溯源**（IntrAA-SD 这类工作）事后追责，而不是事前阻断。

**这也解释了为什么图审与溯源不能合并成一个系统**：图审判"这张图违不违规"，溯源判"这张图是谁生成的"。前者是内容判定，后者是责任判定，失效模式完全不同（图审怕画风捷径，溯源怕分布外）。

## 附：今日一句话结论

**我们所有的指标都在回答"多久错一次"，而业务真正怕的是"错成什么样"。**

Risk Control 用 271.3 mm 证明：一个 α=0.10 的风险证书可以和一次灾难性错误共存，因为**率是集体性质，对个体免疫**。Failure-Boundary 用 52.2 > 39.1 证明：一个把"该停"和"敢闯"混成一个标量的评分，会**给敢闯发奖金**。Number Words 用一个常数 16 证明：exact-match 与 relative-error 分不出"跟得松"和"根本不跟"。

**所以下一版看板不加指标，加三列：最坏个案、分布外、条目级。** 三列都是零训练、半天内出数。
