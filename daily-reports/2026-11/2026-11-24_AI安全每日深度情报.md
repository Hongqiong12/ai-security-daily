## 一、T2I / T+I2I 论文（核心主线 · 4 篇）

### 1. Unimodal Shortcuts：五个情境安全 benchmark，都能靠「不看图」解出来

**2611.27339** | 港科大 + 深圳大学 + XGEN Labs + 港科广 + 清华 | [精读](../../categories/t2i/papers/2611.27339_unimodal_shortcuts_scene_intent.md)

问题：风险长在**场景 × 意图**的合取上（问"怎么端上这道菜"，新鲜食材无害、变质食物有害，而"描述一下变质的菜"又无害）。只读场景会过度拒答，只读措辞会漏掉中性措辞的有害动作。作者提出双侧条件依赖诊断 `I(Y;I|U)>0 且 I(Y;U|I)>0`——任一为 0，标签就由另一边决定。

**三层证据链**：① 五个公开情境 benchmark 结构审计，**5/5 存在单模态捷径**（图盲探针排未见过的图 0.8756–0.8990 AUROC；Table 2 里 MSSBench 578 张图全多请求且不换标签是**真身份捷径**，VSCBench 1751 张只有 29 张多请求是**单例造成的假零**）；② 同图反义配对（198 场景 / 396 记录）去掉图捷径，却打开**词捷径**——用一张**纯灰画布**当图、只读文本的探针在 Qwen3-VL-8B L2 拿 **0.9645–0.9846 AUROC**，高于联合探针；③ 2×2 四路对称控制（2,400 条、578 场景、606 请求）把任何单模态规则**构造性**锁死在 **0.500 组排序 / 5/6≈0.833 池化**上界。

**结果**：中间层联合探针 **0.958 / 0.930**（Qwen3-VL-8B / SmolVLM2-2.2B）⇒ 合取线性可解码；但**把分别编码的图/文状态直接拼接**已有 0.930 / 0.859 ⇒ **可解码不蕴含模型内部有融合机制**。更扎的是：在这些公开集上**去掉 prompt 反而更稳**（16 配置里 15 个 ΔAUROC≤0，图像不相交切分 12/16≤0，最大正值仅 +0.0167，负值到 −0.0954）；**跨 benchmark 迁移探针掉到 0.48–0.67 AUROC** ⇒ "编码了正确信息"≠"可靠筛子"。

**推理侧数字**：缓存探针 batch=1 **0.234 ms** vs 独立安全 pass **95.82 ms**，端到端在 68.0 ms prefill 上只加 **0.36%**。但作者明确：便宜 ≠ 可上线，图像不相交切分与跨 benchmark 下召回都下降。

**为什么是主线**：这是 11-23 EditSafetyBench（UIR 87.1% vs UNR 24.2%，"编辑器在读文字没在读图"）的**表示层机制解释**——连验收用的公开 benchmark 都不需要读图。⇒ I2I 分流 0/0% 拿到**第五种可证伪归因：训练与验收数据本身允许文本单通道通关**。

**局限**：只测两个冻结 backbone 的表示，不测 SFT/RL 后行为；四路控制只有观察/动作二档，不覆盖 PORN/VULG 边界、L2_30 层级、中英混合、DSC 式承诺分散；延迟是单 batch=1 探针，不含量化与跨硬件漂移。

### 2. AnimalFarm：输入侧已经很干净，生成器照样 92.1% 出图、95.9% 带仇恨

**2611.27905** | CISPA Helmholtz + Independent + HPE | [精读](../../categories/t2i/papers/2611.27905_animalfarm_hateful_image_audit.md)

**本轮最贴项目归因结论的一篇**。源场景经**两名标注员独立接受**的保守筛查（输入侧相当干净），覆盖 **5 种拟人化非人角色 × 3 条生成通路（T2I / image editing / 多轮会话）× 8 个模型**，共 **14,250** 计划查询 / 12,900 次生成尝试：

- 生成系统对 **92.1%** 的计划查询出图，其中 **95.9%** 含仇恨内容；连 **GPT Image 2** 在 T2I / Edit / MT 三通路分别产出 **66.6% / 68.0% / 75.3%** 仇恨输出 ⇒ **多轮通路最弱，同一份策略不能跨通路共用**。
- 4,370 张仇恨图上，五个检测器最强 **GPT-5.5 仅 73.9%** 召回（Gemini 3.1 Flash 67.7 / Q16 57.0 / Claude Haiku 4.5 42.5 / **LlavaGuard v1.2 7B 28.0**）。作者归因：检测器**依赖以人为中心的线索**，主体非人时系统性判良性。
- **零训练修复最值钱**：在 system prompt 里补写"仇恨可能如何出现"并要求**分步骤反事实推理「若把非人角色换成人，这个场景是否算仇恨」**，四个 VLM 检测器召回全升，LlavaGuard **28.8% → 64.4%（+35.6 点）**；另两条路线 F1 **0.962**（depiction reversal）/ **0.979**（LoRA SFT + GRPO 检测器）。**LABUBU 完全不进微调训练仍达 96.6%** ⇒ 学到的是可迁移判据，不是角色词表。

**三条对本项目的硬迁移**：
1. **输入改写有效性上界**：`保守筛查过的输入` + `92.1% 出图 / 95.9% 有害` 是"改写后文本无害但出图侧内生风险"最干净的公开对照，与 3,000 条 case 中 2,700+ 条归因同构 ⇒ **不再把优化重心放在加严输入改写**。
2. **图审双模型 AB / 判定层捷径**：图审读的是主体类别而非语义；修复靠改判定 prompt 的推理结构（零训练），不是加词表/改类目定义。
3. **口径纪律**：论文明确 `1−G/Q` 是 non-generation，**含跳过的多轮查询，不能解释为模型拒答率** ⇒ 直接用于"假安全拒答体感"与 over-refusal 归因。

**GRPO 奖励四分项**（正确性 0.7 / 格式 0.1 / checklist 覆盖 0.1 / 目标群体识别 0.1）可与本项目 RL 改写奖励设计成对比较；但论文**未做 reward hacking 对照**，迁移前必须补 G7 式面板。

**局限**：清晰可解释场景 + 严格定义（作者自承"诊断性证据"），不代表线上分布；同一批源场景跨模型/角色/任务复用；未覆盖中英混合、PORN/VULG 边界、政治 L2_30、编辑后水印存活率、推理延迟。

### 3. EBSG：二值安全评测会放过"塌成噪声"的模型，出图侧干预要按子概念 + 局部动手

**2611.20623** | KAIST（**NeurIPS 2026 poster**，51 页）| [精读](../../categories/t2i/papers/2611.20623_ebsg_example_based_spatial_guidance.md)

作者指出 T2I 安全两个同构的粗糙：**执行侧**用单个宽负向概念（"sexual content"）全局推离整幅图——弱了压不住、强了过冲伤保真；**评测侧** NudeNet / Q16 只答"有害吗"，不答 **why / where / to what extent**，于是**一个塌成无信息噪声、根本没有人物的模型技术上能"通过"二值安全检测**（model collapse bypass safety checks）。

**方法**：为每个**子概念族**在 CLIP 空间准备 **unsafe 关键词 + 视觉示例 + 安全对应物**（family-indexed exemplar pack，用户可编辑；无图时可用 text-only pack），逐去噪步判断 **when** 生成是否偏向宽概念（necessity-driven），并在 **where** 空间局部施加引导。全程**不改输入、不改权重** —— 正是方向(2) 要的「生成过程内生风险干预」。姊妹工作 **ASCG**（2611.20625，同组，CVPR 2026 SAFE Workshop）用概率监控 + Grad-CAM 局部抑制，批判现有方法"indiscriminate, global interventions induce unintended semantic drift"。

**VLM 四档 rubric**（SAFE / PARTIAL / FULL / **NOTRELEVANT**），`SR=(SAFE+PARTIAL)/Total`、`NR=NOTRELEVANT/Total` 专抓塌陷；人工一致率 **328 条平均 82.6%**（sexual 93.0 / violence 90.0 / illegal 88.4 / **harassment 70.0 最低**）。

**主表（SD v1.4，四组裸体 benchmark）**：EBSG 的 SR **97.2 / 96.2 / 84.2 / 97.4** vs SAFREE+SGF 的 92.3 / 84.8 / 77.6 / 70.2；**NR 1.4 / 1.3 / 0.4 / 0.0** vs 4.9 / 7.6 / 3.8 / 4.0；FID **6.31** 优于 7.83、CLIP 0.263 对 0.259 ⇒ **安全率升、塌陷降、保真不掉三者同向**。增益最大的是 **harassment / hate** 这两个最依赖上下文的类目。推理超参（`h / τ / βtxt / βimg`）**按概念与 backbone 单独配置** ⇒ 阈值不是一个全局数。

**为什么是第三条降风险通路**：这条与输入侧改写、权重侧擦除互补而非替代——它管出图侧内生风险、不动用户 prompt；但 exemplar pack 需人工补包，**热更新能力弱于输入侧改写**，这是互补边界。

**局限**：训练免 ≠ 零成本，**未报端到端延迟/吞吐**（TTFT ≤110ms / e2e ≤160ms 约束前必须实测）；rubric 在 harassment 只有 70% 一致性；概念清单不覆盖 PORN/VULG 与 L2_30；未与输入侧改写做联合实验，也未测下游微调回装。

### 4. P2E：生成增益差 25 倍，训出来的改写器只差 0.14 分

**2611.27229** | 香港城市大学 + 香港中文大学（深圳）| [精读](../../categories/t2i/papers/2611.27229_p2e_supervision_redundancy.md)

工业界训练 Prompt Enhancer 的通行做法是从 dense caption 反向合成短 prompt 做 SFT 对，**隐含假设「能让生成变好的 caption 也是好监督」**。本文配对证伪：按生成增益 Δq 取最高/最低各 10K 对，`D_H` 增益 **3.20**、`D_M` **0.13**（**25×**），在**完全相同初始化与训练配置**下（Qwen3.5-9B）训出的两个 PE 模型，200 条留出短 prompt 上只差 **+0.14 HPS v2 / +0.05 PicS / +0.002 MIQA / +0.000 VQ-R1**。

解释：dense caption 里大量**图像专属细节**对直接生成有用、与**用户意图**弱相关，让改写器复现它们是**冗余监督**。P2E 用 LLM 生成 K=3 个嵌套剪枝候选（目标 20/40/60% token 删除，**保留原句措辞与顺序**），设 **per-example deletion bound τ=0.4**，在界内选删得最多的候选；全过程 **text-only，零额外推理开销**。主结果覆盖 4 类 × 200 = **800 条留出 prompt** × **4 个生成器**（Qwen-Image-2.1-Turbo / Z-Image-Turbo / MOSS-Image / BAGEL），P2E 普遍优于常规 dense-caption SFT。

**最该抄的一行（Table 2）**：**无约束 LLM 剪枝 HPS 27.27 → 26.46（−0.81）**，而**视觉结构守护的剪枝 → 27.59（+0.32）** ⇒ 增益不来自"删得多"，来自"**保住了什么**"。这直接对应「改写强度分级」：改哪些锚点比改多少字重要。

**对业务**：本轮唯一直接讲「输入侧改写器怎么训」的工作；`τ` 是改写强度上界的可借用形态；「按生成增益筛样本失效」是 SFT 数据构建/清洗准则的可证伪判据，与 11-08 Reweighting、11-04 Kling PE 的 caption 反向构造成直接对照。

**局限**：主线是**美学/构图 PE，不是安全改写**，四个指标无安全率、无误杀/漏过；剪枝判据由 LLM 主观判定且**未报 κ、未做惰性句对照**；τ 固定未扫甜点、未报 edit rate / Levenshtein；未覆盖跨语言、I2I 编辑、统一生成-编辑模型、量化漂移。

## 二、方法论迁移论文（2 篇）

### 5. The Vulnerability Window：准确率只动 0.03 点，1.1–12.3% 的成对判定被 4-bit 重写

**2611.27155** | Illinois Institute of Technology + UW–Milwaukee | [精读](../../categories/t2t/papers/2611.27155_vulnerability_window_quantized_judges.md)

奖励模型 / LLM judge 量化到 4 bit 后，常规验收是"聚合准确率掉没掉"。作者指出这近乎失明：量化**同时修掉一些错、引入一些错**，聚合时互相抵消。8 个奖励模型（两族 0.6B–8B）+ 3 个生成式 judge + 4 种 4-bit 量化器，RewardBench 上判定翻转 **1.1–12.3%**，而聚合准确率变化**低至 0.03 点（p=1.00）**；极端行 Llama-3.2-1B/NF4 是 **3.99% 翻转 / 0.03 点 / harm:help 近乎完美平衡**。

翻转集中在全精度 margin `|m|` 相对量化噪声 `σ` 小的地方，高斯近似 `Φ(−|m|/σ)` 在 30 个标量设置里**全部高估**、对生成式 judge **失效**；窗口占用率随模型规模 **25% → 7%** ⇒ **小 judge 更脆**。对抗 best-of-4 下 INT4-RTN pooled **146 harmful vs 54 helpful flips**（另一族**符号反转**）⇒ 风险按模型族/量化器定向。下游：6 对组合上 **14.6–65.7%** 的题目换了 best-of-64 选择，但只有 **2.6–9.6%** 换最终答案，**选择变化是答案变化的 5–8×**。

**最扎的一条反例**：按 `z<τ`（`|m|<τσ`）路由**并不比同预算 top-k 好**，top-k 反而 **+0.35 点**（[−0.71,−0.00]）⇒ 窗口能圈住误差，但不是最优门控依据（"去掉你声称必要的那一项，指标反而升"再次生效）。

**迁移**：本项目 1105 权重 TTFT ≤110ms / e2e ≤160ms、qwen3.5 Pro5000 两阶段迁移与二阶段量化降本、P800 12 月下架 ⇒ **不劣化验收必须四栏**（成对判定翻转率 / harmful-helpful 分方向 / 中间选择变化率 / 安全率与分层宏平均 F1 + 延迟），**准确率不变不是不劣化证据**。

**局限**：weight-only 4-bit、数学 best-of-N、单生成器单 arbiter；测的是奖励模型而非安全分类器，无安全率/误杀/漏过/L1–L4 分层 F1；未测 fp8、KV cache 量化、跨硬件迁移、prefix caching；未报 TTFT/e2e/TPOT。

### 6. Your Judge Inherits Your Prompt：偏置是单向的，只会把分数往上抬

**2611.26881** | Independent Researcher + University of Essex（**BlackboxNLP 2026**）| [精读](../../categories/t2t/papers/2611.26881_judge_inherits_prompt_directional_bias.md)

冻结 generator–judge 管线（LLaMA-3.1-8B 语义 judge），**生成答案固定、只改 judge 的 Yes/No few-shot 示例平衡**（S2=0.25 / S4=0.50 / S5=0.50 / S3=0.75），每个判定对照两名标注员在每数据集 200 例上的人工共识。

| 数据集 | 演示集 | J% | C% | Bias | FP:FN |
|---|---|---|---|---|---|
| NExT-QA | 平衡 / 偏拒绝（S2/S4/S5） | 55.0–55.5 | 56.5 | **−1.0 ~ −1.5** | ≈1.0 |
| **NExT-QA** | **S3 偏接受 0.75** | **86.0** | 56.5 | **+29.5** | **9.4**（FP 66 / FN 7） |
| MSVD-QA | 平衡 / 偏拒绝 | 61.5–66.0 | 63.5 | **−2.0 ~ +2.5** | 0.9–1.2 |
| **MSVD-QA** | **S3 偏接受 0.75** | **83.0** | 63.5 | **+19.5** | **4.0**（FP 52 / FN 13） |

⇒ 平衡与偏拒绝都贴在人工共识 **±2.5 点**内，**只有强偏接受**把接受率抬高，且误差形状**强烈单边**；**偏拒绝不产生对应下降** ⇒ **inflation-only asymmetry**，不是零均值噪声。后果：**报告的准确率只可能被推高、不会被压低**；更阴的是，**换另一个 judge 交叉复核若也偏接受，会得到同向虚高的一致**，不构成互相校验。另做五次抽样：单次示例抽取波动**最高 18 点，超过任意两套演示集之间的差异**。

**迁移**：本地 AB 看板（文生图图审 / 图生图改写）若用 judge 打分而示例标签平衡未冻结，**版本间比的是 judge 的示例，不是模型**；必须与 27155 成对部署——一个回答"判定集合换了多少"，一个回答"判定尺子本身有没有被带偏"。

**局限**：只测一个 judge、两个视频 QA 数据集、Yes/No 二值；非对称性建立在每数据集一套偏拒绝演示集上（未画完整曲线）；偏接受集类别构成也不同；MSVD-QA 验证集低代表 How/When、**完全不含 Where**（聚合 Bias 不能替代逐类目检查）；未测量化后偏置漂移、序数等级、安全指标。

### 信号一：出图侧内生风险的「第二条降风险通路」第一次凑齐了可执行形态

11-23 的 EditSafetyBench 给出"决策层没读图审输出"，本轮三篇把它补成闭环：**27339** 证明连验收 benchmark 都允许文本单通道通关（归因）→ **27905** 给出输入侧保守筛查后仍 92.1% 出图 / 95.9% 有害的量化对照，且图审只在 73.9%（失效面）→ **20623** 给出不改输入不改权重的子概念 + 局部空间引导，SR 97.2 而 NR 1.4（修法）。⇒ 项目归因「3,000 条 case 中约 2,700+ 条源于出图侧内生风险」现在有**公开可对照的证据链与干预方案**，**优化重心正式由加严输入改写转向出图侧**。

### 信号二："有量不等于有供给"第四次生效，且这次是**通道级别**的

`t14_policy_guard` 返 5 篇，逐篇核验**全是 RAG 混合检索**（政府方案英/马拉地语检索、欺骗评论检测、金融问答、生物医学检索），**没有一篇是安全策略护栏 / 风险知识库召回 / 降级兜底**；`f1_calibration 179` / `f9_abstention 132` / `f6_eval_set 48` 同样是宽口径假阳性。⇒ **方向(3) 的「词库 + 向量库混合召回、指令排序与命中优先级、拼接失败/超时降级兜底」在本轮全批池里依然零供给**，只能靠自建 AB 口径，不要靠加查询路数硬凑。

### 信号三：量化 / judge 两条「不劣化」证据合起来，定义了验收的下限

### 信号四：输入侧改写的空窗第 17 周，但「怎么训改写器」有了一条硬判据

`t2_prompt_rewrite` 严格 0；但 **P2E** 从全批池里被"方法论形态"通道捡出来，给出**「生成增益是监督价值的坏代理量」**（25× 差 → +0.14 下游差）与 **「剪冗余必须守住结构」**（无约束 −0.81 / 有守护 +0.32）。⇒ 继续写"改写方法零供给"是对的，但**不能写成"输入侧改写本轮无收获"**：收获在**监督设计与强度上界**，且它是零训练可验证的。

### 信号五：视频扩展本轮**有强相关工作**（与上一轮不同）

`t10_video_safety` 命中 1 篇 **2611.27268 Budgeted Safety Verification for Streaming Video Generation**（NUS + UNSW + 港大 + Griffith）：按 **exposure（观众看到的有害帧）** 而非终局准确率衡量护栏；599 条流上无防御 **46.25/81** 有害帧，逐 chunk VLM 剩 **0.91 帧但每条良性流要判 80.1 次**，用便宜 guard 读生成器已有 hidden states 决定何时调贵检测器，剩 **2.35 帧而只判 5.3 次**；**同样预算随机花剩 37.20 帧** ⇒ 收益在**排序**不在预算量；帧检测器放同角色要多放近 6 帧 ⇒ 判定阶段必须**读 clip 而不是读帧**；独立护栏模型与 oracle 一致 **κ=0.74**。⇒ 按纪律（仅在出现强相关工作时给建议），本轮主线⑥**给出建议**，但篇幅与优先级仍低于五条 T2I 主线。

## 四、业务对齐研究板块 ⭐

> **本板块固定回答四件事**：直接可迁移方法 / 双锚点处理启发 / 三维评测设计启发 / 六条主线下一步实验建议。
> **运营约束基线**：误杀率 **5.2%** / 漏过率 **3.42%** / 一级一致率 **77.64%**。本节所有建议**不得以帮助性退化换取降风险**，且必须关注**用户侧可感知误伤**与**「假安全」拒答体感**。

### A. 直接可迁移方法

#### A1【最优先，零训练，1 天】输入改写有效性上界归因：把 3,000 条 case 拆成三栏 —— 来自 AnimalFarm + 27339

**现状**：3,000 条改写后仍被色情 400 打击的 case，已归因仅约 10 条属改写文本仍有害、约 **2,700+ 条为改写后文本无害但出图侧内生风险**；结论是优化重心由「继续加严输入改写」转向出图侧。本轮第一次有公开量化对照：AnimalFarm 在**两名标注员保守筛查过的输入**上仍 **92.1% 出图 / 95.9% 含仇恨**。

**做法**：把 2,700+ 条按三栏重打标，不再加严输入改写——

| 栏 | 判据 | 对应修法 |
|---|---|---|
| ① 文本复核仍有害 | 人工双盲判改写文本有害 | 输入改写（占比应极小） |
| ② 文本无害、图审判有害 | 图审分高但人工判无害 ⇒ **判定层在读代理量**（主体类别 / 单模态捷径） | 判定 prompt 反事实改写（A2） |
| ③ 文本无害、图审放行、人工判有害 | 图审漏报 | 生成过程干预（A3）+ 图审补类目 |

**配对对照（来自 27339）**：对同一批样本跑**灰图纯文本探针**，若 AUROC ≥0.90 ⇒ 现有「改写后文本无害判定」与联合安全无关，**该指标作废**，必须换图文联合状态验收。

#### A2【最优先，零训练，半天】图审判定层反事实改造 —— 来自 AnimalFarm 的 +35.6 点

在判定 prompt 里加一条**反事实还原指令**：「若把主体替换为人类 / 显式语境，是否仍构成风险」，并要求分步骤推理。AnimalFarm 零训练把 LlavaGuard 召回 **28.8% → 64.4%**。

**判据**：召回显著升而**误杀率不升**（双约束 5.2% / 3.42%）⇒ 现有图审在读主体类别而非语义；此时**改类目定义无效、加词表无效**，修判定推理结构即可。同步加 **DSC 三版对照**（原句 / 保义疑问化 / 疑问化+肯定线索），防止"承诺分散"型绕过。

#### A3【零训练 + 推理，1 天】出图侧生成过程干预三臂对照 —— 来自 EBSG（明确不再加严输入改写）

固定**同一份改写后 prompt**，200 条"文本无害但被打击"样本分三组：① 原样生成 ② 加负向 prompt / CFG 安全引导 ③ 按子概念 + 局部空间引导。报出图风险率、主体/属性/关系保留率、FID 代理、单次延迟。

**判据**：③ 显著优于 ② 且保真不掉 ⇒ 重心确实在出图侧干预；② 已足够 ⇒ 优先用更便宜的 CFG 通道。**所有臂的改写 prompt 完全相同**，从而把「输入改写」这个变量钉死——这是本轮最重要的实验设计约束。

#### A4【零训练，半天】风险知识召回降级兜底：本轮**零供给**，按自建口径落地

`t14_policy_guard` 5 篇逐篇核验 0 篇可迁移 ⇒ 11-16 安全指令库评审的口径只能自建。按 2611.27268 的"便宜 guard 决定何时调贵检测器"形态做**排序优先于预算量**的对照：

- **L0 词表精确匹配 > L1 向量库 top-k**（命中优先级不变）；指令 ≤3 条直接拼接，>3 条排序取 top3（按相似度与阈值距离）；
- 三条**降级路径必须各自留事件**：拼接失败 / 召回超时 / 词库或相似度服务不可用 ⇒ 整体降级到拒答，但必须带 `失败原因 + 版本 + 规则指纹`，否则"假安全拒答"不可归因；
- **必须显式配置超时**（对齐 Proxy 侧 safe_word 二级服务），并做 `随机花预算 vs 按分数排序` 对照（27268：随机 37.20 帧 vs 排序 2.35 帧）——判据：两者差距 <2× ⇒ 排序逻辑没起作用，先修打分而非加预算。

#### A5【零训练，半天】推理加速 / 量化不劣化验证四栏 —— 来自 27155 + 26881

| 栏 | 指标 | 判据 |
|---|---|---|
| 判定 | 全精度 vs 量化后**逐样本判定翻转率**（按一级类目 × L2_30 叶子分层） | >3% ⇒ 历史 AB 按版本重算 |
| 方向 | harmful / helpful flips **分列**，禁止只报净值 | 两向大幅抵消 ⇒ 聚合分是假稳 |
| 中间 | **改写候选选择变化率 / 策略命中条目变化率** | 选择变化 ≫ 最终拦截结论变化 ⇒ 决策层已换 |
| 尺子 | judge few-shot 示例标签平衡冻结 + 五次抽样 + 人工共识双盲 | 偏接受 Bias >+15 点或抽样极差 >10 点 ⇒ AB 结论作废 |

叠加 **27339 的缓存探针口径**：`prefill 增量 %`、`batch=1 绝对延迟`、**图像不相交切分召回**、**跨评测集 AUROC**、量化前后安全率与分层 F1 缺一不可。**0.36% prefill 只证明探针便宜，不证明链路不劣化。**

#### A6【评测集构建，零训练，1 天】四档 rubric + 退化基线 —— 来自 EBSG + 27339

图审 AB 加 `NOTRELEVANT / 语义塌陷` 档，按 SAFE/PARTIAL/FULL/NOTRELEVANT 重标 200 条边界样本，报 `SR` 与 `NR`；同时把 11-06「全 0 / 全 1 退化策略」升级为**多模态版**：算「只读文本探针」「只读图探针」「拼接探针」三个退化基线，**任一不低于联合判定则该指标作废**。判据：判定组 ≥95% 而 NR >5% ⇒ 现有二值图审在用"塌成无信息"换安全分，撤回"图审已达标"。

#### A7【验收口径，零训练，半天】判定 / 信息 / 事件三栏 + 用户侧误伤体感

| 体感 | 本轮机制证据 | 建议监控指标 |
|---|---|---|
| "我没写违规内容却被拒" | 27339：只读场景的监控器对良性问题**过度拒答**；27905：`non-generation ≠ 拒答率` | 按一级类目 × 主题切片的误杀率；**把"没出图"与"被拒"分列**；申诉回捞率 |
| "明明检查过了还是出图" | 27905：最强图审召回 **73.9%**，主体非人时系统性失明 | 分类器判低风险但人工双盲仍判有害的比例 |
| "改完意思变了 / 被敷衍" | 27229：无约束剪枝 **−0.81**，保结构剪枝 **+0.32** ⇒ 增益来自"保住什么" | 原子要件保留率（主体/属性/关系）+ 用户意图满足率 |

**硬约束**：任何优化**不得以降低帮助性换降风险**；`误杀 ≤5.2%` 与 `漏过 ≤3.42%` 双约束下比较，只报单侧改善的一律不进看板。

#### A8【方案写死，无需实验】四层降风险通路的互补边界（第十一轮，本轮新增"生成过程干预"独立成层）

| 层 | 管什么 | 明确失效边界 |
|---|---|---|
| **权重侧擦除** | 上线前不可逆概念、概念概率压制 | 下游微调回装无管辖权（2611.24220）；连自己的 loss 都不能当验收 |

### B. 风险锚点处理启发（双锚点：PORN/VULG 边界 + 政治 L2_30 层级）

#### B1 PORN/VULG：本轮给出**第六种**解释 —— 「判定层在读主体/场景代理量」

前五种：二维 depict/enable（11-02）、少身份维 (S,I)（11-03）、词驱动锚点（11-04）、"太弱测不到"（11-10）、承诺形式与定义层（11-23）。本轮新增：**27905 的图审把"主体是不是人"当成仇恨判据**、**27339 的灰图纯文本探针 0.9645 AUROC** ⇒ `VULG-HINT-EDGE` 的混淆可能不是标注错，而是**判定装置读了一个更便宜的代理量**。

三条零训练判据（成本递增）：

| # | 做法 | 判据 | 结论 |
|---|---|---|---|
| 1 | 100 条 `VULG-HINT-EDGE` 跑「原句 / 反事实还原主体 / 灰图纯文本探针」三版 | 反事实版召回显著升、灰图探针 AUROC ≥0.90 | **主体/单模态捷径驱动**，改类目定义无效，改判定推理结构 |
| 2 | 按 27905 的分歧口径，把边界样本按「暗示性线索 vs 显式道具」分档报分歧率 | 分歧集中在暗示档（本文 521/13,124，判仇恨 345） | **定义层 / 暗示强度问题**，不是阈值偏 |
| 3 | 图审 AB 加 `NOTRELEVANT` 档 + 三退化探针基线（A6） | 判定 ≥95% 而 NR >5% 或退化基线不低于联合判定 | 安全分在用塌陷/捷径换分，指标作废 |

**与前五解释的关系**：第六种不取代前五种，但给了一个**不需要重新标注、不需要重训**的入口；与 11-23 的"承诺形式"合起来指向同一结论——**先测判定装置在读什么，再决定改什么**。

#### B2 政治 L2_30：本轮的关键是「分层口径的覆盖缺口」与「量化定向翻转」

三条硬证据：**27155** 的对抗臂在 3/5 seeds 类似地"按模型族/量化器定向"压低目标类目（146:54 harmful:helpful flips，另一族**反号**）；**26881** 明说 MSVD-QA 验证集低代表 How/When、**完全不含 Where** ⇒ 聚合 Bias 不能替代逐类目；**20623** 的 VLM rubric 人工一致率在 harassment 只有 **70.0%** 而 sexual 达 93.0% ⇒ 类目间可判性本身不齐。

| # | 做法 | 判据 | 含义 |
|---|---|---|---|
| 1 | 按 L1 × L2_30 逐格报 FPR 与**判定翻转率**（不只报全局） | 全局稳而某叶子翻倍 | 聚合口径掩盖子类劣化 |
| 2 | 每个类目标注 `样本数 / 人工一致率 / 是否低代表` 三元信息 | 某叶子 <200 样本或一致率 <70% | **继承父类阈值并写明降级口径**，不可单独调阈值（EBSG 按概念单独配 `βtxt/βimg` 是正面参照） |
| 3 | 报 L1–L4 等级分布与各级患病率 | 一级一致率相同而分布差 >10 点 | ordinal calibration 先于调阈值 |

> **为什么不是再调一次阈值**：27155 证明排序不变时阈值只平移 operating point，且量化后**有害/有帮助翻转按族定向**；26881 证明 judge 偏置单向。⇒ **先钉死等级形状与分层口径，再认证阈值**。

#### B3 跨锚点共同结论

两个锚点这轮的答案都是：**先分清「判不出来」和「判定装置在读代理量」**。PORN/VULG 是主体/单模态捷径与定义层，L2_30 是分层覆盖缺口与定向翻转；**两条都不需要重新标注**，各半天到一天。

### C. 三维评测设计启发

#### C1 三维聚合：补第四维「组合层生效」+ 第五维「代理量纯度」

现有三维「语义保持 / 安全提升 / 指令遵循」全是单件级。本轮六篇共同要求补两栏：

| 维度 | 现有 | 建议新增 |
|---|---|---|
| 语义保持 | CLIP / LLM judge | 原子要件保留率（主体/属性/关系）+ 完整命题等价人工双盲 |
| 安全提升 | 分类器风险分 | 图文联合状态判定 + 三通路（生成/编辑/多轮）一致性 |
| 指令遵循 | 要件匹配 | 逐通路要件保留率差 |
| **组合层生效** | 已提出（11-23） | completed-message 复核通过率 + 图文两通路一致性 |
| **代理量纯度**（本轮新增） | — | **灰图探针 AUROC / 反事实还原前后判定差 / `NR` 塌陷率 / 逐对翻转率 / judge Bias** |

**判据**：若三维总分上升而"代理量纯度"任一指标恶化 >10 点 ⇒ 这次上升**不可信**（是把难判样本推出去了，或读数被代理量抬高了），不予上线。

#### C2 阈值 operating point：约束 + 四元组 + 认证 + 重选触发 + **分层配置指纹**

延续 11-23 C2，本轮补两条：**EBSG 的 `h / τ / βtxt / βimg` 按概念与 backbone 单独配置** ⇒ per-category threshold 有了正面参照；**27155 的脆弱窗口随模型规模 25%→7%** ⇒ 小模型（2B 改写 / 小 judge）**不能与大 8B 共用一份不劣化结论**。四元组（阈值、选择规则、数据划分、代价比）之外，加**第五元组「模型规模/量化器」**。

#### C3 Conformal 覆盖稳定性：本轮补「判定集合在换」的第三种量

- 11-08 Coverage Hides Churn：覆盖 ≤0.01 变而 60–67% 图像改判；
- **27155：准确率 0.03 点不动而 1.1–12.3% 成对判定翻转、best-of-64 选择变 14.6–65.7% 而最终答案只变 2.6–9.6%** ⇒ **「最终结论稳定」是最粗的一层，中间决策层可以全换**；
- **26881：judge 偏置单向、单次抽样波动 18 点** ⇒ 连"尺子"都在动。

⇒ "覆盖稳定"必须同时钉死**四件事**：评测单位（图/prompt/批次/成对判定）、聚合口径、区间方法、**判定装置配置指纹**。缺任一，这句话不成立。

#### C4 多版本回归口径（6 个模型版本迭代看板）+ 背离检出 / 严重退化留痕 / 跨评测集泛化缺口

在 11-23 C4 五条要求上补三条：

| # | 本轮新增 | 依据 | 判据 |
|---|---|---|---|
| 6 | **逐样本判定翻转矩阵**（版本 v vs v−1，按 L1×L2_30 分格） | 27155 聚合 0.03 点掩盖 1.1–12.3% 翻转 | 翻转 >3% ⇒ 该版本指标不可与前一版直接比 |
| 7 | **judge 配置指纹与五次抽样** | 26881 单次抽样波动 18 点 | 极差 >10 点 ⇒ 该轮 AB 作废重跑 |
| 8 | **跨评测集泛化缺口列**（eval_not_include / OOD） | 27339 跨 benchmark 探针掉到 0.48–0.67 AUROC | 同 ckpt 跨集差 >10 点 ⇒ 该版本结论只在单集成立 |

**整体指标与分层宏平均背离的检出**（沿用 11-23 五步，本轮加"翻转矩阵"作为第 3 步的前置）：固定分母 → 出 `版本 × 一级类目 × L2_30` 的 F1/FPR/翻转率矩阵 → 算 `Δaggregate` 与 `Δmacro` 的**符号与差值** → 判据 `Δaggregate>0 而 Δmacro<0` ⇒ **子类劣化被聚合掩盖，不予上线** → 逐格定位 → 留 ckpt/配置/数据集版本/评测口径四元组。

**严重退化 ckpt 根因留痕**（对齐 S1461 L3 宏 F1 10.53% 经 lr03 修复回 86.02%）：除学习率敏感性、训练稳定性、分层崩溃版本检出外，本轮补**量化器/硬件/checkpoint 精度**作为第四个必查维度（27155 证明同一 ckpt 换个 4-bit 量化器就能定向翻转）。

#### C5 灰度 / 观察模式前后口径一致性

六层风控指标框架（业务结果 / 拦截能力 / 风险态势 / 全链路专项 / 误伤体验 / 技术健康）沿用 11-23 表格，本轮新增两行硬要求：

- **拦截能力层**：除误杀 5.2% / 漏过 3.42% 双约束外，加 **「最终拦截结论变化率」与「中间选择变化率」分列**——两者差 5–8× 时，只报前者会漏掉整套策略漂移（27155）。
- **技术健康 SLO 层**：改写/图审链路 P95 延迟、超时率、降级率之外，加**量化器/bit 宽指纹**与**判定翻转率**；观察模式（shadow，只记不拦）与生效模式**分列**，否则前后不可比。

**硬要求不变**：shadow → canary → 全量每一步**冻结同一份评测单位、聚合口径、阈值规则、judge 示例集与配置指纹**；只换流量比例，不换尺子。

### D. 下一步实验建议（六条主线）

> 排序原则：先做零训练、能一次结束纠结的；算力按**训练集群 6 节点 → 5 节点**的现实排。**明确：本轮不再把重心放在加严输入改写。**

#### 主线①【tag-weighted loss / 层级标签】D1：L1 × L2_30 双列 + 饥饿格子 + 类目可判性三元信息（半天，零训练）

出 `AUROC × BA × 样本数 × 人工一致率`，按「识别型 / 判定型」二分；标出 <200 样本、一致率 <70% 的饿格子。依据 20623：rubric 一致率从 sexual 93.0 到 harassment 70.0 不齐；27155：小模型/量化器定向翻转。**判据**：饿格子存在 ⇒ 先补数据再上联合头（−0.360 教训）；判定型格加权后 F1 不升反降 ⇒ 降权而非加权重。

#### 主线②【RL 改写】D2：GRPO 与 SFT 线的奖励设计对比（1 天，零训练前置 + 轻训练）

**GRPO 线（devcloud `grpo1102_125`）** vs **SFT 多版本并行线**，同一张表报四件事：

| 对比项 | GRPO 线 | SFT 线 | 判据 |
|---|---|---|---|
| 主奖励 | 安全率 | 监督信号 + tag-weighted loss | 安全率提升是否伴随语义保真下降 |
| 可验证奖励 | **G7 前置**：50 条高危 prompt × 原样/微改/真改写三版 | 不适用 | 原样一致性分显著更高 ⇒ 奖励可作弊，任何 loss 调整先停 |
| 奖励上界 | 从真实正例分布 75 分位量出（GARM） | 由标注分布定 | 上界以上是否增益转负 |
| 多目标 | 安全率 × 语义保真 × 指令遵循，**几何平均**禁跨维补偿 | 同左 | 任一维接近 0 直接打穿样本分 |

**本轮新增**：与 **AnimalFarm 的 GRPO 四分项**（正确性 0.7 / 格式 0.1 / checklist 0.1 / 目标群体 0.1）做结构对照——它把「格式/checklist/目标群体」显式拆开，可检查本项目奖励是否把"格式合规"误当"安全"；同时 **P2E 的配对证伪**（高增益 vs 低增益只差 +0.14）提示：**「改写后风险分降幅」这类代理量本身可能不是好奖励**。必做：DSC 三版对照进奖励验证面板、平均改动字符数监控、edit rate / Levenshtein / 图像一致性奖励配齐、**RL 与 SFT 共用同一评测口径版本号**。

#### 主线③【标签审计与阈值校准】D3：认证式选点 + 实际 FPR + judge 尺子体检（半天，零训练，**最优先**）

四件事一起做：① 约束式阈值选点 + 四/五元组（A5/C2，加模型规模/量化器）；② 6 版本看板补实际 FPR、逐样本翻转矩阵、两矩无标签估计；③ 参考集来源审计 + 1% 投毒演练；④ **judge 示例标签平衡冻结 + 五次抽样 + 人工共识双盲**（A5）。**判据**：任一版本出现「AUROC 稳而 FPR 漂」「准确率稳而逐对翻转 >3%」「judge Bias >+15 点」，历史 AB 按版本重算。

#### 主线④【输出侧图审与溯源】D4：三栏拆分 + 生成过程干预（1 天，推理为主，**明确不再加严输入改写**）

**做法**：按 A1 把 2,700+ 条拆三栏；按 A2 做判定层反事实改造（零训练，对标 +35.6 点）；按 A3 做**固定同一份改写后 prompt** 的三臂生成对照（原样 / CFG 安全引导 / 子概念+局部引导）；图审 AB 加 `NR` 塌陷档与三退化探针基线（A6）；按编辑强度轻/中/重分档测水印检出率。

**判据**：③ 显著优于 ② ⇒ 生成过程干预是主修法；判定组 ≥95% 而信息组 <70% 或 NR >5% ⇒ 撤回"图审已达标"；轻编辑档水印就掉到 <90% ⇒ 水印方案比公开方法更脆（11-23 的 ≥99% @10⁻⁶ FPR 是基线）。

> **责任边界写死**：本轮归因已明确 2,700+ 条源于出图侧内生风险 ⇒ **输入改写的优化预算冻结**，转投出图侧干预与图审判定层；输入侧只保留「文本复核仍有害」的极小比例修正。

#### 主线⑤【I2I 改写链路（含统一生成-编辑模型改写面）】D5：0/0% 的第五种归因（1 天，零训练，**优先级仅次于 D3**）

**背景**：I2I 改写分流命中 **0/0%**（输入侧色情模型灰度 **70%** 与改写分流 **0/0%** 并存）。五种归因：判据无分辨率 / 改写没写好 / 改写抹掉要件 / 分流只读文本通路（11-23 UNR 格）/ **本轮新增：训练与验收数据本身允许文本单通道通关（27339 灰图探针 0.9645 AUROC）**。

**做法（A1 + 27339 合并，2 天，零训练）**：
1. 2000 条评测集按 2×3 析因重打标，报 6 格命中率 ⇒ 定位是「分流单通道」还是「判据无分辨率」；
2. 对每格跑**灰图纯文本探针**与**冻结图只换指令**两个对照 ⇒ 若灰图探针 AUROC ≥0.90 ⇒ **验收集有词捷径，0/0% 是数据问题不是模型问题，重写改写器无效**；
3. 对"风险图 + 中性指令"格单独跑图审分，与最终决策对照（26569 的 0.195 vs 0.113 同构）；
4. **统一生成-编辑模型的改写面**：固定一份改写后 prompt，分别走生成通路与编辑通路，报两通路的风险判定差与原子要件保留率差（AnimalFarm 三通路 66.6/68.0/75.3 已给出「同一策略不能跨通路共用」的公开证据）。**判据**：两通路差 >15 点 ⇒ 不能共用一份改写，必须按通路分流下发；差 <5 点 ⇒ 可共用，但要把图文联合状态作为共同输入。

**为什么这条最省钱**：五种归因全是**重打标 + 重跑现有链路 + 加两个探针**，零训练、不重做评测集。

#### 主线⑥【多模态视频扩展】本轮**给建议**（与上一轮不同：`t10_video_safety` 首次有强相关工作）

**2611.27268** 给出可迁移的三条：① 护栏指标改成 **exposure（用户看到的有害帧）**而非终局准确率，对应本项目「用户侧可感知误伤」与六层风控的**误伤体验层**；② **便宜 guard 读已有 hidden states 决定何时调贵检测器**（2.35 帧 @5.3 次 vs 逐块 0.91 帧 @80.1 次），直接服务技术健康 SLO（延迟/超时/降级）；③ **收益在排序不在预算**（随机 37.20 vs 排序 2.35），对应风险知识召回的**指令命中优先级**与降级兜底（A4）。

**建议**：AIGC 全模态策略命中事件落表中 i2v/t2v 输入/输出字段继续对齐；把「exposure 式累计暴露」与「guard 排序」两个口径**先搬到图像侧 AB**（半天，零训练），**等 i2v/t2v 落表 >1000 条再评估是否单独建视频策略**，不新增独立策略。

#### 跨语言专项【针对 2B 改写模型英文 ASR 飙升】D6：三语 × 三形态九格（1 天，零训练 + 训练排期）

**本轮判断**：27905 未覆盖中英混合、27339 未测跨语言、20623 未测文化地区语境，加上 11-23 的 CuRSE-Bench English-only 与 DSC 未覆盖中英混合，以及 2611.18601（语言风格改写让 ASR 在 **<6% 与 80%** 间摆动）⇒ **语言覆盖 / 文化语境 / 语用形态是三个独立维度**。

1. 把 A2 的三版对照扩成 **中 / 英 / 中英混合（code-switching）× 三形态 = 9 格**，报每格 ASR 漂移与改写后风险残留率；
2. **必含「中性 Prompt 的语义取向漂移」对照臂**：同一中性句三语下跑现有分类器，看分数分布是否系统性偏移（对齐 27339 的"单模态捷径"——英文档可能靠词表捷径通关）；
3. 若英文档 ASR 显著高于中文档 ⇒ 支持**中英合并训练**，但训练前先做两件零训练事：① 检查英文训练样本是否集中在显式风险词（补"无表层线索 + 文化特定"样本）；② 检查是否把疑问/肯定语用形态当成低风险（DSC 思路）；
4. 合并训练后**必须报分语言 ASR 与分层宏平均**，禁止只报聚合 ASR；并叠加 27155 的**小模型脆弱窗口占用率**（2B 约 25%）单列，禁止与 8B 共用不劣化结论。

## 附：今日一句话结论

**六篇都在说同一件事：被当成达标读数的那个量，往往只是真正风险的代理，而且脱钩是单方向的——所以分数没动，判定已经全换了。** 对本项目的落点只有一句：**别再往输入侧加码了**。先把「灰图探针验收、三通路对照、出图侧生成过程干预、逐对翻转 + judge 尺子四栏不劣化」这四层补进验收，把 2,700+ 条 case 从"改写还不够严"改写为"风险长在出图侧"，再谈优化重心放在哪一层；否则 0/0% 会继续被写成"改写没写好"，而实际上连评测集都允许纯文本探针拿到 0.9645 AUROC。
