### 沉淀的可复用经验
1. 检索首选定 API 的 `submittedDate` 窗口 + 降序 + 分页；HTML 通道不要用其日期字段做窗口过滤。
2. 下"空窗"结论前必须先核对 arXiv 最新公告批次停在哪天。
3. 奖励审计必须同时读**配对差值**与**正胜率**，只看均分会把方向相反的奖励判成好奖励。
4. "最差类别"这类极差统计要过置换检验，bootstrap 在参数边界上覆盖率只有 64–76%。
5. 路由层不需要大模型：2B 与 32B 主任务分几乎持平（4.5898 / 4.6002），开销只 94ms。
