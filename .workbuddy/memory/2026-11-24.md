## 方法论沉淀（跨轮可复用）

1. **代理量 ≠ 目标量，且脱钩是单方向的**：本次六组配对（benchmark AUROC / 输入文本无害 / 二值安全通过 / SFT 生成增益 / 聚合准确率 / judge 准确率）全部呈现「代理量稳住、目标量整体换边」。⇒ 任何聚合指标上线前必须配一个「逐单元」对照量（单模态控制上界 / 三通路对照 / 语义完整性 / 逐对翻转 / 人工共识）。
2. **验收装置本身要先被验收**：五个公开 benchmark 允许纯文本探针拿 0.9645 AUROC，judge 的 few-shot 标签平衡能单向抬 29.5 点 ⇒ 版本间比较的可能是装置而不是模型；AB 看板必须冻结「judge 配置指纹」。
3. **输入改写的有效性上界是责任边界问题，不是训练问题**：它只能对「文本无害」负责，不能对「出图无害」负责。AnimalFarm 是公开文献里第一次给出跨三通路量化对照（92.1%/95.9%/73.9%）。
4. **四层降风险通路补齐**：输入侧热更新改写（P2E 证明 SFT 监督目标应按「意图相关」而非「生成增益」筛选）· 权重侧概念擦除 · 不改输入不改权重的生成过程干预（EBSG）· 输出侧图审与溯源（主体非人时检测器系统性失明）。任一层单独宣称内容安全已解决即判越界。
5. **量化 / 加速验收的下限**：聚合准确率 0.03 点 vs 1.1–12.3% 成对翻转、selection 变 5–8× 于 answer、脆弱窗口小模型 25%→7% ⇒ fp8/fp4 与 P800/qwen3.5 Pro5000 迁移必须做「逐对翻转 + 分层 F1 + 安全率不劣化 + 灰度前后策略一致性」四栏。
6. **第十一条检索纪律**：网页端十分类串行拉全批池后，全部主题/形态通道本地正则复现；零命中只判「该主线零供给」，不能判「整批零供给」，且必须逐篇过 title+abstract 才能定「可迁移」。
