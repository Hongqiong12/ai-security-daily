### 关键坑：工蜂 committer-check
工蜂开启提交者校验，直接 `git push gongfeng main` 被拒：
```
You can't push commit[03300a9d] with committer[sentinelliu]
or email[sentinelliu@users.noreply.github.com] that does not belong to the account[aegisliu]
```
- 本仓库 64 个历史 commit 的 committer 均为 `sentinelliu`（GitHub noreply），2 个为 `ageisliu@*.local`，都不属于工蜂账号 `aegisliu`。
- **工蜂账号正确身份：`aegisliu <aegisliu@tencent.com>`**
- 认证本身没问题（`~/.ssh` 无公钥 → SSH 走不通；HTTPS 无 .git-credentials / keychain 记录，但仍通过，疑似环境注入）。

### 解决方案：快照同步（已写入 scripts/sync_remotes.sh）
在 `gongfeng/master` 之上追加一个 commit，文件树用 `git read-tree -u --reset main` 取自本地 main，
committer 强制 `aegisliu <aegisliu@tencent.com>`，再 push 到 master。
- 优点：不 force push、不改历史、不被 committer-check 拒
- 代价：工蜂历史是快照式（每次同步 1 commit），与 GitHub 完整历史不同
- 幂等：内容一致时输出 SKIP 并判定成功
