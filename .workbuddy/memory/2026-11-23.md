## 方法论沉淀（跨轮可复用）

1. **第十条检索纪律**：并发打导出 API 会限掉整个 IP 且不区分查询类型；网页端是独立限流池。全批池拉全后，主题词/形态通道一律本地正则复现。
2. **只在单个部件 / 入口 / 平均值上做的验收，必须补一个组合层的生效指标**：图文析因格 / 不变换 control / 承诺分散对照 / reject-vs-report / 排序-vs-操作点 / 效用-vs-约束，六组配对对照模板可直接复用。

4. **判定、信息、事件是三个独立的量**：NotaryMark（判定 100% / 信息 60.69%）+ Tripwire-WM（拒了却没记录）⇒ 图审 AB 至少三栏。
