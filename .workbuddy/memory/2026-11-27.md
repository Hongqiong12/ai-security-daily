## 方法论结论（可跨轮复用）

1. **安全率上涨 ≠ 策略变强，增益机制纯度成第八维**：Flow-GRPO 按技能拆 `pass@k`，四技能为 **sharpening**（`k*=4/10/8/5`、`pass@32` 几乎不动）、relations 为 **unlocking**（`pass@32→1.00`、零覆盖 prompt 93% 被救、`pass@128=0.89 < RL pass@1=0.94`）；Activation Steering 用 188 个常数向量 / `0.29M` 参数（rank-32 LoRA `18.8M` 的 `1/65`）、**目标不含奖励**即恢复六个 image ckpt `90.0–96.3%` 增益。⇒ 安全率涨了先报 `k*` 与 Δceiling 判锐化/解锁；锐化转 best-of-k + verifier，解锁才动训练；策略容量不是瓶颈，奖励稀疏才是。
2. **输入改写有效性上界归因五栏扩为六栏**，新增「GRPO 增益机制」栏；3,000 条 case 中约 10 条改写文本仍有害、约 2,700+ 条为出图侧内生风险的结论不变，**优化重心仍不在加严输入改写**。
3. **语义保真必须能判「该改的改了、不该改的没动」**：PreserveReward 双教师 OPSD（local 查细微变化 / joint 判是否符合编辑意图）+ minimum-KL 投影校准（误差预算 0.01）+ score-guided gradient routing + 双负跳过蒸馏（消融 **+4.7** 点）。Table 2 显示 EditScore-72B / RationalRewards / UnifiedReward 做 RL 后 GEdit-v1 反不如 Base ⇒ **奖励选型先过版本回归关再进 RL**，可直接迁移到 I2I 0/0% 归因与风险知识召回降级。
4. **加速比必须按类目 × 难度拆开**：T2ISpec 1,400 prompts × 7 topics × 2 difficulty，AR 类 topic 偏离 **±20%** 而 diffusion/flow 仅 **±4%**；Overall criterion `0.0000` 掩盖 text `+0.0233` / commonsense `−0.0242`；ADT-Tree `−42.0% work` 只换 `1.0889×`；SpeCa 阈值 `5→9`，Easy `+0.0383` / Hard `−0.0517` 方向反转。⇒ 量化/加速不劣化**八栏扩为十栏**（新增 Δwork vs Δlatency、分层方向一致性），并始终并报安全率与分层宏 F1。
5. **英文 ASR 飙升有机制级解释**：`2611.33307` 25 models × 17 tasks × 14 languages / 25,626 平行项，**325/325** model–language pair 掉准确率、**301** 过度自信上升，`Gap = ΔConf − ΔAcc = +1.6`；英文 95% 阈值迁到 Tamil 只保 90.0%、中文 93.1%。per-language temperature scaling 把 ECE `4.1%→2.9%` 但**准确率不回**；语言 60% + base model 34% 解释方差。⇒ 先做 per-language 校准体检，再决定中英合并训练；别把阈值漂移当数据不足。
6. **策略可配置护栏首次实质命中（六周零供给终结）**：`2611.33263` what/who/when 三元组 `triplet → safety protocol` 放在**权重外**、可编辑可审计，换策略不重训不重标注；判定与干预解耦；what/who 一致率 >89% 而 **when 仅 0.53**；median latency 低约 10×，发布版 FPR `0.09/0.02/0.03`。⇒ A3 风险知识召回降级兜底（词库 > 向量库、≤3 直拼、>3 top3、超时/拼接失败事件化）与 D1 分层标签的参考实现。
